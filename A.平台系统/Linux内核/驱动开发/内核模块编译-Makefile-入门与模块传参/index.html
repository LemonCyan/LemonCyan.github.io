三、内核编程 内核模块文件的入口和出口。它由2 个宏来注册入口和出口，分别是： 这 2 个宏在头文件目录的include/linux/module.h。宏里面的x 代表注册到内核的入口和出口函数。通俗 一点讲就是模块初始化和模块卸载时调用的函数。 http://d5da2ffa.fromwiz.com/share/s/3lSy_W0xl4SM2WTmit29CtcC0aOXaW2tHkHM23TYyg1L4txc ifneq ($(KERNELRELEASE),) obj-m:=hello.o else KDIR := /lib/modules/$(shell uname -r)/build PWD:=$(shell pwd) all: make -C (KDIR)M=(PWD) modules clean: rm -f *.ko *.o *.symvers *.cmd *.cmd.o endif makefile 中变量的说明 KERNELRELEASE 在内核源码的顶层目录下的 Makefile 中有定义 KDIR 获得当前内核的源码目录 shell uname -r 获得当前内核版本号 shell pwd 获得当前工作目录 makefile 的执行过程 输入 make 执行 makefile 后，由于 KERNELRELEASE 没有定义，会执行 else 段代码 记录下内核的源码目录和当前工作目录 make -C (KDIR)M=(PWD) modules ，参数 -C 就会进入内核源码顶层目录，然后执行 Makefile ，此时会对 KERNELRELEASE 进行赋值，参数 M=$(PWD) 表示返回当前目录再次执 行 Makefile ，参数 modules 表示编译成模块 再次执行 Makefile ，此时 KERNELRELEASE 已经有值，就会执行 obj-m ： =hello.c
