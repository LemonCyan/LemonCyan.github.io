day01（模块） #

【1】模块 可在运行的时候添加到内核中的代码称之为模块

【2】模块和应用程序的区别 应用程序 模块 运行空间： 用户空间 内核空间 入口函数： main函数 加载函数 库 ： 操作系统提供的lib库 内核源码库 资源释放： 可以释放 必须释放 段错误危害： 危害小 危害大

【3】模块的三要素 模块许可证声明（必须） MODULE_LICENSE( "GPL" ) 模块加载函数（必须） 1--- 缺省的形式 int init_module(void) { //做初始化相关的工作 return 0； } 2-- 自定义形式 int hello_init(void) { //做初始化相关的工作 return 0； } //声明hello_init为模块的入口函数 module_init(hello_init); 模块卸载函数（必须） 1--- 缺省形式 void cleanup_module(void) { //做和init_module相反的工作 } 2-- 自定义形式 void hello_exit(void) { //做和init_module相反的工作 } //声明hello_exit为模块的卸载函数 module_exit(hello_exit); 【4】模块相关的命名 insmod: 装载一个模块 insmod hello.ko lsmod : 查找一个模块 lsmod 或者 lsmod | grep hello rmmod : 卸载一个模块 rmmod hello

 dmesg -C: 清空缓冲区
 dmesg -c: 先打印再清除

 dmesg:   查看printk打印信息

 modinfo hello.ko： 查看模块信息

【5】模块传参 1. 在模块中定义一个变量来接收参数 int myint = 0; 2. 声明变量来接收参数 module_param(参数名,参数类型,参数读/写权限） module_param(myint, int, 600) 3. 装载模块的时候传入参数 sudo insmod hello.ko myint=10

    insmod hello.ko myint=10 mystring="farsight" myarr=2,12,34

=========== 字符设备驱动框架 ===================

【1】按访问方式分类 字符设备驱动 按照字节顺序访问 鼠标，键盘 帧缓冲设备：LCD，摄像头 c 块设备驱动 按照块进行随机访问 存储设置 emmc flash b 网络设备驱动

【2】设备号 dev_t: 32位的无符号整形 高12位： 主设备号，表示这个设备属于哪一类设备 低20位： 次设备号，表示这个设备属于这类设备中的某一个具体的设备

 构造设备号：
      int major = 255
      int minor = 0
      1-- 传统方法
          dev_t devno = major << 20 | minor;
      2--
          dev_t devno = MKDEV(major, minor);
 注册设备号  ---  加载函数里面实现    注册成功可通过cat /proc/devices 查看
      int register_chrdev_region(dev_t from, unsigned count cnt, const char *name)
      register_chrdev_region（devno, 1, "hello-device"）
      dev_t from： 设备号
      unsigned count cnt：注册的设备的数量
      const char *name：设备的描述
      返回值：成功返回0， 失败返回一个负数
 卸载设备号： ---  卸载函数里面
      void unregister_chrdev_region(dev_t from, unsigned count)

 动态注册设备号
       int alloc_chrdev_region(dev_t *dev, unsigned baseminor, unsigned count,const char *name)

【3】初始化cdev结构体 文件操作集合 struct file_operations hello_fops{ .owner = THIS_MODULE, // };

 1. 构造一个cdev结构体
    struct cdev mycdev;
 2. 初始化cdev
    void cdev_init(struct cdev *cdev, const struct file_operations *fops)
cdev_init(&mycdev, &hello_fops);

    mycdev.owner = THIS_MODULE;
 3. 注册cdev
    int cdev_add(struct cdev *, dev_t, unsigned)
    cdev_add(&mycdev, devno, 1);
 4. 释放cdev
    void cdev_del(struct cdev *);

创建设备节点 节点名字 字符设备 主设备号 次设备号 sudo mknod /dev/hello c 255 0

搭建一个字符设备驱动框架分三步 1-- 注册一个设备号 2-- 初始化cdev 3-- 实现文件操作的集合
