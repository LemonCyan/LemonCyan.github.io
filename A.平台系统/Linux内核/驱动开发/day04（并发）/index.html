day04（并发）

day04（并发） #

【1】并发 多条指令同时执行 优点：高效 缺点：竞争问题 -- 对临界资源的访问

 临界资源：同一时刻可能被多个进程访问的资源
 临界区：  访问临界资源的代码

 产生竞态的原因：
    1. 多核处理器   原子操作， 自旋锁
    2. 多进程       信号量
    3. 进程和中断   中断屏蔽

用一个flag实现一个驱动同一时刻只能被一个进程打开 24 if (hello_dev.flag == 1) 25 { 26 hello_dev.flag = 0;

以上程序存在问题 flag是一个临界资源，对它的访问不是原子的

互斥机制 中断屏蔽 原子操作 自旋锁 信号量

【1】原子操作 1. 定义一个原子变量 atomic_t flag; 2. 设置原子变量的值 void atomic_set(atomic_t v, int i); / 设置原子变量的值为i */ atomic_set(&flag, 1); 3. 操作并测试 int atomic_inc_and_test(atomic_t *v); int atomic_dec_and_test(atomic_t *v);

   上述操作对原子变量执行自增、自减和减操作后（注意没有加）测试其是否为0，为0返回true，否则返回false。

4. 原子变量自增/自减
   void atomic_inc(atomic_t *v);    /* 原子变量增加1 */
   void atomic_dec(atomic_t *v);    /* 原子变量减少1 */

【2】信号量 信号量一般是用来同步的，二值信号量可以用来互斥的 申请到信号量，信号量的值减1，可以访问临界资源 申请不到信号量，阻塞睡眠

1. 定义信号量
    struct semaphore sem;

2. 初始化信号量
   void  sema_init(struct semaphore *sem, int val);
   sema_init(&sem, 1)

3. 信号量的获取
   void  down(struct semaphore * sem);
   int  down_interruptible(struct semaphore * sem);

   睡眠的时候可以被中断打断
4. 信号量的释放
   void up(struct semaphore * sem);

【3】 中断屏蔽 一般情况下不推荐使用 local_irq_disable() /* 屏蔽中断 / . . . critical section / 临界区*/ . . . local_irq_enable() /* 开中断*/

【4】自旋锁 锁：获取锁，可以访问临界资源 自旋：获取不到锁，忙等待，

对于不同的cpu，锁的处理方法：
 1. 单核非抢占      空操作
 2. 单核抢占        关抢占
 3. 多核            关抢占， 自旋

  1. 定义自旋锁 spinlock_t lock;

  2. 初始化自旋锁 spin_lock_init(&lock)

  3. 获得自旋锁 spin_lock(&lock) 如果能够立即获得锁，它就马上返回，否则，它将自旋在那里

  4. 访问临界资源

  5. 释放自旋锁 spin_unlock(&lock)
