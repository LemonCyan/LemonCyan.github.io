Linux系统大致可分为3层：靠近硬件的底层是内核kernel，即Linux操作系统的常驻内存部分；中间层 是内核之外的Shell（命令解析器）层，亦即操作系统的系统程序部分，负责用户和操作系统的沟 通。；最高层是应用层，即用户程序部分，包括各种文本处理程序、语言编译程序及游戏程序等。

预处理阶段：预处理器可以删除注释、包含其它文件以及进行宏替换。 gcc -E  -o hello.i hello.c 编译阶段：编译阶段的主要工作是把我们的源代码生成相应的汇编代码的过程。 gcc -S -o hello.s hello.i 汇编阶段：将汇编语言翻译成计算机能识别的机器语言。 gcc -c hello.s -o hello.o 链接阶段：将一个或者多个由编译器或汇编器生成的目标文件外加库链接为一个可执行的文件。（链 接阶段是通过链接器完成的） gcc hello.o -o hello
