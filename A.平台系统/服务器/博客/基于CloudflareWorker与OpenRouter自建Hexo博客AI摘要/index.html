基于CloudflareWorker与OpenRouter自建Hexo博客AI摘要

Hexo 博客接入 OpenRouter：基于 Cloudflare Worker + KV 打造白嫖级流式 AI 摘要 #

很多主题（比如 Stellar、Butterfly）都支持 AI 摘要功能，但点开配置一看，默认几乎都绑定了商业 SaaS 的 Key。想要用自己的大模型 Key 吧，又面临一个致命问题：静态博客没有后端，把 OpenRouter 或 OpenAI 的 API Key 直接塞进前端 JS，等于裸奔，分分钟被别人顺着网线把你的 Token 薅秃。

想要白嫖 OpenRouter 的免费/低价模型（比如 DeepSeek、Gemini 2.0 Flash），又想要炫酷的实时流式打字机效果，最优雅的解法就是：手搓一个 Cloudflare Worker 做中转代理 + 挂一个免费的 Cloudflare KV 缓存。

核心架构与爽点 #

sequenceDiagram
    autonumber
    actor User as 访客浏览器
    participant CF as Cloudflare Worker (中转+鉴权)
    participant KV as Cloudflare KV (永久缓存)
    participant OR as OpenRouter (LLM 大模型)

    User->>CF: 请求文章摘要 (POST post_id + 正文)
    CF->>KV: 检查该文章是否生成过摘要？
    alt KV 命中缓存
        KV-->>CF: 返回缓存文本
        CF-->>User: 秒级返回完整摘要 (零 Token 消耗)
    else 首次访问 / 未缓存
        CF->>OR: 携带私密 API_KEY 请求流式生成 (SSE)
        OR-->>CF: 流式 Chunk 返回
        CF-->>User: 实时打字机推流到浏览器
        CF->>KV: 生成完毕，将完整文本写入 KV 永久保存
    end

为什么这么设计？ #

  • 保住钱包与 Key：API Key 存在 Cloudflare Worker 环境变量里，前端完全不可见。
  • 白嫖级成本：Cloudflare Worker 每天免费 10 万次请求，KV 每天免费 10 万次读取。
  • 零重复扣费：每篇文章不管有几万人看，只要第一次访问生成后写入 KV，后续所有人都是直接读缓存，调用 OpenRouter 的次数永远为 1 次。

一、 后端部署：手搓 Cloudflare Worker #

1. 创建 KV 命名空间 #

  1. 登录 Cloudflare Dashboard。
  2. 依次点击左侧侧边栏 Workers & Pages -> KV。
  3. 点击 Create a namespace，起个名字，比如 AI_SUMMARY_KV。

2. 创建 Worker #

  1. 回到 Workers & Pages -> Overview，点击 Create Application -> Create Worker。
  2. 起个名字（如 hexo-ai-summary），点击 Deploy。
  3. 点击 Edit code，把里面的代码全删掉，换成下面这套即配即用的完整逻辑：
javascript
// Cloudflare Worker: hexo-ai-summary.js

const SYSTEM_PROMPT = `你是一个专业的技术博客助手。请阅读用户提供的博文内容，生成一段 100~180 字以内的精炼文章摘要。
要求：
1. 语言通顺精炼，概括核心技术点与解决的问题。
2. 直接输出摘要纯文本，绝不包含任何诸如“本文介绍了”、“摘要：”等多余的前缀或废话。`;

export default {
  async fetch(request, env) {
    // 1. 处理 CORS 跨域预检
    if (request.method === "OPTIONS") {
      return new Response(null, {
        headers: {
          "Access-Control-Allow-Origin": "*",
          "Access-Control-Allow-Methods": "POST, OPTIONS",
          "Access-Control-Allow-Headers": "Content-Type",
        },
      });
    }

    if (request.method !== "POST") {
      return new Response("Only POST method allowed", { status: 405 });
    }

    try {
      const { id, content } = await request.json();
      if (!id || !content) {
        return new Response(JSON.stringify({ error: "Missing id or content" }), { 
          status: 400,
          headers: { "Content-Type": "application/json" }
        });
      }

      // 2. 查询 KV 缓存
      const cacheKey = `summary:${id}`;
      const cached = await env.AI_SUMMARY_KV.get(cacheKey);
      if (cached) {
        // 如果命中缓存，直接返回 JSON，前端直接显示
        return new Response(JSON.stringify({ summary: cached, cached: true }), {
          headers: {
            "Content-Type": "application/json",
            "Access-Control-Allow-Origin": "*",
          },
        });
      }

      // 3. 没命中缓存，请求 OpenRouter 流式接口
      const model = env.MODEL_NAME || "deepseek/deepseek-chat";
      const openRouterResp = await fetch("https://openrouter.ai/api/v1/chat/completions", {
        method: "POST",
        headers: {
          "Authorization": `Bearer ${env.OPENROUTER_API_KEY}`,
          "Content-Type": "application/json",
          "HTTP-Referer": "https://github.com/hexo",
          "X-Title": "Hexo AI Summary",
        },
        body: JSON.stringify({
          model: model,
          stream: true,
          messages: [
            { role: "system", content: SYSTEM_PROMPT },
            { role: "user", content: content.slice(0, 2500) } // 截取前 2500 字足够提取核心
          ],
        }),
      });

      if (!openRouterResp.ok) {
        const errText = await openRouterResp.text();
        return new Response(JSON.stringify({ error: "OpenRouter Error", detail: errText }), {
          status: 500,
          headers: { "Access-Control-Allow-Origin": "*", "Content-Type": "application/json" }
        });
      }

      // 4. 流式转发并异步收集完整文本写入 KV
      let fullText = "";
      const { readable, writable } = new TransformStream();
      const writer = writable.getWriter();
      const reader = openRouterResp.body.getReader();
      const encoder = new TextEncoder();
      const decoder = new TextDecoder();

      (async () => {
        try {
          while (true) {
            const { done, value } = await reader.read();
            if (done) break;
            const chunk = decoder.decode(value, { stream: true });
            
            // 解析 SSE 数据行
            const lines = chunk.split("\n");
            for (const line of lines) {
              if (line.startsWith("data: ") && line.trim() !== "data: [DONE]") {
                try {
                  const json = JSON.parse(line.slice(6));
                  const text = json.choices?.[0]?.delta?.content || "";
                  fullText += text;
                } catch (e) {}
              }
            }
            // 实时把 chunk 推送给前端
            await writer.write(value);
          }
        } finally {
          await writer.close();
          // 推流完成后，将聚合好的完整文本写入 KV 永久缓存
          if (fullText.trim().length > 0) {
            await env.AI_SUMMARY_KV.put(cacheKey, fullText.trim());
          }
        }
      })();

      return new Response(readable, {
        headers: {
          "Content-Type": "text/event-stream",
          "Cache-Control": "no-cache",
          "Connection": "keep-alive",
          "Access-Control-Allow-Origin": "*",
        },
      });

    } catch (e) {
      return new Response(JSON.stringify({ error: e.message }), {
        status: 500,
        headers: { "Access-Control-Allow-Origin": "*", "Content-Type": "application/json" }
      });
    }
  },
};

3. 绑定环境变量与 KV #

代码保存后，进入该 Worker 的 Settings 页面：

  1. Variables（环境变量）：
    • 点击 Add，添加 OPENROUTER_API_KEY，值为你在 OpenRouter 申请的 Key（勾选 Encrypt 加密保存）。
    • 添加 MODEL_NAME，值为 deepseek/deepseek-chat 或 google/gemini-2.0-flash-001。
  2. KV Namespace Bindings（绑定 KV）：
    • 点击 Add binding。
    • Variable name 填：AI_SUMMARY_KV。
    • KV namespace 选择你刚刚创建的 AI_SUMMARY_KV。
  3. 点击 Save and Deploy 搞定！
  4. 记录下你的 Worker 访问域名，比如：https://hexo-ai-summary.yourname.workers.dev。

二、 前端挂载：接入 Hexo 博客文章页 #

在博客根目录下，新建一个前端脚本文件 source/js/ai_summary.js：

javascript
// source/js/ai_summary.js
document.addEventListener('DOMContentLoaded', () => {
  const postArticle = document.querySelector('article.content') || document.querySelector('.post-content') || document.querySelector('#article-container');
  if (!postArticle) return;

  // 1. Worker 地址配置 (换成你自己的 Worker 域名)
  const WORKER_URL = 'https://hexo-ai-summary.yourname.workers.dev';

  // 2. 获取当前文章唯一标识与纯文本内容
  const postId = location.pathname;
  const rawText = postArticle.innerText.replace(/\s+/g, ' ').trim();
  if (rawText.length < 50) return; // 字数太少不生成

  // 3. 在文章正文前插入 AI 摘要卡片容器
  const aiBox = document.createElement('div');
  aiBox.className = 'custom-ai-box';
  aiBox.innerHTML = `
    <div class="ai-header">
      <div class="ai-title">🤖 <span>AI 摘要</span></div>
      <div class="ai-tag">OpenRouter</div>
    </div>
    <div class="ai-content" id="ai-summary-text">
      <span class="ai-loading">正在思考并提取文章核心...</span>
    </div>
  `;
  postArticle.parentNode.insertBefore(aiBox, postArticle);

  const textEl = document.getElementById('ai-summary-text');

  // 4. 发起请求
  fetch(WORKER_URL, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ id: postId, content: rawText })
  }).then(async (response) => {
    const contentType = response.headers.get('content-type') || '';
    
    // 如果返回 JSON 说明命中了 KV 缓存
    if (contentType.includes('application/json')) {
      const data = await response.json();
      if (data.summary) {
        textEl.innerText = data.summary;
      } else {
        textEl.innerText = '暂无摘要生成。';
      }
      return;
    }

    // 否则为 SSE 流式响应，打字机实时展示
    textEl.innerText = '';
    const reader = response.body.getReader();
    const decoder = new TextDecoder();
    
    while (true) {
      const { done, value } = await reader.read();
      if (done) break;
      const chunk = decoder.decode(value, { stream: true });
      const lines = chunk.split('\n');
      for (const line of lines) {
        if (line.startsWith('data: ') && line.trim() !== 'data: [DONE]') {
          try {
            const json = JSON.parse(line.slice(6));
            const char = json.choices?.[0]?.delta?.content || '';
            textEl.innerText += char;
          } catch (e) {}
        }
      }
    }
  }).catch((err) => {
    console.error('AI Summary Error:', err);
    textEl.innerText = 'AI 摘要服务暂时离线。';
  });
});
