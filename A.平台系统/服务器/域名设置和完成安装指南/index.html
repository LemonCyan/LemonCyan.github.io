域名设置和完成安装指南 #

  • 步骤 1：设置域名和子域名
  • 步骤 2：在脚本安装后访问管理员页面
  • 步骤 3：完成最终安装

在安装脚本后，您必须完成最终的面板安装配置。这共分为 3 个步骤。首先，您需要注册一个域名。

1. 如何设置域名和子域名 #

在下面的视频中，详细介绍了设置域名和子域名的所有步骤。虽然此视频是波斯语的，但通过观看操作步骤您依然可以轻松完成。我们也计划制作英文版的视频教程，在那之前您可以先阅读并参考本文中的指南。

设置域名和子域名的步骤 #

  • 首先，访问 FreeDNS 网站 并注册一个账号（无需填入真实身份信息，但邮箱必须正确）。

  • 通过发送到您邮箱的链接激活您的账号。
  • 登录创建的账号，点击此链接并选择一个公共域名。

建议选择以下后缀的域名：

com , net , org

  • 输入您想要的子域名以及您服务器的 IP 地址。

  • 复制您创建完成的子域名。

注：以上步骤仅适用于直连（Direct）域名。如果您想了解如何注册其他类型的域名，请点击此处。

2. 脚本安装完成后访问管理员页面 #

您主要可以通过以下 2 种方式来完成初始安装（即脚本安装阶段）：

  • 通过知名云服务商的一键安装脚本 (cloud-init)。
  • 通过 SSH 登录 Ubuntu 服务器并直接运行安装脚本。

请根据您所使用的方法继续进行：

重要提示：本程序仅支持在 Ubuntu 22.04 服务器版本上安装。

2.1. 通过 cloud-init 方式继续安装 #

如果您在 Vultr、Hetzner 等平台使用了快速安装脚本 (cloud-init 模式)，系统会自动为您生成一个临时链接（有效期为 1 小时）。

如何获取此临时链接？

请等待约 10 分钟。然后直接在浏览器中输入并打开您的服务器 IP 地址：http://your_server_ip。

例如，如果您的服务器 IP 是 1.1.1.1，请在浏览器中输入 http://1.1.1.1 并打开。 注意：该临时链接仅在一小时内有效，过期后将失效。

打开该一次性临时链接即可访问管理员页面。

2.2. 直接在 Ubuntu 上继续安装 #

如果已安装在 Ubuntu 系统上，安装完毕后，终端中会生成管理员链接。请确保管理员链接的格式是正确的。详细信息

在浏览器中打开该链接以进入管理面板。

步骤 3：完成最终安装 #

首次打开管理员页面时，系统会显示快速设置页面。将我们在第一步中复制的子域名填入指定字段，如下图所示：

点击“提交” (Submit) 按钮，然后点击 应用配置 (Apply Configs) 以使设置在面板中生效。

为了更好地使用面板的各项功能，请参考这篇文章。

获取客户端连接节点的链接 #

为此，请前往管理菜单中的用户部分。点击用户对应的链接，进入该用户的专属主页。

在此页面中，系统会根据操作系统推荐适合的客户端连接软件。

您也可以在页面下方查看为该用户生成的各种代理节点配置。

使用二维码（黄色突出显示部分）或节点链接导入客户端即可。
