VPS选型

最近在找便宜的美国 VPS，预算控制在一年二十美元以内，翻了几个论坛后发现 Dedirock 这家出现频率挺高。这篇记录一下我对他们两款年付套餐的了解，包括配置、适用场景和需要注意的坑。

💡 如果你已经决定买了，直接看官网：Dedirock VPS 套餐页面

我为什么要找便宜 VPS #

需求其实挺简单的：

  • 放个人博客或者小工具
  • 跑点轻量服务：定时脚本、API、Bot 之类的
  • 有个开发测试环境，和生产隔离开
  • 美国机房，访问北美资源方便

主流 VPS 服务商动不动就 5 美元/月起步，一年下来六七十美元，对个人项目来说有点贵。所以十几美元年付的选项就很有吸引力，前提是——真的能用。

Dedirock 的卖点就是便宜但靠谱：KVM 虚拟化、SSD 存储、美国机房，该有的都有。

核心配置一览 #

机房位置 #

  • 洛杉矶：西海岸，对亚太访问相对友好
  • 纽约：东海岸，面向北美东部和欧洲更合适

两个都是经典的美国机房位置。

虚拟化 #

KVM 虚拟化 + 完整 root 权限。比 OpenVZ 隔离性好，想装什么系统和软件都行。

硬件 #

  • SSD 存储，读写速度不拖后腿
  • 1Gbps 网络端口（共享带宽）

技术支持 #

7×24 工单支持，一般问题能得到响应。不过毕竟是便宜套餐，别指望秒回。

两个套餐对比 #

Special Saver（入门款） #

配置项 参数
存储 10 GB SSD
内存 768 MB
CPU 1 核
流量 1 TB / 月
IPv4 1 个
价格 约 $10.18 / 年

适合场景：

  • 单个静态博客或小站
  • 定时任务、脚本服务
  • 想体验一下美国 VPS 的入门用户

768 MB 内存跑个 Hexo 博客或者轻量 API 绰绰有余，再重就有点吃力了。

Special Economy（进阶款） #

配置项 参数
存储 20 GB SSD
内存 2 GB
CPU 1 核
流量 2 TB / 月
IPv4 1 个
价格 约 $20.88 / 年

适合场景：

  • 跑多个站点或服务
  • 装 Docker、面板之类稍重的东西
  • 打算长期用，需要一点余量

2 GB 内存日常使用松很多，多开几个容器也不容易 OOM。

怎么选 #

选 Saver 的情况：

  • 只跑一个小站，需求明确
  • 静态站或者纯 API 服务
  • 就想便宜，够用就行

选 Economy 的情况：

  • 想在一台机器上跑多个东西
  • 后续可能会扩展
  • 多花十美元换个安心

我最后选的是 Economy。虽然现在用不满 2 GB，但万一以后想加点服务，不用再折腾迁移。

适合干什么 #

推荐用法：

  • 个人博客（WordPress、Hexo、Hugo）
  • 小工具（短链接、Webhook、自动化脚本）
  • 开发测试环境
  • 轻量面板 + 少量站点

不建议用法：

  • 高并发数据库
  • CPU 密集型任务（编译、爬虫）
  • 关键生产环境的唯一节点

简单说就是：轻量服务没问题，重活别指望它。

买之前想清楚这几点 #

  1. 年付有风险
    便宜是便宜，但万一用不上或者服务商跑路，钱就打水漂了。确认自己真的会用再买。

  2. 备份自己做
    别指望服务商帮你备份。重要数据定期同步到其他地方。

  3. 性能预期要合理
    十几美元一年的机器，不可能有多强的性能。够用就行，别扛大流量。

  4. 看清 TOS
    邮件群发、挖矿、爬虫之类的用途大多禁止，上车前看清规则。

总结 #

Dedirock 这两个套餐定位很清楚：

Saver Economy
价格 $10.18/年 $20.88/年
内存 768 MB 2 GB
存储 10 GB 20 GB
流量 1 TB 2 TB

都是 KVM + SSD + 独立 IPv4 + 美国机房，对个人项目来说配置够用。

如果你也在找一台便宜的美国 VPS，不需要多强的性能，只要能稳定跑一年，Dedirock 可以考虑。
