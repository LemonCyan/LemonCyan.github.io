如何在服务器与计算机之间传输文件 #

许多时候，您需要在服务器和本地计算机之间互相传输文件。例如，您可能想要下载服务器上的备份文件到本地，或者将本地系统中的配置文件上传到服务器。实现此目的有多种简单的方法。

前置准备 #

根据您的操作系统，在本地打开对应的终端工具：

  • Windows 系统：PowerShell
  • Mac 系统：终端 (Terminal)
  • Linux 系统：终端 (Terminal)

提示： 在 Windows 系统中，如果您的 PowerShell 尚未安装 SSH 相关组件，可以以管理员权限打开 PowerShell 并运行以下命令安装：

Add-WindowsCapability -Online -Name OpenSSH.Client

在服务器上查看备份文件列表 #

要查看服务器上已有的备份文件列表，请先通过 SSH 连接到服务器，然后运行以下命令：

ls /opt/hiddify-manager/hiddify-panel/backup

命令的输出结果如下所示：

选择其中一个您想要传输的备份文件名。

通过 SCP 命令将文件从服务器传输到本地系统 #

在本地终端（PowerShell 或 Terminal）中使用以下命令格式：

scp <用户名>@<服务器IP>:<服务器上的文件路径> "本地系统中的存放路径"

例如，如果您的服务器登录用户名是 root，服务器 IP 是 1.1.1.1，您想要将服务器上的面板备份文件下载到本地 C 盘的 Backup 文件夹中，则可以运行以下命令：

scp root@1.1.1.1:/opt/hiddify-manager/hiddify-panel/backup/2023_05_06__06_00_03.json "C:\Backup"

传输完成后，目标备份文件就会成功保存到本地的 Backup 文件夹中。

通过 SCP 命令将文件从本地系统传输到服务器 #

同样，假设您的服务器登录用户名是 root，IP 地址是 1.1.1.1。现在您本地 C:\File 路径下有一个 text.txt 文件需要上传到服务器上。在本地终端中运行以下命令：

scp "C:\File	ext.txt" root@1.1.1.1:/opt/hiddify-manager

上传完成后，text.txt 文件就会被复制到服务器上的相应目录下。您可以通过在服务器中运行以下命令来查看上传的文件：

ls /opt/hiddify-manager
