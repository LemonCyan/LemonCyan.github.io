如何在服务器上更改 SSH 默认端口 #

要在 Ubuntu 或其他 Debian 系的 Linux 系统上更改 SSH 端口，您需要修改 SSH 守护进程的配置文件。以下是具体的执行步骤：

  1. 打开 SSH 守护进程配置文件： 使用 nano 或 vim 等命令行文本编辑器打开 SSH 配置文件 (sshd_config)。编辑此文件需要 root 或管理员权限。例如运行以下命令：

    bash
    sudo nano /etc/ssh/sshd_config

  2. 定位 Port 配置项： 在文件中查找以 Port 开头的行。该配置项指定了 SSH 服务所监听的端口，默认通常为 22。您可以将其修改为您想要的任何未被占用的端口号，例如：

    text
    Port 2222

  3. 保存并退出： 保存您的修改并退出文本编辑器。在 nano 中，您可以通过依次按 Ctrl + x，然后按 y 键确认，最后按回车键（Enter）完成保存并退出。

  4. 重启 SSH 服务： 修改配置文件后，必须重新启动 SSH 服务使配置生效。运行以下命令：

    bash
    sudo systemctl restart ssh

    或者在较旧的 Linux 系统版本中运行：

    bash
    sudo service ssh restart

  5. 验证端口更改： 您可以通过运行以下命令来验证 SSH 服务是否已成功监听在新的端口上：

    bash
    ss -tuln | grep 2222

    （请将 2222 替换为您实际设置的新端口号）

  6. 在防火墙中放行新端口： 如果您在服务器上开启了防火墙，请务必更新规则以放行新的 SSH 端口，否则在退出当前会话后您将无法再次连接到服务器。以使用 iptables 为例，运行以下命令放行新端口：

    bash
    sudo iptables -A INPUT -p tcp --dport 2222 -j ACCEPT

    （将 2222 替换为您配置的新端口）

为了使规则在服务器重启后依然有效，您需要将其持久化保存。对于 Ubuntu 系统，可以使用 iptables-persistent 或以下命令将规则保存到文件中：

bash
sudo sh -c 'iptables-save > /etc/iptables/rules.v4'

以后如果需要恢复这些规则，可以执行：

bash
sudo sh -c 'iptables-restore < /etc/iptables/rules.v4'

提示： 更改默认的 22 端口可以有效防止黑客对您的服务器进行批量的自动化扫描与暴力破解，从而显著提高服务器的安全性。请务必记住您配置的新端口，并在下次使用 SSH 连接时指定该端口。
