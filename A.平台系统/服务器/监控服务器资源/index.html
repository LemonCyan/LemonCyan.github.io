监控服务器资源

使用 htop 工具进行资源控制 #

htop 是 Linux 服务器中控制和查看资源的常用工具之一。

  • 首先，通过 SSH 连接到服务器。

  • 点击 Cancel（取消）或同时按下 Ctrl+c 键关闭 Hiddify 菜单。如果菜单在此之后仍显示，请输入命令 clear 并回车。

  • 如果您的服务器尚未安装 htop，请通过以下命令进行安装：

    apt install htop

通常，此程序在 Ubuntu 20.04 和 22.04 上是默认安装的。

  • 然后运行此命令以打开 htop：

    htop

在该程序中，您可以查看每个进程对服务器资源的消耗情况。

  • 要查看每个进程的 CPU 消耗量，可以点击 CPU 进行排序，以此查看哪个进程占用的 CPU 百分比最高。

  • 同样，要查看每个进程消耗了多少 内存 (RAM)，可以点击 MEM 进行排序。

  • 如果发现是 Hiddify 服务（如 hiddify-panel、hiddify-nginx、hiddify-xray 等）占用了最多资源，请退出 htop。

  • 要退出 htop 环境，您只需按下 ctrl+c 或 q 键。

  • 然后，通过以下命令进入一次 Hiddify 菜单：

    bash /opt/hiddify-config/menu.sh

  • 使用方向键（上下）选择 restart 选项，等待服务重启完成。然后再次退出 Hiddify 菜单 并检查 htop。

释放内存 (RAM) #

内存 (RAM) 实际上是一个临时存储空间，其空间被运行中的服务所占用。部分内存也由操作系统本身占用。

内存的占用量与面板上的用户数量没有直接的线性关系。无论面板中定义了多少用户，为了使操作系统及外围服务正常工作，一系列基础服务必须保持运行。因此，内存占用并非单纯由用户数决定，而是由当前运行的服务直接决定。

操作系统始终负责管理服务器的资源，如果服务器的内存占用率达到 80% 左右，这完全属于正常现象，无需担心。

在 Linux 服务器中，不要仅为了解决内存占用问题而重启系统。

  • 改善服务器内存状况的方法之一是清理内存缓存。当您以 root 用户身份登录时，可以在终端中使用以下命令清理缓存：

    sync && sysctl -w vm.drop_caches=3

请务必确保以 root 用户身份登录后再执行此命令。
