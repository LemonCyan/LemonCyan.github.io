FTP 配置

FTP 的数据传输模式 #

FTP（File Transfer Protocol）是一个基于客户端/服务器架构的文件传输协议，支持两种工作模式：

  • 主动模式：客户端向 FTP 服务器发送端口信息，服务器主动连接该端口。
  • 被动模式：FTP 服务器开启并发送端口信息给客户端，客户端连接服务器的端口，服务器被动接受连接。

说明：大多数 FTP 客户端运行在局域网中，通常没有独立的公网 IP 地址，并且可能会被防火墙拦截。在主动模式下，FTP 服务器连接客户端将面临更多困难。因此，除非有特殊需求，否则建议将 FTP 服务器配置为被动模式。

Linux 环境下的 FTP 服务器 #

在 Linux 环境下，有几种常用的 FTP 服务器软件，每种都有其特点和用途：

  • Wu-ftpd

    • 特点：Wu-ftpd 是历史最久的非商业 FTP 服务器之一，功能丰富，支持多种传输模式和用户管理方式。
    • 官网：http://www.wu-ftpd.org/

  • Proftpd

    • 特点：Proftpd 是一个完全独立开发的 FTP 服务器，旨在提供一个安全且易于配置的替代品。它支持多种认证方式和访问控制机制。
    • 官网：http://www.proftpd.org/

  • vsftpd

    • 特点：vsftpd 以其高性能和稳定性著称，尤其适合需要处理大量并发连接的服务器。它的配置文件简单，易于管理。
    • 官网：http://vsftpd.beasts.org/

FTP 服务的使用者 #

FTP 支持以下三种认证模式：

  1. 匿名用户模式：允许任何人无需密码直接登录 FTP 服务器。此模式安全性最低，通常只用于存放不重要的公开文件，生产环境中不推荐使用。
  2. 本地用户模式：依赖于 Linux 系统的本地账号进行验证，相较于匿名模式更为安全。
  3. 虚拟用户模式：FTP 服务器专用的用户，限制访问 Linux 系统的其他资源，进一步提升 FTP 服务器的安全性。

FTP 的典型消息 #

消息号 含义
125 数据连接打开，传输开始
200 命令 OK，表示上一个命令执行成功
226 数据传输完毕，表示文件传输已经成功完成
331 用户名 OK，需要输入密码
425 不能打开数据连接，可能是服务器端口被占用或防火墙阻止了连接
426 数据连接被关闭，传输被中断，可能是网络问题或服务器主动断开连接
452 错误写文件，可能是服务器磁盘满、权限不足或文件被锁定
500 语法错误，不可识别的命令，可能是客户端发送了服务器不支持的命令

vsftpd 的配置文件 #

vsftpd 的配置文件分为以下几个部分：

  • /etc/vsftpd/vsftpd.conf：vsftpd 的核心配置文件。包含了大部分的配置选项，如匿名用户设置、权限控制、传输模式等。
  • /etc/pam.d/vsftpd ：这是 vsftpd 的 PAM 配置文件，用于配置用户认证方式。PAM（Pluggable Authentication Modules）允许 vsftpd 使用不同的认证模块，如本地用户认证、LDAP 认证等。
  • /etc/vsftpd.ftpusers 或 /etc/vsftpd/ftpusers：黑名单文件，列出的用户将无法访问 FTP 服务器。默认情况下，这些用户包括 root 和其他系统用户，以防止敏感账号被用于 FTP 登录。
  • /etc/vsftpd.user_list 或 /etc/vsftpd/user_list：白名单文件，列出的用户可以访问 FTP 服务器。该文件用于指定允许或禁止访问 FTP 服务器的用户列表。当 userlist_enable 选项启用时，可以通过 userlist_deny 选项控制是允许还是禁止列出的用户访问服务器。

安装 VSFTPD #

默认使用 21 端口作为服务端口，需要保证服务器的规则启用的 21 端口

cpp
sudo apt install vsftpd

安装完成后，通过以下命令查看 vsftpd 启动状态，已经启动并监听了 21 端口

cpp
sudo netstat -nltp  | grep 21
sudo netstat -antup | grep ftp            # 查看监听端口

启动服务 #

cpp
sudo systemctl enable vsftpd.service      # 设置开机启动
sudo systemctl start vsftpd.service       # 启动 vsftpd 服务
sudo systemctl status vsftpd              # 检查 vsftpd 服务的状态

sudo service vsftpd start                 # 启动 vsftpd 服务
sudo service vsftpd stop                  # 停止 vsftpd 服务
sudo service vsftpd restart               # 重启 vsftpd 服务

配置文件解析 #

以下是优化后的 vsftpd 配置文件，添加了详细的注释和示例，帮助您更好地理解每个参数的作用。

cpp
# 基本设置
listen=YES                       # 启用IPv4监听
listen_ipv6=YES                  # 启用IPv6监听
listen_port=21                 # 设置监听端口为8021

# 安全设置
local_umask=022                  # 设置上传文件的权限掩码，022表示其他用户无写权限
security_mask=077                 # 定义安全掩码，限制上传文件的权限

# 用户访问控制
local_enable=YES                 # 允许本地用户登录
anonymous_enable=NO              # 禁用匿名访问，保护服务器安全
chroot_local_user=YES            # 将用户限制在其主目录中，增强安全性
chroot_list_enable=YES           # 启用例外用户列表
chroot_list_file=/etc/vsftpd.chroot_list  # 指定例外用户列表文件

# 用户列表控制
userlist_enable=YES              # 启用用户列表功能
userlist_deny=NO                 # 允许列表中的用户登录
userlist_file=/etc/vsftpd.user_list  # 指定允许访问的用户列表文件

# FTP根目录
local_root=/home/ubuntu             # 设置FTP用户的根目录

# 被动模式设置
#pasv_enable=YES                  # 启用被动模式
#pasv_address=<FTP服务器公网IP>    # 设置被动模式的公网IP
#pasv_min_port=6000               # 设置被动模式的最小端口
#pasv_max_port=6010               # 设置被动模式的最大端口

# 传输限制
max_per_ip=3                     # 每个IP的最大连接数为3
local_max_rate=5000000             # 本地用户的最大传输速率为5000KB/s
anon_max_rate=3000000              # 匿名用户的最大传输速率为3000KB/s

# 权限控制
write_enable=YES                 # 允许文件上传
anon_upload_enable=NO            # 禁止匿名用户上传文件
anon_mkdir_write_enable=NO       # 禁止匿名用户创建目录
anon_other_write_enable=NO       # 禁止匿名用户修改或删除文件
chown_username=ftpuser           # 匿名上传的文件归属用户

# 编码设置
utf8_filesystem=YES              # 使用UTF-8编码支持

# 日志设置
xferlog_enable=YES               # 启用传输日志
xferlog_std_format=YES           # 使用标准格式记录传输日志
vsftpd_log_file=/var/log/vsftpd.log  # 指定日志文件路径

# 其他设置
tcp_wrappers=YES                 # 启用TCP包装器进行访问控制
seccomp_sandbox=NO               # 禁用seccomp沙盒，避免潜在问题
allow_writeable_chroot=YES       # 允许可写的chroot目录

用户列表配置 #

编辑用户列表文件，允许特定用户访问 FTP 服务器：

bash
sudo vim /etc/vsftpd.user_list

添加允许的用户名，每行一个：

plaintext
ftpuser1
ftpuser2

保存后，重启 vsftpd 服务：

bash
sudo systemctl restart vsftpd

创建 FTP 用户 #

  1. 创建 FTP 用户组：
bash
sudo groupadd ftpgroup
  1. 创建 FTP 用户，指定主目录：
bash
sudo useradd -g ftpgroup -d /home/ftpuser -s /sbin/nologin ftpuser
  1. 设置用户密码：
bash
sudo passwd ftpuser
  1. 创建 FTP 文件存放目录：
bash
sudo mkdir -p /data/ftp
sudo chown ftpuser:ftpgroup /data/ftp
sudo chmod 755 /data/ftp
  1. 限制用户仅能通过 FTP 访问：
bash
sudo usermod -s /sbin/nologin ftpuser

本地用户配置示例 #

cpp
listen=YES
listen_ipv6=NO

# 禁止匿名登录
anonymous_enable=NO

# 允许本地用户使用系统账号登录
local_enable=YES

# 允许用户上传文件
write_enable=YES

# 设定 umask，保证上传文件权限安全
local_umask=022

# 指定用户根目录（可选）
chroot_local_user=YES

# 允许用户进入自己的 home 目录
allow_writeable_chroot=YES

# 允许 ASCII 传输（可选）
ascii_upload_enable=YES
ascii_download_enable=YES

# 允许被动模式
pasv_enable=YES

# 指定被动模式端口范围（确保端口范围较小，方便防火墙配置）
pasv_min_port=9080
pasv_max_port=9099
