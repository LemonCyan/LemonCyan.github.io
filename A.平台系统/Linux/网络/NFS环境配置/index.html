NFS环境配置

配置 TFTP 服务 #

a. 安装 TFTP 服务 #

使用以下命令在系统中安装 TFTP 服务及其守护进程：

bash
sudo apt-get install tftp tftpd-hpa

这一步骤确保拥有一个功能齐全的 TFTP（简易文件传输协议）服务，能够在网络环境中进行文件的传输和共享。

b. 修改配置文件 #

编辑 TFTP 的默认配置文件，以便于调整服务参数：

bash
sudo vi /etc/default/tftpd-hpa

在该文件中，可以设置 TFTP 服务器的基本属性，例如服务启动的方式、监听的 IP 地址等。确保根据自己的需求对这些参数进行适当的配置。

c. 修改服务目录 #

指定 TFTP 服务的根目录，不同于默认目录：

bash
/home/fs/tftpboot

确保该目录的存在，并具备足够的存储空间以存放要共享的文件。

d. 重启 TFTP 服务 #

保存配置文件后，通过下面的命令重启 TFTP 服务，以应用上述配置：

bash
sudo service tftpd-hpa restart

这将重新加载 TFTP 服务，确保新的配置被正确应用。

e. 拷贝内核文件 #

为了保证开发环境能够从虚拟机中下载内核文件，需要将 zImage 文件拷贝到 TFTP 服务的根目录：

bash
cp /path/to/zImage /home/fs/tftpboot/

确保在拷贝之前，zImage 文件已经存在于指定路径。

常见报错

  • 权限不允许
    检查权限设置，可通过以下命令更改 tftpboot 目录及其子目录的访问权限：

    bash
    chmod 777 /home/fs/tftpboot -R

  • 文件名未找到
    确保 zImage 文件确实存在于 TFTP 根目录。

确认配置文件中定义的服务目录与实际运行的目录一致。

挂载目录 #

a. 配置 NFS 文件 #

编辑 NFS 导出文件以定义要共享的目录：

bash
sudo vi /etc/exports

添加共享目录的配置：

bash
/home/fs/nfsboot *(rw,sync,no_subtree_check)

这里 *(rw,sync,no_subtree_check) 的含义是所有客户端可以以读写模式访问这个目录，且文件同步时不会检查子目录。

b. 重启 NFS 服务 #

虽然 NFS 服务默认情况下会一直运行，但在更改配置后，执行以下命令以确保更改生效：

bash
sudo service nfs-kernel-server restart

c. 拷贝文件系统 #

将 rootfs.tgz 文件系统拷贝到 NFS 的共享目录中：

bash
cp /path/to/rootfs.tgz /home/fs/nfsboot/

d. 解压文件 #

解压刚才拷贝的 rootfs.tgz 文件，以便使用：

bash
sudo tar -zxvf /home/fs/nfsboot/rootfs.tgz

此命令将文件解压到 nfsboot 目录，方便后续访问。

e. 改变文件权限 #

确保文件系统内的文件和目录对所有用户开放访问权限：

bash
sudo chmod 777 /home/fs/nfsboot/rootfs -R

开发板设置 #

a. 设置开发相关 IP #

在开发板的环境中设置相关的网络参数：

bash
setenv serverip 192.168.2.2  // 服务器 IP 地址
setenv ipaddr 192.168.2.3    // 开发板 IP 地址
setenv netmask 255.255.255.0 // 子网掩码
setenv gatewayip 192.168.1.1  // 网关

这些环境变量将确保开发板能够连接到网络和服务器。

b. 设置开发板启动参数 #

定义启动命令，以通过 TFTP 从服务器下载内核文件并启动：

bash
setenv bootcmd tftp 20008000 zImage; go 20008000

当开发板启动时，它会自动执行该命令，通过 TFTP 从服务器（192.168.2.2）下载 zImage 文件到开发板内存地址 0x20008000，下载完成后，CPU 从该地址开始执行内核。

如果想使用 zImage_all 内核进行启动，可以按照以下步骤操作：

  1. 重启开发板。
  2. 设置新的启动命令：
bash
setenv bootcmd tftp 20008000 zImage_all; go 20008000
  1. 使用命令保存更改：
bash
save
  1. 启动开发板：
bash
boot

c. 设置文件系统挂载方式 #

配置开发板的启动参数，以指定 NFS 文件系统的相关信息：

bash
setenv bootargs root=nfs nfsroot=192.168.2.2:/home/fs/nfsboot/rootfs ip=192.168.2.3 init=/linuxrc console=ttySAC0,115200

这些设置将确保开发板在启动时通过 NFS 挂载指定的文件系统。

d. 保存设置 #

注意，以上所有设置仅在内存中生效，重启后将会丢失。因此，需要将设置保存到非易失性存储中：

bash
saveenv

各种方式启动开发板 #

  1. 按电源键重启开发板。

  2. 在启动命令行输入 boot 命令。

  3. 使用以下命令从 TFTP 下载内核：

    bash
    tftp 20008000 zImage
go 20008000

通过以上步骤，可以轻松配置和启动开发板，以便于进行开发和测试。
