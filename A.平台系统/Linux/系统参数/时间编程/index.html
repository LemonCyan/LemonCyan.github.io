时间编程

时间类型 #

Coordinated Unicersal Time（UTC）：世界标准时间，也就是大家所熟知的格林威治标准时间（Greenwich Mean Time 吗 GMT）

Calendar Time：日历时间，是用"从一个标准时间点（如：1970 年 1 月 1 日 0 点）到此时经过的秒数"来表示时间

时间获取 #

获取日历时间，即从 1970 年 1 月 1 日 0 点到现在所经历的秒数

cpp
#include <time.h>
time_t time(time_t*tloc);

将日历时间转化为格林威治标准时间，并保存至 TM 结构

cpp
struct tm *gmtime(const time_t*timep);

将日历时间转化为本地时间，并保存至 TM 结构

cpp
struct tm *localtime(const time_t*timep);

cpp
struct tm {
int tm_sec; /* Seconds(0-60) */
int tm_min; /* Minutes(0-59) */
int tm_hour; /* Hours(0-23) */
int tm_mday; /* Day of the month (1-31) */
int tm_mon; /* Month (0-11) */
int tm_year; /* Year - 1900 */
int tm_wday; /* Day of the week (0-6, Sunday = 0) */
int tm_yday; /* Dayin the year (0-365, 1 Jan = 0) */
int tm_isdst; /* Daylightsaving time */
};

将 tm 格式的时间转化为字符串，如：Sat Jul 30 08：43：03：2005

cpp
char*asctime(conststruct tm *tm);

将日历时间转化为本地时间的字符串形式

cpp
char*ctime(const time_t*timep);

获取从今日凌晨到现在的时间差，常用于计算事件耗时

cpp
#include <sys/time.h>
int gettimeofday(struct timeval *tv,struct timezone *tz);

cpp
struct timeval {
time_t tv_sec; /*seconds*/ 秒数
suseconds_t tv_usec; /* microseconds*/ 微秒
};

延时执行 #

使程序睡眠 seconds

cpp
#include <unistd.h>
unsigned intsleep(unsigned intseconds);

使程序睡眠 usec 微秒

cpp
#include <unistd.h>
int usleep(useconds_t usec);
