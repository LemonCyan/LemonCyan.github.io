linux 内存性能调优-alloysystem-ChinaUnix博客

要有效管理和优化 Linux 内存性能，了解其底层结构和可用的工具至关重要。Linux 内存系统划分为虚拟地址和物理地址，由 MMU 进行虚拟地址映射。每个进程都有自己的虚拟空间，通常划分为 4KB 的页，可以通过 getconf PAGESIZE 确认。

内存管理结构 #

  • 节点和区域：内存根据 CPU 访问速度划分为节点，在节点内又划分为区域（例如 DMA、NORMAL、HIGHMEM）。区域负责管理内存区域，维护活动和非活动页表，以便于内存回收。

交换机制 #

当内存紧张时，Linux 将匿名页交换到磁盘。命令如 swapon -s、swapon -a 和 swapoff -a 用于管理交换空间的使用。交换倾向性可以通过调整来优化系统交换的积极程度。

缓存 #

  • 页缓存：存储文件内容以加快访问速度。
  • 缓冲区缓存：缓存如目录和块等元数据。

内存分配 #

Slab 分配器高效地管理小内核分配，减少了开销。命令 slabtop 和 cat /proc/slabinfo 监控 Slab 使用情况，其中包括如 inode 等内核对象。

内存类型 #

内存用于用户空间（代码、数据、堆、栈）和内核空间功能。用户空间包括文件映射和共享内存。页被分类为可回收（匿名、缓存）或不可回收（内核分配）。

监控工具 #

  • vmstat 显示内存统计信息，包括空闲、缓冲、缓存、交换和 I/O 指标。
  • top 结合 shift + m 按内存排序，shift + p 按 CPU 排序。
  • pmap 显示每个进程的详细内存使用情况。

优化策略 #

  1. 监控交换空间使用情况：使用 vmstat 检查交换活动。高交换使用可能表明内存压力。
  2. 调整交换倾向性：修改 /proc/sys/vm/swappiness 控制交换行为。
  3. 区域回收：根据需要调整如 zone_reclaim_mode 等设置，特别是在 NUMA 系统中。
  4. 分析缓存：使用 vmstat 和 slabtop 确保缓存和 Slab 使用效率。
  5. 应用分析：使用如 top 和 pmap 识别出内存密集型进程。

通过利用这些工具并理解内存管理，你可以有效诊断问题并优化性能。
