如何在 Linux VPS 上无缝启用交换空间 (Swap) #

本指南介绍如何在正在运行且缺乏 Swap 的 Linux 虚拟服务器 (VPS) 上无缝添加 Swap 内存。请仔细按照这些步骤操作以避免对现有服务产生干扰。

步骤一：检查当前的 Swap 状态 #

首先，检查当前系统的 Swap 激活状态：

sudo swapon --show

如果输出为空，则表示系统目前没有启用任何 Swap 空间。

步骤二：检查磁盘剩余空间 #

在创建 Swap 交换文件前，确保您的磁盘上有足够的剩余空间。使用以下命令进行检查：

df -h

步骤三：创建 Swap 文件 #

创建一个新的 Swap 交换文件。在以下示例中，我们将创建一个 2GB 大小的 Swap 文件：

sudo fallocate -l 2G /swapfile

如果您的系统不支持 fallocate 命令，可以使用以下替代方案：

sudo dd if=/dev/zero of=/swapfile bs=1M count=2048

步骤四：设置文件权限 #

通过限制其他用户对 Swap 文件的读写权限来确保安全：

sudo chmod 600 /swapfile

步骤五：将文件配置为 Swap 交换分区 #

将新创建的文件格式化为 Swap 交换分区文件：

sudo mkswap /swapfile

步骤六：启用 Swap 空间 #

激活刚刚配置的 Swap 交换文件：

sudo swapon /swapfile

再次验证 Swap 状态以确认其已被正确启用并激活：

sudo swapon --show

步骤七：设置 Swap 开机自启与永久生效 #

为了确保在系统重新启动后 Swap 依然保持激活状态，需要将其写入系统的 /etc/fstab 配置文件中：

echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab

注意事项 #

  • 合适的 Swap 大小：请根据您服务器的实际配置（如物理内存大小）和可用磁盘资源来选择合适的 Swap 大小。
  • 监控 Swap 使用情况：创建完成后，可以使用 free -h 或 htop 等工具来实时监控内存与 Swap 的使用状况。
