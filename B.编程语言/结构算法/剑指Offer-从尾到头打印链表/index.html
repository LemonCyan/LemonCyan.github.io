题目：输入一个链表的头节点，从尾到头打印出每一个节点的值。 ( 要求不改变链表的结构 ) 链表节点定义如下： 1 struct ListNode 2 { 3 int nKey; 4 ListNode *pNext; 5 } 思路一：由从尾到头容易想到栈的后进先出的性质，于是可以用栈实现。 ( 如果可以改变链表的结构，则可以先把链表反转， 再从头依次输出结果 ) 反转链表可参考：
code: 1 // 利用栈实现 2 void PrintListInStack(ListNode *pHead) 3 { 4 ListNode pCur = pHead; 5 std::stack<ListNode> stackA; 6 7 while(pCur != NULL) 8 { 9 stackA.push(pCur); 10 pCur = pCur-

pNext; 11 } 12 13 while(!stackA.empty()) 14 { 15 ListNode *pNode = stackA.top(); 16 stackA.pop(); 17 printf("%d ",pNode->nKey); 18 } 19 }
