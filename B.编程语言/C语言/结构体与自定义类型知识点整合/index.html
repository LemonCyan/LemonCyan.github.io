结构体与自定义类型知识点整合

C 语言结构体与自定义数据类型核心知识点整合 #

结构体 (Structure) 是 C 语言中极其重要的自定义复合数据类型。它允许程序员将不同类型的数据项组合成一个有机的整体，是实现模块化封装和模拟面向对象开发的重要基石。

1. 结构体初始化与字符数组赋值约束 #

1.1 结构体内的字符数组赋值大坑 #

很多初学者在声明结构体后，会尝试直接给其中的字符数组数组成员进行整体赋值，但这在 C 语言语法中是完全禁止的：

❌ 典型错误示范： #

c
#include <stdio.h>

struct Man {
    char name[10];
};

int main()
{
    struct Man N;
    N.name = "qiang"; // ❌ 编译报错：incompatible types when assigning to type 'char[10]' from type 'char *'
    return 0;
}
  • 原因剖析：右侧的 "qiang" 是一个字符串常量，其在表达式中代表该只读字符串的首地址。左侧的 N.name 是结构体内分配的字符数组的数组名。
  • 我们在数组章节中强调过，数组名代表该数组的物理首地址，是一个地址常量（右值），不可被重新赋值。因此试图改变常量地址的赋值会直接引发编译器报错。

正确解决方案： #

  1. 使用 strcpy 物理拷贝内容（最通用方式）：
    c
    #include <string.h>
strcpy(N.name, "qiang"); // 将常量区的内容挨个字符复制到 N.name 数组所在的内存空间中
  2. 对单个元素单独赋值：
    c
    N.name[0] = 'q';
N.name[1] = '\0'; // 必须手动追加空终止符以构成合法字符串

2. 结构体指针的定义与引用 #

2.1 指向结构体变量的指针 #

定义一个指向结构体对象的指针，其指针的类型是该结构体类型本身。

1) 声明与内存分配 #

c
struct stu {
    char name[20];
    long num;
};

struct stu *p1; // 定义结构体指针变量 p1
❢重要

指针变量 p1 自身仅占用 4 字节（32位下）或 8 字节（64位下）的地址内存。如果未对其进行初始化赋值或通过 malloc 申请物理存储空间，它就是一个野指针，任何对其成员的解引用写操作都会触发程序段错误崩溃。

安全分配示例： #

c
#include <stdlib.h>

// 利用 malloc 申请一块能安全容纳 struct stu 大小的堆内存空间
p1 = (struct stu *)malloc(sizeof(struct stu));
if (p1 == NULL) {
    // 错误处理
    return -1;
}

2.2 结构体成员引用操作符：. 与 -> #

  • 成员运算符 . (Dot)：用于结构体类型变量本身。
    • 语法：结构体变量名.成员名
  • 指向运算符 -> (Arrow)：用于结构体指针变量。
    • 语法：结构体指针名->成员名
    • 指向运算符 p1->num 在编译器底层物理等价于：(*p1).num。

嵌套结构体的引用深度： #

当结构体中嵌套了另一个结构体作为成员时，引用的深度随之递增，运算符的选择由当前解引用的变量类型决定：

c
struct data {
    int year, month, day;
};

struct stu {
    char name[20];
    struct data birthday; // 嵌套的结构体成员
};

struct stu *student;
student = (struct stu *)malloc(sizeof(struct stu));

// 1. student 是指针，指向 name，使用 ->
scanf("%s", student->name); 

// 2. student 是指针，指向 birthday，使用 ->。
// 但 birthday 成员是一个普通的结构体变量（不是指针），它引用自己的成员 year 时，必须使用 . 运算符
scanf("%d", &student->birthday.year);

3. 结构体类型数组与指针引用 #

定义一个结构体类型数组时，数组名 student 代表整个数组的首地址。我们可以使用结构体指针指向并遍历该数组。

c
struct stu student[4], *p;
p = student; // 指针 p 指向数组首元素 student[0]

对于结构体数组中第 i 个元素的成员的访问，以下三种方法完全等价：

3.1 1) 地址法（行指针偏移） #

利用指针或数组名进行地址偏移计算，然后通过指向符访问：

  • (student + i)->name
  • (p + i)->name
  • (&student[i])->name

3.2 2) 指针步进法（自增移位） #

利用指针变量的可变性，在循环中执行自增，每次向后移动一个 sizeof(struct stu) 的物理跨度：

c
for (int i = 0; i < 4; i++) {
    printf("%s ", p->name);
    p++; // 移动指针，指向下一个结构体元素
}

3.3 3) 指针的数组下标表示法 #

当指针 p 指向数组 student 首地址后，我们可以直接把 p 当作数组名，利用变址运算符 [] 进行下标访问。

⚠警告

下标运算 p[i] 代表的是第 i 个结构体变量本身，因此访问数组成员时必须使用 . (点运算符)，而绝对不能使用 ->。

  • p[i].name（等价于 student[i].name）

4. 实战项目：基于结构体指针的动态模拟时钟 #

这是一个经典的 Linux 控制台动态时钟程序。它利用结构体存储时间状态，使用指针传递数据，并巧妙利用转义字符 \r 与标准输出刷新，实现在控制台原地跳秒 ticking 的动态动画效果。

c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h> // 提供 sleep 函数

// 1. 定义时间结构体，并用 typedef 简化别名为 Clock
typedef struct Clock
{
    int hour;
    int minute;
    int second;
} Clock;

// 2. 状态更新函数：传入结构体指针，实现秒数累加与进位逻辑
void update(Clock *p)
{
    p->second++;
    if (p->second == 60)
    {
        p->second = 0;
        p->minute++;
    }
    if (p->minute == 60)
    {
        p->minute = 0;
        p->hour++;
    }
    if (p->hour == 24)
    {
        p->hour = 0;
    }
}

// 3. 屏幕刷新显示函数
void display(Clock *p)
{
    // \r 是回车符，使光标回到当前行的起始位置（但不换行）
    // %02d 表示输出最小宽度为 2 的整型，不足 2 位时左侧自动填充字符 '0'，达到 00:00:00 的对齐效果
    printf("\r%02d:%02d:%02d", p->hour, p->minute, p->second);
    
    // 关键点：printf 默认属于行缓冲，在没有遇到换行符 \n 之前不会物理刷新显示器。
    // 这里由于使用了 \r 覆盖写而没有 \n，必须手动调用 fflush 强行冲刷缓冲区输出至屏幕。
    fflush(stdout);
}

int main()
{
    Clock *my_clock;
    
    // 4. 堆区申请内存
    my_clock = (Clock *)malloc(sizeof(Clock));
    if (my_clock == NULL)
    {
        return -1;
    }
    
    // 5. 初始化结构体内存区为 0 （等价于 00:00:00）
    memset(my_clock, 0, sizeof(Clock));
    
    printf("Ticking Clock (Press Ctrl+C to exit):\n");
    
    // 6. 开启定时刷新死循环
    while (1)
    {
        sleep(1);      // 挂起进程 1 秒钟
        update(my_clock);  // 累加秒数
        display(my_clock); // 原地覆盖刷新显示
    }
    
    // 7. 释放堆内存
    free(my_clock);
    my_clock = NULL;
    
    return 0;
}

5. 面向对象编程 (OOP) 在 C 语言中的实现 #

面向对象编程是一种设计思想，而不是某种语言的专属特权。利用 C 语言的结构体、函数指针和聚合组合等特性，我们同样可以优雅地实现面向对象的三大基本特征：封装、继承和多态。

5.1 封装 (Encapsulation) 的 C 语言模拟 #

封装的本质是将“数据成员”与“成员函数”绑定在一起，限制外部对内部数据的随意改动。

  • 在 C++ 中，类（Class）自带 this 指针，成员函数隐式获得对象地址。
  • 在 C 中，我们通过在结构体中定义成员变量 + 函数指针来模拟类，并通过在调用成员函数时显式传递对象地址（作为第一个参数）来模拟 this 指针。

示例：封装一个 Person 类 #

c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

// 1. 类结构声明
typedef struct Person Person;

// 定义成员函数指针接口
typedef void (*fptrDisplay)(Person*);
typedef void (*fptrDelete)(Person*);

struct Person {
    char *firstName;
    char *lastName;
    // 成员函数指针绑定
    fptrDisplay Display;
    fptrDelete Delete;
};

// 2. 成员函数具体实现（显式传递指针模拟 this）
void Person_Display(Person *self) {
    printf("Name: %s %s\n", self->firstName, self->lastName);
}

void Person_Delete(Person *self) {
    if (self->firstName) free(self->firstName);
    if (self->lastName) free(self->lastName);
    free(self);
    printf("Person object deleted.\n");
}

// 3. 构造函数：为数据分配空间并绑定成员函数
Person* new_Person(const char *fName, const char *lName) {
    Person *p = (Person *)malloc(sizeof(Person));
    if (!p) return NULL;
    
    p->firstName = strdup(fName); // 拷贝字符串
    p->lastName = strdup(lName);
    
    // 绑定函数指针到具体实现
    p->Display = Person_Display;
    p->Delete = Person_Delete;
    return p;
}

int main() {
    // 实例化并调用
    Person *p = new_Person("Xiao", "Qiang");
    p->Display(p); // 显式传入 p 指针作为 self/this
    p->Delete(p);
    return 0;
}

5.2 继承与多态 (Inheritance & Polymorphism) 的 VTable 模拟 #

  • 继承：通过在派生类（子类）结构体中嵌套基类（父类）实例的引用或结构体来实现。
  • 多态（虚函数）：通过基类结构体中声明一个 void *pDerivedObj 属性指向子类对象，并在子类构造函数中改写（Override）基类的函数指针位置指向子类成员函数（即模拟 C++ 的虚函数表 VTable 覆盖）。

示例：Employee 继承自 Person 并覆盖 Display 虚函数 #

c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

// 1. 基类 Person 声明
typedef struct Person Person;
typedef void (*fptrDisplay)(Person*);
typedef void (*fptrDelete)(Person*);

struct Person {
    void *pDerivedObj; // 指向子类对象的泛型指针（实现多态的关键）
    char *firstName;
    char *lastName;
    fptrDisplay Display;
    fptrDelete Delete;
};

void Person_Display(Person *self) {
    printf("Base Person: %s %s\n", self->firstName, self->lastName);
}

void Person_Delete(Person *self) {
    free(self->firstName);
    free(self->lastName);
    free(self);
}

Person* new_Person(const char *fName, const char *lName) {
    Person *p = (Person *)malloc(sizeof(Person));
    p->pDerivedObj = p; // 基类创建时指向自身
    p->firstName = strdup(fName);
    p->lastName = strdup(lName);
    p->Display = Person_Display;
    p->Delete = Person_Delete;
    return p;
}

// 2. 子类 Employee 声明
typedef struct Employee {
    Person *pBaseObj; // 持有基类对象实例（实现继承）
    char *department;
    int salary;
} Employee;

// 子类覆盖后的虚函数实现
void Employee_Display(Person *self) {
    // 通过 pDerivedObj 找回真正的子类 Employee 实例
    Employee *emp = (Employee *)self->pDerivedObj; 
    printf("Employee Name: %s %s | Dept: %s | Salary: %d\n", 
           self->firstName, self->lastName, emp->department, emp->salary);
}

// 虚析构函数：释放子类特有属性，并调用基类析构释放通用属性
void Employee_Delete(Person *self) {
    Employee *emp = (Employee *)self->pDerivedObj;
    free(emp->department);
    free(emp); // 释放子类空间
    // 调用基类底层的常规删除释放基类成员
    free(self->firstName);
    free(self->lastName);
    free(self);
    printf("Employee object (base and derived) deleted.\n");
}

// 子类构造函数
Person* new_Employee(const char *fName, const char *lName, const char *dept, int salary) {
    // 2.1 首先调用基类构造函数初始化父类部分
    Person *pBase = new_Person(fName, lName);
    
    // 2.2 申请子类空间并初始化
    Employee *pEmp = (Employee *)malloc(sizeof(Employee));
    pEmp->pBaseObj = pBase;
    pEmp->department = strdup(dept);
    pEmp->salary = salary;
    
    // 2.3 多态绑定：将父类的 pDerivedObj 指向子类
    pBase->pDerivedObj = pEmp;
    
    // 2.4 改写函数指针指向子类覆盖实现（Override VTable）
    pBase->Display = Employee_Display;
    pBase->Delete = Employee_Delete;
    
    return pBase; // 向上转型：返回基类指针
}

int main() {
    // 3. 测试多态调用
    Person *p1 = new_Person("Tom", "Green");
    Person *p2 = new_Employee("Jerry", "White", "R&D", 15000);
    
    // 统一通过基类指针调用 Display 接口，行为截然不同
    p1->Display(p1); // 调用 Base Person: Tom Green
    p2->Display(p2); // 多态调用 Employee Name: Jerry White | Dept: R&D | Salary: 15000
    
    p1->Delete(p1);
    p2->Delete(p2); // 虚析构：正确清理 Employee 全部内存
    
    return 0;
}

5.3 工业级实战：Linux 内核设备驱动框架中的 OOP #

在 Linux 内核（例如经典的 Platform 设备总线驱动框架）中，面向对象的设计随处可见。内核代码就是利用结构体嵌套完美实现了“驱动的继承与多态”。

内核类继承关系大图： #

  +-------------------------------------+
  |   struct device_driver (基类/父类)   | <---+  定义了所有驱动通用的总线操作和名称属性
  +-------------------------------------+     |
                     ^                        |
                     | 继承 (组合方式)         |
  +-------------------------------------+     |
  |  struct platform_driver (子类/派生类)| ----+  增加了平台设备特有的 probe/remove 方法
  |  - struct device_driver driver;      | (继承 driver 实例)
  |  - int (*probe)(...);                | (定义派生类特有行为)
  |  - int (*remove)(...);               |
  +-------------------------------------+

1) 继承在内核结构体中的定义 #

c
struct platform_driver {
    int (*probe)(struct platform_device *);
    int (*remove)(struct platform_device *);
    void (*shutdown)(struct platform_device *);
    // ...
    struct device_driver driver; // 组合嵌入基类对象，直接继承了基类的属性和可见度
};

2) 多态与覆盖实现（以声卡或蜂鸣器驱动为例） #

当驱动注册到 platform 总线时，会对其进行重写赋值，根据特定的平台重定义 probe 和 remove：

c
static struct platform_driver fs4412_beep_driver = {
    .probe  = beep_probe,    // 子类实现方法：多态重载
    .remove = beep_remove,   // 子类实现方法
    .driver = {
        .name = "fs4412-beep", // 继承并改写父类的成员数据
    },
};

// 注册时内核会将子类的方法覆盖到 device_driver 的底层注册逻辑中
platform_driver_register(&fs4412_beep_driver);

通过这种方式，Linux 内核不需要一行 C++ 代码，就成功架构了一套高度抽象、解耦和高内聚的设备驱动面向对象平台。
