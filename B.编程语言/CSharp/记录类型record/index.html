记录类型record

C# 记录类型（record）：不可变数据载体的核心解析（面向 C++ 程序员） #

C# 9.0 引入的 记录类型（record） 是一种专门用于 存储不可变数据 的引用类型（默认），核心设计目标是：简化 “仅承载数据、无需复杂行为” 的场景（如 DTO、配置数据、查询结果），自动实现值相等性、哈希码、字符串格式化等基础功能 —— 无需手动重写 Equals、GetHashCode、== 等方法。

对 C++ 程序员来说，record 可类比为 “带自动实现的不可变 struct + 值语义” 的组合，但本质是引用类型（默认），且比 C++ 的 struct 更简洁（自动实现数据相关方法）、比 std::tuple 更易读（有明确成员名）、比手动实现的不可变类更高效（编译器自动生成底层代码）。

一、核心定义：record 是什么？ #

1. 本质：不可变数据载体 #

  • 核心定位：用于存储 “只读数据”，强调 值语义（Value Semantics）（相等性基于成员值，而非引用地址）；
  • 默认特性：
    1. 不可变性：成员默认是 init-only 属性（仅允许构造时或对象初始化器赋值，之后不可修改）；
    2. 自动实现：编译器自动生成 Equals、GetHashCode、==、!=、ToString() 方法（基于所有成员值）；
    3. 数据导向：无默认行为方法，仅聚焦数据存储和数据相关操作（如非破坏性修改 with 表达式）。

2. 与 C++ 类似类型的类比 #

C# 类型 核心特性 C++ 类似实现 核心差异
record（默认） 引用类型、不可变、值相等性 struct + const 成员 + 手动重载 == C++ struct 是值类型，需手动实现相等性
record class 显式引用类型、不可变、值相等性 class + const 成员 + 手动重载方法 C++ 类默认是引用语义，需手动实现值相等
record struct 值类型、不可变 / 可变、值相等性 struct + const 成员（C++11+） C# 自动实现所有数据方法，C++ 需手动写
std::tuple 匿名数据载体、值语义 std::tuple<string, int>（C++11+） C# record 有明确成员名，可读性更高

二、核心特性：record 为什么好用？ #

1. 不可变性（默认）：init-only 属性 #

record 的成员默认是 init 访问器（而非 set），允许 构造时赋值 或 对象初始化器赋值，但赋值后无法修改 —— 确保数据一旦创建就不可变，避免意外修改导致的 bug。

语法示例：基础 record 定义

csharp

运行

csharp
// 定义 record（默认是 record class，引用类型）
public record Cat(
    string Name,    // 自动生成 init-only 属性（public）
    int Age,        // 位置参数：按顺序对应构造函数参数
    DateTime BirthDate
);

// 用法：创建 record 对象（两种方式）
// 方式1：位置构造函数（按参数顺序赋值，简洁）
var cat1 = new Cat("Fritz", 3, new DateTime(2022, 1, 1));

// 方式2：对象初始化器（显式指定成员名，灵活）
var cat2 = new Cat(
    Name: "Boots",
    Age: 2,
    BirthDate: new DateTime(2023, 5, 15)
);

// 以下代码编译报错：init-only 属性无法修改
// cat1.Name = "New Name"; // 错误：Cat.Name 只有 init 访问器，无 set
C++ 对比：手动实现不可变 struct

C# record 一行代码实现的不可变特性，C++ 需手动定义 const 成员和构造函数：

cpp

运行

cpp
// C++ 手动实现类似 record 的不可变 struct
struct Cat {
    const std::string Name;
    const int Age;
    const std::chrono::system_clock::time_point BirthDate;

    // 必须手动写构造函数（无默认构造）
    Cat(std::string name, int age, std::chrono::system_clock::time_point birthDate)
        : Name(std::move(name)), Age(age), BirthDate(birthDate) {}

    // 还需手动重载 ==、!=、hash 等方法（否则是浅拷贝比较）
    bool operator==(const Cat& other) const {
        return Name == other.Name && Age == other.Age && BirthDate == other.BirthDate;
    }
};

可见 C# record 极大简化了不可变数据类型的定义。

2. 自动实现值相等性：基于成员值比较 #

class 的相等性默认是 引用相等（比较内存地址），而 record 的相等性是 值相等（比较所有成员的值）—— 编译器自动重写 Equals(object)、Equals(TSelf)、GetHashCode() 以及 == 和 != 运算符。

示例：record 的值相等性

csharp

运行

csharp
var cat1 = new Cat("Fritz", 3, new DateTime(2022, 1, 1));
var cat2 = new Cat("Fritz", 3, new DateTime(2022, 1, 1));
var cat3 = new Cat("Boots", 2, new DateTime(2023, 5, 15));

// 1. == 运算符：比较成员值（而非引用）
Console.WriteLine(cat1 == cat2); // 输出 true（值相等）
Console.WriteLine(cat1 == cat3); // 输出 false（值不同）

// 2. 引用比较：需用 ReferenceEquals
Console.WriteLine(ReferenceEquals(cat1, cat2)); // 输出 false（不同对象，引用不同）

// 3. GetHashCode：相同值的 record 哈希码相同
Console.WriteLine(cat1.GetHashCode() == cat2.GetHashCode()); // 输出 true
C++ 对比：手动重载 == 运算符

C++ 的 struct/class 默认不支持值相等比较，需手动重载 == 和 !=，且需确保所有成员都参与比较（容易遗漏）：

cpp

运行

cpp
// C++ 需手动实现 ==，否则比较的是内存地址（值类型 struct 除外）
bool operator==(const Cat& lhs, const Cat& rhs) {
    return lhs.Name == rhs.Name 
        && lhs.Age == rhs.Age 
        && lhs.BirthDate == rhs.BirthDate;
}

bool operator!=(const Cat& lhs, const Cat& rhs) {
    return !(lhs == rhs);
}

而 C# record 自动完成这一切，且不会遗漏成员。

3. 自动生成 ToString ()：清晰的字符串表示 #

record 自动重写 ToString() 方法，输出所有成员的名称和值（格式：类型名 { 成员1 = 值1, 成员2 = 值2, ... }），无需手动实现调试友好的字符串格式化。

示例：ToString () 自动格式化

csharp

运行

csharp
var cat = new Cat("Fritz", 3, new DateTime(2022, 1, 1));
Console.WriteLine(cat.ToString());
// 输出：Cat { Name = Fritz, Age = 3, BirthDate = 2022/1/1 0:00:00 }
C++ 对比：手动实现 operator<<

C++ 需手动重载 operator<< 才能实现类似效果：

cpp

运行

cpp
#include <iostream>
std::ostream& operator<<(std::ostream& os, const Cat& cat) {
    os << "Cat { Name = " << cat.Name 
       << ", Age = " << cat.Age 
       << ", BirthDate = ... }"; // 还需处理时间格式化
    return os;
}

// 使用
Cat cat("Fritz", 3, std::chrono::system_clock::now());
std::cout << cat << std::endl;

C# record 无需任何额外代码，直接获得调试友好的字符串输出。

4. 非破坏性修改：with 表达式（核心特性） #

不可变对象的痛点是 “修改部分成员需创建新对象”，record 提供 with 表达式，可 基于原有对象创建新对象，仅修改指定成员（其余成员复制原有值），语法简洁且保持不可变性。

示例：with 表达式修改 record

csharp

运行

csharp
var cat1 = new Cat("Fritz", 3, new DateTime(2022, 1, 1));

// with 表达式：创建新对象，修改 Name 和 Age，保留 BirthDate
var cat2 = cat1 with { Name = "Fritz Jr.", Age = 4 };

Console.WriteLine(cat1.ToString()); // 输出原对象：Cat { Name = Fritz, Age = 3, ... }
Console.WriteLine(cat2.ToString()); // 输出新对象：Cat { Name = Fritz Jr., Age = 4, ... }
Console.WriteLine(cat1 == cat2); // 输出 false（值不同）
C++ 对比：手动复制构造 + 修改

C++ 无 with 表达式，需通过复制构造函数创建新对象，再手动修改成员（但因不可变，需重新构造）：

cpp

运行

cpp
// C++ 不可变 struct 需重新构造新对象
Cat cat1("Fritz", 3, std::chrono::system_clock::from_time_t(...));
// 复制原有成员，修改指定字段（需手动传递所有未修改成员）
Cat cat2(
    "Fritz Jr.", // 新 Name
    4,           // 新 Age
    cat1.BirthDate // 保留原有 BirthDate
);

当 record 成员较多时，C# 的 with 表达式优势极其明显（无需传递未修改成员）。

三、record 的三种类型（C# 10+ 支持） #

C# 10.0 扩展了 record 类型，支持三种变体，分别对应不同场景（值类型 / 引用类型、不可变 / 可变）：

类型 本质类型 不可变性 相等性语义 适用场景 C++ 类比
record（默认） 引用类型 不可变（init） 值相等 复杂数据载体（如 DTO、配置） class + const 成员 + 手动重载
record class 引用类型 不可变（init） 值相等 显式声明引用类型 record（与 record struct 区分） 同 record（默认）
record struct 值类型 可选（init/set） 值相等 轻量级数据载体（如坐标、点、短期数据） struct + const 成员（不可变）或普通 struct（可变）

1. record struct（值类型 record） #

  • 本质是值类型（存储在栈上，复制时深拷贝成员）；
  • 支持不可变（init）或可变（set），默认不可变；
  • 自动实现值相等性、ToString()、GetHashCode()。
示例：record struct 定义与使用

csharp

运行

csharp
// 定义值类型 record（record struct）
public record struct Point(int X, int Y); // 不可变（init-only）

// 可变 record struct（显式用 set）
public record struct MutablePoint(int X, int Y) {
    // 显式定义 set 访问器，支持修改
    public int X { get; set; } = X;
    public int Y { get; set; } = Y;
}

// 用法
var p1 = new Point(10, 20);
var p2 = new Point(10, 20);
Console.WriteLine(p1 == p2); // 输出 true（值相等）

var mp = new MutablePoint(5, 5);
mp.X = 10; // 允许修改（因 X 有 set 访问器）
Console.WriteLine(mp); // 输出：MutablePoint { X = 10, Y = 5 }

2. 关键区别：record vs class vs struct #

特性 record（默认） class struct record struct
类型语义 引用类型 引用类型 值类型 值类型
默认不可变性 是（init） 否（set） 否（set） 是（init）
相等性语义 值相等 引用相等 值相等 值相等
自动实现方法 是（==/!=/ToString 等） 否（需手动重写） 否（需手动重写） 是
适用场景 复杂不可变数据 有状态、有行为 轻量级可变数据 轻量级不可变数据

四、实际应用场景（record 该怎么用？） #

1. 数据传输对象（DTO）：最核心场景 #

DTO 用于跨层 / 跨服务传输数据（如 API 接口请求 / 响应、数据库查询结果），通常仅需存储数据，无需复杂行为 ——record 完美适配，无需手动实现相等性和序列化支持。

示例：API 响应 DTO

csharp

运行

csharp
// 接口响应 DTO（不可变，自动支持值相等和序列化）
public record CatResponseDto(
    string Id,
    string Name,
    int Age,
    string Breed,
    DateTime CreatedAt
);

// 控制器返回 DTO
[ApiController]
[Route("api/cats")]
public class CatController : ControllerBase {
    [HttpGet("{id}")]
    public async Task<ActionResult<CatResponseDto>> GetCat(string id) {
        // 从数据库查询数据
        var cat = await _catRepository.GetByIdAsync(id);
        // 转换为 DTO（不可变，避免后续修改）
        return new CatResponseDto(
            cat.Id,
            cat.Name,
            cat.Age,
            cat.Breed,
            cat.CreatedAt
        );
    }
}

2. 配置数据：不可变配置 #

应用配置（如数据库连接字符串、第三方 API 密钥）通常是只读的，用 record 存储可避免程序运行时被意外修改。

csharp

运行

csharp
// 配置 record（不可变）
public record AppConfig(
    string ConnectionString,
    string ApiKey,
    int TimeoutMs
);

// 加载配置
var config = new AppConfig(
    ConnectionString: "Server=.;Database=Test;...",
    ApiKey: "sk-123456",
    TimeoutMs: 5000
);

// 无法修改配置（init-only）
// config.ApiKey = "sk-654321"; // 编译报错

3. LINQ 查询结果：临时数据载体 #

LINQ 查询返回的临时数据（如投影结果），用 record 可直接接收，无需定义额外的类 /struct。

csharp

运行

csharp
// 从 Cat 列表查询“名称+年龄”投影
var catInfos = cats
    .Where(c => c.Age > 2)
    .Select(c => new record(string Name, int Age)(c.Name, c.Age)) // 匿名 record（C# 10+ 支持）
    .ToList();

// 或提前定义命名 record
public record CatInfo(string Name, int Age);
var catInfos = cats.Select(c => new CatInfo(c.Name, c.Age)).ToList();

4. 轻量级值类型数据：record struct #

如坐标、尺寸、时间区间等轻量级数据，用 record struct 存储（值类型，性能更高）。

csharp

运行

csharp
// 时间区间（值类型 record）
public record struct TimeRange(DateTime StartTime, DateTime EndTime) {
    // 可添加计算属性（record 支持自定义成员）
    public TimeSpan Duration => EndTime - StartTime;
}

// 用法
var range = new TimeRange(
    StartTime: new DateTime(2025, 1, 1),
    EndTime: new DateTime(2025, 1, 2)
);
Console.WriteLine(range.Duration.TotalHours); // 输出 24

五、常见误区与避坑指南 #

1. 误区 1：record 是 struct 的 “升级版” #

  • 错误认知：record 和 struct 功能重叠，record 可替代 struct；
  • 正确逻辑：
    • record 默认是引用类型（存储在堆上），struct 是值类型（栈上）；
    • record 强调不可变性和值相等性，struct 默认可变；
    • 轻量级数据（如 Point）用 record struct 或 struct，复杂数据（如 Cat）用 record。

2. 误区 2：record 完全不可变 #

  • 错误认知：record 所有成员都不能修改；
  • 正确逻辑：

    • 默认不可变（成员是 init-only），但可显式定义 set 访问器实现可变；

    • 若 record 包含引用类型成员（如 List<string>），record 仅保证 “成员引用不可变”，但引用对象内部可修改：

      csharp

      运行

      csharp
      public record Cat(string Name, List<string> Hobbies);

var cat = new Cat("Fritz", new List<string> { "Sleep", "Eat" });
// cat.Hobbies = new List<string>(); // 编译报错（Hobbies 是 init-only）
cat.Hobbies.Add("Play"); // 允许！Hobbies 是 List，内部可修改
Console.WriteLine(string.Join(", ", cat.Hobbies)); // 输出：Sleep, Eat, Play

    • 解决方案：若需完全不可变，引用类型成员应返回只读包装（如 IReadOnlyList<string>）。

3. 误区 3：record 不能有自定义成员 #

  • 错误认知：record 只能定义自动属性，不能添加方法 / 计算属性；
  • 正确逻辑：record 支持添加自定义方法、计算属性、构造函数等，仅自动实现数据相关方法。

csharp

运行

csharp
public record Cat(string Name, int Age) {
    // 计算属性
    public string LifeStage => Age < 2 ? "Kitten" : "Adult";

    // 自定义方法
    public string Greet() => $"Hello, I'm {Name}, a {LifeStage}!";
}

// 用法
var cat = new Cat("Fritz", 3);
Console.WriteLine(cat.LifeStage); // 输出：Adult
Console.WriteLine(cat.Greet());   // 输出：Hello, I'm Fritz, a Adult!

4. 误区 4：with 表达式是 “修改原有对象” #

  • 错误认知：with 表达式会修改原有 record 对象；
  • 正确逻辑：with 表达式是 非破坏性修改，会创建新对象，原有对象保持不变（符合不可变性设计）。

5. 误区 5：record struct 一定比 record 性能好 #

  • 事实：record struct 是值类型，适合 “小数据、短期使用、频繁复制” 场景；
  • 若数据量大（如长字符串、复杂引用类型成员），record struct 的复制成本（深拷贝）会高于 record（引用复制），此时应选 record。

六、与 C++ 核心差异总结 #

特性 C# record C++ 类似实现 核心优势（C#）
不可变性实现 关键字 init 自动支持 const 成员 + 手动构造函数 语法简洁，无需手动限制修改
值相等性 编译器自动生成 ==/!= 手动重载 operator==/operator!= 无遗漏成员，减少出错概率
字符串格式化 自动重写 ToString() 手动重载 operator<< 调试友好，无需编写格式化代码
非破坏性修改 with 表达式一键实现 复制构造 + 手动修改成员 代码简洁，无需传递所有未修改成员
引用 / 值类型灵活切换 record（引用）/record struct（值） class（引用）/struct（值） 统一语法，数据方法自动实现

总结 #

对 C++ 程序员来说，理解 record 的核心是：

  1. record 是 “数据优先” 的类型，专为存储不可变数据设计，自动实现值相等性、字符串格式化等基础功能，避免重复代码；
  2. 核心价值是 简洁性和安全性：一行代码定义不可变数据类型，无需手动重写 Equals、ToString() 等方法，且不可变性避免意外修改；
  3. 三种变体适配不同场景：
    • 复杂不可变数据（DTO、配置）：用 record（默认，引用类型）；
    • 轻量级不可变数据（坐标、时间区间）：用 record struct（值类型）；
    • 有状态、有复杂行为：仍用 class；
  4. 与 C++ 对比：record 相当于 “C++ struct/class + 自动实现的相等性 / 格式化 / 不可变性”，开发效率极高，无需关注底层细节。

record 是 C# 对 “数据载体类型” 的优化，解决了 C++ 中 “手动实现不可变数据类型繁琐、易出错” 的痛点，让开发者聚焦数据本身而非底层方法实现 —— 这也是 C# 比 C++ 更适合快速开发数据密集型应用的原因之一。
