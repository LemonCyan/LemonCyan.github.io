类和结构 #

结构体 #

  • 结构可带有方法、字段、索引、属性、运算符方法和事件，用于表示轻量级数据。
  • 结构可定义构造函数，但不能定义析构函数。但不能为结构定义无参构造函数。无参构造函数(默认)是自动定义的，且不能被改变。
  • 结构不能继承其他的结构或类，也不能作为其他结构或类的基础结构（不能被继承）。
  • 结构可以继承接口，可实现一个或多个接口。
  • 结构成员不能指定为 abstract、virtual 或 protected。
  • 当使用 New 操作符创建一个结构对象时，会调用适当的构造函数来创建结构。与类不同，结构可以不使用 New 操作符即可被实例化。如果不使用 New 操作符，只有在所有的字段都被初始化之后（显示赋值，防止未初始化的字段使用），字段才被赋值，对象才被使用。
  • 结构变量通常分配在栈上，这使得它们的创建和销毁速度更快。但是，如果将结构用作类的字段，且这个类是引用类型，那么结构将存储在堆上。
  • 结构默认情况下是可变的，这意味着你可以修改它们的字段。但是，如果结构定义为只读，那么它的字段将是不可变的。

类 #

  • 构造函数与类的名称完全相同，它没有任何返回类型。
  • 析构函数在类的名称前加上 ~，无返回值，参数。析构函数用于在结束程序（比如关闭文件、释放内存等）之前释放资源。析构函数不能继承或重载
  • 静态成员，声明一个类成员为静态时，意味着无论有多少个类的对象被创建，只会有一个该静态成员的副本，可以通过直接调用类而不需要创建类的实例来获取

区别 #

值类型 vs 引用类型：

  • 结构是值类型（Value Type）： 在栈上分配内存。传递给方法或赋值时，执行深拷贝。
  • 类是引用类型（Reference Type）： 在堆上分配内存。传递给方法或赋值时，执行浅拷贝

继承和多态性：

  • 结构不能继承： 结构不能继承其他结构或类，也不能作为其他结构或类的基类。
  • 类支持继承： 类支持继承和多态性，可以通过派生新类来扩展现有类的功能。

默认构造函数：

  • 结构不能有无参数的构造函数
  • 类可以有无参数的构造函数

赋值行为：

  • 类型为类的变量在赋值时存储的是引用，因此两个变量指向同一个对象。
  • 结构变量在赋值时会复制整个结构，因此每个变量都有自己的独立副本。

传递方式：

  • 类对象在方法调用时通过引用传递，在方法中对对象所做的更改会影响到原始对象。
  • 结构对象通过值传递，传递的是结构的副本。在方法中对结构所做的更改不影响原始对象

可空性：

  • 结构体是值类型，不能直接设置为 null： 可以使用 Nullable<T> 或称为 T? 的可空类型
  • 类是引用类型，可为 null

性能和内存分配：

  • 结构通常更轻量： 值类型且在栈上分配内存，比类更轻量，适用于简单的数据表示。
  • 类可能有更多开销： 由于类是引用类型，可能涉及更多的内存开销和管理。

接口 #

  • 接口定义 interface IMyInterface
  • 如果一个接口继承其他接口，那么实现类或结构就需要实现所有接口的成员

异常处理 #

  • try：一个 try 块标识了一个将被激活的特定的异常的代码块。后跟一个或多个 catch 块。
  • catch：程序通过异常处理程序捕获异常。catch 关键字表示异常的捕获。
  • finally：finally 块用于执行给定的语句，不管异常是否被抛出都会执行。例如，如果您打开一个文件，不管是否出现异常文件都要被关闭。
  • throw：当问题出现时，程序抛出一个异常。使用 throw 关键字来完成。
  • 用户自定义的异常类是派生自 ApplicationException 类，eg

        t.GetConstructor(Type.EmptyTypes) != null

List<IPlugin> plugins = new List<IPlugin>();
//根据获取到的类型创建实例
foreach (var type in pluginTypes)
{
    var instance = (IPlugin)Activator.CreateInstance(type);
    plugins.Add(instance);
}

索引器 #

  • 允许一个对象可以像数组一样使用下标的方式进行访问
  • 索引器定义的时候不带有名称，但带有 this 关键字，它指向对象实例

  • 索引器的生命类似于属性，可以使用 get 和 set 来定义索引器，属性返回/设置一个特定成员数据，索引器返回/设置对象实例的一个特定值

重载索引器 #

索引器（Indexer）可被重载。索引器声明的时候也可带有多个参数，且每个参数可以是不同的类型。没有必要让索引器必须是整型的。C# 允许索引器可以是其他类型，例如，字符串类型。

cpp
using System;
namespace IndexerApplication
{
   class IndexedNames
   {
      private string[] namelist = new string[size];
      static public int size = 10;
      public IndexedNames()
      {
         for (int i = 0; i < size; i++)
         {
          namelist[i] = "N. A.";
         }
      }
      public int this[string name]
      {
         get
         {
            int index = 0;
            while(index < size)
            {
               if (namelist[index] == name)
               {
                return index;
               }
               index++;
            }
            return index;
         }

      }

      static void Main(string[] args)
      {
         IndexedNames names = new IndexedNames();
         names[0] = "Zara";
         names[1] = "Riz";
         names[2] = "Nuha";
         names[3] = "Asif";
         names[4] = "Davinder";
         names[5] = "Sunil";
         names[6] = "Rubic";
         // 使用带有 int 参数的第一个索引器
         for (int i = 0; i < IndexedNames.size; i++)
         {
            Console.WriteLine(names[i]);
         }
         // 使用带有 string 参数的第二个索引器
         Console.WriteLine(names["Nuha"]);
         Console.ReadKey();
      }
   }
}

委托 #

  • 类型安全的函数指针，只有匹配的方法才可以赋值给委托，赋值后允许将方法作为参数进行传递，帮助实现事件驱动的编程、回调机制和函数式编程风格
  • 存有对某个方法的引用的引用类型变量，可在运行时被改变
  • 用于事件处理，回调函数，LINQ 等操作
  • 所有的委托都继承自 System.Delegate 类
  • 委托对象需要通过 new 关键字进行创建
  • 委托对象可以通过 + 进行合并，通过 - 移除委托，只用同类型的委托可以合并
  • 委托的多播，一个委托被调用时要调用的方法的调用列表，多播委托（Multicast Delegate）调用顺序是严格按照添加顺序执行的
  • 委托常常和事件一起使用，事件是一种特殊类型的委托
  • 事件本质上是一个封装了委托的类型，用于响应程序中的某些操作
  • 异步调用：可以将委托与 BeginInvoke 和 EndInvoke 方法一起使用，进行异步调用
  • 可以用匿名方法和 lambda 表达式创建委托
csharp
//声明一个委托
delegate int NumberChanger(int n);

namespace DelegateAppl
{
   class TestDelegate
   {
      static int num = 10;
      public static int AddNum(int p)
      {
         num += p;
         return num;
      }
      public static int MultNum(int p)
      {
         num *= p;
         return num;
      }

      static void Main(string[] args)
      {
         // 创建委托实例
         NumberChanget nc;
         NumberChanger nc1 = new NumberChanger(AddNum);
         NumberChanger nc2 = new NumberChanger(MultNum);
         nc = nc1;
         nc += nc2;
         // 使用委托对象调用方法
         nc(5);//输出75
      }
   }
}

   class PrintString
   {
      static FileStream fs;
      static StreamWriter sw;
      // 委托声明
      public delegate void printString(string s);

      // 该方法打印到控制台
      public static void WriteToScreen(string str)
      {
         Console.WriteLine("The String is: {0}", str);
      }
      // 该方法打印到文件
      public static void WriteToFile(string s)
      {
         fs = new FileStream("c:\\message.txt", FileMode.Append, FileAccess.Write);
         sw = new StreamWriter(fs);
         sw.WriteLine(s);
         sw.Flush();
         sw.Close();
         fs.Close();
      }
      // 该方法把委托作为参数，并使用它调用方法
      public static void sendString(printString ps)
      {
         ps("Hello World");
      }
      static void Main(string[] args)
      {
         printString ps1 = new printString(WriteToScreen);
         printString ps2 = new printString(WriteToFile);
         sendString(ps1);
         sendString(ps2);
         Console.ReadKey();
      }
   }
}

事件 #

  1. 声明委托 定义事件将使用的委托类型，委托是一个函数签名
  2. 声明事件 使用 event 关键字声明一个事件
  3. 触发事件 在适当的时候调用事件，通知所有订阅者
  4. 订阅和取消订阅事件 其他类可以通过 += 和 -= 订阅和取消订阅事件
  • event 是一种成员，用于将特定的事件通知发送给订阅者，允许一个对象将状态的变化通知其他对象，而不需要知道这些对象的实现细节，C#中使用事件机制实现线程间的通讯
  • 事件在类中声明且生成，通过使用同一个类或其他类中的委托与事件处理程序相关联，包含事件的类用于发布事件，称为发布器。其他接受该事件的类称为订阅器
  • 发布器是一个包含事件和委托定义的对象，事件和委托之间的联系也定义在这个对象中。发布器类的对象调用这个事件，并通知其他对象
  • 订阅器是一个接受事件并提供事件处理程序的对象，在发布器类中的委托调用订阅器类中的方法（事件处理程序）
csharp
namespace EventSub
{
    // 发布者类
    class MyPublisher
    {
        // 1. 在类的内部声明事件，首先需要声明事件关联的委托类型
        public delegate void EventSlot(string s);

        // 2. 使用event关键字声明事件,该事件在生成的时候会调用委托
        public event EventSlot MessageReceivedEvent;

        // 触发事件的方法（通常用 protected virtual 封装，便于子类重写）
        public void TriggerEvent(string s)
        {
            // 空值判断：确保有订阅者才触发（避免 NullReferenceException）
            MessageReceivedEvent?.Invoke(s);
        }
    }

    // 订阅者类
    class MySubscriber
    {
        // 订阅者的处理方法（签名必须和委托完全匹配）
        public void OnMessageReceived(string s)
        {
            Console.WriteLine("订阅者收到消息：{0}", s);
        }
    }

    //创建包含 Main 方法的类（入口方法必须在类中）
    public class Program
    {
        public static void Main()
        {
            // 实例化发布者和订阅者
            MyPublisher pub = new MyPublisher();
            MySubscriber sub = new MySubscriber();

            // 订阅事件：将订阅者的方法绑定到事件上
            pub.MessageReceivedEvent += sub.OnMessageReceived;

            // 触发事件
            pub.TriggerEvent("hello");
        }
    }
}

不安全代码 #

指的是使用了指针变量的代码块。由于 C#中声明的变量在内存中的存储受垃圾回收器管理；因此一个变量（例如一个大数组）有可能在运行过程中被移动到内存中的其他位置。如果一个变量的内存地址会变化，那么指针也就没有意义了。解决方法就是使用 fixed 关键字来固定变量位置不移动。

csharp
static unsafe void Main(string[] args)
{
  fixed(int *ptr = int[5])  {}
}

stackalloc 在 unsafe 不安全环境中，我们可以通过 stackalloc 在堆栈上分配内存，因为在堆栈上分配的内存不受内存管理器管理，因此其相应的指针不需要固定。

csharp
static unsafe void Main(string[] args)
{
  int *ptr = stackalloc int[1] ;
}

多线程 #

  • 线程生命周期开始于 System.Threading.Thread 类的对象被创建时
  • 程序开始执行时，主线程自动创建。使用 Thread 类创建的线程被主线程的子线程调用。您可以使用 Thread 类的 CurrentThread 属性访问线程。
  • 线程是通过扩展 Thread 类创建的。扩展的 Thread 类调用 Start() 方法来开始子线程的执行
  • Thread 类提供了各种管理线程的方法，sleep
  • Abort() 方法用于销毁线程。通过抛出 threadabortexception 在运行时中止线程。这个异常不能被捕获，如果有 finally 块，控制会被送至 finally 块。
cpp
using System;
using System.Threading;

namespace MultithreadingApplication
{
    class ThreadCreationProgram
    {
        public static void CallToChildThread()
        {
            try
            {

                Console.WriteLine("Child thread starts");
                // 计数到 10
                for (int counter = 0; counter <= 10; counter++)
                {
                    Thread.Sleep(500);
                    Console.WriteLine(counter);
                }
                Console.WriteLine("Child Thread Completed");

            }
            catch (ThreadAbortException e)
            {
                Console.WriteLine("Thread Abort Exception");
            }
            finally
            {
                Console.WriteLine("Couldn't catch the Thread Exception");
            }

        }
        
        static void Main(string[] args)
        {
	        //1.注册线程入口函数
            ThreadStart childref = new ThreadStart(CallToChildThread);
            Console.WriteLine("In Main: Creating the Child thread");
            //2.创建线程
            Thread childThread = new Thread(childref);
            //3.启动线程
            childThread.Start();
            //4.停止主线程一段时间
            Thread.Sleep(2000);
            //5.中止子线程
            Console.WriteLine("In Main: Aborting the Child thread");
            childThread.Abort();
            Console.ReadKey();
        }
    }
}
