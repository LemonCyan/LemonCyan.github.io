class和struct的异同

在 C# 中，class（类）和 struct（结构体）是两种核心的自定义类型，本质区别是：class 是引用类型，struct 是值类型。

  • 小（尺寸小）、静（不可变）、简（无继承/多态）→ struct；
  • 大（尺寸大）、动（可变）、杂（需继承/多态/null）→ class。

一、相同点（共性特性） #

class 和 struct 作为自定义类型，具备以下共同能力：

  1. 可包含 字段、属性、方法、构造函数、索引器、事件 等成员；
  2. 可实现 一个或多个接口（支持接口多态）；
  3. 可定义 泛型版本（如 List<T> 是泛型类，Nullable<T> 是泛型结构体）；
  4. 支持 成员访问控制（public/private/protected 等）；
  5. 可包含 静态成员（静态字段、静态方法、静态构造函数）。

示例：class 和 struct 都能实现接口、定义成员

csharp
// 公共接口 
public interface IMeasurable { double GetValue(); } 
// 结构体实现接口 
public struct Celsius : IMeasurable { 
	public double Value { get; } 
	public Celsius(double value) => Value = value; 
	public double GetValue() => Value; 
} 
// 类实现接口 
public class Temperature : IMeasurable { 
	public double Value { get; set; } 
	public Temperature(double value) => Value = value; 
	public double GetValue() => Value; 
}

二、核心差异 #

以下是二者最关键的区别，用表格清晰总结，再逐一展开说明：

对比维度 struct（值类型） class（引用类型）
类型本质 值类型（Value Type） 引用类型（Reference Type）
存储位置 栈（Stack）或嵌入到引用类型（堆）中 堆（Heap）（对象数据）+ 栈（引用地址）
内存分配/回收 分配快（栈自动弹栈），无垃圾回收（GC）压力 分配慢（堆需 GC 管理），大对象可能触发 GC
赋值行为 复制整个对象的所有字段（值拷贝） 复制引用地址（引用拷贝，对象数据共享）
默认构造函数 编译器自动生成无参构造（不可删除），不能自定义无参构造（C# 10+ 允许为 struct 定义无参构造） 无默认无参构造（需手动定义，否则不能无参实例化）
继承特性 密封（sealed，不可继承其他 struct/class），仅能实现接口 可继承其他 class（单继承）、实现接口，支持多态
null 支持 不能直接为 null，需用可空值类型（struct?） 可直接赋值 null（表示无引用对象）
相等性比较（默认） 逐字段值比较（ValueType.Equals） 引用地址比较（object.ReferenceEquals）
析构函数 不支持（无 GC 回收环节） 支持（用于释放非托管资源，搭配 IDisposable）
装箱/拆箱 转换为 object 时触发装箱（性能开销） 无需装箱（本身是 object 子类）

赋值行为（值拷贝 vs 引用拷贝） #

  • struct：值拷贝（复制整个对象）
csharp
public struct Point { 
	public int X { get; set; } 
	public int Y { get; set; } 
} 
// 示例：赋值时复制整个对象 
Point p1 = new Point { X = 10, Y = 20 }; 
Point p2 = p1; // 值拷贝：p2 是 p1 的完整副本，修改 p2 不影响 p1 
p2.X = 100; 
Console.WriteLine(p1.X); // 输出 10（p1 未变） 
Console.WriteLine(p2.X); // 输出 100（p2 独立修改）
  • class：引用拷贝（复制地址，共享数据）
csharp
public class PointClass { 
	public int X { get; set; } 
	public int Y { get; set; } 
} 
// 示例：赋值时复制引用地址
PointClass pc1 = new PointClass { X = 10, Y = 20 }; 
PointClass pc2 = pc1; // 引用拷贝：pc1 和 pc2 指向堆中同一个对象 
pc2.X = 100; 
Console.WriteLine(pc1.X); // 输出 100（pc1 被间接修改） 
Console.WriteLine(pc2.X); // 输出 100（同一对象）

继承与多态 #

  • struct：

  • 天生是 sealed（密封）的，不能继承其他 struct 或 class（避免值类型继承导致的内存布局复杂）；

  • 仅能实现接口（实现接口时会触发装箱，因为接口是引用类型）；

  • 不能用 virtual/override 修饰成员（无继承，无需多态）。

  • class：

  • 支持 单继承（只能继承一个父类），可多层继承；

  • 支持实现多个接口，支持 virtual/override 实现多态；

  • 可被标记为 sealed 禁止继承。

示例：class 的继承与多态

csharp
public class Animal { 
	public virtual void Speak() => Console.WriteLine("动物叫"); 
} 
public class Dog : Animal // 继承 Animal 
{ 
	public override void Speak() => Console.WriteLine("汪汪叫"); // 重写父类方法 
} 
Animal dog = new Dog(); 
dog.Speak(); // 输出 "汪汪叫"（多态生效）

相等性比较（默认行为） #

  • struct：默认调用 ValueType.Equals，进行 逐字段值比较（判断两个对象的所有字段是否完全相同）；
  • class：默认调用 object.ReferenceEquals，进行 引用地址比较（判断两个变量是否指向堆中同一个对象）。

示例：默认相等性比较

csharp
// struct：值比较 
Point p1 = new Point { X = 10, Y = 20 }; 
Point p2 = new Point { X = 10, Y = 20 }; 
Console.WriteLine(p1.Equals(p2)); // 输出 True（字段完全相同） 

// class：引用比较 
PointClass pc1 = new PointClass { X = 10, Y = 20 }; 
PointClass pc2 = new PointClass { X = 10, Y = 20 }; 
Console.WriteLine(pc1.Equals(pc2)); // 输出 False（指向不同对象） 
Console.WriteLine(ReferenceEquals(pc1, pc2)); // 输出 False（引用地址不同）

注意：无论是 class 还是 struct，都可重写 Equals 方法和 == 运算符，自定义相等性逻辑（如 class 按字段比较）。
