Matlab 仿真框图转 C 代码实现说明文档 #

实现步骤 #

  1. 搭建框图

    使用 Matlab 2016b 搭建仿真框图，命名为 test.dll。以下是仿真框图的示意图：

    图 1: Simulink 模型

  2. 初始设置

    • 选择菜单栏 Simulink -> Model Configuration Parameters，设置参数为固定步长，采用四阶龙格库塔方法解算微分方程。具体步长可以在后期进行二次设置。

      图 2: 设置求解器参数

    • 系统的目标文件选择为 ert.tlc，即采用嵌入形式的 C/C++ 代码生成。生成的语言可选择 C 或 C++。

      图 3: 代码生成的参数设置

    • 接口模块进行如下设置，需要选中 continuoustime 选项。至此，参数设置工作完毕，其余设置采用默认设置方式。

      图 4: 接口参数设置

  3. 代码生成

    • 直接点击代码生成功能键，生成代码成功后会收到如图 5 所示的提示。此时，在示例文件 test.mdl 的目录下会出现名为 slprj 和 test_ert_rtw 的文件夹，如图 6 所示，包含了生成的 C 代码的相关文件。

      图 5: 代码生成成功提示

      图 6: 生成文件

  4. 代码应用

    • 代码可在 Visual Studio 2013 上运行，通过 文件 -> 打开 -> 项目/解决方案，找到 test_ert_rtw\msvc 目录下的 test.sln 文件并添加，添加成功如下所示。

      图 6: 生成文件

    • 主文件经过初始化后，在 while 循环中调用 test_step() 函数按单步执行，最后通过 test_terminate 终止。在带有积分环节的模型中，还可以通过找到 test_M->Timing.stepSize0 重新设置仿真步长。图 7 显示，每次给输入设置常值，经第五次调用后的输出结果。

      图 7: 代码测试

结论 #

采用 Matlab 和 C 混合编程，设计简单，结构清晰，修改方便，同时大大降低了编程失误带来的风险，为保证项目有效进行提供了保障。

MATLAB 动态链接库转换步骤 #

  1. 配置 MATLAB 编译器

    在 MATLAB 的命令行窗口输入以下命令：

    matlab
    mbuild -setup
mex -setup
deploytool

    选择 C++ 选项。以下是命令界面：

    图 8: MATLAB 命令界面

  2. 创建动态链接库

    • 运行 deploytool 后，选择 Library Compiler 选项，进入如下界面：

      图 9: Compiler 界面

    • 选择 .NET Assembly，添加相关脚本文件，将类的名字定义为 airplane（自定义），确认后选择 Package 按钮进行打包。

      图 10: 操作界面

  3. 生成 DLL 文件

    • 打包完成后，会生成几个文件夹，包含调用到的 dll 文件。

      图 11: 输出界面

总结 #

通过以上步骤，可以将 Matlab 仿真框图成功转换为 C 代码，并生成动态链接库，方便在其他项目中调用。这种方法不仅提高了开发效率，还降低了编程错误的风险，是一种高效可靠的开发方式。
