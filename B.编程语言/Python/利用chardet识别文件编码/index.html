测试代码

cpp
import chardet

open_file = open(file="miui.cpp",mode='rb') # 以二进制模式读取文件
data = open_file.read() # 获取文件内容
print(data) 
open_file.close() # 关闭文件

result = chardet.detect(data) # 检测文件内容
print(result)  #{'encoding': 'utf-8', 'confidence': 0.99, 'language': ''}

输出结果

cpp
'encoding': 'utf-8'     表示检测到文件的编码格式为utf-8
'confidence': 0.99      表示可信度为百分之九十九
'language': ''          表示文件内容的语言
