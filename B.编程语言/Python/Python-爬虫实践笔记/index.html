Python 爬虫实践笔记

前言 #

最近想把一个博客网站的文章都爬下来存到本地，正好借这个机会记录一下爬虫的设计思路。这篇笔记会从零开始讲解，即使你没有太多编程经验，跟着做也能写出自己的爬虫。

工具选择 #

爬虫说白了就是模拟浏览器去访问网页，然后把需要的内容提取出来。Python 有很多现成的库可以用：

工具 用途 特点
requests 发送 HTTP 请求 简单好用，大多数情况够用
BeautifulSoup 解析 HTML 语法直观，容易上手
Selenium 浏览器自动化 能处理 JavaScript 渲染的页面，但速度慢
Scrapy 专业爬虫框架 功能强大，适合大型项目

对于普通的静态网站，requests + BeautifulSoup 就足够了。如果是那种需要 JavaScript 才能加载内容的网站（比如无限滚动加载的页面），就需要用 Selenium。

动手之前先搞清楚网站结构 #

不管爬什么网站，第一步都是打开浏览器的开发者工具（F12），看看网页的真实结构。

查看网页源码 #

右键 -> 查看网页源码，看看内容是直接写在 HTML 里，还是通过 JavaScript 动态加载的。

分析数据来源 #

切换到 Network 标签，刷新页面，观察网络请求。很多现代网站的数据是通过 API 返回的 JSON 格式，直接请求 API 比解析 HTML 方便多了。

找规律 #

比如文章列表页的 URL 是不是有规律？分页是怎么实现的？文章详情页的 URL 格式是什么样的？这些规律决定了爬虫的设计思路。

实战：爬取 findmoney.club 博客 #

下面以 https://www.findmoney.club/ 为例，演示完整的爬虫设计过程。

分析网站 #

这个网站用的是 Next.js 框架，有个特点：页面数据都嵌在 HTML 里的一个 <script id="__NEXT_DATA__"> 标签中，是 JSON 格式。

打开首页的源码，搜索 __NEXT_DATA__，你会发现里面有个 allNavPages 数组，包含了所有文章的基本信息：标题、分类、链接等。

同样地，打开某篇文章的页面，__NEXT_DATA__ 里有个 post 对象，包含文章的详细内容。这些数据存储在 Notion 的 block 结构中。

安装依赖 #

bash
pip install requests beautifulsoup4 markdownify
  • requests：发送网络请求
  • beautifulsoup4：解析 HTML（虽然我们主要解析 JSON，但也可能用到）
  • markdownify：把 HTML 转成 Markdown

完整代码 #

python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
FindMoney.club 博客爬虫
将网站的所有文章爬取并转换为 Markdown 格式保存
"""

import requests
import json
import os
import re
import time
from urllib.parse import urljoin, quote

class FindMoneyCrawler:
    """爬虫主类"""
    
    def __init__(self, output_dir="./articles"):
        self.base_url = "https://www.findmoney.club"
        self.output_dir = output_dir
        self.session = requests.Session()
        
        # 设置请求头，模拟浏览器访问
        # 这一步很重要，很多网站会检查 User-Agent
        self.session.headers.update({
            "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120.0.0.0 Safari/537.36",
            "Accept": "text/html,application/xhtml+xml,application/xml;q=0.9,*/*;q=0.8",
            "Accept-Language": "zh-CN,zh;q=0.9,en;q=0.8",
        })
        
        # 创建输出目录
        os.makedirs(output_dir, exist_ok=True)
    
    def get_page(self, url):
        """获取页面内容，带重试机制"""
        max_retries = 3
        for i in range(max_retries):
            try:
                response = self.session.get(url, timeout=30)
                response.raise_for_status()
                return response.text
            except requests.RequestException as e:
                print(f"请求失败 ({i+1}/{max_retries}): {e}")
                if i < max_retries - 1:
                    time.sleep(2)  # 等待2秒后重试
        return None
    
    def extract_next_data(self, html):
        """从 HTML 中提取 __NEXT_DATA__ JSON 数据"""
        # 用正则表达式匹配 script 标签中的 JSON
        # 为什么不用 BeautifulSoup？因为这种场景正则更简洁
        pattern = r'<script id="__NEXT_DATA__" type="application/json">(.*?)</script>'
        match = re.search(pattern, html, re.DOTALL)
        
        if match:
            try:
                return json.loads(match.group(1))
            except json.JSONDecodeError as e:
                print(f"JSON 解析错误: {e}")
                return None
        return None
    
    def get_all_articles(self):
        """获取所有文章列表"""
        print("正在获取文章列表...")
        html = self.get_page(self.base_url)
        
        if not html:
            print("获取首页失败")
            return []
        
        data = self.extract_next_data(html)
        if not data:
            print("解析首页数据失败")
            return []
        
        # 从 pageProps 中提取文章列表
        try:
            all_pages = data["props"]["pageProps"]["allNavPages"]
            # 过滤出文章（有些可能是菜单或其他类型）
            articles = [
                page for page in all_pages 
                if page.get("href") and not page.get("href").startswith("/#")
            ]
            print(f"找到 {len(articles)} 篇文章")
            return articles
        except KeyError as e:
            print(f"数据结构异常: {e}")
            return []
    
    def get_article_content(self, article_url):
        """获取单篇文章的详细内容"""
        full_url = urljoin(self.base_url, article_url)
        html = self.get_page(full_url)
        
        if not html:
            return None
        
        data = self.extract_next_data(html)
        if not data:
            return None
        
        try:
            return data["props"]["pageProps"]["post"]
        except KeyError:
            return None
    
    def notion_blocks_to_markdown(self, post_data):
        """将 Notion blocks 转换为 Markdown 格式"""
        if not post_data or "blockMap" not in post_data:
            return ""
        
        blocks = post_data.get("blockMap", {}).get("block", {})
        content_ids = post_data.get("content", [])
        
        markdown_lines = []
        
        # 添加文章标题
        title = post_data.get("title", "无标题")
        markdown_lines.append(f"# {title}\n")
        
        # 添加元信息
        if post_data.get("category"):
            markdown_lines.append(f"**分类**: {post_data['category']}")
        if post_data.get("tags"):
            tags = ", ".join(post_data["tags"])
            markdown_lines.append(f"**标签**: {tags}")
        if post_data.get("summary"):
            markdown_lines.append(f"**摘要**: {post_data['summary']}")
        if post_data.get("publishDay"):
            markdown_lines.append(f"**发布日期**: {post_data['publishDay']}")
        
        markdown_lines.append("\n---\n")
        
        # 遍历内容块
        for block_id in content_ids:
            if block_id not in blocks:
                continue
            
            block = blocks[block_id].get("value", {})
            block_type = block.get("type", "")
            properties = block.get("properties", {})
            
            # 获取文本内容
            text_content = self._extract_rich_text(properties.get("title", []))
            
            # 根据块类型转换为 Markdown
            if block_type == "header":
                markdown_lines.append(f"# {text_content}")
            elif block_type == "sub_header":
                markdown_lines.append(f"## {text_content}")
            elif block_type == "sub_sub_header":
                markdown_lines.append(f"### {text_content}")
            elif block_type == "text":
                if text_content:
                    markdown_lines.append(text_content)
                else:
                    markdown_lines.append("")  # 空行
            elif block_type == "bulleted_list":
                markdown_lines.append(f"- {text_content}")
            elif block_type == "numbered_list":
                markdown_lines.append(f"1. {text_content}")
            elif block_type == "quote":
                markdown_lines.append(f"> {text_content}")
            elif block_type == "code":
                language = block.get("properties", {}).get("language", [[""]])[0][0]
                markdown_lines.append(f"```{language}")
                markdown_lines.append(text_content)
                markdown_lines.append("```")
            elif block_type == "image":
                source = properties.get("source", [[""]])[0][0]
                if source:
                    markdown_lines.append(f"![image]({source})")
            elif block_type == "divider":
                markdown_lines.append("---")
            elif block_type == "callout":
                markdown_lines.append(f"> **提示**: {text_content}")
            
        return "\n\n".join(markdown_lines)
    
    def _extract_rich_text(self, rich_text_array):
        """从 Notion 的富文本数组中提取纯文本和格式"""
        if not rich_text_array:
            return ""
        
        result = []
        for item in rich_text_array:
            if not isinstance(item, list) or len(item) == 0:
                continue
            
            text = item[0]
            
            # 处理格式（粗体、链接等）
            if len(item) > 1 and isinstance(item[1], list):
                for format_item in item[1]:
                    if isinstance(format_item, list):
                        format_type = format_item[0] if len(format_item) > 0 else ""
                        format_value = format_item[1] if len(format_item) > 1 else ""
                        
                        if format_type == "b":  # 粗体
                            text = f"**{text}**"
                        elif format_type == "i":  # 斜体
                            text = f"*{text}*"
                        elif format_type == "a":  # 链接
                            text = f"[{text}]({format_value})"
                        elif format_type == "c":  # 代码
                            text = f"`{text}`"
                    elif isinstance(format_item, str):
                        if format_item == "b":
                            text = f"**{text}**"
                        elif format_item == "i":
                            text = f"*{text}*"
            
            result.append(text)
        
        return "".join(result)
    
    def sanitize_filename(self, name):
        """清理文件名，移除不合法字符"""
        # 替换 Windows 不允许的文件名字符
        invalid_chars = r'[<>:"/\\|?*]'
        name = re.sub(invalid_chars, "_", name)
        # 限制长度
        if len(name) > 100:
            name = name[:100]
        return name.strip()
    
    def save_article(self, article_info, content):
        """保存文章为 Markdown 文件"""
        title = article_info.get("title", "无标题")
        category = article_info.get("category", "未分类")
        
        # 创建分类目录
        category_dir = os.path.join(self.output_dir, self.sanitize_filename(category))
        os.makedirs(category_dir, exist_ok=True)
        
        # 生成文件名
        filename = self.sanitize_filename(title) + ".md"
        filepath = os.path.join(category_dir, filename)
        
        # 写入文件
        with open(filepath, "w", encoding="utf-8") as f:
            f.write(content)
        
        print(f"  已保存: {filepath}")
        return filepath
    
    def run(self):
        """运行爬虫"""
        print("=" * 50)
        print("FindMoney.club 博客爬虫")
        print("=" * 50)
        
        # 获取文章列表
        articles = self.get_all_articles()
        
        if not articles:
            print("没有找到文章")
            return
        
        success_count = 0
        fail_count = 0
        
        for i, article in enumerate(articles, 1):
            title = article.get("title", "无标题")
            href = article.get("href", "")
            
            print(f"\n[{i}/{len(articles)}] 正在处理: {title}")
            
            # 获取文章详情
            post_data = self.get_article_content(href)
            
            if not post_data:
                print(f"  获取失败，跳过")
                fail_count += 1
                continue
            
            # 转换为 Markdown
            markdown_content = self.notion_blocks_to_markdown(post_data)
            
            # 保存文件
            self.save_article(article, markdown_content)
            success_count += 1
            
            # 礼貌性延迟，避免请求太频繁
            # 这是爬虫的基本礼仪，不要给对方服务器太大压力
            time.sleep(1)
        
        print("\n" + "=" * 50)
        print(f"爬取完成！成功: {success_count}, 失败: {fail_count}")
        print(f"文章保存在: {os.path.abspath(self.output_dir)}")
        print("=" * 50)


if __name__ == "__main__":
    # 可以在这里修改输出目录
    crawler = FindMoneyCrawler(output_dir="./findmoney_articles")
    crawler.run()

代码解读 #

核心逻辑 #

  1. 获取文章列表：访问首页，从 __NEXT_DATA__ 中提取 allNavPages
  2. 遍历每篇文章：根据 URL 访问文章页面，获取详细内容
  3. 内容转换：把 Notion 的块结构转换为 Markdown 格式
  4. 保存文件：按分类创建目录，保存为 .md 文件

几个关键点 #

模拟浏览器

python
self.session.headers.update({
    "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) ...",
})

很多网站会检查 User-Agent 请求头，如果发现不是正常浏览器就会拒绝访问。所以我们要伪装成浏览器。

错误处理和重试

python
for i in range(max_retries):
    try:
        response = self.session.get(url, timeout=30)
        ...
    except requests.RequestException as e:
        time.sleep(2)  # 等待后重试

网络请求难免会失败，加上重试机制能提高成功率。

礼貌性延迟

python
time.sleep(1)  # 每次请求后等待1秒

不要一股脑地狂发请求，给对方服务器留点喘息的机会。这是爬虫的基本素养。

运行方法 #

把代码保存为 crawler.py，然后在命令行运行：

bash
python crawler.py

爬取的文章会保存在 ./findmoney_articles 目录下，按分类整理好。

常见问题和解决方案 #

被网站封禁了怎么办？ #

  • 降低请求频率（增加 time.sleep 的时间）
  • 使用代理 IP
  • 更换 User-Agent

页面内容是 JavaScript 渲染的 #

用 Selenium 模拟浏览器：

python
from selenium import webdriver
from selenium.webdriver.chrome.options import Options

options = Options()
options.add_argument("--headless")  # 无头模式，不显示浏览器窗口

driver = webdriver.Chrome(options=options)
driver.get("https://example.com")

# 等待页面加载
time.sleep(3)

# 获取渲染后的 HTML
html = driver.page_source
driver.quit()

登录后才能访问的内容 #

需要先模拟登录获取 Cookie：

python
session = requests.Session()

# 登录
login_data = {
    "username": "your_username",
    "password": "your_password"
}
session.post("https://example.com/login", data=login_data)

# 后续请求自动带上 Cookie
response = session.get("https://example.com/protected-page")

总结 #

设计爬虫的一般流程：

  1. 分析目标网站：用浏览器开发者工具研究页面结构和数据来源
  2. 选择合适的工具：静态页面用 requests，动态页面用 Selenium
  3. 编写爬虫逻辑：获取页面 -> 解析数据 -> 保存结果
  4. 处理异常情况：重试机制、错误处理、延迟控制

记住几个原则：

  • 遵守网站的 robots.txt 规则
  • 控制请求频率，不要给服务器造成压力
  • 仅用于个人学习和研究，不要用于商业用途或侵犯版权

爬虫本身是个中性的技术，关键看你怎么用它。希望这篇笔记能帮到你！
