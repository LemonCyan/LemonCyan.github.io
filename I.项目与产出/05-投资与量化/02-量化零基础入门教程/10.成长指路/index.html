引言 #

基础知识基本讲完了，本教程也要完结了，最后一篇讲下接下来的学习方向，仅供参考。

如果这是你第一次读完一条完整的技术教程，可能会产生一种"学完了但好像什么都不会"的错觉。这不是错觉，而是正常的：教程给的是骨架，肉要你自己长。所以这一篇不谈知识，谈方法。

自学意识 #

量化交易是不适合分享的行业，自学必不可少。或奇货可居，或敝帚自珍，有价值的内容很难会被公之于众。所以不要幻想会有特别有价值的系统的学习资源等着你去学，或是指望能把别人公开的东西直接搬来就能赚到钱。

诚然，会有幸运的时候，但还是不要指望幸运，那没前途的。绝大多数情况都是大浪淘金式的，在各种资讯中寻找着、思索着只言片语。因此，自学是一个极其重要的能力，有志者需要对它像量化交易本身一样去重视。

注意"不适合分享"这个判断有一个直接推论，它对你有实际用处：当你看到某个公开展示的策略，最先该想的是"为什么它愿意公开"。常见答案有三个：策略已经失效了、策略是靠卖课变现的、或者披露的版本与真实运行的版本不是一回事。三种情况都不构成"照抄就能赚钱"。

之后去学什么 #

首先要自问：之前讲过的内容是否都学会了？比如每篇后的自测与自学内容是否都能回答，当时学的时候不理解的地方现在是否理解等。如果明显感觉一路囫囵吞枣强行跟过来的，不妨回头再看看，再动手练练。当然，也不必太完美主义，毕竟有的坑看着不大但是真的深，不妨暂且搁下。

所以如果感觉学得还可以，就可以先到聚宽的量化课堂去学习下，普遍有讲解有代码，其中重点推荐以下文章：

  • 双均线策略
  • 彼得·林奇的成功投资
  • Fama-French三因子火锅
  • 凯利公式，你用对了吗？

请尽你所能去读懂这四篇文章。你可能会感受到来自数学、编程、金融等方面的知识的不足，可能会感到有之前我没讲过的内容，可能需要你去搜索、去阅读、去询问，可能你会感觉很难搜、很难读、很少有答复。这一切将是刚离开新手村的你将遇到的各种挑战的第一个，而且其实是相对简单的一个，所以哪怕可能会花不少时间，请尽你所能去读懂这四篇文章。

当你读懂这四篇文章时，你应该可以算是基础入门了，之后就要靠你个人修行了。一个基本的模式是：有一个灵感，然后去研究与实现，在过程中学习新知识、战胜新挑战，最后或成或败都获得新的认识，继续下一个灵感，从而不断前进。当然，你在前进，你渴望的答案可能也在动，就像市场一样不断变动，或向你走来，或离你远去。（题外话：你认为世界是静止的还是运动的，或者说随机是否存在？）

特别提下，本教程教的编程知识是非常精简的，所以建议适当简单浏览下 Python 系统的知识，做到以后见到、或想用了知道怎么找即可。集合、元组、列表生成式这三个推荐去重点学下，这三个相对常用，但看见不懂想搜索可能都想不出关键词。编程参考资料可以看下这里。

顺着这个思路，可以把"之后学什么"分成三条线来看：

  • 编程线：集合、元组、列表生成式，然后是异常处理与模块化。目标是"看到别人的代码能读懂、想用的功能知道去哪找"。
  • 数学与统计线：收益率与波动率的定义、相关性与回归、假设检验的基本思想。目标是不至于把"相关"当"因果"。
  • 金融线：交易制度（涨跌停、停牌、除权除息）、财报的基本结构、常见因子（价值、成长、动量、波动率）。目标是能给策略找到"为什么它该有效"的理由。

三条线不必齐头并进，但任何一条完全空着都会成为天花板。只懂编程的人写不出有逻辑的策略，只懂金融的人写不出能跑的策略。

灵感的来源 #

灵感的最重要来源当然是阅读。本人水平太低就不做具体推荐了，以下列举一些可能的内容来源类别：

  • 论文
  • 研报
  • 聚宽的量化课堂与社区
  • 知乎量化交易话题下的回答
  • 宽客的博客（多数是国外的）
  • 各类书籍

关于书籍，除了专门讲量化交易的书，稍稍关注些其他领域可能带来全新的视角，比如财务分析、行为金融、数学、统计学、机器学习、甚至心理学、物理学等。据说美国做量化交易还有用到语音识别的。

学习时，建议用批判的眼光去看，保持自身独立思考，警惕盲从。还是那句话，量化交易行业很难有特别有价值的东西出现在大众眼前的。

除了阅读外，直接参与实际市场也是另一种重要的灵感来源。毕竟多数的阅读资源本身的灵感来自市场，比如市场交易时，市场对时下新闻的反应、对量价走势的瞬时反应、不同股票或人群的反应、你自己的反应等等。你自己不亲身投入这场波云诡谲之中，很难指望事后体会到其中的种种，而这些可能带给你许多灵感。比如比较知名的冰山算法与不少技术指标，当时的发明就离不开发明者对市场的了解。

关于"如何记录灵感"，一个很实用的建议：把每个灵感当场写成一句可回测的话。比如"低市盈率股票长期收益更好"就是一个半成品，而要写成第 8 篇那种程度——买什么、什么时候买、买多少、什么时候卖——才算真正可用于验证的灵感。这个习惯能大幅减少"想法很多但一个都验证不了"的情况。

六类来源的可信度与获取难度 #

把上面这些来源按"可信度"和"获取难度"两个维度摆一下，会得到一张很有用的地形图：

  • 论文：可信度最高，获取难度也最高。优点是有方法、有检验、有边界条件；缺点是多数论文的场景与 A 股差异很大，直接照搬往往不成立。适合用来找"思路"而不是找"参数"。
  • 研报：可信度中等，获取难度中等。优点是贴近本土市场、数据扎实；缺点是结论往往服务于卖方立场，且披露程度有限。
  • 聚宽量化课堂与社区：可信度中等，获取容易。这是入门阶段性价比最高的一类，因为有代码、能跑、能改。缺点是很多内容已经过时，且正如本篇开头所说，真正有效的策略很少会被公开。
  • 问答平台与博客：可信度参差，获取容易。适合用来补齐概念、了解某个指标的含义，不适合用来找策略。看到具体策略时要格外警惕。
  • 书籍：可信度较高，获取难度中等。优点是系统性强、有脉络；缺点是更新慢，往往落后市场好几年。
  • 自己的市场观察：可信度取决于你的记录是否客观，获取成本最高（要用时间换）。但它是唯一可能产出"别人没有的东西"的来源。

对刚入门的人来说，合理的顺序是：先用社区与博客补齐工具与概念，再用书籍搭起体系，然后用研报与论文去找具体想法，最后用自己的观察去微调与创新。

一份可执行的自学计划 #

自学最怕的不是没资料，而是没有节奏。下面给一份以周为单位、大约三个月的安排，你可以按自己的时间伸缩，但顺序不要打乱，因为后一步都依赖前一步的产出。

第一到第二周：把工具跑熟 #

  • 注册聚宽账号，把第 2 篇的完整代码亲手敲一遍（不要复制粘贴），跑通编译运行与运行回测。
  • 把第 3 篇所有代码片段逐段执行一遍，确认每处 print 的输出与文中一致。
  • 目标：能独立新建一个策略、粘代码、看日志、定位报错行号。

这个阶段最容易犯的错是"看懂了就不动手"。工具熟练度是纯肌肉记忆，跳过这一步，后面每次调策略都要多花半小时在和环境较劲上。

第三到第五周：复现别人的策略 #

  • 从聚宽量化课堂挑两到三篇带完整代码的文章，照着复现。
  • 每复现一个，改一个参数（比如持股数量从 10 改成 5），看结果怎么变，并写下你的解释。
  • 目标：能说清楚"这个策略为什么这么写"，而不只是"它能跑"。

复现的价值在于它是唯一能即时验证你理解程度的方式。看懂别人的代码是低标准，改对它、改坏它、解释它为什么变坏，才是理解。

第六到第八周：写一个自己的策略 #

  • 按第 8 篇的流程，从一句明确的规则出发，写成完整代码。
  • 必须包含：选股条件、卖出条件、买入金额、调仓频率四个要素。
  • 跑回测，然后按第 9 篇的指标表逐项检查，写一段结论说明这个策略行不行、为什么。
  • 目标：产出一个能拿去跟人讨论的完整作品。

这三个月的产出里，这一项最有价值。它不一定要赚钱，但必须逻辑完整、结论诚实。将来无论是进机构还是独立做，你需要展示的都是这个。

第九到第十二周：建立怀疑的习惯 #

  • 把自己那个策略故意"做坏"三次：加一个未来函数看看回测会变多好；把参数调到最优看看换段时间还剩多少；把交易次数砍到很少看看指标还成不成立。
  • 每次都记录下"坏"的样子。这份记录就是你未来的避坑清单。
  • 目标：看到任何漂亮的回测结果时，第一反应是"它可能是怎么骗我的"。

这一步听起来消极，实际上是从"会写策略"跨到"会判断策略"的关键。第 9 篇那些内容，只有亲手制造过一次假象，才算真懂。

关于工具与环境 #

除了聚宽，自学过程中还会用到几样东西，简单交代一下，免得你在不该花时间的地方花时间。

  • 聚宽网站内：策略回测、模拟交易、投资研究（研究环境支持 Python3 与 notebook，适合做数据探索）。入门阶段只用网站内就够，不必折腾本地环境。
  • 本地 Python 环境：等你想用 JQData 下载数据、或者想跑更重的计算时才需要。建议用虚拟环境隔离，避免包的版本互相冲突。
  • 数据存储：本地分析时，csv 文件足够应付入门阶段的数据量。等数据量到 GB 级别再考虑数据库，不必过早优化。
  • 版本管理：给自己的策略代码用 git 管理。这不是程序员的形式主义——策略调参过程中你一定会想回到"上周那个版本"，没有版本管理就只能靠复制文件，很快就会乱。

最后这条尤其值得强调。策略开发本质上是一个不断试错的过程，而试错的前提是"每次改动都可回退"。没有版本管理的策略开发，等于在没有存档的情况下打一局很长的游戏。

四类进阶方向 #

读完本教程后，往深处走大致有四个方向。它们不是互斥的选项，而是同一件事的不同切面，但每个方向的"入门门槛"和"见效速度"差别很大，值得先有个全貌。

方向一：更好的数据 #

本教程只讲了成分股、行情、财务三类数据。真实研究里还会用到更多维度：

  • 因子数据：估值、成长、质量、动量、波动率等各类因子。聚宽的财务数据表里大多已经现成。
  • 资金流与交易行为：龙虎榜、大宗交易、融资融券余额、北向资金。
  • 行业与指数数据：行业分类、指数成分变化历史。
  • 另类数据：新闻情绪、研报评级、公告文本。这类数据获取门槛高，但可能包含别人还没用上的信息。

这个方向的性价比很高，因为它通常不需要新的数学知识，只需要多查文档、多试 API。很多"策略不行"的问题，本质上是"数据不够"。

方向二：更好的方法 #

本教程的策略都是"规则型"的：条件满足就买，不满足就卖。往下走会接触到更系统的方法：

  • 多因子模型：把多个指标合成一个打分，按分数排序选股。这基本是第 8 篇策略的一般化。
  • 组合优化：在给定风险约束下求最优权重。需要一点线性代数与最优化基础。
  • 统计检验：判断一个因子的超额收益是不是显著的，而不是碰巧。这是最被低估的一项。
  • 机器学习：用模型去拟合特征与收益的关系。门槛最高，也最容易过拟合，第 9 篇的警告在这里尤其适用。

这个方向的学习曲线明显更陡，但它是从"能写策略"到"能系统地做研究"的分水岭。

方向三：更好的工程 #

当策略的数量变多、参数变多、回测次数变多之后，会冒出一批纯粹的工程问题：

  • 怎么批量跑几百组参数并保存结果，而不是手工点几百次。
  • 怎么管理几十个策略代码的版本与依赖。
  • 怎么把回测、模拟、实盘的代码复用起来，避免三份代码互相不一致。
  • 怎么监控策略在实盘中的运行状态，出问题能第一时间知道。

这些问题不涉及金融知识，但会实实在在地消耗你的时间。早一点建立基本的工程习惯（版本管理、脚本化、日志），后面的效率差距会非常大。

方向四：更深的市场理解 #

这是最无形、也最难速成的一项。它包括：理解交易制度如何影响价格、理解某类资金的行为模式、理解一个现象背后的经济学逻辑。

它的重要性在于：前三个方向都能帮你把策略做得更"精致"，只有这个方向能帮你判断一个策略"该不该有效"。而一个说不清为什么该有效的策略，无论回测多漂亮，都不值得投入真金白银。

四个方向怎么选？建议的顺序是：先把方向一用熟（数据是最快见效的），同时并行推进方向四（市场理解需要长期浸泡），等手上有了几个成型的策略，再回头补方向二与方向三。反过来做——先啃机器学习、再想策略——是新手最常见的低效路径。

关于职业化 #

想要入职量化行业，学历门槛往往较高。但别怕，学历不够的有志者不要被吓倒，毕竟人家也不是真要你的毕业证，无非是希望你能知识储量够、基础好、学习新东西快、有潜力。学历门槛高只是提效手段，你只要向他们证明你同样有相当的能力即可。

你应该被录取的理由是什么？怎么把这个理由告诉他们？回答这个问题比量化交易简单——至少有一个好策略了、想入职带他们赚钱，他们总不会还嫌你学历不够吧。当然，这是一个不必要的界，比如若你有相当的策略实现能力或因子发掘能力可能也可以了。所以建议你结合实际情况认真负责地想想，然后真的去试几次。

那做独立的职业量化交易可不可以呢？也是可以的，很多量化交易团队就几个人，甚至一个人的也有，但毕竟人多效率高不少。实际上，多数还是从原本公司独立出来的，学生毕业阶段就转独立的职业做量化交易还是少，现金流压力可能比较大，但也是有做得好的，后来成立公司的。

聚宽也有能帮助展示策略、证明自身、快速职业化与变现的栏目，而且也会有行业内人士来聚宽，找好策略与人才，比如策略被看中要谈买断、发的文章不错被录取等。注意，保护自己的成果不被无良人士窃取。总之，量化行业是相对公平、看重实力的，金子总会发光。

这一段里最值得记住的一句是"保护自己的成果"。它在实操上意味着两件事：一，不要把带真实逻辑的策略代码提交到公开仓库（回想第 7 篇里那个明文写账号密码的例子）；二，在社区展示策略时，可以先展示研究结论与思路，而不必披露完整的参数与实现。

三条路径的现实差异 #

把职业化的选择摊开，大致是三条路，各自的约束条件完全不同：

  • 进机构。优点是有人带、有数据、有资金、有风控；约束是学历与背景筛选较严，且你能接触到的策略往往受限于团队分工。适合想在体系内快速积累经验的人。
  • 做独立交易。优点是自由、上限高；约束是现金流压力大、没有风控兜底、一个人的精力很难覆盖研究、开发、运维全部环节。多数成功案例是先有积累再独立，而不是毕业即独立。
  • 做策略提供方。优点是可以用别人的资金跑自己的策略；约束是对策略的透明度与稳定性要求更高，且收益分成模式往往不利于新人。需要先有可展示的历史业绩。

对刚读完本教程的人来说，最现实的其实不是立刻选一条，而是先做出一个能拿得出手的东西——一个逻辑清楚、回测扎实、经得起追问的策略。有了这个东西，三条路径的门都会松一点；没有它，三条路都会卡在同一个地方。

关于"实力"的一个提醒 #

"量化行业看重实力"这句话是对的，但"实力"的定义需要说清楚。它通常不是"你懂多少模型"，而是这三件事：

  1. 你能不能独立提出一个有意义的问题。
  2. 你能不能把它变成一个可验证的实验。
  3. 你能不能诚实地解读结果——包括承认"这个想法不行"。

第三点往往最被低估。市场上绝大多数想法都是无效的，能快速、诚实、低成本地否掉一个想法，本身就是极高的生产力。本教程第 9 篇花那么大篇幅讲未来函数和过拟合，本质上就是在训练这种诚实。

十篇回顾 #

走完这十篇，你手里应该有这些东西：

  • 观念：知道量化交易是什么、值不值得学、需要什么条件（第 1 篇）。
  • 框架：能把任何想法装进"初始化 + 周期循环"，并跑出第一份回测（第 2 篇）。
  • 语言：够用的 Python——变量、数据类型、判断、循环、函数（第 3、4、5、6 篇）。
  • 数据：会取成分股、行情、财务数据（第 7 篇）。
  • 组合：能把前三样合成一个完整策略（第 8 篇）。
  • 判断力：知道一个回测结果该信到什么程度，以及未来函数、过拟合这些坑长什么样（第 9 篇）。
  • 方向：知道接下来往哪走（本篇）。

其中最后两项往往比前面几项更难，也更值钱。写代码的能力几个月就能练出来，而"判断一个策略是不是真的有效"的能力，需要长期在市场里被打脸才能长出来。

自测与自学 #

  • 回头把十篇的「自测与自学」全部过一遍，把答不上来的记录下来，形成一个属于你自己的补漏清单。
  • 从本篇推荐的四篇文章里选一篇，尽你所能读懂它，并把不懂的概念逐条列出来去搜索。
  • 看一眼你手上的第 8 篇策略，试着回答三个问题：它为什么该有效？它在什么情况下会失效？如果它失效了，你怎么知道？
  • 把第 8 篇的练习（加止损、剔除 ST 股与停牌涨停股）做完。那是整条连载里最有价值的一道题。

常见问题：学完之后还是觉得不会，怎么办 #

这大概是读完教程后最普遍的困惑。下面几种情形，对号入座即可。

情形一：代码能看懂，但让自己从零写就写不出来。 这是最正常的状态，也最容易解决。办法是把第 8 篇的参考代码合上，自己重写一遍；写不出来就翻一眼，再合上重写。通常重复三四次就能形成肌肉记忆。看懂和自己写出来之间的差距，只能靠重复来填，没有捷径。

情形二：策略能写出来，但不知道写什么策略。 这说明"灵感"这一环还空着。办法是从复现别人的策略开始：聚宽量化课堂里的文章基本都带代码，挑一篇照着做一遍，把参数换掉看看结果怎么变。复现是最快建立"什么样的想法值得试"这种直觉的方式。

情形三：能跑出结果，但判断不了结果好不好。 回到第 9 篇的指标速查表，按顺序过一遍：跑赢基准了吗、年化多少、最大回撤多大、交易次数够不够。这四问能筛掉大部分明显不合格的策略。剩下的判断，需要经验，而经验只能靠多看多比。

情形四：一切都好，但一到实盘就亏。 这通常不是技术问题，而是心理问题。回测时你知道后面会发生什么，实盘时你不知道，同样的回撤带来的感受完全不同。第 9 篇讲的"收益与风险的取舍"就是在讨论这件事。一个实用的办法是先用模拟交易跑足够久，久到你对账户的波动不再紧张，再考虑实盘。

四种情形有一个共同答案：继续做，别停。量化交易不是一门"读完教材就会"的学科，它更像游泳——所有必要的知识都可以在几天内讲完，但要真正会，只能下水。
