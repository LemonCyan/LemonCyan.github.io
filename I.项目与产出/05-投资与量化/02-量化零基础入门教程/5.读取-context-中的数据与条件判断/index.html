从已有的基础上继续 #

通过前文的讲解，我们已经能理解最开始的那个简单的策略例子，如下：

python
def initialize(context):
    run_daily(period, time='every_bar')
    g.security = '000001.XSHE'


def period(context):
    order(g.security, 100)

接下来，我们将在此基础上进行改进与举例，学习新内容。

到目前为止，这个策略是"瞎"的：它不知道今天几号、不知道手里有多少钱、不知道自己是赚是亏，它只会机械地每天买 100 股。这一篇要做的，就是给策略装上"眼睛"——context。

context 的结构 #

context 是一个回测系统建立的 Context 类型的对象，其中存储了如当前策略运行的时间点、所持有的股票、数量、持仓成本等数据。

对象可以理解为特殊类型的变量，对象的结构往往比我们之前见过的 list 与 dict 更复杂。被定义好的对象是有名字的，比如 context 是一个变量，它的变量类型是一个 Context 类型的对象。就像 dict 包括 key 与 value，Context 类型的对象也包括很多属性，而且可以嵌套另一种类型的对象，结构见下图。图中只包括了主要与常用的内容，详细介绍可以看 API 文档：Context 对象。

关于对象的知识非常复杂繁多，目前我们只需学习如何取用 context 中的数据就好。

context 中的数据取用方法 #

获取对象类型变量内包含的数据，方法是用英文句号隔开；而当包含的是另一个对象时，只需再继续用英文句号隔开即可。例子如下：

python
# 打印可用资金
print(context.portfolio.available_cash)
# 打印运行频率
print(context.run_params.frequency)
# 打印当前单位时间的开始时间
print(context.current_dt)

# 执行后日志内容如下
# 1000000.0
# day
# 2016-06-01 09:30:00

注意 context.portfolio.available_cash 这串写法：它由三个名字用点连起来，读法是"context 里的 portfolio 里的 available_cash"——即"上下文中、账户组合中的、可用资金"。这种一层层往里点的写法是读取嵌套对象的标准姿势，第 7 篇取财务数据时还会见到类似结构。

当要获取的对象内的数据是另一种有结构的变量类型时，比如 dict 或 list，正常按照该变量类型的用法进一步取用数据即可。例如 context.portfolio.positions 是一个 dict，我们就可以应用之前讲过的 dict 的用法来使用它。例子如下，这次给出了完整代码。

python
# context.portfolio.positions 的含义是仓位信息，所以为了让它有数据，需要在取之前买入并持有股票。

def initialize(context):
    run_daily(period, time='every_bar')
    g.security = '000001.XSHE'


def period(context):
    order(g.security, 100)
    # 打印所有键
    print(context.portfolio.positions.keys())
    # 打印所有值
    print(context.portfolio.positions.values())
    # 打印 g.security 的开仓均价
    print(context.portfolio.positions[g.security].avg_cost)

# 执行后日志内容如下
# ['000001.XSHE']
# [UserPosition({'avg_cost': 8.539999999999997, 'security': '000001.XSHE', 'closeable_amount': 0, 'price': 8.53, 'total_amount': 100})]
# 8.54

这里有三层结构值得拆开看：positions 是字典，键（key）是股票代码，值（value）是一个 UserPosition 对象；这个对象里又有 avg_cost（开仓均价）、price（现价）、total_amount（总持仓量）、closeable_amount（可卖持仓量）等属性。所以 positions[g.security].avg_cost 的含义是"仓位字典里、代码为 g.security 的那一项的、开仓均价"。

常用的 context 数据写法 #

推荐自己动手试下：

  • 当前时间：context.current_dt
  • 当前时间的「年-月-日」字符串格式：context.current_dt.strftime("%Y-%m-%d")
  • 前一个交易日：context.previous_date
  • 当前可用资金：context.portfolio.available_cash
  • 持仓价值：context.portfolio.positions_value
  • 累计收益：context.portfolio.returns
  • 当前持有股票：context.portfolio.positions.keys()
  • 当前持有的某股票的开仓均价：context.portfolio.positions['xxxxxx.xxxx'].avg_cost
  • 当前持有的某股票的可卖持仓量：context.portfolio.positions['xxxxxx.xxxx'].closeable_amount

其中 strftime("%Y-%m-%d") 这个写法很值得记住——它把时间对象转成 '2018-05-04' 这样的字符串，用于和日期字符串比较。第 8 篇写选股周期时会用到类似的日期处理。

条件判断 #

能够获取 context 的数据后，我们会考虑利用这些数据丰富策略的逻辑，但在此之前我们还要学习 if 条件判断语句，如下：

python
# 如果 条件1 成立为 True 将执行代码块1
# 如果 条件1 不成立为 False，将判断条件2
# 如果 条件2 成立为 True 将执行代码块2
# 如果 条件2 还不成立为 False，将执行代码块3

if 条件1:
    代码块1
elif 条件2:
    代码块2
else:
    代码块3

# 注意
# elif 可以有多个连续写
# 且 elif 和 else 都可以省略
# 条件判断语句中可以嵌套条件判断语句

举几个例子：

python
# 打印 a、b 中最大值
if a >= b:
    print(a)
else:
    print(b)

# 判断 a 的正负性
if a > 0:
    print('正')
elif a < 0:
    print('负')
elif a == 0:
    print('零')

# 如果当前是 2018-05-04，则下单买入 100 股平安银行
date = context.current_dt.strftime("%Y-%m-%d")
if date == '2018-05-04':
    order('000001.XSHE', 100)

# 判断 a 大小情况
if a > 0:
    if a < 1:
        print('a 大于 0 且小于 1')
    else:
        print('a 大于等于 1')
else:
    print('a 小于等于 0')

条件判断语句比较简单，但还需说明的是条件的写法中用到的运算符：

python
# 写条件常用运算符：
# <  小于
# >  大于
# <= 小于等于
# >= 大于等于
# == 等于
# != 不等于
# and 与，即 and 两边条件同为真，则真
# or  或，即 or 两边条件任意一个为真，则真
# not 非，即 not 右侧条件为真则假，not 右侧条件为假则真

# 以判断 a 是否为 0 的几个写法为例
# 写法1
if a != 0:
    print('否')
else:
    print('是')

# 写法2
if a > 0 or a < 0:
    print('否')
else:
    print('是')

# 写法3
if a >= 0 and a <= 0:
    print('是')
else:
    print('否')

# 写法4
if not a == 0:
    print('否')
else:
    print('是')

请特别注意 == 和 = 的区别，这是新手最高频的错误来源：= 是赋值（把右边的值装进左边的变量），== 是判断相等（产出一个 True 或 False）。写成 if a = 0: 会直接报语法错误。

止损 #

狭义的止损是指当亏损达到一定幅度后下单卖出该股票的操作，目的是减少进一步的亏损。广义则指在狭义的思路上衍生的复杂的减少亏损的方法。更多的情况下指狭义的止损。综合运用前文讲过的内容，我们已经可以实现当亏损达到一定幅度后下单卖出该股票的止损操作了，不妨先自己思考下再继续学习。

通过 context 的数据可以得到持有股票的成本和现价，从而可以算出该股票的盈亏情况；运用条件判断语句根据盈亏情况从而决定是否卖出股票，从而实现止损操作。代码如下：

python
def initialize(context):
    run_daily(period, time='every_bar')
    g.security = '000001.XSHE'


def period(context):
    # 买入股票
    order(g.security, 100)
    # 获得股票持仓成本
    cost = context.portfolio.positions['000001.XSHE'].avg_cost
    # 获得股票现价
    price = context.portfolio.positions['000001.XSHE'].price
    # 计算收益率
    ret = price / cost - 1
    # 打印日志
    print('成本价：%s' % cost)
    print('现价：%s' % price)
    print('收益率：%s' % ret)
    # 如果收益率小于-0.01，即亏损达到 1% 则卖出股票，幅度可以自己调，一般 10%
    if ret < -0.01:
        order_target('000001.XSHE', 0)
        print('触发止损')

设置回测时间为从 2017-03-01 到 2017-03-31，初始资金为 100000，频率为天。回测发现会在 2017-03-20 触发止损。

这段代码值得逐行理解，因为它把前四篇的所有知识都用上了：

  • context.portfolio.positions['000001.XSHE'] 用字典取值拿到这只股票的持仓对象。
  • .avg_cost 和 .price 从持仓对象里取出成本价与现价——都是浮点数。
  • price / cost - 1 是收益率的常见算法：现价除以成本减一。成本 10 元、现价 9 元时，9/10-1 = -0.1，即亏 10%。
  • if ret < -0.01: 是条件判断，亏损超过 1% 时成立。
  • order_target('000001.XSHE', 0) 用第 4 篇讲的"目标持仓量"函数，目标量写 0 就是清仓。

这段代码有一个已知的粗糙之处：它在每个周期开头无条件买入 100 股，然后再判断是否止损。所以一旦触发止损，下一周期又会重新买入。这在实际策略里是明显的逻辑缺陷，第 6 篇会把它改成"先判断持仓、再决定买入还是止损"的写法。

本篇小结 #

  • context 是系统在每个周期自动传给你的对象，装着时间、资金、持仓等现场信息。
  • 用点号逐层深入取数：context.portfolio.available_cash。
  • positions 是字典，取值后再点属性：positions['代码'].avg_cost。
  • if / elif / else 控制分支，条件是布尔值；== 判等，= 赋值。
  • 止损 = 用 avg_cost 与 price 算出收益率 + if 判断 + order_target(x, 0) 清仓。

条件判断的几条实践要领 #

if 的语法本身很简单，但写策略时出问题的往往不是语法，而是逻辑。这里补几条从实际调试中总结出来的要领。

第一，先判断再取值，不要取值后再判断。 上一篇末尾那个止损例子里，positions['000001.XSHE'] 是在确认持仓之前取的。如果某天这只股票恰好清仓了，这一行就会直接报 KeyError，后面的判断根本没机会执行。正确顺序永远是"确认存在 → 再取值 → 再判断数值"。

第二，elif 的顺序决定了优先级，而且只会命中第一个成立的分支。 如果同时写了 if a > 0: 和 elif a > 100:，那么 a = 200 时只会走第一个分支，第二个永远不会被执行。所以条件要从最严格到最宽松排列，或者确认各条件之间互斥。

第三，== 用于比较，且对浮点数要格外小心。 第 3 篇讲过浮点数不精确，所以 if ret == 0: 这种写法常常永远不成立——两个理论上相等的浮点数，实际可能有极小差异。判断浮点数是否相等，更稳的写法是判断差值是否足够小，比如 if abs(ret) < 0.0001:。

第四，and / or 有短路特性。 a and b 里如果 a 已经为假，b 根本不会被求值；a or b 里如果 a 为真，b 也不会被求值。这条特性常被用来防报错，例如 if stk in positions and positions[stk].avg_cost > 0:——前半句为假时，后半句里的取值动作就不会发生，于是不会报 KeyError。这个套路在后文写选股时很有用。

第五，空值和零值在条件里都算"假"。 if positions: 这条语句的含义是"如果 positions 非空"，空字典会被判为假。类似地 0、''、None、空列表都会被当成假。利用这一点可以写出很简洁的判断，但也要小心：0 在数值上是合法的（比如收益率恰好为 0），此时写成 if ret: 会把它误判为假。

自测与自学 #

  • 实践下文中的例子。
  • 阅读 API 文档中 Context 对象，了解下其中的结构与内容。
  • 写一个策略，内容为在 20180301 买入一个股票，在 20180321 卖出一个股票。股票可以自己定。
  • 试着根据止损的例子实现止盈，即指当盈利达到一定幅度后下单卖出股票。
  • 写一个自定义函数，功能是判断一个年份是否是闰年。闰年定义为：普通年（不能被 100 整除的年份）能被 4 整除的为闰年（如 2004 年就是闰年，1999 年不是闰年）；世纪年（能被 100 整除的年份）能被 400 整除的是闰年（如 2000 年是闰年，1900 年不是闰年）。【提示：利用取余运算（%）判断是否整除。】
