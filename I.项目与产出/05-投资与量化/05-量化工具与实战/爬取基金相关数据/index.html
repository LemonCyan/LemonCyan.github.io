基金数据是量化投资里最容易获取、也最容易踩坑的一类数据。天天基金和东方财富提供了公开接口，但它们的返回值格式不统一：有的是包裹在 jsonpgz(...) 里的 JSONP，有的是 HTML 表格需要解析，有的还要分页。

这篇文章把三类接口的调用方式整理成可复用的函数，并给出一个完整的净值抓取流程。

注意：这些接口是公开的网页接口，不是官方 API。它们没有文档、没有稳定性承诺、可能随时变更或限流。用于学习和小规模研究没问题，用于生产系统需要自行加缓存、限速和容错。

本文涵盖与不涵盖 #

涵盖：基金实时估值、历史净值、基金代码表三类数据的抓取方法，以及分页处理与数据清洗。

不涵盖：分钟级行情、基金持仓明细、费率数据。这些接口的获取方式各不相同，且变动更频繁。

一、首先要修正的问题 #

原始代码里有两处必须改掉的写法：

① 伪造的认证头。 原文用了 'Authorization': 'Bearer token123' 和 'Cookie': 'session=abcdef123456'——这是占位符，不是真实凭据。这些接口不需要认证，带上假凭据反而可能被服务端拒绝或标记。本文已将其删除。

② 重复调用的函数。 原文在不同位置重复定义了多次 Print_FundData，逻辑完全相同。本文合并为一个，通过参数控制输出。

四、获取基金实时估值 #

天天基金的估值接口返回 JSONP 格式，形如 jsonpgz({"fundcode":"007345",...});，需要先用正则把外层包装剥掉。

python
def get_fund_info_now(fund_code):
    """
    获取指定基金的实时估值数据。

    参数：
        fund_code (str): 六位基金代码，例如 '007345'

    返回：
        dict: 含 fundcode / name / dwjz / gsz / gszzl / gztime 等字段；
              失败时返回 None
    """
    url = f"http://fundgz.1234567.com.cn/js/{fund_code}.js"
    try:
        resp = requests.get(url, headers=HEADERS, timeout=10)
        resp.encoding = 'utf-8'
    except requests.RequestException as exc:
        print(f"[{fund_code}] 请求失败: {exc}")
        return None

    # 剥掉 JSONP 外壳：jsonpgz(...)
    match = re.search(r'jsonpgz\((.*)\)', resp.text, re.S)
    if not match:
        print(f"[{fund_code}] 未匹配到 JSONP 数据，可能代码不存在或接口已变更")
        return None

    try:
        return json.loads(match.group(1))
    except json.JSONDecodeError as exc:
        print(f"[{fund_code}] JSON 解析失败: {exc}")
        return None


# 用法示例
info = get_fund_info_now('007345')
if info:
    print(f"基金名称: {info['name']}")
    print(f"单位净值({info['jzrq']}): {info['dwjz']}")
    print(f"实时估值({info['gztime']}): {info['gsz']}  涨跌: {info['gszzl']}%")

返回字段说明：

字段 含义
fundcode 基金代码
name 基金名称
jzrq 净值日期（上一交易日）
dwjz 单位净值
gsz 实时估值
gszzl 估值涨跌幅（%）
gztime 估值时间

五、获取历史净值 #

历史净值走的是东方财富的分页 HTML 接口，返回的是一段带 <table> 的 JavaScript 字符串，需要用 BeautifulSoup 解析，并且必须先知道总页数才能翻完。

请求单页 #

python
F10_API = "http://fund.eastmoney.com/f10/F10DataApi.aspx"


def fetch_history_page(fund_code, start_date, end_date,
                       data_type='lsjz', page=1, per=20):
    """
    获取基金历史数据的单页 HTML。

    参数：
        fund_code   (str): 基金代码
        start_date  (str): 起始日期 'YYYY-MM-DD'
        end_date    (str): 结束日期 'YYYY-MM-DD'
        data_type   (str): 'lsjz' 历史净值
        page        (int): 页码，从 1 开始
        per         (int): 每页条数

    返回：
        str: 服务器返回的 HTML 片段（含 table）
    """
    params = {
        'type': data_type,
        'code': fund_code,
        'page': page,
        'sdate': start_date,
        'edate': end_date,
        'per': per,
    }
    resp = requests.get(F10_API, params=params, headers=HEADERS, timeout=10)
    resp.encoding = 'utf-8'
    return resp.text

解析总页数 #

返回的片段里含 pages:49 这类字段，直接正则提取：

python
def parse_total_pages(html):
    """从返回值中提取总页数；失败时按 1 页处理。"""
    match = re.search(r'pages\s*:\s*(\d+)', html)
    return int(match.group(1)) if match else 1

解析表格为 DataFrame #

python
def parse_history_table(html):
    """
    把 HTML 片段里的净值表格解析成 DataFrame。

    返回：
        DataFrame: 列含 净值日期 / 单位净值 / 累计净值 / 日增长率 / 申购状态 / 赎回状态
    """
    soup = BeautifulSoup(html, 'lxml')
    table = soup.find('table')
    if table is None:
        return pd.DataFrame()

    rows = []
    for tr in table.find_all('tr')[1:]:          # 跳过表头
        cells = [td.get_text(strip=True) for td in tr.find_all('td')]
        if cells:
            rows.append(cells)

    if not rows:
        return pd.DataFrame()

    # 表格列数固定为 6 列，个别行可能缺列
    header = ['净值日期', '单位净值', '累计净值', '日增长率', '申购状态', '赎回状态']
    rows = [r[:len(header)] for r in rows if len(r) >= 4]
    df = pd.DataFrame(rows, columns=header[:len(rows[0])] if rows else header)

    # 类型转换：数值列去掉 % 并转 float
    for col in ['单位净值', '累计净值']:
        if col in df.columns:
            df[col] = pd.to_numeric(df[col], errors='coerce')
    if '日增长率' in df.columns:
        df['日增长率'] = pd.to_numeric(
            df['日增长率'].astype(str).str.rstrip('%'), errors='coerce'
        )
    if '净值日期' in df.columns:
        df['净值日期'] = pd.to_datetime(df['净值日期'], errors='coerce')
    return df

抓完所有页 #

python
def fetch_all_history(fund_code, start_date, end_date, per=20, max_pages=200):
    """
    翻页抓取全部历史净值并合并。

    参数：
        max_pages (int): 安全上限，防止接口异常导致死循环

    返回：
        DataFrame: 按日期升序排列的净值数据
    """
    first = fetch_history_page(fund_code, start_date, end_date, per=per, page=1)
    total = min(parse_total_pages(first), max_pages)
    print(f"[{fund_code}] 共 {total} 页，每页 {per} 条")

    frames = [parse_history_table(first)]
    for page in range(2, total + 1):
        time.sleep(REQUEST_INTERVAL)             # 限速，别把服务器打爆
        html = fetch_history_page(fund_code, start_date, end_date,
                                  per=per, page=page)
        frames.append(parse_history_table(html))

    df = pd.concat(frames, ignore_index=True)
    df = df.dropna(subset=['净值日期']).sort_values('净值日期').reset_index(drop=True)
    return df


# 用法示例
nav = fetch_all_history('007345', '2024-01-01', '2025-12-31')
print(f"共获取 {len(nav)} 条记录")
print(nav.head())

六、获取基金代码表 #

要批量抓取，首先需要一份「代码 → 名称」的映射。东方财富提供了一个全量 JS 文件：

python
def fetch_fund_code_list():
    """
    获取全市场基金代码表。

    返回：
        DataFrame: 列含 基金代码 / 拼音缩写 / 基金名称 / 基金类型 / 拼音全称
    """
    url = "http://fund.eastmoney.com/js/fundcode_search.js"
    resp = requests.get(url, headers=HEADERS, timeout=15)
    resp.encoding = 'utf-8'

    match = re.search(r'var\s+r\s*=\s*(\[.*\]);?', resp.text, re.S)
    if not match:
        print("未匹配到基金代码表")
        return pd.DataFrame()

    data = json.loads(match.group(1))
    df = pd.DataFrame(data, columns=['基金代码', '拼音缩写', '基金名称',
                                     '基金类型', '拼音全称'])
    return df


codes = fetch_fund_code_list()
print(f"共 {len(codes)} 只基金")
print(codes['基金类型'].value_counts().head(10))

七、组合使用：批量抓取指定类型基金 #

有了代码表，就能按类型批量抓取估值：

python
def batch_fetch_estimates(fund_type='混合型', limit=20):
    """
    按基金类型批量抓取实时估值。

    参数：
        fund_type (str): 基金类型关键字，如 '混合型' / '指数型' / '债券型'
        limit     (int): 最多抓取数量

    返回：
        DataFrame: 各基金的估值快照
    """
    codes = fetch_fund_code_list()
    if codes.empty:
        return pd.DataFrame()

    targets = codes[codes['基金类型'].str.contains(fund_type, na=False)]
    targets = targets.head(limit)

    records = []
    for _, row in targets.iterrows():
        info = get_fund_info_now(row['基金代码'])
        if info:
            records.append({
                '代码': info.get('fundcode'),
                '名称': info.get('name'),
                '单位净值': info.get('dwjz'),
                '估值': info.get('gsz'),
                '涨跌幅%': info.get('gszzl'),
                '估值时间': info.get('gztime'),
            })
        time.sleep(REQUEST_INTERVAL)

    return pd.DataFrame(records)


snapshot = batch_fetch_estimates('指数型', limit=10)
print(snapshot)

八、注意事项 #

① 接口无承诺。 这类网页接口不是官方 API，字段名和 URL 都可能变。生产环境要加监控，一旦解析失败要能告警而不是静默返回空。

② 必须限速。 批量抓取时每次请求之间至少间隔 0.5 秒。高频请求会被限流，甚至封 IP。

③ 不要用于商业分发。 数据版权属于数据提供方，个人研究使用是合理范围，抓取后大规模再分发存在法律风险。

④ 缓存原始响应。 调试解析逻辑时反复请求同一页很浪费，建议把 HTML 存到本地再解析，确认逻辑正确后再接入网络。

⑤ 估值 ≠ 净值。 实时估值是盘中基于持仓的估算，与实际收盘净值有偏差，尤其对重仓股停牌或调仓频繁的基金偏差更大。用估值做回测结果会失真。
