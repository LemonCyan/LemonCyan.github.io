二、量化的本质 #

量化没有创造出新的投资逻辑，也不改变市场的运行和结构，但它用新的技术对实现方法和工具进行了创新——利用数学统计、人工智能等方法取代人工决策。一般情况，市场研究、基本面分析、选股、择时、下单等都可以由计算机自动完成。

量化投资的核心优势在于：

  • 通过计算机分析挖掘因子的能力更强，可以从低信噪比的大数据中提取有价值的信息
  • 可以更好地量化风险及收益
  • 决策更为及时、客观、可靠
  • 可以克服情绪及人为操作的局限性

量化投资广泛出现在各种交易市场：股市、期货、基金、期权、外汇、债券、比特币、NFT 等等——有资源交换需求的地方就可以量化交易。

三、A 股市场：融资市而非投资市 #

股票市场是股票发行和交易的场所，股份公司通过面向社会发行股票集中资金实现规模经营，社会资金也可以购买股票谋求财富增值。

但国内股票市场（A 股）更多是融资市场的角色，而不是投资市场——主要为融资服务，卖力 IPO，助力实体经济。这也解释了为什么 A 股在投资层面的表现相对较差。

国内市场上各种「面」的分析——基本面、技术面、市场面、政策面——都很好，但在 A 股都不够用。各种理论层出不穷，比如缠论、庄家理论，以及美股推崇的长期价值理论，尽管都很有道理，却经不住 A 股现实的打击。

归根结底，市场的核心还是信息差：真正重要的信息获取不到，能拿到的很多是烟雾弹。只能寄望于更好的经济预期，以及信息披露与制度的完善。

股票量化能不能赚钱 #

个人感觉，量化会比散户有优势（但并非绝对优势）。股票量化的盈利来源和其他市场参与者并无本质区别，主要可归因成两部分：

一是源于企业自身的价值和成长。 能够实现这个收益可能只是 A 股的理想，因为现实中很受打击——辛苦成长这么多年，指数还在 3000 点徘徊。

二是源于股票价格的非理性波动，并提供更准确的定价。 量化的盈利基于市场失效的前提：用较低价格买入被低估的「商品」，推动价格达到更好的平衡。在热衷跟风炒作的 A 股上，这点还有不错空间——只要跑赢散户的非理性，就有一定收益。

四、期货市场 #

期货合约（Futures Contract）是一种跨越时间的交易方式。买卖双方签订合约，同意按指定时间、价格与其他交易条件交收指定数量的现货。期货通常集中在期货交易所，以标准化合约买卖，也有部分可透过柜台交易（场外交易合约）。交易资产通常是商品或金融工具。

类别 品种
农产品期货 棉花、大豆、小麦、玉米、白糖等
金属期货 铜、铝、锡、锌、镍、黄金、白银
能源期货 原油、汽油、燃料油
金融期货 国债期货、股指期货（波动性与风险相对更大）

与股市不同，期货市场的操作空间更多（可做多、可做空、支持 T+0），同时杠杆更大、回撤更大、风险更高，风险收益比也可能更高。

个人感觉，期货是一个负和博弈市场，收益主要来自对手的失误，赢的只有少数具有信息优势的人。期货可能更适合行业人员，需要敏锐捕捉行业机遇。此外，通过期现套利对冲实业经营风险也是不错的手段。

五、六类量化策略 #

量化策略方法五花八门。简单点可以通过基本面、技术面分析获得因子进行交易（比如 RSI 大于 80 就卖出），复杂点可以利用各种数据结合人工智能分析预测、高频交易等。

按个人理解，大致归为六类：

A. 多因子选股模型 #

用「因子」识别股票和市场的特征，在因子帮助下评估价格，买入价格偏低的、卖出价格偏高的股票。

比如根据 RSI 设计一个反转因子——RSI 非常高说明过度高涨，后面可能容易跌；再根据过去时间 T 内的加权平均涨幅设计动量因子，通过结合多个因子做打分/回归建模来预测未来收益。

常见因子：

因子 含义 经验规律
价值因子 市盈率、市净率、现金流等财务指标 估值低的票容易涨
成长因子 过去三年净利润和营收的复合增长率 高增长的票容易涨
动量因子 过去 T 期内的加权平均涨幅 趋势确立则延续
波动率因子 股价波动幅度 波动率偏低，后续往往上涨
流动性因子 换手率 换手率偏低，后续往往上涨（缩量筑底）
情绪因子 市场参与者乐观程度 普遍乐观则倾向上涨
资金流因子 大盘、板块、个股资金流入 持续流入则倾向上涨
板块因子 板块内热点股票表现 龙头涨则板块跟涨
盘口因子 十档买卖挂单强弱 买盘强于卖盘则短期偏强
反转因子 涨多必跌、跌多必涨 均值回复

因子清单来源：幻方量化 18 问

市场常见的多因子模型体系：

B. 价值投资策略 #

通过基本面分析，如市盈率、市净率、现金流、净利润和营收复合增长率等财务指标，分析公司的盈利模式是否可靠，预估未来价值，在价格较低时考虑买入。

C. 事件驱动策略 #

及时根据政策变化（货币政策、外汇、行业政策）、自然因素变化制定对应策略，这是炒股、期货的必知策略。

比如：当有加息计划，大家会考虑把钱存银行获得无风险收益，可能适当减持股票；当有自然灾害，农作物期货价格可能上升，可以做多。

D. 对冲策略 #

通过投资组合多样化降低市场风险。核心思想是利用不同资产之间的价格波动来抵消彼此风险，从而降低整体组合风险。

具体操作方式很多，包括配对交易、套利交易、期权交易、alpha 对冲等。以经典配对交易为例：当两个合约有很强相关性时，可能存在相似的变动关系，两者价差会维持在某一水平。当市场变化导致价差偏离均衡，可以买入其中一份合约同时卖出另一份，等价差恢复正常水平时平仓获利。

E. 高频交易策略 #

核心思想是利用市场价格的短期波动获利。通过高频数据分析和预测，快速买卖股票、期货和其他金融产品，捕捉微小的价格差异与波动。

这种策略依赖高速交易系统和算法，在毫秒或更短时间内执行决策，交易频率高、风险高，潜在收益也高。

F. 量化择时策略 #

通过分析历史数据、市场趋势、投资者情绪等因素预测未来市场走势，作为投资决策依据。常用方法有趋势择时、市场情绪择时、牛熊线、神经网络预测、统计套利等。

比如经典的双均线趋势跟踪策略：当短期上升趋势有所突破就考虑买入，反之考虑卖出。下面附上可直接运行的完整实现。

六、双均线实盘策略完整代码 #

以下代码在迅投 QMT（xtquant / MyQuant 平台）上运行。注意几个平台特性：

  • 文件首行 #encoding:gbk 是 QMT 的编码声明，不能省
  • init(C) 在策略启动时调用一次，用于初始化
  • handlebar(C) 每根 K 线或每个分笔触发一次
  • passorder() 是下单函数，参数顺序固定
  • get_trade_detail_data() 查询账户、持仓、委托
python
#encoding:gbk
import pandas as pd
import numpy as np
import datetime

"""
示例说明：
当短期均线由上向下穿越长期均线时做空
当短期均线由下向上穿越长期均线时做多
策略讲解：https://www.myquant.cn/docs/python_strategyies/153
"""


class GlobalState:
    """用于保存委托状态的全局容器。"""
    pass


A = GlobalState()

# ContextInfo 对象在盘中每次 handlebar 调用前都会被深拷贝。
# 如果调用 handlebar 的分笔不是 K 线最后分笔，ContextInfo 会被回退到深拷贝的内容，
# 所以 ContextInfo 不能用来记录快速交易的信号。


def init(C):
    """策略初始化，只在启动时执行一次。"""
    A.acct = '88'
    A.acct_type = "STOCK"
    A.stock = C.stockcode + '.' + C.market   # 品种为模型交易界面选择品种
    # A.acct = account                       # 账号为模型交易界面选择账号
    # A.acct_type = accountType              # 账号类型为模型交易界面选择账号
    A.amount = 10000                         # 单笔买入金额
    A.line1 = 5                              # 快线周期
    A.line2 = 20                             # 慢线周期
    A.waiting_list = []                      # 未查到委托列表，存在则暂停后续报单，防止超单
    A.buy_code = 23 if A.acct_type == 'STOCK' else 33    # 买入代码，区分股票与两融
    A.sell_code = 24 if A.acct_type == 'STOCK' else 34   # 卖出代码
    C.set_universe([A.stock])                # 设置股票池，订阅品种行情
    print(f'设置双均线{A.line1}，{A.line2}实盘示例{A.stock} '
          f'{A.acct} {A.acct_type} 单笔买入金额{A.amount}')


def handlebar(C):
    """每根 K 线触发一次。"""
    # 跳过历史 K 线
    if not C.is_last_bar():
        print('is last null')
        return

    now = datetime.datetime.now()
    now_time = now.strftime('%H%M%S')

    # 跳过非交易时间
    if now_time < '093000' or now_time > "150000":
        print('非交易时间')
        return

    # 获取账户信息
    account = get_trade_detail_data(A.acct, A.acct_type, "account")
    if len(account) == 0:
        print(f'账号{A.acct} 未登录 请检查')
        return
    account = account[0]
    available_cash = int(account.m_dAvailable)

    # 如果有未查到委托，先查询委托状态
    if A.waiting_list:
        found_list = []
        orders = get_trade_detail_data(A.acct, A.acct_type, 'order')
        print('wait-orders', A.waiting_list, orders)
        for order in orders:
            if order.m_strRemark in A.waiting_list:
                found_list.append(order.m_strRemark)
        A.waiting_list = [i for i in A.waiting_list if i not in found_list]

    # 回测时置空（真实盘请注释掉下面这一行，让上面的查询生效）
    A.waiting_list = []

    if A.waiting_list:
        print(f"当前有未查到委托 {A.waiting_list} 暂停后续报单")
        return

    # 当前持仓
    holdings = get_trade_detail_data(A.acct, A.acct_type, 'position')
    holdings = {
        i.m_strInstrumentID + '.' + i.m_strExchangeID: i.m_nCanUseVolume
        for i in holdings
    }

    # ==== 核心逻辑 ====
    # 获取日线收盘价，前复权
    data = C.get_history_data(max(A.line1, A.line2) + 1, '1d', 'close',
                              dividend_type='front_ratio')
    close_list = data[A.stock]
    if len(close_list) < max(A.line1, A.line2) + 1:
        print('行情长度不足(新上市或最近有停牌) 跳过运行')
        return

    # 上一根 K 线时的均线值 vs 当前均线值
    pre_line1 = np.mean(close_list[-A.line1 - 1: -1])
    pre_line2 = np.mean(close_list[-A.line2 - 1: -1])
    current_line1 = np.mean(close_list[-A.line1:])
    current_line2 = np.mean(close_list[-A.line2:])

    # 买入数量向下取整到 100 的整数倍（A 股一手 = 100 股）
    vol = int(A.amount / close_list[-1] / 100) * 100

    # 金叉：旧短 < 旧长，新短 > 新长 —— 当前无持仓则买入
    if (A.amount < available_cash and vol >= 100
            and A.stock not in holdings
            and pre_line1 < pre_line2 and current_line1 > current_line2):
        msg = f"双均线实盘 {A.stock} 上穿均线 买入 {vol}股"
        passorder(A.buy_code, 1101, A.acct, A.stock, 14, -1, vol,
                  '双均线实盘', 1, msg, C)
        print(msg)
        A.waiting_list.append(msg)

    # 死叉：旧短 > 旧长，新短 < 新长 —— 有持仓则卖出
    if (A.stock in holdings and holdings[A.stock] > 0
            and pre_line1 > pre_line2 and current_line1 < current_line2):
        msg = f"双均线实盘 {A.stock} 下穿均线 卖出 {holdings[A.stock]}股"
        passorder(A.sell_code, 1101, A.acct, A.stock, 14, -1,
                  holdings[A.stock], '双均线实盘', 1, msg, C)
        print(msg)
        A.waiting_list.append(msg)

代码要点说明 #

关键点 为什么重要
C.is_last_bar() 回测时会遍历历史 K 线，这一句确保只在最新 K 线上执行
dividend_type='front_ratio' 前复权处理，避免除权缺口被误判为价格波动
close_list[-line-1:-1] 与 [-line:] 取「上一次」和「当前」的均线值，用交叉判断而非大小判断，才能真正识别金叉死叉
int(... / 100) * 100 A 股必须整手买卖，向下取整避免资金不足
A.waiting_list 防止上一笔委托未成交就重复下单，这是实盘必备的保护
passorder 的参数顺序 (买卖方向, 下单类型, 账号, 代码, 价格类型, 价格, 数量, 备注, 快速下单标志, 消息, C)，错一个就报错

七、给新手的建议 #

量化策略设计开发中，Python 编程入门并不难。前期编程只要入门够用就行，只有交易的思路才是始终的核心。

除了积累交易经验、学习经典策略，还可以研究各大公司的研报，学习前沿的策略设计，才比较有可能跟得上市场。有时找 ChatGPT 聊聊策略、激发些思路也是不错的选择。

特别地，对于新手而言，先学习写一个止盈止损策略是必修课。先学会如何控制风险是首要的，其次才是折腾怎么盈利。
