量化金融运用数学、统计学和计算机科学等工具，通过系统性的方法进行金融分析和交易。这一领域为复杂的市场行为提供了深入的分析框架，使得交易策略不再依赖直觉，而是建立在严格的数据分析和模型基础之上。

本篇不涉及具体平台与安装步骤，只做两件事：把量化交易中最常被混用的术语讲清楚，把主流策略分门别类地枚举出来。平台与环境搭建属于工程问题，术语与策略分类才是需要反复回来的知识骨架。

量化交易的基本框架 #

在展开术语之前，先建立一张整体图。任何一套量化交易系统，无论复杂到什么程度，都可以拆成四个环节：

  1. 研究：从数据出发提出假设——某个指标、某个价差、某种市场状态，是否对未来收益具有稳定的预测力。
  2. 建模：把假设写成可计算的规则，包括信号的计算方式、持仓的建立与退出条件、仓位的分配比例。
  3. 回测：在历史数据上模拟策略的运行，检验其收益、风险与稳健性，判断收益是否来自真实的规律而非偶然。
  4. 执行：把模型输出的信号转化为实际订单，涉及下单方式、交易成本、滑点以及异常情况下的风控处置。

四个环节中，研究决定"有没有用"，建模与回测决定"是不是真的有用"，执行决定"能不能拿到手"。多数策略的失败并不发生在建模环节，而是发生在执行成本与研究假设的错配上。

量化核心术语 #

以下是与量化交易直接相关的基础概念，它们构成了一套描述策略的标准语言。理解这些术语，等于获得了评估任何一份策略说明书的能力。

策略（Strategy） #

量化交易的核心是交易策略，它定义了在何时、何地、以及以何种条件进行买卖的系统。策略可以基于技术指标，例如简单移动平均线（SMA）交叉策略，或使用统计模型，如回归分析。

一个完整的策略至少要说清三件事：入场条件（什么情况下建立头寸）、出场条件（什么情况下平仓，包含止盈与止损）、仓位规则（单笔投入多少资金）。缺少任何一项，策略都无法被独立复现，也就无法被验证。

此外，现代量化交易还越来越多地采用机器学习方法，如强化学习，来不断优化策略。例如，一个基于机器学习的策略可以通过分析历史价格数据，自动调整其买入和卖出的时机以最大化收益。但要注意，"自动优化"带来的风险是过拟合：模型可能学到的是历史噪声而不是市场规律。

因子（Factor） #

因子是用来衡量资产或市场特征的数值。在量化交易中，因子可以是任何与股价或交易量相关的变量，如价格、成交量、均线、公司市值、市盈率等。许多投资者会将这些因子组合起来进行多因子模型分析，优化其投资决策。例如，某投资者可能会同时考虑股价与市盈率（P/E Ratio）来评估某只股票的投资价值。

因子通常按来源分为几类：价值（估值指标）、成长（盈利增速）、质量（ROE、负债率）、动量（过去收益）、波动与流动性（波动率、换手率）、规模（市值）。因子的价值判断依赖两个性质——区分度（不同分组之间的收益差异是否显著）与稳定性（这种区分能力在多期、多市场上是否持续存在）。

信号（Signal） #

信号是基于交易策略和因子生成的指令，告诉投资者在何时进行买入或卖出。信号来自于对市场条件的定量分析。例如，当短期均线超过长期均线时，可能会生成买入信号，反之则产生卖出信号。

信号的设计要区分三个层次：原始信号（如均线交叉的布尔值）、强度（信号的幅度或可信度，可用于决定仓位大小）、过滤条件（如只在趋势明确或流动性充足时接受信号）。把三者混为一谈，往往是策略实盘表现弱于回测的原因之一。

模型（Model） #

量化交易使用数学模型来表示市场行为。这些模型的复杂程度可以相差很大，从简单的线性回归模型到复杂的深度学习算法都在应用之中。比如，深度学习模型可以用来分析社交媒体情绪对股价波动的影响，进而帮助交易者做出决策。

模型的作用不是"预测未来"，而是"以可检验的方式刻画变量之间的关系"。因此评估模型时，重点不在样本内的拟合程度，而在样本外是否还能保持方向与幅度上的准确性。

回测（Backtesting） #

回测是在历史市场数据上模拟和评估一个交易策略的过程。通过回测，投资者可以获取有关策略表现的重要信息，例如一年中的某个特定月份是否表现良好。

一个可信的回测需要处理好几类偏差：

  • 前视偏差：使用了当时还不可能获得的信息，例如用当日收盘价决定当日开盘的操作。
  • 幸存者偏差：只测试了当前仍然存活的标的，忽略了已退市或被并购的样本。
  • 复权处理：未正确复权会使得分红、拆股附近的收益计算失真。
  • 成本假设：忽略手续费、滑点与冲击成本，会系统性高估高频类策略的收益。

在进行回测时需谨防过度拟合（overfitting），这发生在模型在历史数据上表现极好但在真实交易中却表现差劲的情况。控制过拟合的常用手段包括：减少自由参数、做样本外检验、做参数敏感性分析，以及用滚动窗口验证。

收益与风险指标 #

量化策略的评价依赖一组标准指标，它们从不同角度刻画"这笔收益是如何赚来的"。

Alpha 是一个衡量策略相对于市场基准（通常是无风险收益率）的超额收益指标。正的 Alpha 意味着策略在风险调整后表现优于市场，比如一个策略的 Alpha 为 2%，意味着其收益高于基准的 2%。

Beta 指标表示一个投资组合相对于市场的敏感性，通常用于评估风险。Beta 值大于 1 表示该投资组合比市场更敏感，这意味着在市场上涨时，投资组合可能有更大的上涨幅度，而在市场下跌时也可能经历更大的损失。反之，Beta 值小于 1 表示相对不敏感。Beta 接近 0 的策略通常被称为市场中性。

夏普比率（Sharpe Ratio） 在量化金融中广泛用于衡量投资组合风险调整后收益，其定义为（策略收益率 - 无风险利率）/ 策略波动率。夏普比率越高，表明每单位风险带来的收益越大。例如，年收益率为 12%、波动率为 8% 的策略，若无风险利率为 2%，则夏普比率为 (12%-2%)/8% = 1.25，这表示投资者在承担风险时所获得的回报相对较高。

夏普比率有一个明显的局限：它把向上波动与向下波动同等视为风险。因此对于收益分布明显偏斜的策略，还需要参考索提诺比率、卡玛比率等指标。

最大回撤（Maximum Drawdown） 描述的是策略在历史上任何时期内可能损失的最大百分比，通常用于评估风险水平。比如，一个投资策略在某段时间内经历的最大回撤为 15%，这表明投资者在最糟糕的情况下可能会损失 15% 的资金。了解最大回撤可以帮助投资者制定合适的风险管理策略，也直接决定一个人能否在实盘中坚持执行该策略。

资金管理（Money Management） #

资金管理是一种通过控制投资组合风险和保护本金的方法，其中包括投资组合的分散投资、仓位控制等技巧。例如，某投资者可能决定将资金的 60% 投入蓝筹股，30% 投入债券，10% 保留为现金以保持流动性，这样的分配可以降低整体风险。

在量化策略中，资金管理通常体现为三条规则：单笔风险上限（单次交易最多亏损总资金的固定比例）、总杠杆上限（所有头寸风险敞口的合计限制）、相关性约束（避免同时在多个高度相关的标的上持有同向头寸）。它的作用是把单次判断失误的后果限制在可承受范围内，从而让策略能够长期存活。

金融基础术语 #

量化交易建立在传统金融的概念体系之上。以下术语虽然不是量化特有，但几乎所有策略说明都会用到。

股票（Stocks） #

股票是公司的所有权证券，代表对公司部分资产和利润的所有权。购买股票意味着成为股东，享有分红权和投票权。例如，投资者购买某科技公司的股票，即成为该公司的股东，有权分享未来的利润增长。

投资组合（Portfolio） #

投资组合是由多种不同资产（如股票、债券、期货等）构成的一揽子投资。通过构建投资组合，投资者能够分散风险，提高收益潜力。例如，一个由 40% 美国股票、30% 国际股票和 30% 债券组成的投资组合，可以降低单一市场波动对整体投资的影响。

组合的核心结论来自相关性：当资产之间的收益不完全正相关时，组合整体的波动会低于各资产波动的加权平均。这也是"分散化是唯一免费的午餐"这句话的含义。

风险管理（Risk Management） #

风险管理是一种识别、测量和控制投资中的潜在风险的方法。在量化金融中，使用统计学和数学模型来评估和管理投资组合的风险。例如，可以使用历史波动率、VaR（在险价值）等指标来衡量投资组合可能的损失。

需要注意的是，VaR 回答的是"在正常市场条件下，某一置信水平下的最大可能损失"，它对极端行情的刻画并不充分。因此实务上常配合压力测试与情景分析一起使用。

收益（Return） #

收益是投资的盈利，通常以百分比表示。投资者在追求最大化收益的同时，必须合理考虑潜在的风险。例如，某投资策略的年度收益为 15%，但如果相应的风险水平也较高，投资者需要权衡这种收益的吸引力与承受的风险。

收益的口径必须说明清楚：是简单收益率还是对数收益率、是否含分红、是否扣除费用、是时间加权还是资金加权。口径不同的两个数字放在一起比较，结论往往错误。

算法交易（Algorithmic Trading） #

算法交易是通过计算机程序执行的，由预定规则和数学模型引导的交易方法。这种方式能够实现高速和高效交易，例如在一秒钟内执行成千上万笔订单，以捕捉市场瞬息万变的机会。

算法交易还包括一类"执行算法"——目标不是产生信号，而是以尽可能低的冲击成本完成既定的大额订单，如按时间切片下单或按成交量比例下单。

量化模型（Quantitative Models） #

量化模型利用数学和统计学工具来分析和预测金融市场的行为。这些模型可能基于历史数据、技术分析或基本分析等多种方法。例如，通过建立一个基于时间序列分析的预测模型，投资者可以根据历史价格数据预测未来股价走势，从而做出买入或卖出的决策。

高频交易（High-Frequency Trading） #

高频交易指的是以极快的速度进行交易，通常依赖于复杂的计算机算法。这类交易能够在毫秒级别内执行，以捕捉市场微小的价格波动。高频交易机构利用市场流动性，试图在短时间内实现利润，例如机器人自动交易平台每天可能执行数十万笔交易。

高频交易的收益来源与低频策略有本质区别：它更多依赖延迟优势、订单簿微观结构与做市返佣，而不是对价格方向的预测，因此对基础设施的投入要求远高于对模型的要求。

套利（Arbitrage） #

套利是一种通过同时买入和卖出同一资产或相似资产来利用价格差异的交易策略。其核心目的在于法律允许的范围内，以无风险或低风险的手段获取利润。例如，若某商品在不同交易所的价格存在差异，交易者可先低价买入，再高价卖出，以实现套利收益。

严格意义上的无风险套利在成熟市场中极为罕见，常见的套利机会都带有某种残余风险：跨期套利承担展期风险，跨市场套利承担汇率与结算风险，统计套利承担模型误设风险。

蒙特卡洛模拟（Monte Carlo Simulation） #

蒙特卡洛模拟是一种用于模拟金融市场不确定性的数学技术。通过生成大量随机样本来评估投资组合的风险和收益，投资者可以看出在不同市场状况下可能的损失和赢利。这种方法在风险管理中尤为重要，能够帮助投资者量化潜在的风险。

它的基本流程是：为关键变量设定分布假设，重复抽样生成大量可能情景，对每个情景计算组合结果，最后统计结果的分布特征。其结论的可信度高度依赖分布假设是否合理，因此它更适合用来比较不同方案之间的相对优劣，而不是给出精确的绝对数值。

八类基本量化策略 #

量化交易依赖于数学模型、统计学原理和计算机算法，通过系统化的方法来识别和执行交易机会。以下八类策略是最常见的分类骨架，几乎所有的具体策略都可以归入其中某一类，或是若干类的组合。

1. 移动平均策略（趋势跟踪） #

策略思想：该策略基于股价的历史平均值，目的是通过计算短期和长期移动平均线之间的差异来产生买卖信号。例如，在短期均线上穿长期均线时，交易者可能会选择买入，预期股价将继续上涨。

实现方式：交易者计算短期（如 50 日移动平均）和长期（如 200 日移动平均）移动平均。当短期均线上穿长期均线时，根据这一交叉信号产生买入信号；反之，当短期均线下穿长期均线时，产生卖出信号。这种方法简单易用，并且在趋势明显的市场环境中表现良好。

主要弱点：在震荡行情中会反复触发假信号，产生连续的摩擦成本。策略的有效性因此在很大程度上取决于标的所处的市场状态。

2. 均值回归策略 #

策略思想：该策略基于价格的历史波动，认为价格在经历剧烈波动后，会逐渐回归其历史平均水平。例如，如果一家公司的股票价格因为市场情绪过度反应而短暂下跌，均值回归策略可能会在价格接近历史均值时产生买入信号。

实现方式：交易者通过计算当前价格与其历史均值之间的差异来识别信号。当价格偏离均值超过一定阈值时（例如标准差的两倍），就可以发出买入或卖出信号。这种策略在波动型市场中尤为有效。

主要风险：均值回归假设价格终将回头，但当基本面发生实质变化时，"偏离"可能就是新的均衡，此时逆势加仓会放大亏损。因此需要设置明确的止损与偏离上限。

3. 动量策略 #

策略思想：动量策略基于一个假设，即价格趋势往往会延续一段时间。交易者通常在价格上涨时买入，而在价格下跌时卖出。例如，如果某只股票在过去一个月内涨幅显著，动量策略可能促使交易者继续持有该股票，期待涨势持续。

实现方式：通过计算价格的变化率、相对强弱指数（RSI）或牛市/熊市信号，动量策略生成买入或卖出信号。这种策略在处于强趋势的市场中表现尤为突出。

动量与均值回归在逻辑上互为反面，它们各自在特定时间尺度上有效：短期的过度反应倾向回归，中期的趋势倾向延续。两者的边界是量化研究中的经典问题。

4. 市场中性策略 #

策略思想：市场中性策略试图通过同时进行买入和卖出，利用市场的相对强弱来获取利润。比如，交易者或许会选择买入一家公司的股票，同时卖空其同行业中的另一家公司，以减少整体市场风险。

实现方式：这种策略通常基于两个或多个相关资产之间的价差或相关性生成交易信号。如果某两个相关资产的价格关系发生显著变化，可能会触发交易。例如，若某一股票相对其竞争对手的价格出现偏差，交易者可以采取相应的多头或空头策略。

由于多头与空头的市场暴露相互抵消，组合的 Beta 接近 0，业绩主要取决于配对关系的稳定性以及对冲比例是否恰当。

5. 统计套利策略 #

策略思想：统计套利策略依托统计学原理，寻找资产之间的临时不平衡来实现套利。例如，假设某两只股票的历史价格走势十分相似，但短期内出现了价格差异，交易者可以通过买入低估股票和卖空高估股票来获取利润。

实现方式：交易者通过寻找价格、波动性或其他统计指标出现的异常值来发出交易信号。这种策略要求交易者具备稳定的模型和大量的数据支持，以供决策。

统计套利的前提是"关系稳定"。因此在建立信号之前，通常先检验价差序列的平稳性，并持续监控关系是否发生结构性断裂——一旦协整关系消失，策略的基础也就不存在了。

6. 事件驱动策略 #

策略思想：事件驱动策略旨在利用一些特定事件或新闻的发生来产生交易信号。例如，企业财报发布后，一些交易者可能会依据利好或利空信息迅速调整持仓。

实现方式：交易者需监控相关的新闻动态、公司财报、经济指标等。一旦预测的事件发生，如商业并购、行业变革等，便会立即执行交易。这样的策略适合那些愿意快速反应并对新闻敏感的交易者。

事件驱动策略的难点在于事件的定义与时间戳：信息何时公开、市场何时消化，直接决定了策略能捕捉的是超额收益还是已经消失的残值。

7. 机器学习策略 #

策略思想：这一策略运用机器学习算法，从海量数据中学习市场行为的模式，以预测未来价格的走势。

实现方式：交易者可以使用回归分析、分类算法或深度学习模型对市场行为进行训练。这些模型不仅能够分析历史数据，还能自动优化以适应不断变化的市场条件，提升预测的准确性。

应用机器学习时需要注意：金融数据信噪比极低、样本非独立同分布、且存在结构性变化，因此交叉验证必须按时间切分，特征工程必须严格避免未来信息渗入。

8. 高频交易策略 #

策略思想：高频交易策略通过快速执行大量交易，以利用微小价格差异进行盈利。例如，交易者在毫秒级别内执行交易，以捕捉瞬息万变的市场价格变化。

实现方式：这种策略通常涉及使用高效的算法和高性能计算系统，来支持交易者完成大量的短期交易。这要求极低的延迟和优越的市场进入策略，适合于从事流动性提供和市场制造的专业交易者。

这八类策略仅是量化交易领域中的一部分。实际上，量化交易策略的形成和实现多种多样，可以根据市场状况、资产类别和交易者的个人偏好进行灵活调整。设计有效的量化策略需要经过充分的历史数据回测，并考虑潜在的风险管理，以确保在不同市场环境下的有效性和可持续性。

常用技术指标的择时作用 #

除了按策略逻辑分类，实践中也常按信号来源分类。以下几类指标是择时信号的常见来源，它们既可以单独使用，也可以作为前述策略的触发器。指标的计算细节与理论依据属于技术分析范畴，本篇只说明它们在策略中的角色。

移动平均线 #

最常用的两条是 50 天均线 与 200 天均线。

50 天均线是过去 50 个交易日的平均价格，可以帮助判断一个资产的短期趋势。当价格在 50 天均线之上时，表明资产处于上升趋势；而当价格在 50 天均线之下时，则表明资产处于下降趋势。

200 天均线则用来观察资产的长期趋势。长期投资者通常会使用这个指标来判断一个资产的整体走势。如果价格在 200 天均线之上，这往往意味着资产处于长期上升趋势；反之则可能表明资产正处于长期下降趋势。

不同的交易者和投资者会根据自己的策略和风险承受能力来选择周期。短期交易者通常更关注短期趋势，因此会选择较短的均线，如 20 天均线；而长期投资者更关注资产的整体走势，因此会选择 50 天和 200 天均线。周期参数的选择本质上是在灵敏度与稳定性之间取一个平衡，这一点在均线类文章中会有更完整的讨论。

相对强弱指数（RSI） #

RSI 是一种动量指标，用于评估资产的超买或超卖状态。当 RSI 超过 70 时，资产可能被视为超买，反之，当 RSI 低于 30 时，资产可能被视为超卖。

在策略中，RSI 既可以直接作为均值回归的触发条件，也可以作为趋势策略的过滤条件——例如只在 RSI 未进入极端区域时才接受趋势信号。

布林带 #

布林带由三条线组成，分别是中间的移动平均线和上下两条标准差线。价格触及上轨可能意味着超买，而触及下轨则可能意味着超卖。

布林带的带宽本身也是信息：带宽收窄表示波动压缩、行情处于积蓄状态，随后往往伴随方向性突破；带宽扩张则表示波动释放。

MACD #

MACD（移动平均收敛发散指标）是一种趋势跟踪动量指标，通过两条移动平均线之间的关系来判断买入或卖出信号。

它的构造是把快慢两条指数移动平均线的离差再作一次平滑，因此同时具备趋势跟踪与动量确认的双重性质，常被用作趋势策略的二次确认条件。

支撑与阻力 #

支撑位是价格下跌时可能遇到的底部，而阻力位是价格上涨时可能遇到的顶部。交易者可以利用这些水平来制定进出场策略。

在量化实现中，支撑与阻力通常被转换为可计算的形式，如前期高低点、成交密集区、或整数关口，并用作止盈止损的参考位置。

趋势线 #

通过连接价格图表上的高点或低点，交易者可以识别出趋势的方向，并据此做出交易决策。

趋势线的主观性较强，不同人画出的线可能不同。若要用于系统化交易，必须给出明确的取点规则，否则无法回测，也无法复现。

术语使用中的常见混淆 #

同一套术语在不同语境下常被混用，导致策略说明出现歧义。下面几组是最容易出问题的。

Alpha 与超额收益 #

严格地说，Alpha 指经风险调整后的超额收益，而不是"收益减去指数收益"。只有当组合的 Beta 与基准一致时，两者才近似相等。若组合因承担了更高的 Beta 而跑赢基准，那部分收益属于风险暴露的补偿，不应计入 Alpha。

波动率与风险 #

波动率只是风险的一种度量，它假设收益对称分布。而在实际中，策略的亏损分布常有厚尾，极端行情下的损失远超波动率所提示的水平。因此用波动率衡量风险时，必须同时查看最大回撤与尾部指标。

回测收益与实盘收益 #

两者之间的差距通常来自三处：交易成本被低估、流动性约束被忽略、以及策略容量不足（自有资金能跑通，规模扩大后冲击成本迅速上升）。在评估一份回测结果时，先问这三项如何处理，比看收益曲线更有意义。

因子暴露与择时 #

因子暴露描述的是组合长期处于某种风格之中，择时描述的是对市场状态做短期判断。前者靠分散与组合构建来控制，后者靠信号来触发。把择时收益误认为因子收益，是归因分析中最常见的错误。

信号频率与交易频率 #

信号可以每天更新，但交易不必每天发生。区分两者可以显著降低成本：让信号负责判断方向，让交易规则（如阈值、最小持仓期）负责过滤噪声，是实践中提高净收益的常用手法。

从术语到策略：一条实践路径 #

把上述术语与策略组织起来，一个可执行的路径大致是：

  1. 先定义评价标准。在写任何规则之前，先确定用什么指标判断成败——通常需要同时看年化收益、最大回撤、夏普比率与换手率，单一指标容易把策略引向极端。
  2. 再确定策略属于哪一类。趋势、均值回归、中性、事件驱动，不同类别对市场状态、数据频率与执行成本的要求完全不同。
  3. 然后明确信号与仓位规则。信号回答"做不做"，仓位回答"做多少"，后者对最终风险的影响往往大于前者。
  4. 最后处理成本与偏差。把手续费、滑点、涨跌停与流动性约束纳入回测，并在样本外与小样本区间上复核结论。

这条路径的共同点是：所有环节都以可复现的量化口径表达。术语精确、分类清楚、口径统一，才是量化研究能够积累的前提——否则每一轮研究都要从重新定义概念开始。
