🤖 AI 摘要
OpenRouter
正在思考并提取文章核心…

静态博客没有独立后端，直接在前端 JavaScript 代码中调用大模型 API（如 OpenRouter、DeepSeek、OpenAI）会导致 API Key 完全暴露在客户端。任何访客打开开发者工具就能提取 Key 并消耗你的调用额度。

安全且低成本的解法是：通过 Cloudflare Workers 在边缘节点做 API Key 隔离与请求中转，同时挂载 Cloudflare KV 充当永久缓存。每篇文章首次访问时调用模型流式生成摘要并落盘至 KV，后续访问直接秒级返回缓存文本，避免重复计费。

1. 核心架构与请求流转 #

sequenceDiagram
    autonumber
    actor User as 访客浏览器
    participant CF as Cloudflare Worker (中转与鉴权)
    participant KV as Cloudflare KV (永久缓存)
    participant OR as OpenRouter (LLM 大模型)

    User->>CF: POST post_id + 正文文本
    CF->>KV: 检查 cacheKey 是否已存在摘要？
    alt KV 命中缓存
        KV-->>CF: 返回已缓存的摘要纯文本
        CF-->>User: 返回 JSON，前端直接完成展示
    else 未命中缓存（首次访问）
        CF->>OR: 携带环境变量中的私密 API_KEY 请求流式接口 (SSE)
        OR-->>CF: 流式 Chunk 数据返回
        CF-->>User: 边生成边推流给前端打字机展示
        CF->>KV: 流结束时，将拼装好的完整摘要写入 KV 永久保存
    end

架构考量 #

  • 密钥安全：OPENROUTER_API_KEY 存放在 Cloudflare Worker 加密环境变量中，前端仅能拿到公开的 Worker 域名。
  • 调用成本锁定：KV 充当防重写屏障。一篇文章无论后续产生多少次浏览，只要不主动清理 KV，模型调用成本严格为 1 次。
  • 额度配额：Cloudflare 免费计划提供每日 10 万次 Worker 请求、10 万次 KV 读取以及 1,000 次 KV 写入。对于个人博客的增量文章生成已足够充裕。

2. 后端部署：编写 Cloudflare Worker #

2.1 创建 KV 命名空间 #

  1. 登录 Cloudflare 控制台。
  2. 进入左侧 Workers & Pages -> KV。
  3. 点击 Create a namespace，命名为 AI_SUMMARY_KV。

2.2 创建 Worker 服务 #

  1. 进入 Workers & Pages -> Overview，点击 Create Application -> Create Worker。
  2. 命名为 hexo-ai-summary，点击 Deploy。
  3. 进入 Edit code，将默认代码替换为以下逻辑：
javascript
// Cloudflare Worker: hexo-ai-summary.js

const SYSTEM_PROMPT = `你是一个专业的技术博客助手。请阅读用户提供的博文内容，生成一段 100~180 字以内的精炼文章摘要。
要求：
1. 语言通顺精炼，概括核心技术点与解决的问题。
2. 直接输出摘要纯文本，绝不包含任何诸如“本文介绍了”、“摘要：”等多余的前缀或废话。`;

export default {
  async fetch(request, env) {
    // 1. 处理 CORS 跨域预检请求
    if (request.method === "OPTIONS") {
      return new Response(null, {
        headers: {
          "Access-Control-Allow-Origin": "*",
          "Access-Control-Allow-Methods": "POST, OPTIONS",
          "Access-Control-Allow-Headers": "Content-Type",
        },
      });
    }

    if (request.method !== "POST") {
      return new Response("Only POST method allowed", { status: 405 });
    }

    try {
      const { id, content } = await request.json();
      if (!id || !content) {
        return new Response(JSON.stringify({ error: "Missing id or content" }), { 
          status: 400,
          headers: { "Content-Type": "application/json" }
        });
      }

      // 2. 查询 KV 缓存，命中则直接返回 JSON 避免触发大模型调用
      const cacheKey = `summary:${id}`;
      const cached = await env.AI_SUMMARY_KV.get(cacheKey);
      if (cached) {
        return new Response(JSON.stringify({ summary: cached, cached: true }), {
          headers: {
            "Content-Type": "application/json",
            "Access-Control-Allow-Origin": "*",
          },
        });
      }

      // 3. 没命中缓存，请求 OpenRouter 流式接口
      const model = env.MODEL_NAME || "deepseek/deepseek-chat";
      const openRouterResp = await fetch("https://openrouter.ai/api/v1/chat/completions", {
        method: "POST",
        headers: {
          "Authorization": `Bearer ${env.OPENROUTER_API_KEY}`,
          "Content-Type": "application/json",
          "HTTP-Referer": "https://hexo.io",
          "X-Title": "Hexo AI Summary",
        },
        body: JSON.stringify({
          model: model,
          stream: true,
          messages: [
            { role: "system", content: SYSTEM_PROMPT },
            // 截取前 2500 字足以提炼主旨，同时避免超长文章打爆上下文配额
            { role: "user", content: content.slice(0, 2500) }
          ],
        }),
      });

      if (!openRouterResp.ok) {
        const errText = await openRouterResp.text();
        return new Response(JSON.stringify({ error: "OpenRouter Error", detail: errText }), {
          status: 500,
          headers: { "Access-Control-Allow-Origin": "*", "Content-Type": "application/json" }
        });
      }

      // 4. 双向流处理：实时透传 SSE 给前端，并在后台收集文本写入 KV
      let fullText = "";
      const { readable, writable } = new TransformStream();
      const writer = writable.getWriter();
      const reader = openRouterResp.body.getReader();
      const decoder = new TextDecoder();

      (async () => {
        try {
          while (true) {
            const { done, value } = await reader.read();
            if (done) break;
            const chunk = decoder.decode(value, { stream: true });
            
            // 解析标准 SSE 数据格式以提取累积文本
            const lines = chunk.split("\n");
            for (const line of lines) {
              if (line.startsWith("data: ") && line.trim() !== "data: [DONE]") {
                try {
                  const json = JSON.parse(line.slice(6));
                  const text = json.choices?.[0]?.delta?.content || "";
                  fullText += text;
                } catch (e) {}
              }
            }
            // 实时将字节流转发给客户端
            await writer.write(value);
          }
        } finally {
          await writer.close();
          // 推流结束后，将聚合好的完整文本写入 KV 永久保存
          if (fullText.trim().length > 0) {
            await env.AI_SUMMARY_KV.put(cacheKey, fullText.trim());
          }
        }
      })();

      return new Response(readable, {
        headers: {
          "Content-Type": "text/event-stream",
          "Cache-Control": "no-cache",
          "Connection": "keep-alive",
          "Access-Control-Allow-Origin": "*",
        },
      });

    } catch (e) {
      return new Response(JSON.stringify({ error: e.message }), {
        status: 500,
        headers: { "Access-Control-Allow-Origin": "*", "Content-Type": "application/json" }
      });
    }
  },
};

2.3 绑定环境变量与 KV 命名空间 #

进入该 Worker 的 Settings 页面：

  1. Variables（环境变量）：
    • 添加 OPENROUTER_API_KEY：填入在 OpenRouter 申请的 API Key，勾选 Encrypt 加密。
    • 添加 MODEL_NAME：填入模型代号，如 deepseek/deepseek-chat 或 google/gemini-2.0-flash-001。
  2. KV Namespace Bindings：
    • Variable name 填：AI_SUMMARY_KV。
    • KV namespace 选择刚刚创建的 AI_SUMMARY_KV。
  3. 点击 Save and Deploy，记录下分配的域名（例如 https://hexo-ai-summary.yourname.workers.dev）。

3. 前端挂载：Hexo 文章页接入 #

3.1 前端脚本 #

在博客根目录创建 source/js/ai_summary.js：

javascript
// source/js/ai_summary.js
document.addEventListener('DOMContentLoaded', () => {
  const postArticle = document.querySelector('article.content') || document.querySelector('.post-content') || document.querySelector('#article-container');
  if (!postArticle) return;

  // 1. 替换为你自己的 Worker 访问域名
  const WORKER_URL = 'https://hexo-ai-summary.yourname.workers.dev';

  // 2. 以路径作为文章唯一标识
  const postId = location.pathname;
  const rawText = postArticle.innerText.replace(/\s+/g, ' ').trim();
  if (rawText.length < 80) return; // 短文不触发摘要

  // 3. 在文章正文顶部动态插入摘要卡片
  const aiBox = document.createElement('div');
  aiBox.className = 'custom-ai-box';
  aiBox.innerHTML = `
    <div class="ai-header">
      <div class="ai-title">AI 摘要</div>
      <div class="ai-tag">OpenRouter</div>
    </div>
    <div class="ai-content" id="ai-summary-text">
      <span class="ai-loading">正在提炼文章核心内容...</span>
    </div>
  `;
  postArticle.parentNode.insertBefore(aiBox, postArticle);

  const textEl = document.getElementById('ai-summary-text');

  // 4. 发起请求
  fetch(WORKER_URL, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ id: postId, content: rawText })
  }).then(async (response) => {
    const contentType = response.headers.get('content-type') || '';
    
    // 命中了 KV 缓存直接返回 JSON
    if (contentType.includes('application/json')) {
      const data = await response.json();
      textEl.innerText = data.summary || '暂无摘要内容。';
      return;
    }

    // 未命中则消费 SSE 流式数据展示打字机效果
    textEl.innerText = '';
    const reader = response.body.getReader();
    const decoder = new TextDecoder();
    
    while (true) {
      const { done, value } = await reader.read();
      if (done) break;
      const chunk = decoder.decode(value, { stream: true });
      const lines = chunk.split('\n');
      for (const line of lines) {
        if (line.startsWith('data: ') && line.trim() !== 'data: [DONE]') {
          try {
            const json = JSON.parse(line.slice(6));
            const char = json.choices?.[0]?.delta?.content || '';
            textEl.innerText += char;
          } catch (e) {}
        }
      }
    }
  }).catch((err) => {
    console.error('AI Summary Error:', err);
    textEl.innerText = 'AI 摘要服务暂时不可用。';
  });
});

4. 边界条件与限制 #

  • 网络连通性：Cloudflare 默认的 *.workers.dev 域名在部分国内网络环境下可能受到 DNS 污染或阻断。如果需要保障国内访客稳定性，需在 Cloudflare 控制台添加自定义域名并绑定该 Worker。
  • KV 写入配额：免费计划每天支持 1,000 次写入操作。初次上线大量文章时如果一次性批量触发，可能会在当日耗尽写入配额，可通过分批访问或预热解决。
  • 摘要更新：当文章正文发生重大修改时，KV 中旧的 summary:${postId} 仍会生效。如需刷新，进入 Cloudflare KV 控制台找到对应 key 删掉即可重新生成。
