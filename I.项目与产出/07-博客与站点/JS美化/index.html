静态博客搭建完成后，默认样式通常较素。可以通过注入自定义 CSS 变量、引入 WebFont 字体、配置代码块样式以及挂载交互组件来调整阅读体验。本文整理基于 Hexo 主题（以 Stellar 为例）的前端样式与常用挂件配置，并说明动态特效带来的性能取舍。

1. 主题无损定制原则 #

修改主题样式时，不要直接编辑 themes/ 下的原生模板和样式文件，否则后续拉取主题更新会直接产生 Git 冲突或覆盖改动。

推荐的两种外部无损注入方式：

  1. 外部配置文件覆盖：在根目录下维护 _config.theme.stellar.yml，构建时复制到主题目录生效。
  2. 全局 inject 钩子注入：在站点 _config.yml 中利用 inject.head 与 inject.bottom 挂载自定义样式与外部脚本：
yaml
# _config.yml 注入自定义样式与脚本
inject:
  head:
    - '<link rel="stylesheet" href="/css/custom.css">'
  bottom:
    - '<script src="/js/custom.js"></script>'

所有新写的样式保存在 source/css/custom.css，所有自定义 JS 保存在 source/js/custom.js。

2. 中文字体配置：引入霞鹜文楷 #

霞鹜文楷（LXGW WenKai）适合作为技术博客与长文的主体排版字体。通过 CDN 引入 WebFont 并配合 font-display: swap，避免字体未加载完成时文字白屏（FOIT）。

2.1 引入 WebFont 样式表 #

在 _config.yml 的 inject.head 挂载 CDN：

yaml
inject:
  head:
    - '<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/satouriko/LxgwWenKai_Webfonts@v1.101/dist/LXGWWenKaiMono-Bold.css" />'

2.2 在主题中配置字体族 #

在主题配置（如 themes/stellar/_config.yml）中将字体名加入对应属性：

yaml
style:
  font-family:
    logo: 'LXGWWenKaiMono, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif'
    body: 'LXGWWenKaiMono, "PingFang SC", "Microsoft YaHei", sans-serif'
    code: 'LXGWWenKaiMono, "Fira Code", Consolas, Monaco, monospace'
    codeblock: 'LXGWWenKaiMono, "Fira Code", Consolas, Monaco, monospace'

3. 深色模式（Dark Mode）与 CSS 变量 #

通过 CSS 自定义属性配合 @media (prefers-color-scheme: dark)，让页面能自动跟随访客操作系统的亮色/暗色设置：

css
/* source/css/custom.css */

/* 亮色模式默认变量 */
:root {
  --bg-primary: #f8fafc;
  --bg-card: rgba(255, 255, 255, 0.85);
  --text-main: #1e293b;
  --text-muted: #64748b;
  --border-color: #e2e8f0;
  --accent-color: #0284c7;
}

/* 跟随系统暗色偏好 */
@media (prefers-color-scheme: dark) {
  :root {
    --bg-primary: #0f172a;
    --bg-card: rgba(30, 41, 59, 0.85);
    --text-main: #f1f5f9;
    --text-muted: #94a3b8;
    --border-color: #334155;
    --accent-color: #38bdf8;
  }
}

/* 主题手动切换开关类名 */
body.dark-theme {
  --bg-primary: #0f172a;
  --bg-card: rgba(30, 41, 59, 0.85);
  --text-main: #f1f5f9;
  --text-muted: #94a3b8;
  --border-color: #334155;
  --accent-color: #38bdf8;
}

5. 核心阅读体验挂件 #

5.1 顶部阅读进度指示条 #

在长文滚动时，页面最上方展示横向延展的进度条。

在 inject.bottom 中添加：

html
<div id="reading-progress-bar" style="position: fixed; top: 0; left: 0; height: 3px; background: linear-gradient(to right, #38bdf8, #818cf8); z-index: 9999; transition: width 0.1s ease;"></div>

<script>
window.addEventListener('scroll', function() {
  const winScroll = document.documentElement.scrollTop || document.body.scrollTop;
  const height = document.documentElement.scrollHeight - document.documentElement.clientHeight;
  const scrolled = (winScroll / height) * 100;
  document.getElementById('reading-progress-bar').style.width = scrolled + '%';
});
</script>

5.2 图片灯箱画廊（Fancybox） #

文章中的高清图片需要点击放大查看。通过自动遍历正文图片并包裹 Fancybox 标签实现：

在 inject.head 与 inject.bottom 引入 Fancybox 库与初始化脚本：

html
<!-- inject.head -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@fancyapps/ui@5.0/dist/fancybox/fancybox.css" />

<!-- inject.bottom -->
<script src="https://cdn.jsdelivr.net/npm/@fancyapps/ui@5.0/dist/fancybox/fancybox.umd.js"></script>
<script>
document.addEventListener("DOMContentLoaded", function() {
  document.querySelectorAll(".post-content img, .article-entry img").forEach(function(img) {
    const parent = img.parentElement;
    if (parent.tagName !== "A") {
      const a = document.createElement("a");
      a.href = img.src;
      a.setAttribute("data-fancybox", "gallery");
      a.setAttribute("data-caption", img.alt || "");
      parent.insertBefore(a, img);
      a.appendChild(img);
    }
  });
  Fancybox.bind("[data-fancybox='gallery']", {});
});
</script>

6. 媒体与交互组件 #

6.1 APlayer + MetingJS 悬浮音乐播放器 #

在 inject.bottom 挂载吸底播放器，通过 MetingJS 解析网易云歌单 ID：

html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/aplayer/dist/APlayer.min.css">
<script src="https://cdn.jsdelivr.net/npm/aplayer/dist/APlayer.min.js"></script>
<script src="https://cdn.jsdelivr.net/npm/meting@2/dist/Meting.min.js"></script>

<meting-js
  server="netease"
  type="playlist"
  id="512983678"
  fixed="true"
  mini="true"
  autoplay="false"
  theme="#38bdf8"
  order="random">
</meting-js>
ℹ笔记

国内网易云等平台的 API 经常调整外链策略，部分版权限制歌曲可能无法播放，需定期检查歌单有效性。

7. 站点访问统计集成 #

7.1 百度统计 #

  1. 登录百度统计平台获取站点专属的 hm.js 脚本 Key。
  2. 在主题配置文件注入：
yaml
baiduanalytics:
  enable: true
  inject: |
    <script>
    var _hmt = _hmt || [];
    (function() {
      var hm = document.createElement("script");
      hm.src = "https://hm.baidu.com/hm.js?你的百度统计Key";
      var s = document.getElementsByTagName("script")[0]; 
      s.parentNode.insertBefore(hm, s);
    })();
    </script>

7.2 不蒜子（Busuanzi）访客量统计 #

主题自带支持时直接在 _config.theme.yml 中开启：

yaml
busuanzi:
  enable: true
  site_uv: true    # 访客数
  site_pv: true    # 访问量
  page_pv: true    # 单页阅读数

8. 动效挂件与性能代价 #

部分常见特效虽然视觉丰富，但存在明显的性能代价，按需开启：

挂件名称 引入方式 性能与资源代价
Canvas Nest 粒子连线 <script color="0,200,255" count="80" src="...canvas-nest.js"></script> 每帧都在重绘 Canvas 连线，移动端和低配笔电会有发热和卡顿风险。粒子数（count）建议压在 60 以下。
鼠标点击烟花粒子 <script src="...fireworks.js"></script> 每次点击创建数十个 DOM 节点或 Canvas 粒子，连续点击时会产生明显的掉帧。
Live2D 看板娘 <script src="...autoload.js"></script> 需要加载数十 MB 的模型静态纹理和 WebGL 渲染管线，直接拖慢首屏加载时间。

如果博客重点在于长文技术阅读，建议优先保留排版、代码高亮、暗黑模式与灯箱，尽量减少高帧率持续运行的背景 Canvas 动效。
