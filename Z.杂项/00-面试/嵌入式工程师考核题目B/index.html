嵌入式软件工程师考核题目 (B) #

一、 题目说明 #

本考核题目旨在考察嵌入式 C 语言底层数据结构、指针操作、内存管理、动态链接库封装及跨语言架构设计能力。

二、 核心考核题目 #

1. 通用数据容器设计 #

试用 C 语言实现一个容器，可以装字符串、字符、数字、二进制数据，其中每一个被装进的数据要附带一个唯一识别码（UID）。

c
int put_char(List *list, unsigned int uid, char c);
int put_string(List *list, unsigned int uid, char *str);
int put_integer(List *list, unsigned int uid, int num);
int put_binary(List *list, unsigned int uid, unsigned char *data, unsigned int data_len);

说明：主要考核 C 语言结构体和链表指针方面的基础知识，请不要用 C++ 的 std::map、std::vector 等已经做好的容器库来实现。

2. 容器管理与遍历接口 #

实现能遍历容器内节点数、根据 UID 删除指定节点、打印节点及清空容器的相关接口：

c
unsigned int getNodeNum(List *list);
int delete_node(List *list, unsigned int uid);
int print_node(List *list, unsigned int uid);
void delete_all_nodes(List *list);

3. 动态链接库封装与测试 #

考虑如何将上述函数编译成一个 DLL（动态链接库），另外用一个控制台程序来访问这个 DLL 中的函数，并编写相应的测试代码来验证各接口的正确性与健壮性。

4. 架构设计与重构思考 #

试考虑从设计模式的观点出发对上述代码进行重构：

  1. 如何做到代码和数据的完全隔离？
  2. DLL 标准 C 接口，如何实现跨语言调用？（例如如何用 C#、Delphi 等上层语言调用您编写的该 DLL？）

三、 技术要点总结 #

  1. 回调函数（Callback Function）：在嵌入式与系统级编程中是一种常用技术，涉及到函数指针、函数类型，用法灵活，是必须掌握的核心技巧。
  2. 动态库技术（DLL / SO）：Windows 下的 DLL 与 Linux 下的 .so 共享库是模块化工程的基础。
  3. 跨语言互操作：遵循标准 cdecl / stdcall 调用约定以及避免内存跨模块释放，是当前工程架构中必须掌握的技巧。
