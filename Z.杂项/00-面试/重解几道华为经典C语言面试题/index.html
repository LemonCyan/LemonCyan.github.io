1. 找错题（字符串与数组越界） #

题目 1.1 #

c
void test1()
{
    char string[10];
    char* str1 = "0123456789";
    strcpy(string, str1);
}
  • 问题分析：string 数组越界。字符串 "0123456789" 长度为 10，但末尾还有一个字符串结束符 '\0'，因此实际占用 11 字节空间。string 数组大小仅为 10，导致越界写入。
  • 总结：使用 strcpy 时，目标缓冲区的空间必须严格大于源字符串的长度（含 \0），否则将发生缓冲区溢出。

题目 1.2 #

c
void test2()
{
    char string[10], str1[10];
    int i;
    for (i = 0; i < 10; i++)
    {
        str1[i] = 'a';
    }
    strcpy(string, str1);
}
  • 问题分析：
    1. 循环给 str1 的 10 个元素全部赋值为 'a'，没有写入结束符 '\0'。
    2. strcpy 函数依赖第二个参数中的 '\0' 来判断拷贝结束。由于 str1 没有字符串结束标志，strcpy 会继续向后读取非法内存直到偶遇 '\0'，导致越界读取和越界拷贝。
  • 修复方法：在 for 循环后添加 str1[9] = '\0';，或者为 str1 分配至少 11 字节并将最后一位设为 '\0'。

题目 1.3 #

c
void test3(char* str1)
{
    char string[10];
    if (strlen(str1) <= 10)
    {
        strcpy(string, str1);
    }
}
  • 问题分析：判断条件仍存在越界风险。strlen 返回的是字符串不包含 '\0' 的有效字符个数。若 strlen(str1) == 10，拷贝时加上 '\0' 总共需要 11 个字节，而 string 只有 10 字节，因此依然会溢出。
  • 修复方法：判断条件应改为 if (strlen(str1) < 10)。

2. 找错题（静态变量与逻辑自增） #

c
DSN get_SRM_no()
{
    static int SRM_no;
    int I;
    for (I = 0; I < MAX_SRM; I++)
    {
        SRM_no %= MAX_SRM;
        if (MY_SRM.state == IDLE)
        {
            break;
        }
    }
    if (I >= MAX_SRM)
        return (NULL_SRM);
    else
        return SRM_no;
}
  • 功能意图：该函数用于从上一次分配的位置之后循环查找并分配一个空闲的 SRAM 块。如果找到空闲块（IDLE），则返回当前块号 SRM_no；若遍历所有块后均无空闲，则返回无可用资源的标志 NULL_SRM。
  • 问题分析：在 for 循环内部，没有对 SRM_no 执行递增累加操作（例如缺少 SRM_no++）。若首次检测未命中，后续循环每次检测的依然是同一个静态块号，导致死循环或无法正确轮询。

3. 看代码写出运行结果（auto 与 static） #

c
#include <stdio.h>

int sum(int a)
{
    auto int c = 0;
    static int b = 3;
    c += 1;
    b += 2;
    return (a + b + c);
}

void main()
{
    int I;
    int a = 2;
    for (I = 0; I < 5; I++)
    {
        printf("%d, ", sum(a));
    }
}
  • 运行结果：8, 10, 12, 14, 16,
  • 原理解析：
    • c 是 auto 局部变量，每次进入函数时都会被重新初始化为 0，随后 c += 1 始终为 1。
    • b 是 static 静态局部变量，只初始化一次，后续每次调用都保留上一次的值并累加 2。
    • 每次调用时：
      • 第 1 次：b = 5, c = 1, sum = 2 + 5 + 1 = 8
      • 第 2 次：b = 7, c = 1, sum = 2 + 7 + 1 = 10
      • 第 3 次：b = 9, c = 1, sum = 2 + 9 + 1 = 12
      • 第 4 次：b = 11, c = 1, sum = 2 + 11 + 1 = 14
      • 第 5 次：b = 13, c = 1, sum = 2 + 13 + 1 = 16

4. switch-case 穿透与赋值陷阱 #

c
int func(int a)
{
    int b;
    switch (a)
    {
        case 1: b = 30;
        case 2: b = 20;
        case 3: b = 16;
        default: b = 0;
    }
    return b;
}
  • 问：func(1) 的返回值是多少？
  • 答案：0
  • 原因分析：每个 case 分支后均未写 break; 语句。当传入参数为 1 时，程序匹配到 case 1 将 b 赋值为 30，但随后一直顺序穿透执行 case 2、case 3 以及 default，最终 b 被覆盖赋值为 0。

5. 指针相减运算 #

c
int a[3];
a[0] = 0; a[1] = 1; a[2] = 2;
int *p, *q;
p = a;
q = &a[2];
  • 问：a[q - p] 的值是多少？
  • 答案：2
  • 原因分析：同类型指针相减表示两个指针之间相隔的元素个数。q 指向 a[2]，p 指向 a[0]，因此 q - p = 2。代入数组索引 a[2]，结果为 2。

6. 二维多级指针数组占用内存空间 #

  • 定义：int **a[3][4];
  • 内存占用：
    • 在 16 位系统中：指针大小为 2 字节，总空间为 3 * 4 * 2 = 24 字节。
    • 在 32 位系统中：指针大小为 4 字节，总空间为 3 * 4 * 4 = 48 字节。
    • 在 64 位系统中：指针大小为 8 字节，总空间为 3 * 4 * 8 = 96 字节。
  • 本质：a 是一个 3×4 的二维数组，每个元素都是一个二级指针 int**。

7. 编程题：计算年月日时分秒的下一秒 #

题目要求：编写一个函数，输入年月日时分秒，输出该时刻的下一秒。例如输入 2004年12月31日23时59分59秒，输出 2005年1月1日0时0分0秒。

c
#include <stdio.h>

void ResetTheTime(int *year, int *month, int *date, int *hour, int *minute, int *second)
{
    int dayOfMonth[12] = {31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};

    // 参数合法性校验
    if (*year < 0 || *month < 1 || *month > 12 ||
        *date < 1 || *date > 31 || *hour < 0 || *hour > 23 ||
        *minute < 0 || *minute > 59 || *second < 0 || *second > 59)
    {
        return;
    }

    // 闰年判断（2月变为29天）
    if ((*year % 400 == 0) || (*year % 100 != 0 && *year % 4 == 0))
    {
        dayOfMonth[1] = 29;
    }

    // 秒递增
    *second += 1;
    if (*second >= 60)
    {
        *second = 0;
        *minute += 1;
        if (*minute >= 60)
        {
            *minute = 0;
            *hour += 1;
            if (*hour >= 24)
            {
                *hour = 0;
                *date += 1;
                if (*date > dayOfMonth[*month - 1])
                {
                    *date = 1;
                    *month += 1;
                    if (*month > 12)
                    {
                        *month = 1;
                        *year += 1;
                    }
                }
            }
        }
    }
}
