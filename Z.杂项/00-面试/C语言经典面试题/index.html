C 语言经典面试题（嵌入式工程师必备 16 题） #

1. 预处理指令 #define 常数声明 #

题目：用预处理指令 #define 声明一个常数，用以表明 1 年中有多少秒（忽略闰年问题）。

c
#define SECONDS_PER_YEAR (60 * 60 * 24 * 365)UL

考察要点：

  • #define 语法的基本规范（不带分号，宏体用括号保护）。
  • 懂得预处理器在编译期执行常量折叠，写出算式比写出硬编码数字更具自解释性。
  • 溢出意识：该值超出 16 位整型取值范围，必须加 L 或 UL 指定为无符号长整型。

2. 标准宏定义 MIN #

题目：写一个“标准”宏 MIN，输入两个参数并返回较小的一个。

c
#define MIN(A, B) ((A) <= (B) ? (A) : (B))

考察要点：

  • 宏参数与外层表达式严格用括号括起。
  • 明确宏展开带来的副作用（如 MIN(*p++, b) 会导致指针多次自增）。

3. 预处理器指令 #error #

题目：预处理器标识 #error 的目的是什么？

解答： 用于在预编译阶段强制中断编译过程，并在控制台输出用户指定的自定义错误提示。常用于平台特性检测、版本依赖检查或编译宏配置校验。

4. 无限循环编写 #

题目：在嵌入式系统中如何用 C 编写死循环？

常见方案：

c
// 方案 1: 最常用
while (1) {
    /* loop body */
}

// 方案 2: 经典惯用法
for (;;) {
    /* loop body */
}

// 方案 3: 标签跳转
Loop:
    /* loop body */
    goto Loop;

5. 复杂数据类型声明 #

题目：用变量 a 给出下面的定义：

  • int a; // 一个整型数
  • int *a; // 一个指向整型数的指针
  • int **a; // 一个指向指针的指针，指向整型数
  • int a[10]; // 一个有 10 个整型数的数组
  • int *a[10]; // 一个有 10 个指针的数组，指针指向整型数
  • int (*a)[10]; // 一个指向有 10 个整型数数组的指针
  • int (*a)(int); // 一个指向函数的指针，参数为 int，返回值为 int
  • int (*a[10])(int); // 一个包含 10 个函数指针的数组

6. static 关键字的作用 #

  1. 修饰局部变量：改变存储期（从栈区变为静态存储区），变量生命周期持续到程序结束，并在多次调用间维持状态。
  2. 修饰全局变量：限制作用域为当前源文件，避免全局命名污染。
  3. 修饰函数：限制函数为内部函数，仅在当前模块内可见。

7. const 关键字深入 #

c
const int a;             // a 是一个常整型数
int const a;             // 等价于 const int a
const int *a;           // a 是一个指向常整型数的指针（指向内容只读，指针可变）
int * const a;           // a 是一个指向整型数的常指针（指针只读，指向内容可变）
int const * const a;     // a 是一个指向常整型数的常指针（指针及指向内容均只读）

8. volatile 关键字及其应用场景 #

含义：告知编译器该变量随时可能在外部发生改变，每次访问必须直接从内存地址中读取，禁止从 CPU 寄存器缓存优化。

三个典型场景：

  1. 并行外设硬件寄存器（如状态寄存器读取）。
  2. 中断服务子程序（ISR）修改的全局变量。
  3. 多任务并发操作系统中各任务共享的信号量或标志位。

9. 位操作技巧 #

题目：给定整型变量 a，分别设置与清除 a 的 bit 3，保持其余位不变。

c
#define BIT3 (0x1 << 3)

static int a;

void set_bit3(void) {
    a |= BIT3;
}

void clear_bit3(void) {
    a &= ~BIT3;
}

10. 绝对物理内存地址访问 #

题目：在工程中设置绝对地址为 0x67a9 的整型变量的值为 0xaa66。

c
int *ptr;
ptr = (int *)0x67a9;
*ptr = 0xaa66;

// 或者直接强转写入：
*(volatile int * const)0x67a9 = 0xaa66;

11. 中断服务例程（ISR）规范与禁忌 #

c
__interrupt double compute_area(double radius)
{
    double area = PI * radius * radius;
    printf(" Area = %f", area);
    return area;
}

问题剖析：

  1. ISR 不能有返回值。
  2. ISR 不能传入参数。
  3. 很多架构下浮点运算不可重入且开销大。
  4. printf() 具有不可重入与 I/O 阻塞问题，严禁在中断中调用。

12. 整数隐式转换陷阱 #

c
void foo(void)
{
    unsigned int a = 6;
    int b = -20;
    (a + b > 6) ? puts("> 6") : puts("<= 6");
}
  • 输出结果：> 6
  • 原因：有符号数 b 自动提升为无符号数，-20 变为巨大的正整数，相加后仍远大于 6。

13. 处理器字长与位取反 #

c
unsigned int zero = 0;
unsigned int compzero = 0xFFFF; // 仅对 16 位系统有效
  • 改进：
c
unsigned int compzero = ~0; // 跨平台全字长自适应取反

14. 动态内存分配与堆安全 #

  • 潜在问题：内存碎片、内存泄漏、运行时间不确定性（破坏实时性）。
  • 思考题：
    c
    char *ptr;
if ((ptr = (char *)malloc(0)) == NULL)
    puts("Got a null pointer");
else
    puts("Got a valid pointer");
    在多数现代 C 运行时中将输出 "Got a valid pointer"。

15. typedef 与 #define 声明指针对比 #

c
#define dPS struct s *
typedef struct s * tPS;

dPS p1, p2; // 展开后: struct s * p1, p2; (p1 是指针, p2 是普通结构体变量)
tPS p3, p4; // p3, p4 均为结构体指针

16. C 语法贪婪匹配 #

c
int a = 5, b = 7, c;
c = a+++b;
  • 编译器按最长合法词法单元匹配，解析为：c = (a++) + b;
  • 运算后：a = 6, b = 7, c = 12。
