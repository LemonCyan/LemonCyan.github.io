C/C++ 经典面试题（持续更新） #

(原载：知秋一叶 - CSDN博客)

面试题 1：变量的声明和定义有什么区别？ #

  • 定义：为变量分配地址和存储空间的操作称为定义。一个变量只能在一个地方定义。
  • 声明：不分配内存地址的操作称为声明。一个变量可以在多个地方声明。使用 extern 修饰的是变量的声明，说明该变量定义在文件外部或文件的后面部分。
  • 说明：很多时候一个变量只是声明，不分配内存空间，直到具体使用时才初始化并分配内存空间（如外部变量）。

面试题 2：sizeof 和 strlen 的区别 #

  1. sizeof 是一个编译期操作符，而 strlen 是一个C 标准库函数。
  2. sizeof 的参数可以是数据类型，也可以是变量名或表达式；而 strlen 的参数只能是以 '\0' 结尾的字符串指针（char *）。
  3. 编译器在编译期即计算出 sizeof 的结果；而 strlen 必须在程序运行时遍历字符串直到遇到 '\0' 才能计算出长度。
  4. sizeof 计算的是数据类型或变量在内存中所占的物理字节大小；strlen 计算的是字符串实际的字符个数（不包含末尾的 '\0'）。
  5. 数组名作为 sizeof 的参数时不会退化；但作为参数传递给函数或赋给指针时，数组名会退化为首元素指针，此时传递给 strlen 仅计算指针指向的有效字符长度。

面试题 3：写一个“标准”宏 MIN #

c
#define MIN(a, b) ((a) <= (b) ? (a) : (b))

面试题 4：一个指针可以是 volatile 吗？ #

可以。因为指针本身是一个变量，保存的是内存地址。如果指针变量本身的值可能在中断服务子程序或另一个线程中被修改，那么就必须将该指针声明为 volatile。

例如：

c
int * volatile ptr; // ptr 是一个 volatile 指针，指向 int

面试题 5：a 和 &a 有什么区别？ #

写出以下代码的打印结果：

c
#include <stdio.h>

void main(void)
{
    int a[5] = {1, 2, 3, 4, 5};
    int *ptr = (int *)(&a + 1);
    printf("%d, %d\n", *(a + 1), *(ptr - 1));
    return;
}
  • 输出结果：2, 5
  • 原因分析：
    • a 是数组名，在多数表达式中退化为首元素地址，类型为 int *。因此 a + 1 指向数组的第二个元素 a[1]，*(a + 1) 值为 2。
    • &a 取的是整个数组的地址，类型为 int (*)[5]。因此 &a + 1 会跨过整个数组的内存空间（跨过 5 个 int，即 20 个字节），指向数组末尾之后紧随的地址。
    • ptr 被强制转换为 int * 并指向数组末尾后一个位置，因此 ptr - 1 指向数组最后一个元素 a[4]，*(ptr - 1) 值为 5。

面试题 6：简述 C/C++ 程序编译的内存分配情况 #

C/C++ 中内存分配方式分为三种：

  1. 从静态存储区域分配：内存在程序编译链接时就已分配好，在程序的整个运行期间都存在。速度快、不易出错。如全局变量、static 变量等。
  2. 在栈上分配：在执行函数时，函数内局部变量的存储单元在栈上创建，函数退出时自动释放。栈分配速度极快（内置于 CPU 指令集），但栈空间容量有限。
  3. 从堆上分配：即动态内存分配。程序运行时调用 malloc 或 new 申请内存，由程序员手动负责在合适时机调用 free 或 delete 释放。若未释放将导致内存泄漏，频繁小块分配会产生堆内存碎片。

程序运行时的五大内存分区：堆区、栈区、全局/静态存储区、文字常量区、程序代码区。

面试题 7：简述 strcpy、sprintf 与 memcpy 的区别 #

  1. 操作对象不同：
    • strcpy 的操作对象只能是以 '\0' 结尾的字符串。
    • sprintf 的目标对象是字符串，但源对象可以格式化多种数据类型（数字、浮点、指针等）。
    • memcpy 的操作对象是两块纯粹的二进制内存块，不限于任何数据类型。
  2. 执行效率不同：memcpy 最高，strcpy 次之，sprintf 最低（需要解析格式化字符串）。
  3. 功能侧重不同：strcpy 用于字符串复制；sprintf 用于多类型数据到字符串的格式化拼接；memcpy 用于高效内存块按字节拷贝。

面试题 8：链表与数组的区别 #

  1. 存储形式：数组是物理地址连续的固定空间，声明时需确定容量；链表是逻辑相连但物理地址可不连续的动态空间，长度动态扩展。
  2. 查找效率：数组支持 $O(1)$ 随机索引访问；链表必须顺序遍历，查找效率为 $O(n)$。
  3. 插入与删除：数组插入删除需要移动后续大量元素（$O(n)$）；链表只需要修改前后指针节点（$O(1)$）。
  4. 内存开销：数组空间紧凑但容易浪费或溢出；链表不会溢出，但每个节点需要额外保存指针域。

面试题 9：简述队列和栈的异同 #

  • 队列（Queue）：先进先出（FIFO），只允许在一端（队尾）插入，在另一端（队头）删除。
  • 栈（Stack）：后进先出（LIFO），数据的插入和删除都在同一端（栈顶）进行。

面试题 10 & 11：冒泡排序实现 #

c
#include <stdio.h>

#define LEN 10

int main(void)
{
    int i, j, temp;
    int array[LEN] = {23, 1, 4, 9, 6, 17, 24, 56, 98, 72};

    // 冒泡排序核心算法
    for (i = 0; i < LEN - 1; i++)
    {
        for (j = 0; j < LEN - 1 - i; j++)
        {
            if (array[j] > array[j + 1])
            {
                temp = array[j];
                array[j] = array[j + 1];
                array[j + 1] = temp;
            }
        }
    }

    printf("After sorting, this array is:\n");
    for (i = 0; i < LEN; i++)
    {
        printf("%d ", array[i]);
    }
    printf("\n");

    return 0;
}

面试题 12：直接选择排序实现 #

c
#include <stdio.h>

int main(void)
{
    int i, j, min_idx, temp;
    int array[10] = {2, 7, 1, 8, 5, 9, 3, 4, 0, 6};

    // 选择排序：每次选出剩余部分最小值的索引
    for (i = 0; i < 9; i++)
    {
        min_idx = i;
        for (j = i + 1; j < 10; j++)
        {
            if (array[j] < array[min_idx])
            {
                min_idx = j;
            }
        }
        if (min_idx != i)
        {
            temp = array[i];
            array[i] = array[min_idx];
            array[min_idx] = temp;
        }
    }

    printf("After sorting, the array is:\n");
    for (i = 0; i < 10; i++)
    {
        printf("%d ", array[i]);
    }
    printf("\n");

    return 0;
}

面试题 13：typedef 和 define 有什么区别？ #

  1. 执行阶段不同：#define 在预处理阶段执行纯文本替换，无类型检查；typedef 在编译阶段处理，有严格的类型检查。
  2. 作用范围不同：#define 宏不受函数作用域限制，直到文件末尾或遇到 #undef；typedef 遵守标准变量作用域规则。
  3. 指针定义差异：
    c
    #define PINT int*
PINT p1, p2; // 展开为 int* p1, p2; -> p1 是指针，p2 是 int

typedef int* Pint;
Pint p3, p4; // p3 和 p4 都是 int* 指针

面试题 14：const 有什么作用？ #

  1. 定义变量为只读，防止被意外修改。
  2. 修饰函数参数，保护实参不被函数体改变。
  3. 修饰函数返回值，保护返回的指针指向内容不被调用方意外改写。
  4. 在 C++ 中，const 成员函数保证该函数内不会修改对象的成员变量。

面试题 15：static 有什么作用？ #

  1. 隐藏作用域：修饰全局变量或函数时，限制其作用域仅限当前文件，避免多模块符号冲突。
  2. 延长生命周期：修饰局部变量时，将变量放入静态存储区，函数退出时不销毁，下次进入保留前次值。
  3. C++ 类成员：静态数据成员为所有类实例共享；静态成员函数不依赖类对象实例即可调用（无 this 指针）。

面试题 16：extern 有什么作用？ #

extern 用于声明在其他模块中定义的全局变量或函数，通知编译器在链接阶段跨模块解析该符号。

面试题 17：指针常量与常量指针的区别 #

  • 常量指针（Pointer to Constant）：
    c
    const int *p; // 或 int const *p;
    指向常量的指针，指针本身可以改变指向，但不能通过该指针修改所指向的内存值。
  • 指针常量（Constant Pointer）：
    c
    int * const p = &a;
    指针本身是常量，一旦初始化后不能再指向其他地址，但可以通过该指针修改指向的数据。

面试题 18：如何避免“野指针”？ #

  1. 指针在定义时必须初始化（指向合法内存或赋为 NULL）。
  2. 指针释放（free/delete）后必须立即置为 NULL。
  3. 绝不返回局部变量的栈地址。
  4. 使用指针前必须进行合法性检查（if (ptr != NULL)）。

面试题 20：编码实现变量某位清 0 或置 1 #

c
#define BIT3 (0x1 << 3)
static int a;

// 设置 a 的 bit 3 置 1
void set_bit3(void)
{
    a |= BIT3;
}

// 将 a 的 bit 3 清 0
void clear_bit3(void)
{
    a &= ~BIT3;
}

// 保留第 3 位，其余位清零
void keep_bit3(void)
{
    a &= BIT3;
}

面试题 22：宏定义的符号替换陷阱 #

c
#include <stdio.h>
#define S(a, b) a * b

int main(void)
{
    int n = 3;
    int m = 5;
    printf("%d\n", S(n + m, m + n));
    return 0;
}
  • 问：输出是多少？
  • 答案：31
  • 原因：宏只是机械文本替换。S(n + m, m + n) 展开为 n + m * m + n = 3 + 5 * 5 + 3 = 31，并非 (3 + 5) * (5 + 3) = 64。

面试题 23：运算对象必须是整型的运算符 #

题目：C 语言中，运算对象必须是整型数的运算符是（ ） A. %　　B. /　　C. % 和 /　　D. *

  • 答案：A
  • 说明：求余运算符 % 左右两侧的操作数必须均为整数类型。

面试题 24 & 25：宏定义的复合展开计算 #

c
#include <stdio.h>
#define N 2
#define M N + 1
#define NUM (M + 1) * M / 2

int main(void)
{
    printf("%d\n", NUM);
    return 0;
}
  • 答案：8
  • 解析：
    • M 为 N + 1 即 2 + 1；
    • NUM 展开为：(2 + 1 + 1) * 2 + 1 / 2；
    • 先算乘除：4 * 2 + 0 = 8。
