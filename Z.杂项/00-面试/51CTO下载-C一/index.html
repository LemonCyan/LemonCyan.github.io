经典 C++ 核心面试题深度解析 #

本文档整理自 51CTO 经典 C/C++ 高频面试题库，覆盖 STL 底层实现、面向对象核心机制、内存管理与指针引用、虚函数与多态、设计模式、常见编译/链接错误（LNK2001/2005）及经典手写算法题。

经典 C++ 面试题（一） #

1. 介绍一下 STL，详细说明 STL 如何实现 vector #

STL (标准模版库，Standard Template Library) 由容器、算法、迭代器组成。
STL 有以下显著优点：

  • 可以方便容易地实现搜索数据或对数据排序等一系列的算法；
  • 调试程序时更加安全和方便；
  • 跨平台移植性好，代码可读性高。

vector 实质上就是一个动态数组，当容量不足时会自动分配更大的连续内存空间（通常扩容为原容量的 1.5 倍或 2 倍），并将原有元素拷贝/移动到新空间，然后释放旧内存。

2. 如果用 VC 开发程序，常见这么几个错误：LNK2001, LNK2005, C2011，这些错误的原因是什么 #

  • LNK2001（unresolved external symbol）：链接器找不到所引用的函数、变量或符号的实现。常见原因：声明了函数/变量但未定义实现、未包含相应的静态库/源文件、函数签名不一致或拼写错误。
  • LNK2005（symbol already defined）：重复定义符号。常见原因：在头文件中定义了全局变量或非内联函数，并在多个 cpp 文件中包含该头文件；或者重复链接了包含相同符号的库。
  • C2011（type redefinition）：类型重定义。常见原因：头文件缺少 #ifndef ... #define ... #endif 或 #pragma once 头文件卫士，导致同一个类/结构体在一个编译单元中被包含多次。

3. 继承和委派（组合）有什么分别，在决定使用继承或者委派的时候需要考虑什么 #

  • 在面向对象设计中，组合优于继承（Favor composition over inheritance）。
  • 继承表达的是 is-a 关系，是多态的基础；委派/组合表达的是 has-a 关系，耦合度更低。
  • 当对象的类型不影响类中函数的行为时，可使用模板或组合；当对象的类型影响类中函数的行为且需要多态行为时，才使用继承。

4. 指针和引用的区别；如果传引用比传指针安全，为什么？如果我使用常量指针难道不行吗？ #

  1. 初始化：引用在创建的同时必须初始化；指针定义时可以不初始化。
  2. 空值合法性：不存在 NULL 引用，引用必须绑定合法对象；指针可以是 NULL，可能产生野指针。
  3. 重新绑定：引用一旦绑定对象，不能再重新绑定到另一对象；指针在生命周期内可以随时改变指向。
  4. 语法语义：引用在语法上是对象的别名，底层通常由编译器使用常指针实现。
  5. 安全性：常量指针虽然指针本身不可变，但依然可以被初始化为 NULL 或失效地址；引用在语法上保证非空且不可重新绑定，因此使用时更安全直观。

5. 参数传递有几种方式；实现多态参数传递采用什么方式 #

参数传递有三种方式：值传递、指针传递、引用传递。
实现多态必须采用基类指针传递或基类引用传递。如果采用值传递，派生类对象传入时会发生“对象切片”（Object Slicing），派生类特有数据与虚函数表会被剥离，无法触发多态。

6. 结合一个项目说明你怎样应用设计模式的理念 #

设计模式的核心是提高代码的扩展性、可复用性与可维护性。例如在日志框架中使用单例模式保证全局唯一的日志句柄；在网络消息分发中使用工厂模式创建对应的协议处理器；在事件通知中使用观察者模式解耦业务模块。切忌滥用设计模式导致简单问题过度复杂化。

7. 介绍一下你对设计模式的理解与框架的区别 #

  • 问题域不同：设计模式针对通用的面向对象软件设计问题；框架针对特定的具体业务或架构领域（如 Web 框架、GUI 框架）。
  • 抽象层次不同：设计模式是抽象的指导思想与结构蓝图，不能直接运行；框架是半成品的软件，已经提供了现成代码与调用架构。
  • 粒度不同：框架是宏观体系结构，一个框架中往往包含并应用了多种设计模式。

8. C++ 和 C 定义结构体（struct）的区别 #

  • C 语言中的 struct 仅是纯数据的集合，内部不能定义成员函数，不能有访问控制权限修饰符（public/private），且定义变量时必须显式写 struct TagName var（除非使用 typedef）。
  • C++ 中的 struct 是完整的类（class），可以包含成员函数、构造/析构函数、支持继承和多态。struct 与 class 的唯一区别是：struct 默认成员访问权限和默认继承方式为 public，而 class 默认为 private。

9. 构造函数可否是虚函数？析构函数呢？可否是纯虚的？ #

  • 构造函数不能是虚函数：虚函数调用依赖对象内存中的虚表指针（vptr），而 vptr 是在构造函数执行期间才被初始化的；对象构造完成之前虚表机制尚未就绪。
  • 析构函数可以且经常必须是虚函数：当通过基类指针 delete 派生类对象时，虚析构函数保证能正确调用派生类的析构函数，防止内存/资源泄漏。
  • 析构函数可以是纯虚函数：但纯虚析构函数必须提供函数体实现，因为派生类析构时仍会向上隐式调用基类析构函数。

10. 拷贝构造函数、深拷贝与浅拷贝 #

  • 浅拷贝：仅按位拷贝对象的成员变量，如果成员变量是指向堆内存的指针，两个对象的指针将指向同一块内存，导致析构时同一块内存被 delete 两次，引发崩溃。
  • 深拷贝：为指针成员重新在堆上分配独立的内存，并将内容复制过去，保证对象生命周期相互独立。

11. 基类的虚函数，子类覆写时还需要声明为 virtual 吗？ #

子类覆写基类虚函数时，即使不显式写 virtual 关键字，该函数在子类中依然是虚函数。但在工程实践中强烈建议显式声明 virtual，且在 C++11 后加上 override 关键字，以便编译器协助检查签名并提升代码可读性。

12. 为什么要引入抽象基类和纯虚函数？ #

为了定义统一的接口规范。抽象基类不能被直接实例化，它通过纯虚函数（virtual void func() = 0;）强制所有派生类必须实现对应的行为，从而在面向对象架构中实现统一的接口契约与依赖倒置。

13. 模板与容器的理解 #

模板体现了泛型编程（Generic Programming）的思想，将算法与数据类型解耦。STL 核心容器包括：顺序容器（vector, deque, list）、关联容器（set, multiset, map, multimap）以及容器适配器（stack, queue, priority_queue）。

14. 多重继承如何消除向上继承的菱形二义性？ #

使用虚继承（virtual inheritance），基类作为虚基类继承，派生类只保留一份公共基类的实例拷贝，消除二义性。

经典 C++ 面试题（二） #

15. 以下三条输出语句分别输出什么？ #

cpp
char str1[] = "abc";  
char str2[] = "abc";  
const char str3[] = "abc";  
const char str4[] = "abc";  
const char* str5 = "abc";  
const char* str6 = "abc";  
cout << boolalpha << ( str1==str2 ) << endl; // false
cout << boolalpha << ( str3==str4 ) << endl; // false
cout << boolalpha << ( str5==str6 ) << endl; // true

解析：

  • str1 和 str2 是分别分配在栈上的两个独立字符数组，首地址不同，故比较结果为 false。
  • str3 和 str4 同理，是栈上两个不同的只读数组，首地址不同，故为 false。
  • str5 和 str6 是两个指针，指向常量存储区中合并存储的同一个只读字符串常量 "abc"，故指针值相等，为 true。

16. 非 C++ 内建型别 A 和 B，在哪几种情况下 B 能隐式转化为 A？ #

  1. class B : public A：B 公有派生自 A（向上类型转换/切片）。
  2. class B { operator A(); };：B 定义了到 A 的类型转换运算符。
  3. class A { A(const B&); };：A 实现了非 explicit 的以 B 为参数的转换构造函数。

17. 数组传参时的 sizeof 陷阱 #

cpp
void UpperCase( char str[] ) // 将 str 中的小写字母转换成大写字母  
{  
    for( size_t i = 0; i < sizeof(str)/sizeof(str[0]); ++i )  
        if( 'a' <= str[i] && str[i] <= 'z' )  
            str[i] -= ('a' - 'A');  
}  
char str[] = "aBcDe";  
cout << "str 字符长度为: " << sizeof(str)/sizeof(str[0]) << endl;  
UpperCase( str );  
cout << str << endl;

问题解析： 在 UpperCase 函数形参中，char str[] 已经退化为指针 char*。在 32 位系统下 sizeof(str) 为 4，在 64 位下为 8，无法得到原数组长度。循环无法遍历完整个数组。必须将数组长度作为形参显式传入函数。

18. 求下面统计二进制中 1 的个数的函数返回值（微软经典题） #

cpp
int func(int x)  
{  
    int countx = 0;  
    while(x)  
    {  
        countx++;  
        x = x & (x - 1);  
    }  
    return countx;  
}

若 x = 9999： $9999 = 8192 + 1024 + 512 + 256 + 15 = 2^{13} + 2^{10} + 2^9 + 2^8 + 8 + 4 + 2 + 1$，二进制为 10011100001111，共含 8 个 1。因此返回 8。
x = x & (x - 1) 的作用是每次消去二进制中最低位的 1。

19. 在什么时候需要使用“常引用”？ #

如果既要利用引用避免大对象拷贝提高程序效率，又要保证实参不被函数内部意外修改，应使用常引用（const Type&）。常引用还可以安全绑定临时对象（右值）。

20. 将“引用”作为函数返回值类型的规则与注意事项 #

  1. 绝对不能返回局部变量的引用：局部变量在函数返回时栈内存被销毁，返回其引用会导致悬空引用及未定义行为。
  2. 不能返回函数内部 new 分配内存的引用：容易导致内存泄漏，因为接收方难以显式获取指针进行 delete。
  3. 流操作符 << 和 >> 返回流引用的原因：支持链式连续调用（如 cout << a << b;）。
  4. 四则运算操作符（+、-、*、/）不能返回引用：因为四则运算产生的是新的临时数学结果对象，必须返回对象值。

21. 结构体（struct）与联合体（union）的核心区别 #

  1. 内存占用：结构体各成员独立占用内存空间，总大小为各成员对齐后的累加；联合体所有成员共享同一块内存空间，大小至少为最大成员的尺寸。
  2. 赋值影响：对联合体某个成员赋值会覆盖其他成员的内容；对结构体某个成员赋值互不影响。

22. 面向对象的三大基本特征及其含义 #

  1. 封装（Encapsulation）：将客观事物抽象为包含数据属性与操作行为的类，并对成员实行访问权限控制（private, protected, public），隐藏实现细节，对外暴露安全受控的接口。
  2. 继承（Inheritance）：基于现有类创建新类，实现代码复用与类型层次扩展。广义上有实现继承（继承具体方法实现）、接口继承（仅继承函数签名与契约，具体由子类实现）。
  3. 多态（Polymorphism）：同一接口在不同对象上表现出不同的行为。通过父类指针/引用指向子类对象，并在运行时动态绑定子类的虚函数实现。

23. 重载（Overload）与重写/覆盖（Override）的区别 #

维度 重载（Overload） 重写/覆盖（Override）
发生范围 同一个类内部 父类与子类之间
函数签名 函数名相同，参数列表必须不同（个数/类型/顺序） 函数名、参数列表、返回值必须完全相同（协变除外）
virtual 关键字 可有可无 父类基函数必须声明为 virtual
绑定时期 编译期绑定（早绑定 / 静态多态，通过 name mangling 区分） 运行期绑定（晚绑定 / 动态多态，通过虚表指针与虚表查询）

24. 预编译是什么？何时需要预编译头文件？ #

预编译是指将不经常修改的大型公共代码体（如系统 SDK 头文件、标准库 <vector>, <windows.h> 等）预先编译为二进制中间格式（如 .pch 文件）。当工程由多个源文件组成且都包含大量相同的标准头文件时，预编译头文件能将整体编译构建时间大幅缩短数倍。

26. 数组指针与数组越界偏移计算 #

写出以下代码的打印结果：

c
int main()
{
    int a[5] = {1, 2, 3, 4, 5};
    int *ptr = (int *)(&a + 1);
    printf("%d, %d\n", *(a + 1), *(ptr - 1));
    return 0;
}

输出：2, 5
原理解析：

  • a 是数组首元素地址（类型为 int*），a + 1 偏移 1 个 int，指向 a[1]，故 *(a + 1) = 2。
  • &a 是整个数组的指针（类型为 int(*)[5]），&a + 1 将跳过整个数组的内存大小（$5 \times 4 = 20$ 字节），指向数组末尾之后紧随的下一个内存位置。
  • (int*)(&a + 1) 强制转换为整型指针赋值给 ptr，因此 ptr - 1 向前移动一个整型单位，恰好指向数组最后一个元素 a[4]，故 *(ptr - 1) = 5。

28. 经典内存泄漏与野指针陷阱分析 #

c
void getmemory(char *p)
{
    p = (char *)malloc(100);
}
int main()
{
    char *str = NULL;
    getmemory(str);
    strcpy(str, "hello world"); // 崩溃！str 仍为 NULL
    printf("%s\n", str);
    free(str);
    return 0;
}

问题解析： C 语言中函数参数默认采用值传递。在 getmemory 中，形参 p 仅是实参 str 的副本。在函数体内为 p 分配内存仅改变了局部指针 p 的指向，实参 str 依旧为 NULL。函数退出后 p 销毁，导致分配的 100 字节内存泄漏，且 strcpy 向空指针写入数据引发内存段错误。
正确写法：传入二级指针 char **p，或在 C++ 中使用指针的引用 char *&p。

29. 死锁的四个必要条件与处理策略 #

  • 四个必要条件：
    1. 互斥条件：资源同一时刻只能由一个进程占用；
    2. 请求与保持条件：进程因请求新资源受阻时，对已有资源保持不放；
    3. 不剥夺条件：进程获得的资源在未使用完前不能被强行剥夺；
    4. 循环等待条件：存在一组进程相互形成环路等待彼此释放资源。
  • 处理策略：预防死锁（破坏四个必要条件之一）、避免死锁（银行家算法动态分配）、检测与解除死锁、鸵鸟策略。

32. 单链表逆序与合并有序链表（Intel & Autodesk 经典手撕题） #

cpp
struct Node  
{  
    int data;  
    Node *next;  
};  

// (1) 迭代法实现单链表逆序
Node* ReverseList(Node *head)
{  
    if (head == NULL || head->next == NULL)  
        return head;  
    Node *p1 = head;  
    Node *p2 = p1->next;  
    Node *p3 = p2->next;  
    p1->next = NULL; // 原头节点变尾节点
    
    while (p3 != NULL)  
    {  
        p2->next = p1;  
        p1 = p2;  
        p2 = p3;  
        p3 = p3->next;  
    }  
    p2->next = p1;  
    head = p2;  
    return head;  
}  

// (2) 迭代法合并两个有序单链表
Node* Merge(Node *head1, Node *head2)  
{  
    if (head1 == NULL) return head2;  
    if (head2 == NULL) return head1;  
    
    Node *head = NULL;  
    Node *p1 = NULL;  
    Node *p2 = NULL;  
    
    if (head1->data < head2->data)  
    {  
        head = head1;  
        p1 = head1->next;  
        p2 = head2;  
    }  
    else  
    {  
        head = head2;  
        p2 = head2->next;  
        p1 = head1;  
    }  
    
    Node *pcurrent = head;  
    while (p1 != NULL && p2 != NULL)  
    {  
        if (p1->data <= p2->data)  
        {  
            pcurrent->next = p1;  
            pcurrent = p1;  
            p1 = p1->next;  
        }  
        else  
        {  
            pcurrent->next = p2;  
            pcurrent = p2;  
            p2 = p2->next;  
        }  
    }  
    if (p1 != NULL) pcurrent->next = p1;  
    if (p2 != NULL) pcurrent->next = p2;  
    return head;  
}  

// (3) 递归法合并两个有序链表
Node* MergeRecursive(Node *head1, Node *head2)  
{  
    if (head1 == NULL) return head2;  
    if (head2 == NULL) return head1;  
    
    Node *head = NULL;  
    if (head1->data < head2->data)  
    {  
        head = head1;  
        head->next = MergeRecursive(head1->next, head2);  
    }  
    else  
    {  
        head = head2;  
        head->next = MergeRecursive(head1, head2->next);  
    }  
    return head;  
}

33. 判断单链表是否有环（快慢指针法） #

cpp
bool checkHasCycle(const Node* head)  
{  
    if(head == NULL || head->next == NULL) return false;  
    const Node *slow = head;
    const Node *fast = head->next;  
    
    while(fast != NULL && fast->next != NULL)  
    {  
        if(slow == fast) return true;  
        slow = slow->next;          // 慢指针每次走 1 步
        fast = fast->next->next;    // 快指针每次走 2 步
    }  
    return false;  
}

34. 查找整数数组中的第二大数（Microsoft） #

cpp
int find_sec_max(const int data[], int count)  
{  
    int maxnumber = data[0];  
    int sec_max = -32767;  
    for (int i = 1; i < count; i++)  
    {  
        if (data[i] > maxnumber)  
        {  
            sec_max = maxnumber;  
            maxnumber = data[i];  
        }  
        else if (data[i] > sec_max && data[i] != maxnumber)  
        {  
            sec_max = data[i];  
        }  
    }  
    return sec_max;  
}

35. 堆（Heap）与栈（Stack）的核心区别 #

比较维度 栈（Stack） 堆（Heap）
分配与回收 编译器自动分配与释放，存放局部变量、函数参数 程序员通过 malloc/new 申请，free/delete 释放
内存连续性与碎片 连续的向下扩展空间，无碎片，速度极快 链表式离散分配，向上扩展，容易产生内存碎片
空间容量 较小（Windows 默认通常为 1MB 或 2MB） 受限于系统的虚拟内存，容量大
生长方向 由高地址向低地址生长 由低地址向高地址生长

36. 宏定义展开陷阱计算 #

cpp
#define DOUBLE(x) x + x
int i = 5 * DOUBLE(5);

问：i 的值是多少？
答：宏替换在预处理期按文本直接替换：5 * DOUBLE(5) 展开为 5 * 5 + 5 = 25 + 5 = 30。因此 i 为 30（而不是 50）。
教训：编写宏时每个操作数和整体表达式必须用括号严格包围：#define DOUBLE(x) ((x) + (x))。

37. 如何在 C++ 类中实现回调函数 #

类的普通成员函数隐含了一个参数 this 指针，其函数指针类型与标准 C 风格回调函数指针（如 void (*)(void)）不匹配。
解决方案：将类的成员函数声明为 static 静态成员函数。静态成员函数没有 this 指针，具备标准的 C 函数调用约定，可以无缝作为回调函数传递给底层系统。若需要访问实例成员，可通过将对象指针作为上下文参数（void *context）传入回调中强转使用。
