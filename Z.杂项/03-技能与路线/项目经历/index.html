项目一：航电系统嵌入式 Linux 平台迁移与上位机开发 #

项目时间：2021.10 – 2025.08（核心迁移阶段：2024.05 - 2025.08）

项目介绍 #

原航电系统基于 Windows 平台下的 VS2005 环境开发，现基于国产化、客户定制化和后期适航许可等多项需求，将整个系统移植到嵌入式 Linux 系统（RK3568）中，并配套开发通讯中间件软件，完善各模块的验证测试文档。

系统架构 #

  • 系统主要用于飞机的六大仪表显示、飞行路径规划、机体相关信息显示
  • 分为 Windows 和 Linux 双平台开发，Windows 适用于模拟器，Linux 适用于真机

职责描述 #

平台选型与调研 #

  • 负责目标嵌入式平台的选型与技术调研
  • 从接口兼容性（LVDS/CAN/232 串口，匹配航电硬件）、CPU/GPU 性能（支撑实时数据处理）、成本控制 3 维度评估
  • 初步确定嵌入式 Linux RK3568 平台

环境搭建与系统部署 #

  • 完成嵌入式 Linux 系统部署与环境配置
  • 进行 Linux 系统裁剪 / 移植，优化根文件系统
  • 内核实时性 xenomai 方案学习

代码迁移与重构 #

  • 利用 Linux 环境下的 Qt/C++ 重构 Windows API（窗口创建、互斥锁、基础数据类型）
  • 采用宏定义和条件编译方式实现双平台适配，解决多项兼容性问题
  • 实现 Win 和 Linux 下的线程调度 / 数据传输 / 窗口显示部分
  • 为迁移后的程序在 Qt 环境下设计新的窗口系统

功能开发 #

  • 对系统功能模块进行梳理与拆分，按模块进行二次开发与功能验证
  • 基于 Qt / C++ 开发上位机软件，实现设备状态显示、数据转发和交互
  • 完成仪表 / 发动机状态部分的数据协议和显示
  • 设计并实现多线程数据处理机制，保障数据采集与界面显示的实时性

验证与交付 #

  • 完善验证测试文档，配合测试团队解决问题项
  • 编写系统设计文档、接口文档及调试说明文档，支持系统联调与交付
  • 输出验证文档并支撑测试闭环

关键成果 #

  • 主导 Win → Linux 嵌入式平台迁移（RK3568），完成核心模块重构
  • 完成 LVDS / CAN / 串口接口迁移
  • 重构 Win API 适配 Qt/Linux

项目二：基于 ARINC 协议的航空聚合通讯软件（航空通信协议中间件） #

项目时间：2021.10 - 2023.07

项目介绍 #

航电在适配新机型时，需对机上各设备的数据进行整合，包含 ARINC825/429/422 等协议，主要内容为针对航空通信协议标准及客制化协议进行软件开发。输入协议主要包含 CAN/CANOpen，输出协议主要为串口、ARINC422/429 等协议。

职责描述 #

需求梳理与协议设计 #

  • 梳理航电设备数据传输需求，确认协议适配细节
  • 沟通确认协议适配细节，输出协议文档
  • 覆盖数据计算、负载测试核心场景

功能开发 #

  • 整合 ARINC825/429/422 与 CAN/CANOpen 多协议
  • 设计界面功能，输出开发文档，编程实现细节内容
  • 设计并开发多线程收发、数据解析、模拟器、记录系统
  • 实现数据显示与记录 / 数据模拟功能
  • 实现软件识别数据流来源，自动调用对应数据解析模块，避免插错接口

测试与优化 #

  • 在 X86 平台的 Qt 软件中设计多线程负载测试方案
  • 在满负载 / 老化测试条件下降低多模块满负载情况下数据丢帧率

关键成果 #

  • 统一解析框架，实现多线程收发、数据模拟与压力测试
  • 设计完成航空通讯协议中间件（多协议整合 / 模拟 / 负载测试）

项目三：基于嵌入式 Linux 的 28/96 孔 PCR 核酸扩增仪开发 #

项目时间：2019.10 - 2021.09（核心开发阶段：2020.07 – 2021.09）

项目介绍 #

系统通过 STM32+Linux 的配置，实现了温度控制、荧光采集、数据分析与计算。主控 STM32 连接两块附属 STM32，附属 STM32 分别实现温度的控制和荧光的采集功能。附属 STM32 和主控 STM32 间采用 CAN 通讯方式，主控 STM32 和 Linux 采用串口通讯方式。各控制指令和运行流程均由 Linux 上位机控制，采集由 STM32/工业相机拍照收集到的荧光数据，通过算法处理数据/照片后得出结果。

系统模块 #

  • 控制模块（STM32）
  • 分析模块（Linux / RK3399）

职责描述 #

环境搭建与移植 #

  • 负责嵌入式平台的环境部署
  • 相机 BSP 的移植测试工作（Basler 工业相机）
  • Matlab 算法移植，相机支持库的配置及使用

控制流程设计 #

  • 负责控制流程的设计工作，主要包含温度达标和数据采集电机的运动控制
  • 设计设备的升降温（TEC）、电机旋转角度、相机数据采集和多线程处理的同步控制

程序开发 #

  • 负责 RK3399 部分的 Qt 程序的编写
  • 针对程序中的不同通道数据控制和采集时的异步控制
  • 通过多线程进行采集，并根据不同的通道通过共用体的方式标记不同的处理方式
  • 负责 Basler 工业相机的数据采集传输工作
  • 负责上位机程序设计，包含 CAN 协议的设计 / 用户流程编辑 / 数据记录与分析
  • 熟悉 CAN 协议，制定通讯协议，使用 socketCAN 进行通讯

数据优化 #

  • 针对荧光数据的曲线平滑和数据失真及噪点剔除问题，通过积分和卡尔曼滤波的方式解决
  • 在 Matlab 中模拟，优化曲线和算法，配合该样本的录入信息得到结果
  • 针对大量数据绘制曲线时的加载速度问题，测试了加载 OpenGL，之后分别测试了 QChart/Qwt/QCustomPlot 的方式
  • 优化原有的 QChart 方案，通过 Qwt 重新实现，提高大数据量绘制性能（提升 2-3 倍）

文档与交付 #

  • 负责开发文档、设计文档相关资料的编写
  • 支撑专利和软著的申请

关键成果 #

  • 28 孔核酸扩增仪
  • 96 孔核酸扩增仪
  • 多通道采集、卡尔曼滤波、工业相机 BSP 适配

项目四：紫外烟气连续在线监测系统（CEMS） #

项目时间：2018.03 – 2019.02

项目介绍 #

系统通过 USB 通讯读取光谱仪的实时光谱，通过 MATLAB 算法计算烟道中污染气体的实时浓度，通过 MODBUS 与 STM32 通讯控制阀组完成标定等操作，同时读取外部数采仪模块采集 4-20mA 模拟量。

系统架构 #

  • 数据采集中心（STM32）
  • 控制中心（A3352/Cortex-A7）
  • 数据分析中心（Ubuntu）

职责描述 #

环境搭建与库移植 #

  • 负责嵌入式 Linux 环境的交叉编译、裁剪
  • 完成 libusb/libmodbus/tslib 等运行库的移植工作

程序开发 #

  • 负责 Qt 程序编写，多线程完成用户交互、运行逻辑控制、数据整合转发
  • 设计 5 线程并行架构：modbus 监测 → libusb 光谱采集 → 数据库报警存储 → Matlab 算法计算 → UI 显示刷新
  • 通过 MQTT 协议将数据发送到阿里云物联网接口和 DCS 主控室

交付与运维 #

  • 负责开发文档、设计文档、设备认证相关资料编写
  • 累计交付客户 100+ 台，现场调试并根据反馈迭代程序
  • 协助设备通过环保行业计量认证

技术难点 #

  • 多协议数据融合：4-20mA / MODBUS / USB / 串口多协议统一采集
  • libusb 等外部库在嵌入式环境下的编译与移植
  • 现场问题排查：电磁干扰、串口阻塞、电源/地线稳定性

关键成果 #

  • 完成烟气/粉尘分析仪开发，通过环保局计量认证
  • 累计交付 100+ 台，支撑行业认证

项目五：水质监测设备与物联网平台 #

项目时间：2019.02 – 2019.10

项目介绍 #

设备用于抽取河道水样，采集水质数据，通过 4G 终端对接阿里云 MQTT 实现远程监测。STM32 实现水位检测和电机控制，A3352 控制整个系统运行流程。

系统架构 #

  • 数据采集中心（STM32）
  • 控制中心（A3352/Cortex-A7）
  • 数据存储和显示中心（Web 端）

职责描述 #

环境搭建与库移植 #

  • 完成嵌入式 Linux 平台环境部署
  • libmodbus/MQTT 协议等通讯库向 Linux 环境下的移植

程序开发 #

  • 负责多线程/数据库/MODBUS/串口等编程
  • 设计中转协议兼容公司的水质/烟气/粉尘监测数据格式
  • 通过 4G 模块对接阿里云的 MQTT 协议接口
  • 终端的 UI 显示和交互、业务逻辑、通讯协议

交付与认证 #

  • 完成模块及系统测试，输出设计文档、开发文档、测试文档
  • 累计交付客户设备，协助通过环保行业认证

技术难点 #

  • 协议对接与数据格式统一
  • 电机控制的准确度
  • 解决"数据格式不统一、上传丢包"问题

关键成果 #

  • 完成水质分析仪开发
  • 实现物联网远程数据上报

其他项目经历 #

  • 心室辅助装置 VAD：实时监控血压/流量 · socketCAN 通信 · 参数报警逻辑
  • 光谱仪 SDK：双平台 C++ SDK · Socket/USB/RS232 多通信协议封装
  • 3D 打印机：Klipper 固件 · G-code 串口通信 · C++ 上位机
  • 个人博客： 静态站点搭建
  • 基金数据工具：实时数据展示 · AI 操作建议
