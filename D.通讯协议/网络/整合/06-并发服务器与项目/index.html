并发服务器与项目实战 #

整合自《网络聊天室_多线程》《网络聊天室_IO 多路复用》《主机与开发板通信》《网络与数据库》《电子词典项目要求》《sqlite3 函数功能》等笔记。

1. 多线程聊天室（每连接一线程） #

用全局数组维护在线用户，主线程 accept 后 pthread_create 一个线程服务该连接，线程内 recv 并广播给所有在线 fd。

c
#define MAX_ONLINE_NUM 512
struct ON_LINE { int fd; char name[32]; } online[MAX_ONLINE_NUM];

void *func(void *arg) {
    int new_fd = *(int*)arg;
    while (1) {
        int n = recv(new_fd, buf, BUFSIZ, 0);
        if (n <= 0) { close(new_fd); del_user(new_fd, idx); break; } // 断开
        sprintf(msg, "%s say %s", online[idx].name, buf);
        for (int i = 0; i < MAX_ONLINE_NUM; i++)           // 广播
            if (online[i].fd != -1) send(online[i].fd, msg, strlen(msg), 0);
    }
}
// main: socket→bind→listen→online_init→while(accept){ recv(name); add_user(); pthread_create(...) }

要点：用户表用 fd 定位；某用户退出时遍历数组通知其他人 xxx left；广播即遍历所有非 -1 的 fd 发一份。

2. IO 多路复用聊天室（select 单线程） #

不创建线程，用 select 同时监听监听 socket 和所有已连接 socket：

c
fd_set global_rdfs, current_rdfs;
FD_ZERO(&global_rdfs); FD_SET(listenfd, &global_rdfs);
int maxfd = listenfd;
while (1) {
    current_rdfs = global_rdfs;
    select(maxfd+1, &current_rdfs, NULL, NULL, NULL);
    for (i = 3; i <= maxfd; i++) {              // 0,1,2 已被 stdin/out/err 占用
        if (!FD_ISSET(i, &current_rdfs)) continue;
        if (i == listenfd) {                    // 新连接
            connfd = accept(i, NULL, NULL);
            FD_SET(connfd, &global_rdfs);
            maxfd = max(maxfd, connfd);
        } else {                                 // 某客户端数据
            if (recv(i, buf, N, 0) <= 0) { close(i); FD_CLR(i, &global_rdfs); }
            else for (j = 3; j <= maxfd; j++) if (j != listenfd) send(j, buf, N, 0);
        }
    }
}

要点：维护 global_rdfs 备份集合（每次 select 会破坏传入集合）；新连接必须 FD_SET 进全局集合并修正 maxfd；断开时 FD_CLR + close。

3. 主机与开发板通信（select 双向聊天） #

服务器/客户端各自用 select 同时监视"标准输入"和"socket"两个 fd，实现双向实时对话：

c
fd_set rfds; struct timeval tv = {5, 0};
while (1) {
    FD_ZERO(&rfds); FD_SET(0, &rfds); FD_SET(fd, &rfds); // 0=stdin, fd=socket
    int ret = select(maxfd+1, &rfds, NULL, NULL, &tv);
    if (ret == 0) { printf("waiting...\n"); continue; }
    if (FD_ISSET(0, &rfds)) {            // 用户输入 → 发给对端
        fgets(buf, BUFLEN, stdin);
        if (!strncasecmp(buf, "quit", 4)) break;
        send(fd, buf, strlen(buf)-1, 0);
    }
    if (FD_ISSET(fd, &rfds)) {           // 对端消息 → 打印
        int n = recv(fd, buf, BUFLEN, 0);
        if (n <= 0) { printf("peer exit\n"); break; }
        printf("msg: %s\n", buf);
    }
}

4. 网络与数据库（SQLite3） #

C/S 词典类项目常把词库/用户存进 SQLite，关键 API：

c
sqlite3 *db;
sqlite3_open("my.db", &db);                       // 打开，成功返回 0
sqlite3_exec(db, sql, callback, NULL, &errmsg);   // 执行 SQL（无结果集用）
// 回调函数：每找到一条记录自动调用一次
int callback(void *para, int f_num, char **f_value, char **f_name);
sqlite3_get_table(db, sql, &resultp, &nrow, &ncolumn, &errmsg); // 一次取全部结果
sqlite3_close(db);                                 // 关闭
// 编译：gcc test.c -lsqlite3
  • sqlite3_exec 的 callback 参数：f_num=列数，f_value[]=各字段值，f_name[]=各列名。
  • sqlite3_get_table 把所有结果（含表头）压进二级指针 resultp，nrow×ncolumn 定位单元格。判断是否用户名已存在：select ... where name='%s' 后看 nrow != 0。

5. 电子词典项目要求（C/S 综合） #

  • 技术：C 语言 + Linux socket，C/S 架构，数据存数据库，附 Makefile。
  • 功能：登录 / 注册 / 修改信息 / 查词 / 查历史记录。
  • 规范：禁用拼音；多文件、每 .c 配同名 .h；多封装函数、统一交互结构体（命令与状态预定义）。
  • 扩展：公聊/私聊、在线用户、离线消息推送；词库转数据库。
