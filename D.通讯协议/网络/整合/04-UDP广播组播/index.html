UDP、广播与组播 #

整合自《UDP 服务器创建基本流程》《广播》《组播》《组播广播》《recvfrom 超时》等笔记。UDP 是无连接数据报，配套广播/组播是其最常用场景。

1. UDP 服务器创建流程 #

UDP 没有 listen/accept/connect 这套连接管理，核心是 socket → bind → recvfrom/sendto：

c
int sfd = socket(AF_INET, SOCK_DGRAM, 0);
bind(sfd, (struct sockaddr*)&servaddr, sizeof(servaddr));   // 绑定本地端口
for (;;) {
    // 收：拿到对端地址
    n = recvfrom(sfd, buf, BUF, 0, (struct sockaddr*)&peer, &peerlen);
    // 发：指定对端地址
    sendto(sfd, buf, n, 0, (struct sockaddr*)&peer, peerlen);
}

UDP 也可先 connect 固定对端，之后直接用 send/recv（见 02 篇 UDP connect 语义）。

2. 广播（Broadcast） #

广播把数据发给本网段所有主机，地址为 子网.255（如 192.168.1.255）。须开启 SO_BROADCAST 选项，否则 sendto 失败：

c
int on = 1;
setsockopt(sfd, SOL_SOCKET, SO_BROADCAST, &on, sizeof(on));

struct sockaddr_in bcast;
bcast.sin_family = AF_INET;
bcast.sin_port = htons(8888);
inet_pton(AF_INET, "192.168.1.255", &bcast.sin_addr);
sendto(sfd, msg, len, 0, (struct sockaddr*)&bcast, sizeof(bcast));

前提：网卡支持广播（ifconfig 显示 BROADCAST）。广播无法跨路由器（被 TTL/子网隔离）。

3. 组播 / 多播（Multicast） #

组播地址范围 224.0.0.0/4（D 类），只发给加入了该组的成员，是网络游戏、视频会议、分布式系统的基石。

关键步骤（易踩坑）：

  1. 先确认网卡支持多播（ifconfig 含 MULTICAST）。
  2. 发送组播包的主机必须设网关，否则 sendto 报 network is unreachable：
    bash
    route add default gw 192.168.40.1 dev eth0
# 添加组播路由（部分环境需要）
route add -net 224.0.0.0 netmask 240.0.0.0 dev eth0
  3. 加入组（IP_ADD_MEMBERSHIP）：
    c
    struct ip_mreq mreq;
mreq.imr_multiaddr.s_addr = inet_addr("224.0.0.88"); // 组地址
mreq.imr_interface.s_addr = htonl(INADDR_ANY);        // 本机接口
setsockopt(sfd, IPPROTO_IP, IP_ADD_MEMBERSHIP, &mreq, sizeof(mreq));
  4. 组地址转换报错 No such device：说明地址开头不是 1110（D 类）。用 htonl(inet_network("224.0.0.88")) 或 inet_aton 转成 uint32_t 网络序。

发送组播和普通 UDP 发送一致，目标地址填组播 IP 即可。

4. recvfrom 超时控制 #

UDP 的 recvfrom 默认阻塞，可用 alarm + 信号中断实现超时：

c
#include <unistd.h>
#include <signal.h>

static void dealSigAlarm(int signo) { /* 仅用于打断 recvfrom */ }

struct sigaction act;
memset(&act, 0, sizeof(act));
act.sa_handler = dealSigAlarm;
act.sa_flags = SA_NOMASK;   // 不重启被中断的系统调用
sigaction(SIGALRM, &act, NULL);

while (1) {
    alarm(5);               // 5 秒后发 SIGALRM
    n = recvfrom(sfd, buf, 1420, 0, (struct sockaddr*)&peer, &peerlen);
    if (n < 0) {
        if (errno == EINTR) printf("recvfrom timeout.\n");
    } else {
        alarm(0);           // 非常重要：收到数据立即关闹钟
    }
}

用 signal() 会自动重启被中断的 recvfrom，导致超时后继续阻塞——必须用 sigaction 并设 SA_NOMASK（old 行为）。进程只有一个定时器，用完务必 alarm(0) 关闭。

更现代的做法是 setsockopt(SO_RCVTIMEO, &tv) 或在 select/poll/epoll 上设超时，避免信号处理。
