01-网络编程基础

网络编程基础 #

整合自《网络进程通信原理》《网络字节序》《socket 地址结构》等笔记。本篇只解决一个根本问题：网络中的进程如何互相找到对方，并说上话。

1. 网络进程通信的本质 #

单机进程靠 PID 唯一标识；不同主机的 PID 互不通用（A 机的 5 号进程 ≠ B 机的 5 号进程）。TCP/IP 用 三元组（IP 地址，协议，端口） 唯一标识一个网络进程：

  • IP 地址 → 标识主机（网络层）
  • 协议（TCP/UDP）→ 标识传输层
  • 端口 → 标识主机内的应用进程

应用进程通过 Socket（套接字） 这一中间软件抽象层与 TCP/IP 协议族通信。Socket 脱胎于 Unix "一切皆文件"：创建即 open，收发即 read/write，关闭即 close。它本身是一个门面（Facade）模式——把复杂的协议细节藏到一组简单接口后面，对用户来说一组接口就是全部。

体系里几乎所有网络应用都基于 socket，所以才说"一切皆 socket"。

套接字描述符 sockfd 就是内核在进程文件描述符表里分配的一个小整数，用法与普通文件描述符一致：应用程序拿到它，后续所有 I/O 都以它为参数。

2. 网络字节序 #

多字节整数在内存中的存放顺序称为字节序：

  • 小端（Little-Endian）：低位字节放低地址（x86 平台）
  • 大端（Big-Endian）：高位字节放低地址

网络字节序规定为大端（Big-Endian），与具体 CPU、操作系统无关，保证跨主机传输时被正确解释。在把地址/端口赋给 socket 之前必须转成网络序——这个坑曾导致过"血案级"的莫名 bug，切勿假定主机序与网络序相同。

常用转换函数（头文件 <arpa/inet.h>）：

函数 作用
htons host → network，16 位（端口号）
htonl host → network，32 位（IP 地址）
ntohs / ntohl network → host，对应逆操作

IP 地址文本与二进制的互转：

c
#include <arpa/inet.h>
// 点分十进制 -> 网络字节序二进制（返回值已含 htonl，勿再转换！）
servaddr.sin_addr.s_addr = inet_addr("192.168.0.1");
// 推荐替代 inet_addr：支持 IPv6，返回 1 成功 / 0 格式错 / -1 失败
inet_pton(AF_INET, "192.168.0.1", &servaddr.sin_addr);
// 网络地址 -> 点分十进制（返回静态缓冲，非可重入，下次调用会覆盖）
printf("%s", inet_ntoa(addr.sin_addr));

⚠️ inet_addr 失败返回 -1，恰等于广播地址 255.255.255.255，务必先判错再使用。inet_ntoa 返回的是内部静态指针，需 strcpy 保存后再做下一次调用。

3. Socket 地址结构 #

bind / connect / accept 等函数统一接收通用指针 struct sockaddr *，实际传入的是各协议族的专属结构，靠首字段 sa_family 区分。强制转换即可：

c
// IPv4
struct sockaddr_in {
    sa_family_t    sin_family; // AF_INET
    in_port_t      sin_port;   // 网络字节序
    struct in_addr sin_addr;   // 网络字节序（32 位）
};
// IPv6
struct sockaddr_in6 {
    sa_family_t     sin6_family; // AF_INET6
    in_port_t       sin6_port;
    uint32_t        sin6_flowinfo;
    struct in6_addr sin6_addr;   // 16 字节
    uint32_t        sin6_scope_id;
};
// Unix 域（本机进程间通信，用路径名作地址）
struct sockaddr_un {
    sa_family_t sun_family;          // AF_UNIX
    char        sun_path[108];
};

典型用法：

c
struct sockaddr_in servaddr;
memset(&servaddr, 0, sizeof(servaddr));
servaddr.sin_family = AF_INET;
servaddr.sin_addr.s_addr = htonl(INADDR_ANY); // 监听本机所有网卡
servaddr.sin_port = htons(8000);              // 端口必须网络字节序
bind(sockfd, (struct sockaddr*)&servaddr, sizeof(servaddr));

4. 小结 #

  • 网络进程 = (IP, 协议, 端口)，socket 是应用层访问协议栈的接口。
  • 凡是写端口/地址进结构体，先 htons/htonl。
  • sockaddr_in 是 IPv4 实际用的结构，传给 API 时转成 sockaddr*。
