12 无线与其他网络基础 #

覆盖：WIFI 与 WLAN/无线网卡概念、802.11 协议族与术语（SSID/BSSID/AP/Station）、802.11 帧与 CSMA/CA、路由器与 OSI 七层模型及工作原理、ACL 访问控制列表（分类/规则/步长/配置示例）、VLAN 原理补充（为何分割广播域、Access/Trunk 端口对标签的处理）。

一、WIFI 与无线基础 #

  • WLAN（Wireless LAN）：利用射频（RF）技术传输数据的无线局域网络，弥补有线网络不足。使用 ISM 频段：802.11a 用 5GHz（最高 54Mbps），802.11b/g 用 2.4GHz（11/54Mbps）。
  • WIFI（Wireless Fidelity）：基于 IEEE 802.11 系列标准的无线联网技术品牌，由 Wi-Fi 联盟持有。WIFI 包含于 WLAN，是其中一种技术。
  • 无线网卡：终端连接无线网络的设备，按接口分 PCMCIA/PCI/MiniPCI/USB/CF-SD。自身只收发信号，须找到互联网出口才能上网。手机热点即便携 WLAN 热点，把 GPRS/3G/4G 信号转为 WIFI 发出。

802.11 协议演进：a(1999,5G,54M) / b(1999,2.4G,11M) / g(2003,2.4G,54M) / n(2009,2.4G&5G,600M)。802.11n 在 MAC 层改进：HT-40（双信道合并）、MIMO（多天线同 Channel 用 OFDM 互不干扰），大幅提升吞吐。

常见术语：

  • LAN/WAN/WLAN：有线局域网 / 广域网 / 无线局域网；
  • AP（Access Point）：无线接入点，站点借此与外部/内部通信；
  • Station：连入无线网络的设备；Associate：站点与 AP 关联入网；
  • SSID：无线网络名（给人看）；BSSID：BSS 标识（机器看，即 AP 的 MAC 地址格式）；
  • BSS：802.11 基本组件，基础结构型网络为 Station↔AP↔Station；DS（分布式系统）：AP 间转发帧的骨干（一般为以太网）。
  • Band/Channel/Channel Width：频段（2.4G/5G）/ 子信道 / 信道带宽（20M/40M，N 可合并两信道提速）。

无线网络相对有线缺点：需先建连、半双工、链路层出错/重传概率高、易被抓包、功耗大、吞吐偏低（n 已改善）。

二、802.11 帧与 CSMA/CA #

三类帧：

  • 管理帧：Beacon（AP 周期广播通告存在、含 SSID/Region/Power-Save 信息）、Probe（主动探寻）、Association/Authentication（建连与认证）；
  • 控制帧：RTS/CTS（预约信道、解决隐藏节点）、ACK（单播帧确认，本身无需再确认）；
  • 数据帧：承载业务数据，头部 DS 字段（To DS / From DS） 标识方向——To DS=1 表示 Station→AP（Upload），From DS=1 表示 AP→Station（Download）。无线帧有 4 个地址（SA/DA/TA/RA），比以太网多出发送/接收无线电地址。

CSMA/CA（冲突避免）：与以太网 CSMA/CD 相对。空闲后等 DIFS → 进入竞争窗口随机退避（Backoff Slot）→ 到自己的 Slot 才发送；发送方用帧中 Duration/NAV 字段声明"未来一段时间链路被占用"，其他 Station 在此期间退避，保证本次通信原子性。QoS 即靠更小退避 Slot 获得更高发送优先级。

无线安全：WEP（RC4，已淘汰）/ WPA（TKIP）/ WPA2（CCMP/AES，最强）。WPA2-Enterprise 用 802.1X/EAP+Radius；WPA2-Personal（PSK）家用无需验证服务器。

三、路由器与 OSI 七层模型 #

设备工作在第几层，看它利用哪一层的数据头部信息：

层 数据单位 典型设备/协议
物理层 bit 网卡、网线、集线器、中继器、调制解调器
数据链路层 frame 网桥、交换机（PPP、HDLC、STP、帧中继）
网络层 packet 路由器（IP、ARP、RIP、OSPF）
传输层及以上 segment+ 网关
  • 数据链路层解决同一网络内节点通信；网络层解决不同子网间通信（路由选择、寻址）。
  • 路由器本质是互联异种网的专用计算机（IP 网关），属"多穴主机"，每个端口一个 IP。主机靠寻址+路由把去往 Internet 的报文交给正确路由器；路由器靠路由表把报文发给下一跳。路由 = 目的地址(含掩码) + 下一跳。获取路由：静态配置 或 动态路由协议（RIP/EIGRP 用距离矢量，OSPF 用链路状态）。

相关概念：NAT/地址代理（见 07/10 篇）；PPP 验证有 PAP（明文、单向、仅协商时一次）和 CHAP（密文、双向、传输中随时验证）；防火墙分分包过滤（查地址/端口）与应用网关（查内容）；VPN 用 Internet 隧道技术（PPP 封装进 UDP）以低成本获得私有网服务。

四、ACL 访问控制列表 #

ACL（Access Control List）是一系列"报文匹配条件"规则的集合，类似报文过滤器（规则即滤芯）。可阻塞攻击报文、为不同报文提供差分服务、控制 Telnet/FTP 等，提升安全与可靠。

分类（按功能/编号范围）：

类型 可匹配项 编号
基本 ACL 仅源 IP、分片标记 2000–2999
高级 ACL 源/目的 IP、优先级、TOS、DSCP、协议、ICMP 类型、TCP/UDP 端口 3000–3999
二层 ACL 源/目的 MAC、以太帧协议类型 4000–4999
用户自定义 ACL 报文偏移位置/偏移量 5000–5999
用户 ACL IPv4 源/目的、UCL 组、协议、端口等 6000–9999

可为数字型（如 2000）或命名型（"名字+数字"，便于记忆识别）。

规则（rule）：含动作 deny|permit、规则编号、匹配选项（二/三/四层字段）。所有规则按编号从小到大排序，一旦命中即停止匹配。

步长（step）：系统自动分配规则编号时的相邻差值，默认 5（5、10、15…）。便于在已有规则间插入新规则（如 rule 10、15 间插 rule 11），避免重排代价。可 step 修改，display acl 查看。

配置示例（反掩码：0 表示精确匹配，1 表示忽略）：

text
rule 5  deny   source 1.1.1.1 0          # 禁止源 1.1.1.1
rule 10 deny   source 1.1.1.2 0          # 禁止源 1.1.1.2
rule 11 deny   source 1.1.1.3 0          # 插入规则，禁止 1.1.1.3
rule 15 permit source 1.1.1.0 0.0.0.255  # 允许 1.1.1.0/24 网段其余

五、VLAN 原理补充（为何分割广播域） #

VLAN（Virtual LAN，虚拟局域网）指用路由器分割出的广播域。二层交换机默认只能构建单一广播域，启用 VLAN 后可分割成多个广播域。

为何要分割？若不分割，单一广播域内任意主机通信都要先发 ARP 广播，交换机会 Flooding 到所有端口、所有主机，消耗带宽与 CPU。广播帧极频繁：ARP、DHCP（请求 IP）、RIP（每 30 秒广播路由）等。VLAN 通过限制广播域范围减少无用泛洪。

（与 08 篇呼应）VLAN 实操依赖 VID/PVID 与 Access/Trunk 端口：

  • Access 端口：一般归属单一 VLAN，发往端口的帧按 PVID 打/去标签，连接终端设备；
  • Trunk 端口：在交换机间承载多 VLAN 流量，对带标签的帧按 802.1Q 标签转发，仅对 Native VLAN 可能去标签；
  • 帧进入交换机时打上入端口 PVID 对应 VID，交换机内按 VLAN 隔离转发，出端口时按端口类型决定是否保留或剥离 802.1Q 标签。
