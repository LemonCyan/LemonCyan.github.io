网络协议栈基础（TCP/IP） #

整合自《Linux 网络协议栈开发基础篇》系列及《ping 命令执行过程详解》。本篇讲"数据怎么被分层封装、各层头里有什么、一次 ping 跨网段时包如何变化"，是理解后面二层和内核机制的前提。

1. TCP/IP 四层模型 #

层 代表协议 数据单位 核心职责
应用层 HTTP/DNS/DHCP/SMTP 报文 业务逻辑
传输层 TCP / UDP 段(segment) 端到端、端口复用
网络层 IP / ICMP / ARP 包(packet) 寻址、路由
链路层 Ethernet / PPP 帧(frame) 相邻节点交付

Socket 位于应用层与传输层之间，是应用访问协议栈的接口（见 01 篇）。

2. 关键报文头字段 #

以太网头（14B）：目的 MAC、源 MAC、类型（0x0800=IP，0x0806=ARP）。

IP 头（20B 固定）：

  • 版本、首部长度、TOS
  • 总长度、标识、标志/片偏移（分片用）
  • TTL（每跳 -1，防环路）、协议（6=TCP，17=UDP，1=ICMP）
  • 首部校验和、源 IP、目的 IP

TCP 头（20B 固定）：

  • 源端口、目的端口
  • 序号 seq（字节流编号）、确认号 ack（期望收到的下一字节）
  • 标志位 SYN / ACK / FIN / RST / PSH / URG
  • 窗口大小（流量控制）、校验和、紧急指针

UDP 头（8B）：源端口、目的端口、长度、校验和——极简，无连接无可靠。

ICMP 头：类型(type)、代码(code)、校验和；用于 ping（type 8=回显请求，0=回显应答）与差错报告（如 type 3 不可达、11 超时）。

3. TCP vs UDP #

TCP UDP
连接 面向连接（三次握手） 无连接
可靠 确认/重传/排序/流量控制 尽力交付，不可靠
速度 慢、开销大 快、开销小
边界 字节流（无消息边界） 数据报（保留边界）
场景 网页/文件/SSH 视频/语音/DNS/广播

4. TCP 核心机制 #

  • seq/ack：保证有序与可靠。每字节编序号，ack = 收到的 seq + 长度。
  • 滑动窗口：接收方用 窗口 字段通告还可接收的字节数，实现流量控制。
  • 拥塞控制：慢启动（指数增 cwnd）、拥塞避免（线性增）、快重传、快恢复——防止把网络压垮。
  • 三次握手/四次挥手细节见 03 篇；TIME_WAIT 持续 2MSL 以保证最后 ACK 到达、旧报文消散。

5. IP 与 ARP #

  • IP：无连接、尽最大努力交付，靠 TTL 防环，靠路由表转发。
  • ARP（地址解析协议）：把 IP → MAC。主机广播 ARP 请求，目标回 ARP 应答，结果缓存进 ARP 表（arp -n 查看）。
    • 免费 ARP：主机主动广播自己的 IP↔MAC 映射，用于检测 IP 冲突、通告 MAC 变更。
    • 代理 ARP：路由器代替目标子网主机应答 ARP，使跨子网通信像在同一网段。
    • 手动构造 ARP 请求见 03 篇 raw socket。

6. NAT 原理 #

NAT 解决 IPv4 地址不足，在网关上改写包的 IP 地址：

  • SNAT（源 NAT）：内网多机共享一个公网 IP 上网，改源地址，在 POSTROUTING 做。
  • DNAT（目的 NAT）：把公网 IP:端口映射到内网服务器，改目的地址，在 PREROUTING 做（须在路由前）。
  • NAPT/端口映射：连端口一起转换（Linux 完整支持，RFC3022）。
  • 公网地址动态（如 ADSL）用 MASQUERADE 自动伪装。
  • 连接跟踪（conntrack）：NAT 依赖 nf_conntrack 记录每条流的五元组与转换关系，反向包自动还原。

7. 一次数据传输的全过程（封装/解封装） #

发送方：应用数据 → 加 TCP 头 → 加 IP 头 → 加以太网头 → 发往链路。 接收方：剥以太网头 → 剥 IP 头 → 剥 TCP 头 → 交付应用。 每过一跳路由器只动 IP 层（查路由表改 MAC），TCP 端到端连接保持不变。

ping 跨网段示例：

  1. 主机发现目的 IP 不在本网，查路由表找到网关，先 ARP 解析网关 MAC（目的 MAC=网关）；
  2. IP 头目的 IP 不变、目的 MAC 改写为网关 MAC，发往网关；
  3. 网关路由转发，下一跳若仍跨网则再 ARP 解析下一跳 MAC，逐跳重写目的 MAC；
  4. 到达目的主机后，目的主机回 ICMP 应答，沿原路（或反向路由）返回，源/目的 IP 始终不变、MAC 逐跳变化。

关键：IP 层端到端不变，链路层 MAC 每跳重写；同网段则无需网关、直接 ARP 对端 MAC。
