文件服务器： 功能要求： 1 命令要用结构体 struct file_server { int cmd; char localfile[32]; char remotefile[32];} 2 过滤多余的空格 scanf( "%[^\n]" ,buf)------->获取标准输入直到遇到空格 3. 命令修改成 put file1 file2 将本地的file1 发送给对方，接收方把文件名命名为file2 get file1 file2 从远端接收文件file1，保存到本地，本地文件名是file2

UDP

socket （） SOCK_DGRAM // 数据报套接字 bind（） 指定ip地址，可以INADDR_ANY， port 如果想内核自动置顶，填写0， 客户端一般不用 客户端的端口号一般在connect的时候由OS自动给我们分配 listen tcp使用 accept tcp专用 connect udp：会影响到后续发送数据包时填写的对端ip地址和port号，会立刻返回 不会去尝试3次握手， 指定了对端的地址，后续就不可以用recvfrom/sendto 只能用send/recv read/write udp 可以多次调用connect更改对端的地址，对于tcp来说，只能调用一次 ssize_t sendto(int socket, void *message, size_t length, int flags, struct sockaddr *dest_addr, socklen_t dest_len); 功能：udp专用 参数： int socket void *message 发送的数据地址 size_t length 长度 int flags 0 struct sockaddr *dest_addr 对端的ip+port 自己填充 socklen_t dest_len dest_addr 长度

返回值： 发送字节的个数，出错-1 errno被置 ssize_t recvfrom(int socket, void *buffer, size_t length, int flags, struct sockaddr *address, socklen_t *address_len); 功能：udp专用 参数： int socket void *buffer 接收的数据要存放的地址 size_t length 缓冲区的长度，最多接收多少数据 int flags 0 struct sockaddr *address 对端的ip+port 会自动填充到这个位置 socklen_t dest_len dest_addr 长度 tcp udp server client server client socket bind listen accept connect read/write send/recv sendto/recvfrom sendmsg、recvmsg close/shutdown
