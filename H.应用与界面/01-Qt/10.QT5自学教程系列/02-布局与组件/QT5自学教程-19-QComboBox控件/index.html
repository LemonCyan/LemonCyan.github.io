A：ComboBox也就是组合框，组合框和列表框的功能类似,但使用更为灵活,更为常用。实际上,组合框是由一个文本框和一个列表框组成的,组合框又被称为弹出式菜单。用户使用时,单击文本框右侧的三角即可表。

在这一节将介绍QListWidget的内容，首先依旧是简单阐述新的名词。

A：QListWidget类提供了一个基于项的列表控件。QListWidget是一个便捷的类，它提供了类似于由QListView支持的一个列表视图，但采用了经典的基于项目的界面用于添加和删除项。 QListWidget使用内部模型来管理列表中每个QListWidgetItem。

cpp
在了解了这些知识之后就给出今天的例子。今天的例子的作用是改变QListWidget中项的颜色。
#include "ui_dialog.h"
ui(new Ui::Dialog)
{
ui->setupUi(this);
//在QListWidget当中添加选项
for(int i = 0;i != 10;++i)
{
ui->listWidget->addItem(QString::number(i) + " item");
}
Dialog::~Dialog()
{
delete ui;
}
void Dialog::on_pushButton_clicked()
{
//设置当前选中项的属性
QListWidgetItem *item = ui->listWidget->currentItem();
item->setTextColor(Qt::red); //设置当前选中项文字的颜色
}
