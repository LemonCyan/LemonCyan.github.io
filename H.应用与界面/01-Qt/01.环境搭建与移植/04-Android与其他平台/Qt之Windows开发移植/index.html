在开发机上调试运行 Qt 项目通常非常顺利，然而一旦进入交付阶段，将 .exe 复制到没有安装 Qt 开发环境的普通用户电脑（俗称“裸机”）上运行，往往会引发各种无法启动或视觉失效的报错。

本文总结了在 Windows 平台打包移植 Qt 应用程序时的三大经典常见问题，并提供高效的解决方案。

常见问题一：移植后界面全部回退为英文 (QM 翻译文件缺失) #

1. 现象描述 #

在开发环境中明明正确汉化了中文，但在裸机上运行安装包后，所有的标准对话框按钮（如 OK / Cancel）以及自定义控件标签全部显示为英文。

2. 根本原因 #

国际化翻译是由对应的编译二进制 .qm 翻译文件控制的。如果在发布时忘记携带 *_zh.qm 或系统专用的 qt_zh_CN.qm 文件，Qt 引擎便无法汉化内容，从而回退为默认的英文。

3. 解决办法 #

  • 方案 A（分包打包）：将生成的 *.qm 翻译文件随可执行程序放到同一级目录下进行分发。
  • 方案 B（内嵌资源，推荐）：为了避免散落文件丢失，直接在 *.qrc 资源配置文件中将 .qm 作为内置资源打包：
    xml
    <qresource prefix="/translations">
    <file>my_app_zh.qm</file>
    <file>qt_zh_CN.qm</file>
</qresource>
    并在 main.cpp 中使用资源路径加载：
    cpp
    QTranslator translator;
translator.load(":/translations/my_app_zh.qm");
app.installTranslator(&translator);

常见问题二：提示“应用程序并行配置不正确”或“配置不正确” #

1. 现象描述 #

双击可执行文件，Windows 直接弹出系统报错：

“由于应用程序配置不正确，应用程序未能启动。重新安装应用程序可能会纠正这个问题。” 或者提示“并行配置不正确”。

2. 根本原因 #

这是因为该程序由 Visual Studio 编译器（MSVC）编译输出，而目标裸机上缺少对应的 C++ 运行时库 (MSVC Redistributable)。

3. 解决办法 #

  • 方案 A（拷贝运行时目录，适合快捷调试）： 直接去开发机 VS 的安装路径下拷贝所需的共享库子文件夹（包含 Microsoft.VCxx.CRT.manifest 和 msvcrxx.dll、msvcpxx.dll），将其粘贴到 .exe 的同一级目录下：
    • Debug版本路径参考：D:\SoftWare\Microsoft Visual Studio 9.0\VC\redist\Debug_NonRedist\x86\Microsoft.VC90.DebugCRT
    • Release版本路径参考：D:\SoftWare\Microsoft Visual Studio 9.0\VC\redist\x86\Microsoft.VC90.CRT
  • 方案 B（安装 Redist 包，生产推荐）： 在安装包脚本（如 NSIS 或 Inno Setup）中，静默打包安装微软官方对应的运行时库安装器（如 vcredist_x86.exe 或 vcredist_x64.exe）。

常见问题三：安装到系统盘后无法运行 (需要管理员权限) #

1. 现象描述 #

应用程序在开发目录可以完美打开，但通过安装包部署到 C:\Program Files\ 目录下后，双击程序无响应，或者部分写配置文件、写数据库功能瘫痪。但如果右键点击选择 “以管理员身份运行” 即可恢复正常。

2. 根本原因 #

Windows 自 Vista 时代起引入了严格的 UAC（用户账户控制）权限机制，默认情况下，普通权限的软件禁止直接擦写系统关键目录或注册表。

3. 解决办法 #

通过配置生成清单文件，强制让程序在启动时向操作系统申请管理员特权（弹出 UAC 提权盾牌提示）。

方式 A：如果使用 Visual Studio 编译集成 #

  1. 右键 VS 项目工程 -> 选择 属性。
  2. 展开左侧 链接器 -> 选择 清单文件。
  3. 将右侧的 UAC 执行级别 修改为：requireAdministrator。

方式 B：如果使用 Qt Creator (qmake) 构建 .pro 文件 #

在 Windows 平台下，可以在 .pro 文件中追加底层的链接器控制命令（限 MSVC 编译器）：

win32-msvc* {
    # 强制注入提权清单标志
    QMAKE_LFLAGS += /MANIFESTUAC:\"level=\'requireAdministrator\'\"
}

(注意：若使用 MinGW 编译，则需要通过自定义 .rc 资源文件或单独编写扩展清单 .manifest 文件以注入提权指示。)
