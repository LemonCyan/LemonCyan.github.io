本篇讲什么：集成学习这条线的完整知识。从「为什么要把多个模型拼起来」讲到 Bagging、随机森林、Boosting、AdaBoost、GBDT，再落到工程里真正在跑的 XGBoost 和 LightGBM。

本篇不讲什么：不重推 CART 的分裂增益公式，不展开 stacking 的工程实现，不做各框架的源码逐行剖析。

跨篇指路：决策树怎么长、怎么剪，看决策树原理那几篇；损失函数与正则化的通用讨论，看正则化那篇；本篇只回答一个问题——多个模型怎么拼成一个。

一、集成学习是什么 #

单个模型的能力有上限。一棵决策树切出来的边界是锯齿状的，换个随机种子就换一棵树；一个线性模型的表达能力又压不住非线性的关系。集成学习的做法很直接：不只训一个，训一群，再把它们的输出合起来。

合起来为什么比单个好？因为每个模型的错误不完全一样。模型 A 在样本 x 上错了，模型 B 在同一个点上往往不错。让它们投票，错的票被对的票压过去，最终结果就比任何一个单独模型都稳。前提是错误不同——如果所有模型都在同一个地方错，投票也救不回来。这条前提就是「个体学习器要足够多样」，它是整套方法的地基。

集成学习本身不是一个单独的机器学习算法，而是「构建并组合多个学习器来完成学习任务」这一整类方法。分类问题可以集成，回归问题可以集成，特征选取可以集成，异常点检测也可以集成。机器学习里几乎每个方向都能看到它的身影。

用一句话概括它的野心：用多个弱模型拼出一个强模型。弱不是贬义，指的是「比随机猜好一点点」的那种模型。单看输得很惨，凑够数量、凑够多样性，合起来就能打赢一个精雕细琢的强模型。

两个要解决的问题 #

整套框架拆开只有两件事：

  1. 怎么得到若干个个体学习器；
  2. 怎么选一种结合策略，把这些个体学习器合成一个强学习器。

第一个问题决定多样性从哪来。可以是不同的训练子集（Bagging 的路子），可以是不同的样本权重（Boosting 的路子），可以是不同的特征子空间（随机森林加的那一手），也可以是不同种类的模型（stacking 的路子）。

第二个问题决定怎么合并。回归用平均，分类用投票，复杂一点就再套一层学习器。

下面这张图（文字版）把流程说清楚：

text
训练集 ──┬─> 采样/加权/选特征 ──> 个体学习器 h1 ─┐
         ├─> 采样/加权/选特征 ──> 个体学习器 h2 ─┼─> 结合策略 ──> 强学习器
         └─> 采样/加权/选特征 ──> 个体学习器 hT ─┘

注意中间那一列「采样/加权/选特征」——它才是制造差异的地方。同一个训练集、同一个算法、同一个超参，不加任何扰动训出来的一群模型长得一模一样，组合起来等于没组合。集成学习的全部技巧，都花在「怎么让 h1 到 hT 不一样」上。

一个必须建立的直觉 #

假设有 T 个个体学习器，每个的错误率是 ε，且错误之间相互独立。简单多数投票的错误率是：

$P_{err} = \sum_{k > T/2}^{T} \binom{T}{k} \varepsilon^k (1-\varepsilon)^{T-k}$

T 越大，这个值往 0 掉得越快。T=1 时是 ε，T=25、ε=0.3 时已经掉到很小的量级。

但「错误相互独立」是强假设，现实中做不到。个体学习器都是在同一份数据上训出来的，错误天然正相关。相关性越高，投票带来的收益越小；相关性趋近 1，收益归零。

这就是为什么所有集成方法都在拼命制造多样性，也是为什么「个体学习器要足够多样」这句话要反复强调——它是公式里唯一能让错误率往下掉的变量。

和单个模型的关系 #

有一类误读：以为集成学习能凭空造出信息。不能。它做的是「把已有信息里的信号稳定地压出来」，靠的是平均掉噪声。

所以两个推论：

  • 基学习器太弱（比如全是线性模型去拟合强非线性），再怎么集成也拧不出非线性边界。基学习器要有能力捕捉到信号，集成才有东西可压。
  • 基学习器太强且高度相关（比如全用同一份数据训的深树），集成收益会被相关性吃掉。要么降相关，要么换更强的扰动。

二、个体学习器与结合策略 #

同质与异质 #

得到个体学习器有两条路。

第一条，所有个体学习器是同一种类，叫同质。比如全是决策树，或者全是神经网络。

第二条，个体学习器不全是一个种类，叫异质。比如一个分类问题，用支持向量机、逻辑回归、朴素贝叶斯各训一个，再按某种策略合成最终结果。

同质是目前用得最多的形态，说到「集成学习」多半指的就是它。同质个体学习器最常选的两个底座是 CART 决策树和神经网络。选决策树的原因很实在：它本身就是不稳定的学习器，训练数据稍微一动，树的结构就变，天然适合被扰动；而且它好解释、好调。

异质集成在竞赛里见得多，工业上少。原因是维护成本——三个不同框架的模型，序列化、版本、推理延迟都要分别处理。除非单模型的瓶颈已经很明显，否则不值得。

按依赖关系分成两类 #

同质个体学习器再往下分，看个体学习器之间有没有强依赖：

类型 依赖关系 生成方式 代表算法 主要作用
Boosting 族 有强依赖 串行，后一个依赖前一个 AdaBoost、GBDT、XGBoost、LightGBM 降偏差
Bagging 族 无强依赖 并行，各自独立 Bagging、随机森林 降方差

这个分类不是学术上的洁癖，它直接决定了后面所有工程选择：能不能并行、调参往哪个方向走、基学习器该深该浅。第三章会把这条线彻底讲透。

结合策略：平均法 #

假定已经拿到 T 个弱学习器 {h1, h2, ..., hT}。回归这类数值输出的问题，用平均法。

算术平均，最朴素的一种：

$H(x) = \frac{1}{T}\sum_{i=1}^{T} h_i(x)$

如果每个个体学习器有个权重 ωi，就是加权平均：

$H(x) = \sum_{i=1}^{T} \omega_i h_i(x)$

权重满足约束：

$\sum_{i=1}^{T}\omega_i = 1,\quad \omega_i \geq 0$

权重怎么定？看个体学习器的可靠程度，误差小的给大权重。这件事在 AdaBoost 里会被推成一个闭式解（第七章），在 stacking 里会被学出来。

算术平均是加权平均在 ωi 全相等时的特例。实践中先跑算术平均当基线，再试加权，多数时候差距不大——除非各基学习器的质量差异明显。

结合策略：投票法 #

分类问题的输出是类别，不能求平均，用投票。假定类别集合是 {c1, c2, ..., ck}，T 个弱学习器对样本 x 的预测是 {h1(x), h2(x), ..., hT(x)}。

相对多数投票法：少数服从多数。T 个预测里出现次数最多的类别 ci 就是最终类别。如果不止一个类别并列最高票，随机挑一个。

绝对多数投票法：不光要求票数最高，还要求票数过半。不过半就拒绝预测。

拒绝预测这个能力在风控、医疗这类场景有实际价值——模型说「我不确定」，比硬给一个答案强。代价是覆盖率下降，落地时要额外设计兜底逻辑。

加权投票法：和加权平均一个思路，每个弱学习器的票数乘一个权重，各类别的加权票数求和，最大的那个类别胜出。

三种投票法的差别只在「怎么算赢」。相对多数最常用，因为它永远给得出答案；绝对多数适合对误判代价敏感的场景；加权投票在基学习器水平参差时才有意义，水平齐平的话权重全是 1/T，退化成相对多数。

结合策略：学习法 #

上面几种都是对弱学习器的结果做固定的逻辑处理——平均、投票，规则写死。误差偏大。

学习法换了个思路：不写死规则，再训一个模型来学怎么组合。代表是 stacking。

做法分两层：

  1. 用训练集训出 T 个弱学习器，把它们对训练集的预测结果拼成新的特征矩阵；
  2. 用这个新特征矩阵当输入，原始标签当输出，训一个次级学习器。

这一层里，原来的弱学习器叫初级学习器，用来结合的那个叫次级学习器。

预测时分两次：先用初级学习器对测试样本预测一次，得到次级学习器的输入；再用次级学习器预测一次，得到最终结果。

stacking 有个必须处理好的细节：初级学习器的输出如果是在训练集上「自己预测自己」，会有严重的信息泄漏，次级学习器学到的是过拟合后的假信号。所以工程上用 K 折的方式生成次级训练集——每一折的预测由没在该折上训练过的模型给出。这个细节不做，stacking 的效果会比单模型还差。

结合策略 适用问题 关键输入 复杂度
算术平均 回归 各学习器输出值 低
加权平均 回归 输出值 + 权重 低
相对多数投票 多分类 各学习器类别 低
绝对多数投票 多分类 类别 + 过半门槛 低
加权投票 多分类 类别 + 权重 低
stacking 分类/回归 输出值 + 一层新模型 高

先用简单策略，简单策略压不住再上学习法。这是调参之外的顺序问题，顺序反了会白花很多时间。

三、偏差与方差：两条路线 #

这一章是整篇的理论骨架。把偏差和方差拆清楚，后面 Bagging 与 Boosting 的所有差别都能一句话推出来。

误差从哪来 #

模型在测试集上的期望误差可以分解成三块：

E[(y−f^​(x))2]=Bias2[f^​(x)]+Var[f^​(x)]+σ2
项 含义 来源
偏差平方 模型的平均预测与真实值的偏离 模型假设太简单，表达力不够
方差 模型预测随训练集变化的波动幅度 模型对数据太敏感，记住了噪声
不可约误差 数据本身的噪声 任何模型都消不掉

第三项 σ² 是数据的下限，调模型动不了它。能动的只有前两项。

两种失败形态 #

高偏差：模型在训练集上就差。线性模型去拟合一个环形边界，怎么训都欠拟合。加大数据量没用，模型压根没有那个表达力。

高方差：模型在训练集上很好，测试集上崩。一棵不限深度的决策树，每个叶子一个样本，训练集准确率 100%，换个样本集结构就全变。这类模型的预测方差大——同样的分布，重采一次样，训出来的函数能差很远。

这两类失败对应两种解法，而集成学习刚好各有一条路线。

两条路线的核心区分 #

Bagging 主要降方差。

并行训练多个模型，对输出取平均。设每个模型的方差是 σ²，两两相关系数是 ρ，平均后整体方差是：

ρσ2+T1−ρ​σ2

T 增大，第二项趋近 0，但第一项 ρσ² 留下来。所以：平均这个动作本身能把方差压到原来的 1/T 量级（在 ρ=0 的理想情况）；但相关性 ρ 是地板，压不下去；想让 ρ 变小，就得在「造基学习器」时加扰动——这就是 Bagging 采样和随机森林特征采样的全部动机。

再看偏差。平均 T 个模型的输出，如果每个模型的偏差都是 b，平均后的偏差还是 b。Bagging 对偏差几乎无改善。所以它必须用高方差、低偏差的基学习器——深决策树。

Boosting 主要降偏差。串行训练，每个新模型专门修正前一个模型的错误。本质是在函数空间里做梯度下降，每一轮往「损失更小的方向」走一步。走 T 步，偏差被逐步削掉。

方差呢？Boosting 用简单弱学习器（浅树、树桩），单个模型的方差本来就小，加权求和后方差涨一点，但整体仍在可控范围。所以它不需要靠平均降方差。

现在回答那个经典疑问：为什么随机森林调深树，而 GBDT 调浅树？

随机森林靠平均降方差，基学习器越深、方差越大，被平均掉的空间就越大。把树剪浅了，每棵树本身偏差就上去了，而随机森林没有降偏差的机制，最后整体偏差高、方差低——两头不讨好。所以随机森林里 max_depth 常常不设限或设很大，让树长到接近纯。

GBDT 每一轮是在前一轮的残差上再拟合一次。单棵树的任务是「补一小步」，补得太猛就过拟合。树深了，它会把当前残差里的噪声也学进去，下一轮又在噪声上继续拟合，误差累积。所以 GBDT 的树限在 3 到 8 层，甚至用深度 1 的树桩。

一句话：随机森林要的是「每棵树都很强但各不相同」，GBDT 要的是「每棵树都很弱但方向都对」。

一个常见的组合 #

两条路线不互斥。可以先用 Boosting 降偏差，再用 Bagging 降方差；也可以在随机森林的叶子上挂一个线性模型。工程上更常见的做法是：先用 GBDT 拿到一个低偏差的基线，如果发现验证集和训练集差距大，再上 bagging 风格的子采样（GBDT 的 subsample 参数就是干这个的）压方差。

四、Bagging 与随机森林 #

Bagging 的机制 #

Bagging 的弱学习器之间没有依赖，可以并行生成。

对训练集做 T 次随机采样，得到 T 个采样集。每个采样集独立训一个弱学习器，最后用结合策略合成。

这里的采样是自助采样（bootstrap sampling）：原始训练集有 m 个样本，每次从里面随机抽一个样本放进采样集、抽完放回，重复 m 次，得到一个 m 样本的采样集。

放回这个动作很关键。某个样本在 m 次抽样里一次都没被抽中的概率是：

$\left(1 - \frac{1}{m}\right)^m \approx \frac{1}{e} \approx 0.368$

也就是说，每个采样集大约只覆盖原始数据的 63.2%，剩下 36.8% 是「袋外样本」（out-of-bag，OOB）。这不是浪费——OOB 样本天然构成了一个免费的验证集，可以用来估泛化误差，不用额外切分。这正是 Bagging 比交叉验证讨巧的地方：每棵树都有一批自己没见过、但别人见过的样本，把这些样本的预测汇总，就是一个几乎不花额外成本的验证估计。

从 Bagging 到随机森林 #

随机森林是 Bagging 的特化进阶版。两个词要拆开看：

特化：随机森林的弱学习器全都是决策树。不换别的模型。

进阶：在 Bagging 的样本随机采样之外，再加一层特征随机采样。

具体做法是：在每个节点做分裂时，不是从全部 n 个特征里挑最优，而是先随机抽一个大小为 max_features 的子集，只在这个子集里挑最优分裂点。

这就是随机森林的两个随机性：

随机性 在哪一层 作用
样本采样 每棵树的训练集 让每棵树看到不同的数据
特征采样 每个节点的分裂候选 让每棵树在同一份数据上也不走同一条路

为什么两个随机性就能降方差 #

回到方差公式：

ρσ2+T1−ρ​σ2

Bagging 的样本采样让每棵树的数据不同，能压低一部分相关性。但有个漏洞：如果数据里存在一个特别强的特征，那么不管怎么采样，每棵树都会优先在这个特征上分裂。树和树的结构就长得极像，ρ 依然很高，平均掉的部分有限。

特征采样补上了这个漏洞。强特征在某些节点压根没进候选集，树只能找次优特征，结构被迫分化。ρ 掉下来，方差公式里那个地板降低。

代价是每棵树变弱了——不能用上所有特征，单棵树的偏差略微上升。但随机森林降的是方差，偏差的小幅上升换方差的大幅下降，总体误差还是降。

这也解释了一个现象：随机森林的特征重要性估计会比单棵树更稳。单棵树的「最重要特征」往往只是采样噪声的产物，几百棵树统计下来，真信号才会浮出来。

和单棵树、和纯 Bagging 的差别 #

对比对象 差别
单棵决策树 方差极大，换样本就换结构；随机森林用平均把方差压下去，且几乎不需要剪枝
纯 Bagging（只有样本采样） 强特征会导致树高度相关，ρ 压不下来；随机森林加特征采样再降一层 ρ

随机森林另一个实际优势：它对超参不敏感。n_estimators 从 100 加到 500 只是变慢一点、效果略好，不会崩。这决定了它常常是「拿到数据先跑一下」的基线模型。

max_features 是随机森林里最值得动手的那个。它直接控制两棵树的差异度：

  • 调小 → 树之间差异大 → ρ 低 → 方差低，但单棵树更弱；
  • 调大 → 每棵树更强 → 但树之间更像 → ρ 高 → 平均的收益变小。

实践中从 sqrt(n) 附近开始往两边试，这是唯一一条不能靠默认值蒙过去的线。

随机森林的一个手写视角 #

用 sklearn 跑起来只有三行，但要理解它在干什么，可以看这段等价的手工流程：

python
import numpy as np
from sklearn.tree import DecisionTreeClassifier

def bootstrap_sample(X, y, rng):
    m = X.shape[0]
    idx = rng.integers(0, m, size=m)   # 有放回抽样
    return X[idx], y[idx]

def random_forest_fit(X, y, n_trees=100, max_features=None, seed=0):
    rng = np.random.default_rng(seed)
    n_features = X.shape[1]
    if max_features is None:
        max_features = int(np.sqrt(n_features))
    forest = []
    for _ in range(n_trees):
        Xb, yb = bootstrap_sample(X, y, rng)
        tree = DecisionTreeClassifier(max_features=max_features, random_state=int(rng.integers(1 << 31)))
        tree.fit(Xb, yb)
        forest.append(tree)
    return forest

def random_forest_predict(forest, X):
    # 分类：让所有树投票，取众数；回归：取均值
    preds = np.stack([t.predict(X) for t in forest], axis=0)
    return np.array([np.bincount(preds[:, i]).argmax() for i in range(X.shape[0])])

这段代码只是把机制摊开，生产上不要用——sklearn 的 RandomForestClassifier 在并行、缓存、分裂搜索上都做了大量优化，手写版本慢一个数量级。

看清两件事就够了：bootstrap_sample 制造第一个随机性，max_features 制造第二个随机性。这两个随机性是随机森林的全部秘密。

五、Boosting 的基本思想 #

Boosting 是把「弱学习算法」提升为「强学习算法」的过程。老话讲三个臭皮匠顶个诸葛亮——先找一个容易找到的弱学习器（比随机猜好一点就行），反复学，得到一系列弱分类器，再把它们组合成一个强分类器。

两个组成部分 #

Boosting 有两个必须说清的部分：加法模型和前向分步算法。

加法模型是说，强分类器由一系列弱分类器线性相加而成：

$f(x;P) = \sum_{k=1}^{K}\beta_k h(x;\gamma_k)$

其中 h(x; γk) 是一个个弱分类器，γk 是第 k 个弱分类器学到的最优参数，βk 是它在强分类器里占的比重，P 是所有 γk 和 βk 的组合。

前向分步是说，训练过程里下一轮的分类器是在上一轮的基础上接着训出来的：

$f_k(x) = f_{k-1}(x) + \beta_k h_k(x;\gamma_k)$

这两条合起来的意思：不是一次性优化 K 个模型，而是一轮加一个，每轮只优化当前这一个的参数。

为什么这么设计？因为联合优化 K 个模型太难，而每一轮只优化一个模型是可行的。这个「贪心」的做法牺牲了全局最优性，换来了可解性。事后看，它其实等价于在函数空间里做梯度下降——第十一章会展开。

损失函数不同，Boosting 就分家。AdaBoost 是损失函数取指数损失的 Boosting，GBDT 是损失函数取任意可微损失的 Boosting。这是两大家族的分岔点。

工作机制 #

用初始权重 D(1) 训出第一个弱学习器，看它的误差率更新样本权重——误差率高的样本权重变大，第二个弱学习器就会更关注它们。重复到弱学习器数量达到预设的 T，再把它们按结合策略整合成强学习器。抽象成图：

text
D(1) ─> 弱学习器 h1 ─┐
                     ├─> 计算误差 e1 ─> 更新权重 D(2)
D(2) ─> 弱学习器 h2 ─┤
                     ├─> 计算误差 e2 ─> 更新权重 D(3)
        ...          │
D(T) ─> 弱学习器 hT ─┘
                     └─> 加权组合 ─> 强学习器

注意箭头的方向——每一条都指回权重。串行不是设计偏好，是逻辑必然：第二个模型必须知道第一个模型错在哪，才知道该往哪使劲。

四个必须回答的问题 #

只要是 Boosting 家族的算法，都要解决这四个问题：

问题 问的是什么
怎么算分类误差率 e 当前弱学习器在当前权重下错得有多严重
怎么定弱学习器权重 α 这个弱学习器在最终组合里该有多大话语权
怎么更新样本权重 D 下一轮该更关注哪些样本
用什么结合策略 最后怎么把 T 个弱学习器合成一个

AdaBoost 给了一套基于指数损失的具体答案（第六章、第七章）。GBDT 换了另一套——用负梯度拟合，样本不分权重而是拟合残差（第九章）。

这四个问题是理解整个 Boosting 家族的钥匙。读任何新变种，先找它的这四个答案。

六、AdaBoost 的算法流程 #

AdaBoost 是 Boosting 里最著名的算法之一，既能分类也能回归。

记号约定 #

训练集：

$T = {(x_1, y_1), (x_2, y_2), \ldots, (x_m, y_m)}$

第 k 个弱学习器对应的样本权重系数：

$D(k) = (w_{k1}, w_{k2}, \ldots, w_{km}), \quad \sum_{i=1}^{m} w_{ki} = 1, \quad w_{1i} = \frac{1}{m}$

初始权重全相等，都是 1/m。这一假设的意思是：第一个弱学习器训练时，每个样本的作用相同。没有先验信息时这是唯一合理的选择。

二元分类的四个答案 #

误差率：设输出为 {-1, +1}，第 k 个弱分类器 Gk(x) 在训练集上的分类误差率是

$e_k = P(G_k(x_i) \neq y_i) = \sum_{i=1}^{m} w_{ki} I(G_k(x_i) \neq y_i)$

注意这不是简单数错几个——是按权重求和。权重大的样本错一个，顶权重小的错十个。

弱学习器权重系数：

αk​=21​logek​1−ek​​

这个式子的行为：ek 越大，αk 越小。误差率小的弱分类器权重大，误差率大的权重小。ek = 0.5 时（和瞎猜一样）αk = 0，这个学习器完全不起作用。ek > 0.5 时 αk < 0，意味着它反着投票反而更好——实践中遇到这种情况一般直接丢弃。

这个公式不是拍脑袋定的，第七章会从指数损失推出来。

样本权重更新：

$w_{k+1,i} = \frac{w_{ki}}{Z_k}\exp\left(-\alpha_k y_i G_k(x_i)\right)$

规范化因子：

$Z_k = \sum_{i=1}^{m} w_{ki}\exp\left(-\alpha_k y_i G_k(x_i)\right)$

看指数里的符号。如果第 i 个样本分错了，y_i G_k(x_i) < 0，负负得正，exp 的值大于 1，权重变大。分对了，y_i G_k(x_i) > 0，exp 的值小于 1，权重变小。

这就是「错分的样本权重加大」的完整机制：不改变训练集数据本身，只改每个样本的权重，让同一份数据在不同弱分类器眼里呈现不同的重要性。下一轮训练会更关注上一轮错掉的那些点。

结合策略：加权平均，取符号

$f(x) = \text{sign}\left(\sum_{k=1}^{K}\alpha_k G_k(x)\right)$

αk 表示弱分类器 Gk(x) 的重要性。这里所有 α 之和并不为 1——不需要，因为最后只取符号。f(x) 的符号决定类别，f(x) 的绝对值表示分类的置信度。

二元分类完整流程 #

把四个答案按执行顺序串起来，就是完整算法。

输入：样本集 T，输出为 {-1, +1}，弱分类器算法，弱分类器迭代次数 K。 输出：最终的强分类器 f(x)。

  1. 初始化样本集权重 D(1)，每个 w_1i = 1/m。
  2. 对 k = 1, 2, ..., K 依次执行：
    • a) 用带权重 Dk 的样本集训练，得到弱分类器 Gk(x)；
    • b) 算分类误差率 ek（按权重求和的错分率）；
    • c) 算弱分类器系数 αk；
    • d) 更新样本权重分布，得到 D(k+1)，用 Zk 归一化。
  3. 构建最终分类器 f(x) = sign(Σ αk Gk(x))。

公式都在上一节给过了，这里只强调顺序：先训模型，再算误差，用误差定系数，用系数改权重。四步的顺序不能换——αk 依赖 ek，D(k+1) 依赖 αk。

从二元到多元：SAMME #

多元分类的原理和二元类似，主要区别在弱分类器的系数上。以 AdaBoost SAMME 为例：

$\alpha_k = \frac{1}{2}\log\frac{1-e_k}{e_k} + \log(R-1)$

其中 R 是类别数。R = 2 时，log(R-1) = log 1 = 0，退化成二元分类的公式。这个设计保证多分类公式在二分类时和前面一致——是个自洽的扩展，不是另起一套。

多出来的 log(R-1) 项在干什么？R 越大，随机猜对的概率越低（1/R），一项弱分类器只要比 1/R 好就有价值。log(R-1) 就是把这个「随机基线变了」的事实吸收进系数里。

回归流程：AdaBoost R2 #

AdaBoost 的回归问题有很多变种，这里以 AdaBoost R2 为准。

回归没有「分对分错」这个概念，误差是连续的。所以要先定义一个相对的误差度量。

最大误差：

$E_k = \max|y_i - G_k(x_i)|, \quad i = 1, 2, \ldots, m$

每个样本的相对误差，按误差损失的类型分三种：

$e_{ki} = \frac{|y_i - G_k(x_i)|}{E_k} \quad \text{（线性）}$

$e_{ki} = \frac{(y_i - G_k(x_i))^2}{E_k^2} \quad \text{（平方）}$

$e_{ki} = 1 - \exp\left(\frac{-|y_i - G_k(x_i)|}{E_k}\right) \quad \text{（指数）}$

除以最大误差是为了归一化，让不同轮次的误差可比。

回归误差率：

$e_k = \sum_{i=1}^{m} w_{ki} e_{ki}$

弱学习器系数，注意这里和分类是反的：

$\alpha_k = \frac{e_k}{1 - e_k}$

分类里 ek 越小 αk 越大，回归里 ek 越小 αk 越小。别被这个符号绕进去——回归这边 αk 在权重更新时是指数底数，作用方向不同。

样本权重更新：

$w_{k+1,i} = \frac{w_{ki}}{Z_k}\alpha_k^{1 - e_{ki}}$

规范化因子：

$Z_k = \sum_{i=1}^{m} w_{ki}\alpha_k^{1 - e_{ki}}$

看指数 1 - eki。误差 ek i 小的样本，指数接近 1，权重乘上 αk 的一次方；误差大的样本，指数接近 0，权重乘上 αk 的零次方即 1。由于 αk < 1，误差小的样本权重反而缩小了，误差大的样本权重相对变大——方向还是「更关注错得多的样本」，和分类一致，只是通道不同。

结合策略：回归不能用投票，也不直接加权平均，而是取加权中位数：

f(x)=∑k=1K​(lnαk​1​)g(x)

其中 g(x) 是所有 αk Gk(x)（k = 1, 2, ..., K）的中位数。

为什么用中位数不用平均？因为回归的弱学习器会有离群输出，平均值会被一个离谱的预测拖走，中位数稳健。这是 AdaBoost R2 相对分类版本的一个实质改动，不是形式上的对称。

七、AdaBoost 的损失函数与权重更新 #

上一章给了弱学习器权重公式和样本权重更新公式，但没解释为什么是这两个式子。看起来像魔法公式。其实它们能从 AdaBoost 的损失函数完整推出来。

换个角度看 AdaBoost #

从优化角度讲，AdaBoost 是这样一个问题：模型是加法模型，学习算法是前向分步学习算法，损失函数是指数函数。

三条都摆出来之后，整套流程就是这三条的直接推论。

加法模型好理解——最终强分类器是若干个弱分类器加权平均得到的。

前向分步也好理解——一轮轮学，用前一个弱学习器的结果去更新后一个的训练集权重。写出来，第 k-1 轮的强学习器是

$f_{k-1}(x) = \sum_{i=1}^{k-1}\alpha_i G_i(x)$

第 k 轮是

$f_k(x) = \sum_{i=1}^{k}\alpha_i G_i(x)$

两式一比：

$f_k(x) = f_{k-1}(x) + \alpha_k G_k(x)$

强学习器确实是一步步前向加出来的。

指数损失与推导 #

AdaBoost 的损失函数是指数函数：

$loss = \sum_{i=1}^{m}\exp\left(-y_i f_k(x_i)\right)$

代入前向分步的关系 f_k = f_{k-1} + αk Gk：

$loss = \sum_{i=1}^{m}\exp\left[-y_i\left(f_{k-1}(x_i) + \alpha_k G_k(x_i)\right)\right]$

假设已经过了 k-1 次迭代，f_{k-1}(x) 是已知的、固定的。令 w'ki = exp(-y_i f_{k-1}(x_i))。这个 w'ki 只依赖 f_{k-1}，在当前轮里是常数。代进去：

$loss = \sum_{i=1}^{m} w'_{ki}\exp\left[-y_i \alpha_k G_k(x_i)\right]$

把样本分成「分对的」和「分错的」两组。分对时 y_i G_k(x_i) = 1，分错时是 -1，指数项只剩 ±αk：

$loss = \sum_{y_i = G_k(x_i)} w'{ki}\exp(-\alpha_k) + \sum{y_i \neq G_k(x_i)} w'_{ki}\exp(\alpha_k)$

把 exp(-αk) 提成公因子重排：

loss=(eαk​−e−αk​)i=1∑m​wki′​I(yi​=Gk​(xi​))+e−αk​i=1∑m​wki′​

对 αk 求导并令其为零：

∂αk​∂loss​=(eαk​+e−αk​)i∑​wki′​I(yi​=Gk​(xi​))−e−αk​i∑​wki′​=0

两边同乘 e^{αk} 整理：

$\left(e^{2\alpha_k} + 1\right)\sum_{i} w'{ki} I(y_i \neq G_k(x_i)) = \sum{i} w'_{ki}$

解出：

$e^{2\alpha_k} = \frac{\sum_i w'{ki}}{\sum_i w'{ki} I(y_i \neq G_k(x_i))} - 1 = \frac{1 - e_k}{e_k}$

所以

αk​=21​logek​1−ek​​

其中 ek 是分类误差率：

ek​=∑i=1m​wki′​∑i=1m​wki′​I(yi​=Gk​(xi​))​=i=1∑m​wki​I(yi​=Gk​(xi​))

最后一步成立是因为 w'ki 归一化之后就等于 wki。这就是「魔法公式」的来源——它是指数损失在当前轮上的最优解，不是经验拍出来的。

样本权重从哪来 #

样本权重更新也是同一个推导的副产品。利用

$f_k(x) = f_{k-1}(x) + \alpha_k G_k(x), \quad w'{ki} = \exp\left(-y_i f{k-1}(x_i)\right)$

直接得到

$w'{k+1,i} = w'{ki}\exp\left[-y_i \alpha_k G_k(x_i)\right]$

这和上一章那个样本权重更新公式只差一个规范化因子 Zk，两者等价——除以 Zk 只是为了保持权重和为 1，不影响相对大小。

权重更新的三条性质 #

把公式摊开看，能读出三件事。

第一，错分的样本权重严格变大。

分错时 y_i G_k(x_i) = -1，乘数是 exp(αk) > 1（因为 αk > 0）。权重乘一个大于 1 的数，变大。

分对时乘数是 exp(-αk) < 1，权重变小。

第二，增大的幅度由这个弱学习器本身的分量决定。αk 大（也就是这个弱学习器很准），错的那个样本被放大的倍数就大——一个几乎全对的模型错了一个样本，这个样本会被狠狠放大，因为它太反常了。反过来，一个勉强及格的模型（ek 接近 0.5），αk 接近 0，权重几乎不变，因为它错的地方不太可信，不值得特别关注。这个设计很克制：它没有无脑放大所有错误，而是按「这个模型的可靠程度」来决定放大的力度。

第三，权重和保持为 1。除以 Zk 之后 sum(w) = 1 恒成立，权重始终构成一个概率分布。这一步不是可有可无的归一化——下一轮的 ek 是加权求和，如果权重不归一，误差率的量纲就不对了。

为什么是「指数」损失 #

指数损失有个特别的性质：它对误分类的惩罚是指数级增长的。分错越多、越离谱（y f(x) 越负），惩罚涨得越快。好处是收敛快，AdaBoost 在实践中往往几十轮就能把训练误差压到很低，甚至在某些数据上训练误差会在有限轮内降到 0。

坏处是对噪声和异常点脆弱。一个标错的样本，会在每轮都被分错，每轮权重都被放大，最后权重集中到少数几个点身上，模型被迫去拟合这些噪声。这就是 AdaBoost 对异常样本敏感的根本原因，不是实现问题，是损失函数形状决定的。

指数损失的上界性质也值得一提：它实际上是 0-1 损失的一个上界，优化指数损失等价于在优化 0-1 损失的一个凸上界。这是它能奏效的理论保证。

AdaBoost 的正则化 #

和所有 Boosting 一样，AdaBoost 也需要防过拟合。手段是步长（learning rate），记作 ν：

$f_k(x) = f_{k-1}(x) + \nu \alpha_k G_k(x)$

ν 的取值范围是 0 < ν ≤ 1，不加时 ν = 1。同样的训练集，较小的 ν 意味着需要更多的弱学习器迭代次数才达到相同效果。所以 ν 和迭代次数要一起看——把它们看成一对参数，而不是两个独立的参数。

经验关系：ν 减半，迭代次数大致要翻倍才能补回来。这个关系不是精确等式，但调参时能省很多试错。

用李航《统计学习方法》里那个经典例子走一遍，能看清权重怎么流动。

八、AdaBoost 的实践 #

sklearn 的两个类 #

sklearn 里 Adaboost 的接口很直接：AdaBoostClassifier 和 AdaBoostRegressor。前者用了 SAMME 和 SAMME.R 两种实现，后者用 AdaBoost.R2。

调参分两部分：AdaBoost 框架本身的参数，和所选弱学习器的参数。先把框架参数定下来，再动基学习器的参数。

框架参数 #

base_estimator：弱分类学习器或弱回归学习器。理论上任何支持样本权重的分类器或回归器都能用，常用 CART 决策树和神经网络 MLP。默认是决策树：分类用 DecisionTreeClassifier，回归用 DecisionTreeRegressor。

有个容易踩的坑：如果 algorithm 选 SAMME.R，弱学习器还必须支持概率预测——除了 predict 还要有 predict_proba。SAMME 没有这个限制。

algorithm：只有 AdaBoostClassifier 有。SAMME 用对样本集的分类效果（对错）作为弱学习器权重依据，SAMME.R 用对样本集的预测概率大小作为依据。SAMME.R 用的是概率这种连续值，信息量更大，迭代一般更快，所以是默认值。如果你选的基学习器不支持 predict_proba（比如某些自定义模型），就必须切到 SAMME。

loss：只有 AdaBoostRegressor 有，对应 R2 算法的相对误差度量，三选一：

默认 'linear'，多数情况够用。如果你怀疑这个参数导致拟合不良，再试另外两个。

n_estimators：弱学习器的最大迭代次数，也就是最大个数。太小容易欠拟合，太大容易过拟合，默认 50。

learning_rate：每个弱学习器的权重缩减系数 ν。加上之后迭代公式变成 f_k = f_{k-1} + ν α_k G_k，范围 0 < ν ≤ 1，默认 1。较小的 ν 需要更多弱学习器才能达到同样的效果，所以这个参数和 n_estimators 要一起调。

基学习器参数 #

max_depth 在 AdaBoost 里特别关键——基学习器是一棵树桩还是一棵深树，直接决定模型是「弱学习器集成」还是「强学习器集成」。用深树做基学习器，AdaBoost 的降偏差优势发挥不出来，反而容易过拟合。

min_weight_fraction_leaf 也值得单独提一句。AdaBoost 一直在改样本权重，所以这个参数在这里比在普通决策树里更需要留意——一旦有较多缺失值或类别分布偏差大，权重会集中，这个值就该设了。

AdaBoost 的弱学习器怎么选 #

理论上任何学习器都能用于 AdaBoost。用得最广的是决策树和神经网络。决策树的场合：分类用 CART 分类树，回归用 CART 回归树。

神经网络做 AdaBoost 基学习器的情形很少见，主要因为训练成本——T 轮就要训 T 个网络，代价太高。决策树的训练成本低得多，且天然适合加权样本。

优缺点 #

优点：

  • 作为分类器时分类精度高；
  • 框架下可以用各种回归分类模型构建弱学习器，很灵活；
  • 作为简单的二元分类器时，构造简单，结果可理解；
  • 不容易发生过拟合。

最后一条要加个限定：不容易不等于不会。AdaBoost 的过拟合风险主要来自噪声样本，不是来自模型复杂度本身。干净数据上它确实很抗过拟合。

缺点：对异常样本敏感。异常样本在迭代中会获得越来越高的权重，把最终强学习器的预测带偏。

这个缺点和第七章的分析对上——指数损失对错分样本的惩罚是指数级的，噪声点会被反复放大。缓解手段是限制 n_estimators、加正则化项、或者干脆在预处理阶段把明显异常的点剔掉。

九、GBDT：用负梯度代替残差 #

GBDT（Gradient Boosting Decision Tree）是 Boosting 家族的另一个成员，和 AdaBoost 的路子很不一样。

先统一简称。GBDT 有很多名字：GBT（Gradient Boosting Tree）、GTB（Gradient Tree Boosting）、GBRT（Gradient Boosting Regression Tree）、MART（Multiple Additive Regression Tree），指的都是同一个算法。本篇统一叫 GBDT。

和 AdaBoost 的分岔 #

回顾 AdaBoost：我们用前一轮迭代弱学习器的分类误差率来更新训练集权重，一轮轮迭代下去。

GBDT 也是迭代，也用前向分布算法，但有两处不同：

  1. 弱学习器限定只能用 CART 回归树；
  2. 迭代思路不同——它不用样本权重，改用拟合残差（更准确地说是拟合负梯度）。

用权重和用残差，是两条平行的路。权重改的是「每个样本被关注的程度」，残差改的是「每个样本的目标值」。数学上前者在样本空间重加权，后者在函数空间做梯度步。GBDT 这条路更通用，原因后面会讲清。

迭代目标 #

在 GBDT 的第 t 轮，假设前一轮得到的强学习器是 f_{t-1}(x)，损失函数是 L(y, f_{t-1}(x))。本轮的目标是找一个 CART 回归树 h_t(x)，让本轮的损失

$L\left(y, f_t(x)\right) = L\left(y, f_{t-1}(x) + h_t(x)\right)$

最小。也就是说，本轮找到的这棵树，要让样本的损失尽量变得更小。

一个通俗的例子 #

有个人 30 岁。第一轮用 20 岁去拟合，损失是 10 岁；第二轮用 6 岁去拟合剩下的 10 岁，差距剩 4 岁；第三轮用 3 岁拟合剩下的 4 岁，差距只剩 1 岁。

每轮拟合的都是「上一轮剩下的差距」，差距逐轮缩小。这就是「提升」的字面意思——不是一次学到位，是一点点往上垒。

问题在哪 #

这个思路很直白，但有个关键问题没解决：损失的拟合不好度量。

如果损失是平方损失，残差就是 y - f(x)，直接算，好办。但损失函数各种各样——绝对值损失、Huber 损失、分位数损失、对数似然——它们的「残差」怎么定义？

总不能每换一个损失函数就重新设计一套算法。需要一个通用的拟合方法。

负梯度：Friedman 的答案 #

Freidman 给出的答案：用损失函数的负梯度来拟合本轮损失的近似值，进而拟合一棵 CART 回归树。

第 t 轮第 i 个样本的损失函数负梯度：

$r_{ti} = -\left[\frac{\partial L(y_i, f(x_i))}{\partial f(x_i)}\right]{f(x) = f{t-1}(x)}$

这就是把「残差」这个具体概念，推广成了「负梯度」这个一般概念。

用 (x_i, r_ti)（i = 1, 2, ..., m）去拟合一棵 CART 回归树，得到第 t 棵回归树，其叶节点区域为 R_tj（j = 1, 2, ..., J），J 是叶子节点个数。

对每个叶子节点里的样本，求使损失函数最小的输出值 c_tj：

$c_{tj} = \underbrace{\arg\min}{c}\sum{x_i \in R_{tj}} L\left(y_i, f_{t-1}(x_i) + c\right)$

本轮的决策树拟合函数：

$h_t(x) = \sum_{j=1}^{J} c_{tj} I(x \in R_{tj})$

本轮最终的强学习器：

$f_t(x) = f_{t-1}(x) + \sum_{j=1}^{J} c_{tj} I(x \in R_{tj})$

为什么负梯度能代替残差 #

这是全篇最需要讲透的一点。

平方损失下，负梯度就是残差。

$L(y, f(x)) = \frac{1}{2}(y - f(x))^2$

对 f(x) 求偏导：

$\frac{\partial L}{\partial f(x)} = -(y - f(x))$

取负号：

$-\frac{\partial L}{\partial f(x)} = y - f(x)$

正好是残差。所以「拟合残差」是「拟合负梯度」在平方损失下的特例，不是两套方法。

换成别的损失，负梯度给出的是不同的东西，但框架不变。

以绝对值损失 L = |y - f(x)| 为例：

$-\frac{\partial L}{\partial f(x)} = \text{sign}\left(y - f(x)\right)$

这就不是残差了，是残差的符号，只取 ±1。意思变成「只要方向对，幅度不重要」——这正是绝对值损失对异常值不敏感的原因：不管残差是 3 还是 300，负梯度都是同样的 1。

Huber 损失下：

r(yi​,f(xi​))={yi​−f(xi​),δsign(yi​−f(xi​)),​∣yi​−f(xi​)∣≤δ∣yi​−f(xi​)∣>δ​

误差小于 δ 时退化成残差（像平方损失），超过 δ 时截断成常数（像绝对值损失）。一个损失，两种行为，靠 δ 切换。

分位数损失下：

r(yi​,f(xi​))={θ,θ−1,​yi​≥f(xi​)yi​<f(xi​)​

θ 是分位数，回归前指定。θ = 0.9 时，模型学的是「90% 的样本真实值在我下面」——输出不再是均值，是条件分位数。这个能力残差法给不了。

这就是 GBDT 比 AdaBoost 更通用的原因：换损失函数不用换算法。算法的骨架——算负梯度、拟合树、求叶子最优值、累加——完全不动，只有负梯度的表达式变。AdaBoost 被锁死在指数损失上，想换损失就得换一整套权重更新规则。

用负梯度拟合损失误差，找到了一种通用的办法。不管是分类还是回归，都用损失函数的负梯度来拟合一棵回归树。区别仅仅在于损失函数不同导致负梯度不同。

为什么叫「梯度下降」 #

把 f 看成参数空间里的一个点（函数也是向量），损失 L 是它的函数。梯度下降的更新是

$f_t = f_{t-1} - \eta \nabla L$

GBDT 的更新是

$f_t = f_{t-1} + h_t$

而 h_t 拟合的是 -∇L。两者同构——GBDT 是在函数空间里做梯度下降，每一棵回归树就是一个「沿着负梯度方向的步长函数」。

这个视角解释了 GBDT 为什么能work，也解释了为什么学习率（步长）能防过拟合：和一个标准梯度下降一样，步子迈小一点，收敛更稳。

十、GBDT 的回归与分类 #

回归算法 #

先看回归。分类的输出不连续，需要额外处理，放到后面。

输入是训练集 T = {(x_1, y_1), (x_2, y_2), ..., (x_m, y_m)}、最大迭代次数 T、损失函数 L，输出是强学习器 f(x)。

第一步，初始化弱学习器：

$f_0(x) = \underbrace{\arg\min}{c}\sum{i=1}^{m} L(y_i, c)$

这一步是找一个常数 c，让整体损失最小。平方损失下就是所有 y 的均值；绝对值损失下是中位数——这个细节很实用，它能解释为什么用绝对值损失的 GBDT 对初值不敏感。

第二步，对 t = 1, 2, ..., T 迭代：

a) 对样本 i = 1, 2, ..., m，计算负梯度：

$r_{ti} = -\left[\frac{\partial L(y_i, f(x_i))}{\partial f(x_i)}\right]{f(x) = f{t-1}(x)}$

b) 用 (x_i, r_ti)（i = 1, 2, ..., m）拟合一棵 CART 回归树，得到第 t 棵回归树，叶节点区域为 R_tj（j = 1, 2, ..., J）。

c) 对叶子区域 j = 1, 2, ..., J，计算最佳拟合值：

$c_{tj} = \underbrace{\arg\min}{c}\sum{x_i \in R_{tj}} L\left(y_i, f_{t-1}(x_i) + c\right)$

d) 更新强学习器：

$f_t(x) = f_{t-1}(x) + \sum_{j=1}^{J} c_{tj} I(x \in R_{tj})$

第三步，得到最终强学习器：

$f(x) = f_T(x) = f_0(x) + \sum_{t=1}^{T}\sum_{j=1}^{J} c_{tj} I(x \in R_{tj})$

注意 c_tj 这一步不能省。拟合回归树时用的是负梯度 r_ti 当目标，但树叶子上真正该输出的值不是 r_ti 的均值——要按原始损失函数 L 重新求一次最优 c。有些实现里这两者相等（平方损失下树叶子输出的就是残差均值），但一般情况下不等。

分类为什么不能直接套 #

GBDT 的分类从思想上和回归没有区别，但样本输出不是连续值，是离散类别，没法直接拟合类别输出的误差。

两条解决路径：

  1. 用指数损失函数。这时 GBDT 退化成 AdaBoost。
  2. 用类似逻辑回归的对数似然损失函数。

第二条是主流。思路是用类别的预测概率值和真实概率值的差来拟合损失。

二元分类 #

用对数似然损失：

$L(y, f(x)) = \log\left(1 + \exp(-y f(x))\right)$

y ∈ {-1, +1}。负梯度：

rti​=−[∂f(xi​)∂L(yi​,f(xi​))​]f(x)=ft−1​(x)​=1+exp(yi​f(xi​))yi​​

各叶子节点的最佳残差拟合值：

ctj​=cargmin​​xi​∈Rtj​∑​log(1+exp(−yi​(ft−1​(xi​)+c)))

上式比较难优化，实践中用近似值代替：

$c_{tj} = \frac{\sum_{x_i \in R_{tj}} r_{ti}}{\sum_{x_i \in R_{tj}} |r_{ti}|(1 - |r_{ti}|)}$

这是牛顿法一步近似的结果——分母是二阶导数之和的近似。除了负梯度的计算和叶子最优值的线性搜索，二元 GBDT 分类和回归的流程完全相同。

多元分类 #

多元 GBDT 比二元复杂，对应多元逻辑回归和二元逻辑回归的复杂度差别。假设类别数为 K，对数似然损失为

$L(y, f(x)) = -\sum_{k=1}^{K} y_k \log p_k(x)$

样本输出类别为 k 时 y_k = 1，其余为 0。第 k 类的概率

pk​(x)=∑l=1K​exp(fl​(x))exp(fk​(x))​

这是 softmax。两个式子联立，算出第 t 轮第 i 个样本对应类别 l 的负梯度：

rtil​=−[∂f(xi​)∂L(yi​,f(xi​))​]fk​(x)=fl,t−1​(x)​=yil​−pl,t−1​(xi​)

这个式子很干净——误差就是样本 i 对应类别 l 的真实概率和 t-1 轮预测概率的差值。真实概率是 one-hot（0 或 1），预测概率是 softmax 输出（0 到 1 之间）。所以：

  • 真实类别的那一项，负梯度 = 1 - p，正的，力度等于「还差多少没预测准」；
  • 其他类别，负梯度 = 0 - p = -p，负的，力度等于「错给了多少概率」。

这就是多元 GBDT 每一轮在干的事：把预测对了的部分往回压，把没预测够的部分往上推。

叶子节点的最佳残差拟合值：

ctjl​=cjl​argmin​​i=0∑m​k=1∑K​L(yk​,ft−1,l​(x)+j=0∑J​cjl​I(xi​∈Rtj​))

同样难优化，用近似值：

ctjl​=KK−1​⋅∑xi​∈Rtil​​∣rtil​∣(1−∣rtil​∣)∑xi​∈Rtjl​​rtil​​

比二元多了一个 (K-1)/K 的缩放系数。除了负梯度和叶子最优值的线性搜索，多元 GBDT 分类和二元分类、回归的流程都一样。

三种任务的对照 #

多元分类每轮要训 K 棵树，这是 GBDT 在多分类上慢的直接原因。K = 10 时，100 轮就是 1000 棵树。

十一、损失函数与正则化 #

分类的损失函数 #

分类有两类损失可选。

指数损失：

$L(y, f(x)) = \exp(-y f(x))$

它的负梯度和叶子最优值参见第七章 AdaBoost 的推导。选它，GBDT 就退化成 AdaBoost——这也说明两者是同一个框架的两个填法。

对数损失：分二元和多元两种，负梯度见第十章。

损失 表达式 特点
指数损失 exp(−yf(x)) 对噪声敏感，等价 AdaBoost
二元对数损失 log(1+exp(−yf(x))) 输出概率，主流选择
多元对数损失 $-\sum_k y_k \log p_k$ softmax，输出各类概率

回归的损失函数 #

回归有四种常用损失。

均方差：最常见的回归损失。

$L(y, f(x)) = (y - f(x))^2$

负梯度就是残差 y - f(x)。优化友好（处处可导、二阶导为常数），缺点是对异常值敏感——一个离谱的 y 会把损失拉爆。

绝对损失：

$L(y, f(x)) = |y - f(x)|$

对应负梯度：

sign(yi​−f(xi​))

只看方向不看幅度，因此对异常点稳健。代价是在 f(x) = y 处不可导，以及优化时收敛慢一些（梯度大小恒定，不随误差减小而减小）。

Huber 损失：均方差和绝对损失的折衷。远离中心的异常点用绝对损失，中心附近的点用均方差。界限用分位数点 δ 度量。

L(y,f(x))={21​(y−f(x))2,δ(∣y−f(x)∣−2δ​),​∣y−f(x)∣≤δ∣y−f(x)∣>δ​

对应负梯度：

r(yi​,f(xi​))={yi​−f(xi​),δsign(yi​−f(xi​)),​∣yi​−f(xi​)∣≤δ∣yi​−f(xi​)∣>δ​

δ 是关键超参。δ 趋大，退化成均方差；δ 趋小，退化成绝对损失。

分位数损失：对应分位数回归。

$L(y, f(x)) = \sum_{y \geq f(x)}\theta|y - f(x)| + \sum_{y < f(x)}(1-\theta)|y - f(x)|$

θ 为分位数，回归前要指定。对应负梯度：

r(yi​,f(xi​))={θ,θ−1,​yi​≥f(xi​)yi​<f(xi​)​

Huber 和分位数损失都主要用于健壮回归，也就是减少异常点对损失函数的影响。区别在目标不同：Huber 学的是「稳健的中心」，分位数损失学的是「条件分位数」——预测区间上下界时用它，而不是用两个模型减标准差。

四种损失的选择 #

损失 异常值稳健性 输出含义 典型场景
均方差 弱 条件均值 数据干净、误差近高斯
绝对损失 强 条件中位数 有离群点
Huber 中（可调） 折衷 不确定异常比例
分位数 强 条件分位数 区间预测、风控

正则化的三种方式 #

和 AdaBoost 一样，GBDT 也要正则化防过拟合。

第一种，步长（learning rate）。记作 ν。原来的迭代是 f_k = f_{k-1} + h_k，加上正则化项后变成 f_k = f_{k-1} + ν h_k。ν 的范围是 0 < ν ≤ 1。同样的训练集，较小的 ν 意味着需要更多迭代次数。实践中用步长和最大迭代次数一起决定拟合效果。

第二种，子采样比例（subsample）。取值 (0, 1]。这里的子采样和随机森林不一样：随机森林用的是放回抽样，GBDT 的子采样是不放回抽样。

取 1 时全部样本都用，等于没开子采样。小于 1 时只有一部分样本参与本轮的树拟合，好处是降方差、防过拟合，代价是增大偏差，所以取值不能太低。常用区间 [0.5, 0.8]。

用了子采样的 GBDT 有时候也叫随机梯度提升树（Stochastic Gradient Boosting Tree，SGBT）。它还带来一个附带好处：因为每轮只用一部分样本，程序可以把采样分发到不同任务上做 boosting 迭代，最后合并成新树——这缓解了「弱学习器之间强依赖、难以并行」的弱点。

第三种，对弱学习器本身剪枝。也就是对 CART 回归树加深度限制、叶子最少样本数等约束。

三种手段作用在不同层面：步长控制每轮的步幅，子采样控制每轮看到的数据量，剪枝控制单个学习器的复杂度。三者可以叠加，也可以只调一个。

十二、XGBoost 与 LightGBM #

GBDT 是算法，XGBoost 和 LightGBM 是它的两个工程实现。两者都是 GBDT，差别在工程实现——不在模型结构，不在损失函数框架。

理解这一点很重要：调 XGBoost 和调 LightGBM 的直觉是通用的，参数名字不同而已。

XGBoost 做了什么 #

XGBoost 是 GBDT 的工程优化版，在四个地方动了手。

第一，加了正则项。

原始 GBDT 的目标只有损失：

$Obj = \sum_{i=1}^{m} L(y_i, \hat{y}_i)$

XGBoost 加上树复杂度惩罚：

$Obj = \sum_{i=1}^{m} L(y_i, \hat{y}i) + \sum{k=1}^{K}\Omega(f_k)$

其中

$\Omega(f) = \gamma T + \frac{1}{2}\lambda\sum_{j=1}^{T} w_j^2$

T 是叶子数，w 是叶子权重。γ 惩罚叶子数量（树越复杂罚越重），λ 惩罚叶子权重的平方（权重越大罚越重）。这个改动把「正则化」从训练外的手段（早停、剪枝、步长）变成了目标函数的一部分，模型自己就会避开过于复杂的结构。

第二，二阶泰勒展开。原始 GBDT 只用了损失的一阶导（负梯度），XGBoost 同时用一阶和二阶：

$Obj^{(t)} \approx \sum_{i=1}^{m}\left[g_i f_t(x_i) + \frac{1}{2}h_i f_t^2(x_i)\right] + \Omega(f_t)$

g_i 是一阶导，h_i 是二阶导。好处有两个：一是收敛更快（牛顿法比梯度下降快），二是二阶信息让目标函数可以化成关于叶子权重的二次函数，有闭式最优解，以及对应的最优目标值可以拿来当分裂增益的评分：

$w_j^* = -\frac{\sum_{i \in I_j} g_i}{\sum_{i \in I_j} h_i + \lambda}$

第三，列采样。借鉴随机森林，每次分裂只在随机抽的特征子集里找最优分裂点。降方差、加速训练。

第四，并行特征分裂。这一点常被误解。XGBoost 的并行不是「并行训树」（树之间是串行的，改不了），而是并行地找每个特征上的最优分裂点。做法是先把数据按特征预排序、存成块结构，分裂时各特征的计算可以并行跑。所以 XGBoost 的快，快在特征粒度上的并行和缓存友好，不是打破了 Boosting 的串行性。

LightGBM 做了什么 #

LightGBM 换了另一套工程手段，四个关键点。

第一，直方图算法。把连续特征离散化成 k 个桶（默认 255），分裂时只在桶边界上找切分点。

  • 内存：原来的浮点数值存成桶索引，8 字节变 1 字节；
  • 速度：分裂点候选从 O(样本数) 降到 O(桶数)；
  • 代价：分裂点变粗，精度略降，但实践中几乎不影响效果，甚至因为粗粒度带了点正则化效果。

第二，Leaf-wise 生长。XGBoost 用 Level-wise：一层一层地长，同一层的叶子一起分裂。LightGBM 用 Leaf-wise：每次从所有叶子里挑增益最大的那个分裂。

生长方式 特点
Level-wise 每层所有叶子都分裂，树更「平衡」，可并行，但会分裂增益很低的叶子
Leaf-wise 只分裂增益最大的叶子，同样叶子数下损失更低，但树更「深」且不平衡，小数据易过拟合

Leaf-wise 的代价是要用 num_leaves 和 max_depth 双重约束，否则一棵树能长成一条链。

第三，GOSS（Gradient-based One-Side Sampling）。梯度大的样本还没学好，梯度小的样本已经学得差不多了。GOSS 全部保留梯度大的样本，对梯度小的样本随机采样一部分，并给采样到的样本一个放大系数补偿。这样在几乎不损失精度的情况下大幅减少每轮用的样本量。它和 subsample 的区别：subsample 是随机丢弃，GOSS 是有方向地保留难样本。

第四，EFB（Exclusive Feature Bundling）。高维稀疏数据里很多特征是互斥的（不同时取非零值）。EFB 把这些互斥特征捆绑成一个特征，把特征维度降下来。稀疏数据上效果好，稠密数据上没什么可捆的。

三者对比 #

两个实现都不是「更好」，是「更适合」。LightGBM 的速度优势建立在大数据 + 直方图的近似上；样本只有几千行时，直方图的近似误差反而成了负担，XGBoost 的精确搜索更稳。

十三、三者的选型与调参 #

选型 #

按数据规模分三档，这是最实用的判断方式。

数据规模 首选 理由
小（万行以内） AdaBoost / 随机森林 简单、不易过拟合、训练快
中（万到百万行） XGBoost 稳，精度和速度平衡好
大（百万行以上） LightGBM 直方图 + Leaf-wise + GOSS，速度和内存优势明显

这张表是起点不是教条。三个补充判断：

  • 特征维度极高且稀疏（比如文本 TF-IDF），LightGBM 的 EFB 和直方图优势会被放大；
  • 需要输出概率且样本很少，随机森林的 predict_proba 比 AdaBoost 稳；
  • 数据里有大量异常值，优先试带 Huber 或分位数损失的 GBDT，而不是硬套均方差。

调参顺序 #

顺序错了会白跑很多轮。按这个来：

  1. 先定学习率和一个较大的树数量。learning_rate 取 0.05~0.1，n_estimators 先给个大值（比如 1000），靠早停自己停下来。
  2. 再调单树复杂度。GBDT 的 max_depth 从 3 开始试，LightGBM 的 num_leaves 从 31 附近开始试。这一步影响最大。
  3. 再调采样比例。subsample 和列采样从 0.8 往下试，0.5 是常见下限。
  4. 最后调正则化。min_child_samples、λ、γ 这些。
  5. 回头微调学习率。如果早停停在了很靠后的轮次，学习率可以调大一点省时间。

    GradientBoostingClassifier,

ada = AdaBoostClassifier(

)

    max_depth=3,

rf = RandomForestClassifier(

早停 #

GBDT 类的模型一定要用早停。「加树」对 Bagging 无害，对 Boosting 有害——树加多了，模型会在训练集的噪声上继续拟合，验证集误差回升。

sklearn 的 GradientBoostingClassifier 用 n_iter_no_change 和 validation_fraction；XGBoost 用 early_stopping_rounds 配合 eval_set；LightGBM 用 early_stopping 配合 callbacks。机制一致：连续若干轮验证集指标没改善就停。

对应的参数就三处，名字各异但逻辑一样：

框架 早停轮数 监控集
sklearn n_iter_no_change validation_fraction 自动切
XGBoost early_stopping_rounds eval_set 手动传
LightGBM early_stopping valid_sets 手动传

12 小数据上直接上 LightGBM 默认参数 Leaf-wise 会过拟合，压 num_leaves、加 min_child_samples
13 GBDT 不开早停 加树会过拟合，必须早停
14 学习率和树数量分开调 两者是一对参数，成对调
15 stacking 用训练集自身预测做次级输入 用 K 折生成，避免信息泄漏
16 用训练集分数判断集成效果 随机森林看 oob_score，其余看验证集

三条判断口诀 #

遇到不确定的情形，按这三条走。

看误差来源选路线。训练集就差 → 偏差问题 → 用 Boosting。训练集好测试集差 → 方差问题 → 用 Bagging 或加子采样。

看数据量选实现。万行以内 AdaBoost 或随机森林，百万行以上 LightGBM，中间 XGBoost。先用小规模实验验证特征，再换实现扩规模。

看损失形状选函数。数据干净用均方差，有离群点用 Huber 或绝对值，要区间用分位数，要概率用对数损失。

最后一条 #

集成学习的全部价值在「多个弱模型拼出一个强模型」，而这句话成立的前提只有一个：个体学习器要有差异。

没有差异的集成，只是把同一个模型算了 T 遍。所有采样、加权的技巧，都在服务这一条。调参之前先确认你的基学习器真的不一样——这件事比调任何超参都重要。
