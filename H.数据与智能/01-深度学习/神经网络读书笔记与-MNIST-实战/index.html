这篇笔记做两件事。一件是把《Neural Networks and Deep Learning》这本书的主干捋一遍：感知机怎么走到 Sigmoid 神经元，三层网络怎么认手写数字，梯度下降和反向传播的公式从哪来，过拟合和梯度消失怎么处理。另一件是把书里讲的东西用 TensorFlow 跑两遍：一个前馈网络，一个卷积网络。

不讲的东西也划清楚。循环神经网络、注意力、Transformer 不在本书范围，本篇不碰。工程侧的分布式训练、模型部署、线上推理同样不讲。代码按 TensorFlow 1.x 的图模式会话写，tf.placeholder、tf.Session、tf.InteractiveSession 这些在 2.x 里已经换成别的写法，读的时候按 1.x 的语义理解。

跨篇指路：卷积的直观理解在卷积神经网络那篇展开，本篇只讲 tf.nn.conv2d 的接口细节和两个实现的对比。优化器的推导在优化算法那篇，本篇只用 Adam，不推它的更新式。

一、这本书讲了什么 #

Michael Nielsen 写的《Neural Networks and Deep Learning》，免费挂在 neuralnetworksanddeeplearning.com 上。全书六章，配套代码在 github.com/mnielsen/neural-networks-and-deep-learning，纯 numpy 实现，不依赖任何深度学习框架。数据集也从那个仓库拿，mnist.pkl.gz 一个文件，解压完就能跑。

六章的结构：

章 主题 读完拿到什么
1 使用神经网络识别手写数字 感知机 → Sigmoid → 三层网络 → 梯度下降 → 随机梯度下降的完整链条
2 反向传播算法如何工作 四个公式，加一个能跑起来的三层网络
3 改进神经网络的学习方法 交叉熵、softmax、L2 规范化、弃权、更好的权重初始化
4 神经网络可以计算任何函数的可视化证明 万能近似定理的直观版本
5 深度神经网络为何很难训练 消失的梯度、激增的梯度、不稳定的梯度
6 深度学习 卷积网络，Theano 版本的实现

**这本书的价值在于从零把原理讲透。**它不用框架。全书的核心代码就是一个 Network 类，七十来行 numpy：feedforward 一个循环，backprop 两个循环，update_mini_batch 一个累加。没有自动微分，没有计算图，没有 GPU。

具体到每一行在干什么：

  • np.dot(w, activation) + b 是一次前向，一个矩阵乘加一个向量加。
  • np.dot(self.weights[-l+1].transpose(), delta) * sp 是一次误差回传，把后一层的误差用转置权重摊回前一层，再乘本层激活函数的导数。
  • np.dot(delta, activations[-2].transpose()) 是一次权重梯度，误差乘上一层的激活。
  • w - (eta/len(mini_batch))*nw 是一次参数更新，学习率除掉批量大小，乘累积梯度。

看明白这四行，再看 TensorFlow 里的 tf.matmul、tf.nn.relu、tf.nn.conv2d、train.run(feed_dict=...)，你就知道每个 op 里被包起来的是什么东西。框架不是黑盒，是你自己手写过一遍的运算被折叠成了一个函数调用。

这也是为什么入门推荐先读这本书再碰框架。反过来走——先学框架再补原理——容易停在「调 API 能跑，但不知道为什么能跑」的状态，调参全靠试。

阅读顺序上，前三章连着读完，别跳。第四章是可视化证明，思路漂亮但对写代码没直接帮助，可以缓一缓。第五章和第六章是通往深度网络的入口，第五章讲的那个不稳定梯度问题，是后面所有初始化技巧和 ReLU 的动机。

书里的原始代码是 Python 2 时代的写法，本篇按 Python 3 重排：print 带括号，pickle.load 加 encoding='bytes'，文件头部的作者和创建时间注释去掉，其余逻辑一行不改。

二、感知机与 Sigmoid 神经元 #

感知机是二分类的线性分类模型。输入是实例的特征向量，输出是类别，取 +1 和 -1。它可以写成一个映射 f: R^n -> {-1, +1}：

text
f(x) = sign(w·x + b)

w 和 b 都是 n 维列向量，w 是权重，b 是偏置，w·x 是内积。感知机的训练过程就是求 w 和 b 的过程。求对了，超平面 w·x + b = 0 恰好把两类数据点分在平面两侧。

这个模型的局限很硬：

  • 只能把数据分成 2 类。
  • 数据必须线性可分。

第一条意味着它做不了 MNIST 这种 10 分类。第二条意味着它连异或都做不了。不过感知机是 ANN 和 SVM 的共同底座，理解它的几何含义，对后面理解「神经网络在特征空间里切什么形状」有用。

从感知机走到 Sigmoid，动机是一个很实际的问题：感知机的输出是阶跃的。权重动一点点，输出要么纹丝不动，要么直接从 +1 翻到 -1。这种不连续让「往正确方向挪一小步」这个动作没法定义。而学习恰恰就是一步一步挪。

Sigmoid 神经元把这个阶跃换成一条平滑曲线：

text
z = w·x + b
σ(z) = 1 / (1 + e^(-z))

输出落在 (0, 1) 区间，连续，单调。它的关键性质是：

text
Δoutput ≈ Σ (∂σ/∂w_j) Δw_j + (∂σ/∂b) Δb

权重和偏置的小改动，只带来输出的小改动，而且这个关系是线性的一阶近似。这是整个梯度下降能成立的前提。没有这一条，后面所有的求导、链式法则、参数更新都无从谈起。

Sigmoid 的导数有个很省事的形式：

text
σ'(z) = σ(z) * (1 - σ(z))

函数值算出来，导数顺带就有了，不用再算一次指数。代价是这个导数的最大值只有 1/4，在 z = 0 处取到。这个 1/4 是后面消失梯度问题的源头之一。

对比项 感知机 Sigmoid 神经元
输出 sign(w·x + b)，取 ±1 σ(w·x + b)，落在 (0, 1)
值域 离散两值 连续
决策边界 硬超平面 软过渡带
可微性 几乎处处不可微 处处可微
小步调整 输出跳变，方向信息丢失 输出平缓跟随，梯度给出方向
能做几分类 2 类 叠成多层后可做多类
局限 线性可分才行 单层仍是线性边界，靠堆层解决

除了 Sigmoid，书里还提了另外三种神经元，本篇后面单独一节讲它们的取舍：

  • 双曲正切神经元 tanh，输出 (-1, 1)，零中心，收敛比 Sigmoid 快一些。
  • 修正线性神经元 ReLU，max(0, z)，正区间导数恒为 1，把消失梯度挡在门外。
  • Softmax 神经元，把一组实数压成概率分布，专门用在多分类的输出层。

代码里有个细节要提前说。本篇的程序把函数名写成 sigmod 和 sigmod_prime，少了字母 i，这是书里代码的拼写，读的时候别被带偏，它指的就是 sigmoid。后文引用的代码保持原样，不做改名，以免和书上对不上。

三、神经网络的结构 #

一个三层网络，输入 784 个神经元，隐藏层 30 个，输出层 10 个。写成 sizes = [784, 30, 10]。

层的编号从 1 开始，输入层是第 1 层，输出层是第 L 层，中间都叫隐藏层。num_layers = len(sizes) = 3。

参数的形状由相邻两层的神经元数决定：

text
第 l 层的权重 W^l：形状 (sizes[l], sizes[l-1])，即 (后一层神经元数, 前一层神经元数)
第 l 层的偏置 b^l：形状 (sizes[l], 1)，一列

具体到这个网络：

层 神经元数 权重形状 偏置形状 参数量
输入层 l=1 784 无 无 0
隐藏层 l=2 30 (30, 784) (30, 1) 23520
输出层 l=3 10 (10, 30) (10, 1) 310
合计 824 23830

前向传播就是逐层做同一个动作：

text
z^l = W^l * a^(l-1) + b^l
a^l = σ(z^l)

a^(l-1) 是上一层的激活输出，也是一个列向量。W^l * a^(l-1) 是矩阵乘向量，得到一个长度为 sizes[l] 的列向量，加上偏置，过激活函数，成为本层输出。输入层的 a^1 直接就是样本 x，不做任何变换。

这种每一层的每个神经元都连到上一层所有神经元的接法，叫全连接。它没有任何结构假设，图像、文本、表格都能喂进去，代价是参数量随层宽平方增长，而且丢掉了输入的拓扑。

两个数字得解释清楚。

784 来自 28×28。MNIST 的图是 28 像素见方，拉平成一维就是 784 维。这一步拉平把二维的空间结构压没了——相邻像素在向量里还是相邻，但「上下左右」的邻接关系不再被显式表达。卷积网络的价值就在于不拉平。

10 来自类别数。输出层第 j 个神经元对应数字 j，输出值经过 softmax 后可以读成「这张图是数字 j 的概率」。训练时目标输出用 one-hot：真实标签是 7，目标向量就是第 7 位为 1、其余为 0 的十维列向量。

隐藏层在干什么，书里给的说法是它学中间表示。30 个隐藏神经元在 784 维输入和 10 维输出之间架了一层压缩，网络自己决定这 30 维编码什么——比如笔画的方向、端点、圈的位置。这些编码不是人工设计的，是梯度下降推出来的。这也是「表示学习」这个词最朴素的版本。

一个容易忽略的点：sizes 里 30 这个数是超参数。改成 100，参数量从 2.3 万涨到 10 万，训练变慢，准确率不一定涨。书里用 30 是教学选择，篇幅短、跑得快、结果够看。

四、手写数字识别：问题的定义 #

MNIST 是手写数字的灰度图集，从 NIST 的特别数据库里挑出来重新整理过。规格：

项目 数值
图像尺寸 28 × 28 像素
通道数 1（灰度）
像素取值 0 ~ 255，读入后归一化到 0 ~ 1
类别数 10（数字 0 ~ 9）
训练集 50000
校验集 10000
测试集 10000
单样本特征维数 784
单样本标签形式 one-hot，10 维

有个坑要提前说：书的切分和 TensorFlow 的切分不一样。

  • Nielsen 的 mnist_loader.load_data_wrapper()：50000 训练 + 10000 校验 + 10000 测试。
  • TensorFlow 的 input_data.read_data_sets()：55000 训练 + 5000 校验 + 10000 测试。

两套代码用的不是同一个切分，所以准确率数字不能直接横比。差别在后面那篇实战里能看出来：TF 版训练集多了 5000 张，校验集少了 5000 张。

手写数字识别为什么是入门标准任务，理由有五条。

数据小。6 万张 28×28 的单通道图，gzip 压缩后十几兆，能整个读进内存。一次训练在 CPU 上几分钟跑完，改个想法立刻能验证。这一点决定了它的用途——它是个试验台，不是竞技场。

类别均衡。10 个数字，每个类别的样本数差不多，没有长尾。你不必先写一堆采样策略来对付类别不平衡，注意力可以全放在模型本身。

单通道。灰度图省掉了颜色这整个维度。RGB 三通道会让第一层卷积的输入通道变成 3，参数量翻三倍，还会引入「颜色对数字识别有用吗」这种和任务无关的问题。

任务定义干净。输入定长 784，输出定长 10，没有变长序列，没有对齐，没有掩码。数据管道就是「读数组、除以 255、切成批」，三行代码。

基准清晰。简单全连接网络 97% ~ 98%，卷积网络 99% 以上。这两个数是公共参照。你的实现跑出 92%，那不是「模型不够强」，是有 bug。跑出 99.2%，那是正常水平，不用怀疑人生。

横向比一下另外两个常见数据集：

数据集 规模 输入 难点 简单模型的水平
MNIST 6 万训练 28×28×1 基本没有 全连接 97%，CNN 99%+
CIFAR-10 5 万训练 32×32×3 物体姿态、背景干扰 CNN 75% 上下起步
ImageNet 128 万训练 变尺寸 RGB 1000 类、细粒度 需要 GPU 集群

MNIST 的位置很清楚：它是验证想法的地方，不是证明能力的地方。一个新初始化、一个新激活函数、一个新正则项，先在 MNIST 上跑通，再看它在 CIFAR 上成不成立。速度差一个数量级。

问题的数学形式，落到代码里就三句话：

text
输入：x ∈ R^784，像素值已归一化到 [0, 1]
输出：a ∈ R^10，第 j 维读作「这张图是数字 j」的得分或概率
目标：y ∈ {0,1}^10，one-hot，真实类别那一位为 1

训练就是找一组参数，让在这 5 万张图上 a 和 y 尽量接近，同时希望在没见过的 1 万张测试图上也能对上。前一句是优化，后一句是泛化。整本书的第三章在讲怎么让这两件事同时成立。

评测指标只有一个：分类准确率。取 a 的最大值下标，和目标类别比，对上了算一次。5 万张里对上 48500 张，准确率 97%。

书里的 mnist_loader 把数据读成三个列表，每个元素是一个 (x, y) 元组：

python
training_data, validation_data, test_data = mnist_loader.load_data_wrapper()

# training_data:   50000 个 (784x1 列向量, 10x1 one-hot 列向量)
# validation_data: 10000 个 (784x1 列向量, 标量标签)
# test_data:       10000 个 (784x1 列向量, 标量标签)

注意训练集和测试集的标签形式不一样。训练集是 one-hot 列向量，因为反向传播要算 a - y，形状必须对齐；测试集是标量，因为评估只需要比大小，np.argmax 出来的就是标量。

这个不对称在代码里衍生出一个参数 convert。evaluate(test_data) 直接用标量比；accuracy(training_data, convert=True) 得先把标量 y 转成 one-hot 再 argmax。传错这个参数，程序不报错，准确率变成 10%。

像素值在读入时已经除以 255，落在 0 到 1。不归一化的话，输入值域是 0 到 255，第一层权重乘出来的 z 会大到 Sigmoid 直接饱和，训练一开始就废。

五、梯度下降与代价函数 #

代价函数先用二次的：

text
C(w, b) = (1 / 2n) * Σ_x || y(x) - a ||^2

n 是训练样本数，a 是网络对输入 x 的实际输出，y(x) 是目标输出，求和遍历所有训练样本，||·|| 是向量二范数。

前面那个 1/2 是为了求导时和平方的 2 抵消，式子干净。它对极值点的位置没有影响，纯粹是书写方便。

为什么不直接拿准确率当优化目标？准确率是离散的。权重微调一点点，一个样本的预测都不会变，指标平坦得像台阶，梯度处处为零，没法往下走。代价函数连续可微，才有梯度可用。

梯度下降的想法很直白。把 C 看成两万三千多个变量的函数，求它的梯度 ∇C，然后往梯度的反方向走一步：

text
w ← w - η * ∂C/∂w
b ← b - η * ∂C/∂b

η 是学习率，控制步长。步子太大会在谷底来回弹，步子太小要走到天荒地老。这个参数后面还会反复出现。

问题出在计算量。n = 50000，算一次完整梯度要把 5 万张图全过一遍，一轮迭代就是 5 万次前向加反向。参数稍微多一点，一轮几个小时。

随机梯度下降把这个过程打散。每次只取 m 个样本组成一个小批量，用这小批量的梯度去估计整体梯度：

text
∇C ≈ (1/m) * Σ_{x ∈ mini_batch} ∇C_x

更新法则变成：

text
w = w - (η/m) * Σ ∂C_x/∂w
b = b - (η/m) * Σ ∂C_x/∂b

m 是小批量大小，书里取 10。把 5 万张图切成 5000 组，每组更新一次参数，一轮迭代从 1 次更新变成 5000 次更新。

为什么估计出来的梯度还能用？因为小批量是从训练集里随机抽的，梯度的期望和全量梯度一致。方差随 m 增大而下降，m 取 10 已经能让方向大致靠谱。这也是为什么每个 epoch 开始要打乱数据——不打乱的话，同一批里的样本高度相关（比如按类别排过序），估出来的梯度会有系统性偏差。

三个术语定下来，后面一直用：

术语 含义 书里的取值
epoch（迭代期） 把整个训练集过一遍 30
mini_batch_size（小批量大小） 一次更新用多少样本 10
eta（学习率） 每步走多远 3.0（未加规范化时）

随机梯度下降的流程，按书里的顺序：

text
输入训练集
初始化迭代期数 epochs
for i in range(epochs):
    打乱训练集
    按 mini_batch_size 切成若干组
    for 每组 mini_batch:
        调用 update_mini_batch，算梯度、更新 w 和 b
    一轮结束，用测试集评估准确率

在第 2 层的 update_mini_batch 里，还要再套一层循环：遍历组内每个样本，调用 backprop 算出这个样本的梯度，累加，最后按 η/m 更新。这一层循环就是下一篇要展开的反向传播。

Sigmoid 配二次代价有个隐患。输出层神经元的输出接近 0 或者 1 的时候，Sigmoid 曲线压得很平，σ'(z) 趋近 0。输出层误差是：

text
δL = (aL - y) * σ'(zL)

σ' 一小，误差就一小，∂C/∂w 和 ∂C/∂b 跟着一小，学习慢得像停住。而且这个「错得越离谱、学得越慢」的搭配很反直觉——网络明明输出得很错，却几乎不调整。

换来交叉熵代价：

text
C = -(1/n) * Σ_x [ y * ln(a) + (1 - y) * ln(1 - a) ]

它的输出层误差干净得离谱：

text
δL = aL - y

没有 σ' 那一项了。输出错得越远，aL - y 越大，梯度越大，学得越快。输出层饱和导致的停滞被消掉。

交叉熵只解决输出层。隐藏层的神经元在 σ(z) 接近 0 或 1 时照样饱和，这个问题第八章讲初始化时再处理。

再往前一步，把输出层换成柔性最大值（softmax）：

text
a_j = e^(z_j) / Σ_k e^(z_k)

输出的 10 个分量都落在 (0, 1) 内，加起来正好是 1，可以读成概率分布。配对数似然代价：

text
C = -ln(a_y)

y 是目标类别，a_y 是网络给这个类别打的分。输入是 7，代价就是 -ln(a_7)。网络输出 a_7 接近 1，代价接近 0；网络表现很差，a_7 很小，代价跟着变大。

这个代价满足两个条件：非负，且网络对每个输入都能给出接近目标的输出时代价趋近 0。这正是期望中代价函数该有的样子。

三种代价函数摆一起：

代价函数 形式 输出层误差 δL 配什么输出层 饱和时
二次代价 0.5 * Σ (y_j - a_j)^2 (aL - y) * σ'(zL) Sigmoid 梯度趋 0，学习停滞
交叉熵 -Σ [y ln a + (1-y) ln(1-a)] aL - y Sigmoid 梯度不衰减
对数似然 -ln(a_y) aL - y Softmax 梯度不衰减

代码上，前两种被写成两个类：QuadraticCost 和 CrossEntropyCost，各自提供 fn 算代价、delta 算输出层误差。换代价函数只是换一个类传进 Network，反向传播的代码一行不动。这个设计在下一章的 Network2 里能看到。

六、反向传播的直觉 #

反向传播要干的事很具体：算出每个样本的 ∂C_x/∂w 和 ∂C_x/∂b。网络里两万多个参数，逐个求偏导不现实，反向传播是用链式法则把这些偏导一次算完的算法。

它围绕一个量转：δ^l_j，第 l 层第 j 个神经元的误差。定义是

text
δ^l_j = ∂C / ∂z^l_j

也就是代价对本层带权输入的偏导。这个量一有，偏置和权重的梯度立刻就有，因为 z^l = W^l a^(l-1) + b^l 对 b 和 w 的偏导就是 1 和 a^(l-1)。

四个公式，书里就是这么摆的：

text
δL = ∇_a C ⊙ σ'(zL)                            输出层误差
δl = ((W^(l+1))^T * δ^(l+1)) ⊙ σ'(zl)           误差回传
∂C/∂b^l = δ^l                                  偏置梯度
∂C/∂w^l = δ^l * (a^(l-1))^T                    权重梯度

⊙ 是逐元素乘，(W^(l+1))^T 是下一层权重矩阵的转置。

四个公式各自的直觉：

第一个，输出层误差等于「代价对输出的导数」乘「激活函数在本层的斜率」。代价函数在说「输出该往哪调」，σ' 在说「输入的这一点点变化能在输出上体现多少」。两者相乘，才是真正该由输出层承担的责任。

第二个是全部魔法所在。后一层的误差 δ^(l+1) 乘上转置权重 (W^(l+1))^T，就摊回了前一层。前向是 W a，反向是 W^T δ，方向相反，用的是同一个矩阵。这一条把误差从输出层一路推回输入侧。

第三个最省事。偏置的梯度就是误差本身，因为偏置直接加在 z 上，导数系数是 1。

第四个，权重的梯度等于「本层的误差」乘「上一层激活的转置」。上一层那个神经元激活得越强、本层误差越大，这条连接背的责任就越大。

代进具体代价函数，第一个公式还会再简化：

代价函数 输出层误差 δL 说明
二次代价 (aL - y) ⊙ σ'(zL) 保留了 σ'，饱和时会衰减
交叉熵 aL - y σ' 被约掉，饱和不影响
对数似然 + softmax aL - y 同上

交叉熵那一行就是第五章说的「解决了输出层学习缓慢」在公式层面的样子。

完整的计算流程，分两层嵌套：

text
update_mini_batch(mini_batch, eta):
    初始化 nabla_w、nabla_b 为全零，形状和 weights、biases 一致
    for 每个样本 (x, y) in mini_batch:
        调用 backprop(x, y)，得到这个样本的梯度
        累加：nabla_w += 梯度_w，nabla_b += 梯度_b
    更新：w = w - (eta/m) * nabla_w，b = b - (eta/m) * nabla_b

backprop(x, y):
    前向：逐层算 z^l = W^l a^(l-1) + b^l，a^l = σ(z^l)，把每层的 z 和 a 存下来
    输出层：δL = ∇_a C ⊙ σ'(zL)，存 ∂C/∂w^L = δL (a^(L-1))^T，∂C/∂b^L = δL
    反向：for l = L-1, L-2, ..., 2:
              δl = ((W^(l+1))^T δ^(l+1)) ⊙ σ'(zl)
              存 ∂C/∂w^l = δl (a^(l-1))^T，∂C/∂b^l = δl
    返回累积好的 (nabla_b, nabla_w)

注意 a、b、z、y、δ 全是列向量。这个约定不写清楚，代码里矩阵乘的顺序会错。

为什么这一趟能省下巨量计算？因为 δ^l 只算一次，就被 l-1 层和 l 层的梯度共用。挨个参数求偏导的复杂度是「参数量 × 层数」，反向传播是「参数量」，差一个层数的因子。

拿 [784, 30, 10] 这个网络把每个量的形状列出来，写代码时照着对：

量 形状 来源
x (784, 1) 一个训练样本
W^2 (30, 784) 第 2 层权重
b^2 (30, 1) 第 2 层偏置
z^2 / a^2 (30, 1) W^2 x + b^2 过 σ
W^3 (10, 30) 第 3 层权重
b^3 (10, 1) 第 3 层偏置
z^3 / aL (10, 1) 网络输出
y (10, 1) one-hot 目标
δL (10, 1) (aL - y) ⊙ σ'(zL)
∇_w^3 (10, 30) δL @ (a^2)^T
∇_b^3 (10, 1) δL
δ^2 (30, 1) (W^3)^T δL ⊙ σ'(z^2)
∇_w^2 (30, 784) δ^2 @ x^T
∇_b^2 (30, 1) δ^2

整张表里没有一处形状是随便来的。δL @ (a^2)^T 是 (10,1) 乘 (1,30)，出来 (10,30)，和 W^3 一样；δ^2 @ x^T 是 (30,1) 乘 (1,784)，出来 (30,784)，和 W^2 一样。矩阵乘的行列配对规则自动保证了梯度形状和参数形状一致，这也是为什么形状错了会立刻炸——它们必须一致。

∇_b 那一列全是 (n, 1)，因为单个样本的偏置梯度就是误差列向量本身。换成小批量之后，m 个样本的偏置梯度要按行求和，形状还是 (n, 1)，这就是 keepdims=True 存在的理由。

三层网络，Sigmoid 激活，二次代价，非向量化的实现：

python
import numpy as np
import random

def sigmod(z):
    """S 型函数。z 是标量、向量或 numpy 数组时按元素计算。"""
    return 1.0 / (1.0 + np.exp(-z))

def sigmod_prime(z):
    """S 型函数的导数。"""
    return sigmod(z) * (1 - sigmod(z))


class Network(object):
    def __init__(self, sizes):
        # sizes：各层神经元个数，如 [784, 30, 10]
        self.num_layers = len(sizes)
        self.sizes = sizes
        # 第 i 层到第 i+1 层的权重矩阵，形状 (sizes[i+1], sizes[i])
        self.weights = [np.random.randn(y, x) for x, y in zip(sizes[:-1], sizes[1:])]
        # 第 i+1 层的偏置列向量，形状 (sizes[i+1], 1)
        self.biases = [np.random.randn(y, 1) for y in sizes[1:]]

    def feedforward(self, a):
        """给定输入向量 a，返回网络输出。"""
        for b, w in zip(self.biases, self.weights):
            a = sigmod(np.dot(w, a) + b)
        return a

    def SGD(self, training_data, epochs, mini_batch_size, eta, test_data=None):
        if test_data:
            n_test = len(test_data)
        n = len(training_data)
        for j in range(epochs):
            # 每个 epoch 先打乱，再切小批量
            random.shuffle(training_data)
            mini_batches = [training_data[k:k + mini_batch_size]
                            for k in range(0, n, mini_batch_size)]
            for mini_batch in mini_batches:
                self.update_mini_batch(mini_batch, eta)
            # 一轮结束，评估一次
            if test_data:
                print('Epoch {0}: {1}/{2}'.format(j, self.evaluate(test_data), n_test))
            else:
                print('Epoch {0} complete'.format(j))

    def update_mini_batch(self, mini_batch, eta):
        nabla_b = [np.zeros(b.shape) for b in self.biases]
        nabla_w = [np.zeros(w.shape) for w in self.weights]
        for x, y in mini_batch:
            delta_nabla_b, delta_nabla_w = self.backprop(x, y)
            nabla_b = [nb + dnb for nb, dnb in zip(nabla_b, delta_nabla_b)]
            nabla_w = [nw + dnw for nw, dnw in zip(nabla_w, delta_nabla_w)]
        # w = w - (eta/m) * sum(dC_x/dw)
        self.weights = [w - (eta / len(mini_batch)) * nw
                        for w, nw in zip(self.weights, nabla_w)]
        # b = b - (eta/m) * sum(dC_x/db)
        self.biases = [b - (eta / len(mini_batch)) * nb
                       for b, nb in zip(self.biases, nabla_b)]

    def backprop(self, x, y):
        nabla_b = [np.zeros(b.shape) for b in self.biases]
        nabla_w = [np.zeros(w.shape) for w in self.weights]
        # 前向：存下每一层的 z 和 sigma(z)
        activation = x
        activations = [x]
        zs = []
        for b, w in zip(self.biases, self.weights):
            z = np.dot(w, activation) + b
            zs.append(z)
            activation = sigmod(z)
            activations.append(activation)
        # 输出层误差
        delta = self.cost_derivative(activations[-1], y) * sigmod_prime(zs[-1])
        nabla_b[-1] = delta
        nabla_w[-1] = np.dot(delta, activations[-2].transpose())
        # 逐层回传
        for l in range(2, self.num_layers):
            z = zs[-l]
            sp = sigmod_prime(z)
            delta = np.dot(self.weights[-l + 1].transpose(), delta) * sp
            nabla_b[-l] = delta
            nabla_w[-l] = np.dot(delta, activations[-l - 1].transpose())
        return (nabla_b, nabla_w)

    def evaluate(self, test_data):
        # np.argmax 取最大值下标，得到预测数字
        test_results = [(np.argmax(self.feedforward(x)), y) for x, y in test_data]
        return sum(int(x == y) for x, y in test_results)

    def cost_derivative(self, output_activations, y):
        """二次代价对输出的偏导 dC/da = a - y。"""
        return (output_activations - y)

上面的 backprop 每次只处理一个样本，Python 层的循环是瓶颈。向量化的做法是把整个小批量拼成矩阵，一次前向把 m 个样本全过完。

关键改动只有一处：把 m 个列向量横着摞起来。

text
X = [样本1列向量  样本2列向量  ...  样本m列向量]    形状 (784, m)
Y = [样本1类别列向量  样本2列向量  ...  样本m列向量]  形状 (10, m)

然后权重梯度变成 delta @ activations[-2].T，偏置梯度变成一个按行求和。整段替换掉原来的 update_mini_batch：

python
def update_mini_batch(self, mini_batch, eta):
    """向量化版本：一次性处理整个小批量"""
    nabla_b = [np.zeros(b.shape) for b in self.biases]
    nabla_w = [np.zeros(w.shape) for w in self.weights]

    m = len(mini_batch)
    training_x = [x for x, y in mini_batch]      # m 个 (784, 1)
    training_y = [y for x, y in mini_batch]      # m 个 (10, 1)

    # 摞成矩阵，注意要转置
    X = np.array(training_x).reshape(m, training_x[0].shape[0]).T   # (784, m)
    Y = np.array(training_y).reshape(m, training_y[0].shape[0]).T   # (10, m)

    # 前向
    activation = X
    activations = [X]
    zs = []
    for b, w in zip(self.biases, self.weights):
        z = np.dot(w, activation) + b
        zs.append(z)
        activation = sigmod(z)
        activations.append(activation)

    # 输出层误差
    delta = self.cost_derivative(activations[-1], Y) * sigmod_prime(zs[-1])
    nabla_w[-1] = np.dot(delta, activations[-2].transpose())
    # 偏置梯度：按行求和，保持二维
    nabla_b[-1] = np.sum(delta, axis=1, keepdims=True)

    # 反向回传
    for l in range(2, self.num_layers):
        delta = np.dot(self.weights[-l + 1].transpose(), delta) * sigmod_prime(zs[-l])
        nabla_w[-l] = np.dot(delta, activations[-l - 1].transpose())
        nabla_b[-l] = np.sum(delta, axis=1, keepdims=True)

    # 更新
    self.weights = [w - eta / m * nw for w, nw in zip(self.weights, nabla_w)]
    self.biases = [b - eta / m * nb for b, nb in zip(self.biases, nabla_b)]

np.sum(..., axis=1, keepdims=True) 里的 keepdims 不能省。省掉之后偏置从 (30, 1) 退化成 (30,)，下一轮广播时会悄悄做错形状的加法，程序不报错，结果全歪。这是 numpy 里最典型的静默失败。

X 的构造里那个 .T 也不能省。np.array(training_x) 的形状是 (m, 784)，每行一个样本；矩阵乘要求 (784, m)，每列一个样本。写反了程序照样跑，准确率卡在 10% 左右，跟瞎猜一个水平。

七、过拟合与正则化 #

过拟合说的是：模型对已有的数据表现很好，但对新数据很难泛化。对一个模型真正的测验，是它对没见过的场景的预测能力。

书里给的判断信号很实用。训练集准确率一路涨到 100%，测试集准确率涨到 98% 就横住了，两边差出两个点——这就是过拟合。代价曲线更直观：训练代价单调下降，测试代价先降后升，那个拐点就是开始记住噪声的位置。

缓解手段，书里列了五条：

  • L1 规范化
  • L2 规范化
  • 弃权（dropout）
  • 人为增加训练样本
  • 早停（用校验集挑迭代轮数）

L2 是书里重点讲的那个。它在原始代价后面加一项所有权重平方和：

text
C = C0 + (λ / 2n) * Σ_w w^2

C0 是原始代价函数，λ 是规范化参数，n 是训练样本数。这个式子可以读成一种折中：一边要最小化原始代价，一边要把权重压小。λ 小，偏向原始代价；λ 大，偏向小权重。

权重更新法则跟着变：

text
w = (1 - ηλ/n) * w - (η/m) * Σ ∂C_x/∂w

跟原来的式子比，多出来的 (1 - ηλ/n) 让权重每一步先自己缩一点，再减梯度。所以 L2 也叫权重衰减。

小权重为什么能缓解过拟合？因为权重小，输入的一点扰动传到输出就被压掉了。也就是说，网络学到的函数更平滑，不会为了记住某个训练样本而在它周围挖一个窄坑。平滑的函数在训练集之外的地方更靠得住。

L1 是另一条路：

text
C = C0 + (λ/n) * Σ_w |w|

它的梯度是常数 λ/n 乘符号，不管权重多小都推着往 0 走，结果是一部分权重被压成精确的 0，得到稀疏解。L2 是把所有权重均匀地缩小，L1 是挑一部分直接抹掉。

弃权的做法更粗暴：训练时每一轮按概率 p 随机把一部分隐藏神经元的输出置 0，测试时全部启用。

python
def dropout_layer(layer, p_dropout):
    srng = shared_randomstreams.RandomStreams(
        np.random.RandomState(0).randint(999999))
    # 二项分布 n=1，返回 1 的概率是 1-p_dropout
    mask = srng.binomial(n=1, p=1 - p_dropout, size=layer.shape)
    return layer * T.cast(mask, theano.config.floatX)

被丢掉的那部分输出，训练时按 1/(1-p_dropout) 放大回去，这样测试时全部启用，期望值不变。这一步漏掉，训练和测试的尺度就对不上，准确率会掉。

人为增加训练样本是第五种手段。MNIST 是数字图，把训练图轻微旋转、平移、缩放，生成新的样本，标签不变。网络见过更多姿态，对真实世界里写歪的字更耐受。

早停是这五条里最省事的。每一轮在校验集上算准确率，记下最高的那一轮的参数，后面准确率不再涨就停。Network2 的 SGD 每轮都打印 Accuracy on evaluation data，就是在给早停提供依据。

把改进落到代码上，Network2 相对 Network1 改了两处：

  • 代价函数抽成类，可切换二次代价和交叉熵，规范化项加进 total_cost 和参数更新。
  • 权重、偏置初始化改成 N(0, 1/n_in)，缓解隐藏层饱和。

import numpy as np
import json
import random
import sys


class QuadraticCost(object):
    @staticmethod
    def fn(a, y):
        """C0 = 0.5 * sum((y_j - a_j)^2)"""
        return 0.5 * np.linalg.norm(a - y) ** 2

    @staticmethod
    def delta(z, a, y):
        """输出层误差 δL = (a - y) * σ'(z)"""
        return (a - y) * sigmod_prime(z)


class CrossEntropyCost(object):
    @staticmethod
    def fn(a, y):
        """C0 = -sum[y*ln(a) + (1-y)*ln(1-a)]"""
        # nan_to_num 把 log(0) 产生的 nan/inf 换成有限值，
        # 不加这一层，一个样本就能把整批代价变成 nan
        return np.sum(-1 * np.nan_to_num(y * np.log(a) + (1 - y) * np.log(1 - a)))

    @staticmethod
    def delta(z, a, y):
        """输出层误差 δL = a - y，σ' 在这里被约掉"""
        return (a - y)


class Network(object):
    def __init__(self, sizes, cost=CrossEntropyCost):
        self.num_layers = len(sizes)
        self.sizes = sizes
        self.default_weight_initializer()
        self.cost = cost

    def default_weight_initializer(self):
        """改进版：w 服从 N(0, 1/nin)，b 服从 N(0, 1)"""
        self.biases = [np.random.randn(y, 1) for y in self.sizes[1:]]
        self.weights = [np.random.randn(y, x) / np.sqrt(x)
                        for x, y in zip(self.sizes[:-1], self.sizes[1:])]

    def large_weight_initializer(self):
        """对照版：w、b 都服从 N(0, 1)，用来复现隐藏层饱和"""
        self.biases = [np.random.randn(y, 1) for y in self.sizes[1:]]
        self.weights = [np.random.randn(y, x)
                        for x, y in zip(self.sizes[:-1], self.sizes[1:])]

    def feedforward(self, a):
        for b, w in zip(self.biases, self.weights):
            a = sigmod(np.dot(w, a) + b)
        return a

    def SGD(self, training_data, epochs, mini_batch_size, eta, lamda,
            evaluation_data=None,
            monitor_evaluation_cost=False,
            monitor_evaluation_accuracy=False,
            monitor_training_cost=False,
            monitor_training_accuracy=False):
        if evaluation_data:
            n_data = len(evaluation_data)
        n = len(training_data)
        evaluation_cost, evaluation_accuracy = [], []
        training_cost, training_accuracy = [], []
        for j in range(epochs):
            random.shuffle(training_data)
            mini_batches = [training_data[k:k + mini_batch_size]
                            for k in range(0, n, mini_batch_size)]
            for mini_batch in mini_batches:
                self.update_mini_batch(mini_batch, eta, lamda, n)
            print('Epoch {0} training complete'.format(j))
            if monitor_evaluation_cost:
                cost = self.total_cost(evaluation_data, lamda, convert=True)
                evaluation_cost.append(cost)
                print('Cost on evaluation data: {0}'.format(cost))
            if monitor_evaluation_accuracy:
                accuracy = self.accuracy(evaluation_data)
                evaluation_accuracy.append(accuracy)
                print('Accuracy on evaluation data: {0}/{1}'.format(accuracy, n_data))
            if monitor_training_cost:
                cost = self.total_cost(training_data, lamda)
                training_cost.append(cost)
                print('Cost on training data: {0}'.format(cost))
            if monitor_training_accuracy:
                accuracy = self.accuracy(training_data, convert=True)
                training_accuracy.append(accuracy)
                print('Accuracy on training data: {0}/{1}'.format(accuracy, n))
        return evaluation_cost, evaluation_accuracy, training_cost, training_accuracy

    def update_mini_batch(self, mini_batch, eta, lamda, n):
        nabla_b = [np.zeros(b.shape) for b in self.biases]
        nabla_w = [np.zeros(w.shape) for w in self.weights]
        for x, y in mini_batch:
            delta_nabla_b, delta_nabla_w = self.backprop(x, y)
            nabla_b = [nb + dnb for nb, dnb in zip(nabla_b, delta_nabla_b)]
            nabla_w = [nw + dnw for nw, dnw in zip(nabla_w, delta_nabla_w)]
        # L2 的痕迹就在 (1 - eta*lamda/n) 这一项上
        self.weights = [(1 - eta * lamda / n) * w - (eta / len(mini_batch)) * nw
                        for w, nw in zip(self.weights, nabla_w)]
        self.biases = [b - (eta / len(mini_batch)) * nb
                       for b, nb in zip(self.biases, nabla_b)]

    def backprop(self, x, y):
        nabla_b = [np.zeros(b.shape) for b in self.biases]
        nabla_w = [np.zeros(w.shape) for w in self.weights]
        activation = x
        activations = [x]
        zs = []
        for b, w in zip(self.biases, self.weights):
            z = np.dot(w, activation) + b
            zs.append(z)
            activation = sigmod(z)
            activations.append(activation)
        # 输出层误差交给代价函数类去算，这里不再写死
        delta = self.cost.delta(zs[-1], activations[-1], y)
        nabla_b[-1] = delta
        nabla_w[-1] = np.dot(delta, activations[-2].transpose())
        for l in range(2, self.num_layers):
            z = zs[-l]
            sp = sigmod_prime(z)
            delta = np.dot(self.weights[-l + 1].transpose(), delta) * sp
            nabla_b[-l] = delta
            nabla_w[-l] = np.dot(delta, activations[-l - 1].transpose())
        return (nabla_b, nabla_w)

    def accuracy(self, data, convert=False):
        """convert=True 表示标签是 one-hot，需要先 argmax"""
        if convert:
            results = [(np.argmax(self.feedforward(x)), np.argmax(y))
                       for x, y in data]
        else:
            results = [(np.argmax(self.feedforward(x)), y) for x, y in data]
        return sum(int(x == y) for x, y in results)

    def total_cost(self, data, lamda, convert=False):
        cost = 0.0
        for x, y in data:
            if convert:
                y = vectorized_result(y)
            cost += self.cost.fn(self.feedforward(x), y)
        cost /= len(data)
        # 规范化项也计入总代价
        cost += 0.5 * lamda / len(data) * sum(np.linalg.norm(w) ** 2
                                              for w in self.weights)
        return cost

    def save(self, filename):
        data = {'sizes': self.sizes,
                'weights': self.weights,
                'biases': self.biases,
                'cost': str(self.cost.__name__)}
        with open(filename, 'w') as f:
            json.dump(data, f)

    @staticmethod
    def load(filename):
        with open(filename, 'r') as f:
            data = json.load(f)
        # 从当前模块里按名字找回代价函数类
        cost = getattr(sys.modules[__name__], data['cost'])
        net = Network(data['sizes'], cost=cost)
        net.weights = data['weights']
        net.biases = data['biases']
        return net


def vectorized_result(j):
    """把 0-9 的数字变成 10 维 one-hot 列向量"""
    e = np.zeros((10, 1))
    e[j] = 1.0
    return e


def sigmod(z):
    return 1.0 / (1.0 + np.exp(-z))


def sigmod_prime(z):
    return sigmod(z) * (1 - sigmod(z))

八、权重初始化与超参数 #

Network1 的初始化是 np.random.randn，标准正态。这个选择在浅层网络上勉强能用，在网络变宽时会直接卡死学习。

推理过程书里写得清楚。假设某层有 10000 个输入权重，输入 x 一半是 1 一半是 0，那么带权和：

text
z = Σ w_j x_j + b

w_j ~ N(0, 1)，5000 个非零项相加，z 服从 N(0, 501)，标准差约 22.4。z 落在 ±1 之外的概率极高，σ(z) 早就贴到 0 或者 1 上了。

后果是：隐藏神经元饱和，σ'(z) ≈ 0。权重上的一次微小调整只给激活值带来极其微弱的改变，这点改变再传到后面的层，代价几乎不动，梯度下降时这些权重学得极慢。

这个问题和第五章那个输出层饱和是同一类，但交叉熵救不了它——交叉熵只作用在输出层，管不到隐藏层。

修法是把初始化分布的尺度改成和输入数量挂钩：

text
w ~ N(0, 1/n_in)
b ~ N(0, 1)

n_in 是这一层的输入个数。上面那个例子，z 变成 N(0, 501/1000)，标准差约 0.7，绝大多数神经元落在 Sigmoid 的线性区，σ' 接近 1/4 的上限，梯度充足。

代码上就是多除一个 np.sqrt(x)：

python
self.weights = [np.random.randn(y, x) / np.sqrt(x)
                for x, y in zip(self.sizes[:-1], self.sizes[1:])]

这个思路在 TensorFlow 里对应 tf.truncated_normal(shape, stddev=0.1) 和 Xavier 初始化。

初始化只解决了「一开始」的问题。层数堆深之后，还有三个梯度问题：

问题 触发条件 表现 书里的对策
消失的梯度 导数绝对值小于 1/4，且初始化 w ~ N(0,1) 使权重绝对值小于 1 前面的隐藏层比后面的学得慢得多 换初始化；换 ReLU
激增的梯度 权重初始化得偏大，σ' 又不小 前面的隐藏层反而比后面的学得快 换初始化；梯度裁剪
不稳定的梯度 层数过多 各层学习速度差出数量级 让乘积平衡的机制，或换 ReLU

根本原因是第三个。前面层的梯度是后面层若干项的乘积，层数一多，连乘要么趋于 0 要么趋于无穷，本质上是数值不稳定。唯一让所有层以接近相同速度学习的方式，是所有这些因子恰好平衡。没有机制保证这种平衡，网络就不稳定。

ReLU 是对这个问题的直接回应：正区间上 σ'(z) = 1，连乘不再衰减。代价是负区间导数为 0，那些神经元会死掉，这也是 ReLU 的偏置要用小的正数初始化的原因——避免一开始就整片落在负区。

书里另外提的两个神经元模型：

  • tanh，tanh(z)，输出 (-1, 1)，零中心。零中心的输入让下一层的梯度方向更正，收敛比 Sigmoid 快一些，但饱和问题照旧。
  • ReLU，max(0, z)，正区间不饱和，计算便宜（只有一次比较），是现在隐藏层的默认选择。

三个激活函数的取舍，落到实际选型：

激活函数 值域 导数 饱和 适用位置
Sigmoid (0, 1) σ(1-σ)，最大 1/4 两端饱和 输出层配二分类，或浅层网络
tanh (-1, 1) 1 - tanh^2，最大 1 两端饱和 浅层网络的隐藏层
ReLU [0, +∞) 正区间 1，负区间 0 正区间不饱和 深层网络的隐藏层默认
softmax (0, 1)，和为 1 — — 多分类输出层

ReLU 有个副作用：负区间的导数是 0，一旦某个神经元的输入整片落在负区，它的梯度就永远是 0，权重再也不会更新，这个神经元彻底死掉。偏置初始化成 0.1 而不是 0，就是为了让初始状态下大部分神经元落在正区，先活下来。学习率设太大也会成片杀死神经元，这是 ReLU 网络训练不稳的主要原因。

第四章那个「神经网络可以计算任何函数」的结论值得单独说一句。它讲的是万能近似定理：包含一个隐藏层的网络，能以任意给定的精度近似任何连续函数。书里用一元函数、二元函数、多元实值函数各做了一遍可视化。

这个定理容易被读成「一层就够了，深度没必要」。它说的是表示能力，不是学习能力。一层网络要拟合复杂函数，宽度会爆炸；深层网络靠层次复用，用少得多的参数达到同样精度。能表示和能学出来，是两件事。

第三章末尾还提了两个随机梯度下降的变体：

  • Hessian 技术：用二阶导数信息，收敛更快。但 Hessian 矩阵是参数数量的平方，两万个参数就是四亿个元素，内存和计算都扛不住。
  • momentum：给更新加惯性。
text
v = μ * v - η * ∇C
w = w + v

μ 是动量系数，取 0.5 到 0.9。梯度方向稳定时越走越快，方向来回摆时相互抵消。这个技巧在损失曲面像长峡谷的时候特别管用——SGD 在峡谷两侧来回弹，momentum 把它压成沿谷底前进。

超参数汇总，以及本篇两个实现里实际用的值：

超参数 作用 书里取值 调大的后果
epochs 训练集过几遍 30 / 40 过拟合，校验代价回升
mini_batch_size 一次更新用几个样本 10 梯度更准，更新次数变少，单轮变慢
eta 学习率 3.0 / 0.5 / 0.015 震荡甚至发散
lamda L2 规范化强度 5.0 / 0.0 欠拟合，权重被压太平
隐藏层宽度 容量 30 / 100 / 1000 参数变多，训练慢，过拟合
初始化 stddev 初始权重尺度 1/sqrt(n_in) 饱和，学习停滞
p_dropout 弃权比例 0.5 欠拟合，训练不稳

调参的顺序，书里没给系统的做法，实践上是从粗到细：先固定 lamda = 0，把 eta 调到损失能稳定下降又不震荡，再把 lamda 加上去压过拟合，最后动 epochs 和层宽。一次只动一个，看校验集，别看测试集——测试集是最后报数用的。

def weight_variable(shape):
    # 截断正态，标准差 0.1，把两倍标准差外的采样丢掉
    initial = tf.truncated_normal(shape, stddev=0.1)
    return tf.Variable(initial)


def bias_variable(shape):
    # 常数 0.1，不是 0。ReLU 神经元给 0 偏置容易一开始就死掉
    initial = tf.constant(0.1, shape=shape)
    return tf.Variable(initial)

y_ = tf.placeholder(tf.float32, shape=[None, 10])

# 隐藏层

b_h = bias_variable([1024])
hidden = tf.nn.relu(tf.matmul(x_, w_h) + b_h)

# 输出层
w_o = weight_variable([1024, 10])
b_o = bias_variable([10])
output = tf.nn.softmax(tf.matmul(hidden, w_o) + b_o)

# 三 对数似然损失 J = -(sum y*log(aL)) / n
cost = tf.reduce_mean(-tf.reduce_sum(y_ * tf.log(output), axis=1))

那两张曲线怎么读，值得说清楚。准确率图把 y 轴锁在 90 到 100，不是为了好看，是因为 0 到 90 那一段的信息量太低——几千步之后两条曲线都进了 95 以上，纵轴从 0 画起会把差别压成一条线。

两条线的关系是判断过拟合的第一手证据：

  • 训练准确率和测试准确率一起往上走，间距稳定在 1 个点以内，说明还在正常学习。
  • 训练准确率继续涨到 99.9%，测试准确率横在 98% 不动，间距拉开，说明开始记训练集了。
  • 测试准确率往下掉，几乎肯定是学习率太大或者批量太小，不是过拟合。

代价图同理。训练代价单调下降是应该的，测试代价先降后升的那个拐点，就是该早停的位置。

classification_report 打出来的三个指标，各有各的用法：

   number 0       1.00      1.00      1.00         2

   number 9       0.67      1.00      0.80         2

precision 是「判成这个类的样本里，有多少真的是这个类」，recall 是「这个类的样本里，有多少被找出来了」。24 个样本的规模下这些数字没有统计意义，它只是让你肉眼确认模型没跑偏。要看真的错在哪，得跑全量测试集再看混淆矩阵。

MNIST 上的混淆集中在几对：4 和 9、3 和 5、7 和 1、8 和 3。这几对在笔迹潦草时人也会看错，模型错在这里不算 bug。

这段程序有个明显的缺陷：层数是写死的。想加第三层隐藏层，就得再手写一对 w、b、一个 matmul、一个激活。五层网络意味着二十行重复代码，还容易在某一层写错激活函数。

第二版把网络封成一个类，层数由 sizes 决定。plot_gallery 和 title 沿用上一段，类里只管网络本身：

python
import numpy as np
import random
import tensorflow as tf
import matplotlib.pyplot as plt


class network(object):
    """按 sizes 自动展开的全连接网络"""

    def __init__(self, sizes):
        # 保存结构，注意 __sizes 是 Python 属性名，不是 TF 变量
        self.__sizes = sizes
        self.sizes = tf.placeholder(tf.int64, shape=[1, len(sizes)])
        self.num_layer = tf.size(self.sizes)

        # 权重：第 i 层到第 i+1 层，形状 (sizes[i], sizes[i+1])
        self.weights = [self.weight_variable(shape=(x, y))
                        for x, y in zip(sizes[:-1], sizes[1:])]
        # 偏置：形状必须是 (n,)，不能写成 (n, 1)
        self.biases = [self.bias_variable(shape=[x, ]) for x in sizes[1:]]

        self.x_ = tf.placeholder(tf.float32, shape=[None, sizes[0]])
        self.y_ = tf.placeholder(tf.float32, shape=[None, sizes[-1]])

        config = tf.ConfigProto()
        config.gpu_options.allow_growth = True
        self.sess = tf.InteractiveSession(config=config)

    def weight_variable(self, shape):
        # 标准差取 1/nin，对应书里 w ~ N(0, 1/n_in)
        initial = tf.truncated_normal(shape, mean=0.0, stddev=1.0 / shape[0])
        return tf.Variable(initial)

    def bias_variable(self, shape):
        initial = tf.truncated_normal(shape, mean=0.0, stddev=1.0 / shape[0])
        return tf.Variable(initial)

    def feedforward(self, x):
        """构建阶段：给定输入的 op，返回输出的 op"""
        output = x
        for i in range(len(self.__sizes) - 1):
            b, w = self.biases[i], self.weights[i]
            if i != len(self.__sizes) - 2:
                output = tf.nn.relu(tf.matmul(output, w) + b)
            else:
                # 最后一层用 softmax，其余层用 relu
                output = tf.nn.softmax(tf.matmul(output, w) + b)
        return output

    def fit(self, training_x, training_y, learning_rate=0.001,
            batch_size=64, epochs=10):
        output = self.feedforward(self.x_)
        cost = tf.reduce_mean(-tf.reduce_sum(self.y_ * tf.log(output), axis=1))
        train = tf.train.AdamOptimizer(learning_rate).minimize(cost)

        # 初始化必须在建好图之后，顺序反了变量还没创建
        self.sess.run(tf.global_variables_initializer())

        n = training_x.shape[0]
        for i in range(epochs):
            # 注意：这一行只打乱了一个两元素列表，样本顺序并没有变
            random.shuffle([training_x, training_y])
            x_batches = [training_x[k:k + batch_size] for k in range(0, n, batch_size)]
            y_batches = [training_y[k:k + batch_size] for k in range(0, n, batch_size)]

            for x_batch, y_batch in zip(x_batches, y_batches):
                train.run(feed_dict={self.x_: x_batch, self.y_: y_batch})

            train_cost = cost.eval(feed_dict={self.x_: training_x,
                                              self.y_: training_y})
            print('Epoch {0} Training set cost {1}:'.format(i, train_cost))

    def predict(self, test_x):
        output = self.feedforward(self.x_)
        return output.eval(feed_dict={self.x_: test_x})

    def accuracy(self, x, y):
        output = self.feedforward(self.x_)
        correct = tf.equal(tf.argmax(output, 1), tf.argmax(self.y_, 1))
        accuracy = tf.reduce_mean(tf.cast(correct, tf.float32))
        return accuracy.eval(feed_dict={self.x_: x, self.y_: y})

    def cost(self, x, y):
        output = self.feedforward(self.x_)
        cost = tf.reduce_mean(-tf.reduce_sum(self.y_ * tf.log(output), axis=1))
        return cost.eval(feed_dict={self.x_: x, self.y_: y})

跑出来的准确率同样在 97% ~ 98%。两层全连接网络在 MNIST 上就这么个水平，堆到 1024 个隐藏神经元也顶不上去，因为瓶颈不在宽度。

十、用 CNN 实现 MNIST #

前馈网络在 MNIST 上卡在 98% 附近，原因是它一开始就把图拉平成了 784 维向量。拉平之后，「哪个像素挨着哪个像素」这条信息没了，网络只能靠权重自己去学，而每个权重只对一个固定位置的像素负责。

卷积网络不拉平。它把图当成 28×28 的二维网格，用一个 5×5 的小窗口在上面滑动，每滑到一个位置就算一次「这个局部区域和卷积核有多像」。这个动作带来两个后果：

  • 参数共享。同一个 5×5 卷积核扫全图，28×28 个位置上用的是同一组 25 个权重。
  • 局部性先验。卷积核只看 5×5 的邻域，符合「笔画特征由邻近像素组成」这个事实。

书里第六章用 Theano 写了一个完整的卷积网络。保留这个版本有好处——Theano 的 conv2d 和 TensorFlow 的 tf.nn.conv2d 参数含义几乎一一对应，看懂一个就懂另一个。

整个程序按十四步展开，这个顺序照着抄也不会乱：

text
[1]  导入数据，拿到测试集和校验集
[2]  启动 InteractiveSession
[3]  定义权重、偏置两个初始化函数
[4]  定义卷积和池化函数
[5]  分配输入 x_ 和 y_ 两个 placeholder
[6]  把 x 从 (batch, 784) 改形到 (batch, 28, 28, 1)
[7]  定义第一层卷积的 w 和 b
[8]  x 和 w 卷积，加 b，过 ReLU，再过 max pooling
[9]  第二层卷积，重复第 7、8 步
[10] 全连接层
[11] 输出层之前加 dropout 压过拟合
[12] softmax 得到最终输出
[13] 写代价函数、训练步骤，交给优化器
[14] 在测试集上评估

第 4 步之所以把卷积和池化包成两个小函数，是因为它们各被调用两次。不包的话，tf.nn.conv2d(x, W, strides=[1,1,1,1], padding='SAME') 那串参数要写四遍，改一次步长得改四处。

第 11 步在 MNIST 上收益有限。这个任务本身不复杂，5 万张训练图足够压住过拟合，加不加 dropout 差半个点。但在 CIFAR 那种任务上，这一层是必须的。结构先留好，换个数据集就不用改骨架。

def ReLU(z):
    return T.maximum(0.0, z)


def load_data_shared(filename="data/mnist.pkl.gz"):
    with gzip.open(filename, 'rb') as f:
        training_data, validation_data, test_data = pickle.load(f, encoding='bytes')

    def shared(data):
        shared_x = theano.shared(
            np.asarray(data[0], dtype=theano.config.floatX), borrow=True)
        shared_y = theano.shared(
            np.asarray(data[1], dtype=theano.config.floatX), borrow=True)
        # y 转 int32，和后面 y_out 的类型对齐
        return shared_x, T.cast(shared_y, "int32")

    return [shared(training_data), shared(validation_data), shared(test_data)]


class ConvPoolLayer(object):
    """卷积 + 最大池化，合成一层"""

    def __init__(self, filter_shape, image_shape, poolsize=(2, 2),
                 activation_fn=sigmoid):
        # filter_shape: (滤波器个数, 输入深度, 高, 宽)，如 (20, 1, 5, 5)
        # image_shape:  (mini_batch_size, 深度, 高, 宽)，如 (10, 1, 28, 28)
        self.filter_shape = filter_shape
        self.image_shape = image_shape
        self.poolsize = poolsize
        self.activation_fn = activation_fn

        n_out = filter_shape[0] * np.prod(filter_shape[2:]) / np.prod(poolsize)
        self.w = theano.shared(
            np.asarray(np.random.normal(loc=0.0, scale=np.sqrt(1.0 / n_out),
                                        size=filter_shape),
                       dtype=theano.config.floatX),
            name='w', borrow=True)

        self.b = theano.shared(
            np.asarray(np.random.normal(loc=0.0, scale=1.0,
                                        size=(filter_shape[0],)),
                       dtype=theano.config.floatX),
            name='b', borrow=True)
        self.params = [self.w, self.b]

    def set_inpt(self, inpt, inpt_dropout, mini_batch_size):
        self.inpt = inpt.reshape(self.image_shape)
        # 卷积，输出还没过激活
        conv_out = conv.conv2d(input=self.inpt, filters=self.w,
                               filter_shape=self.filter_shape,
                               image_shape=self.image_shape)
        # 2x2 最大池化
        pooled_out = pool_2d(input=conv_out, ds=self.poolsize,
                             ignore_border=True)
        # b 是一维的，dimshuffle 成 (1, n, 1, 1) 才能和四维输出相加
        self.output = self.activation_fn(
            pooled_out + self.b.dimshuffle('x', 0, 'x', 'x'))
        self.output_dropout = self.output


class FullyConnectedLayer(object):
    """全连接层"""

    def __init__(self, n_in, n_out, activation_fn=sigmoid, p_dropout=0.0):
        self.n_in = n_in
        self.n_out = n_out
        self.activation_fn = activation_fn
        self.p_dropout = p_dropout

        self.w = theano.shared(
            np.asarray(np.random.normal(loc=0.0, scale=np.sqrt(1.0 / n_out),
                                        size=(n_in, n_out)),
                       dtype=theano.config.floatX),
            name='w', borrow=True)

        self.b = theano.shared(
            np.asarray(np.random.normal(loc=0.0, scale=1.0, size=(n_out,)),
                       dtype=theano.config.floatX),
            name='b', borrow=True)
        self.params = [self.w, self.b]

    def set_inpt(self, inpt, inpt_dropout, mini_batch_size):
        # 输入是 mini_batch_size 个 1*28*28，这里按层宽展平
        self.inpt = inpt.reshape((mini_batch_size, self.n_in))
        self.output = self.activation_fn(T.dot(self.inpt, self.w) + self.b)

        # 弃权版本
        self.inpt_dropout = dropout_layer(
            inpt_dropout.reshape((mini_batch_size, self.n_in)), self.p_dropout)
        # 补偿尺度：训练时丢掉 p，测试时全启用，期望才对齐
        self.inpt_dropout /= 1 - self.p_dropout
        self.output_dropout = self.activation_fn(
            T.dot(self.inpt_dropout, self.w) + self.b)
        self.y_out = T.argmax(self.output_dropout, axis=1)

    def accuracy(self, y):
        return T.mean(T.eq(y, self.y_out))


class SoftmaxLayer(object):
    """柔性最大输出层"""

    def __init__(self, n_in, n_out, p_dropout=0.0):
        self.n_in = n_in
        self.n_out = n_out
        self.p_dropout = p_dropout
        # 输出层从零开始训，权重和偏置都初始化为 0
        self.w = theano.shared(
            np.zeros((n_in, n_out), dtype=theano.config.floatX),
            name='w', borrow=True)
        self.b = theano.shared(
            np.zeros((n_out,), dtype=theano.config.floatX),
            name='b', borrow=True)
        self.params = [self.w, self.b]

    def set_inpt(self, inpt, inpt_dropout, mini_batch_size):
        self.inpt = inpt.reshape((mini_batch_size, self.n_in))
        self.output = softmax(T.dot(self.inpt, self.w) + self.b)

        self.inpt_dropout = dropout_layer(
            inpt_dropout.reshape((mini_batch_size, self.n_in)), self.p_dropout)
        self.inpt_dropout /= 1 - self.p_dropout
        self.output_dropout = softmax(T.dot(self.inpt_dropout, self.w) + self.b)
        self.y_out = T.argmax(self.output_dropout, axis=1)

    def cost(self, net):
        """对数似然代价：只取真实类别那一项，再取负平均"""
        return -T.mean(T.log(self.output_dropout)[T.arange(net.y.shape[0]), net.y])

    def accuracy(self, y):
        return T.mean(T.eq(self.y_out, y))


def size(data):
    return data[0].get_value(borrow=True).shape[0]


def dropout_layer(layer, p_dropout):
    srng = shared_randomstreams.RandomStreams(
        np.random.RandomState(0).randint(999999))
    # 二项分布，n=1，返回 1 的概率是 1-p_dropout
    mask = srng.binomial(n=1, p=1 - p_dropout, size=layer.shape)
    return layer * T.cast(mask, theano.config.floatX)


class Network(object):
    def __init__(self, layers, mini_batch_size):
        self.layers = layers
        self.mini_batch_size = mini_batch_size
        self.params = [param for layer in self.layers for param in layer.params]
        self.x = T.matrix('x')
        self.y = T.ivector('y')

        # 把每层的输出接到下一层的输入上
        init_layer = self.layers[0]
        init_layer.set_inpt(self.x, self.x, self.mini_batch_size)
        for j in range(1, len(self.layers)):
            prev_layer, layer = self.layers[j - 1], self.layers[j]
            layer.set_inpt(prev_layer.output, prev_layer.output_dropout,
                           self.mini_batch_size)
        self.output = self.layers[-1].output
        self.output_dropout = self.layers[-1].output_dropout

    def SGD(self, training_data, epochs, mini_batch_size, eta,
            validation_data, test_data, lamda=0.0):
        training_x, training_y = training_data
        validation_x, validation_y = validation_data
        test_x, test_y = test_data

        num_training_batches = int(size(training_data) / mini_batch_size)
        num_validation_batches = int(size(validation_data) / mini_batch_size)
        num_test_batches = int(size(test_data) / mini_batch_size)

        # L2 项：所有权重元素的平方和
        l2_norm_squared = sum([(layer.w ** 2).sum() for layer in self.layers])
        cost = self.layers[-1].cost(self) + \
            0.5 * lamda * l2_norm_squared / mini_batch_size
        grads = T.grad(cost, self.params)
        updates = [(param, param - eta * grad)
                   for param, grad in zip(self.params, grads)]

        i = T.lscalar()   # 小批量索引
        train_mb = theano.function(
            [i], cost, updates=updates,
            givens={
                self.x: training_x[i * self.mini_batch_size:
                                   (i + 1) * self.mini_batch_size],
                self.y: training_y[i * self.mini_batch_size:
                                   (i + 1) * self.mini_batch_size]})

        validate_mb_accuracy = theano.function(
            [i], self.layers[-1].accuracy(self.y),
            givens={
                self.x: validation_x[i * self.mini_batch_size:
                                     (i + 1) * self.mini_batch_size],
                self.y: validation_y[i * self.mini_batch_size:
                                     (i + 1) * self.mini_batch_size]})

        test_mb_accuracy = theano.function(
            [i], self.layers[-1].accuracy(self.y),
            givens={
                self.x: test_x[i * self.mini_batch_size:
                               (i + 1) * self.mini_batch_size],
                self.y: test_y[i * self.mini_batch_size:
                               (i + 1) * self.mini_batch_size]})

        self.test_mb_predictions = theano.function(
            [i], self.layers[-1].y_out,
            givens={
                self.x: test_x[i * self.mini_batch_size:
                               (i + 1) * self.mini_batch_size]})

        best_validation_accuracy = 0.0
        for epoch in range(epochs):
            for minibatch_index in range(num_training_batches):
                iteration = num_training_batches * epoch + minibatch_index
                if iteration % 1000 == 0:
                    print('Training mini_batch number {0}'.format(iteration))
                cost_ij = train_mb(minibatch_index)

                # 一轮跑完，校验一次
                if (iteration + 1) % num_training_batches == 0:
                    validation_accuracy = np.mean(
                        [validate_mb_accuracy(j)
                         for j in range(num_validation_batches)])
                    print('Epoch {0}: validation accuracy {1:.2%}'.format(
                        epoch, validation_accuracy))
                    # 只记住最好的那一轮
                    if validation_accuracy >= best_validation_accuracy:
                        print('This is the best validation accuracy to date.')
                        best_validation_accuracy = validation_accuracy
                        best_iteration = iteration
                        if test_data:
                            test_accuracy = np.mean(
                                [test_mb_accuracy(j)
                                 for j in range(num_test_batches)])
                            print('The corresponding test accuracy is {0:.2%}'
                                  .format(test_accuracy))

        print('Finished training network.')
        print('Best validation accuracy of {0:.2%} obtained at iteration {1}'
              .format(best_validation_accuracy, best_iteration))
        print('Corresponding test accuracy of {0:.2%}'.format(test_accuracy))

尺寸是一路缩下来的，而且 Theano 这版和 TF 版缩法不同。Theano 的 conv.conv2d 在这个写法下走 valid 卷积，不补零：28×28 过 5×5 核变 24×24，2×2 池化变 12×12，深度 20；再过一次 5×5 变 8×8，池化变 4×4，深度 40。所以全连接层的输入是 40 * 4 * 4 = 640。TF 版全程 SAME：28 → 28 → 14 → 14 → 7，展平是 7 * 7 * 64 = 3136。两个数字差五倍，读代码时对着 shape 核一遍，比记结论可靠。

python
import tensorflow as tf

sess = tf.InteractiveSession(config=config)


def weight_variable(shape):
    initial = tf.truncated_normal(shape, stddev=0.1)
    return tf.Variable(initial)


def bias_variable(shape):
    # 0.1 而不是 0，ReLU 神经元用 0 偏置容易整片死掉
    initial = tf.constant(0.1, shape=shape)
    return tf.Variable(initial)


def conv2d(x, W):
    """strides[0] 和 strides[3] 必须是 1，中间两个才是空间步长"""
    return tf.nn.conv2d(x, W, strides=[1, 1, 1, 1], padding='SAME')


def max_pooling(x):
    return tf.nn.max_pool(x, ksize=[1, 2, 2, 1],
                          strides=[1, 2, 2, 1], padding='SAME')


x_ = tf.placeholder(tf.float32, [None, 784])
y_ = tf.placeholder(tf.float32, [None, 10])

# 从 (batch, 784) 变回 (batch, 28, 28, 1)，最后一维是通道数，灰度图取 1
X = tf.reshape(x_, shape=[-1, 28, 28, 1])

# 第一层卷积：32 个 5x5 核，输入深度 1，输出 32，形状 (5, 5, 1, 32)
w_conv1 = weight_variable([5, 5, 1, 32])
b_conv1 = bias_variable([32])
h_conv1 = tf.nn.relu(conv2d(X, w_conv1) + b_conv1)      # (?, 28, 28, 32)
h_pool1 = max_pooling(h_conv1)                          # (?, 14, 14, 32)

# 第二层卷积：64 个 5x5 核，输入深度 32
w_conv2 = weight_variable([5, 5, 32, 64])
b_conv2 = bias_variable([64])
h_conv2 = tf.nn.relu(conv2d(h_pool1, w_conv2) + b_conv2)  # (?, 14, 14, 64)
h_pool2 = max_pooling(h_conv2)                            # (?, 7, 7, 64)

# 全连接层：7x7x64 展平后接 1024 个隐藏神经元
h_pool2_flat = tf.reshape(h_pool2, [-1, 7 * 7 * 64])
w_h = weight_variable([7 * 7 * 64, 1024])
b_h = bias_variable([1024])
hidden = tf.nn.relu(tf.matmul(h_pool2_flat, w_h) + b_h)

# 弃权：keep_prob 用 placeholder 传，训练时喂 0.5，测试时喂 1.0
keep_prob = tf.placeholder(tf.float32)
hidden_drop = tf.nn.dropout(hidden, keep_prob)

# 输出层
w_o = weight_variable([1024, 10])
b_o = bias_variable([10])
output = tf.nn.softmax(tf.matmul(hidden_drop, w_o) + b_o)

cost = tf.reduce_mean(-tf.reduce_sum(y_ * tf.log(output), axis=1))
train = tf.train.AdamOptimizer(0.0001).minimize(cost)

correct = tf.equal(tf.argmax(output, 1), tf.argmax(y_, 1))
accuracy = tf.reduce_mean(tf.cast(correct, tf.float32))

training_accuracy_list, test_accuracy_list = [], []
training_cost_list, test_cost_list = [], []

sess.run(tf.global_variables_initializer())

for i in range(5000):
    x_batch, y_batch = mnist.train.next_batch(batch_size=64)
    train.run(feed_dict={x_: x_batch, y_: y_batch, keep_prob: 1.0})
    if (i + 1) % 200 == 0:
        training_accuracy, training_cost = sess.run(
            [accuracy, cost],
            feed_dict={x_: x_batch, y_: y_batch, keep_prob: 1.0})
        training_accuracy_list.append(training_accuracy)
        training_cost_list.append(training_cost)
        print('Step {0}:Training set accuracy {1}, cost {2}.'.format(
            i + 1, training_accuracy, training_cost))

# 测试分 200 批，每批 50 张。一次喂 10000 张会 OOM
for i in range(200):
    x_batch, y_batch = mnist.test.next_batch(batch_size=50)
    test_accuracy, test_cost = sess.run(
        [accuracy, cost],
        feed_dict={x_: x_batch, y_: y_batch, keep_prob: 1.0})
    test_accuracy_list.append(test_accuracy)
    test_cost_list.append(test_cost)
    if (i + 1) % 20 == 0:
        print('Step {0}:Test set accuracy {1}, cost {2}.'.format(
            i + 1, test_accuracy, test_cost))
print('Test accuracy:', np.mean(test_accuracy_list))

十一、tf.nn.conv2d 的用法 #

函数签名：

python
tf.nn.conv2d(input, filter, strides, padding,
             use_cudnn_on_gpu=None, name=None)

四个参数，一个都不能含糊：

参数 要求的形状或取值 含义 写错会怎样
input [batch, in_height, in_width, in_channels] 一个批次的图，四维 Tensor，float32 或 float64 通道维放错位置，卷积把通道当宽度扫
filter [filter_height, filter_width, in_channels, out_channels] 卷积核，第三维必须等于 input 的第四维 第三维填了滤波器个数，直接报形状不匹配
strides 长度 4 的一维向量，[1, sh, sw, 1] 四个维度各自的步长 写成两维、或者 batch 维不是 1，形状对但语义错
padding 字符串，'SAME' 或 'VALID' 是否补零 小写 'same' 报错；VALID 当 SAME 用会少一圈

use_cudnn_on_gpu 是布尔值，默认 True，走 cuDNN 加速。name 是图里的名字，调试和 TensorBoard 上用。

返回值是一个 Tensor，就是常说的 feature map。

input 的维度顺序是 NHWC，不是 PyTorch 那张 NCHW。批量在前，高、宽居中，通道在最后。MNIST 是灰度图，in_channels = 1；换成 RGB 彩图就是 3，这一维一变，第一层卷积核的第三维跟着变。

filter 的第四维是本层输出通道数，也就是「用几个卷积核」。写 32 就是这一层出 32 张 feature map，下一层看到的 in_channels 就是 32。这两处必须对上，对不上是最常见的报错来源。

**strides 是最容易写错的地方。**它是四维的，因为这四维分别对应 input 的四个维度：

text
strides = [stride_batch, stride_height, stride_width, stride_channel]

stride_batch 和 stride_channel 必须是 1。批量维跨步意味着跳过样本，通道维跨步意味着跳过特征图——这两种操作都没有意义，而且会让输出形状变得无法解释。真正有意义的是中间两个：高和宽的滑动步长。

python
# 正确写法：高、宽各走 1 步
strides = [1, 1, 1, 1]
# 正确写法：高、宽各走 2 步，尺寸减半
strides = [1, 2, 2, 1]
# 错误写法：只有两维，直接报错
strides = [2, 2]
# 错误写法：能跑，但跳了样本和通道，结果毫无意义
strides = [2, 2, 2, 2]

padding 只决定要不要补零，不决定补多少。两种取值的输出尺寸公式：

text
VALID:  output = ceil((in - filter + 1) / stride)
SAME:   output = ceil(in / stride)

SAME 的名字容易误导。它保证的是「输出尺寸等于输入除以步长后向上取整」，不是「输出尺寸等于输入尺寸」。只有在 stride = 1 的时候，两者才相等。

28×28 的图，5×5 的核，四种组合：

padding stride 输出高宽 说明
VALID 1 24 × 24 不补零，每边少 2
VALID 2 12 × 12 不补零再减半
SAME 1 28 × 28 补零，尺寸不变
SAME 2 14 × 14 补零后减半

SAME 补零的具体数量：

text
pad_height = max((out_height - 1) * stride_height + filter_height - in_height, 0)
pad_width  = max((out_width  - 1) * stride_width  + filter_width  - in_width,  0)
pad_top    = pad_height // 2
pad_bottom = pad_height - pad_top
pad_left   = pad_width // 2
pad_right  = pad_width - pad_left

补零量上下尽量均分，分不匀时多的一行加在下边，多的一列加在右边。28 配 5×5 配 stride 1：pad_height = max((28-1)*1 + 5 - 28, 0) = 4，上下各 2；宽度一样。补完变成 32×32，5×5 的核滑过去正好 28 个位置。

池化函数是同一套参数逻辑：

python
tf.nn.max_pool(input, ksize, strides, padding, name=None)
tf.nn.avg_pool(input, ksize, strides, padding, name=None)
参数 含义 注意
input 待池化的 feature map，[batch, h, w, c] 一般接在卷积层后面
ksize 池化窗口大小，四维 写成 [1, 2, 2, 1]，batch 和 channel 维为 1
strides 窗口滑动步长，四维 同上，[1, 2, 2, 1]
padding 'VALID' 或 'SAME' 和卷积一致

ksize 和 strides 都写成 1 在 batch 和 channel 维上，理由和卷积一样：不在样本之间池化，不在特征图之间池化。2×2 的窗口配 2 的步长，四个格子取一个最大值，尺寸精确减半，这是最常用的配置。

尺寸推演得自己动手算一遍。TF 版那个网络，从 28×28 到 3136 维向量：

text
输入                    (?, 28, 28, 1)
conv1  5x5, 32 核, SAME  (?, 28, 28, 32)
pool1  2x2, stride 2     (?, 14, 14, 32)
conv2  5x5, 64 核, SAME  (?, 14, 14, 64)
pool2  2x2, stride 2     (?, 7, 7, 64)
reshape                  (?, 3136)

每一步的通道数来自上一层卷积核的个数，不是随便写的。conv2 的 filter 第三维必须是 32，因为它的输入是 pool1 输出的 32 通道。这一条链断在哪一环，报错就指到哪一环。算不准尺寸时，把中间每个 op 的输出 shape 打出来，比对着公式猜快得多：

python
print(h_conv1.shape)   # (?, 28, 28, 32)
print(h_pool1.shape)   # (?, 14, 14, 32)
print(h_conv2.shape)   # (?, 14, 14, 64)
print(h_pool2.shape)   # (?, 7, 7, 64)

四个参数拆开验证一遍，别靠背：

python
# 造一个假输入：(2 张图, 28 高, 28 宽, 1 通道)
x = tf.placeholder(tf.float32, [2, 28, 28, 1])
# 造一个假卷积核：5x5，输入通道 1，输出 3 个特征图
W = tf.constant(np.random.randn(5, 5, 1, 3), dtype=tf.float32)

y = tf.nn.conv2d(x, W, strides=[1, 1, 1, 1], padding='VALID')
print(y.shape)      # (2, 24, 24, 3)：24 = 28 - 5 + 1，最后那维 3 = 核的个数

y = tf.nn.conv2d(x, W, strides=[1, 1, 1, 1], padding='SAME')
print(y.shape)      # (2, 28, 28, 3)：补零补回原尺寸

y = tf.nn.conv2d(x, W, strides=[1, 2, 2, 1], padding='SAME')
print(y.shape)      # (2, 14, 14, 3)：步长 2，尺寸减半

y = tf.nn.conv2d(x, W, strides=[1, 2, 2, 1], padding='VALID')
print(y.shape)      # (2, 12, 12, 3)：先减 4 再按步长 2 取整

四个输出里最后那维全是 3，因为卷积核的第四维是 3。它跟 strides 和 padding 一点关系都没有——输出通道数只由卷积核个数决定，这条规则记牢，能省掉一半的形状困惑。

头两维的变化只由 padding、strides、核尺寸三者共同决定。VALID 是先减核再除步长，SAME 是先除步长再补零补齐。两次除法的取整方向都是向上，ceil，不是 floor。写成 floor 会在图尺寸不能被步长整除时差一位，这种差一位的错在小图上会一路传下去，最后报个莫名其妙的形状错。

十二、两个实现的效果对比 #

两个实现在同一份数据上的表现：

实现 结构 参数量 测试准确率 训练配置
前馈网络 784 → 1024 → 10 814,090 97% ~ 98% Adam 0.001，batch 64，5000 步
前馈网络（类封装） 784 → 1024 → 10 814,090 97% ~ 98% Adam 0.0001，batch 64，10 轮
CNN（Theano） 2 组卷积池化 + 1000 + 100 + 10 762,670 99% 以上 SGD 0.015，batch 10，40 轮，L2
CNN（TensorFlow） 2 组卷积池化 + 1024 + 10 3,274,634 99% 以上 Adam 0.0001，batch 64，5000 步

先看一个反直觉的地方：**TF 版 CNN 的参数比前馈网络多，不是少。**前馈那版 81 万个参数，TF 版 CNN 327 万个，是它的四倍。

多出来的全在最后那个全连接层：3136 × 1024 就是 321 万。卷积部分反而很省——5×5×1×32 = 800 加 5×5×32×64 = 51200，两层卷积加起来五万二千个参数，只占全部参数的 1.6%。

所以准确率的提升不来自参数更多。它来自这五万多个参数被用在了对的地方。

第一是局部性。卷积核只看 5×5 的邻域，这直接对应「一个笔画特征由邻近的像素组成」这个事实。前馈网络没有这个先验，它要花大量参数去学「第 300 号像素和第 301 号像素是邻居」这件事，而这件事本来就知道。

第二是参数共享。同一个 5×5 卷积核在 28×28 个位置上都用一次。也就是说，一个「横折」检测器在图的左上角学会之后，在右下角自动可用。前馈网络要给每个位置单独学一个检测器，参数效率差一到两个数量级。

第三是层次化。第一层卷积学边缘和短笔画，第二层在第一层的输出上学拐角和圈，池化把位置精度抹掉、留下「有没有这个特征」。这个从局部到整体的堆叠，正是图像该有的结构。

第四是池化带来的小范围平移不变。数字 7 往右偏两个像素，池化后的特征几乎不变，分类结果也就不变。前馈网络对两个像素的平移是敏感的，因为输入向量的每一维都绑死了位置。

一句话：**归纳偏置对上了任务的结构，样本效率就上来了。**CNN 把「图像是二维的、特征是局部的、特征在哪都会出现」这三条先验写进了网络结构，剩下的才交给梯度下降去学。前馈网络什么先验都不给，全靠数据硬学，5 万张图不够。

训练成本的差别也在这一层。前馈网络跑 5000 步、每步 64 张图，CPU 上几分钟；CNN 同样的步数，CPU 上要几十分钟。卷积的乘加次数比矩阵乘高一个量级——第一层 28×28×32×5×5 就是 62.7 万次乘加，只算一张图。

代价和收益摆一起：

项目 前馈网络 CNN
测试准确率 97% ~ 98% 99% 以上
错误率 2% ~ 3% 1% 以下
单轮训练耗时（CPU） 基准 约 5 到 10 倍
参数里卷积部分的占比 无 1.6%
对平移的容忍度 低 高（池化带来）
对旋转的容忍度 低 低（两者都需要数据增广）

错误率从 3% 降到 1% 以下，看着只是两个点，换算到 1 万张测试集上，是从错 300 张变成错 100 张。在真实场景里，这个差距决定了一套系统能不能上线。

反过来，如果任务本身就是 784 维的无结构向量——比如表格数据、TF-IDF 文本特征——卷积没有意义，因为没有「邻域」这个概念。CNN 的优势全靠输入存在空间结构，把无结构数据硬塞进卷积层，拿到的不会比全连接好。

这个结论有边界。CNN 的内建先验是平移，不是旋转。MNIST 里的数字写得歪一点还能认，是因为池化顺带带来一点容忍度；把图整体转 90 度，准确率会掉得很难看。要处理旋转，得靠数据增广把旋转样本喂进去，让网络见过。

最后三条实操规则，比上面任何一条都省时间：

第一，形状先打印。凡是涉及矩阵乘、reshape、卷积的地方，动手之前先把每个张量的 shape 打出来，和自己算的对一遍。深度学习里九成的报错是形状问题，剩下的一成才需要看数学。

第二，先跑通再调优。拿 100 张图、1 个 epoch、最小的网络跑一遍，确认损失能降、准确率能过 10%（瞎猜水平）。这一步过了，再上全量数据。反过来做，一个形状 bug 会让你在等了三十分钟之后才发现。

第三，改动一次只改一个。学习率、批量大小、初始化、正则强度，同时改两个，结果变好了也不知道是谁的功劳，变差了也不知道该退哪个。

训练完记得把参数存下来。Network2 里的 save 和 load 是书里给的方案，用 JSON，跨语言都能读：

python
net.save('mnist_net.json')
net2 = Network.load('mnist_net.json')

存的时候要带上 self.cost.__name__，因为 load 要按这个名字把代价函数类找回来。少了这一项，读回来的 Network 用的是默认代价类，delta 算错，准确率直接掉一截。

TensorFlow 那边对应的做法是用 tf.train.Saver：

python
saver = tf.train.Saver()
saver.save(sess, 'model/mnist.ckpt')
# 恢复
saver.restore(sess, 'model/mnist.ckpt')

要注意 Saver 只存变量，不存图。恢复时必须先按同样的代码把图建好，再 restore 往变量里填值。图结构改了——加一层、改个名字——旧 checkpoint 就对不上，会报 key 找不到或者形状不匹配。
