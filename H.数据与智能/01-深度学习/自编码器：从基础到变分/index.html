本篇讲什么：自编码器这条线的完整脉络——瓶颈结构、损失与训练、拿它做降维、去噪自编码、栈式自编码，再走到底：变分自编码（VAE）、重参数化技巧、KL 散度，以及条件 VAE。

本篇不讲什么：不讲卷积自编码的逐层设计（只给一版可对照的代码），不讲稀疏自编码、收缩自编码的推导，不讲 ELBO 的严格变分证明，不讲扩散模型。

跨篇指路：CNN 基础看同目录的卷积网络那篇；概率分布与贝叶斯看概率图模型那篇；RBM 与深度信念网络是并行的另一条线，本篇只在对比处提一句。

人看一张图，不是逐像素去读的。扫一眼，形状、颜色、这像个什么东西，信息就进来了。机器能不能也这样？

自编码器就是往这个方向迈的一步。它属于无监督学习，标签不用给，喂进去一堆原始数据就行。它干的事只有一件：把输入压一压，再想办法复原回来。听起来像废话，但压和复原之间的那个中间产物，就是我们要的东西。

这条路一直走下去，会走到一个分岔口。前面几章讲的自编码器，学的是「怎么把这张图记住」；后面几章讲的变分自编码器，学的是「这一类图长什么样」。前者能重构，后者能生成。两者的差别不在代码行数上，在隐空间的形状上。

我们按顺序来。

一、自编码器是什么 #

自编码，直译就是「自己给自己编码」。最粗暴的理解：让网络的输出等于输入本身。

一个三层网络就够说明问题。输入 6 维，中间藏 3 个神经元，输出 6 维。训练目标是把输出拉回到输入上。

text
输入层(6)  →  隐藏层(3)  →  输出层(6)
   x            h = f(x)        x̂ = g(h)

中间那层只有 3 个节点，装不下 6 维输入的全部信息。整个过程一定会丢东西。训练干的事，是让丢的东西尽量少，留下来的尽量是主要特征。

这就是自编码器的全部骨架。剩下的花样，都是在这个骨架上做加减。

瓶颈才是它有价值的原因 #

很多人第一遍学自编码器会犯迷糊：输入等于输出，那网络学了个啥？不就是学了个恒等映射吗？

问题出在你把注意力放在输出上了。输出没用，中间那层才有用。

输入 6 维，中间 3 维。这 3 维是什么？它是原始输入的另一种写法。既然从这 3 维能把 6 维还原回来，说明这 3 维里攥着那 6 维的关键信息。原始数据换个表达方式，维度还降了——这就是特征。

打个比方。一个人站在你面前，你直接看，那是一个人。他不在你面前时，你听到他的名字，你也知道这名字指的是那个人。名字就是这个人的另一种表达，而且往往比一张脸更好用：一个名字就能定位一个人。

所以我们把话说准一点：自编码器的本质，是用瓶颈层强迫网络学压缩表示。

输入经过一个维度远小于输入的瓶颈，再复原。如果它能把输入复原好，说明瓶颈层抓住了数据的本质特征。这个瓶颈，就是它全部价值的来源。

瓶颈逼得越窄，网络越被迫回答一个问题：哪些维度是数据真正的自由度，哪些只是凑数的细节。

反过来说，如果瓶颈不比输入窄，这个网络就没有存在的必要。784 维进，784 维出，中间也 784 维，网络完全可以学一个恒等映射，损失降到零，什么也没学到。瓶颈必须窄，窄到装不下全部信息，网络才被迫做取舍，被迫只留下重要的。

这个「被迫」，就是自编码器的训练动力学。

它跟受限玻尔兹曼机不是一回事 #

两条线经常被摆在一起讲，因为它们都能重构输入，都能做无监督预训练，多层堆起来都能帮后面的监督任务收敛得更快。但内核完全不同。

维度 自编码器 AE 受限玻尔兹曼机 RBM
模型性质 确定性模型 概率模型
训练目标 最小化重构误差 让网络表示的概率分布逼近样本分布
结构 编码器、解码器都可以多层 典型形态是两层
损失函数 输出与输入的偏差，如均方误差 基于能量函数的最大似然
梯度 可直接求偏导，用 BP 偏导不能直接算，要用统计估计
训练算法 反向传播 + Adam / RMSProp 对比散度 CD、PCD、FPCD
物理背景 无 统计物理，能量模型

一句话概括这个差别：AE 想通过非线性变换找到输入的特征表示，它是确定论的路子；RBM 围着概率分布转，用能量函数描述分布，再从中提取高层表示，它是概率论的路子。

RBM 用 CD 算法训练时，可见层初始状态设成一个训练样本，算出隐藏层状态，再反推一个可见层的重构，比对重构和初始状态去更新参数。这个流程跟 AE 的训练看着很像，但背后的数学对象不一样：一个是误差，一个是似然。

我们后面要讲的 VAE，恰好是站在这两条线的交叉口上——结构是 AE 的，目标里带着概率分布的味道。

自编码器能干什么 #

最直接的一个例子：找跟你长得像的明星。

训练好一个自编码器，把输入层到中间层这一段单独拿出来。所有明星的照片过一遍，每张脸变成一个向量，存起来。用户传一张自拍，同一个编码器压成向量，去跟明星向量算距离，距离最近的几位就是答案。

这里没有任何分类标签参与。编码器不知道谁是明星，它只知道怎么把脸压成一个向量，并且保证这个向量能还原回一张脸。同一张脸压出来的向量靠得近，这就是它有用的地方。

同样的逻辑可以搬到文本上。文档压成向量，检索、聚类、去重都能做。

我们还得说清楚一件事：自编码器不是压缩算法。zip 那种压缩是可逆的、无损的，它不关心数据长什么样。自编码器是有损的，而且它丢什么留什么，取决于训练数据。它学的是数据待着的那个低维曲面，不是通用的编码规则。换个数据集，学出来的东西完全不一样。

二、编码器、瓶颈层与解码器 #

一个自编码器拆成三段。

text
x  --编码器 f-->  h  --解码器 g-->  x̂

编码器把高维输入压成低维隐变量：

text
h = σ(W₁x + b₁)

解码器把隐变量还原回输入空间：

text
x̂ = σ(W₂h + b₂)

整个网络的参数就是 W₁、b₁、W₂、b₂。训练时要优化的东西全在这四个张量里。

三段各有各的职责。

编码器负责丢信息。它要做的是判断哪些维度可以扔、哪些必须留。这一步没有标准答案，由损失函数逼出来。

瓶颈层是分界线，也是整个结构的约束点。它的宽度就是信息通道的宽度。宽一寸，网络轻松一点，特征粗一点；窄一寸，网络吃力一点，特征精一点。

解码器负责补信息。它拿到的是一份被压缩过的残缺描述，要拼回原来的样子。它必须学会数据本身的规律，才能把丢掉的部分合理地填回来。

瓶颈宽度怎么定 #

这是调参里第一个要拍板的事。几个经验：

  • 远小于输入维度才有降维意义。784 维的图压到 256、128、32、2，都能压；压到 700 就没什么意思了。
  • 任务决定下限。做可视化，压到 2 维或 3 维，人眼能看。做检索，压到 32 到 128 维就够用。做去噪，瓶颈可以宽一些，因为重点不在压缩率。
  • 太窄会欠拟合。瓶颈小到一定程度，重构误差掉不下去，输出一片模糊。
  • 太宽会偷懒。瓶颈接近输入维度时，网络容易学出近似恒等映射，损失很低但特征没用。看损失曲线看不出这个问题，得拿下游任务验。

还有一点常被忽略：编码器和解码器不必严格对称。源教程里 784 → 256 → 128 → 256 → 784 是对称的，图省事。真实项目里解码器往往比编码器宽一点，因为它干的活更难。

一个能跑的两层自编码器 #

MNIST，784 维压到 256，再压到 128，然后按原路返回。损失用均方误差，优化器用 Adam。

python
import tensorflow as tf
import numpy as np
import matplotlib.pyplot as plt
from tensorflow.examples.tutorials.mnist import input_data


def two_layer_auto_encoder():
    '''
    784 -> 256 -> 128 -> 256 -> 784
    提取 MNIST 特征，再用特征重建图片
    '''
    mnist = input_data.read_data_sets('MNIST-data', one_hot=True)

    print('Training data shape:', mnist.train.images.shape)        # (55000, 784)
    print('Test data shape:', mnist.test.images.shape)             # (10000, 784)
    print('Validation data shape:', mnist.validation.images.shape)  # (5000, 784)
    print('Training label shape:', mnist.train.labels.shape)       # (55000, 10)

    '''
    网络参数
    '''
    n_input = 784            # 输入节点
    n_hidden_1 = 256         # 第一层 256 个节点
    n_hidden_2 = 128         # 第二层 128 个节点
    batch_size = 256
    training_epochs = 20
    display_epoch = 5
    learning_rate = 1e-2
    show_num = 10

    '''
    占位符
    '''
    input_x = tf.placeholder(dtype=tf.float32, shape=[None, n_input])
    input_y = input_x        # 输出就是输入自己

    '''
    学习参数
    '''
    weights = {
        'encoder_h1': tf.Variable(tf.random_normal(shape=[n_input, n_hidden_1])),
        'encoder_h2': tf.Variable(tf.random_normal(shape=[n_hidden_1, n_hidden_2])),
        'decoder_h1': tf.Variable(tf.random_normal(shape=[n_hidden_2, n_hidden_1])),
        'decoder_h2': tf.Variable(tf.random_normal(shape=[n_hidden_1, n_input]))
    }

    biases = {
        'encoder_b1': tf.Variable(tf.random_normal(shape=[n_hidden_1])),
        'encoder_b2': tf.Variable(tf.random_normal(shape=[n_hidden_2])),
        'decoder_b1': tf.Variable(tf.random_normal(shape=[n_hidden_1])),
        'decoder_b2': tf.Variable(tf.random_normal(shape=[n_input]))
    }

    '''
    编码：输出层用 sigmoid，把特征限制在 [0,1]
    '''
    encoder_h1 = tf.nn.sigmoid(tf.add(tf.matmul(input_x, weights['encoder_h1']), biases['encoder_b1']))
    encoder_h2 = tf.nn.sigmoid(tf.add(tf.matmul(encoder_h1, weights['encoder_h2']), biases['encoder_b2']))

    '''
    解码
    '''
    decoder_h1 = tf.nn.sigmoid(tf.add(tf.matmul(encoder_h2, weights['decoder_h1']), biases['decoder_b1']))
    pred = tf.nn.sigmoid(tf.add(tf.matmul(decoder_h1, weights['decoder_h2']), biases['decoder_b2']))

    '''
    代价函数：逐元素平方误差后取平均
    '''
    cost = tf.reduce_mean((input_y - pred) ** 2)

    '''
    求解
    '''
    train = tf.train.AdamOptimizer(learning_rate).minimize(cost)

    with tf.Session() as sess:
        sess.run(tf.global_variables_initializer())

        num_batch = int(np.ceil(mnist.train.num_examples / batch_size))

        for epoch in range(training_epochs):
            sum_loss = 0.0
            for i in range(num_batch):
                batch_x, batch_y = mnist.train.next_batch(batch_size)
                _, loss = sess.run([train, cost], feed_dict={input_x: batch_x})
                sum_loss += loss

            if epoch % display_epoch == 0:
                print('Epoch {}  cost = {:.9f}'.format(epoch + 1, sum_loss / num_batch))
        print('训练完成')

        print('最大值：', np.max(mnist.train.images[0]), '最小值：', np.min(mnist.train.images[0]))

        '''
        可视化：第一行原图，第二行重构
        '''
        reconstruction = sess.run(pred, feed_dict={input_x: mnist.test.images[:show_num]})
        plt.figure(figsize=(1.0 * show_num, 1 * 2))
        for i in range(show_num):
            plt.subplot(2, show_num, i + 1)
            plt.imshow(np.reshape(mnist.test.images[i], (28, 28)), cmap='gray')
            plt.axis('off')
            plt.subplot(2, show_num, i + show_num + 1)
            plt.imshow(np.reshape(reconstruction[i], (28, 28)), cmap='gray')
            plt.axis('off')
        plt.show()


if __name__ == '__main__':
    two_layer_auto_encoder()

跑完看到的是一张两行十列的图。上面一行是输入，下面一行是重构。数字的轮廓、粗细、倾斜角都在，只是边缘软了一点，笔画的锐度掉了一些。这是有损压缩的正常表现——128 维装不下 784 维的全部细节，但它确实把「这是个 8」这个信息完整保住了。

这里有个细节值得单独说。编码器的输出用了 sigmoid，值域被压在 [0,1]。MNIST 的像素本来就是 [0,1] 的灰度值，正好对上。换个数据集就不一定了。做过 PCA 白化的数据，值也许是负的、也会超过 1，sigmoid 一卡就废。

解决办法是把输出层的激活换成恒等映射 f(z) = z。这种结构有个名字：线性解码器——前面几层带 sigmoid，最后一个解码层不带。

我们把编码器最后一层也换成线性，再压到 2 维，图上会出现一个挺有意思的现象：同一类数字的点会自己聚成一堆。这个放到讲降维的那一章细说。

三、损失函数与训练 #

自编码器的训练目标只有一句话：让输出尽量接近输入。损失函数就是这句话的数学化。

均方误差 #

最常用的是均方误差：

text
L = (1/N) · Σ (xᵢ - x̂ᵢ)²

TensorFlow 里一行：

python
cost = tf.reduce_mean((input_y - pred) ** 2)

它假设误差是高斯分布的，等价于在高斯噪声模型下做最大似然。像素值连续、范围有界的数据，比如归一化后的图像，用它最省事。

它对大误差更敏感——平方会把大偏差放大。好处是模型会优先咬住那些错得最狠的地方；坏处是碰上离群点容易被带偏。

交叉熵与二元交叉熵 #

输入是 [0,1] 的二值或近似二值数据时，交叉熵更合适：

text
L = -(1/N) · Σ [xᵢ·log(x̂ᵢ) + (1-xᵢ)·log(1-x̂ᵢ)]

python
cost = tf.reduce_mean(-(input_y * tf.log(pred) + (1 - input_y) * tf.log(1 - pred)))

MNIST 的像素被归一化到 [0,1]，许多像素恰好等于 0 或 1，用这一版损失，重构出来的笔画边缘会更干脆。用均方误差训练出的结果看着「糊」，一部分原因就在这里。

源教程里用的都是均方误差。想换就换成上面这行，网络结构不用动。

三种损失怎么选 #

损失 适用数据 特点 训练出来的重构
均方误差 MSE 连续值，归一化到 [0,1] 对离群点敏感，梯度平滑 边缘偏软，整体连贯
二元交叉熵 BCE 二值或近似二值，[0,1] 对像素级独立建模，梯度陡 边缘锐利，偶有噪点
交叉熵 CE softmax 输出的类别分布 配 softmax 使用 只用于分类头，不做重构

选哪个，看你的输出层激活。输出层 sigmoid，两个都能用；输出层是线性，只能用 MSE。

优化器与超参 #

源教程里一开始用 RMSProp，后来换成 Adam，都没解释原因。我们的经验：Adam 省心，学习率 1e-3 到 1e-2，几乎不用调就能出结果。RMSProp 在老版本的 TensorFlow 上更稳一点，差别不大。

几个超参的取值区间：

text
batch_size      64 / 128 / 256        # 越大越稳，显存换稳定
learning_rate   1e-3 ~ 1e-2           # 太大震荡，太小慢
training_epochs 20 ~ 50               # 看损失曲线，别死记
display_epoch   2 ~ 10                # 只是打印频率

这里没有神秘的调参玄学。自编码器的损失曲线很老实：一路往下，慢慢变平。如果它开始往上走，说明学习率大了，或者过拟合了。

完整的训练循环 #

结构都一样：初始化、分批量、喂数据、算损失、反向传播。写成模板就是：

python
with tf.Session() as sess:
    sess.run(tf.global_variables_initializer())

    num_batch = int(np.ceil(mnist.train.num_examples / batch_size))

    for epoch in range(training_epochs):
        total_cost = 0.0
        for i in range(num_batch):
            batch_x, batch_y = mnist.train.next_batch(batch_size)
            _, loss = sess.run([train, cost], feed_dict={input_x: batch_x})
            total_cost += loss

        if epoch % display_epoch == 0:
            print('Epoch {}/{}  average cost {:.9f}'.format(
                epoch + 1, training_epochs, total_cost / num_batch))

    print('训练完成')

feed_dict 里只喂了 input_x，没喂标签。自编码器的标签就是输入本身——这就是它叫「无监督」的原因。

num_batch 那行的 np.ceil 别省。55000 除以 256 除不尽，差的那点样本得算进一个不完整的批次里，不然每个 epoch 会漏掉几十个样本。

训练里真正会出问题的地方 #

损失降不下去，先看这三件事。

第一，瓶颈太窄。784 压到 2 维，重构必然糊，这不是 bug，是信息论。想重构清楚就把瓶颈放宽。

第二，激活函数和值域对不上。输出层用 sigmoid，值域 [0,1]，输入数据得先归一化到 [0,1]。喂进去 [-1,1] 的数据，输出永远贴不到负数上，损失卡在一个下不去的平台上。

第三，学习率太大。损失曲线上下抖，甚至变成 NaN。降到 1e-3 再看。

损失降得很低但特征没用，看这两件事。

第一，瓶颈太宽。前面提过，网络学会了近似恒等映射，损失好看，特征没信息量。判断方法：把隐变量拿去跑个最简单的分类器，准确率接近随机，就说明白训了。

第二，过拟合。训练集重构得极好，测试集一塌糊涂。自编码器的过拟合有个特点——它不体现在分类准确率上，体现在重构的泛化性上。加 dropout、加噪声、减小瓶颈宽度，都能压。

dropout 在这里的作用 #

源教程的去噪自编码器里加了 dropout：

python
h1 = tf.nn.sigmoid(tf.add(tf.matmul(input_x, weights['h1']), biases['b1']))
h1 = tf.nn.dropout(h1, keep_prob)

注意 keep_prob 在训练时传 0.5，在推理和可视化时传 1.0。这个细节错了，评估结果会莫名其妙地差一截。TensorFlow 1.x 的 dropout 是训练期缩放，推理期必须关掉。

dropout 在自编码器里的角色跟分类网络里不太一样。它不只是防过拟合，它还在往隐层里注入随机性——每次前向传播，一半的神经元被临时拿掉，网络被迫用残缺的表征去复原完整输入。这跟去噪是同一个思路的两种实现：一个在输入端加噪，一个在中间层加噪。

后面讲去噪自编码器时，这个联系会更清楚。

四、用自编码器做降维 #

瓶颈层天生就是个降维器。输入 784 维，瓶颈 2 维，那个 2 维向量就是降维结果。

跟 PCA 摆在一起看，会发现它们的关系比想象中近。

线性自编码器就是 PCA #

这句话得说准：线性激活 + 均方误差的自编码器，学到的就是 PCA 的子空间。

推导不复杂。假设编码和解码都是线性的：

text
h = W₁x
x̂ = W₂h = W₂W₁x

损失是 E[‖x - W₂W₁x‖²]。要让这个损失最小，W₂W₁ 必须等于数据协方差矩阵前 k 个主成分构成的投影矩阵。这就是 PCA 的定义。

说白了，一个不带任何非线性激活的自编码器，训练完之后，权重张成的子空间跟 PCA 算出来的是同一个。差别只在于：PCA 有解析解，一个特征值分解就出来了；自编码器是梯度下降一点点逼近的。同一个答案，两条路。

既然如此，为什么还要用自编码器做降维？因为：

加非线性激活，才能超越 PCA。

这是关键的一步。PCA 只能找线性子空间，它假设数据躺在一个平坦的低维面上。真实数据很少这么听话——MNIST 的手写数字，笔画的旋转、粗细的变化、书写风格的差异，这些关系不是线性的。在原始像素空间里，它们弯成一张卷曲的曲面。

自编码器中间插几层 sigmoid 或 ReLU，就能把这张曲面摊开。它学的不再是一个线性投影，而是一个非线性映射。这是 PCA 做不到的。

对比项 PCA 线性自编码器 非线性自编码器
解的形式 解析解，特征值分解 梯度下降逼近 梯度下降
映射 线性 线性 非线性
能否处理弯曲流形 不能 不能 能
与 PCA 的关系 — 学到的子空间等价 严格强于 PCA
训练成本 一次分解 需要迭代 需要迭代
重构质量 线性最优 与 PCA 持平 优于 PCA

源教程里有句话说得挺到位：把自编码器的激活函数从 sigmoid 换成恒等函数，那就是 PCA 模型。反过来说，sigmoid 一加，它就不是 PCA 了。

压到 2 维看聚类 #

把 MNIST 压到 2 维，然后把测试集的 2 维坐标画出来，用真实标签上色。

784 → 256 → 64 → 16 → 2，中间一路用 sigmoid，最后一层不用。

def four_layer_auto_encoder():
    '''
    784 -> 256 -> 64 -> 16 -> 2 -> 16 -> 64 -> 256 -> 784
    最后一层编码不使用 sigmoid：2 维特征已经是高度浓缩的主要特征，
    少一层变换能少丢一点信息
    '''
    mnist = input_data.read_data_sets('MNIST-data', one_hot=True)

    n_input = 784
    n_hidden_1 = 256
    n_hidden_2 = 64
    n_hidden_3 = 16
    n_hidden_4 = 2
    batch_size = 256
    training_epochs = 20
    display_epoch = 5
    learning_rate = 1e-2
    show_num = 10

    input_x = tf.placeholder(dtype=tf.float32, shape=[None, n_input])
    input_y = input_x

    weights = {
        'encoder_h1': tf.Variable(tf.random_normal(shape=[n_input, n_hidden_1])),
        'encoder_h2': tf.Variable(tf.random_normal(shape=[n_hidden_1, n_hidden_2])),
        'encoder_h3': tf.Variable(tf.random_normal(shape=[n_hidden_2, n_hidden_3])),
        'encoder_h4': tf.Variable(tf.random_normal(shape=[n_hidden_3, n_hidden_4])),
        'decoder_h1': tf.Variable(tf.random_normal(shape=[n_hidden_4, n_hidden_3])),
        'decoder_h2': tf.Variable(tf.random_normal(shape=[n_hidden_3, n_hidden_2])),
        'decoder_h3': tf.Variable(tf.random_normal(shape=[n_hidden_2, n_hidden_1])),
        'decoder_h4': tf.Variable(tf.random_normal(shape=[n_hidden_1, n_input]))
    }

    biases = {
        'encoder_b1': tf.Variable(tf.random_normal(shape=[n_hidden_1])),
        'encoder_b2': tf.Variable(tf.random_normal(shape=[n_hidden_2])),
        'encoder_b3': tf.Variable(tf.random_normal(shape=[n_hidden_3])),
        'encoder_b4': tf.Variable(tf.random_normal(shape=[n_hidden_4])),
        'decoder_b1': tf.Variable(tf.random_normal(shape=[n_hidden_3])),
        'decoder_b2': tf.Variable(tf.random_normal(shape=[n_hidden_2])),
        'decoder_b3': tf.Variable(tf.random_normal(shape=[n_hidden_1])),
        'decoder_b4': tf.Variable(tf.random_normal(shape=[n_input]))
    }

    # 编码：前三层 sigmoid
    encoder_h1 = tf.nn.sigmoid(tf.add(tf.matmul(input_x, weights['encoder_h1']), biases['encoder_b1']))
    encoder_h2 = tf.nn.sigmoid(tf.add(tf.matmul(encoder_h1, weights['encoder_h2']), biases['encoder_b2']))
    encoder_h3 = tf.nn.sigmoid(tf.add(tf.matmul(encoder_h2, weights['encoder_h3']), biases['encoder_b3']))
    # 最后一层不加激活，直接线性输出
    encoder_h4 = tf.add(tf.matmul(encoder_h3, weights['encoder_h4']), biases['encoder_b4'])

    # 解码
    decoder_h1 = tf.nn.sigmoid(tf.add(tf.matmul(encoder_h4, weights['decoder_h1']), biases['decoder_b1']))
    decoder_h2 = tf.nn.sigmoid(tf.add(tf.matmul(decoder_h1, weights['decoder_h2']), biases['decoder_b2']))
    decoder_h3 = tf.nn.sigmoid(tf.add(tf.matmul(decoder_h2, weights['decoder_h3']), biases['decoder_b3']))
    pred = tf.nn.sigmoid(tf.add(tf.matmul(decoder_h3, weights['decoder_h4']), biases['decoder_b4']))

    cost = tf.reduce_mean((input_y - pred) ** 2)
    train = tf.train.AdamOptimizer(learning_rate).minimize(cost)

    with tf.Session() as sess:
        sess.run(tf.global_variables_initializer())
        num_batch = int(np.ceil(mnist.train.num_examples / batch_size))

        for epoch in range(training_epochs):
            sum_loss = 0.0
            for i in range(num_batch):
                batch_x, batch_y = mnist.train.next_batch(batch_size)
                _, loss = sess.run([train, cost], feed_dict={input_x: batch_x})
                sum_loss += loss

            if epoch % display_epoch == 0:
                print('Epoch {}  cost = {:.9f}'.format(epoch + 1, sum_loss / num_batch))
        print('训练完成')

        '''
        二维特征散点图
        '''
        labels = [np.argmax(y) for y in mnist.test.labels]
        encoder_result = sess.run(encoder_h4, feed_dict={input_x: mnist.test.images})
        plt.figure(figsize=(10, 8))
        plt.scatter(encoder_result[:, 0], encoder_result[:, 1], c=labels)
        plt.colorbar()
        plt.show()

2 维瓶颈下重构一定糊，784 维压到 2 维，只剩 0.26% 的通道宽度，能把数字的「大致形状」留住已经算不错。但这张散点图才是重点。

同一类数字的点会自己聚成一堆。没有任何标签参与训练，网络只是被逼着压到 2 维还要尽量复原，它就把「哪些数字长得像」这个信息编码进了坐标里。1 和 7 挨得近，4 和 9 挨得近，0 和 6 挨得近。分类边界在图上肉眼可见。

这个现象很值得琢磨：自编码器从没见过标签，但它压出来的空间天然按类别分开。原因在于，能区分数字的那些特征恰好也是重构数字所必需的特征。类间差异就是信息量最大的地方，瓶颈当然会优先保留。

线性解码器为什么效果更好 #

源教程做了个对比实验：同一套 4 层结构，一次让编码器最后一层线性输出，一次让它过 sigmoid，看重构结果。

结论是线性那一版更好，噪点明显更少。

原因有两个。

一是 sigmoid 会压缩值域。最后一层编码的输出，值域被硬压在 [0,1]，大量信息挤在饱和区。sigmoid 在两端梯度接近零，那些落在饱和区的神经元，梯度传不回去，基本等于卡死。

二是 2 维特征本身就是高度浓缩的主成分，再套一层非线性变换，只会增加形变、多丢信息。源教程的原话是「少一些变化，可以最大化地保存原有的主要特征」——这个判断是对的，而且在多层压缩的末端尤其成立。

这条经验可以推广：瓶颈层及其前面一两层，尽量别用容易饱和的激活。ReLU 比 sigmoid 好，线性比 ReLU 更适合做最终瓶颈。想让隐变量有界，用 tanh 也别用 sigmoid。

用卷积做自编码 #

全连接层做图像自编码有个致命问题：参数太多。784 到 256 那一层就是 20 万个参数，图像稍大一点就爆。而且全连接层把图像的空间结构完全打散了，相邻像素的关系它不认。

换成卷积，编码用 conv + pool，解码用 deconv + unpool。参数共享，空间结构保留。

解码端的反池化需要记下最大值的位置。TensorFlow 没有现成的反最大池化，得自己写：

python
def max_pool_with_argmax(net, stride):
    '''
    最大池化，同时返回每个最大值的位置索引（形状和池化结果一致）

    args:
        net: 输入数据，形状 [batch, in_height, in_width, in_channels]
        stride: 步长，最大池化时窗口大小和步长设成一样
    '''
    # mask 保存每个最大值的位置，这个函数只支持 GPU
    _, mask = tf.nn.max_pool_with_argmax(
        net, ksize=[1, stride, stride, 1], strides=[1, stride, stride, 1], padding='SAME')
    # 停止 mask 的梯度回传
    mask = tf.stop_gradient(mask)
    # 常规最大池化
    net = tf.nn.max_pool(
        net, ksize=[1, stride, stride, 1], strides=[1, stride, stride, 1], padding='SAME')
    return net, mask


def un_max_pool(net, mask, stride):
    '''
    反最大池化：按 mask 的索引把值填回原来的位置

    args:
        net: 最大池化后的输出，形状 [batch, height, width, in_channels]
        mask: 位置索引，形状同 net
        stride: 步长，就是 max_pool_with_argmax 传入的那个 stride
    '''
    ksize = [1, stride, stride, 1]
    input_shape = net.get_shape().as_list()
    # 还原后的形状
    output_shape = (input_shape[0], input_shape[1] * ksize[1],
                    input_shape[2] * ksize[2], input_shape[3])
    # 为 batch、height、width、feature map 分别算索引
    one_like_mask = tf.ones_like(mask)
    batch_range = tf.reshape(tf.range(output_shape[0], dtype=tf.int64),
                             shape=[input_shape[0], 1, 1, 1])
    b = one_like_mask * batch_range
    y = mask // (output_shape[2] * output_shape[3])
    x = mask % (output_shape[2] * output_shape[3]) // output_shape[3]
    feature_range = tf.range(output_shape[3], dtype=tf.int64)
    f = one_like_mask * feature_range
    # 转置索引，把待填的值拉成一维
    updates_size = tf.size(net)
    indices = tf.transpose(tf.reshape(tf.stack([b, y, x, f]), [4, updates_size]))
    values = tf.reshape(net, [updates_size])
    ret = tf.scatter_nd(indices, values, output_shape)
    return ret

    mnist = input_data.read_data_sets('MNIST-data', one_hot=True)

    n_input = 784
    batch_size = 256
    n_conv_1 = 16            # 第一层 16 个通道

    training_epochs = 8
    display_epoch = 5
    learning_rate = 1e-2
    show_num = 10

    # 用反卷积时，placeholder 形状里不能有 None，否则报错
    input_x = tf.placeholder(dtype=tf.float32, shape=[batch_size, n_input])

    weights = {
        'encoder_conv1': tf.Variable(tf.truncated_normal([5, 5, 1, n_conv_1], stddev=0.1)),
        'encoder_conv2': tf.Variable(tf.random_normal([3, 3, n_conv_1, n_conv_2], stddev=0.1)),
        'decoder_conv1': tf.Variable(tf.random_normal([5, 5, 1, n_conv_1], stddev=0.1)),
        'decoder_conv2': tf.Variable(tf.random_normal([3, 3, n_conv_1, n_conv_2], stddev=0.1))
    }
    biases = {
        'encoder_conv1': tf.Variable(tf.zeros([n_conv_1])),
        'encoder_conv2': tf.Variable(tf.zeros([n_conv_2])),
        'decoder_conv1': tf.Variable(tf.zeros([n_conv_1])),
        'decoder_conv2': tf.Variable(tf.zeros([n_conv_2]))
    }

    image_x = tf.reshape(input_x, [-1, 28, 28, 1])

    # 编码
    encoder_conv1 = tf.nn.relu(
        tf.nn.conv2d(image_x, weights['encoder_conv1'], strides=[1, 1, 1, 1], padding='SAME')
        + biases['encoder_conv1'])
    print('encoder_conv1:', encoder_conv1.shape)
    encoder_conv2 = tf.nn.relu(
        tf.nn.conv2d(encoder_conv1, weights['encoder_conv2'], strides=[1, 1, 1, 1], padding='SAME')
        + biases['encoder_conv2'])
    print('encoder_conv2:', encoder_conv2.shape)
    encoder_pool2, mask = max_pool_with_argmax(encoder_conv2, 2)

        decoder_conv1 - biases['decoder_conv1'], weights['decoder_conv1'],
        image_x.shape, strides=[1, 1, 1, 1], padding='SAME')

    with tf.Session() as sess:

        num_batch = int(np.ceil(mnist.train.num_examples / batch_size))

五、去噪自编码器 #

重构得好，不代表特征好。

一个只学过重构的网络，可以死记硬背。给它 784 维输入，瓶颈 512 维，它完全可以把大部分细节原样抄进瓶颈，重构误差低到 0.001，但那个瓶颈只是原始像素的一个副本，没有抽象。

要让特征真正有意义，得给它加难度。

去噪自编码器（Denoising Auto Encoder, DAE）的做法很直接：训练时给输入加噪声，标签还是干净的原图。网络必须从一堆噪点里把原来的样子捞出来。

text
干净输入 x  →  x̃ = x + noise  →  编码  →  瓶颈  →  解码  →  重构 x̂
损失：‖x - x̂‖²     注意标签是 x，不是 x̃

这个不对称是关键。输入是脏的，监督信号是干净的。网络想降低损失，就不能再去抄输入了——输入里参着噪声，抄过来只会更糟。它必须学会「什么是数字真实的形状」，把噪声当成无关的东西滤掉。

逼着网络学去噪，等于逼着它学数据的内在结构。这才是特征的来源。

噪声怎么加 #

源教程列了两条路：

  • 在选择训练数据集时，额外混入一些样本集以外的数据。
  • 改变已有样本的数据，让样本个体不完整，或者用噪声跟样本做加减乘除运算。

第二条用得更多。具体形式有几种：

噪声类型 做法 学到的能力
加性高斯噪声 x̃ = x + σ·ε, ε ~ N(0,1) 对连续扰动鲁棒
掩码噪声 随机把一部分像素置零 补全残缺信息，类似 dropout
椒盐噪声 随机把一部分像素翻成 0 或 1 对离群点、坏像素鲁棒
乘性噪声 x̃ = x·(1 + σ·ε) 对增益变化鲁棒

源教程主要用高斯噪声，并且在鲁棒性测试阶段特意换成椒盐噪声，验证模型学到的是通用的抗干扰能力，而不是只对某一种噪声过拟合。这个验证思路值得学：训练用一种噪声，测试换另一种，能看出模型是不是真学到了结构。

加噪的强度 #

这是 DAE 里唯一的超参，也是最容易调错的一个。

0.3 倍的高斯噪声是源教程的取值：

python
batch_x_noise = batch_x + 0.3 * np.random.randn(batch_size, 784)

噪声太小，比如 0.05，网络几乎不用费劲，学到的东西跟普通 AE 差不多。

噪声太大，比如 0.8，输入几乎被打散，网络只能学到一堆模糊的平均值，重构出来是一团灰。

经验值在 0.2 到 0.4 之间。判断标准是看加噪后的图还能不能认出数字——能认出但很吃力，这个强度就对了。

def denoising_auto_encoder():

    去噪自编码器 784-256-256-784

    给 MNIST 原图加噪声,在自编码网络里训练,
    得到抗干扰更强的特征提取模型
    '''
    mnist = input_data.read_data_sets('MNIST-data', one_hot=True)

    n_input = 784

dropout 的作用 #

源教程做了两次对照：一次 keep_prob = 1.0，一次 keep_prob = 0.5。

结论是 0.5 的效果更好，还原后的噪声几乎全被滤掉。

原因不复杂。keep_prob = 0.5 时，每次前向传播随机丢掉一半神经元，网络不能依赖任何单个神经元，必须把信息分布到多条路径上。这相当于在隐层里又加了一层噪声，跟输入端的噪声形成叠加。训练难度上去了，学到的表征也更结实。

两条噪声通道叠加起来做正则，这就是 DAE 里 dropout 的真实作用——不是防过拟合的常规手段，而是噪声注入的一部分。

去噪自编码器的边界 #

DAE 学的是「怎么从脏数据恢复干净数据」，这跟降噪算法不是一回事。降噪算法针对特定噪声模型设计滤波器，DAE 是从数据里学一个映射，它对训练时见过的噪声类型效果好，换了完全陌生的噪声也会退化。

它也不能凭空补信息。一张图如果 70% 的像素都被抹掉了，DAE 补出来的只能是它见过的平均形状，细节是编的。这个「编」在生成模型里是优点，在数据恢复里就是风险。

六、栈式自编码器 #

把多个自编码器一层层堆起来，就是栈式自编码器（Stacked Autoencoder, SA）。

思路：第一层的隐变量，当成第二层的输入；第二层的隐变量，当成第三层的输入。每一层都单独训练，训练好之后把编码部分串起来，接上分类器，最后整体微调。

text
784 --AE1--> 256 --AE2--> 128 --softmax--> 10

每层都是独立的网络，各训各的。这个「分开训练」的做法，是栈式自编码器的核心。

为什么要分开训 #

直接堆一个深网络，端到端训练，不行吗？

行，但难。

深度网络的问题在于误差反传。层数一多，梯度一路传回去，越传越小，到了浅层基本归零。这就是梯度消失。浅层学不到东西，整个网络就废了。源教程的原话：层越深，传播的误差越小。

栈式自编码绕开了这个问题。每一层都是单独训练的两三层小网络，梯度只需要传两三层，不会消失。每层训练好之后，它的参数就是一个合理的初始值。深网络最怕的「随机初始化 + 深层反传」这个组合，被拆成了若干个「小网络 + 浅层反传」。

这样做有几个实打实的好处：

  • 每一层单独训练，降维特征的可控性强。想看看第二层学到了什么，直接把它单独拿出来看。
  • 高维分类问题一下拿出一套完整可用的模型不容易。节点太多，参数太多，一味加深度只会让结果不可控，变成彻底的黑盒。逐层降维把复杂问题拆成几个简单问题。
  • 绕开了深层反传的梯度衰减，层数可以任意加。
  • 能拿到输入的「层次型分组」或者「部分-整体分解」结构。自编码器倾向于学到跟样本对应的低维向量，这个向量比高维原始数据更能表达数据特征。

最后一条值得展开。输入是图像时，第一层学到的是边，第二层学到的是边组合成的轮廓，更高层学到的是轮廓组合成的部件。人脸识别这个任务上，第一层是边缘，中间层是眼睛、鼻子、嘴，高层是整个脸。这种分层结构不是人设计的，是逐层压缩自然长出来的。

逐层训练 + 微调 #

整个流程分四步：

text
1. 训 AE1：784 -> 256 -> 784，去噪自编码器，取编码部分
2. 训 AE2：256 -> 128 -> 256，输入是 AE1 的隐变量
3. 训分类头：128 -> 10，softmax
4. 级联微调：把 1、2、3 串起来，端到端再训一遍

前三步是无监督的，不需要标签。只有第三步的 softmax 和第四步的微调用到标签。

第四步叫微调，英文 fine-tune。它在整个深度学习里都是常见技术，不只是自编码器。

微调什么时候有用：有大量已标注数据的时候，微调能显著提升分类器性能。标注数据很少、未标注数据很多的时候，微调的收益有限——预训练已经把特征学好了，微调能改的空间不大，反而容易过拟合那点少得可怜的标签。

def stacked_auto_encoder():
    tf.reset_default_graph()
    '''
    栈式自编码器

    最终网络：一个输入、一个输出、两个隐藏层
    MNIST(784) -> 编码层1(256) -> 编码层2(128) -> softmax(10)

    除输入层外每层都用一个网络单独训练,训练 3 个网络,
    最后把训练好的各层组合成第 4 个网络
    '''
    n_input = 784
    n_hidden_1 = 256
    n_hidden_2 = 128
    n_classes = 10

    learning_rate = 0.01
    training_epochs = 20
    batch_size = 256
    display_epoch = 10
    show_num = 10

    savedir = './stacked_encoder/'      # 检查点保存路径
    savefile = 'mnist_model.cpkt'       # 检查点文件名

    # 第一层的输入输出
    x = tf.placeholder(dtype=tf.float32, shape=[None, n_input])
    y = tf.placeholder(dtype=tf.float32, shape=[None, n_input])
    keep_prob = tf.placeholder(dtype=tf.float32)

    # 第二层的输入输出
    l2x = tf.placeholder(dtype=tf.float32, shape=[None, n_hidden_1])
    l2y = tf.placeholder(dtype=tf.float32, shape=[None, n_hidden_1])

    # 第三层的输入输出
    l3x = tf.placeholder(dtype=tf.float32, shape=[None, n_hidden_2])
    l3y = tf.placeholder(dtype=tf.float32, shape=[None, n_classes])

    weights = {
        # 网络1 784-256-256-784
        'l1_h1': tf.Variable(tf.truncated_normal(shape=[n_input, n_hidden_1], stddev=0.1)),
        'l1_h2': tf.Variable(tf.truncated_normal(shape=[n_hidden_1, n_hidden_1], stddev=0.1)),
        'l1_out': tf.Variable(tf.truncated_normal(shape=[n_hidden_1, n_input], stddev=0.1)),
        # 网络2 256-128-128-256
        'l2_h1': tf.Variable(tf.truncated_normal(shape=[n_hidden_1, n_hidden_2], stddev=0.1)),
        'l2_h2': tf.Variable(tf.truncated_normal(shape=[n_hidden_2, n_hidden_2], stddev=0.1)),
        'l2_out': tf.Variable(tf.truncated_normal(shape=[n_hidden_2, n_hidden_1], stddev=0.1)),
        # 网络3 128-10
        'out': tf.Variable(tf.truncated_normal(shape=[n_hidden_2, n_classes], stddev=0.1))
    }

    biases = {
        'l1_b1': tf.Variable(tf.zeros(shape=[n_hidden_1])),
        'l1_b2': tf.Variable(tf.zeros(shape=[n_hidden_1])),
        'l1_out': tf.Variable(tf.zeros(shape=[n_input])),

        'l2_b1': tf.Variable(tf.zeros(shape=[n_hidden_2])),
        'l2_b2': tf.Variable(tf.zeros(shape=[n_hidden_2])),
        'l2_out': tf.Variable(tf.zeros(shape=[n_hidden_1])),

        'out': tf.Variable(tf.zeros(shape=[n_classes]))
    }

    '''
    网络 1：784-256-256-784，带噪声和 dropout
    '''
    l1_h1 = tf.nn.sigmoid(tf.add(tf.matmul(x, weights['l1_h1']), biases['l1_b1']))
    l1_h1_dropout = tf.nn.dropout(l1_h1, keep_prob)
    l1_h2 = tf.nn.sigmoid(tf.add(tf.matmul(l1_h1_dropout, weights['l1_h2']), biases['l1_b2']))
    l1_h2_dropout = tf.nn.dropout(l1_h2, keep_prob)
    l1_reconstruction = tf.nn.sigmoid(
        tf.add(tf.matmul(l1_h2_dropout, weights['l1_out']), biases['l1_out']))

    l1_cost = tf.reduce_mean((l1_reconstruction - y) ** 2)
    l1_optm = tf.train.AdamOptimizer(learning_rate).minimize(l1_cost)

    '''
    网络 2：256-128-128-256
    '''
    l2_h1 = tf.nn.sigmoid(tf.add(tf.matmul(l2x, weights['l2_h1']), biases['l2_b1']))
    l2_h2 = tf.nn.sigmoid(tf.add(tf.matmul(l2_h1, weights['l2_h2']), biases['l2_b2']))
    l2_reconstruction = tf.nn.sigmoid(
        tf.add(tf.matmul(l2_h2, weights['l2_out']), biases['l2_out']))

    l2_cost = tf.reduce_mean((l2_reconstruction - l2y) ** 2)
    l2_optm = tf.train.AdamOptimizer(learning_rate).minimize(l2_cost)

    '''
    网络 3：128-10，softmax 分类
    '''
    l3_logits = tf.add(tf.matmul(l3x, weights['out']), biases['out'])
    l3_cost = tf.reduce_mean(
        tf.nn.softmax_cross_entropy_with_logits(logits=l3_logits, labels=l3y))
    l3_optm = tf.train.AdamOptimizer(learning_rate).minimize(l3_cost)

    '''
    网络 4：级联，把前三个串起来
    '''
    # 1 联 2
    l1_l2_out = tf.nn.sigmoid(tf.add(tf.matmul(l1_h1, weights['l2_h1']), biases['l2_b1']))
    # 2 联 3
    logits = tf.add(tf.matmul(l1_l2_out, weights['out']), biases['out'])

    cost = tf.reduce_mean(tf.nn.softmax_cross_entropy_with_logits(logits=logits, labels=l3y))
    optm = tf.train.AdamOptimizer(learning_rate).minimize(cost)

    num_batch = int(np.ceil(mnist.train.num_examples / batch_size))

    # max_to_keep=1：最多留一个检查点，新模型覆盖旧模型
    saver = tf.train.Saver(max_to_keep=1)
    kpt = tf.train.latest_checkpoint(savedir)
    print('kpt:', kpt)

注意级联那一行 l1_l2_out：它复用 weights['l2_h1']，但输入是 l1_h1 而不是训练网络 2 时的 l2_h1 输出。这是故意的——网络 2 学到的从 256 维到 128 维的映射，现在直接接在第一层的隐变量后面用。

        sess.run(tf.global_variables_initializer())
        print('级联微调 开始训练')

        for epoch in range(training_epochs):
            total_cost = 0.0
            for i in range(num_batch):
                batch_x, batch_y = mnist.train.next_batch(batch_size)
                _, loss = sess.run([optm, cost], feed_dict={x: batch_x, l3y: batch_y})
                total_cost += loss

            if epoch % display_epoch == 0:
                print('Epoch {0}/{1}  average cost {2}'.format(
                    epoch, training_epochs, total_cost / num_batch))

            saver.save(sess, os.path.join(savedir, savefile), global_step=epoch)
        print('训练完成')
        print('Accuracy:', accuracy.eval({x: mnist.test.images, l3y: mnist.test.labels}))

结果 #

三步走完，数字是这样：

阶段 测试集准确率
逐层训练后直接级联 86.97%
级联微调 20 轮后 97.74%

从 86.97% 到 97.74%，提了将近 11 个百分点。这些提升全部来自第四步的端到端微调。

为什么微调这么管用？因为前三层是各自独立训练的，每层都只考虑「怎么让这一层的输出复原这一层的输入」，没有全局目标。第一层学到的特征，对第二层来说未必最优；第二层学到的，对分类来说也未必最优。级联微调把这些局部最优往下压，让整条链路朝着分类目标一起调整。

97.74% 这个数字，跟一个普通的前馈神经网络差不多。栈式自编码器在这里的价值不在于更高的准确率，而在于它给了你一个可以继续加深的起点。加到五六层，普通前馈网络就训不动了，栈式还能一层层往上堆。

一个实现上的坑 #

上面代码里三次 with tf.Session() as sess 是分开的。每次新开 session,tf.global_variables_initializer() 会把所有变量重新初始化。

那第二层训练时，用的是哪一层的权重？

答案是：第一层的权重根本没保存下来。网络 1 训练完的权重存在检查点文件里，但 saver.restore(sess, kpt) 只在第一个 session 里调用了。第二个 session 从头初始化，l1_h1 是随机值。

源教程的完整代码里，kpt 是在构图阶段就取好的，并且第一个 session 里做了 restore。第二、三个 session 里没有再 restore，所以实际跑出来的结果跟论文里的栈式自编码不是一回事——它的各层权重并没有真正串起来。

要修，在每个 with tf.Session() as sess 里都加上：

python
with tf.Session() as sess:
    sess.run(tf.global_variables_initializer())
    if kpt != None:
        saver.restore(sess, kpt)      # 每层训练前都恢复

或者更干净的做法：所有训练放在同一个 session 里，顺序执行，靠 sess.run(l1_h1, ...) 现算中间结果。源教程后半段确实是这么做的——第二层和第三层都用 sess.run(l1_h1, ...) 现场算输入，这一点是对的。

这个坑值得单独说，因为它不影响代码跑通，只影响结果对不对。你会在没有任何报错的情况下，拿到一个「看起来还行但其实是随机初始化」的模型。

自编码器不是万能的 #

源教程在应用场合那一段说了句实话：全连接网络的自编码器并不适合处理图像类问题，参数太多。

自编码器更像是一种技巧，不是一种能解决所有问题的模型。任何一种网络和方法都做不到一成不变就满足所有场景。现实里得用具体模型配各种技巧。

明白原理、知道优缺点才是核心。任何一个多维数据的分类任务都可以试试自编码，大型图片分类任务里，卷积池化之后的特征送进自编码降维也是个办法。但它不是首选方案，更不是唯一方案。

现在的做法多是：用大规模预训练模型当特征提取器，自编码器退到特定场景——异常检测、数据去噪、表示学习的研究基线。它仍然是理解「表示学习」这件事最干净的入口，这一点没变。

七、从自编码到生成模型 #

从最基础的重构，到去噪、栈式，前面这些自编码器有一个共同的上限：只能重构，不能生成。

差在哪 #

普通自编码器把输入 x 映射成一个点 h。整张脸进网络，出来一个 128 维的向量。这张脸对应这个点，一一对应。

想生成一张新脸？做不到。

问题是：如果你随手在隐空间里取一个点，解码出来多半是一团噪声。为什么？

因为训练从来没有约束过隐空间的形状。网络只是被要求「把这张脸压成 h，再从 h 复原」。h 落在哪里、点与点之间是不是连续、中间那些空白区域解码出来是什么——一概不管。

用数字说更清楚。假设训练集只有两张图，一张 1，一张 8。编码器把它们压到 (3.1, -7.2) 和 (3.3, -7.0)。这两个点挨得很近，因为它们长得有点像。但 (5.0, 2.0) 这个点呢？那里什么都没有，解码器从没在这个位置训练过，它输出什么是随机的。

所以普通 AE 的隐空间是碎的、有洞的、边界混乱的。

这在降维任务里无所谓——你只需要沿着训练样本走的路径压，不会掉到空白处。但在生成任务里是致命的——生成就是要往空白处走。

生成模型要什么 #

生成模型的目标是从数据分布 p(X) 里采样，造出新样本。

理想情况：知道 p(X) 的表达式，直接采样。这是终极形态，基本做不到——一张 28×28 的灰度图有 784 个维度，分布复杂到写不出来。

退一步的思路：引入隐变量 Z，假设 X 是由 Z 生成的。

text
Z  ~ p(Z)         先验，比如标准正态
X  = g(Z)         用神经网络拟合 g

如果这个模型学好了，采样流程就是：从 p(Z) 取样一个 z，过 g 得到一张新图。

现在问题变成：怎么让 g(Z) 的分布跟真实数据分布对上？

一个绕不过去的困难 #

从 N(0,I) 采样若干个 z₁, z₂, …, zₙ，过 g 得到 x̂¹, x̂², …, x̂ⁿ，跟真实样本 x¹, x², …, xⁿ 比，怎么判断这两个分布一样？

用 KL 散度？

不行。KL 散度需要两个概率分布的表达式，KL(p‖q) = ∫ p log(p/q)。我们现在只有两批采样出来的点，没有 p 和 q 的表达式。只有样本，没有分布，算不了 KL。

这就是生成模型的核心难题：判断生成分布跟真实分布的相似度，但你只有采样结果。

GAN 的做法是绕过它——用一个判别器网络来当「相似度」的替代品，两个网络对抗着训。VAE 的做法是另一条路：不直接比较分布，而是先用一个编码器把 X 压成 Z，再对 Z 的形状做强假设，最后用一个可算的变分下界去逼近。

这条路的代价是推导长一点，好处是目标函数是解析的，一个式子写出来就能训。

四种自编码器的谱系 #

把整条线拉平看：

类型 核心改动 学到什么 能干嘛 局限
基础 AE 瓶颈压缩再复原 低维特征表示 降维、检索、去噪 隐空间无结构，不能生成
去噪 AE（DAE） 输入加噪，标签干净 抗干扰的鲁棒特征 去噪、鲁棒表示 同上
栈式 AE（SA） 逐层训练 + 微调 分层特征 深层网络预训练 同上
变分 AE（VAE） 编码成分布 + KL 约束 结构化的隐空间 生成新样本 生成偏模糊

前三种是同一个思路的不同变体，都在解决「怎么学到好特征」。第四种换了个问题，问的是「怎么让隐空间长得像一张能走的地图」。

这个转折点在哪？在于编码器的输出从「一个点」变成了「一个分布」。下一章讲这个。

八、变分自编码器的思路 #

变分自编码器（Variational Auto-Encoder, VAE）的核心改动只有一句话：

编码器不再输出一个点，输出一个分布。

一个点 vs 一个分布 #

普通 AE：输入 x，编码器给出 h。一个确定的向量。

VAE：输入 x，编码器给出 μ 和 σ²。两个向量，共同定义一个正态分布 N(μ, σ²)。

text
普通 AE：x  →  h                    （一个点）
VAE   ：x  →  μ, σ²  →  z ~ N(μ, σ²)  （一个分布，再从里面采样一个点）

这才是 VAE 与普通自编码器的根本差别：普通 AE 把输入映射成一个点，VAE 把它映射成一个分布。这样才能从分布里采样生成新样本。

为什么这个改动能带来生成能力？

设想训练完成之后，所有图片对应的 μ 挤在一起，形成一个覆盖标准正态分布的区域。这时候你在标准正态里随便采一个 z，它一定落在某个已有 μ 的附近；而由于每个点的分布都有一定的 σ，这个 z 附近一定有一些「训练时见过的」样本。解码器在这个位置是训练过的，所以它能吐出一张合理的图。

点变成分布，等于给每个样本在隐空间里圈了一块地盘。地盘之间必然重叠，重叠的区域就是插值——两个 6 之间的位置，解码出来是能看的数字。

这就是「从分布里采样生成新样本」的原理。

代价是什么？

代价是每个样本不再精确对应一个位置。z 是采样出来的，带噪声，重构会受影响。为了不让噪声太大，模型会想把 σ 压到 0——但那又退化成普通 AE 了。

所以还要加一层约束，这层约束就是 KL 散度。

专属的后验 #

VAE 的推导里有个容易搞混的地方，得说清楚。

很多教程说：p(Z) 是标准正态分布，所以我们从 N(0,I) 采样 z，再过生成器得到 X。

这个说法有问题。

问题在于：假设 p(Z) 是标准正态，从里面采样一个 z，你根本不知道这个 z 应该对应哪个真实的 x。那还怎么训练重构？

把假设改一下：p(Z|X) 是正态分布。

也就是说，对每一个真实样本 xᵏ，存在一个专属于它的分布 p(Z|xᵏ)。这个分布是正态的，有它自己的均值 μᵏ 和方差 σᵏ²。从这个专属分布里采出来的 zᵏ，应该能还原回 xᵏ。

「专属」这两个字是全套推导的支点。有了它，重构才有明确的目标。

原论文《Auto-Encoding Variational Bayes》里专门强调过这一点：variational approximate posterior 是一个对角协方差的多变量高斯。很多教程介绍 VAE 时没有把这一步凸显出来，导致后面全是糊涂账。

那么 p(Z) 是标准正态这个假设还有用吗？

有用，但它不是出发点，是终点。VAE 通过训练让所有 p(Z|X) 都向 N(0,I) 看齐，从而使得聚合起来的 p(Z) = ∫ p(Z|X)p(X)dX 也接近 N(0,I)。这时候从 N(0,I) 采样才成立。

顺序不能反。先有专属后验，后有标准先验。

用神经网络拟合 μ 和 σ² #

现在的问题：每个 xᵏ 都有自己的 μᵏ 和 σᵏ²，样本有多少个就有多少组参数，怎么求？

用神经网络拟合。

text
μ    = f₁(x)
logσ² = f₂(x)

两个网络，或者一个网络两个头。输入是 x，输出是 μ 和 logσ²。

这里有个细节：为什么拟合 logσ² 而不是直接拟合 σ²?

因为 σ² 必须非负。直接拟合的话，得在输出上加个 softplus 或者 exp 保证非负，多一层约束。拟合 logσ² 就没这个限制——它可正可负，想得到 σ² 时做一次 exp 就行。

这个技巧不只是省事。logσ² 的取值空间是整条实数轴，梯度传起来更自然；而且 logσ² 在数值上也更好控制——σ 从 1e-3 到 1e3,logσ² 只是 -7 到 7，一个很小的范围。

到这里，VAE 的骨架就齐了：

text
x  →  编码器  →  μ, logσ²
                    ↓
              z = μ + σ·ε,  ε ~ N(0,I)
                    ↓
             解码器  →  x̂

剩下的两件事：重参数化，和损失函数。

一个会退化的漏洞 #

按上面这套走，训练能跑起来，但结果会让你失望。

想想模型会怎么优化。

重构损失要求 z 能还原 x。但 z 是采样的，带噪声。噪声越大，重构越难。所以模型的最优策略是把 σ 压到 0。

σ = 0 时，z 恒等于 μ，没有随机性。这不就退回普通 AE 了吗？

而且这还更糟——既然 z = μ 是确定的，那模型完全可以让 μ 就是原始输入的一个副本，重构损失降到接近 0，但隐空间彻底失去结构，一点生成能力都没有。

源教程里对这个过程的描述很形象：模型会慢慢退化成普通的 AutoEncoder，噪声不再起作用。

这就是为什么必须有 KL 项。它的作用是顶住这个退化趋势，逼 σ 不能太小。

KL 项在干什么 #

KL 项是 KL(N(μ, σ²) ‖ N(0, I))。

它衡量的是「你这个专属分布，跟标准正态差多远」。

如果 μ 偏离 0、σ 偏离 1,KL 就大，惩罚就重。为了压低这一项，模型只能让步：让 μ 往 0 靠，让 σ 往 1 靠。

这一逼，效果就出来了：

  • μ 都往 0 附近挤，隐空间被压进一个紧凑的区域，不会散得到处都是。
  • σ 都被逼到 1 附近，不会缩到 0，噪声通道保住了。
  • 所有分布都朝同一个标准正态看齐，它们之间就会重叠、连续，不会各占一块互不相通的地盘。

三点合起来，隐空间变成一张连续的地图。这张地图的中心区域对应真实数据，边缘和中间区域解码出来是合理的插值——生成能力就是这么来的。

所以 VAE 的总损失是两项相加：

text
总损失 = 重构损失 + KL 散度

重构损失管「能不能看清」，KL 管「隐空间规不规矩」。

两项互相拉扯。重构想把 σ 压到 0 换精度，KL 想把 σ 撑到 1 换结构。平衡点由两个损失的量级自然决定，不需要人工调权重——这一点后面讲损失函数的那一章会展开。

VAE 的本质 #

抛开变分和贝叶斯那套术语，VAE 其实很接地气。

它就是在普通自编码器的基础上，给编码器的输出加了高斯噪声，让解码器对噪声有鲁棒性。那个额外的 KL 项，相当于给编码器加了一个正则，希望编码出来的东西都零均值。

这个视角跟去噪自编码器很像。DAE 在输入端加噪声，VAE 在隐层加噪声。都是逼网络学得皮实一点。

那另一个编码器(算方差的那个)干什么用？

它动态调噪声强度。

推理过程是这样的：

  • 解码器还没训好时，重构误差远大于 KL。模型会想，重构太难了，先把噪声调小一点，拟合容易些。σ 变小，KL 变大，重构误差开始降。
  • 解码器训得不错时，重构误差小于 KL。模型会想，反正重构不难，不如把噪声调大，让 KL 降下来。σ 变大，拟合变难，重构误差又抬起来。

两个损失就这样自动博弈，噪声强度自己找到了平衡点。你不用调这个参数，它是学出来的。

这个机制有个副作用：训练早期容易不稳。所以源教程特别提醒，权重初始化要用很小的值(0.001)。原因很直接——KL 算的是跟标准高斯的距离，如果网络初始化时输出的 μ 和 σ 都很大，KL 会是一个巨大的数，直接把训练带崩，输出 NaN。

这个 0.001 不是随便写的，是踩过坑之后的结果。

一个式子看懂生成流程 #

把整个数据流串起来：

text
训练：
  x → 编码器 → μ, logσ²
  ε ~ N(0,1)
  z = μ + exp(logσ²/2) · ε
  x̂ = 解码器(z)
  loss = ‖x - x̂‖² + KL(N(μ, σ²) ‖ N(0,1))

生成：
  z ~ N(0,1)
  x_new = 解码器(z)

注意训练和生成的解码器是同一个，但输入来源不同：训练时 z 来自专属分布，生成时 z 来自标准正态。

这就是 VAE 的全部。剩下的都是实现细节。

九、重参数化技巧 #

上一章留了一个坑：z 是从 N(μ, σ²) 采样出来的。这个采样操作，在反向传播里是个死结。

为什么采样不可导 #

训练的时候，损失函数对 μ 和 σ 求梯度，梯度要一路传回编码器。

链路是这样：

text
x → 编码器 → μ, σ² → [采样] → z → 解码器 → x̂ → loss

梯度从 loss 往回走，走到 z 这一步，要算 ∂z/∂μ 和 ∂z/∂σ。

但 z 是采样出来的，不是 μ 和 σ 算出来的。采样这个操作里有一个随机数生成器，它没有导数。梯度到这里就断了。

这不是实现层面的问题，是数学层面的问题。采样是一个随机操作，给定 μ 和 σ，输出 z 是随机的，不存在一个确定的函数关系让你求偏导。

两个办法：一个是放弃反传，改用别的估计方法，那是 REINFORCE 那一派的路子，方差大、收敛慢。另一个是重参数化，把随机性挪走。

我们讲后者。

把随机性挪到 ε 上 #

关键观察是这一句：

采样这个操作不可导，但采样的结果可导。

具体做法：不从 N(μ, σ²) 里直接采样，而是先从标准正态里采一个 ε，再做一次变换：

text
z = μ + σ · ε        ε ~ N(0, 1)

这两个写法在概率上是等价的。均值 μ 加标准差 σ 乘标准正态，得到的就是 N(μ, σ²)。数学上，如果 ε ~ N(0,1)，那么 μ + σε ~ N(μ, σ²)。分布完全一样。

但计算图变了：

text
改造前： μ, σ  →  [随机采样器]  →  z       梯度断在这
改造后： ε ~ N(0,1)  →  z = μ + σ·ε        ε 是常数输入，μ、σ 参与运算

现在 ε 只是一个从外部进来的常量，不参与求导。z 是 μ 和 σ 的确定性函数：

text
∂z/∂μ = 1
∂z/∂σ = ε

这两个偏导都能算，梯度可以顺畅地传回编码器。

一句话概括：把随机性挪到那个不参与求导的 ε 上，μ 和 σ 就可导了。 直接从 N(μ, σ) 采样这个操作不可导，梯度传不回去；改写成 μ + σ·ε 之后，ε 从 N(0,1) 采样，随机性与求导路径彻底分开。

这里有个细节容易被忽略。我们说 ε 不参与求导，不是因为它被当成常数截断了梯度——它本来就不需要梯度。ε 是采样的结果，是一个给定的数值，像训练数据一样从外面喂进来。梯度只需要流经 μ 和 σ 这两条路径。

为什么这个变换成立 #

严谨一点的推导：

已知 z ~ N(μ, σ²)，令 ε = (z - μ)/σ。

因为正态分布对线性变换封闭，z 减均值再除以标准差，得到的就是标准正态。所以 ε ~ N(0,1)。

反过来，z = μ + σε，如果 ε ~ N(0,1)，那么 E[z] = μ + σ·E[ε] = μ,Var[z] = σ²·Var[ε] = σ²。所以 z ~ N(μ, σ²)。

两个方向都成立，变换是等价的双向映射。

这里要提一句：严格写的话，换元的时候得带上雅可比行列式。密度函数变换是 p(z)dz = p(ε)dε，乘上 dz 才算概率，不乘 dz 只是概率密度。但这件事只影响概率密度的写法，不影响采样流程本身——我们采样只要数值，不要密度。

代码里长什么样 #

在 TensorFlow 里就是两行：

python
# 从标准正态采样 eps，形状和 z_mean 一致
eps = tf.random_normal(tf.stack([tf.shape(h1)[0], n_hidden_2]), 0, 1, dtype=tf.float32)
# z = mu + sigma * eps，其中 sigma = sqrt(exp(log_sigma_sq))
z = tf.add(z_mean, tf.multiply(tf.sqrt(tf.exp(z_log_sigma_sq)), eps))

拆开看：

text
z_log_sigma_sq = log(σ²)        ← 网络输出
tf.exp(...)    = σ²
tf.sqrt(...)   = σ
tf.multiply(σ, eps)            = σε
tf.add(μ, σε)                  = z

三个函数套在一起，就是 z = μ + σ·ε。写得紧凑，但每一步都是明式的，看懂了不难。

tf.stack([tf.shape(h1)[0], n_hidden_2]) 这一段是动态形状。tf.shape(h1)[0] 拿的是当前批次的样本数，训练时是 128，最后一个批次也许不满。写死成 batch_size 也能跑，但最后一个批次会报形状不匹配。

如果输出的是 logσ² 而不是 σ²，也可以直接从 logσ² 算：

python
std = tf.exp(0.5 * z_log_sigma_sq)     # 等价于 sqrt(exp(log_sigma_sq))
z = z_mean + std * eps

exp(0.5 · logσ²) = exp(logσ) = σ，数学上一样，数值上更稳一点，少了一次开方。

一个比喻 #

这个技巧可以这么理解。

想象你要随机从一群人里抽一个，但你希望抽签的结果能影响后面某个环节的评分，并且要能反过来算出「抽签规则该怎么改」。

如果每次抽签的随机性都独立于规则，你没法知道规则往哪改。

重参数化的做法是：把随机性拆成两个部分，一个固定的随机种子 ε，一个由规则决定的偏移 μ 和缩放 σ。抽出来的人 = μ + σ·ε。现在随机性在 ε 里，与规则无关；而规则(μ、σ)对结果的影响是明确的、可微的。评分低了，你就知道该把 μ 往哪挪、σ 放大还是缩小。

随机性没消失，只是被隔离到了一个不动声色的角落。

它为什么必要 #

如果不用重参数化，VAE 就训不起来。这不是「用了更快」，是「不用就不行」。

有人试过绕开：采样之后，把 z 当成常量，梯度只从解码器传，编码器干脆不训。这样能跑，但编码器学不到任何东西，μ 和 σ 全是随机初始化时的值。整个模型退化成「一个随机投影 + 一个解码器」，生成出来是噪声。

另一种绕法是用得分函数估计(REINFORCE)，用 log p(z) 的梯度乘上奖励当梯度的估计。理论正确，但方差极大，需要大量样本才能收敛，在 VAE 这种高维连续空间里基本不可用。

重参数化之所以成为标准做法，是因为它把「随机采样」这个不可导的操作，转化成「确定性变换 + 外部噪声输入」，梯度估计的方差比 REINFORCE 小几个数量级。

这是 VAE 能训练的根本原因。没有这一步，前面所有推导都是纸上谈兵。

一个副作用 #

重参数化还有一个不太被提起的好处：它让隐空间的噪声是可控的。

因为 z = μ + σ·ε，而 σ 是网络自己算出来的，所以每个样本、每个维度上的噪声强度都是独立的、可学习的。模型可以决定「这个维度要精确，σ 小一点」「这个维度可以糊一点，σ 大一点」。

这个自由度在训练中会自然形成一种分工：一部分维度承载精确信息，σ 小；另一部分维度承载模糊的变化方向，σ 大。解码器读到 σ 大的维度，就知道那里的信息不可靠，会更多地依赖其他维度。

如果把 σ 写成全局固定的超参，这层自适应就没了，效果会明显变差。

十、VAE 的损失函数：重构加 KL #

VAE 的损失是两项相加。

text
L = L_recon + L_KL

第一项管重构，第二项管隐空间形状。两项都得有，少一项就退化。

重构项 #

跟普通自编码器一样，衡量 x̂ 和 x 的差距。

text
L_recon = ‖x - x̂‖²

代码里常写成：

python
reconstr_loss = 0.5 * tf.reduce_sum((reconstruction - x) ** 2)

注意这里是 reduce_sum，对整个 batch 的所有元素求和，不是 reduce_mean。而 KL 那一项也是 reduce_sum，但只对最后一维求和，所以形状是 (batch,)。两项最后一起 reduce_mean:

python
cost = tf.reduce_mean(reconstr_loss + latent_loss)

这个形状搭配容易错。reconstr_loss 是标量(对整个 batch 求和之后),latent_loss 是 (batch,) 的向量，两个一加，标量被广播到整个向量上，再取平均。数值上等价于每个样本的重构损失(平均分摊)加每个样本自己的 KL。能跑，但语义上有点绕。

更清楚的写法是两项都算到 (batch,):

python
reconstr_loss = 0.5 * tf.reduce_sum((reconstruction - x) ** 2, 1)   # (batch,)
latent_loss = -0.5 * tf.reduce_sum(1 + z_log_sigma_sq - tf.square(z_mean) - tf.exp(z_log_sigma_sq), 1)  # (batch,)
cost = tf.reduce_mean(reconstr_loss + latent_loss)

这样每个样本有自己的一份损失，语义干净。

重构项也可以用交叉熵：

python
reconstr_loss = tf.reduce_sum(tf.nn.sigmoid_cross_entropy_with_logits(
    logits=reconstruction, labels=x), 1)

用哪个取决于输出层。输出层是线性，sigmoid_cross_entropy_with_logits 会把 logits 过一遍 sigmoid，值域压到 [0,1]，适合 MNIST。

KL 项 #

这一项是 KL(N(μ, σ²) ‖ N(0, I))，推导结果是一个闭式解：

text
L_KL = -0.5 · Σᵢ (1 + logσᵢ² - μᵢ² - σᵢ²)

其中 i 遍历隐变量的每一维，d 是隐变量维度。

代码：

python
latent_loss = -0.5 * tf.reduce_sum(
    1 + z_log_sigma_sq - tf.square(z_mean) - tf.exp(z_log_sigma_sq), 1)

注意代码里写的是 z_log_sigma_sq，就是 logσ²，跟公式里的 logσᵢ² 对应。tf.exp(z_log_sigma_sq) 就是 σ²。

这个式子怎么来的？值得推一遍，不然记不住。

对一维正态分布，N(μ, σ²) 和 N(0, 1) 的 KL 是：

text
KL = ∫ p(x) log(p(x)/q(x)) dx

其中 p 是 N(μ, σ²),q 是 N(0, 1)。

把两个密度函数代进去，log 里变成一个分式，拆开成三项：

text
第一项：-log σ²  ×  ∫p(x)dx

∫p(x)dx 等于 1，所以第一项结果是 -logσ²。

text
第二项：(x-μ)²/(2σ²) 这类项，其实就是正态分布的二阶矩

正态分布的二阶矩是 μ² + σ²。

text
第三项：-∫p(x)·x²/2 dx，化简后是 -(μ² + σ²)/2 ...

一步步算下来，最后合并：

text
KL = -0.5 · (1 + logσ² - μ² - σ²)

对 d 个独立维度求和，就得到上面那个式子。

三项的物理意义挺直观：

  • -logσ² 惩罚 σ 太小(方差太窄)。
  • -μ² 惩罚均值偏离 0。
  • -σ² 惩罚方差太大。

加起来取负号，最小值在 μ = 0、σ = 1 处取得，此时 KL = 0。正好对应「专属分布就是标准正态」。

两项的分工 #

损失项 作用对象 想干什么 单独存在会怎样
重构损失 解码器、编码器的 μ 让 x̂ 逼近 x σ 被压到 0，退化成普通 AE
KL 散度 编码器的 μ 和 σ 让 N(μ, σ²) 靠近 N(0, I) 隐空间完全不携带信息，重构全糊
两项相加 整条链路 在保真和可生成之间找平衡 —

这两项是明确的对抗关系。

重构项希望 σ → 0，这样 z 确定，重构容易。KL 项希望 σ → 1，这样才有生成能力。

均衡点不是人调的，是两项自然形成的。重构项的梯度大小取决于数据难度，KL 项的梯度大小取决于偏离程度，两者一对抗，σ 自己就找到了位置。

这就是为什么源教程里说「直接用这个式子做补充 loss，就不用考虑均值损失和方差损失的相对比例问题」。如果分开写两个损失(一个惩罚 μ，一个惩罚 logσ²)，你确实得调权重；写成 KL 一项，权重就是 1，自然平衡。

不过在实践里，经常还是要加一个 β 系数：

text
L = L_recon + β · L_KL

β > 1 时，隐空间更规整，生成更多样，但重构更糊，这叫 β-VAE。β < 1 时反过来。原版 β = 1。

完整实现 #

784 → 256 → (μ, logσ²) → 2 → 256 → 784。隐变量 2 维，方便画图。

python
import tensorflow as tf
import numpy as np
import matplotlib.pyplot as plt
from tensorflow.examples.tutorials.mnist import input_data
from scipy.stats import norm

mnist = input_data.read_data_sets('MNIST-data', one_hot=True)

print('Training data shape:', mnist.train.images.shape)        # (55000, 784)
print('Test data shape:', mnist.test.images.shape)             # (10000, 784)
print('Validation data shape:', mnist.validation.images.shape)  # (5000, 784)
print('Training label shape:', mnist.train.labels.shape)       # (55000, 10)

'''
网络参数
'''
n_input = 784
n_hidden_1 = 256
n_hidden_2 = 2
learning_rate = 0.001
training_epochs = 20
batch_size = 128
display_epoch = 3
show_num = 10

x = tf.placeholder(dtype=tf.float32, shape=[None, n_input])
# 单独开一个入口，用来喂分布数据，生成模拟样本
zinput = tf.placeholder(dtype=tf.float32, shape=[None, n_hidden_2])

'''
学习参数
注意：初始化用了很小的值 0.001
算 KL 时比较的是与标准高斯的距离，如果初始输出的均值方差都很大，
KL 会非常大，模型直接训崩，输出 NaN
'''
weights = {
    'w1': tf.Variable(tf.truncated_normal([n_input, n_hidden_1], stddev=0.001)),
    'mean_w1': tf.Variable(tf.truncated_normal([n_hidden_1, n_hidden_2], stddev=0.001)),
    'log_sigma_w1': tf.Variable(tf.truncated_normal([n_hidden_1, n_hidden_2], stddev=0.001)),
    'w2': tf.Variable(tf.truncated_normal([n_hidden_2, n_hidden_1], stddev=0.001)),
    'w3': tf.Variable(tf.truncated_normal([n_hidden_1, n_input], stddev=0.001))
}

biases = {
    'b1': tf.Variable(tf.zeros([n_hidden_1])),
    'mean_b1': tf.Variable(tf.zeros([n_hidden_2])),
    'log_sigma_b1': tf.Variable(tf.zeros([n_hidden_2])),
    'b2': tf.Variable(tf.zeros([n_hidden_1])),
    'b3': tf.Variable(tf.zeros([n_input]))
}

'''
网络结构
'''
# 第一层全连接：784 -> 256
h1 = tf.nn.relu(tf.add(tf.matmul(x, weights['w1']), biases['b1']))
# 第二层并列两个输出网络：一个算均值，一个算 log 方差
z_mean = tf.add(tf.matmul(h1, weights['mean_w1']), biases['mean_b1'])
z_log_sigma_sq = tf.add(tf.matmul(h1, weights['log_sigma_w1']), biases['log_sigma_b1'])

# 重参数化：eps ~ N(0,1)，z = mu + sqrt(exp(logσ²)) * eps
eps = tf.random_normal(tf.stack([tf.shape(h1)[0], n_hidden_2]), 0, 1, dtype=tf.float32)
z = tf.add(z_mean, tf.multiply(tf.sqrt(tf.exp(z_log_sigma_sq)), eps))

# 解码器：2 -> 256
h2 = tf.nn.relu(tf.matmul(z, weights['w2']) + biases['b2'])
# 解码器：256 -> 784，还原原始输入
reconstruction = tf.matmul(h2, weights['w3']) + biases['b3']

# 这两个节点不参与训练，只用于按指定 z 生成数据
h2out = tf.nn.relu(tf.matmul(zinput, weights['w2']) + biases['b2'])
reconstructionout = tf.matmul(h2out, weights['w3']) + biases['b3']

'''
反向传播
'''
# 重构 loss
reconstr_loss = 0.5 * tf.reduce_sum((reconstruction - x) ** 2)
print(reconstr_loss.shape)    # (,) 标量
# KL 散度
latent_loss = -0.5 * tf.reduce_sum(
    1 + z_log_sigma_sq - tf.square(z_mean) - tf.exp(z_log_sigma_sq), 1)
print(latent_loss.shape)      # (128,)
cost = tf.reduce_mean(reconstr_loss + latent_loss)

optimizer = tf.train.AdamOptimizer(learning_rate).minimize(cost)
num_batch = int(np.ceil(mnist.train.num_examples / batch_size))

'''
训练
'''
with tf.Session() as sess:
    sess.run(tf.global_variables_initializer())

    print('开始训练')
    for epoch in range(training_epochs):
        total_cost = 0.0
        for i in range(num_batch):
            batch_x, batch_y = mnist.train.next_batch(batch_size)
            _, loss = sess.run([optimizer, cost], feed_dict={x: batch_x})
            total_cost += loss

        if epoch % display_epoch == 0:
            print('Epoch {}/{}  average cost {:.9f}'.format(
                epoch + 1, training_epochs, total_cost / num_batch))

    print('训练完成')

    print('Result:', cost.eval({x: mnist.test.images}))

    # 重构可视化：第一行原图，第二行 VAE 重构
    reconstruction = sess.run(reconstruction, feed_dict={x: mnist.test.images[:show_num]})
    plt.figure(figsize=(1.0 * show_num, 1 * 2))
    for i in range(show_num):
        plt.subplot(2, show_num, i + 1)
        plt.imshow(np.reshape(mnist.test.images[i], (28, 28)), cmap='gray')
        plt.axis('off')
        plt.subplot(2, show_num, i + show_num + 1)
        plt.imshow(np.reshape(reconstruction[i], (28, 28)), cmap='gray')
        plt.axis('off')
    plt.show()

    # 均值代表的二维数据
    plt.figure(figsize=(5, 4))
    labels = [np.argmax(y) for y in mnist.test.labels]
    mean, log_sigma = sess.run([z_mean, z_log_sigma_sq], feed_dict={x: mnist.test.images})
    plt.scatter(mean[:, 0], mean[:, 1], c=labels)
    plt.colorbar()
    plt.show()

    '''
    从标准高斯采样，生成模拟数据
    '''
    n = 15
    digit_size = 28
    figure = np.zeros((digit_size * n, digit_size * n))
    grid_x = norm.ppf(np.linspace(0.05, 0.95, n))
    grid_y = norm.ppf(np.linspace(0.05, 0.95, n))
    for i, yi in enumerate(grid_x):
        for j, xi in enumerate(grid_y):
            z_sample = np.array([[xi, yi]])
            x_decoded = sess.run(reconstructionout, feed_dict={zinput: z_sample})

            digit = x_decoded[0].reshape(digit_size, digit_size)
            figure[i * digit_size: (i + 1) * digit_size,
                   j * digit_size: (j + 1) * digit_size] = digit

    plt.figure(figsize=(10, 10))
    plt.imshow(figure, cmap='gray')
    plt.show()

看懂结果 #

三个输出，各说明一件事。

第一个是重构图。因为它有损失在逼，重构出来的数字还算清楚，但比普通 AE 糊一点——噪声通道一直在起作用。

第二个是隐空间散点图。μ 的 2 维坐标按类别上色。图上会出现明显的簇团：同一类数字挤在一起，不同类之间有一定的间隔。有些区域是空的，那是标准正态覆盖到了但没有真实样本的空白。

第三个最重要：15×15 的网格图。

norm.ppf(np.linspace(0.05, 0.95, n)) 这行是在横竖两个方向上，从标准正态里按分位点取 15 个值。norm.ppf 是累积分布函数的反函数——输入一个概率，输出对应的分位点数值。比如 ppf(0.05) 就是「小于这个数的概率是 5%」的那个数，大约是 -1.64。

取 0.05 到 0.95 而不是全范围，是为了避开两端的极端值。正态分布在 ±3 以外几乎没有样本，取到那里解码出来的东西没意义。

然后把这 225 个点分别送进解码器，拼成一张大图。

看到的效果是：中间区域是清晰的数字，但数字之间是渐变的。从 3 慢慢变成 8，中间经过的形态既不是 3 也不是 8，是一张过渡的脸。这就是隐空间的连续性——两个真实样本之间的位置，解码出来是合理的插值。

这正是普通 AE 做不到的。普通 AE 的隐空间里，那些中间位置解码出来是噪声。VAE 加了 KL 约束之后，中间位置才有意义。

如果网格图上出现大片模糊、认不出任何数字的区域，多半说明训练不充分，或者 KL 权重过大(β 太大)，把隐空间压得太狠，信息全被抹掉了。

隐变量维度怎么选 #

源教程取了 2 维，纯粹为了能画图。

真实任务里 2 维装不下 MNIST 的全部变化。压到 2 维，重构损失会明显偏高，KL 也压不下来，两项打架打得很厉害。想生成质量高一点，隐变量维度至少 16，常见取 32 到 128。

维度大了不能画散点图，但可以画热力图，或者用 t-SNE 再降到 2 维看。

一个观察是：隐变量维度和 KL 项的量级直接相关。d 维的话，KL 的理论下限是 0，上限大约跟 d 成正比。d 越大，KL 项越容易占主导，重构项被压制，结果是隐空间很规整但重构很糊。这时候降 β 或者升重构权重就派上用场了。

十一、条件变分自编码 #

VAE 有个功能缺陷：生成什么，你说了不算。

从 N(0,1) 采一个 z，解码出一张图。这张图也许是 3，也许是 7，也许是任何东西。你知道它像某个数字，但你没法要求它必须是 6。

更麻烦的是，你连它该是什么都不知道。采样是随机的，题目里没有「类别」这个字段。

条件变分自编码（Conditional VAE, CVAE）补的就是这个字段：给我一个标签，按标签生成。

改动只有一个 #

在编码器和解码器里都塞进标签。

text
普通 VAE：
  编码器：x → μ, σ²
  解码器：z → x̂

CVAE：
  编码器：x, y → μ, σ²
  解码器：z, y → x̂

y 是标签的 one-hot 向量。编码时把 y 拼到 x 后面，解码时把 y 拼到 z 后面。

一句话：CVAE 把 y 当成输入的一部分，让整个网络从头到尾都知道「这次要处理的是哪个类」。

训练的时候，模型看到的就是 (x, y) 对，它的重构目标也是 x。但它重构 x 的时候，已经知道 x 是 6 了。于是它会把「6 长什么样」这个信息编码进参数里，而不只是编码进 z 里。

这样有个好处：z 就可以专门承载「这个 6 和别的 6 有什么不同」的信息，不用再管「这是不是 6」。分工明确了，生成的时候只要给 z 一个随机的值，再指定 y，出来的就是一个 6 的变体。

为什么标签要进两个地方 #

只在解码器加标签行不行？

试试看。编码器还是老样子：x → μ, σ²，不知道 y。解码器收到 (z, y)。

问题在于，编码器不知道 y，所以它压出来的 z 里必然混着类别信息——因为从 x 压到 z，不把类别信息编进去，信息就丢了，重构误差下不来。

结果就是：z 里既有类别信息又有风格信息，纠缠在一起。生成时你指定了 y，但 z 里带的类别信息也许会跟 y 冲突，生成的图就不听话。

编码器也加 y 之后，编码器知道这次处理的是 6，它就可以把「这是 6」这个事实交给 y 去承载，z 只保留 6 之间的差异。信息解耦了。

这是条件模型的一个通用原则：条件要贯穿整条链路，不能只加在一头。

结构 #

text
x (784) ──┐
          ├─→ concat(784+10) ─→ h1(256) ─┬─→ μ(2)
y (10) ───┘                              └─→ logσ²(2)
                                              ↓
                                     z = μ + σ·ε  (2)
                                              ↓
y (10) ──┐                                    │
          ├─→ concat(2+10) ─→ h2(256) ─→ x̂ (784)
z (2) ───┘

两个 concat，一个在编码前，一个在解码前。剩下的部分跟标准 VAE 一模一样。

代码 #

在上一章的 VAE 上改。加一个 y 占位符，加一组标签权重，两处 concat。

python
'''
条件变分自编码
'''
import tensorflow as tf
import numpy as np
import matplotlib.pyplot as plt
from tensorflow.examples.tutorials.mnist import input_data

mnist = input_data.read_data_sets('MNIST-data', one_hot=True)

n_input = 784
n_hidden_1 = 256
n_hidden_2 = 2
n_classes = 10
learning_rate = 0.001
training_epochs = 20
batch_size = 128
display_epoch = 3
show_num = 10

x = tf.placeholder(dtype=tf.float32, shape=[None, n_input])
y = tf.placeholder(dtype=tf.float32, shape=[None, n_classes])
# 生成时从这里喂 z
zinput = tf.placeholder(dtype=tf.float32, shape=[None, n_hidden_2])

'''
学习参数
注意几个形状的变化：
  mean_w1 / log_sigma_w1 的输入是 n_hidden_1 * 2，因为 h1 和 h_lab1 拼起来了
  w2 的输入是 n_hidden_2 + n_classes，因为 z 和 y 拼起来了
'''
weights = {
    'w1': tf.Variable(tf.truncated_normal([n_input, n_hidden_1], stddev=0.001)),
    'w_lab1': tf.Variable(tf.truncated_normal([n_classes, n_hidden_1], stddev=0.001)),
    'mean_w1': tf.Variable(tf.truncated_normal([n_hidden_1 * 2, n_hidden_2], stddev=0.001)),
    'log_sigma_w1': tf.Variable(tf.truncated_normal([n_hidden_1 * 2, n_hidden_2], stddev=0.001)),
    'w2': tf.Variable(tf.truncated_normal([n_hidden_2 + n_classes, n_hidden_1], stddev=0.001)),
    'w3': tf.Variable(tf.truncated_normal([n_hidden_1, n_input], stddev=0.001))
}

biases = {
    'b1': tf.Variable(tf.zeros([n_hidden_1])),
    'b_lab1': tf.Variable(tf.zeros([n_hidden_1])),
    'mean_b1': tf.Variable(tf.zeros([n_hidden_2])),
    'log_sigma_b1': tf.Variable(tf.zeros([n_hidden_2])),
    'b2': tf.Variable(tf.zeros([n_hidden_1])),
    'b3': tf.Variable(tf.zeros([n_input]))
}

'''
网络结构
'''
# 图片分支：784 -> 256
h1 = tf.nn.relu(tf.add(tf.matmul(x, weights['w1']), biases['b1']))
# 标签分支：10 -> 256
h_lab1 = tf.nn.relu(tf.add(tf.matmul(y, weights['w_lab1']), biases['b_lab1']))
# 合并：256 + 256 = 512
hall1 = tf.concat([h1, h_lab1], 1)

# 从合并后的 512 维并列算均值和 log 方差
z_mean = tf.add(tf.matmul(hall1, weights['mean_w1']), biases['mean_b1'])
z_log_sigma_sq = tf.add(tf.matmul(hall1, weights['log_sigma_w1']), biases['log_sigma_b1'])

# 重参数化
eps = tf.random_normal(tf.stack([tf.shape(h1)[0], n_hidden_2]), 0, 1, dtype=tf.float32)
z = tf.add(z_mean, tf.multiply(tf.sqrt(tf.exp(z_log_sigma_sq)), eps))
# 解码前把 z 和 y 拼起来：2 + 10 = 12
zall = tf.concat([z, y], 1)

# 解码器：12 -> 256 -> 784
h2 = tf.nn.relu(tf.matmul(zall, weights['w2']) + biases['b2'])
reconstruction = tf.matmul(h2, weights['w3']) + biases['b3']

# 生成专用节点：指定 z 和 y，输出图片
zinputall = tf.concat([zinput, y], 1)
h2out = tf.nn.relu(tf.matmul(zinputall, weights['w2']) + biases['b2'])
reconstructionout = tf.matmul(h2out, weights['w3']) + biases['b3']

'''
损失：重构 + KL，形式跟标准 VAE 完全一样
'''
reconstr_loss = 0.5 * tf.reduce_sum((reconstruction - x) ** 2)
print(reconstr_loss.shape)    # (,) 标量
latent_loss = -0.5 * tf.reduce_sum(
    1 + z_log_sigma_sq - tf.square(z_mean) - tf.exp(z_log_sigma_sq), 1)
print(latent_loss.shape)      # (128,)
cost = tf.reduce_mean(reconstr_loss + latent_loss)

optimizer = tf.train.AdamOptimizer(learning_rate).minimize(cost)
num_batch = int(np.ceil(mnist.train.num_examples / batch_size))

'''
训练
'''
with tf.Session() as sess:
    sess.run(tf.global_variables_initializer())

    print('开始训练')
    for epoch in range(training_epochs):
        total_cost = 0.0
        for i in range(num_batch):
            batch_x, batch_y = mnist.train.next_batch(batch_size)
            # 注意这里把 y 也喂进去了
            _, loss = sess.run([optimizer, cost], feed_dict={x: batch_x, y: batch_y})
            total_cost += loss

        if epoch % display_epoch == 0:
            print('Epoch {}/{}  average cost {:.9f}'.format(
                epoch + 1, training_epochs, total_cost / num_batch))

    print('训练完成')

    print('Result:', cost.eval({x: mnist.test.images, y: mnist.test.labels}))

    # 重构：给原图和标签，看能不能还原
    reconstruction = sess.run(reconstruction,
                              feed_dict={x: mnist.test.images[:show_num],
                                         y: mnist.test.labels[:show_num]})
    plt.figure(figsize=(1.0 * show_num, 1 * 2))
    for i in range(show_num):
        plt.subplot(2, show_num, i + 1)
        plt.imshow(np.reshape(mnist.test.images[i], (28, 28)), cmap='gray')
        plt.axis('off')
        plt.subplot(2, show_num, i + show_num + 1)
        plt.imshow(np.reshape(reconstruction[i], (28, 28)), cmap='gray')
        plt.axis('off')
    plt.show()

    '''
    按标签生成：z 随机，y 指定
    '''
    z_sample = np.random.randn(show_num, 2)
    reconstruction = sess.run(reconstructionout,
                              feed_dict={zinput: z_sample,
                                         y: mnist.test.labels[:show_num]})
    plt.figure(figsize=(1.0 * show_num, 1 * 2))
    for i in range(show_num):
        plt.subplot(2, show_num, i + 1)
        plt.imshow(np.reshape(mnist.test.images[i], (28, 28)), cmap='gray')
        plt.axis('off')
        plt.subplot(2, show_num, i + show_num + 1)
        plt.imshow(np.reshape(reconstruction[i], (28, 28)), cmap='gray')
        plt.axis('off')
    plt.show()

两幅图在说什么 #

第一幅是重构。上面一行是原始图片，下面一行是 CVAE 的输出。因为喂了标签，重构质量比标准 VAE 好一些——标签帮它排除了一部分不确定性。

第二幅才是重点。上面一行还是原始图片，下面一行是「用同一批标签 + 随机 z 生成」的图。

注意这两行的关系：它们形状相似，但笔画不一样。上面是 4，下面也是 4，但倾斜角、笔画粗细、收笔的位置全变了。这就是「学会了分布」的表现——它生成的不再是某张具体的图，而是「这类图的一个合理实例」。

源教程在这一点上说得挺准：通过标签生成的数据，已经彻底学会了样本数据的分布，并生成了与输入截然不同但带有相同意义的数据。

「截然不同但带有相同意义」，这句话可以当作生成模型的定义。只会复制输入的是自编码器，能造出新实例的是生成模型。

条件生成的边界 #

CVAE 能按标签生成，但它生成的质量有上限。

第一，标签必须提前知道。想生成一个「全新的、训练集里没有的类别」，做不到。CVAE 学的是给定类别的条件分布，类别的集合是固定的。

第二，条件形式受限于 one-hot。如果想让条件是「粗一点的 3」或者「带点斜的 7」，one-hot 表达不了。得把条件换成向量，比如用属性标注，或者用另一个编码器把条件也压成向量。这就是后面条件扩散模型里 classifier-free guidance 那套思路的来源。

第三，标签的作用是强约束，不是建议。喂错标签，生成的图就按错的那个标签走。比如给一个 5 的图配 8 的标签去重构，出来的多半是 8 的样子。这个行为在调试时可以用来验证「标签到底有没有起作用」——如果喂错标签生成结果没变化，说明条件没生效，多半是 concat 拼错了维度或顺序。

VAE 与 CVAE 的差别 #

对比项 VAE CVAE
输入 x x, y
编码器输入 784 784 + 10（拼接）
解码器输入 z (2) z + y (12)
损失函数 重构 + KL 重构 + KL（形式相同）
生成方式 z ~ N(0,1)，类别随机 z ~ N(0,1) + 指定 y，类别可控
能指定的东西 只能指定「像训练数据」 可以指定类别，甚至更多属性
参数增量 — 两组标签权重，约 2.6 万参数

参数增量很小。w_lab1 是 10×256,b_lab1 是 256，再加上 concat 导致的两处输入维度扩张：mean_w1 从 256×2 变成 512×2，多了 512 个；w2 从 2×256 变成 12×256，多了 2560 个。总共不到 3 万个参数，相对整个网络的 40 多万，占比很小。

代价小，收益明确。这就是为什么条件化是生成模型里最常用的改造手段。

几个容易被忽视的点单独说。

激活函数的选择 #

sigmoid 在自编码器里用得很多，原因是输出值域刚好是 [0,1]，跟归一化后的图像对得上。但它有两个毛病：两端饱和，梯度接近零；输出均值不是 0，后面一层学起来慢。

编码器的隐藏层建议用 ReLU 或 leaky ReLU。只有最后一层输出层，如果是图像重构，才用 sigmoid。

瓶颈层之前那一层，用 ReLU 比 sigmoid 好；瓶颈层本身，如果能用线性就用线性，理由讲降维的那一章讲过——少一层非线性变换，少丢一点信息。

权重初始化 #

tf.random_normal 是标准正态，标准差是 1。对一个 784 到 256 的全连接层，输入 784 个数乘上标准差为 1 的权重，输出的量级会到 sqrt(784) ≈ 28。再过 sigmoid，全挤在饱和区，梯度为 0，训练直接卡死。

所以要用 tf.truncated_normal(shape, stddev=0.1)。截断正态把超过两倍标准差的采样砍掉重采，避免极端值；stddev 设小，控制输出量级。

VAE 里用 0.001 是因为 KL 项对初始分布极其敏感，标准更严。

检查点的坑 #

栈式自编码器那段代码里，saver.save 每个 epoch 存一次，max_to_keep=1 意味着只保留最新的一个。这本身没问题，但如果中间训练崩了想回滚到上一轮，就没得回。

调试阶段把 max_to_keep 设成 5 或 10，多留几个。生产环境再改回 1，省磁盘。

还有个更隐蔽的问题：多个 session 分开跑的时候，变量会被重新初始化。栈式自编码器那一章详细讲过这个坑，核心是每个 session 都要 restore，否则你以为在续训，其实每次都是从随机权重开始。

维度对不上 #

tf.concat 是最高频的错误源。

python
hall1 = tf.concat([h1, h_lab1], 1)      # 256 + 256 = 512
zall = tf.concat([z, y], 1)             # 2 + 10 = 12

axis=1 是拼在特征维上。如果两个张量的 batch 维不一致，或者拼完的维度跟下一层的输入权重形状不匹配，报的错会很明确：shape mismatch。但如果是顺序搞反了(先 y 后 z)，形状也许恰好都对，训练也能跑，只是学不到条件——这种静默错误最难查。

判断方法：固定 z，换不同的 y，看输出有没有变。没变就是条件没接上。

采样数量的陷阱 #

python
eps = tf.random_normal(tf.stack([tf.shape(h1)[0], n_hidden_2]), 0, 1, dtype=tf.float32)

tf.shape(h1)[0] 是运行时的批次大小。这个写法是对的。

如果写成 batch_size，训练时 batch_size=128 能对上，但最后一个批次不满，采样出来的 eps 形状是 (128, 2)，而 z_mean 是 (实际样本数， 2)，两个一加就报形状错误。

有人图省事写成 tf.random_normal(tf.shape(z_mean))。这个写法更稳，直接对齐 z_mean 的形状，不用手算。

重构损失用 sum 还是 mean #

VAE 里多用 reduce_sum 而不是 reduce_mean，原因是 KL 项的量级跟隐变量维度挂钩，重构项如果取平均，两项的比例会随 batch 大小和图像尺寸漂移，不好平衡。

用 sum 的话，重构项的量级是「一张图所有像素的误差总和」，KL 的量级是「所有隐变量维度的偏离总和」，两者都在「总和」这个尺度上，直接相加比较合理。

但要注意，用 sum 之后损失值会很大，打印时别被吓到。MNIST 上一个批次的整体损失到几千是正常的。

训练结束后该看什么 #

不看损失数字，看三样东西。

一看重构。找几张测试图，打印原图和重构，肉眼对比。损失 0.05 和 0.06 的区别在图上看不出来，但边缘糊不糊一眼就知道。

二看隐空间。如果是 2 维，画散点图；如果是高维，用 t-SNE 降维再画。看类别有没有分开，看有没有大片的空洞。

三看插值。在隐空间里取两个点，线性插值出一串中间点，全部解码，排成一行。如果中间形态是平滑过渡的，说明隐空间连续；如果中间突然变成噪声，说明隐空间有洞，生成能力不行。

这三样检查比任何单一指标都靠谱。

到这里，自编码器这条线就走完了。从最基础的重构，到去噪、栈式，再到 VAE 和条件 VAE。核心的理解只有一句：瓶颈逼出特征，分布逼出生成。前者是压缩，后者是采样。中间隔着的，是一个重参数化技巧的距离。
