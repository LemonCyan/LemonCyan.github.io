1. 概述与核心概念 #

1.1 系统调用与标准库函数 #

  • 系统调用（System Call）：操作系统内核提供给用户程序的唯一正式编程接口。计算机软硬件资源（CPU、内存、外设、磁盘）由内核统一调度与保护，用户进程无法直接操作硬件，必须通过陷入内核（如软中断或 syscall 指令）由操作系统代为执行。
  • 库函数（Library Function / API）：为了提升易用性与跨平台移植性，C 标准库（如 GLIBC）对底层系统调用进行了二次封装。例如 printf、fopen 在 POSIX/Linux 系统底层封装了 write、open 系统调用，并引入了用户态缓冲区机制以显著减少系统调用频率。

1.2 文件 I/O 与标准 I/O 对比 #

比较维度 文件 I/O（低级 I/O / 系统调用） 标准 I/O（高级 I/O / 库函数）
规范标准 POSIX 标准（特定于 Unix/Linux 平台） ANSI C / ISO C 标准（跨平台通用）
操作句柄 文件描述符（非负整数 int fd） 流指针（FILE *）
缓冲机制 无缓冲（每次调用直接触发陷入内核） 带用户态缓冲（全缓冲 / 行缓冲 / 无缓冲）
操作对象 普通文件、设备节点、管道、套接字等所有文件类型 主要面向普通磁盘文件及标准终端设备
性能特征 小数据量频繁读写时系统调用开销大 缓冲区合并写入，大幅减少系统调用上下文切换开销
核心 API 对照 open, close, read, write, lseek fopen, fclose, fread, fwrite, fseek

1.3 文件描述符（File Descriptor） #

  • 概念：内核为进程维护的打开文件记录表项的索引，是一个非负整数。进程通过该整数操作具体的文件资源通道。
  • 分配原则：系统遵循最小可用非负整数原则（从 0 开始搜索当前进程尚未使用的最小整数进行分配）。
  • 默认预分配描述符：每个进程启动时默认打开三个标准流：
    • 0（STDIN_FILENO）：标准输入，默认映射键盘/终端。
    • 1（STDOUT_FILENO）：标准输出，默认映射屏幕/终端。
    • 2（STDERR_FILENO）：标准错误，默认映射屏幕/终端。

1.4 标准 I/O 缓冲机制 #

标准 I/O 在用户空间为每个文件流开辟了一块内存缓冲区（Buffer），以优化 I/O 执行粒度：

  • 全缓冲（_IOFBF）：缓冲区被填满后，或者显式调用 fflush / fclose 时才执行系统调用。普通磁盘文件默认使用全缓冲。
  • 行缓冲（_IOLBF）：在遇到换行符 \n、缓冲区满、或需要从标准输入读取时触发系统调用。与终端设备连接的流（如 stdout）默认使用行缓冲。
  • 无缓冲（_IONBF）：库函数不维护缓冲区，每次读写直接调用系统调用。标准错误流（stderr）默认无缓冲，保证错误信息第一时间输出。

2. 文件 I/O 系统调用（底层非缓冲 I/O） #

2.1 open / openat（打开与创建文件） #

  • 头文件：<fcntl.h>, <sys/types.h>, <sys/stat.h>
  • 原型：
    c
    int open(const char *pathname, int flags);
int open(const char *pathname, int flags, mode_t mode);
  • 参数说明：
    • flags：访问模式（必选其一：O_RDONLY, O_WRONLY, O_RDWR）与位掩码组合：
      • O_CREAT：文件不存在时创建，此时必须传递第三个参数 mode。
      • O_EXCL：与 O_CREAT 连用，若文件已存在则报错返回（用于保证原子创建）。
      • O_TRUNC：若文件已存在且以写模式打开，则将其长度截断为 0。
      • O_APPEND：以追加方式写入，每次写操作自动移至文件末尾。
      • O_NONBLOCK：非阻塞方式打开（常用于 FIFO、字符设备、套接字）。
    • mode：新文件的初始权限（如 0664），最终权限受进程掩码约束：mode & ~umask。
  • 返回值：成功返回新的文件描述符，失败返回 -1 并置 errno。

2.2 read（读取数据） #

  • 头文件：<unistd.h>
  • 原型：ssize_t read(int fd, void *buf, size_t count);
  • 参数说明：从 fd 中最多读取 count 字节数据到 buf 指向的缓冲区。
  • 返回值：
    • > 0：实际读取的字节数（可能小于 count）。
    • 0：读到文件末尾（EOF）。
    • -1：发生错误，并设置 errno（如被信号中断 EINTR，非阻塞无数据 EAGAIN）。

2.3 write（写入数据） #

  • 头文件：<unistd.h>
  • 原型：ssize_t write(int fd, const void *buf, size_t count);
  • 参数说明：将 buf 中最多 count 字节写入 fd。
  • 返回值：成功返回实际写入字节数，失败返回 -1 并置 errno。

2.4 close（关闭文件） #

  • 头文件：<unistd.h>
  • 原型：int close(int fd);
  • 说明：释放该文件描述符并解除与底层文件表的关联。成功返回 0，失败返回 -1。

2.5 lseek（调整读写位置与空洞文件） #

  • 头文件：<unistd.h>, <sys/types.h>
  • 原型：off_t lseek(int fd, off_t offset, int whence);
  • 参数说明：
    • offset：位移量（可正可负）。
    • whence：基准位置：SEEK_SET（文件开头）、SEEK_CUR（当前位置）、SEEK_END（文件末尾）。
  • 返回值：成功返回相对于文件开头的绝对偏移量（字节数），失败返回 -1。
  • 特性应用：
    • 获取当前偏移：lseek(fd, 0, SEEK_CUR);
    • 测算文件大小：lseek(fd, 0, SEEK_END);
    • 空洞文件（File Hole）：允许将偏移移至超出文件实际大小的位置后写入数据，中间未分配物理磁盘块的区域形成空洞，逻辑上读为 0，节约物理磁盘空间。

2.6 fcntl（文件描述符控制） #

  • 头文件：<fcntl.h>, <unistd.h>
  • 原型：
    c
    int fcntl(int fd, int cmd, ... /* arg */ );
  • 核心命令（cmd）：
    • F_DUPFD：复制文件描述符，返回大于等于 arg 的最小可用描述符。
    • F_GETFD / F_SETFD：获取/设置文件描述符标志（如 FD_CLOEXEC 执行 exec 时自动关闭）。
    • F_GETFL / F_SETFL：获取/设置文件状态标志（仅可动态修改 O_APPEND, O_NONBLOCK, O_ASYNC）。
    • F_GETLK / F_SETLK / F_SETLKW：通过 struct flock 管理记录锁（区域读写锁）。SETLK 非阻塞加锁，SETLKW 阻塞加锁。
  • 锁结构体：
    c
    struct flock {
    short l_type;   // F_RDLCK(共享读锁), F_WRLCK(排他写锁), F_UNLCK(解锁)
    short l_whence; // SEEK_SET, SEEK_CUR, SEEK_END
    off_t l_start;  // 区域相对起点偏移
    off_t l_len;    // 锁定长度（0 表示从起点至文件末尾）
    pid_t l_pid;    // 锁持有者的进程 ID（由 F_GETLK 返回）
};

2.7 flock（文件建议锁） #

  • 头文件：<sys/file.h>
  • 原型：int flock(int fd, int operation);
  • 说明：对整个文件加锁（不支持局部字节区间）。
    • operation：LOCK_SH（共享读锁）、LOCK_EX（排他写锁）、LOCK_UN（释放锁）、LOCK_NB（非阻塞，与前两者按位或）。
    • 成功返回 0，失败返回 -1。

3. 文件属性、元数据与目录操作 #

3.1 stat / fstat / lstat（获取文件元数据） #

  • 头文件：<sys/stat.h>, <unistd.h>
  • 原型：
    c
    int stat(const char *pathname, struct stat *statbuf);
int fstat(int fd, struct stat *statbuf);
int lstat(const char *pathname, struct stat *statbuf);
    • stat 会追踪符号链接；lstat 不追踪，直接获取符号链接自身属性。
  • 核心结构体 struct stat：
    • st_mode：文件类型与权限位（配合 S_ISREG(), S_ISDIR(), S_ISLNK() 等宏判断）。
    • st_ino：Inode 编号。
    • st_nlink：硬链接数。
    • st_uid, st_gid：所有者用户 ID 和组 ID。
    • st_size：文件大小（字节数）。
    • st_atime, st_mtime, st_ctime：最后访问、内容修改、状态修改时间戳。

3.2 用户与组信息解析 #

  • 头文件：<pwd.h>, <grp.h>
  • 函数原型：
    c
    struct passwd *getpwuid(uid_t uid); // 根据 uid 获取用户记录（含用户名 pw_name、主目录等）
struct group *getgrgid(gid_t gid);  // 根据 gid 获取组记录（含组名 gr_name、成员等）

3.3 时间格式转换 #

  • 头文件：<time.h>
  • 函数原型：struct tm *localtime(const time_t *timep);
  • 说明：将 Unix 时间戳（如 st_mtime）转换为本地日历时间结构体 struct tm（年、月、日、时、分、秒）。

3.4 目录操作接口 #

  • 头文件：<dirent.h>, <sys/stat.h>
  • 函数原型：
    c
    int mkdir(const char *pathname, mode_t mode); // 创建目录
int rmdir(const char *pathname);              // 删除空目录
DIR *opendir(const char *name);               // 打开目录，返回目录流指针
struct dirent *readdir(DIR *dirp);            // 读取下一项目录条目
void rewinddir(DIR *dirp);                    // 重置目录读取指针
int closedir(DIR *dirp);                      // 关闭目录流
  • 目录项结构体 struct dirent 关键字段：
    • d_ino：条目 Inode 号。
    • d_name：文件名（字符串）。
    • d_type：文件类型（如 DT_REG, DT_DIR, DT_LNK）。

3.5 常用文件与环境辅助接口 #

  • 权限与存在性探测：int access(const char *pathname, int mode);
    • mode 选项：F_OK（是否存在）、R_OK（可读）、W_OK（可写）、X_OK（可执行）。成功返回 0。
  • 切换工作目录：int chdir(const char *path);
    • 更改当前进程的工作目录，成功返回 0，失败返回 -1。
  • 命令行参数解析：int getopt(int argc, char * const argv[], const char *optstring);
    • 解析诸如 ls -la 的短选项，配合外部变量 optarg, optind, opterr 使用。

4. 标准 I/O 库函数（高级缓冲 I/O） #

4.1 流的打开、重定向与关闭 #

fopen（打开文件流） #

  • 头文件：<stdio.h>
  • 原型：FILE *fopen(const char *pathname, const char *mode);
  • 模式字符串（mode）：
    模式 读写权限 若文件存在 若文件不存在 流初始位置
    "r" 只读 正常打开 打开失败（返回 NULL） 文件开头
    "r+" 可读写 正常打开 打开失败（返回 NULL） 文件开头
    "w" 只写 截断长度为 0 创建新文件 文件开头
    "w+" 可读写 截断长度为 0 创建新文件 文件开头
    "a" 只写（追加） 内容保留，末尾写入 创建新文件 文件末尾
    "a+" 可读写（追加） 内容保留，末尾写入 创建新文件 读从头，写在尾
  • 二进制模式：可附加 "b"（如 "rb", "w+b"），在 Linux/POSIX 中该标志会被忽略。
  • 返回值：成功返回文件流指针 FILE *，失败返回 NULL 并设置 errno。

freopen（文件流重定向） #

  • 原型：FILE *freopen(const char *pathname, const char *mode, FILE *stream);
  • 说明：关闭原 stream 并将该流重定向到指定路径的文件上（常用于重定向 stdin/stdout/stderr）。

fclose（关闭文件流） #

  • 原型：int fclose(FILE *stream);
  • 说明：先刷新用户缓冲区内未写出的数据，随后调用底层 close 释放文件描述符与缓冲区。成功返回 0，失败返回 EOF。

4.2 文件流与文件描述符互转 #

fdopen（从文件描述符包装文件流） #

  • 原型：FILE *fdopen(int fd, const char *mode);
  • 说明：将现有文件描述符 fd 关联并封装为一个 FILE * 流指针。mode 必须与 fd 原有打开权限兼容。

fileno（获取文件流底层文件描述符） #

  • 原型：int fileno(FILE *stream);
  • 说明：取得参数 stream 内部对应的整数文件描述符。成功返回 fd，失败返回 -1。

4.3 单字符 I/O #

fgetc / getc / getchar（读取单个字符） #

  • 头文件：<stdio.h>
  • 原型：
    c
    int fgetc(FILE *stream);
int getc(FILE *stream);       // 通常为宏实现，效率略高，入参不能有副作用
int getchar(void);            // 等价于 getc(stdin)
  • 返回值：成功返回读取字符（以 unsigned char 转为 int 返回），到达文件末尾或出错返回 EOF(-1)。

fputc / putc / putchar（写入单个字符） #

  • 原型：
    c
    int fputc(int c, FILE *stream);
int putc(int c, FILE *stream);        // 宏定义实现
int putchar(int c);                   // 等价于 putc(c, stdout)
  • 返回值：成功返回写入字符，失败返回 EOF。

ungetc（字符推回流） #

  • 原型：int ungetc(int c, FILE *stream);
  • 说明：将字符 c 退回到输入流缓冲区，下次读取流时会优先读出该字符。成功返回 c，失败返回 EOF（标准保证至少支持退回 1 个字符）。

4.4 行 I/O #

fgets / fputs（安全行读写） #

  • 原型：
    c
    char *fgets(char *s, int size, FILE *stream);
int fputs(const char *s, FILE *stream);
  • 说明：
    • fgets：从 stream 读取最多 size - 1 个字符到 s，保留换行符 \n，末尾自动追加 \0。成功返回 s，EOF 或出错返回 NULL。
    • fputs：将以 \0 结尾的字符串 s 写入 stream，不自动添加换行符。成功返回非负整数，失败返回 EOF。

gets / puts 与安全性辨析 #

  • 原型：char *gets(char *s);（已在 C11/POSIX 废除，严禁使用，因无长度限制极易缓冲区溢出）。
  • 原型：int puts(const char *s);（向 stdout 输出字符串并自动追加 \n）。
  • 行函数对比：
    函数 输入/输出流 换行符 \n 处理 缓冲区长度限制 安全性
    fgets 任意文件流 保留读入的换行符 有长度参数 size 安全
    gets 仅 stdin 丢弃换行符 无限制 危险（废弃）
    fputs 任意文件流 原样输出，不补 \n 依赖字符串结束符 安全
    puts 仅 stdout 自动在末尾追加 \n 依赖字符串结束符 安全

4.5 块 / 二进制 I/O（全缓冲） #

fread / fwrite #

  • 头文件：<stdio.h>
  • 原型：
    c
    size_t fread(void *ptr, size_t size, size_t nmemb, FILE *stream);
size_t fwrite(const void *ptr, size_t size, size_t nmemb, FILE *stream);
  • 参数说明：
    • ptr：内存缓冲区指针。
    • size：单个数据块的字节数。
    • nmemb：期望读写的数据块个数。
    • stream：文件流指针。
  • 返回值：成功返回实际读取或写入的数据项个数（nmemb）：
    • 若 fread 返回值小于 nmemb，需用 feof 或 ferror 区分是到文件尾还是发生错误。
    • 若 fwrite 返回值小于 nmemb，通常意味着写入出错（如磁盘空间不足）。

4.6 格式化 I/O #

  • 原型：
    c
    int fprintf(FILE *stream, const char *format, ...);
int sprintf(char *str, const char *format, ...);
int snprintf(char *str, size_t size, const char *format, ...); // 带边界保护，推荐
int fscanf(FILE *stream, const char *format, ...);
int sscanf(const char *str, const char *format, ...);
  • 核心要点：
    • fprintf：按格式输出到文件流。
    • sprintf / snprintf：按格式写入字符数组（snprintf 保证最多写入 size-1 字符并以 \0 结尾）。
    • sscanf：从内存字符串中按格式解析提取变量，返回成功匹配赋值的变量个数。

4.7 文件流定位与寻址 #

fseek / ftell / rewind（标准定位） #

  • 原型：
    c
    int fseek(FILE *stream, long offset, int whence);
long ftell(FILE *stream);
void rewind(FILE *stream);
  • 说明：
    • fseek：调整文件流读写位置，whence 可选 SEEK_SET, SEEK_CUR, SEEK_END。成功返回 0，失败返回 -1。
    • ftell：返回当前流指针相对于文件头的绝对字节偏移量，失败返回 -1L。
    • rewind：重置流位置到文件开头，等价于 (void)fseek(stream, 0, SEEK_SET); 并清除错误标志。

fgetpos / fsetpos（支持超大文件的位置抽象） #

  • 原型：
    c
    int fgetpos(FILE *stream, fpos_t *pos);
int fsetpos(FILE *stream, const fpos_t *pos);
  • 说明：使用不透明结构体 fpos_t 记录和恢复流位置，可在复杂平台或超大文件中提供高移植性支持。成功返回 0。

4.8 缓冲区控制与显式刷新 #

fflush（刷新流缓冲区） #

  • 原型：int fflush(FILE *stream);
  • 说明：
    • 若 stream 为输出流，将用户态缓冲区中所有未写出数据强制送入内核系统调用。
    • 若 stream 为 NULL，则刷新当前进程所有打开的输出流。
    • 成功返回 0，失败返回 EOF 并置 errno。

setbuf / setbuffer / setlinebuf / setvbuf（配置流缓冲行为） #

  • 原型：
    c
    void setbuf(FILE *stream, char *buf);
void setbuffer(FILE *stream, char *buf, size_t size);
void setlinebuf(FILE *stream);
int setvbuf(FILE *stream, char *buf, int mode, size_t size);
  • 参数与模式说明：
    • 必须在流打开后、执行任何 I/O 操作前调用。
    • setbuf(stream, buf)：若 buf 为 NULL 等价于设置为无缓冲；若非 NULL 则使用系统默认 BUFSIZ 的全缓冲。
    • setvbuf 最通用且完全受控：
      • _IOFBF：全缓冲，缓冲区为 buf，大小为 size。
      • _IOLBF：行缓冲。
      • _IONBF：无缓冲（忽略 buf 与 size）。

4.9 流状态与错误检测 #

feof / ferror / clearerr #

  • 原型：
    c
    int feof(FILE *stream);
int ferror(FILE *stream);
void clearerr(FILE *stream);
  • 说明：
    • feof：检查是否触及 EOF（文件结束标志）。触及返回非 0，否则返回 0。
    • ferror：检查流是否产生读写错误标志。有错误返回非 0，否则返回 0。
    • clearerr：同时复位清除流上的 EOF 标志和错误标志，允许流恢复后续操作。

4.10 临时文件接口 #

tmpfile / tmpnam / mktemp #

  • 原型：
    c
    FILE *tmpfile(void);            // 创建并以 "w+b" 打开临时文件，关闭或程序退出时自动删除
char *tmpnam(char *s);          // 生成唯一临时文件名（存在竞态条件，不推荐）
char *mktemp(char *template);   // 需传入以 "XXXXXX" 结尾的字符数组模板
  • 安全提示：tmpfile 会直接打开文件并立刻解除磁盘链接（unlink），避免被其他恶意进程劫持，推荐优先使用 tmpfile 或 POSIX 的 mkstemp。
