第7章 数组与字符串 #

本章目标：掌握一维与多维数组的声明、初始化、访问和传参方式，理解 C 风格字符序列与 std::string 的区别，并能用标准库完成常用字符串操作与分割。

7.1 引子：为什么需要这一章 #

当程序需要保存一组同类型数据时，为它们各起一个变量名显然不可行。数组（array）提供了在内存中连续存放一组同类型元素的办法：所有元素共用一个名称，通过索引（index）区分。字符串本质上也是一串连续的字符，因此既可以用字符数组表示，也可以使用标准库提供的 std::string。本章先把数组与字符序列讲清楚，再过渡到更安全的 std::string；数组名与地址的关系会在 参见 第8章「指针」 中进一步展开。

7.2 一维数组的声明与初始化 #

声明数组要给出元素类型、数组名和元素个数，形式为 type name[elements];。其中 elements 必须是常量，因为数组是一块固定大小的静态空间，编译器要在编译期确定需要分配多少内存。例如 int billy[5]; 声明 5 个 int 元素，double balance[10]; 声明 10 个 double 元素。所有数组都由连续的内存位置组成，最低地址对应第一个元素，最高地址对应最后一个元素。

数组的初始化用花括号完成，例如 int billy[5] = {16, 2, 77, 40, 12071};。若花括号中给出的初值个数与声明长度一致，也可以省略方括号中的长度，由编译器按初值个数推断，写作 int billy[] = {16, 2, 77, 40, 12071};，二者等价。

注意：花括号中初值的个数不能多于方括号中声明的元素个数。局部数组（在函数内声明）若未显式初始化，其元素内容是不确定的；全局数组则会由编译器把所有元素初始化为 0。

7.3 数组元素的访问与越界 #

访问数组元素使用 name[index] 的形式。索引从 0 开始，因此长度为 5 的 billy 的首元素是 billy[0]，第 3 个元素是 billy[2]，最后一个元素是 billy[4]。方括号有两种不同用途：声明时写在类型之后表示数组长度，引用时写在数组名之后表示索引，两者不要混淆。

C++ 不对数组下标做范围检查，billy[5] 这样的越界访问在语法上是合法的，不会触发编译错误，却会在运行时读到或改写数组之外的内存，产生难以定位的错误。越界为何「合法」，其根源要到 参见 第8章「指针」 才能解释清楚——数组下标本质上是指针运算的结果。

下面的例子把声明、初始化、遍历、多维数组和数组传参串在一起：

cpp
#include <iostream>
using namespace std;

// 打印整型数组：数组以地址形式传入，长度需由调用方额外给出
void printArray(int arg[], int length) {
    for (int i = 0; i < length; ++i) {
        cout << arg[i] << " ";
    }
    cout << endl;
}

int main() {
    int billy[5] = {16, 2, 77, 40, 12071};
    int result = 0;
    for (int n = 0; n < 5; ++n) {
        result += billy[n];
    }
    cout << "元素总和：" << result << endl;

    int jimmy[3][5];  // 3 行 5 列的二维数组
    for (int row = 0; row < 3; ++row) {
        for (int col = 0; col < 5; ++col) {
            jimmy[row][col] = (row + 1) * (col + 1);
        }
    }
    cout << "jimmy[1][3] = " << jimmy[1][3] << endl;

    int firstArray[] = {5, 10, 15};
    printArray(firstArray, 3);  // 数组名作为地址传入
    return 0;
}

7.4 多维数组 #

多维数组可以理解为「数组的数组」。例如 int jimmy[3][5]; 声明了一个 3 行 5 列的二维表格，引用第 2 行第 4 列元素写作 jimmy[1][3]。维数不受限制，但维数越多占用的内存增长越快：素材中的 char century[100][365][24][60][60]; 要给一个世纪的每一秒保存一个字符，合计超过 30 亿个字符，约消耗 3000 MB 内存。

多维数组只是一种抽象。编译器在内存中仍然按一维方式连续存放所有元素，int jimmy[3][5]; 与 int jimmy[15];（3 × 5 = 15）占用同样大小的空间；区别在于编译器帮我们记住了每一维的深度，从而把 jimmy[n][m] 换算成 jimmy[n * 5 + m]。用宏定义常量表示各维长度，可以让后续修改只改一处。

数组作为函数参数时，C++ 并不复制整块内存，而是传递它的地址，因此形参只需写成 int arg[]，调用时直接写数组名，例如 procedure(myarray);。由于函数无法从地址得知元素个数，通常要额外传入一个长度参数，如 void printarray(int arg[], int length);。多维数组作参数时，第一维可以留空，其余各维必须写明，例如 void procedure(int myarray[][3][4]);，这样编译器才能正确换算下标。数组与地址、指针的等价关系详见 参见 第8章「指针」。

7.5 C 风格字符串（字符序列） #

字符串是一串连续的字符，可以用字符数组表示，并在有效内容末尾追加一个空字符（null character，写作 '\0' 或 0）标记结束。例如 char jenny[20]; 最多容纳 20 个字符，实际常用来存放 "Hello" 这样更短的内容，剩余字节的值不确定。

字符数组有两种等价的初始化写法：逐个列出字符 char mystring[] = {'H', 'e', 'l', 'l', 'o', '\0'};，或直接用双引号括起的字符串常量 char mystring[] = "Hello";。后者由编译器自动在末尾补上 '\0'，所以 "Hello" 会占用 6 个 char：组成单词的 5 个字符加一个空字符。

注意：一次给数组赋多个值只在「声明并初始化」时合法。数组一旦声明完成，就不能再整体赋值，诸如 mystring = "Hello";、mystring[] = "Hello"; 都是错误的；只能逐个元素赋值，或借助下面介绍的函数。其根本原因同样与数组名是地址有关，参见 第8章「指针」。

给字符数组赋值或读入，通常使用 cstring（即 C 的 string.h）中的函数和输入流成员函数。常用函数如下：

函数 作用
strcpy(dest, src) 把 src 的内容复制到 dest，返回 dest
strcat(dest, src) 把 src 追加到 dest 末尾，返回 dest
strcmp(s1, s2) 比较两个字符串，相等返回 0
strlen(s) 返回字符串长度（不含结尾的 '\0'）
strchr(s, ch) 返回指向 ch 在 s 中首次出现位置的指针
strstr(s1, s2) 返回指向 s2 在 s1 中首次出现位置的指针

从标准输入读取一行，应使用 cin.getline(buffer, length)，它还可以接受第三个参数指定结束符，默认是换行符 '\n'。相比之下，cin >> buffer 有两个明显局限：它以任意空白符（空格、制表符、换行）为分隔，只能读入单个词而不能读入完整句子；同时无法限制缓冲区容量，输入过长时会越界。因此读取字符串时应优先使用 cin.getline。

若字符串里保存的是数字，可以用 cstdlib（即 stdlib.h）提供的函数转换：

函数 作用
atoi(s) 把字符串转换为 int
atol(s) 把字符串转换为 long
atof(s) 把字符串转换为 float 
cpp
#include <iostream>
#include <cstring>   // strcpy、strlen
#include <cstdlib>   // atoi、atof
using namespace std;

int main() {
    char name[20] = "Hello";        // 双引号形式自动追加 '\0'
    strcpy(name, "J. Soulie");      // 用 strcpy 给字符数组赋值
    cout << name << "，长度 " << strlen(name) << endl;

    char buffer[100];
    cout << "请输入一句话：";
    cin.getline(buffer, 100);       // 读取一整行，可含空格
    cout << "读到：" << buffer << endl;

    char number[] = "1977";
    cout << atoi(number) + 1 << endl;  // 字符串转 int 后参与运算
    return 0;
}

注意：素材指出 char* 与 char[] 在函数参数语境下等价，使用 strcpy 等函数需要包含 <cstring> 头文件。

7.6 std::string 常用操作 #

C 风格字符串要求我们自行管理缓冲区大小与结尾的 '\0'，容易出错。标准库（standard library）提供的 std::string 把内存与长度管理封装起来，可以用 = 赋值、== 比较、+ 串联，用起来接近基本数据类型。使用之前要包含头文件 <string>（注意不是 C 的 string.h）。

std::string s; 调用默认构造函数，得到空字符串；此外还有拷贝构造、用 C 字符串构造、用 n 个相同字符构造等多种形式。常用成员函数可归为以下几类：

类别 常用成员函数
赋值与清空 =、assign()、clear()、erase()
尾部追加 +=、append()、push_back()（仅单个字符）
插入、删除、替换 insert()、erase()、replace()
串联 +
比较 ==、!=、<、<=、>、>=、compare()
大小与容量 size()、length()（二者等效）、empty()、max_size()、capacity()、reserve()
元素存取 []、at()
子串 substr()
查找 find()、rfind()、find_first_of()、find_last_of()、find_first_not_of()、find_last_not_of()
输入输出 >>、<<、getline()
与 C 字符串转换 c_str()、data()、copy()
迭代器 begin()、end()、rbegin()、rend()
交换 swap()

几个值得强调的细节：

  • size() 与 length() 完全等效，empty() 判断是否为空。max_size() 是对象最多能容纳的字符数，容量不足时会抛出 length_error 异常；capacity() 是重新分配内存前可容纳的字符数，reserve() 用于预先保留容量。
  • [] 不检查下标是否合法，越界访问属于未定义行为；at() 会做范围检查，越界时抛出 out_of_range 异常。素材特别指出，const std::string 的 [] 在下标等于 length() 时仍有效，返回 '\0'，其余对象的该下标均无效。
  • compare() 返回 0 表示相等，大于 0 表示当前串较大，小于 0 表示当前串较小；它还支持用索引和长度指定子串参与比较。比较运算符按字典顺序从前向后逐字符比较。
  • 查找类函数返回匹配位置，找不到时返回 string::npos；string::npos 的类型是 string::size_type，因此比较索引时应使用该类型，或直接把查找结果与 string::npos 比较。
  • substr(pos, n) 返回从 pos 开始的 n 个字符；c_str() 返回以 '\0' 结尾的 C 字符串，便于传给要求 const char* 的旧接口。getline() 从输入流读取一行，直到换行符或文件尾。
  • std::string 还提供 begin()、end()、rbegin()、rend() 等迭代器，用于类似 STL 容器的遍历；容器与迭代器的完整介绍见 参见 第20章「标准库与 STL 速览」。

注意：素材（写于较早标准时期）称 data() 返回不以 '\0' 结尾的字符数组、std::string 本身不以 '\0' 结尾；涉及与 C 接口交互时，以 c_str() 返回的以 '\0' 结尾的结果为准，并优先使用 std::string。

7.7 字符串分割 #

标准库没有直接的「分割」函数，但用 find() 定位分隔符、substr() 取出片段即可实现。find(str, pos) 从 pos 开始查找子串首次出现的位置，找不到返回 string::npos；substr(pos, n) 返回从 pos 起最多 n 个字符的子串。素材还提到 C 库的 strtok(char *str, const char *delim)，它把字符串分解为一组片段，没有更多片段时返回 NULL，但线程不安全，可用 strtok_r 替代；以及基于 Boost 的 boost::split 与 boost::sregex_token_iterator 方案。下面的实现只依赖 std::string 与 std::vector：

cpp
#include <iostream>
#include <string>
#include <vector>
using namespace std;

// 用 find 与 substr 按 pattern 分割字符串
std::vector<std::string> split(const std::string& str, const std::string& pattern) {
    std::vector<std::string> result;
    std::string::size_type start = 0;
    std::string::size_type pos;
    while ((pos = str.find(pattern, start)) != std::string::npos) {
        result.push_back(str.substr(start, pos - start));
        start = pos + pattern.size();
    }
    result.push_back(str.substr(start));
    return result;
}

int main() {
    std::string s = "Hello";
    s += ", World";                                  // += 在尾部追加
    cout << s << "，长度 " << s.size() << endl;
    cout << "首字符：" << s.at(0) << endl;           // at() 带范围检查
    cout << "子串：" << s.substr(7, 5) << endl;
    cout << "World 位置：" << s.find("World") << endl;
    if (s.find("C++") == std::string::npos) {
        cout << "未找到 C++" << endl;
    }

    std::vector<std::string> parts = split("sss/ddd/ggg/hh", "/");
    for (std::vector<std::string>::size_type i = 0; i < parts.size(); ++i) {
        cout << parts[i] << endl;
    }
    return 0;
}

7.8 小结 #

  • 数组在内存中连续存放同类型元素，声明时长度必须是常量；索引从 0 开始，最后一个索引是长度减 1。
  • 局部数组默认不初始化，全局数组默认清零；可用花括号初始化并省略长度，让编译器推断元素个数。
  • C++ 不检查数组下标范围，越界访问不报编译错误却会带来运行时问题，须自行保证索引合法。
  • 多维数组是「数组的数组」，本质仍是一维连续存储；作函数参数时只有第一维可省略。数组传参传的是地址，通常要另传长度。
  • C 风格字符串是以 '\0' 结尾的字符数组，靠 cstring 的函数操作；读入整行用 cin.getline，内容转数值用 atoi/atol/atof。
  • std::string 封装了内存与长度管理，支持 =、==、+ 以及丰富的成员函数；at() 带范围检查，查找失败返回 string::npos。
  • 字符串分割可由 find() 与 substr() 组合实现，结果存入 std::vector<std::string>。

7.9 常见错误与陷阱 #

  • 把 billy[5] 当作长度为 5 数组的第 5 个元素：它的合法下标只有 0～4，billy[5] 已经越界。
  • 混淆声明时的 []（长度）与访问时的 []（索引），或把下标写成从 1 开始。
  • 在数组声明完成后用 mystring = "Hello"; 之类整体赋值，这是非法写法；初始化之后只能逐元素赋值或调用函数。
  • 用 cin >> buffer 读取含空格的句子且不限定缓冲区容量，导致只读到第一个词或缓冲区越界。
  • 忘记 '\0' 占用的一个元素："Hello" 需要 6 个 char，声明 char greeting[5] 无法容纳。
  • 依赖 [] 访问 std::string 却不检查下标，越界即未定义行为；需要检查时改用 at()。
  • 把 string::npos 与 int 类型索引直接比较，或使用 find() 返回值前不判是否为 npos。
  • 保存 s[2] 的引用或 &s[3] 的指针后继续修改字符串：一旦发生内存重新分配，这些引用和指针立即失效。

第8章 指针 #

本章目标：掌握地址与解引用、指针与数组的关系、指针运算与 const 指针，理解 void*、指向指针的指针、函数指针以及复杂声明的解析办法，并能识别常见的指针误用。

8.1 引子：为什么需要这一章 #

参见 第7章「数组与字符串」 留了一个问题：为什么越界访问 billy[5] 在语法上竟然合法。答案就在本章。程序看到的内存是一串连续的单字节单元，每个单元有唯一地址，就像街道上顺序编号的门牌：说「1776 号」，就知道它位于 1775 与 1777 之间。变量是有名称的内存单元，而指针（pointer）是专门保存地址的变量。理解指针之后，数组下标、函数传参以及 参见 第10章「动态内存管理」 的 new 运算才真正说得通；素材也指出，动态内存分配这类任务没有指针无法完成。引用（reference）是与指针相近但不同的机制，见 参见 第9章「引用」。

8.2 地址与解引用 #

C++ 提供两个与地址有关的一元运算符：

运算符 名称 读法 作用
& 地址运算符（address-of） 「…的地址」 &variable 返回该变量的地址
* 引用运算符 / 间接运算符（dereference） 「…指向的数值」 *p 返回 p 所保存地址中的数值

设 andy = 25; 且 andy 位于地址 1776，再写 ted = &andy;，则 ted 是一个指针，beth = *ted; 会得到 25。此时下列等式同时成立：

表达式 含义 值
andy 变量内容 25
&andy andy 的地址 1776
ted 指针自身保存的值（地址） 1776
*ted ted 所指地址中的数值 25

注意：ted（1776）与 *ted（25）是不同的东西，带不带星号含义完全不同。只要 ted 所指地址里的内容不变，*ted == andy 也成立。

声明指针写作 type *pointer_name;，其中 type 是指针所指向的数据的类型，不是指针自身的类型。int *number;、char *character;、float *greatnumber; 三个指针本身占用同样大小的内存（具体大小取决于平台，32 位程序中为 4 字节），但所指数据的类型不同，各占不同大小的空间。声明中的 * 只表示「这里声明的是一个指针」，与上面的解引用 * 是同一符号的两种不同用途，不要混淆。

指针可以在声明时直接初始化：int *tommy = &number; 等价于先声明 int *tommy;、再赋值 tommy = &number;。给指针赋值时赋的必须是地址，而不是所指对象的值；*tommy = &number; 这种写法没有意义。

cpp
#include <iostream>
using namespace std;

int main() {
    int value1 = 5, value2 = 15;
    int* p1 = &value1;     // 声明并初始化，等价于先声明再赋地址
    int* p2 = &value2;
    *p1 = 10;              // 通过指针间接修改 value1
    *p2 = *p1;             // 把 p1 指向的数值赋给 p2 指向的对象
    p1 = p2;               // 复制的是指针的值（地址）
    *p1 = 20;              // 此后 p1 与 p2 指向同一对象，改的是 value2
    cout << "value1=" << value1 << " value2=" << value2 << endl;
    return 0;
}

注意：int *p1, *p2; 中每个变量名前都要写星号。星号与类型声明的优先级相同、向右结合，只修饰紧随其后的那个名字；若写成 int* p1, p2;，则 p2 是普通 int 而不是指针。

8.3 指针的类型与复杂声明 #

素材把指针分解为四个要点：指针的类型、指针所指向的类型、指针的值（即所指向内存区的首地址）、指针本身占据的内存区。判读办法很简单：把声明语句里的指针名字去掉，剩下的就是指针的类型；把名字连同它左边的 * 一起去掉，剩下的就是指针所指向的类型。sizeof(指针名) 测的是指针自身类型的大小，而不是所指类型的大小；在 32 位程序里 sizeof(ptr) 为 4，而 sizeof(int[10]) 为 40。

解析复杂声明可用「右左法则」：从标识符出发，[] 与 () 的优先级高于 *，先向右结合、再向左结合，括号用来改变结合顺序。常见声明如下：

声明 含义
int p; 普通整型变量
int *p; 指向 int 的指针
int p[3]; 由 3 个 int 组成的数组
int *p[3]; 由 3 个「指向 int 的指针」组成的数组（[] 优先级高于 *）
int (*p)[3]; 指向「由 3 个 int 组成的数组」的指针
int **p; 指向指针的指针
int p(int); 有一个 int 形参、返回 int 的函数
int (*p)(int); 指向「有一个 int 形参并返回 int 的函数」的指针
int (*a[10])(int); 有 10 个元素的数组，元素是指向「有一个 int 形参并返回 int 的函数」的指针

注意：素材给出两个非法声明：int func(void)[5];（函数不能返回数组）与 int func[5](void);（数组元素不能是函数，因为各元素占用空间必须相同）。过于复杂的声明应使用 typedef 逐层分解，例如 typedef int (*PARA)[5]; 搭配 typedef PARA (*func)(int *);，可读性远胜挤成一行的写法。

8.4 指针与数组 #

数组名相当于第一个元素的地址，它本身是一个指针常量（constant pointer）。因此 int numbers[20]; int *p; p = numbers; 合法，而 numbers = p; 或 numbers++ 非法——常量的值不能再被赋予。p 是普通指针变量，可以重新指向别处。

中括号 [] 也叫位移（offset）运算符，a[5] = 0; 与 *(a+5) = 0; 完全等价；这正是 参见 第7章「数组与字符串」 中越界下标不会报编译错误的原因：编译器只是把下标换算成地址偏移，并不检查范围。

数组名有两重含义：声明 TYPE array[n] 后，array 既代表整个数组（类型为 TYPE[n]），又可作为常量指针（类型 TYPE*）指向第 0 号单元。于是 sizeof(array) 测出整个数组的大小，*array 得到第 0 号单元，sizeof(*array) 测单元大小，而 array + n 的结果是指向第 n 号单元的指针，sizeof(array+n) 测的是指针大小。若需要「指向整个数组」的指针，应写 int (*ptr)[10]; ptr = &array;，此时 ptr 的类型是 int(*)[10]，所指类型是 int[10]。

char *terry = "hello"; 这类定义会在内存中预留字符串常量的空间，并把首字符的地址交给 terry——terry 保存的是地址，不是 'h' 也不是整个字符串；terry[4] = '!'; 与 *(terry+4) = '!'; 等价。

注意：知秋一叶系列的示例写成 char *terry = "hello"; 并改写 terry[4]；另一素材 C_C++指针指针应用详解.md 明确指出字符串常量「内容不可改变，且只能是右值」。为避免改写字符串常量，演示下标与指针等价时应改用字符数组 char word[] = "hello";。

数组单元在内存中连续存放、单元之间没有空隙；结构（struct）成员之间则可能因对齐加入填充字节，因此 int *pstr = (int*)&ss; *(pstr+1) 未必落在成员 b 上，访问结构成员应使用 ptr->a（指向运算符）或等价的 (*ptr).a。结构对齐详见 参见 第11章「自定义数据类型」。

把数组名传给以指针为形参的函数时，传的是地址值：实参 str 与形参 s 各占各的存储空间，函数体内对 s 做 s++ 并不会改变 str。

8.5 指针运算 #

对指针只有加法和减法有意义，且以「所指类型的大小」为单位，而不是以字节为单位。素材以 32 位程序为例（char 占 1 字节、short 占 2 字节、long 占 4 字节）：

指针声明 起始地址 +1 后地址 实际增加的字节数
char *mychar; 1000 1001 sizeof(char) = 1
short *myshort; 2000 2002 sizeof(short) = 2
long *mylong; 3000 3004 sizeof(long) = 4

mychar++ 与 mychar = mychar + 1 效果相同：加 1 的含义是「指向下一个同类型元素」，因此加上的是该类型长度的字节数。两个指针不能相加，结果没有意义；类型相同的两个指针可以相减，多用于数组。

注意：递增 ++、递减 -- 的优先级高于解引用 *。*p++ 等价于 *(p++)，递增的是指针保存的地址而不是所指的数值；*p++ = *q++; 等价于先 *p = *q;，再 p++; q++;。建议一律加括号消除歧义，例如 (*p)++ 才是让所指数值加 1。

cpp
#include <iostream>
using namespace std;

int main() {
    int numbers[5] = {0};
    int* p = numbers;        // 数组名即首元素地址
    *p = 10;                 // numbers[0]
    p++;
    *p = 20;                 // numbers[1]
    p = &numbers[2];
    *p = 30;
    p = numbers + 3;
    *p = 40;
    *(p + 1) = 50;           // 等价于 numbers[4] = 50
    for (int n = 0; n < 5; ++n) {
        cout << numbers[n] << " ";
    }
    cout << endl;            // 输出：10 20 30 40 50
    return 0;
}

8.6 const 指针、void* 与空指针 #

const 与指针组合时涉及两个对象——指针本身与它所指的目标变量，因此有三种形式（取自 从C快速过渡到C++.md 的小结表）：

名称 定义格式 指针本身可重新赋值 所指内容可改写
指向常量的指针 const 类型 *p; 或 类型 const *p; 可以 不可以
常量指针 类型 *const p = 地址;（定义时必须初始化） 不可以 可以
指向常量的常量指针 const 类型 *const p = 地址; 不可以 不可以

举例：const char* pc 中 *pc 只读、pc 可以重新指向别的字符串；char* const pc 必须在定义时初始化，pc 不可再赋值而 *pc 可写；const char* const cpc 两者都不可变。变量地址、数组名、结构数组名、对象数组名、函数名等都属于常量指针的范畴。

指针变量必须先赋地址值（「定向」）才能参与运算，否则 *px = 12.6; 这类对未定向指针的写入可能造成系统故障。

void* 是特殊指针，可以指向任意类型的数据（整数、浮点数、字符串），但所指对象类型不确定、长度不定，因此不能直接解引用，也不能直接往里赋值；在赋值或转换成其他类型指针时必须使用强制类型转换，如 *(float*)r = 3.45;、pi = (int*)r;。sizeof 运算符返回其参数的长度字节数常量，例如 sizeof(char) 为 1，可据此在通用函数里判断类型。

空指针（NULL pointer）是值为 0 的指针，标准库中定义了值为零的常量 NULL；它并不是「指针的存储空间为空」，而是具有特定值 0，素材建议程序中尽量避免使用空指针。指针支持的四种算术运算是 ++、--、+、-；此外 C++ 还支持空指针、指针与数组、指针数组、指向指针的指针、把指针传给函数以及从函数返回指针等用法。

8.7 指向指针的指针与函数指针 #

C++ 允许指针指向另一个指针，每多一层引用就多写一个星号。对 char a = 'z'; char *b = &a; char **c = &b; 而言：c 是 char** 类型，其值是 b 的地址；*c 是 char* 类型，其值是 a 的地址；**c 是 char 类型，其值为 'z'。素材用具体地址说明：c 的值 8092、*c 的值 7230、**c 的值 'z'。

函数指针（pointer to function）的声明像函数原型，但函数名要括起来并在前面加 *：int (*minus)(int, int) = subtraction; 定义了指针 minus 并令其指向 subtraction；括号里的 int, int 只是形式参数的类型声明，不是实参。函数指针最大的作用是把一个函数作为参数传给另一个函数，例如 int operation(int x, int y, int (*functocall)(int, int)) 内部用 (*functocall)(x, y) 调用；也可写 int (*pfun1)(char*, int); pfun1 = fun1; int a = (*pfun1)("abcdefg", 7);。

cpp
#include <iostream>
using namespace std;

// void* 形参可接收任意类型的地址，使用前须强制类型转换
void increase(void* data, int type) {
    switch (type) {
        case sizeof(char):  (*((char*)data))++;  break;
        case sizeof(short): (*((short*)data))++; break;
        case sizeof(long):  (*((long*)data))++;  break;
    }
}

int addition(int a, int b)    { return a + b; }
int subtraction(int a, int b) { return a - b; }

// 函数指针作为形参：调用方传入哪个函数，就执行哪个运算
int operation(int x, int y, int (*functocall)(int, int)) {
    return (*functocall)(x, y);
}

int main() {
    char  a = 5;
    short b = 9;
    long  c = 12;
    increase(&a, sizeof(a));
    increase(&b, sizeof(b));
    increase(&c, sizeof(c));
    cout << (int)a << ", " << b << ", " << c << endl;  // 6, 10, 13

    int (*minus)(int, int) = subtraction;
    cout << operation(7, 5, addition) << endl;          // 12
    cout << operation(20, 12, minus) << endl;           // 8
    return 0;
}

8.8 指针的转换与安全 #

强制类型转换 (TYPE *)p 产生一个新指针：其类型为 TYPE*、所指类型为 TYPE、地址与原指针相同，而原指针 p 的一切属性都不变。函数实参形参结合时类型必须一致，否则需要显式转换。素材给出一条安全判据：在 ptr1 = (TYPE *)ptr2 中，若 sizeof(ptr2 的类型) 大于 sizeof(ptr1 的类型)，用 ptr1 访问 ptr2 所指存储区是安全的；若小于则不安全。

char s = 'a'; int *ptr = (int*)&s; *ptr = 1298; 就是反例：s 只占 1 字节，int 占 4 字节，写入不仅改了 s 的那个字节，还改写了相邻高地址方向的三个字节，而这些字节可能存放重要数据甚至代码，足以造成崩溃性错误。类似地，对指针 ptr++ 后写入未知区域也是严重错误。使用指针时必须始终清楚「我的指针究竟指向了哪里」，并避免越过数组的低端与高端界限。

8.9 小结 #

  • 内存是一串连续的单字节单元，每个单元有唯一地址；指针是保存地址的变量。& 取地址，* 取「所指向的数值」，二者互为逆运算。
  • 声明 type *p; 中的 type 是指针所指数据的类型；int *p1, *p2; 中每个名字都要单独加星号。
  • 数组名是首元素地址、是指针常量，可赋给指针却不可被重新赋值；a[5] 与 *(a+5) 等价，这正是下标越界不会被编译器发现的原因。
  • 指针加减以所指类型大小为单位；++、-- 优先级高于 *，用括号消除歧义。
  • const 与指针组合有「指向常量的指针」「常量指针」「指向常量的常量指针」三种形式，分别限制所指内容、指针本身或两者。
  • void* 可指向任意类型但不能直接解引用，使用前必须强制类型转换；空指针是值为 0 的指针。
  • char** 是指向指针的指针；函数指针用 int (*p)(int, int); 声明，可把函数作为参数传递。
  • 复杂声明按「右左法则」从标识符出发解析，[]、() 优先级高于 *；过长的声明用 typedef 分解。

8.10 常见错误与陷阱 #

  • 使用未定向（未赋地址）的指针就解引用或写入，可能造成系统故障；指针必须先赋值再参与运算。
  • 混淆 ted 与 *ted：前者是地址，后者是该地址中的数值；也混淆声明中的 * 与解引用 *。
  • 写成 int* p1, p2; 却以为声明了两个指针，实际 p2 是普通 int。
  • 给数组名赋值或自增，如 numbers = p;、numbers++；数组名是指针常量，不可改变。
  • 把 *p++ 当作「让所指数值加 1」，实际递增的是地址；需要改写数值时应写 (*p)++。
  • 对两个指针做加法，或对类型不同的指针做减法，结果没有意义或非法。
  • 直接解引用 void*、或往类型不确定的存储单元赋值，忘记先做强制类型转换。
  • 把窄类型地址强转成宽类型指针后写入，如 (int*)&charVar，改写了相邻字节，导致难以定位的崩溃。
  • ptr++ 之后写入未知内存区域，或访问数组时越过低端与高端界限。
  • 认为「空指针的存储空间为空」：它只是值为 0 的指针，解引用同样危险。
  • 用 *(pstr+1) 之类的指针运算访问结构成员：成员之间可能存在对齐填充字节，应使用 ptr->member。

第9章 引用 #

本章目标：掌握引用的定义与初始化、引用参数与引用返回值、const 引用，并厘清引用与指针的区别。

9.1 引子：为什么需要这一章 #

参见 第6章「函数」 介绍过，参数默认按值传递：形参是实参的副本，函数内修改形参不会影响调用方。若希望函数真正改动实参，C 语言的做法是传指针，但调用点要写取地址、函数体内要反复解引用，既啰嗦又易错。C++ 为此引入引用（reference）——给已有变量起一个别名。引用在语法上像值传递一样简洁，在效果上却与地址传递等价。本章把引用单独讲透，并与 参见 第8章「指针」 对照，后面 参见 第12章「类与对象」 的拷贝构造函数与 参见 第15章「运算符重载」 也会频繁用到它。

9.2 引用的定义与初始化 #

声明引用的形式为 类型标识符 &引用名 = 目标变量名;，例如 int a; int &ra = a;。此处 & 不是取地址运算符，只起标识作用；int i = 17; int& r = i; 可读作「r 是一个初始化为 i 的整型引用」。以下几点是素材一致强调的硬性规则：

  • 声明引用时必须同时初始化，不能先定义后赋值；Point &pt3; pt3 = pt1; 是非法写法（用作函数参数或返回值时由调用方完成初始化）。
  • 引用一旦初始化完成，就不能再改绑为其他变量的别名；此后对引用的任何赋值都会直接改写其绑定对象的值。
  • 对引用求地址就是对目标变量求地址，&ra == &a 成立；ra = 1; 与 a = 1; 完全等价。
