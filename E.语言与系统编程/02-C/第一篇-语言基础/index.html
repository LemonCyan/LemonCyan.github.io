编译与运行（g++ 常用命令） #

C++ 是编译型语言：源代码（通常以 .cpp 为扩展名）需要先经过编译、链接，生成可执行文件后才能运行。以 GNU 编译器 g++ 为例，最常用的命令为：

cpp
// 本章示例以命令行方式编译，此处用注释块示意命令；代码块本身不参与编译。
// g++ hello.cpp -o hello        编译 hello.cpp，生成可执行文件 hello
// ./hello                        运行该可执行文件
// g++ -Wall main.cpp support.cpp -o write   同时编译多个源文件并链接

说明：g++ 后的 -o 用于指定输出文件名；省略 -o 时默认生成 a.out（Windows 下为 a.exe）。C++ 存储类.md 给出了多文件编译的完整例子 g++ main.cpp support.cpp -o write 与 ./write，可作为「一次编译多个源文件」的参照。本书正文示例多为单个 .cpp 文件，读者把代码保存为 hello.cpp 后执行第一条命令即可。若编译器给出 #include 或命名空间相关报错，请回头检查本章「第一个程序」一节列出的结构清单。

术语与代码约定 #

  • 全教程统一使用「运算符」而非「操作符」，统一使用「命名空间」而非「名空间」；描述成员函数时写「成员函数」，不单用「方法」。
  • 首次出现的术语附英文原词，例如 引用 reference、指针 pointer、命名空间 namespace、标准库 standard library、STL、容器、迭代器、头文件、预处理指令、未定义行为、栈展开、右值引用、移动语义、智能指针、lambda 表达式等；std::string / std::vector 首次出现写全名。
  • 代码块一律用 cpp 开始、 结束，采用 4 空格缩进，#include <iostream> 用尖括号且单独成行，using namespace std; 单独成行，注释用中文。
  • 素材中剪藏残留的硬换行、水印、转载信息、时间戳、孤立数字、破损的 HTML 实体与把作用域符号写坏之类的 OCR 错误均已清洗并统一订正为 ::；需要罗列的清单（优先级、打开模式、函数清单等）一律改用 Markdown 表格。

第1章 从 C 到 C++：概述、第一个程序与编译运行 #

本章目标：理解 C++ 与 C 的关系、程序结构与编译流程，能独立编译运行 Hello World。

1.1 引子：为什么需要这一章 #

学习一门语言，最省力的起点是写出一个能跑起来的最小程序，再回头弄清它每一行的作用。C++ 脱胎于 C 语言，又增加了面向对象、命名空间、异常处理、引用、new/delete 等机制；先把「C++ 程序长什么样、怎么变成可执行文件」这件事弄清楚，后面各章的语法才有落点。本章不堆砌语言特性，只建立一条主线：源文件 → 预处理 → 编译 → 链接 → 运行。

1.2 C++ 与 C 的关系 #

据 0.C++与C 的区别 - 知秋一叶 - CSDN博客.md 与 C++学习.md：1980 年 Bjarne Stroustrup 博士在 C 语言基础上着手创建一种支持面向对象程序设计特色的语言，即 C++；1985 年起逐步流行，ANSI 与 ISO 联合委员会于 1989 年着手制定标准，1998 年正式推出 C++ 国际标准。C++ 常被称为 C 的超集，但两者仍有差别，不能简单认为「C 程序一定能被 C++ 编译器编译」。

素材中明确列出的差别如下：

方面 C C++
关键字 集合较小 增加了 bool、namespace、class、template、new、delete、try/catch/throw 等关键字；这些词在 C 中可作标识符
函数原型 可省略；无参函数可不写 void 不可省略；无参用空参数列表
内存管理 malloc / free 新增 new / delete 运算符，参见 第10章「动态内存管理」
字符串 字符数组与 C 函数库 标准 std::string 类，参见 第7章「数组与字符串」
输入输出 scanf / printf 与 stdio iostream 类库与 cin / cout，参见 第4章「基本输入输出」
出错处理 setjmp() / longjmp() try / catch / throw，参见 第17章「异常处理」
变量定义位置 须在函数开头 可在使用前任意位置定义
注释 /* … */ 新增行注释 //，并保留块注释

C++学习.md 还概括了 C++ 完全支持面向对象程序设计，主要包括类、对象、动态绑定、虚函数和消息传递，其四大特征为封装、抽象、继承、多态；并把 C++ 的组成分为「核心语言（变量、数据类型、常量等构件块）」与「C++ 标准库（操作文件、字符串等的大量函数）」两部分。这些内容将分别在 第12章、第13章、第14章 与 第20章 展开。

注意：C++ primer.md 是古典笔记式速记，本篇仅作背景速览；其函数指针、成员函数与编译细节由 第六篇 附录G 与后续各章分别重组，不在本章逐条核对。素材中关于「C 是 C++ 子集」的表述是通俗说法，上文表格已按素材列出的差别作了限定。

1.3 第一个程序：逐行拆解 #

1. C++程序结构 - 知秋一叶 - CSDN博客.md 给出的 Hello World 程序是多数初学者的第一个程序，其运行结果是在屏幕上输出 Hello World!。按素材中的结构说明，把清洗后的程序写成：

cpp
// my first program in C++
#include <iostream>
using namespace std;

int main() {
    cout << "Hello World!" << endl;
    return 0;
}

各组成部分的作用如下：

  • // my first program in C++：注释行。所有以 // 开始的程序行都被认为是注释，用来对源代码作解释，不影响程序运行。C++ 同时保留 /* … */ 块注释，可跨多行。素材特别指出 // 注释「不能换行」。
  • #include <iostream>：以 # 开始的预处理指令，不是可执行代码，只是对编译器的指示，告诉预处理器把输入输出流标准头文件 iostream 包含进本程序。素材中的 ## include < iostream.h >、#include 与 iostream.h 均为剪藏/OCR 残留，本教程统一写成 #include <iostream>；该行必须单独成行，末尾不需要分号。
  • using namespace std;：C++ 标准函数库的所有元素都声明在 std 命名空间（namespace）中，这条语句表示本程序使用标准命名空间中定义的元素。素材原文称「名空间」，按术语约定统一为「命名空间」。其单独成行。
  • int main()：主函数（main function）的起始声明，是所有 C++ 程序运行的起始点。不论 main 写在代码开头、结尾还是中间，其中的代码总是在程序开始运行时第一个被执行；所有 C++ 程序都必须有一个 main 函数。main 后的一对圆括号表示它是一个函数，括号内可放输入参数。
  • cout << "Hello World!" << endl;：cout 是标准输出流（通常为屏幕），<< 是插入运算符，把字符串插入输出流；endl 表示换行。该语句以分号结尾——分号标示语句结束，忘记写分号是初学者最常犯的错误之一。注意 cout << "Hello"; 与 cout << Hello; 不同：前者打印字符串，后者打印变量 Hello 的内容。
  • return 0;：返回语句使 main 结束，并把 0 返回；这是程序未出现错误时最常见的结束方式。

C++ 基本语法.md 补充：C++ 程序可以定义为对象的集合，这些对象通过调用彼此的成员函数进行交互——这是后续面向对象篇章的视角，本章只需知道「程序由语句组成、语句以分号分隔」即可。

1.4 语句、注释与书写自由 #

素材强调：C++ 以分号 ; 分隔语句，分行写代码只是为了方便人阅读。例如下面两段程序完全等价：

cpp
int main() {
    cout << " Hello World ";
    return 0;
}

cpp
int main() { cout << " Hello World "; return 0; }

多行 cout 调用也一样：cout << "Hello World! "; cout << "I'm a C++ program"; 与写在一行效果相同。但预处理指令（以 # 开头的行）不是真正的语句，必须各自单独成行。初学阶段建议每条语句独占一行并保留花括号，这能让结构更清晰。

素材还给出带更多注释的第二个程序，清洗后为：

cpp
/* my second program in C++
   with more comments */
#include <iostream>
using namespace std;

int main() {
    cout << "Hello World! ";         // 输出第一句
    cout << "I'm a C++ program";     // 输出第二句
    return 0;
}

其输出为 Hello World! I'm a C++ program。

1.5 从源码到可执行文件 #

C++ 基本语法.md 中的实例，以及 C++ 存储类.md 给出的 g++ main.cpp support.cpp -o write 与 ./write，说明一个 C++ 程序通常经历「编辑源文件 → 编译 → 链接 → 运行」几步。预处理指令在编译前由预处理器处理；#include 把头文件内容并入源文件；编译器把源文件翻译成目标代码；链接器把多个目标文件与标准库合并成可执行文件。读者只需掌握「本篇开头的 g++ 常用命令」即可上手，更细的编译与链接机制见 第18章「预处理与多文件工程」。

注意：素材未给出具体编译器版本、标准选项（如 -std=）与优化选项的权威说明，本篇只写「编译并运行」这一层面的内容，不编造标准版本细节。

1.6 小结 #

  • C++ 在 C 的基础上增加了面向对象、命名空间、new/delete、iostream、异常处理等机制；C 与 C++ 虽有超集关系，但关键字、函数原型、变量定义位置等细节并不完全等价。
  • 一个最小 C++ 程序由「注释 + #include 预处理指令 + using namespace std; + main 函数 + 语句 + return 0;」组成。
  • main 是程序运行的唯一起点；语句以分号结束；预处理指令单独成行且不加分号。
  • 编译型语言的流程是：源文件经预处理、编译、链接生成可执行文件，再运行；g++ hello.cpp -o hello 与 ./hello 是最常用的两条命令。

1.7 常见错误与陷阱 #

  • 忘记在语句末尾写分号，或把 #include 写成带分号、与其它代码挤在同一行；素材明确指出预处理指令单独成行、末尾不需要分号。
  • 把 #include <iostream> 写成剪藏中的 #include、## include < iostream.h > 或 #include iostream.h，导致编译失败；本教程统一用尖括号与现代头文件名。
  • 漏写 using namespace std; 却直接使用 cout，或反过来把 std 写成「名空间」等不统一术语。
  • 混淆 cout << "Hello";（输出字符串）与 cout << Hello;（输出变量），以及误以为 cout 会自动换行——cout 不会自动加换行，须写 \n 或 endl。
  • 误以为「C 程序一定能在 C++ 编译器下通过」：素材已列出关键字、函数原型、void 参数等差别。
  • 把 main 写成 intmain、int main 缺括号，或沿用素材 OCR 残留的 return0;、intmain() 等错误写法。
  • 在注释里使用会换行的 // 长说明，或把 /* … */ 块注释嵌套使用。

第2章 变量、数据类型与常量 #

本章目标：掌握基本类型、变量声明与作用域、存储类、const、bool/枚举、类型转换与命名空间入门。

2.1 引子：为什么需要这一章 #

2.变量和数据类型 - 知秋一叶 - CSDN博客.md 用一个记忆实验引入变量：让人先记住 5，再记住 2，把第一个数加 1 得到 6，最后两数相减得到 4。计算机用变量做同样的事——把值存在内存里、按名字取用、参与运算。Hello World 只能打印固定文字，而真正有用的程序必须能存储和处理数据。本章把「数据怎么声明、怎么分类、怎么保持不变」讲清楚。

2.2 变量与标识符 #

变量（variable）可定义为「内存的一部分，用以存储一个确定的值」。每个变量需要一个标识（identifier）以便与其它变量相区别。素材给出的标识符规则：

  • 由字母、数字和下划线 _ 组成；长度没有限制，但有些编译器只取前 32 个字符。
  • 空格、标点和符号都不可以出现在标识中；必须以字母开头，也可以以下划线开头（这种标识通常保留给外部连接用），但不可以以数字开头。
  • 不可与 C++ 语言关键字或编译器特殊关键字同名。素材列出的标准保留关键字包括：asm, auto, bool, break, case, catch, char, class, const, const_cast, continue, default, delete, do, double, dynamic_cast, else, enum, explicit, extern, false, float, for, friend, goto, if, inline, int, long, mutable, namespace, new, operator, private, protected, public, register, reinterpret_cast, return, short, signed, sizeof, static, static_cast, struct, switch, template, this, throw, true, try, typedef, typeid, typename, union, unsigned, using, virtual, void, volatile, wchar_t, while。
  • 不要用运算符的替代表示作标识：and, and_eq, bitand, bitor, compl, not, not_eq, or, or_eq, xor, xor_eq。
  • C++ 大小写敏感：RESULT、result、Result 是三个不同的标识。

变量声明的语法是「数据类型 + 有效标识」，例如 int a;、float mynumber;。同一类型的多个变量可写在一行：int a, b, c; 等价于三行分别声明。

2.3 基本数据类型 #

2.变量和数据类型 - 知秋一叶 - CSDN博客.md 与 C++ 数据类型.md 指出：内存以字节（byte）为单位组织，不同类型占用的空间不同。下表按素材「多数 32 位系统的常用数据」列出基本类型；素材特别说明「字节数一列和范围一列可能根据程序编译和运行的系统不同而有所不同」。

名称 字节数 描述 范围（有符号 / 无符号）
char 1 字符或小整数，8 位 -128..127 / 0..255
short int（short） 2 短整数，16 位 -32768..32767 / 0..65535
long int（long） 4 长整数，32 位 -2147483648..2147483647 / 0..4294967295
int 4 整数 -2147483648..2147483647 / 0..4294967295
float 4 浮点数 3.4e+/-38（7 位数字）
double 8 双精度浮点数 1.7e+/-308（15 位数字）
long double 8 长双精度浮点数 1.7e+/-308（15 位数字）
bool 1 布尔值，只能为 true 或 false true / false
wchar_t 2 宽字符，为两字节长的国际字符设计 一个宽字符

补充说明（均出自素材）：整型 char, short, int, long 的长度必须递增；float, double, long double 同样按递增顺序。short 等价于 short int，long 等价于 long int。整型可用 signed 或 unsigned 修饰，缺省为 signed；unsigned short NumberOfSons; 与 signed int MyAccountBalance; 均合法，unsigned 单独写等价于 unsigned int。唯一例外是 char：它与 signed char、unsigned char 均不相同。

关于 bool：0.C++与C 的区别 指出布尔型变量有两种逻辑状态（真/假），在表达式中按真假赋予整型值 1 或 0；把整型转成布尔型时，0 为假、非 0 为真；布尔型常在运行时用作标志以改变程序流程。wchar_t 是宽度超过 8 位的字符类型，一般为 16 位，用于容纳超过 256 个字符的外文字符集；标准 iostream 类库支持宽字符，用 wout 替代 cout。

C++ 数字.md、C++ 修饰符类型.md、C++中的类型转换.md、从C快速过渡到C++.md 与 C++核心特性与类和对象.md 提供了数字、修饰符、类型转换的补充例子；涉及标准 static_cast / dynamic_cast 等命名转换的完整规则，本篇素材未系统展开，故只列出「存在这类运算符」而不过度展开。

2.4 常量：字面常量、#define 与 const #

3.常量 - 知秋一叶 - CSDN博客.md 定义：常量（constant）是一个有固定值的表达式；字面常量（literal constant）用于在源码中表达特定的值，分为整数、浮点数、字符和字符串。

类别 写法示例 要点
十进制整数 1776、-273 不需引号或特殊字符
八进制 / 十六进制整数 0113、0x4b 八进制前加 0，十六进制前加 0x；75=0113=0x4b
整数后缀 75u、75l、75ul u 无符号、l 长整型，大小写均可；默认类型为 int
浮点数 3.14159、6.02e23、1.6e-19、3.0 可含小数点与 e 指数；默认类型 double，f 为 float、L 为 long double
字符 / 字符串 'z'、"Hello world" 单引号表单个字符，双引号表字符串；x 是变量，'x' 是字符常量

转义码（escape codes）以反斜杠开头，素材列出：\n 换行、\r 回车、\t 跳跃符（tab）、\v 垂直跳跃、\b 退格、\f 换页、\a 警告、\' 单引号、\" 双引号、\? 问号、\\ 反斜杠。另外可用八进制（\23、\40）或十六进制（\x20、\x4A）ASCII 码表示字符；行尾反斜杠可让字符串跨行书写；被空白分隔的多个字符串常量会自动连接；前缀 L（如 L"This is a wide character string"）表示宽字符串。布尔型常量只有 true 与 false，类型为 bool。

定义常量有三种写法：

cpp
#include <iostream>
using namespace std;

#define PI 3.14159265
const int WIDTH = 100;

int main() {
    double r = 2.0;
    double circle = 2 * PI * r;
    const char tab = '	';
    cout << "circle = " << circle << tab << "width = " << WIDTH << endl;
    return 0;
}
  • #define identifier value：预处理指令，把程序中出现的常量名原样替换为定义的代码，故称宏常量（macro constants）。#define 不是代码语句，行末不要加分号，否则分号会被一起替换进代码。
  • const 前缀：定义有指定类型的常量，如 const int width = 100;、const char tab = '\t';。素材指出若未指定类型（如 const zip = 12440;），编译器会假设为 int。C++ primer.md 的速记进一步强调：const 修饰后变成只读变量，常量不可以修改，并且常量在定义时就要初始化，否则会报错。

2.5 作用域、存储类与命名空间入门 #

作用域是程序的一个区域。C++ 变量作用域.md 指出一般有三个地方可以定义变量：在函数或一个代码块内部（局部变量）、在函数参数定义中（形式参数）、在所有函数外部（全局变量）。19.函数I 补充：局部变量的范围局限于声明它的函数或语句块内，全局变量须在所有函数或代码块之外定义，可在代码任何位置访问；0.C++与C 的区别 指出 C++ 允许变量在程序中使用前的任何地方定义，而 C 要求集中在函数开头。

C++ 存储类.md 列出存储类说明符及其语义（放置于所修饰的类型之前）：

存储类 说明
auto C++98 中用于自动变量声明，C++11 起改为「根据初始化表达式自动推断类型」与「函数返回值占位符」；不再是存储类说明符
register 定义存储在寄存器而非 RAM 中的局部变量；只意味着「可能」存入寄存器，且不能对其用一元 &；C++11 起被弃用
static 使局部变量在程序生命周期内保持存在、在函数调用之间保值；修饰全局变量时把作用域限制在声明它的文件内；用于类数据成员时使所有对象共享一个副本
extern 提供全局变量的引用，用于在另一个文件中声明已定义的全局变量或函数
mutable 仅适用于类的对象，允许 const 成员函数修改该成员
thread_local C++11 起，变量仅可在创建它的线程上访问，每个线程各有副本；可与 static 或 extern 合并

C++ 命名空间.md 用「班上有两个同名学生，需要额外信息区分」类比命名空间（namespace）：它可作为附加信息，区分不同库中同名的函数、类、变量，本质上是定义了一个范围。定义用 namespace namespace_name { … }，访问用 name::code; 这样的 :: 形式（素材中该符号曾被 OCR 写坏，本篇一律订正为 ::）。三种常见用法见 C++核心特性与类和对象.md 与 C++ 命名空间.md：

cpp
#include <iostream>
using namespace std;

namespace first_space {
    void func() {
        cout << "Inside first_space" << endl;
    }
}

namespace second_space {
    void func() {
        cout << "Inside second_space" << endl;
    }
}

int main() {
    first_space::func();   // 用 :: 明确限定
    second_space::func();
    return 0;
}

也可用 using namespace first_space;（using 指令，后续代码可省略前缀）、using std::cout;（using 声明，只引入特定项目）。素材指出命名空间可以不连续（由分散在多个文件中的几部分组成）、可以嵌套（用 :: 访问嵌套成员），using 引入的名称遵循正常范围规则。第1章的 using namespace std; 正是 using 指令最常见的用法；深入用法见 第18章「预处理与多文件工程」。

注意：C++ 存储类.md 中出现的 auto 新语义、thread_local、mutable 属于 C++11 及以后或类相关主题；本篇只按素材列出名称与一句话说明，具体用法分别在 第21章「现代 C++」与 第12章「类与对象」展开，不在本章编造细节。C++ 基本语法.md、C++ 变量类型.md、C++ 变量作用域.md、C++ 修饰符类型.md、C++ 数字.md、C++ 数据类型.md、C++中的类型转换.md、从C快速过渡到C++.md、C++核心特性与类和对象.md 中与上述结论重复或属于后续篇章的内容，本篇不重复搬运。

2.6 小结 #

  • 变量是「内存中存储确定值的一部分」，标识符由字母、数字、下划线组成，不能以数字开头、不能与关键字同名，且大小写敏感。
  • 基本类型按「字节数递增」组织：char/short/int/long 与 float/double/long double；signed 缺省、unsigned 只表非负；bool 与 wchar_t 是 C++ 增加的类型。上表数值是多数 32 位系统的常用数据，随系统可能不同。
  • 常量分字面常量、#define 宏常量与 const 只读变量；const 常量必须定义时初始化；#define 行末不要加分号。
  • 作用域分局部、形式参数、全局三层；存储类说明符有 auto/register/static/extern/mutable/thread_local；命名空间用 namespace 定义、:: 限定、using 引入。

2.7 常见错误与陷阱 #

  • 用关键字、运算符替代表示（and、or 等）或数字开头、含空格的名字作标识符；忽略了 C++ 大小写敏感，误把 Result 与 result 当同一变量。
  • 把「字节数与范围」当成所有平台上的绝对标准：素材明确标注这些是多数 32 位系统的常用数据，会随系统不同而变化。
  • const 常量不初始化就使用，或试图修改 const 只读变量；C++ primer.md 明确指出「否则会报错」。
  • 在 #define 宏定义行末加分号，导致替换时把分号一起带入代码。
  • 混淆 x（变量）与 'x'（字符常量）、"x"（字符串），以及单引号与双引号的适用对象。
  • 把 char 与 signed char / unsigned char 当作同一类型；素材指出 char 独立存在，与二者均不相同。
  • 照搬剪藏残留：如 75 // int75u // unsigned int75l // long75ul 之类的挤行、3.14159L // long double6.02e23f // float 之类的粘连，须按表格拆开理解。
  • 把「名空间」「方法」等不统一说法写进正文；本教程统一为「命名空间」「成员函数」，作用域符号一律写成 ::，不沿用剪藏中的 OCR 错误形式。

第3章 运算符与表达式 #

本章目标：掌握运算符分类、优先级与结合性、求值顺序，能正确书写复合表达式。

3.1 引子：为什么需要这一章 #

有了变量与常量，下一步就是对它们进行操作。4.操作符 运算符 - 知秋一叶 - CSDN博客.md 指出：有些语言用 add、equals 这类关键字作运算符，而 C++ 的运算符主要由符号组成，这些符号不在字母表中却在所有键盘上都能找到，使程序更简洁、更国际化。运算符是 C++ 语言的基础，因此非常重要；但素材也提醒「不需要背下所有细节，这些细节知识仅供以后需要时参考」。本章按类别梳理，并给出必须记住的优先级与结合性规则。

3.2 赋值、算术与组合运算符 #

赋值运算符 = 把右边的值赋给左边的变量。= 左边叫 lvalue（left value），必须是变量；右边叫 rvalue（right value），可以是常量、变量、运算结果或它们的组合。赋值永远从右到左，且可以连写：a = b = c = 5; 把 5 同时赋给三个变量；a = 2 + (b = 5); 等价于先 b = 5; 再 a = 2 + b;。

4.操作符 运算符 与 C++ 重载运算符和重载函数.md 列出的运算符类别如下：

类别 运算符
赋值 =
算术 +、-、*、/、%（% 为取模，取两个整数相除的余数，如 11 % 3 得 2）
组合赋值 +=、-=、*=、/=、%=、>>=、<<=、&=、^=、`
递增 / 递减 ++、--（前缀与后缀）
关系 ==、!=、>、<、>=、<=
逻辑 !、&&、`
条件 ? :
逗号 ,
位运算 &、`
其它 sizeof、成员运算符 . 与 ->、强制转换 Cast、指针 &

组合运算符让书写简练：value += increase; 等价于 value = value + increase;；price *= units + 1; 等价于 price = price * (units + 1);。a++;、a += 1;、a = a + 1; 在功能上等同；素材说明这种简写源于早期 C 编译器生成不同机器代码，如今编译器已基本自动优化，三者运行代码基本相同。C++ 运算符.md 逐一给出 C += A 等价于 C = C + A 等组合赋值说明，与上述一致。

3.3 递增、递减与关系、逻辑、条件运算符 #

前缀与后缀的区别是本章最需要留意的点。B=3; A=++B; 中 B 先增 1 再参与表达式，结果 A=4, B=4；B=3; A=B++; 中先把 B 的原值 3 赋给 A，B 才增到 4，结果 A=3, B=4。

关系运算符比较两个表达式，素材明确「如 ANSI-C++ 标准中指出的，关系运算的结果是一个 bool 值，只能是 true 或 false」；同时补充「在 ANSI-C++ 标准出现之前的许多编译器中，像 C 语言一样返回整型 0 或非 0（通常为 1）」。! 取反，&& 为逻辑与、|| 为逻辑或，其真值表为：

| a | b | a && b | a || b | |---|---|---|---| | true | true | true | true | | true | false | false | true | | false | true | false | true | | false | false | false | false |

条件运算符 condition ? result1 : result2 在条件为真时返回 result1，否则返回 result2。例如 a=2, b=7 时 (a>b)?a:b 取 b 的值 7。逗号运算符 , 用来分开多个表达式并只取最右边的值：a = (b=3, b+2); 先令 b=3，再把 b+2 即 5 赋给 a。位运算符 & | ^ ~ << >> 逐位操作，C++ 运算符.md 给出了 p & q、p | q、p ^ q 的真值表与 c = a | b; 等例子，本篇不展开逐位计算，列在附录A 速查。

cpp
#include <iostream>
using namespace std;

int main() {
    int a = 7, b = 3;
    cout << a / b << endl;      // 整数除法，结果 2
    cout << a % b << endl;      // 取余，结果 1

    int x = 3;
    cout << ++x << " " << x << endl;   // 前缀：先增后用
    int y = 3;
    cout << y++ << " " << y << endl;   // 后缀：先用后增

    int m = 2, n = 7;
    int bigger = (m > n) ? m : n;      // 条件运算符取较大值
    cout << "bigger = " << bigger << endl;

    cout << ((5 == 5) && (3 > 6)) << endl;   // false -> 0
    cout << ((5 == 5) || (3 > 6)) << endl;   // true  -> 1
    return 0;
}

3.4 优先级与结合性 #

4.操作符 运算符 给出完整的优先级表（共 18 级），C++ 运算符.md 也给出「从高到低」的优先级说明。下表按素材整理，「结合方向」定义了同级运算符在一起时先算哪一个：

级别 运算符 说明 结合方向
1 :: 范围 从左到右
2 () [] . -> ++ --、dynamic_cast static_cast reinterpret_cast const_cast typeid 后缀 从左到右
3 ++ -- ~ ! sizeof new delete、* &（指针与取地址）、+ -（一元符号） 一元（前缀） 从右到左
4 (type) 类型转换 从右到左
5 .* ->* 指向成员的指针 从左到右
6 * / % 乘、除、取模 从左到右
7 + - 加减 从左到右
8 << >> 位移 从左到右
9 < > <= >= 关系运算符 从左到右
10 == != 等于、不等于 从左到右
11 & 按位与 从左到右
12 ^ 按位异或 从左到右
13 ` ` 按位或
14 && 逻辑与 从左到右
15 ` `
16 ?: 条件运算 从右到左
17 `= *= /= %= += -= >>= <<= &= ^= =` 赋值运算
18 , 逗号 从左到右

素材用 a = 5 + 7 % 2; 说明括号的作用：可写成 a = 5 + (7 % 2); 或 a = (5 + 7) % 2;，两者结果不同；「如果你想写一个复杂的表达式而不敢肯定各个运算的执行顺序，那么就加上括号，这样还可以使代码更易读懂」。C++ 运算符.md 也用 x = 7 + 3 * 2; 得 13 而非 20 说明「乘除优先级高于加减」。更完整的速查见 第六篇 附录A 运算符优先级与结合性速查表。

注意：C++ 重载运算符和重载函数.md 列出了「可重载 / 不可重载运算符」的清单（如逻辑 || && !、位运算、赋值运算可重载等），本篇只讲内置运算符；运算符重载规则见 第15章「运算符重载」。素材未提供「求值顺序」的严格标准细节（如函数实参求值次序），本篇只讲优先级与结合性，不对未覆盖的求值顺序作结论。

3.5 小结 #

  • 运算符主要由符号组成；赋值 = 永远把右值赋给左值，可连写；== 是判断相等，与 = 完全不同。
  • 算术 + - * / %、组合赋值 += -= *= /= %= …、++ --、关系、逻辑 ! && ||、条件 ?:、逗号 , 与位运算符构成运算符主体。
  • 前缀 ++a 先增后用，后缀 a++ 先用后增；关系运算结果为 bool，旧编译器曾返回 0/非 0 整数。
  • 优先级共 18 级，* / % 高于 + -，赋值与条件为右结合；不确定时用括号明确顺序。

3.6 常见错误与陷阱 #

  • 混淆 = 与 ==，在条件表达式里误用赋值；素材专门用 (b=2) == a 的例子提醒二者区别。
  • 两个整数相除仍得整数、小数部分被截断：7 / 3 得 2 而非 2.333…；需要浮点结果时把操作数写成 7.0。
  • 误用 % 于非整数，或忘记 % 取的是「余数」（11 % 3 得 2）。
  • 忽略前缀 / 后缀差异：把 A=++B; 与 A=B++; 当成一样，导致赋值结果相差 1。
  • 记错优先级与结合性又不用括号：5 + 7 % 2 与 (5 + 7) % 2 结果不同；赋值与条件运算符是右结合。
  • 照搬素材挤行残留：如 // 组合运算符例子#include usingnamespace std;int main (){ … }、cout<<::a<< <<<endl;，须拆成规范格式。
  • 把 && / || 与按位 & / | 混用，或误以为 cout << (5==5) && (3>6) 的优先级与关系运算无关。
  • 使用素材中未统一的「操作符」「名空间」「方法」等说法；本教程统一写「运算符」「命名空间」「成员函数」。
