3. 二叉树遍历 #

方式 顺序
前序 根 · 左 · 右
中序 左 · 根 · 右
后序 左 · 右 · 根

按数组下标建完全二叉树（根为 1 号，左孩子 2i，右孩子 2i+1）：

c
typedef struct tree {
    datatype data;
    struct tree *lchild, *rchild;
} bitree;

bitree *create_bitree(int i, int n)
{
    bitree *root = (bitree *)malloc(sizeof(bitree));
    root->data = i;                        /* 节点数据即下标 */

    if (2 * i <= n)                        /* 左孩子存在 */
        root->lchild = create_bitree(2 * i, n);
    else
        root->lchild = NULL;

    if (2 * i + 1 <= n)                    /* 右孩子存在 */
        root->rchild = create_bitree(2 * i + 1, n);
    else
        root->rchild = NULL;

    return root;
}

关键点：先 malloc 再判断孩子是否存在，且必须给不存在的孩子显式赋 NULL，否则叶子节点的指针是野值。

4. 单链表的整表创建与整表删除 #

整表创建（头插法）：先建一个空表（只有头结点）→ 循环「malloc 新结点 / 存入数据 / p->next = head->next / head->next = p」。 尾插法则是维护一个尾指针 r：r->next = p; r = p;，最后 r->next = NULL。

整表删除（ClearList）：

c
Status ClearList(LinkList *L)
{
    LinkList p, q;
    p = (*L)->next;          /* p 指向第一个结点 */
    while (p) {              /* 没到表尾 */
        q = p->next;
        free(p);
        p = q;
    }
    (*L)->next = NULL;       /* 头结点指针域为空 */
    return OK;
}

必须先存 q = p->next 再 free(p)，否则释放后无法继续遍历。

5. 约瑟夫环 #

「逢七杀」的两种解法：

数组解法——数组存「是否已出局」标志，用一个游标循环数到 7，标记出局，直到剩一人。

循环链表解法——链表存犯人编号，双重循环数到 7 就删结点，终止条件是 p->next == p（只剩 1 个幸存者）。

无头结点循环链表的构造有三种思路：

  1. 先建 1 个结点充当临时头结点，再建剩下 n-1 个，最后把头结点也接进去；
  2. 建带头结点的循环链表（n-1 个），最后让表尾指向头结点，同时给头结点赋值；
  3. 建带头结点的循环链表（n 个），最后让表尾指向头结点的下一个结点（即 1 号），头结点不参与报数。
