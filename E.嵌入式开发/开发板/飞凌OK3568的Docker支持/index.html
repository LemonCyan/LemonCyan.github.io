飞凌 OK3568 的 Docker 支持 #

为了在飞凌 OK3568 开发板上支持 Dockeraday nerdferendum 梯形，我们需要对内核配置进行修改，并安装 Docker。以下是详细的操作指南：

一、内核配置 #

首先，我们需要在内核配置文件中启用 Docker 需要的功能。打开 kernel/arch/arm64/configs/OK3568-C-linux_defconfig 文件，并在文件末尾添加以下内容：

cpp
# add docker support
CONFIG_MEMCG=y
CONFIG_VETH=y
CONFIG_BRIDGE=y
CONFIG_BRIDGE_NETFILTER=y
CONFIG_NETFILTER_XT_MATCH_ADDRTYPE=y
CONFIG_NETFILTER_XT_MATCH_CONNTRACK=y
CONFIG_NETFILTER_XT_MATCH_IPVS=y
CONFIG_NETFILTER_XT_MARK=y
CONFIG_POSIX_MQUEUE=y
CONFIG_CGROUP_BPF=y
CONFIG_NETFILTER_ADVANCED=y
CONFIG_NETFILTER_XTABLES=y
CONFIG_IP_VS=y
CONFIG_IP_PNP=y
CONFIG_IP_PNP_DHCP=y

这些配置项的作用如下：

  1. CONFIG_MEMCG: 启用内存控制组功能，用于对容器的内存使用情况进行限制和监控。
  2. CONFIG_VETH: 启用虚拟以太网功能，允许容器之间和宿主机之间进行通信。
  3. CONFIG_BRIDGE: 启用网桥功能，支持将不同的网络接口连接到同一个桥接设备，实现容器网络的通信。
  4. CONFIG_BRIDGE_NETFILTER: 启用网桥的网络过滤功能，支持在桥接网络中执行 iptables 规则。
  5. CONFIG_NETFILTER_XT_MATCH_ADDRTYPE: 启用地址类型匹配模块，用于根据数据包的地址类型进行过滤。
  6. CONFIG_NETFILTER_XT_MATCH_CONNTRACK: 启用连接跟踪匹配模块，支持基于连接状态的过滤规则。
  7. CONFIG_NETFILTER_XT_MATCH_IPVS: 启用 IP 负载均衡匹配模块，支持在容器间分发网络流量。
  8. CONFIG_NETFILTER_XT_MARK: 启用数据包标记模块，支持对数据包进行分类管理。
  9. CONFIG_POSIX_MQUEUE: 启用 POSIX 消息队列功能，支持容器间的进程通信。
  10. CONFIG_CGROUP_BPF: 启用控制组 BPF 功能，支持通过 BPF 程序对资源进行控制和监控。
  11. CONFIG_NETFILTER_ADVANCED: 启用高级网络过滤功能，支持更复杂的网络规则和过滤逻辑。
  12. CONFIG_NETFILTER_XTABLES: 启用扩展 tables 功能，支持更灵活的网络过滤和 NAT 功能。
  13. CONFIG_IP_VS: 启用 IP 虚拟服务器功能，支持负载均衡和高可用性。
  14. CONFIG_IP_PNP: 启用 IP 插入式 DHCP 功能，支持自动 IP 地址配置。
  15. CONFIG_IP_PNP_DHCP: 启用 DHCP 客户端功能，支持动态获取 IP 地址。

完成以上修改后，保存并关闭配置文件，然后重新编译内核并烧写到开发板中进行测试。

二、安装 Docker #

在内核配置完成并烧写后，我们需要在开发板上安装 Docker。以下是详细的步骤：

  1. 更新软件源：

    bash
    sudo apt-get update

  2. 安装必要的依赖包：

    bash
    sudo apt-get install apt-transport-https ca-certificates curl

  3. 添加 Docker 软件源：

    bash
    curl -fsSL http://mirrors.aliyun.com/docker-ce/linux/ubuntu/gpg | sudo apt-key add -

    这一步将添加阿里云提供的 Docker 软件源的公钥，以确保软件包的安全性。

  4. 添加 Docker 软件仓库：

    bash
    sudo add-apt-repository "deb [arch=arm64] http://mirrors.aliyun.com/docker-ce/linux/ubuntu $(lsb_release -cs) stable"

    这里使用了阿里云的 Docker 软件仓库，以加快软件包的下载速度。$(lsb_release -cs) 可以自动获取 Ubuntu 的版本代号（例如 focal）。

  5. 更新软件源索引：

    bash
    sudo apt-get update

  6. 查看可用的 Docker 软件包：

    bash
    apt-cache madison docker-ce

    这一步可以用来查看可用的 Docker 软件包的版本信息。

  7. 安装指定版本的 Docker：

    bash
    sudo apt-get -y install docker-ce=5:20.10.1~3-0~ubuntu-focal

    通过指定版本号安装特定的 Docker 版本，这里安装的版本是 20.10.1。

  8. 验证 Docker 安装：

    bash
    sudo docker image ls

    这里会列出已安装的 Docker 镜像。如果有 hello-world 镜像列出，则说明 Docker 安装成功。

注意事项 #

  • 在执行以上命令时，项注意网络连接的稳定性。若出现网络问题，可尝试更换镜像源或重新更新软件源。

  • 安装 Docker 时需要 root 权限。如果出现权限不足的问题，可以在命令前加上 sudo。

  • 如果在安装过程中遇到依赖关系错误，可以尝试使用以下命令修复：

    bash
    sudo apt-get install -f

通过以上步骤，您可以在飞凌 OK3568 开发板上成功配置 Docker 支持，并运行容器化应用程序。
