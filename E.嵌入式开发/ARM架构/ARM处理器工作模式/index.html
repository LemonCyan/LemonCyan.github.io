ARM处理器工作模式

ARM 处理器 7 种工作模式与寄存器组织架构详解 #

在嵌入式底层开发中，处理器的工作模式和寄存器排布是汇编编程、中断处理和操作系统内核编写的理论基石。

本文将系统剖析 ARM 架构下的 7 种工作模式、特权级别划分、异常切换机制，以及物理寄存器的组织架构。

一、 ARM 处理器 7 种工作模式 #

ARM 体系结构支持 7 种核心工作模式，用以应对不同的程序运行状态和异常事件：

序号 模式名称 缩写 CPSR 编码 (M[4:0]) 权限级别 说明
1 用户模式 (User) usr 0b10000 非特权 (PL0) 正常用户程序的运行状态，受保护，禁止直接改写 CPSR 或读写受限硬件。
2 系统模式 (System) sys 0b11111 特权 (PL1) 运行具有特权的操作系统任务，共享用户模式寄存器。
3 管理模式 (Supervisor) svc 0b10011 特权 (PL1) 操作系统使用的保护模式。系统上电复位、执行软中断（SWI）指令时自动切入。
4 中断模式 (IRQ) irq 0b10010 特权 (PL1) 用于处理普通硬件中断（如外部引脚中断、网卡数据到达等）。
5 快速中断模式 (FIQ) fiq 0b10001 特权 (PL1) 用于支持高速数据传输（如 DMA、高优先级计时器），具备专属寄存器备份。
6 数据中止模式 (Abort) abt 0b10111 特权 (PL1) 当发生数据或指令预取异常（如内存访问失败、MMU 缺页）时进入。
7 未定义模式 (Undefined) und 0b11011 特权 (PL1) 当 CPU 执行到无法识别的非法指令时进入，主要用于软件仿真协处理器。

二、 模式分类：特权与异常的对立统一 #

我们可以将这 7 种工作模式归结为以下两个维度的划分：

                              ARM 工作模式 (7种)
                                      |
                 +--------------------+--------------------+
                 |                                         |
          用户模式 (usr)                            特权模式 (6种)
           (非特权 PL0)                              (特权级别 PL1)
                                                           |
                                      +--------------------+--------------------+
                                      |                                         |
                               系统模式 (sys)                            异常模式 (5种)
                                (无异常进入)                         (复位、中断、中止引发)

1. 用户模式 VS 特权模式 #

  • 用户模式 (User Mode)：应用程序的“沙盒”。在此模式下，程序不能直接读写受保护的硬件寄存器，也无法通过修改 CPSR 模式位主动切换模式。
  • 特权模式 (Privileged Modes)：除用户模式外的其余 6 种模式。程序可以任意访问所有系统资源，并自由读写 CPSR 控制位切换 CPU 工作模式。

2. 系统模式 VS 异常模式 #

  • 系统模式 (System Mode)：特立独行的一个。它既不属于用户模式（它是特权模式），也不属于异常模式（它不通过任何异常触发进入，且与用户模式完全共享相同的物理寄存器）。主要供内核中的特权级任务使用。
  • 异常模式 (Exception Modes)：除系统和用户模式外的其余 5 种。当外设中断、内存访问失败或系统指令出错时，CPU 硬件会自动强行切换到对应的异常模式。

三、 模式切换的软硬件协作机制 #

当异常发生或退出时，CPU 硬件与底层软件（如内核汇编）有一套严密的交接流程。

1. 进入异常模式 (CPU 硬件自发完成) #

当异常发生，CPU 决定切入某异常模式时，硬件会自动完成以下四步：

  1. 在该异常模式专属的 LR 寄存器 (R14) 中，保存前一工作模式下即将执行的下一条指令地址。
  2. 将当前程序状态寄存器 CPSR 的值，备份到该异常模式专属的 SPSR 中。
  3. 修改 CPSR 的 M[4:0] 控制位，将工作模式切换到目标异常模式。
  4. 强行修改 PC (R15) 寄存器 的值为该异常在异常向量表中的入口地址，实现跳转。

2. 退出异常模式 (软件编写者手动完成) #

当异常处理完毕，准备返回先前状态时，必须由汇编软件显式完成以下两步：

  1. 修正 LR 寄存器的值（根据不同的异常类型减去 4 或 8），将其赋值给 PC 寄存器。
  2. 将当前异常模式下的 SPSR 还原回 CPSR 中，恢复先前的模式与中断屏蔽状态。

四、 寄存器组织架构 (Banked Registers) #

ARM 处理器总共拥有 37 个 32 位寄存器：

  • 31 个通用寄存器。
  • 6 个程序状态寄存器（1 个全局共享的 CPSR，5 个异常模式专属的 SPSR）。
  Usr/Sys     SVC       IRQ       FIQ       Abort     Undef
  +-----+   +-----+   +-----+   +-----+   +-----+   +-----+
  | R0  |   | R0  |   | R0  |   | R0  |   | R0  |   | R0  |
  | ... |   | ... |   | ... |   | ... |   | ... |   | ... |
  | R7  |   | R7  |   | R7  |   | R7  |   | R7  |   | R7  |
  +-----+   +-----+   +-----+   +-----+   +-----+   +-----+
  | R8  |   | R8  |   | R8  |   |R8_fiq|   | R8  |   | R8  |
  | ... |   | ... |   | ... |   | ... |   | ... |   | ... |
  | R12 |   | R12 |   | R12 |   |R12_fiq|  | R12 |   | R12 |
  +-----+   +-----+   +-----+   +-----+   +-----+   +-----+
  | R13 |   |R13_s|   |R13_i|   |R13_f|   |R13_a|   |R13_u|  <-- SP (栈指针)
  | R14 |   |R14_s|   |R14_i|   |R14_f|   |R14_a|   |R14_u|  <-- LR (链接寄存器)
  +-----+   +-----+   +-----+   +-----+   +-----+   +-----+
  | R15 |   | R15 |   | R15 |   | R15 |   | R15 |   | R15 |  <-- PC (程序计数器)
  +-----+   +-----+   +-----+   +-----+   +-----+   +-----+
  
  +-----+   +-----+   +-----+   +-----+   +-----+   +-----+
  | CPSR|   | CPSR|   | CPSR|   | CPSR|   | CPSR|   | CPSR|  <-- 状态寄存器
  +-----+   +-----+   +-----+   +-----+   +-----+   +-----+
            |SPSR_s|  |SPSR_i|  |SPSR_f|  |SPSR_a|  |SPSR_u| <-- 备份状态寄存器
            +------+  +------+  +------+  +------+  +------+
  • R13 (SP, Stack Pointer)：栈指针，除 Usr 和 Sys 模式共享外，其余 5 种异常模式均有专属独立的物理寄存器副本（如 SP_svc、SP_irq）。这意味着各个模式拥有各自的堆栈，互不干扰，保证了异常发生时现场的安全。
  • R14 (LR, Link Register)：链接寄存器，在执行子程序调用（BL）或发生异常跳转时备份下一条指令地址。同样，5 种异常模式各自拥有独立的 LR 副本。
  • FIQ 模式的特殊待遇（快速中断）： FIQ 模式拥有多达 7 个专属物理寄存器备份（R8_fiq ~ R14_fiq）。这使得在中断发生切入 FIQ 模式时，绝大多数程序甚至不需要执行压栈操作（STMFD）来保存通用寄存器，直接使用这组专属寄存器运算即可，从而极大地缩减了中断响应的延迟。

五、 当前程序状态寄存器 (CPSR) #

CPSR 寄存器负责维护 CPU 当前的一切核心状态：

 31 30 29 28 27       7   6   5   4      0
+--+--+--+--+--+-----+---+---+---+--------+
|N |Z |C |V |Q | ... | I | F | T | M[4:0] |
+--+--+--+--+--+-----+---+---+---+--------+
  • T 位 (Thumb Bit)：1 表示 CPU 当前运行在 16 位 Thumb 状态；0 表示处于 32 位 ARM 状态。
  • I、F 位 (Interrupt Disable Bits)：
    • I = 1：禁止普通的 IRQ 中断。
    • F = 1：禁止高优先级的 FIQ 中断。
  • M[4:0] (Mode Bits)：工作模式控制位。通过向这 5 位写入对应的二进制编码（如特权模式下），可以直接强制 CPU 切换工作模式。
