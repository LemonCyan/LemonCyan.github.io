ARM 调用栈结构

分析 ARM 架构 Linux 环境中的应用态与内核态调试方法时，了解函数调用栈的结构至关重要。ARM 架构的函数调用遵循 APCS（ARM Procedure Call Standard）规则，通过分析以下实例代码，我们可以更清晰地理解 ARM 调用栈的组织方式。

示例代码： #

c
int callfunctionA(int aa, int bb, int c, int d, int e, int f)  
{  
    int a = 0;  
    int b = 0;  
    printf("the a is %i, the b is %i\n", a, b);  
    callfunctionB();  
    return 0;  
}  

int main() {
    callfunctionA(1, 2, 3, 4, 5, 6);  
}

对应的汇编代码： #

; 函数 callfunctionA 的实现：
8480: e92d4800    push {fp, lr}     ; 保存函数调用者的堆栈指针和链接寄存器
8484: e28db004    add fp, sp, #4    ; 设置函数的栈帧
8488: e24dd018    sub sp, sp, #24    ; 分配局部变量的栈空间
848c: e50b0010    str r0, [fp, #-16] ;保存参数 aa
8490: e50b1014    str r1, [fp, #-20] ;保存参数 bb
8494: e50b2018    str r2, [fp, #-24] ;保存参数 c
8498: e50b301c    str r3, [fp, #-28] ;保存参数 d

; 初始化局部变量 a 和 b：
849c: e3a03000    mov r3, #0  
84a0: e50b3008    str r3, [fp, #-8] ; a = 0

84a4: e3a03000    mov r3, #0  
84a8: e50b300c    str r3, [fp, #-12] ; b = 0

; 调用 printf 函数：
84ac: e59f001c    ldr r0, [pc, #28]  ; 加载格式字符串的地址
84b0: e51b1008    ldr r1, [fp, #-8]  ; 加载变量 a 的值
84b4: e51b200c    ldr r2, [fp, #-12] ; 加载变量 b 的值
84b8: ebffff89    bl 82e4 <_init+0x20> ; 调用 printf 函数

; 调用 callfunctionB()：
84bc: ebffffe0    bl 8444          ; 调用 callfunctionB()

; 返回点：
84c0: e3a03000    mov r3, #0        ; 返回值 0
84c4: e1a00003    mov r0, r3  
84c8: e24bd004    sub sp, fp, #4     ; 恢复栈指针
84cc: e8bd8800    pop {fp, pc}       ; 恢复 fp 和 pc

84d0: 000085cc    word 0x000085cc    ; 格式字符串的地址

调用栈分析： #

  1. 函数调用前的准备工作：

    c
    int main() {
    callfunctionA(1, 2, 3, 4, 5, 6);  
}

    对应的汇编代码：

    8518: e3a03005    mov r3, #5        ; 第五个参数 e
851c: e58d3000    str r3, [sp]  
8520: e3a03006    mov r3, #6        ; 第六个参数 f
8524: e58d3004    str r3, [sp, #4]  
8528: e3a00001    mov r0, #1        ; 第一个参数 aa
852c: e3a01002    mov r1, #2        ; 第二个参数 bb
8530: e3a02003    mov r2, #3        ; 第三个参数 c
8534: e3a03004    mov r3, #4        ; 第四个参数 d
8538: ebffffd0    bl 8480          ; 跳转至 callfunctionA

  2. 参数传递规则：

    • ARM 架构按照 APCS 规则，前四个参数由 r0-r3 寄存器传递。
    • 超过四个的参数由调用栈传递，且栈空间必须 8 字节对齐。

  3. 调用栈的结构：

    • 参数部分：前四个参数通过寄存器传递，超出部分通过栈传递。
    • 返回地址：存储函数调用的下一条指令地址。
    • 局部变量部分：函数内部变量存储在栈中。

  4. 具体实例分析：

    • callfunctionA() 被调用时，参数 1、2 被保存在 r0 和 r1 中，参数 3、4 保存在 r2 和 r3 中。
    • 参数 5 和 6 由于超过四个，保存在调用栈中。
    • 函数内部的局部变量 a 和 b 也被保存在栈中。

通过以上分析，可以清晰地看到 ARM 调用栈的结构和工作原理。了解这些机制对于调试 ARM 架构程序尤为重要。
