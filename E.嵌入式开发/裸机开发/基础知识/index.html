typedef int (*sqlite3_callback)(void *, int, char **, char **); 当执行的语句有返回结果，就会调用这个函数

int sqlite3_exec(sqlite3 *db, const char *sql, sqlite3_callback callback, void *, char **errms g);

功能：执行SQL操作 参数： db：数据库句柄 sql：SQL语句 callback：回调函数，如果语句执行是由结果的，就会调用该函数，把结果返回给我们 errmsg：错误信息指针的地址 返回值：成功返回0，失败返回错误码 typedef int (*sqlite3_callback)(void *para, int f_num, char **f_value, char **f_name); 功能： 每找到一条记录自动执行一次回调函数 功能： para：传递给回调函数的参数 f_num：记录中包含的字段数目 结果列数 f_value：包含每个字段值的指针数组 f_name：包含每个字段名称的指针数组 列标题
返回值：成功返回0，失败返回-1
