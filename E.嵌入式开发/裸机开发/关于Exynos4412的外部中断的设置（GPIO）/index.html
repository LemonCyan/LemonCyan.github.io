关于Exynos4412的外部中断的设置（GPIO） #

外部中断源相关配置（GPIO） 1.查询相应的DevBoard和CoreBoard找到由芯片上引出的对应的引脚

2.设置该引脚的功能，使其能够产生中断，例如有Key设置GPX【】CON的某四位bit为 0xf，使该引脚为WAKEUP_INT状态。

3.为了保证外部中断的稳定性，需关闭上下拉电阻通过设置GPX【】PUD

4.然后配置相关的触发方式（电平方式，上升沿，下降沿等），通过配置相应的 EXT_INT【】_CON确定触发方式。同时配置相应的EXT_INT【】_MASK使该中断能够被 支持。（Enable interrupt支持相应的中断）

关于GIC与CPU的相关配置（Interrupt Controller） （GIC + Distributor） 1.设置ICDDCR分配使能，将Bit置为1时有: GIC monitors the peripheral interrupt signals and forwards pending interrupts to the CPU interfaces （GIC将监听中断并送 至CPU处理）

2.设置ICDISER，使能相应中断到分配器（作为SPI，其使用的CPU随意） （每个CPU有五个interface(0,1,2,3,4)，每一个interface有32bit，判断某一中断源属 于哪一类接口时，例如57号中断源其接口应为57%32 = 1......25所以其应位于CPU的第一 个接口的第25bit。 ） GPX2PUD[n] [2n + 1:2n] N = 0 to 7 RW 0x0 = Disables Pull- up/Pull-down 0x1 = Enables Pull- down 0x2 = Reserved 0x3 = Enables Pull-up

3.设置相应的IPTR，选择相应的CPU【】上的接口 （每一个CPU上又分为不同的接口（0~39），每一个接口存放四个中断号， 判断位于哪一个接口时，例如57号中断源有57%4 = 14......1，则对于该中断源有 ICDIPTR14_CPU0的第8~15bit设置该终端的CPU接 口）

(CPU Interface) 4.配置ICCICR，设置对应CPU的位为1，使得相应的使能中断能到CPU 5.配置ICCPMR，设置相应CPU的低8bit为0xFF,用以设置中断屏蔽优先级

中断的执行 1.通过ICCIAR来获得该中断的中断号（中断号存放在此Reg的低10bit上） 得到中断号以后，通过switch(IRQ_NUMBER)/case语句使得结婚收到不同的中断能够执行 不同的动作。

2.该中断的处理语句结束后，要清除对应的GPIO中断标志位和对应的GIC中断标志位。 （1）通过设置EXT_INT【】_PEND来清除相应的中断标志（interrupt occurs表示该中断 已被处理） （2）通过设置ICDIPTR来清GIC中断标志位//57%32=1...25

3.在中断选择语句之后，进行清除CPU的中断标志位的操作 通过设置ICCEOIR，将中断号写入该Reg的低10bit即可清除
