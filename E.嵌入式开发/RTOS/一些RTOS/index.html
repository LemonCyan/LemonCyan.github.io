其他 RTOS #

3.1 [DDC-i] Deos #

(https://www.ddci.com/products_deos_do_178c_arinc_653 )

Deos™ 是 DDC-I 的安全关键型时间和空间分区实时操作系统 (RTOS)，已根据航空电子应用 DO-178C/ED-12C 设计保证 A 级 (DAL A) 指南进行了验证，支持 ARINC 653 APEX，速率单调调度 (RMS)，针对未来机载能力环境 (FACE™) 安全扩展和安全基础配置文件。 Deos 是第一个获得 FACE 技术标准 3.1 版 OSS 一致性认证的 RTOS。安全扩展配置文件增加了对 TCP/IP 通信、多进程支持和扩展 POSIX 功能（80 个额外功能）的支持，是安全基础和安全配置文件所需功能的超集。

3.2 [Green Hills Software] Integrity RTOS #

( https://www.ghs.com/products/safety_critical/integrity_178_tump.html )

INTEGRITY-178 tuMP 实时操作系统 (RTOS) 是世界领先的多核 RTOS，适用于安全和安保关键型应用。 Green Hills Software 相信安全与保障是齐头并进的，INTEGRITY-178 tuMP 是多核处理器的统一解决方案。 INTEGRITY-178 和 INTEGRITY-178 tuMP 是已通过 80 多个机载系统最高级别机载安全 (DO-178B/C DAL A) 和安全 (SKKP/EAL 6+) 认证的系统的一部分。 INTEGRITY-178 tuMP 是第一个经过认证符合最新未来机载能力环境 (FACE™) 技术标准 3.0 版的操作系统，并且通过了安全基础和安全配置文件的认证。 INTEGRITY-178 tuMP 是第一个也是唯一一个成为 DO-178C 和 CAST-32A 多核认证一部分的 RTOS。

3.3 [Lynx Software] LynxOS #

( https://www.lynx.com/products/lynxos-178-do-178c-certified-posix-rtos )

LynxOS-178 是一款商用现成 (COTS) RTOS，支持 x86、Arm 和 PowerPC 平台。它基于开放标准，专为满足安全关键型实时系统中多线程和多进程应用程序的严格需求而设计，通过实时进程、应用程序和应用程序之间严格的硬件强制隔离来提供安全保障。 RTOS 内核服务和驱动程序。

3.4 [SYSGO]PikeOS #

(https://www.sysgo.com/ )

  • RTOS 以及带有分离内核硬实时操作系统的 1 类虚拟机监视器

  • 强大的时间和资源分区

  • 共享内存、图形和音频（取决于 BSP）

  • 支持 OpenGL，OpenCL

  • 符合 MILS

  • 获得 DO-178C、EN 50218、EN 50657、IEC 61508、ISO 26262、IEC 62304 安全认证

  • 获得 CC EAL 5+和 Airbus SAR 安全认证

  • 支持多核处理器

  • 部分 BSP 的硬件虚拟化、图形和音频共享

  • 可认证的 CIP 和 CFS

  • 基于 Eclipse 的 IDE CODEO

  • 大型软件和硬件体系
