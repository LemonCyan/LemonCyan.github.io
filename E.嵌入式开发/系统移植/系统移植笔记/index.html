系统移植笔记 #



主要任务：在 s5pc100 上移植一个linux操作系统

带操作系统产品开发流程： 1。引导程序 类似于BIOS 2. 操作系统内核 linux 3. 根文件系统

引导程序：uboot xboot vboot supervivi 内核：winCE linux vxworks 文件系统：rootfs

开发模式：将用到的程序或数据 下载 到开发板的内存中 产品模式：将所有数据烧录到外存中

配置网络： 1）将pc防火墙关闭，将wifi共享软件关掉，将虚拟机设置成桥接模式（ctrl+d打开配置） 2）设置开发板的网络环境 在开发板交互界面输入如下： setenv ipaddr 192.168.1.2 setenv serverip 192.168.1.3 setenv netmask 255.255.255.0 saveenv 3)设置虚拟机的网络环境 通过图形化界面配置 检测输入：ifconfig
4)测试开发板与虚拟机是否成功通信 在开发板交互界面输入： ping 192.168.1.3 如果结果是 xxxxx is alive 说明成功

sudo  /etc/init.d/tftpd-hpa  restart
sudo  /etc/init.d/nfs-kernel-server restart

下载内核/运行内核 ： 1）将zImage 拷贝到 虚拟机的tftp服务器目录（ /tftpboot） 2)在开发板中输入： tftp 20008000 zImage //将zImage 下载到开发板内存的20008000 go 20008000 // 将pc 指针指向20008000 2）在开发板输入： setenv bootcmd tftp 20008000 zImage ; go 20008000 saveenv

挂载并运行文件系统： 1）将 rootfs.tgz 拷贝到 虚拟机 nfs目录 （/nfsboot） 2)进入 /nfsboot,解压文件系统 cd /nfsboot sudo tar xvf rootfs.tgz sudo chmod 777 /nfsboot -R

3)在开发板交互界面输入如下：
	setenv  bootargs root=nfs nfsroot=192.168.1.3:/nfsboot/rootfs  
		ip=192.168.1.2  console=ttySAC0,115200 init=/linuxrc
	saveenv

重启开发板

安装交叉编译器：（在x86上编译，在arm上进行运行） 1）交 arm-cortxxxxxxxx.tar.bz2 拷贝到虚拟机主目录 2）解压 cd ~ sudo tar xvf arm-xxxxxxxxxxxx

3)配置
	sudo   vi   /etc/bash.bashrc
	在最后一行添加如下：
	exprot  PATH=$PATH:/home/fs/arm-cortex_a8/bin
4)执行配置文件
	source  /etc/bash.bashrc

5)测试
	arm-c tab  看是否能补全
