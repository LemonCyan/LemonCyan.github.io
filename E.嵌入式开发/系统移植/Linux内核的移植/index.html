linux内核移植 {//一、linux内核和linux操作系统（ubuntu，Redhat）的区别 “内核”指的是一个提供硬件抽象层、磁盘及文件系统控制、多任务等功能的系统软件。一个内核不 是一 套完整的操作系统 通常我们使用的 linux 系统是一个集 linux 内核、工具集、各种库、桌面管理器、应用程序等一体 的一个发布包 (发行版)

linux ubuntu不是一个实时（马上操作，马上响应）操作系统， Vxworks是个实时的操作系统 }

{//二、Linux 内核的特性

开源：免费 可以移植，支持的硬件平台广泛 x86 arm mips powerpc 。。。。 高可扩展性 可剪裁、可扩展，可以运行在大型主机，也可以运行在个人计算机上 模块化设计 模块可以动态加载，卸载，可以减少系统体积，同时可以用来解决冲突问题，模块调试 }

{//三、linux版本的选择 目前linux系统采用 A.B.C.D 的版本号管理方式 A 表示linux的主版本号 B 表示linux的次版本号，B 为偶数表示稳定版本，奇数表示开发中的版本 C 表示linux的发行版本号 D 表示更新版本号 linux-2.4 2.6 3.0 3.14 我们选择3.14.0 }

{//四、linux源码的目录结构 平台相关的目录： arch //每一个架构都有一个单独的目录 include： 平台无关的目录： block： 块设备 drivers： 放各种驱动的目录 fs： 文件系统 }

<> 表示有三种选择状态 不选：不会被编译到内核 *：会被编译到内核 M：被编译成内核模块 [] 有两种状态 不选 和 * 内核的编译 在内核源码顶层目录下执行 make uImage 最终会编译成一个内核镜像 uImage 在内核源码顶层目录下执行 make dtbs 编译设备树文件，最终生成一个dtb文件 在内核源码顶层目录下执行 make modules 编译模块 }

{//六、设备树 Device Tree是一种描述硬件的数据结构，它起源于 OpenFirmware (OF)。 Device Tree由一系列被命名的结点（node）和属性（property）组成，而结点本身可包含子结点。 所谓属性，其实就是成对出现的name和value。 xxx.dts //设备树文件的源码 xxx.dtsi //相当于c的头文件 xxx.dtb //编译设备树生成的二进制文件 有一个root结点”\”,，root结点下又可以有一系列子节点如： / { node1 { child-node1{ }; child-node2{ }; }; node2 { name = val; name2 = val2; }; node3 { }; }; {//子节点的属性 firmware@0203F000 {

compatible = "samsung,secure-firmware"; reg = <0x0203F000 0x1000>; }; compatible：同上用来绑定一个驱动和设备 reg：可寻址设备用来表示编码地址信息，是一个列表 格式：reg = <addr1 len1 [addr2 len2] [addr3 len3]> addr表示地址起始，len表示范围，这两个字段长度可变如父节点#address-cells=<1>和 #size- cells=<1>， 0x0203F0000为地址起始，0x1000为范围，如个父节点#address-cells=<2>和 #size-cells=<0>， 0x0203F0000, 0x1000都是地址，如果不希望继承父节点则可以在本结点中添加#address-cells和 #size-cells的定义 } }
