DM9000网卡移植 #

网卡驱动的移植 a.修改设备树文件（*.dts）添加DM9000的设备节点 b.修改driver/clk/clk.c c.用make menuconfig 配置内核 d.编译内核和设备树

通过外围板==》核心板==》芯片手册 确定接到exynos4412提供的接口（共64MB，分为4部分）

{//DM9000网卡设备树分析

  1. 看原理图，发现DM9000网卡接SROM的Xm0cs1片选，所以DM9000接SROM的bank1，即地址 是5000000
  2. 看原理图，发现DM9000的中断信号线接GPX0_6
  3. 看设备树源码，分析描述中断的属性 interrupt-parent = <&gpx0>; vi arch/arm/boot/dts/exynos4x12-pinctrl.dtsi interrupts = <6 4>; 6代表DM9000网卡中断号是gpx0的第6个资源<0 22 0> 4代表中断的触发方式是高电平触发 SPI ID 22 54 – EINT[6] linux-3.14-OK.bak/Documentation/devicetree/bindings/arm$ vi gic.txt 32 1 = low-to-high edge triggered 33 2 = high-to-low edge triggered 34 4 = active high level-sensitive 35 8 = active low level-sensitive }
