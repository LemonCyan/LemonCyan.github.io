Bootloader及U-boot简介 #

{//一、什么是bootloader {//1. bootloader简介

  1. Bootloader是硬件启动的引导程序，是运行操作系统的前提；
  2. bootloader在操作系统内核或用户应用程序运行之前运行的一小段代码。对软硬件进行相应的初始 化和设定， 为最终运行操作系统准备好环境；
  3. Bootloader不属于操作系统，一般采用汇编语言和C语言开发。需要针对特定的硬件平台编写。所 以硬件平台不一样 那么我们的bootloader代码也不一样 } {//2. bootloader的两种操作模式 自启动模式： 在这种模式下，Bootloader从目标机上的某个固态存储设备（emmc）上将操作系统加载到RAM中运 行，或者从网络下载， 整个过程并没有用户的介入。

交互模式： 在这种模式下（在倒计时结束前按下任意键），目标机上的Bootloader将通过串口或网络等通信手段 从开发主机（Host）上下载 内核映像和根文件系统映像等到RAM中。可以被 Bootloader写到目标机上的固态存储媒质(emmc) 中，或者直接进行系统的引导。 也可以通过串口接收用户的命令 } {//3. Bootloader的基本功能 初始化相关硬件 把bootloader自搬运到内存中(自搬移) 执行用户的命令 访问环境变量 通过网络/串口通信 读写RAM/FLASH 加载并执行内核 } {//4. bootloader启动流程 Bootloader的第一阶段

初始化基本的硬件 时钟 串口 内存 把bootloader自搬运到内存中； 自搬移 设置堆栈指针并将bss段清零。为后续执行C代码做准备； 跳转到第二阶段代码中 Bootloader的第二阶段 初始化本阶段要使用到的硬件； DM9000网卡 读取环境变量 如果是自启动模式，从Flash或通过网络加载内核并执行（bootcmd）； 如果是交互模式，接收到用户的命令后执行 } {//5. 常用bootloader -- u-boot u-boot(Universal Boot Loader)是德国DENX小组开发的用于多种嵌入式CPU的bootloader程序。遵 循GPL条款。 我们选择的u-boot是 u-boot-2013 } }

{//三、u-boot目录结构分析 {//1. u-boot版本的选择 u-boot-1.1.x ... u-boot-2008 u-boot-2009 ... a. 支持当前的硬件平台 b. 选择稳定的版本（资料比较多） u-boot-2013 } {//2. u-boot目录结构分析 u-boot源码下的目录分为平台相关的代码和平台无关的代码，因为uboot支持很多平台，把一些通用 的代码放到 平台无关的目录下，可以减小u-boot的代码量 平台相关的目录： arch：每一个体系结构都对应一个文件夹放在这个目录下 arch->arm->cpu->armv7 == start.S board：板级相关的目录 board->samsung->origen/smdk2412 .... origen是一个三星的官方标准板的对应源码目录， 平台无关的目录： api：放的是u-boot提供的接口函数 common：放的u-boot相关的命令 fs：file system post：Power On Self Test

工具文档目录： doc tools } }

{//四、u-boot源码的配置和编译 u-boot的源码是通过GNU Makefile进行组织编译的，由顶层目录下的Makefile进行对开发板的整体 配置，然后 递归调用各个子目录下的Makfile，最后把所以编译生成的文件都链接成一个u-boot镜像文件--u- boot.bin uboot的配置： 在u-boot的顶层目录下执行：make xxx_config xxx为具体的开发板名称，比如要配置我们华清的开发板就执行make fs4412_config 目的：对uboot工程进行配置，因为u-boot支持很多种板子，通过配置以确定编译特定板子的子目录 和头文件。 编译： 在顶层目录下执行：make 编译成一个u-boot.bin }

{//五、uboot的移植 移植的过程： 先将当前板子所对应的官方标准板的板级源码cp一份，然后修改Makefile等配置文件，进行配置和编 译， 最后下到板子上看是否能运行，如果能运行，说明这套代码可以用。如果不能用则需要进行移植： a. 用点灯发看程序有没有执行到第一个指令 a. 先看串口是否有输出信息，如果没有则需要先实现串口的输出（在此之前可以用电灯法调试） b. 移植网卡，因为只有移植了网卡，才能通过u-boot去下载内核等 c. flash/emmc的移植，可以对flash进行操作，烧写，读flash等操作 }
