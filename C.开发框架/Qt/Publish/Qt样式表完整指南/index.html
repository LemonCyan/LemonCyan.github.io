Qt样式表完整指南

Qt 的 QSS 样式表功能 #

Qt 自带一个强大的皮肤功能，称为 QSS（Qt 样式表），类似于网页设计中的 CSS。即使没有专业的美工设计师，你也能轻松创建出炫酷的用户界面。

1 样式表语法 #

选择器类型 #

  • QPushButton[flat="false"]：匹配所有非扁平化的 QPushButton 实例。
  • .QPushButton：匹配所有 QPushButton 实例，但不包括其子类。
  • QPushButton#okButton：匹配对象名称为 okButton 的所有 QPushButton 实例。
  • QDialog QPushButton：匹配所有 QPushButton 实例，这些实例是 QDialog 的后代。
  • QDialog > QPushButton：匹配所有 QPushButton 实例，这些实例是 QDialog 的直接子代。

声明 #

样式表中的声明部分定义了具体的样式属性。例如：

css
QPushButton { color: rgb(255, 0, 0); }
QPushButton { background-color: rgb(0, 170, 255); }

子控件 #

对于复杂的窗口组件（如 QTabWidget），你需要访问其子控件并单独设置样式。

伪状态 #

伪状态用于实现界面的动态效果，能够检测用户的交互行为，例如鼠标悬停或按下按钮等。以下是一些常用的伪状态：

  • 悬停：:hover
  • 不悬停：:!hover
  • 悬停并选中：:hover:checked
  • 悬停并按下：:hover:!pressed

2 setStyleSheet 使用方法 #

基本句法 #

样式表的语法基本上与 HTML CSS 语法一致。样式表由一系列样式规则组成，每个样式规则由一个 <selector> 和一个 <declaration> 组成。

cpp
QPushButton { color: red; }

多个 <selector> 可以用逗号 , 分隔：

cpp
QPushButton, QLineEdit, QComboBox { color: red; }

<declaration> 部分可以包含多个属性值对，用分号 ; 分隔：

cpp
QPushButton { color: red; font-family: Arial; line-height: 26px; }

常用属性 #

样式-英文 参数 样式-中文
color white rgb(110,110,110) #eb7350 前景颜色，字体颜色
background-color white rgb(110,110,110) #eb7350 背景颜色
border-style outset inset 边框样式
border-width px 边框大小
border-radius px 边框弧度
font-family 微软雅黑 设定字体所属家族
font-size px 字体大小

伪状态使用示例 #

cpp
QWidget->setStyleSheet("QLineEdit::hover { background-color: black; color: yellow; }");

伪状态串联使用：

cpp
QWidget->setStyleSheet("QCheckBox:checked:hover { background-color: green; }");

3 QLabel 样式表详解 #

字体样式 #

cpp
QLabel {
    font-family: "Microsoft YaHei";
    font-size: 14px;
    font-style: italic;
    font-weight: bold;
    color: #BDC8E2;
    font: bold italic 18px "Microsoft YaHei";
}
  • font-family：设置字体类型
  • font-size：设置字体大小
  • font-style：设置字体斜体样式
  • font-weight：设置字体加粗样式
  • color：设置字体颜色

文字位置 #

cpp
padding-left: 10px;
padding-top: 8px;
padding-right: 7px;
padding-bottom: 9px;

在 qss 中，属性 text-align 对 Label 是不起作用的，只能通过设置 padding 来实现文字的显示位置。

边框样式 #

cpp
QLabel {
    border-style: solid;
    border-width: 2px;
    border-color: red;
    border: 2px solid red;
    border-radius: 20px;
}
  • border-style：设置边框样式
  • border-width：设置边框宽度
  • border-color：设置边框颜色
  • border-radius：设置边框圆角半径

背景样式 #

cpp
QLabel {
    background-color: #2E3648;
    background-image: url("./image.png");
    background-repeat: no-repeat; 
    background-position: left center;
}

QLabel 动态样式 #

鼠标悬浮时的样式
cpp
QLabel:hover {
    color: red;
    border-color: green;
    background-color: aqua;
}
标签禁止时的样式
cpp
QLabel:disabled {
    color: blue;
    border-color: brown;
    background-color: aqua;
}

4 QPushButton 样式表详解 #

字体样式 #

cpp
QPushButton {
    font-family: "Microsoft YaHei";
    font-size: 16px;
    color: #BDC8E2;
    background-color: #2E3648;
    font-style: italic;
    font-weight: bold;
}

文字位置 #

cpp
text-align: left center;
padding-left: 10px;
padding-top: 8px;
padding-right: 7px;
padding-bottom: 9px;

边框样式 #

cpp
QPushButton {
    border-style: solid;
    border-width: 2px;
    border-color: red;
    border: 2px solid red;
    border-radius: 20px;
}

背景样式 #

cpp
QPushButton {
    background-color: #2E3648;
    background-image: url("./image.png");
    background-repeat: no-repeat; 
    background-position: left center;
}

动态样式设置 #

鼠标悬浮时的样式
cpp
QPushButton:hover {
    color: red;
    border-color: green;
    background-color: aqua;
}
鼠标点击时的样式
cpp
QPushButton:pressed {
    color: green;
    border-color: blueviolet;
    background-color: black;
}
按钮禁止时的样式
cpp
QPushButton:disabled {
    color: blue;
    border-color: brown;
    background-color: aqua;
}

下拉菜单 #

对于 QPushButton，可以给它设置添加一个下拉菜单，这需要调用 QPushButton 的 setMenu() 方法，当菜单设置成功后，QPushButton 就会默认添加一个 menu-indicator 下拉菜单指示器图标，可以对这个菜单图标进行样式修改

cpp
QPushButton::menu-indicator {
    image: url("./image.png");
    subcontrol-position: right center;
    subcontrol-origin: padding;
    right: 10px;
    top: 15px;
}
  • image：设置菜单指示器图标
  • subcontrol-position：设置菜单指示器图标的位置
  • subcontrol-origin：设置菜单指示器图标与按钮之间的停靠位置
  • right top left bottom：设置菜单指示器图标距离按钮四个位置的距离
