QCustomPlot图表库完整指南

QCustomPlot 是面向 Qt C++ 的 2D 绑图库，用于 QtWidgets 的实时数据可视化。

架构 #

类结构 #

QCustomPlot 是主部件，内部用 Layout 系统管理可视元素。

classDiagram
    QWidget <|-- QCustomPlot
    QCustomPlot *-- QCPLayoutGrid : plotLayout
    QCPLayoutElement <|-- QCPLayout
    QCPLayout <|-- QCPLayoutGrid
    QCPLayout <|-- QCPLayoutInset
    QCPLayoutElement <|-- QCPAxisRect
    QCPAxisRect *-- QCPAxis : xAxis, yAxis
    QCPAbstractPlottable <|-- QCPGraph
    QCPAbstractPlottable <|-- QCPCurve
    QCPAbstractPlottable <|-- QCPBars
    QCPAbstractPlottable <|-- QCPColorMap
    QCPAbstractPlottable <|-- QCPFinancial
类 功能
QCustomPlot 主部件，管理图层、坐标轴、绑定对象和交互
QCPAxisRect 坐标轴矩形，包含多个 QCPAxis
QCPAxis 坐标轴，处理刻度、标签、范围
QCPGraph 折线图/散点图，继承自 QCPAbstractPlottable
QCPLayoutGrid 网格布局，用于排列多个 AxisRect

渲染流程 #

默认用 QPainter 软件渲染。流程：

  1. 按 z-order 遍历 QCPLayer
  2. 每个 Layer 调用 QCPLayerable 的绑制方法
  3. lmBuffered 模式缓存静态元素

实用场景 #

实时数据流 #

传感器、示波器等场景的处理要点：

问题 做法
线程阻塞 采集和渲染分开
频繁重绑 攒数据后批量 setData
过度刷新 用 rpQueuedReplot
内存泄露 removeBefore() 清理旧数据 
cpp
class RealtimePlotWidget : public QWidget {
    Q_OBJECT
public:
    void appendData(double timestamp, double value);  // 线程安全

private slots:
    void updatePlot();

private:
    QCustomPlot *m_plot;
    QTimer *m_refreshTimer;
    QMutex m_dataMutex;
    QVector<double> m_pendingTimestamps, m_pendingValues;
    static constexpr double WINDOW_SIZE = 10.0;   // 显示窗口(秒)
    static constexpr int REFRESH_RATE_MS = 33;    // ~30 FPS
};

void RealtimePlotWidget::updatePlot() {
    QVector<double> timestamps, values;
    {
        QMutexLocker locker(&m_dataMutex);
        if (m_pendingTimestamps.isEmpty()) return;
        timestamps = std::move(m_pendingTimestamps);
        values = std::move(m_pendingValues);
    }

    auto *graph = m_plot->graph(0);
    for (int i = 0; i < timestamps.size(); ++i)
        graph->addData(timestamps[i], values[i]);

    double currentTime = timestamps.last();
    graph->data()->removeBefore(currentTime - WINDOW_SIZE);  // 清旧数据
    m_plot->xAxis->setRange(currentTime - WINDOW_SIZE, currentTime);
    m_plot->yAxis->rescale(true);
    m_plot->replot(QCustomPlot::rpQueuedReplot);
}

QCPItemText *m_textLabel;
QCPItemLine *m_arrow;

// 初始化
m_textLabel = new QCPItemText(m_plot);
m_textLabel->setPositionAlignment(Qt::AlignTop | Qt::AlignHCenter);
m_textLabel->position->setType(QCPItemPosition::ptAxisRectRatio);
m_textLabel->position->setCoords(0.5, 0);
m_textLabel->setVisible(false);

m_arrow = new QCPItemLine(m_plot);
m_arrow->start->setParentAnchor(m_textLabel->bottom);
m_arrow->setHead(QCPLineEnding::esSpikeArrow);

// mousePressEvent 中
double x = m_plot->xAxis->pixelToCoord(event->pos().x());
double y = m_plot->yAxis->pixelToCoord(event->pos().y());
m_arrow->end->setCoords(x, y);
m_textLabel->setText(QString("x=%1\ny=%2").arg(x).arg(y));

常见问题 #

编译错误 #

报错 原因 解法
undefined reference to QPrinter 缺 printsupport .pro 加 QT += printsupport
GL/gl.h: No such file 缺 OpenGL 开发库 Linux: apt install mesa-common-dev libgl1-mesa-dev
too many sections (MinGW) 对象文件太大 加 QMAKE_CXXFLAGS += -Wa,-mbig-obj
unresolved external symbol 文件没加进项目 确认 qcustomplot.cpp 在项目里

运行问题 #

图表不显示

cpp
graph->setData(x, y);
customPlot->replot();  // 别忘了

内存一直涨（实时场景）

cpp
graph->data()->removeBefore(currentTime - windowSize);

高 DPI 模糊

cpp
customPlot->setBufferDevicePixelRatio(devicePixelRatio());

子线程更新崩溃

cpp
// 错：直接操作
workerThread->graph()->addData(x, y);  // 崩溃

// 对：信号槽
emit dataReady(x, y);  // Qt::QueuedConnection

对比 #

QCustomPlot vs Qt Charts #

方面 QCustomPlot Qt Charts
架构 独立 QWidget Graphics View
实时性能 高 (可开 OpenGL) 中等
内存 低 较高
许可证 GPLv3 / 商业 LGPLv3 / 商业
Qt 版本 5.0+ / 6.x 5.7+ / 6.x

局限 #

  1. 没有 QML 原生支持，需用 QQuickPaintedItem 包一层
  2. 只有 2D，没有 3D
  3. 单文件 2.8MB，编译慢
  4. GPLv3 有传染性，闭源要买商业授权
