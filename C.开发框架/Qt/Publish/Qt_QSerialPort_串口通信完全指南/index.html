Qt QSerialPort 串口通信完全指南 #

QSerialPort 是 Qt 5.1+ 的标准串口模块，封装了 Windows/Linux/macOS 底层接口，提供统一 API。本文覆盖异步事件驱动、粘包/断包处理、多线程流控与异常恢复，附 Linux/Windows 原生 API 实现。

1. 概述 #

QtSerialPort 自 Qt 5.1 起成为标准模块，封装了不同操作系统的底层串口接口。

核心优势：

  • 异步事件驱动（信号槽），契合 Qt 事件循环，避免 UI 卡顿
  • 继承自 QIODevice，API 风格与 QFile、QTcpSocket 一致
  • QSerialPortInfo 可枚举系统串口，获取端口名、VID/PID、制造商信息

4. 通信模式详解 #

模式 适用线程 优点 缺点 场景
异步 (Signal/Slot) UI 主线程 不卡界面 状态管理稍复杂 90% 上位机应用
同步 (waitFor...) Worker 子线程 逻辑线性 禁止在 UI 线程使用 简单协议脚本

4.1 异步事件驱动（推荐） #

信号槽机制使数据的接收和发送在事件循环中异步处理，不会阻塞主线程。

读取数据：连接 readyRead 信号。注意，触发一次 readyRead 不等于收到完整数据包。

cpp
connect(&serial, &QSerialPort::readyRead, this, &MyClass::handleReadyRead);

void MyClass::handleReadyRead() {
    QByteArray data = serial.readAll();
    buffer.append(data);
    parseBuffer();  // 尝试解析完整帧
}

发送数据：write() 是非阻塞的，数据写入内部缓冲区后由事件循环发送。

cpp
serial.write("Hello Device");
// 如果需要确切知道已发送字节数，可连接 bytesWritten 信号

4.2 同步阻塞（轮询） #

适用于非 GUI 线程或控制台脚本，函数会挂起当前线程直到操作完成或超时。

⚠警告

禁止在 GUI 线程使用此模式，否则界面"假死"无响应。

cpp
void Worker::run() {
    QSerialPort serial;
    // ... 配置 ...
    serial.open(QIODevice::ReadWrite);

    serial.write("CMD");
    if (!serial.waitForBytesWritten(100)) return;

    if (serial.waitForReadyRead(5000)) {
        QByteArray resp = serial.readAll();
        while (serial.waitForReadyRead(10)) {
            resp += serial.readAll();
        }
        emit resultReady(resp);
    } else {
        qDebug() << "Timeout or Error";
    }
}

5. 进阶场景处理 #

5.1 数据帧解析（粘包/断包） #

串口是流式传输，接收端看到的只是字节流：

  • 断包：一条长指令分两次才收全
  • 粘包：两条指令一次性收到

解决方案：引入应用层协议（Header + Length + Payload + Checksum），配合缓冲区 + 状态机。

flowchart TD
    A[readyRead 信号] --> B[追加到 Buffer]
    B --> C{Buffer >= 最小帧长?}
    C -- No --> D[等待下次数据]
    C -- Yes --> E{帧头正确?}
    E -- No --> F[移除首字节]
    F --> C
    E -- Yes --> G{Buffer >= 完整帧长?}
    G -- No --> D
    G -- Yes --> H[截取完整帧]
    H --> I[移除已处理数据]
    I --> J[分发处理]
    J --> C

cpp
QByteArray m_buffer;

void onReadyRead() {
    m_buffer.append(serial->readAll());

    while (m_buffer.size() >= MIN_PACKET_SIZE) {
        // 寻找帧头 0x55AA
        if ((quint8)m_buffer[0] != 0x55 || (quint8)m_buffer[1] != 0xAA) {
            m_buffer.remove(0, 1);  // 滑动窗口
            continue;
        }

        quint16 len = (quint8)m_buffer[2] << 8 | (quint8)m_buffer[3];
        if (m_buffer.size() < len + HEADER_SIZE) break;  // 等待更多数据

        QByteArray packet = m_buffer.left(len + HEADER_SIZE);
        m_buffer.remove(0, len + HEADER_SIZE);

        if (checkSum(packet)) {
            emit newPacket(packet);
        }
    }
}

5.2 高频发送流控 #

发送频率高（如 1ms 一次）而波特率较低时，Qt 内部缓冲区会迅速堆积。

cpp
void safeWrite(const QByteArray &data) {
    // bytesToWrite() 返回尚未写入硬件的字节数
    if (serial->bytesToWrite() > 10240) { 
        qWarning() << "Output buffer overflow, dropping packet!";
        return; 
    }
    serial->write(data);
}

5.3 多线程缓冲池机制 #

多线程 while(1) 循环过快时，信号槽来不及处理数据。使用 waitFor* 阻塞 + 缓冲池实现线程安全交换。

cpp
struct BufferNode {
    QMutex nodeMutex;
    int nodeStatus;      // 0: 空闲, 1: 待处理
    QByteArray nodeData;
};

BufferNode sendMsg[INDEX_OF_BUFF];
BufferNode recvMsg[INDEX_OF_BUFF];

void threadSendLoop() {
    for (int i = 0; i < INDEX_OF_BUFF; i++) {
        if (sendMsg[i].nodeMutex.tryLock()) {
            if (sendMsg[i].nodeStatus == 1) {
                serial->write(sendMsg[i].nodeData);
                serial->waitForBytesWritten(5);
                sendMsg[i].nodeStatus = 0;
            }
            sendMsg[i].nodeMutex.unlock();
        }
    }
}

void threadRecvLoop() {
    serial->waitForReadyRead(1);
    if (serial->bytesAvailable() > 0) {
        for (int i = 0; i < INDEX_OF_BUFF; i++) {
            if (recvMsg[i].nodeMutex.tryLock()) {
                if (recvMsg[i].nodeStatus == 0) {
                    recvMsg[i].nodeStatus = 1;
                    recvMsg[i].nodeData = serial->readAll();
                    recvMsg[i].nodeMutex.unlock();
                    return;
                }
                recvMsg[i].nodeMutex.unlock();
            }
        }
    }
}

6. 高频并发与性能优化 #

高频数据流（如 EEG 1000Hz 采样）的处理策略：

6.1 核心策略 #

  1. 数据解耦：IO 线程与 UI 渲染线程分离
  2. DMA 思想：不要逐字节 append，使用 memcpy 或预分配 QByteArray
  3. 绘制降频：1000Hz 采样 → 60Hz 刷新，用 QTimer 聚合数据后提交绘图

6.2 错误处理与热插拔 #

USB 转串口被拔掉时的处理：

cpp
connect(&serial, &QSerialPort::errorOccurred, this, [](QSerialPort::SerialPortError error){
    if (error == QSerialPort::NoError) return;
    qWarning() << "Serial error:" << error;

    if (error == QSerialPort::ResourceError) {
        qCritical() << "Device disconnected physically!";
        // 触发自动重连逻辑...
    }
});

// 可选：QTimer 定时检查 QSerialPortInfo 防止 ResourceError 不触发

7. Modbus 集成 #

Qt 提供 QtSerialBus 模块，无需手写协议栈。

cmake
QT += serialbus

Modbus RTU Master 示例：

cpp
#include <QModbusRtuSerialMaster>

void setupModbus() {
    auto modbus = new QModbusRtuSerialMaster(this);
    modbus->setConnectionParameter(QModbusDevice::SerialPortNameParameter, "COM3");
    modbus->setConnectionParameter(QModbusDevice::SerialBaudRateParameter, 19200);
    modbus->setConnectionParameter(QModbusDevice::SerialDataBitsParameter, QSerialPort::Data8);
    modbus->setConnectionParameter(QModbusDevice::SerialParityParameter, QSerialPort::EvenParity);

    if (!modbus->connectDevice()) {
        qDebug() << "Connect failed";
        return;
    }

    auto reply = modbus->sendReadRequest(
        QModbusDataUnit(QModbusDataUnit::HoldingRegisters, 0, 10), 
        1  // Slave ID
    );
    
    if (reply && !reply->isFinished()) {
        connect(reply, &QModbusReply::finished, this, [reply](){
            if (reply->error() == QModbusDevice::NoError) {
                qDebug() << "Data:" << reply->result().values();
            }
            reply->deleteLater();
        });
    }
}

8.2 Linux termios 实现 #

点击展开完整代码 
c
#include <stdio.h>
#include <string.h>
#include <unistd.h>
#include <fcntl.h>
#include <termios.h>

typedef struct {
    int fd;
    struct termios original_tty;
    char port_name[64];
} SerialPort;

int serial_open(SerialPort *port, const char *device, speed_t baudrate) {
    port->fd = open(device, O_RDWR | O_NOCTTY | O_NDELAY);
    if (port->fd == -1) return -1;
    
    strncpy(port->port_name, device, sizeof(port->port_name) - 1);
    if (!isatty(port->fd)) { close(port->fd); return -1; }
    
    tcgetattr(port->fd, &port->original_tty);
    
    struct termios tty = {0};
    cfsetispeed(&tty, baudrate);
    cfsetospeed(&tty, baudrate);
    
    tty.c_cflag |= (CLOCAL | CREAD);
    tty.c_cflag &= ~CSIZE; tty.c_cflag |= CS8;
    tty.c_cflag &= ~PARENB;
    tty.c_cflag &= ~CSTOPB;
    tty.c_cflag &= ~CRTSCTS;
    
    tty.c_lflag &= ~(ICANON | ECHO | ECHOE | ISIG);
    tty.c_iflag &= ~(IXON | IXOFF | IXANY);
    tty.c_oflag &= ~OPOST;
    
    tty.c_cc[VMIN] = 1;
    tty.c_cc[VTIME] = 10;
    
    tcflush(port->fd, TCIOFLUSH);
    tcsetattr(port->fd, TCSANOW, &tty);
    fcntl(port->fd, F_SETFL, 0);
    return 0;
}

ssize_t serial_write(SerialPort *port, const void *data, size_t len) {
    ssize_t written = write(port->fd, data, len);
    tcdrain(port->fd);
    return written;
}

ssize_t serial_read(SerialPort *port, void *buffer, size_t len, int timeout_ms) {
    fd_set read_fds;
    struct timeval tv = { timeout_ms / 1000, (timeout_ms % 1000) * 1000 };
    FD_ZERO(&read_fds); FD_SET(port->fd, &read_fds);
    
    int ret = select(port->fd + 1, &read_fds, NULL, NULL, &tv);
    if (ret <= 0) return ret;
    return read(port->fd, buffer, len);
}

void serial_close(SerialPort *port) {
    if (port->fd != -1) {
        tcsetattr(port->fd, TCSANOW, &port->original_tty);
        close(port->fd);
        port->fd = -1;
    }
}

8.3 Windows Win32 API 实现 #

点击展开完整代码 
c
#include <windows.h>
#include <stdio.h>

typedef struct {
    HANDLE hComm;
    char port_name[32];
    DCB dcb;
    COMMTIMEOUTS timeouts;
} SerialPort;

BOOL serial_open(SerialPort *port, const char *portName, DWORD baudRate) {
    char fullName[32];
    snprintf(fullName, sizeof(fullName), "\\\\.\\%s", portName);
    
    port->hComm = CreateFileA(fullName, GENERIC_READ | GENERIC_WRITE, 
                               0, NULL, OPEN_EXISTING, 0, NULL);
    if (port->hComm == INVALID_HANDLE_VALUE) return FALSE;
    
    strncpy(port->port_name, portName, sizeof(port->port_name) - 1);
    
    ZeroMemory(&port->dcb, sizeof(DCB));
    port->dcb.DCBlength = sizeof(DCB);
    GetCommState(port->hComm, &port->dcb);
    
    port->dcb.BaudRate = baudRate;
    port->dcb.ByteSize = 8;
    port->dcb.StopBits = ONESTOPBIT;
    port->dcb.Parity = NOPARITY;
    port->dcb.fBinary = TRUE;
    port->dcb.fOutxCtsFlow = FALSE;
    port->dcb.fOutxDsrFlow = FALSE;
    port->dcb.fDtrControl = DTR_CONTROL_ENABLE;
    port->dcb.fRtsControl = RTS_CONTROL_ENABLE;
    
    if (!SetCommState(port->hComm, &port->dcb)) {
        CloseHandle(port->hComm);
        return FALSE;
    }
    
    port->timeouts.ReadIntervalTimeout = 50;
    port->timeouts.ReadTotalTimeoutConstant = 2000;
    port->timeouts.ReadTotalTimeoutMultiplier = 10;
    port->timeouts.WriteTotalTimeoutConstant = 2000;
    port->timeouts.WriteTotalTimeoutMultiplier = 10;
    SetCommTimeouts(port->hComm, &port->timeouts);
    
    PurgeComm(port->hComm, PURGE_RXCLEAR | PURGE_TXCLEAR);
    return TRUE;
}

int serial_write(SerialPort *port, const void *data, DWORD len) {
    DWORD bytesWritten = 0;
    WriteFile(port->hComm, data, len, &bytesWritten, NULL);
    return (int)bytesWritten;
}

int serial_read(SerialPort *port, void *buffer, DWORD len) {
    DWORD bytesRead = 0;
    ReadFile(port->hComm, buffer, len, &bytesRead, NULL);
    return (int)bytesRead;
}

void serial_close(SerialPort *port) {
    if (port->hComm != INVALID_HANDLE_VALUE) {
        CloseHandle(port->hComm);
        port->hComm = INVALID_HANDLE_VALUE;
    }
}

9. 总结 #

关键点 建议
IO 模式 默认用异步，仅在独立工作线程中考虑同步
数据缓冲 必须处理粘包，不要假设 readAll 返回完整包
性能 高频数据用缓冲 + 定时器降频
稳定性 处理 ResourceError (掉线) 和 PermissionError (被占用)
