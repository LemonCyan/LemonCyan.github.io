Qt_网络模块

Qt 提供了强大的网络模块 (Qt Network)，涵盖了从高层级的 HTTP 请求 (QNetworkAccessManager) 到低层级的 TCP/UDP 套接字 (QTcpSocket/QUdpSocket)。

本文剔除繁杂的代码封装，直接展示核心实现模式，帮助你快速掌握 HTTP 异步请求与高性能多线程 TCP 的最佳实践。

1. 高层级：HTTP 请求 (QNetworkAccessManager) #

QNetworkAccessManager (QNAM) 是处理 HTTP/HTTPS 的核心，天然异步，无需额外开启线程。

1.1 核心使用范式 #

关键点：复用 Manager 对象，使用 Lambda 处理回调。

cpp
// 【建议】Manager 应作为成员变量长期存在，不要在函数内创建临时变量
QNetworkAccessManager *manager = new QNetworkAccessManager(this);

// 1. 发起 GET 请求
QNetworkRequest request(QUrl("https://api.example.com/data"));
request.setHeader(QNetworkRequest::UserAgentHeader, "MyQtApp/1.0");
QNetworkReply *reply = manager->get(request);

// 2. 处理响应 (信号槽)
connect(reply, &QNetworkReply::finished, this, [reply](){
    if (reply->error() == QNetworkReply::NoError) {
        // 读取并解析 JSON
        QByteArray data = reply->readAll();
        QJsonObject json = QJsonDocument::fromJson(data).object();
        qDebug() << "Success:" << json;
    } else {
        qWarning() << "Network Error:" << reply->errorString();
    }
    // 3. 【重要】清理 Reply 对象
    reply->deleteLater();
});

1.2 常用进阶操作 #

  • POST JSON 数据：
    cpp
    request.setHeader(QNetworkRequest::ContentTypeHeader, "application/json");
QJsonObject json {% raw %}{{"key", "value"}}{% endraw %};
manager->post(request, QJsonDocument(json).toJson());
  • 文件上传 (Multipart)：使用 QHttpMultiPart 类构建 form-data 包体。

2. 低层级：多线程 TCP 客户端 #

在主线程直接操作 QTcpSocket 处理高频数据会导致界面卡死。Worker + moveToThread 是最标准、稳健的多线程方案。

2.1 核心架构图解 #

不要继承 QThread！请遵循以下模式：

  1. Worker 类：继承 QObject，包含 QTcpSocket 指针。
  2. Controller：在主线程创建 QThread 和 Worker。
  3. moveToThread：将 Worker 移入新线程。

2.2 关键代码实现 #

TcpWorker (子线程执行者):

cpp
class TcpWorker : public QObject {
    Q_OBJECT
    QTcpSocket *m_socket = nullptr;

public slots:
    // 连接逻辑：必须在 Worker 线程执行
    void doConnect(const QString &host, quint16 port) {
        m_socket = new QTcpSocket(this); // 【关键】Socket 在此线程创建

        // 接收数据
        connect(m_socket, &QTcpSocket::readyRead, this, [this](){
            QByteArray data = m_socket->readAll();
            // ... 此处添加粘包/拆包处理逻辑 ...
            emit messageReceived(data); 
        });

        m_socket->connectToHost(host, port);
    }
    
    // 发送逻辑
    void doSend(const QByteArray &data) {
        if (m_socket && m_socket->isOpen()) m_socket->write(data);
    }
};

Main Controller (主线程控制):

cpp
void setupThread() {
    QThread *thread = new QThread;
    TcpWorker *worker = new TcpWorker; // 不能指定 parent
    worker->moveToThread(thread);

    // 线程生命周期管理
    connect(thread, &QThread::finished, worker, &QObject::deleteLater);
    connect(thread, &QThread::finished, thread, &QObject::deleteLater);
    thread->start();

    // 【关键】跨线程调用 doConnect
    // 方式1：通过信号触发 (推荐)
    // emit startConnectSignal("127.0.0.1", 8080);
    
    // 方式2：QMetaObject::invokeMethod
    QMetaObject::invokeMethod(worker, "doConnect", 
                              Q_ARG(QString, "127.0.0.1"), Q_ARG(quint16, 8080));
}
⚠警告

常见误区：如果在 TcpWorker 的构造函数中创建 QTcpSocket，那么 Socket 对象仍然属于主线程，后续在子线程调用 socket 方法会报错。

3. TCP 服务端 (QTcpServer) #

处理高并发连接时，需要重写 incomingConnection。

3.1 多线程 Accept 模式 #

cpp
// 继承 QTcpServer
void MyServer::incomingConnection(qintptr socketDescriptor) {
    // 为每个新连接创建一个线程
    QThread *thread = new QThread;
    ClientHandler *handler = new ClientHandler(socketDescriptor); // 传递 socket 描述符
    
    handler->moveToThread(thread);
    connect(thread, &QThread::started, handler, &ClientHandler::process);
    
    // 绑定线程退出清理逻辑...
    thread->start();
}

ClientHandler::process() 实现：

cpp
void ClientHandler::process() {
    QTcpSocket socket;
    // 【关键】使用 Socket 描述符初始化
    if (socket.setSocketDescriptor(m_socketDescriptor)) {
        // 在独立线程中，可以使用阻塞等待，编程更简单
        if (socket.waitForReadyRead(timeout)) {
            QByteArray data = socket.readAll();
            // 处理业务...
        }
    }
    emit finished(); // 通知线程退出
}

4. UDP 与 SSL 简述 #

4.1 UDP 通信 #

UDP 无连接，直接绑定端口收发。

cpp
QUdpSocket udp;
udp.bind(QHostAddress::Any, 9999); // 监听端口

// 接收
connect(&udp, &QUdpSocket::readyRead, [&udp](){
    while (udp.hasPendingDatagrams()) {
        QNetworkDatagram dgram = udp.receiveDatagram();
        qDebug() << "Data:" << dgram.data() << "From:" << dgram.senderAddress();
    }
});

// 发送
udp.writeDatagram("Hello", QHostAddress("192.168.1.100"), 8888);

4.2 SSL/TLS 加密 #

生产环境建议始终开启 SSL。将 QTcpSocket 替换为 QSslSocket。

  • 客户端：使用 socket->connectToHostEncrypted(host, port)。
  • 服务端：
    1. 加载证书：socket->setLocalCertificate("server.crt")
    2. 加载私钥：socket->setPrivateKey("server.key")
    3. 启动握手：socket->startServerEncryption()

附录：核心类速查 #

类名 功能 备注
QNetworkAccessManager HTTP/HTTPS 请求 高级 API，自带 Cookie/缓存管理
QTcpSocket TCP 客户端/数据传输 需注意线程归属，它是 QIODevice
QTcpServer TCP 监听与 Accept 重写 incomingConnection 实现多线程
QUdpSocket UDP 数据报 支持单播、广播、组播
QSslSocket 加密套接字 接口与 TcpSocket 兼容，需 OpenSSL 支持
