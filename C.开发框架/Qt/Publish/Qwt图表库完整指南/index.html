Qwt图表库完整指南

Qwt 6.x 图表库完整指南：配置、核心API与工程实践 #

Qwt (Qt Widgets for Technical Applications) 是一个基于 Qt 的 C++ GUI 组件库，主要用于科学和工程领域。除了二维绘图组件，它还提供刻度尺、滑块、表盘等工业控件。当前稳定版本 Qwt 6.3.0，支持 Qt 5.6+ 和 Qt 6.x。

一、核心架构 #

1.1 类层次结构 #

Qwt 绘图系统以 QwtPlot 为核心，使用组合模式管理图表元素。

classDiagram
    QFrame <|-- QwtPlot
    QwtPlot *-- QwtPlotCanvas : 画布
    QwtPlot *-- QwtScaleWidget : 坐标轴(4个)
    QwtPlot *-- QwtLegend : 图例
    QwtPlot o-- QwtPlotItem : 图元(N个)
    
    QwtPlotItem <|-- QwtPlotCurve
    QwtPlotItem <|-- QwtPlotMarker
    QwtPlotItem <|-- QwtPlotGrid
    QwtPlotItem <|-- QwtPlotSpectroCurve
    
    QwtPlotPicker <|-- QwtPlotZoomer

组件指责：

组件 职责 生命周期
QwtPlot 容器，负责坐标轴与图元的布局 随父窗口销毁
QwtPlotCanvas 渲染层，处理绘制和输入 由 QwtPlot 管理
QwtPlotItem 图元（曲线、标记、网格） attach() 后归 QwtPlot 所有
QwtScaleEngine 刻度计算引擎 通过 setAxisScaleEngine() 设置

1.2 渲染流程 #

sequenceDiagram
    participant App as 应用代码
    participant Plot as QwtPlot
    participant Canvas as QwtPlotCanvas
    participant Item as QwtPlotItem
    
    App->>Plot: replot()
    Plot->>Plot: updateAxes()
    Plot->>Canvas: invalidateBackingStore()
    Canvas->>Canvas: paintEvent()
    loop 每个已附加图元
        Canvas->>Item: draw(painter, xMap, yMap, canvasRect)
    end

replot() 是更新图表的入口。它会先重算坐标轴刻度，标记缓存失效，然后在 paintEvent 中遍历图元进行绘制。

二、部署与配置 #

2.1 环境要求 #

依赖项 最低版本 推荐版本
Qt 5.6.0 6.5+
C++ 标准 C++11 C++17
编译器 MSVC 2017 / GCC 7 / Clang 5 MSVC 2022 / GCC 13

2.2 源码编译 #

建议自己编译源码，这样能保证二进制兼容性。

Windows (MSVC/MinGW)
powershell
# 1. 解压源码
Expand-Archive qwt-6.3.0.zip -DestinationPath C:\libs\
cd C:\libs\qwt-6.3.0

# 2. 配置（用对应 Qt 版本的 qmake）
# 推荐用绝对路径
C:\Qt\6.5.0\mingw_64\bin\qmake.exe qwt.pro

# 3. 编译安装
mingw32-make        # MinGW
# nmake             # MSVC
mingw32-make install
Linux/macOS
bash
tar -xjf qwt-6.3.0.tar.bz2
cd qwt-6.3.0

# 检查 qmake 版本
/opt/Qt/6.5.0/gcc_64/bin/qmake qwt.pro

make -j$(nproc)
sudo make install

2.3 静态编译 #

如果需要单文件部署或嵌入式使用，可以静态编译。修改源码目录下的文件：

  1. 编辑 qwtconfig.pri，注释掉动态库：

    # QWT_CONFIG += QwtDll  <-- 注释掉

  2. 编辑 qwtbuild.pri，加入静态编译选项：

    CONFIG += static
CONFIG += staticlib

  3. 重新运行 qmake 和 make。

2.4 文件部署 #

编译后，把文件放到 Qt 安装目录，方便开发：

文件类型 源路径 目标路径 (Qt安装目录)
动态库 lib/qwt.dll bin/
链接库 lib/libqwt.a 或 qwt.lib lib/
头文件 include/*.h include/Qwt/
插件 plugins/designer/qwt_designer_plugin.dll plugins/designer/
✦提示

静态编译不需要部署 .dll。

2.5 关键配置 (qwtconfig.pri) #

QWT_INSTALL_PREFIX = /usr/local/qwt-$$QWT_VERSION

QWT_CONFIG += QwtPlot          # 绘图模块
QWT_CONFIG += QwtWidgets       # 仪表盘控件
QWT_CONFIG += QwtSvg           # SVG 导出 (依赖 Qt SVG)
QWT_CONFIG += QwtOpenGL        # OpenGL 加速
QWT_CONFIG += QwtDesigner      # Designer 插件
⚠警告

如果编译报错 qsvgrenderer.h not found，说明没装 Qt SVG 模块，把 QWT_CONFIG += QwtSvg 注释掉即可。

2.6 项目集成 #

qmake (.pro)
CONFIG += qwt
# 如果 Qwt 不在 Qt 标准目录：
INCLUDEPATH += /path/to/qwt-6.3.0/src
LIBS += -L/path/to/qwt-6.3.0/lib -lqwt
CMake (CMakeLists.txt)
cmake
find_path(QWT_INCLUDE_DIR qwt_plot.h PATHS /usr/local/qwt-6.3.0/include)
find_library(QWT_LIBRARY qwt PATHS /usr/local/qwt-6.3.0/lib)

target_include_directories(myapp PRIVATE ${QWT_INCLUDE_DIR})
target_link_libraries(myapp ${QWT_LIBRARY})

三、核心 API 示例 #

3.1 基础图表 #

cpp
#include <qwt_plot.h>
#include <qwt_plot_curve.h>
#include <qwt_plot_grid.h>
#include <qwt_legend.h>

class SensorPlot : public QwtPlot {
public:
    explicit SensorPlot(QWidget* parent = nullptr) : QwtPlot(parent) {
        // 1. 设置外观
        setTitle("传感器实时监控");
        setCanvasBackground(Qt::white);
        
        // 2. 坐标轴
        setAxisTitle(QwtPlot::xBottom, "时间 (s)");
        setAxisTitle(QwtPlot::yLeft, "温度 (°C)");
        setAxisScale(QwtPlot::xBottom, 0.0, 100.0);
        setAxisAutoScale(QwtPlot::yLeft);
        
        // 3. 网格
        auto* grid = new QwtPlotGrid();
        grid->setMajorPen(Qt::gray, 0, Qt::DotLine);
        grid->attach(this);
        
        // 4. 图例
        insertLegend(new QwtLegend(), QwtPlot::RightLegend);
    }
    
    void addCurve(const QVector<double>& x, const QVector<double>& y) {
        auto* curve = new QwtPlotCurve("温度传感器 A");
        curve->setPen(Qt::red, 2);
        curve->setRenderHint(QwtPlotItem::RenderAntialiased, true);
        
        // setSamples 会复制数据
        curve->setSamples(x, y); 
        curve->attach(this);
    }
};

3.2 交互配置 #

Qwt 内置了一套交互框架，不需要自己处理底层鼠标事件。

cpp
#include <qwt_plot_zoomer.h>
#include <qwt_plot_panner.h>
#include <qwt_plot_magnifier.h>

void setupInteractions(QwtPlot* plot) {
    // 1. 框选缩放 (右键+Ctrl)
    auto* zoomer = new QwtPlotZoomer(plot->canvas());
    zoomer->setMousePattern(QwtEventPattern::MouseSelect2, Qt::RightButton, Qt::ControlModifier);
    zoomer->setRubberBand(QwtPicker::RectRubberBand); 
    zoomer->setZoomBase(true); // 锁定当前视图
    
    // 2. 拖拽平移 (中键)
    auto* panner = new QwtPlotPanner(plot->canvas());
    panner->setMouseButton(Qt::MiddleButton);
    
    // 3. 滚轮缩放
    auto* magnifier = new QwtPlotMagnifier(plot->canvas());
    magnifier->setWheelFactor(1.1); // 10% 步进
}

3.3 坐标轴定制 #

对数坐标
cpp
#include <qwt_scale_engine.h>
// 启用对数 (范围必须 > 0)
plot->setAxisScaleEngine(QwtPlot::yLeft, new QwtLogScaleEngine(10));
自定义标签
cpp
#include <qwt_scale_draw.h>

class TimeScaleDraw : public QwtScaleDraw {
protected:
    QwtText label(double v) const override {
        // 数值转 HH:mm:ss
        QTime t = QTime(0,0).addSecs(static_cast<int>(v));
        return t.toString("HH:mm:ss");
    }
};

plot->setAxisScaleDraw(QwtPlot::xBottom, new TimeScaleDraw());

3.4 实时绘图 #

高频更新（如示波器）建议禁用自动重绘，用 QwtPlotDirectPainter。

cpp
// 1. 关掉自动重绘
plot->setAutoReplot(false);

// 2. 增量绘制
QwtPlotDirectPainter* painter = new QwtPlotDirectPainter(plot);
// ... 数据更新时 ...
painter->drawSeries(curve, startIndex, endIndex);

四、问题排查 #

4.1 编译链接 #

错误 原因 解决
undefined reference to 'QwtPlot::...' 没链接上 查 .pro 的 LIBS，确认 x86/x64 匹配
qwt_compat.h: No such file 引用了旧头文件 Qwt 6.2+ 删了这个文件，改代码吧
LNK2019 (MSVC) Debug/Release 混用 Debug 用 qwtd.lib，Release 用 qwt.lib

4.2 运行时 #

现象 检查
曲线不显示 1. attach() 了吗？
2. replot() 了吗？
3. 数据在坐标轴范围内吗？
对数轴崩溃 数据里有 ≤0 的数（对数不能处理）
Designer 无插件 qwt_designer_plugin.dll 没放对位置

五、选型：Qwt 还是 Qt Charts? #

5.1 上手对比 #

特性 Qwt Qt Charts
协议 LGPL (闭源友好) GPL / 商业许可
场景 科学绘图、工业控制 商业报表、金融K线
性能 优秀 (支持 OpenGL) 良好
交互 内置 Zoomer/Panner 需要自己写
曲线 自带插值算法 基础线条
集成 需编译 Qt 自带

5.2 如何选择 #

  1. 用 Qwt：如果你做医疗仪器、示波器、工控软件，或者必须用 LGPL 协议。
  2. 用 Qt Charts：如果你只需要画个漂亮的柱状图或饼图，并且接受 GPL 或买了 Qt 商业版。
