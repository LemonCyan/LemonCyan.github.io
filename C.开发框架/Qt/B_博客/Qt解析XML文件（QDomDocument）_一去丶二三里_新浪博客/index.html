Qt解析XML文件（QDomDocument） #

XML (Extensible Markup Language) 是一种广泛使用的标记语言，常用于项目的系统配置、数据交换以及网络报文交互等场景。

QtXml 模块提供了丰富的接口用来读写 XML 文件，主要包含两种解析方法：

  1. DOM (Document Object Model)：将 XML 文件全部读入内存并保存为树状拓扑的形式，操作起来十分直观，非常便于遍历与修改。
  2. SAX (Simple API for XML)：基于事件流的底层驱动，速度较快，内存占用极低，但不便于随机定位和修改。
ℹ笔记

从 Qt 5.0 开始，Qt 推荐使用 QXmlStreamReader 和 QXmlStreamWriter 类来解析和生成 XML。需要注意的是，这两个流处理类包含在 QtCore 核心模块中，而 DOM 和 SAX 基于树接口的类则依然保留在 QtXml 模块中。

一、 项目工程配置 #

要在项目中使用 QDomDocument 等 DOM 类，需要进行如下配置：

  1. 在 .pro 项目文件中添加：
    ini
    QT += xml
  2. 在头文件中包含对应的头：
    cpp
    #include <QDomDocument>
#include <QFile>
#include <QMessageBox>

三、 C++ 解析核心代码实现 #

下面是封装在解析类中，用于解析 XML 并获取节点属性和文本的 C++ 代码实现：

cpp
#include <QFile>
#include <QDomDocument>
#include <QDomElement>
#include <QDomNodeList>
#include <QDomNode>
#include <QMessageBox>
#include <QDebug>

void parseXML(QString file_name)  
{  
    if (file_name.isEmpty())  
        return;  
  
    QFile file(file_name);  
    if (!file.open(QFile::ReadOnly | QFile::Text)) {  
        QMessageBox::warning(nullptr, "Warning", "Open file error!");  
        return;  
    }  
  
    QDomDocument document;  
    QString error;  
    int row = 0, column = 0;  
    
    // 💡 1. 将文件内容读取并加载为内存中的 DOM 树
    if (!document.setContent(&file, false, &error, &row, &column)) {  
        QMessageBox::critical(nullptr, "Error", 
            QString("Parse file failed at line %1, col %2: %3")
            .arg(row).arg(column).arg(error));
        file.close();
        return;  
    }  
    file.close(); // 读取完毕，即可关闭文件句柄
  
    if (document.isNull()) {  
        QMessageBox::warning(nullptr, "Warning", "Document is null!");  
        return;  
    }  
  
    // 💡 2. 获取根元素 (即 <persons>)
    QDomElement root = document.documentElement();  
    QString root_tag_name = root.tagName(); // 返回 "persons"
    qDebug() << "Root Tag:" << root_tag_name;

    // 获取根元素的属性
    if (root.hasAttribute("name")) {  
        QString name = root.attribute("name"); // 返回 "Qt"
        qDebug() << "Root Attribute 'name':" << name;
    }  
       
    // 💡 3. 方法一：通过 firstChildElement 循环遍历子元素
    qDebug() << "\n--- Traversing via firstChildElement & nextSiblingElement ---";
    QDomElement person_element = root.firstChildElement("person");  
    while (!person_element.isNull()) {  
        QString id = person_element.attribute("id"); // 读取属性 "id"
        qDebug() << "Person ID:" << id;

        // 获取名下各标签的值
        QDomElement child = person_element.firstChildElement();
        while (!child.isNull()) {
            QString tag_name = child.tagName();     // 如 "name"、"age"
            QString tag_value = child.text();       // 对应的文本内容
            qDebug() << "  " << tag_name << ":" << tag_value;
            child = child.nextSiblingElement(); // 💡 移向同级的下一个兄弟节点
        }
        person_element = person_element.nextSiblingElement("person");  
    }  

    // 💡 4. 方法二：使用 QDomNodeList 批量索引遍历
    qDebug() << "\n--- Traversing via QDomNodeList ---";
    QDomNodeList list = root.childNodes(); // 获取所有的子节点列表
    int count = list.count();
    for (int i = 0; i < count; i++) {
        QDomNode dom_node = list.item(i);
        if (dom_node.isElement()) {
            QDomElement element = dom_node.toElement(); // 转化为元素对象
            QString id_val = element.attribute("id");
            qDebug() << "Node index" << i << ", ID:" << id_val;

            QDomNodeList child_list = element.childNodes();
            int child_count = child_list.count();
            for (int j = 0; j < child_count; j++) {
                QDomNode child_dom_node = child_list.item(j);
                if (child_dom_node.isElement()) {
                    QDomElement child_element = child_dom_node.toElement();
                    QString tag = child_element.tagName();
                    QString val = child_element.text();
                    qDebug() << "    " << tag << " => " << val;
                }
            }
        }
    }
}

四、 总结 #

  • 在处理小型 XML 文件时，QDomDocument 的使用由于树状映射的直观性而最受欢迎，配合 firstChildElement() 与 nextSiblingElement() 遍历结构非常方便。
  • 需要注意，nextSiblingElement() 支持传递指定的标签名（如 nextSiblingElement("person")），以便在兄弟节点中快速过滤同名元素。
