Qt调用Windows系统属性窗体（ShellExecuteEx） #

在开发文件管理器或资源浏览器类型的客户端应用时，有时需要直接弹出 Windows 系统原生的文件**"属性"对话框**——就是我们右键点击桌面文件时看到的那个系统级弹窗，显示了文件名、类型、位置、大小、创建日期、修改日期、安全权限等详细属性。

在 Qt 中没有直接提供这种接口，但我们可以利用 Win32 API ShellExecuteEx 函数，指定操作动词为 "properties" 来触发系统原生属性窗体。

一、 调用 ShellExecuteEx 弹出原生属性窗体 #

cpp
#include <windows.h>
#include <shellapi.h>

void showWindowsPropertiesDialog(const QString &filePath)
{
    // 将 Qt QString 转换为 Windows 宽字符 LPCWSTR
    std::wstring wFilePath = filePath.toStdWString();

    SHELLEXECUTEINFO shExecInfo;
    ZeroMemory(&shExecInfo, sizeof(shExecInfo));

    shExecInfo.cbSize       = sizeof(SHELLEXECUTEINFO);
    shExecInfo.fMask        = SEE_MASK_INVOKEIDLIST;   // 🔑 使用 IDList 以支持非文件路径目标（如控制面板项）
    shExecInfo.lpVerb       = L"properties";           // 操作动词：弹出属性窗体
    shExecInfo.lpFile       = wFilePath.c_str();       // 目标文件路径（宽字符）
    shExecInfo.lpParameters = L"";
    shExecInfo.lpDirectory  = NULL;
    shExecInfo.nShow        = SW_SHOW;
    shExecInfo.hInstApp     = NULL;

    ShellExecuteEx(&shExecInfo);
}

使用示例（弹出 regedit.exe 的属性） #

cpp
showWindowsPropertiesDialog(R"(C:\Windows\regedit.exe)");

二、 项目配置 #

由于 ShellExecuteEx 属于 Windows Shell 扩展，需要链接 shell32.lib。在 Qt .pro 文件中追加：

win32: LIBS += -lshell32

三、 替代方案：自定义属性展示窗体 #

如果需要在非 Windows 平台运行，或希望对属性显示内容进行高度自定义，可以通过 Qt 的 QFileInfo 读取文件元数据，在自定义 QDialog 中展示：

cpp
#include <QFileInfo>
#include <QDateTime>

void showCustomPropertiesDialog(const QString &filePath)
{
    QFileInfo info(filePath);

    QString details;
    details += QString("文件名：%1\n").arg(info.fileName());
    details += QString("类型：%1\n").arg(info.suffix().toUpper() + " 文件");
    details += QString("位置：%1\n").arg(info.absolutePath());
    details += QString("大小：%1 字节\n").arg(info.size());
    details += QString("创建时间：%1\n").arg(info.birthTime().toString("yyyy-MM-dd hh:mm:ss"));
    details += QString("最后修改：%1\n").arg(info.lastModified().toString("yyyy-MM-dd hh:mm:ss"));
    details += QString("只读：%1\n").arg(info.isReadable() && !info.isWritable() ? "是" : "否");

    QMessageBox::information(nullptr, "文件属性", details);
}
方式 平台支持 自定义度 实现复杂度
ShellExecuteEx("properties") Windows 专属 无（原生系统窗体） 极低
QFileInfo + 自定义 Dialog 跨平台 完全自由 中等
