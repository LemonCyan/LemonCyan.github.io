Qt连接MySQL远程数据库教程与QMYSQL驱动加载失败完美解决方案 #

在开发企业级客户端应用时，本地存储（如 SQLite）往往无法满足多端协同的需求，这时我们需要通过 Qt 连接局域网或云端服务器上的 MySQL 数据库。

Qt 提供了内置的 SQL 模块，通过统一的模型操作接口（QSqlDatabase / QSqlQuery）即可无缝对接 MySQL。

本文介绍 Qt 连接远程 MySQL 的基本代码，并针对高频报错 “QMYSQL driver not loaded” 给出彻底解决方案。

一、 Qt 连接 MySQL 核心代码 #

在开始前，请确保在你的项目 .pro 文件中引入了 sql 模块：

QT += sql

连接与数据查询示例： #

cpp
#include <QCoreApplication>
#include <QSqlDatabase>
#include <QSqlError>
#include <QSqlQuery>
#include <QDebug>

void connectAndQuery()
{
    // 1. 打印当前系统已装载并可用的数据库驱动
    qDebug() << "Available SQL Drivers:";
    QStringList drivers = QSqlDatabase::drivers();
    foreach(const QString &driver, drivers) {
        qDebug() << "  " << driver;
    }

    // 2. 初始化 QMYSQL 驱动连接
    // 💡 最佳实践：使用大写 "QMYSQL"
    QSqlDatabase db = QSqlDatabase::addDatabase("QMYSQL");
    db.setHostName("192.168.1.100"); // 远程数据库主机的 IP 地址
    db.setPort(3306);                // MySQL 默认端口
    db.setDatabaseName("gv_local");  // 数据库名
    db.setUserName("root");          // 用户名
    db.setPassword("root123");       // 密码

    // 3. 打开连接
    if (!db.open()) {
        qDebug() << "Failed to connect to database! Error details:" 
                 << db.lastError().text();
        return;
    }
    qDebug() << "Connect to MySQL successfully!";

    // 💡 防范中文乱码：设置客户端与服务端传输编码为 UTF-8
    db.exec("SET NAMES UTF8");

    // 4. 执行 SQL 查询
    QString sqlStr = "SELECT id, alarm_name FROM gv_alarm_info LIMIT 10;";
    QSqlQuery query;
    query.prepare(sqlStr);
    
    if (!query.exec()) {
        qDebug() << "SQL query failed:" << query.lastError().text();
    } else {
        // 5. 循环遍历结果集游标
        while (query.next()) {
            int id = query.value(0).toInt();
            QString name = query.value(1).toString();
            qDebug() << QString("ID: %1 | Alarm Name: %2").arg(id).arg(name);
        }
    }

    // 6. 关闭连接
    db.close();
}

二、 💡 解决 “QMYSQL driver not loaded” 报错 #

即使你在代码中正确引入了 sql 模块，运行程序时控制台也极大概率会报错：

QSqlDatabase: QMYSQL driver not loaded
QSqlDatabase: available drivers: QSQLITE QODBC QODBC3 QPSQL QPSQL7

❓ 产生原因： #

Qt 的 SQL 驱动（qsqlmysql.dll）只是一个“桥梁”，它的底层运行依然需要调用 MySQL 官方的客户端通信动态库（libmysql.dll）。 如果运行环境下找不到 libmysql.dll，Qt 就无法初始化 QMYSQL 驱动。

🔧 黄金解决方案： #

  1. 定位 libmysql.dll 文件：
    • 到你本地安装的 MySQL 服务端或客户端的 lib/ 目录下找到 libmysql.dll。
    • 如果没有安装 MySQL，可以去官方下载 MySQL Connector/C 的 Zip 压缩包，解压后在 lib/ 目录中提取该文件。
  2. 拷贝至 Qt 编译环境：
    • 将 libmysql.dll 拷贝到你的 Qt 安装编译链的 bin/ 目录中。
    • 例如：C:\Qt\Qt5.9.1\5.9.1\msvc2015_64\bin\
  3. 拷贝至运行软件目录：
    • 在软件打包发布时，需要将 libmysql.dll 复制到与你的可执行程序（.exe）同级目录下。
⚠警告

位数一致性陷阱：
拷贝的 libmysql.dll 其体系结构（32 位/64 位）必须与你当前 Qt 编译链的位数完全一致！

  • 如果你的 Qt Creator 选用的是 MinGW 32bit 编译器，你必须去寻找 32 位的 libmysql.dll。
  • 如果选用的是 MSVC 64bit，则必须对应 64 位的库，混合搭配会导致装载静默失败。

三、 进阶要点与防坑指南 #

1. 杜绝覆写连接警告（多数据库连接管理） #

如果不带参数直接调用 QSqlDatabase::addDatabase("QMYSQL")，系统会创建名为 qt_default_connection 的默认链接。如果代码在多处重复调用此行，Qt 会报错警告： duplicate connection name 'qt_default_connection', old connection was overwritten.

正确多链接声明方式：

cpp
// 💡 传入第二个参数指定连接名字
QSqlDatabase db = QSqlDatabase::addDatabase("QMYSQL", "log_db");
db.setHostName("...");
// ...

// 💡 其它类中通过连接名字获取该库实例，不用重复创建
QSqlDatabase dbLog = QSqlDatabase::database("log_db");

2. 避免连接卸载死锁 (removeDatabase) #

当你需要销毁数据库连接并调用 QSqlDatabase::removeDatabase("log_db") 时，如果此时作用域中还有 QSqlQuery 变量未被销毁，会造成连接死锁。

正确释放连接的方法：限制变量作用域

cpp
{
    QSqlDatabase db = QSqlDatabase::addDatabase("QMYSQL", "temp_db");
    // ... 连接并使用 ...
    QSqlQuery query(db);
    query.exec("...");
    db.close(); 
    // 💡 离开右括号，db 和 query 的生命周期结束，析构释放
}
// 💡 此时没有占用引用，可以安全移除连接
QSqlDatabase::removeDatabase("temp_db");
