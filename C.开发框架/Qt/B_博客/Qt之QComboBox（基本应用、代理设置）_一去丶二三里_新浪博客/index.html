Qt之QComboBox（基本应用、代理设置） #

QComboBox 下拉列表框是 Qt 界面开发中最常用的输入控件之一。在常规开发中，我们不仅要能够熟练地使用它进行基本的文本选择，还需要针对复杂的业务场景（例如 QQ 登录界面的多帐号记录与删除列表）设置自定义的代理视图（Delegate View）。

本文将分别介绍 QComboBox 的基本用法与自定义代理选项列表的深度开发。

一、 基本应用 #

1. 使用 QSS 样式表配置外观 #

默认的下拉列表高度通常过于局促，我们可以利用 QSS 调整下拉子控件的项高度、边框、以及下拉箭头图标：

cpp
QComboBox *network_type = new QComboBox(this);

// 💡 必须调用 setView(new QListView())，否则 QAbstractItemView::item 样式可能无法生效
network_type->setView(new QListView());

network_type->setStyleSheet(
    "QComboBox { border: 1px solid gray; }"
    "QComboBox QAbstractItemView::item { height: 20px; }" // 下拉选项行高
    "QComboBox::down-arrow { image: url(:/icon/arrowdown); }" // 下拉箭头图标
    "QComboBox::drop-down { border: 0px; }" // 隐藏自带的右侧分隔边框
);

2. 插入选项与附带数据 (UserData) #

addItem() 方法支持为每个文本关联一个自定义的 QVariant 数据，方便后续根据选中状态提取逻辑 ID。

cpp
typedef enum {
    PROXY_NONE,      // 没有代理
    PROXY_BROWSER,   // 浏览器代理
    PROXY_HTTP,      // HTTP代理
    PROXY_SOCKS4,    // SOCKS4代理
    PROXY_SOCKS5,    // SOCKS5代理 
} Proxy_Types;

// 插入显示文本及关联的自定义枚举值
network_type->addItem("no proxy", PROXY_NONE);
network_type->addItem("use browser", PROXY_BROWSER);
network_type->addItem("http", PROXY_HTTP);
network_type->addItem("socks4", PROXY_SOCKS4);
network_type->addItem("socks5", PROXY_SOCKS5);

3. 获取所选项与信号连接 #

当用户切换选项时，可以获取其索引值或附带的数据：

cpp
// 1. 获取当前关联的用户数据
Proxy_Types current_type = static_cast<Proxy_Types>(network_type->currentData().toInt());

// 2. 连接信号与槽
connect(network_type, QOverload<int>::of(&QComboBox::currentIndexChanged), this, &MyWidget::proxyChange);

二、 自定义下拉列表项代理组件 #

如果我们希望 QComboBox 下拉列表不仅显示文本，还能在每一行右侧带有一个“删除”小按钮（如图所示的用户登录帐号历史记录列表），就需要使用代理容器。

【 下拉项自定义布局示意 】
+------------------------------+
| 👤 safe_0@sina.com       [❌] | -> 点击 [❌] 可触发 removeAccount 信号
+------------------------------+

1. 编写自定义行 Widget 类 (AccountItem) #

每一个下拉项实际上是一个内含 QLabel（展示帐号）与 QPushButton（用于删除）的独立小 QWidget：

cpp
// AccountItem.h
#pragma once
#include <QWidget>
#include <QLabel>
#include <QPushButton>
#include <QHBoxLayout>
#include <QMouseEvent>

class AccountItem : public QWidget
{
    Q_OBJECT
public:
    explicit AccountItem(QWidget *parent = nullptr);
    void setAccountNumber(const QString &account_text);
    QString getAccountNumber() const;

signals:
    void showAccount(const QString &account);
    void removeAccount(const QString &account);

private slots:
    void onRemoveClicked();

protected:
    // 🔑 必须自定义鼠标点击事件，避免点击删除按钮时触发 QComboBox 整体的项选中
    void mousePressEvent(QMouseEvent *event) override;
    void mouseReleaseEvent(QMouseEvent *event) override;

private:
    QLabel *account_number_label;
    QPushButton *delete_button;
    bool is_mouse_press;
};

// AccountItem.cpp
AccountItem::AccountItem(QWidget *parent)
    : QWidget(parent), is_mouse_press(false)
{
    account_number_label = new QLabel(this);
    delete_button = new QPushButton(this);
    
    QPixmap delete_pixmap(":/loginDialog/delete");
    delete_button->setIcon(delete_pixmap);
    delete_button->setIconSize(delete_pixmap.size());
    delete_button->setStyleSheet("background: transparent; border: 0px;");
    
    connect(delete_button, &QPushButton::clicked, this, &AccountItem::onRemoveClicked);
    
    QHBoxLayout *layout = new QHBoxLayout(this);
    layout->addWidget(account_number_label);
    layout->addStretch();
    layout->addWidget(delete_button);
    layout->setContentsMargins(5, 5, 5, 5);
    layout->setSpacing(5);
    setLayout(layout);
}

void AccountItem::setAccountNumber(const QString &account_text) {
    account_number_label->setText(account_text);
}

QString AccountItem::getAccountNumber() const {
    return account_number_label->text();
}

void AccountItem::onRemoveClicked() {
    emit removeAccount(account_number_label->text());
}

void AccountItem::mousePressEvent(QMouseEvent *event) {
    if (event->button() == Qt::LeftButton) {
        is_mouse_press = true;
    }
}

void AccountItem::mouseReleaseEvent(QMouseEvent *event) {
    if (is_mouse_press) {
        emit showAccount(account_number_label->text());
        is_mouse_press = false;
    }
}

2. 将代理视图绑定到 QComboBox #

我们不能直接向 QComboBox 添加此组件，必须以 QListWidget 充当底层的 Model 和 View，并将 AccountItem 嵌入进去：

cpp
QComboBox *account_combo = new QComboBox(this);
QListWidget *list_widget = new QListWidget(this);

// 💡 1. 覆盖 QComboBox 默认的 Model 和 View
account_combo->setModel(list_widget->model());
account_combo->setView(list_widget);
account_combo->setEditable(true); // 设为可编辑状态

// 💡 2. 循环添加项并绑定自定义 Widget
for (int i = 0; i < 3; ++i) {
    AccountItem *account_item = new AccountItem(list_widget);
    account_item->setAccountNumber(QString("safe_%1@sina.com").arg(i));
    
    // 连接信号
    connect(account_item, &AccountItem::showAccount, this, &LoginDialog::showAccount);
    connect(account_item, &AccountItem::removeAccount, this, &LoginDialog::removeAccount);
    
    // 实例化一个标准的 list 项，然后用 setItemWidget 替换其渲染组件
    QListWidgetItem *list_item = new QListWidgetItem(list_widget);
    list_widget->setItemWidget(list_item, account_item);
}

3. 处理交互槽函数 #

当点击某项文字或执行删除时的槽函数逻辑：

cpp
// 用户选中了某一项
void LoginDialog::showAccount(const QString &account)
{
    account_combo->setEditText(account);
    account_combo->hidePopup(); // 关闭下拉框
}

// 用户点击了某项右侧的删除按钮
void LoginDialog::removeAccount(const QString &account)
{
    account_combo->hidePopup();
    
    // 弹出自定义提示框进行安全二次确认
    if (QMessageBox::question(this, "Remove Account", "Are you sure to remove account?") == QMessageBox::Yes) {
        int count = list_widget->count();
        for (int i = 0; i < count; ++i) {
            QListWidgetItem *item = list_widget->item(i);
            AccountItem *account_item = qobject_cast<AccountItem *>(list_widget->itemWidget(item));
            if (account_item && account_item->getAccountNumber() == account) {
                list_widget->takeItem(i); // 移出列表
                delete item; // 释放内存
                break;
            }
        }
    }
}

三、 避坑要点提示 #

  • 信号闪烁问题：如果采用 QListWidget 自带的 itemClicked() 或 itemPressed() 信号来实现行选中填空，会因为在调用 setEditText() 时触动了 QComboBox 的重复刷新事件，导致下拉弹出框产生一闪而过、无法关闭或点击无效的 Bug。因此，对于这种定制布局，强烈推荐在子项内使用 mouseReleaseEvent 拦截重写，以隔离点击穿透。
