Qt之内置控件与标准对话框中文本地化实现（QMessageBox、QLineEdit右键菜单） #

在开发 Qt 应用程序时，经常会遇到标准对话框（如 QMessageBox）的动作按钮（例如 Yes、No、Cancel）或者文本框（如 QLineEdit、QTextEdit）在右键点击时弹出的快捷上下文菜单显示为英文的问题。

很多开发者为了解决右键菜单为英文的不足，会粗暴地选择使用 setContextMenuPolicy(Qt::NoContextMenu) 直接关闭右键菜单。然而在常规文本录入区，这会极大地损害用户体验。

实际上，解决这个问题极其简单：我们只需要加载 Qt 官方为内置控件和对话框预置的中文翻译包即可。

一、 汉化步骤 #

1. 复制官方翻译 QM 文件 #

从你本机的 Qt 安装路径中，找到自带的标准中文翻译文件 qt_zh_CN.qm。

  • 路径参考：C:\Qt\Qt5.2.0\5.2.0\msvc2010\translations\qt_zh_CN.qm (根据你实际安装的套件版本进行定位)

将该 .qm 文件复制到你的项目源码目录下。

2. 编写资源配置文件 (QRC.qrc) #

为了避免用户安装后由于文件缺失导致汉化失效，应将该翻译文件直接编入可执行程序资源包中：

xml
<RCC>
    <qresource prefix="/qm">
        <file>qt_zh_CN.qm</file>
    </qresource>
</RCC>

3. 在 main.cpp 中用 QTranslator 动态装载 #

在 main() 入口函数中，创建 QTranslator 对象，加载该资源路径，并注册到全局的 QApplication 中：

cpp
#include <QApplication>
#include <QTranslator>
#include <QTextCodec>
#include "MainWindow.h"

int main(int argc, char *argv[])
{
    QApplication app(argc, argv);

    // 💡 针对 Qt 4.x 版本的编码设置（若使用 Qt5 及更高版本，可忽略此编码段）
#if QT_VERSION < QT_VERSION_CHECK(5, 0, 0)
    QTextCodec *codec = QTextCodec::codecForName("System"); // 获取系统本地编码 (如 Windows 下的 GBK)
    QTextCodec::setCodecForLocale(codec);
    QTextCodec::setCodecForTr(codec);
    QTextCodec::setCodecForCStrings(codec);
#endif

    // 💡 核心步骤：加载内置控件的中文汉化翻译包
    QTranslator translator; 
    // load 第一个参数填写资源文件名（不加后缀），第二个参数为前缀目录
    if (translator.load("qt_zh_CN", ":/qm"))
    {
        app.installTranslator(&translator); 
    }
    else
    {
        qWarning() << "Failed to load translation file: qt_zh_CN";
    }

    MainWindow w;
    w.show();  

    return app.exec();
}

二、 💡 补充技巧：如何将官方翻译的 .ts 编译为 .qm #

有时在 Qt 安装路径下，你只能找到源码形式的翻译文件 qt_zh_CN.ts，而没有编译好的二进制 qt_zh_CN.qm。此时你可以利用 Qt 命令行工具快速生成：

  1. 打开 Qt 对应的命令行终端（例如 Qt 5.x.x (MSVC 2012) Command Prompt）。
  2. 使用 lrelease 编译器指令进行生成：
    bash
    lrelease qt_zh_CN.ts -qm qt_zh_CN.qm
  3. 或者使用 Linguist (Qt语言家) 界面程序打开该 qt_zh_CN.ts 文件，选择菜单栏 File -> Release，即可在同级目录下输出 qt_zh_CN.qm。
