Qt使用QAxObject读写操作Excel文件完全指南（COM接口） #

在工业软件或企业管理系统中，经常需要导出或导入 Excel 报表。在 Windows 平台下，Qt 提供了 ActiveQt 模块，可以通过 QAxObject 封装的 COM 组件接口 直接操纵底层的 Office/Excel 进程。这本质上是利用 Qt C++ 去调用 Excel 的 VBA (Visual Basic for Applications) 宏语言接口。

本文总结了 Qt 操作 Excel 各种常见场景（包含单元格读写、工作表增删、排版对齐、颜色配置、合并拆分单元格等）的代码实现。

一、 项目工程配置 #

要在项目中使用 QAxObject 容器，必须在 Qt .pro 配置文件中添加 axcontainer 模块支持（该模块仅限 Windows 平台有效）：

# 在项目 .pro 文件中追加
QT += axcontainer

在需要操作 Excel 的 C++ 源文件头部引入对应的头文件：

cpp
#include <QAxObject>
#include <QDebug>
#include <QColor>

二、 读取已存在的 Excel 数据 #

下面演示如何打开一个已有文件，读取工作表数量、各工作表名称，并通过 UsedRange（已使用区域）自动计算数据的行列边界，遍历读取所有单元格内容。

cpp
void readExcel(const QString &filePath)
{
    // 1. 关联 Excel 进程（要求运行机器必须安装了 Microsoft Excel 或兼容的 WPS）
    QAxObject excel("Excel.Application");
    
    // 设置 Excel 界面是否可见（调试阶段设为 true 方便观察，后台静默处理设为 false）
    excel.setProperty("Visible", false);

    // 2. 打开工作簿集合并打开目标文件
    QAxObject *workbooks = excel.querySubObject("Workbooks");
    QAxObject *workbook = workbooks->querySubObject("Open(const QString&)", filePath);
    if (!workbook) {
        qWarning() << "Failed to open Excel file:" << filePath;
        excel.dynamicCall("Quit()");
        return;
    }

    // 3. 获取所有工作表（Sheets）
    QAxObject *sheets = workbook->querySubObject("Sheets");
    int sheetCount = sheets->property("Count").toInt(); // 获取 Sheet 数量
    qDebug() << "Total worksheets:" << sheetCount;

    // 遍历获取所有 Sheet 的名字
    for (int i = 1; i <= sheetCount; i++) {
        QAxObject *sheet = workbook->querySubObject("Sheets(int)", i);
        QString sheetName = sheet->property("Name").toString();
        qDebug() << QString("Sheet %1 Name: %2").arg(i).arg(sheetName);
    }

    // 4. 读取第一个 Sheet 的有效数据范围
    if (sheetCount > 0) {
        QAxObject *sheet = workbook->querySubObject("Sheets(int)", 1);
        QAxObject *usedRange = sheet->querySubObject("UsedRange");
        
        // 获取有效数据区域的起始边界与行数、列数
        int startRow    = usedRange->property("Row").toInt();
        int startColumn = usedRange->property("Column").toInt();
        
        QAxObject *rows = usedRange->querySubObject("Rows");
        QAxObject *cols = usedRange->querySubObject("Columns");
        int rowCount    = rows->property("Count").toInt();
        int colCount    = cols->property("Count").toInt();

        // 遍历所有行列单元格并读取值
        // ⚠️ 注意：Excel VBA 的坐标索引均从 1 开始
        for (int r = startRow; r < startRow + rowCount; r++) {
            for (int c = startColumn; c < startColumn + colCount; c++) {
                QAxObject *cell = sheet->querySubObject("Cells(int,int)", r, c);
                QVariant cellValue = cell->property("Value"); // 读取单元格数值
                qDebug() << QString("Row[%1], Col[%2]:").arg(r).arg(c) << cellValue.toString();
            }
        }
    }

    // 5. 关闭 Workbook 并不保存修改，退出 Excel 进程
    workbook->dynamicCall("Close(Boolean)", false);
    excel.dynamicCall("Quit()");
}

三、 新增、修改并排版 Excel 文件 #

下面演示如何动态操作 Excel 单元格，调整列宽行高，配置字体字号，设置单元格背景色、对齐方式以及合并单元格的操作：

cpp
void createAndStyleExcel(const QString &savePath)
{
    QAxObject excel("Excel.Application");
    excel.setProperty("Visible", true); // 展示 Excel 前台窗口

    QAxObject *workbooks = excel.querySubObject("Workbooks");
    
    // 打开一个已有模板或者新建一个 Workbook
    QAxObject *workbook = workbooks->querySubObject("Open(const QString&)", savePath);
    QAxObject *sheets = workbook->querySubObject("Sheets");

    // 1. 删除第一个 Sheet
    QAxObject *firstSheet = sheets->querySubObject("Item(int)", 1);
    firstSheet->dynamicCall("delete");

    // 2. 插入新工作表至最后一行
    int sheetCount = sheets->property("Count").toInt();
    QAxObject *lastSheet = sheets->querySubObject("Item(int)", sheetCount);
    // 新增工作表
    QAxObject *newSheet = sheets->querySubObject("Add(QVariant)", lastSheet->asVariant());
    // 移动到最后
    lastSheet->dynamicCall("Move(QVariant)", newSheet->asVariant());
    newSheet->setProperty("Name", "Qt Customized Sheet");

    // 3. 定位并编辑指定单元格 (第 2 行第 2 列)
    QAxObject *cell = newSheet->querySubObject("Cells(int,int)", 2, 2);
    cell->setProperty("Value", "Qt & VBA Excel Report");
    cell->setProperty("RowHeight", 40);   // 设置行高
    cell->setProperty("ColumnWidth", 30);  // 设置列宽

    // 4. 设置单元格对齐方式 (VBA 常数 xlCenter = -4108)
    cell->setProperty("HorizontalAlignment", -4108); // 水平居中
    cell->setProperty("VerticalAlignment", -4108);   // 垂直居中
    cell->setProperty("WrapText", true);             // 文本过多时自动换行

    // 5. 设置背景色 (Interior) 与边框色 (Borders)
    QAxObject *interior = cell->querySubObject("Interior");
    interior->setProperty("Color", QColor(220, 245, 220)); // 淡绿色背景
    
    QAxObject *borders = cell->querySubObject("Borders");
    borders->setProperty("Color", QColor(0, 0, 255));      // 蓝色细边框

    // 6. 配置字体样式 (Font)
    QAxObject *font = cell->querySubObject("Font");
    font->setProperty("Name", QStringLiteral("微软雅黑"));
    font->setProperty("Size", 14);                // 字号 14
    font->setProperty("Bold", true);              // 加粗
    font->setProperty("Italic", false);           // 不倾斜
    font->setProperty("Underline", 0);            // 无下划线 (1=单下划线, 2=双下划线)
    font->setProperty("Color", QColor(255, 0, 0)); // 红色字体

    // 7. 合并单元格 (例如合并第 5 行第 3 列 [C5] 至 第 8 行第 5 列 [E8])
    // 坐标计算：3列->C，5列->E
    QString rangeText = "C5:E8";
    QAxObject *mergeRange = newSheet->querySubObject("Range(const QString&)", rangeText);
    mergeRange->setProperty("Value", "Merged Content Area");
    mergeRange->setProperty("HorizontalAlignment", -4108);
    mergeRange->setProperty("VerticalAlignment", -4108);
    mergeRange->setProperty("MergeCells", true); // 执行合并 (若拆分设为 false)

    // 8. 另存并退出
    workbook->dynamicCall("SaveAs(const QString&)", "E:\\StyledReport.xlsx");
    workbook->dynamicCall("Close(Boolean)", true);
    excel.dynamicCall("Quit()");
}

四、 对齐方式与下划线宏定义速查表 #

在使用 setProperty 配置格式时，VBA 中定义的命名枚举常数通常需要我们直接填入对应的数值代码：

1. 水平对齐方式 (HorizontalAlignment) #

选项 VBA 枚举常数 填充数值 说明
居左 xlLeft -4131 文字靠左对齐
居中 xlCenter -4108 文字水平居中
居右 xlRight -4152 文字靠右对齐

2. 垂直对齐方式 (VerticalAlignment) #

选项 VBA 枚举常数 填充数值 说明
置顶 xlTop -4160 靠单元格顶部
居中 xlCenter -4108 垂直居中对齐
置底 xlBottom -4107 靠单元格底部

3. 下划线类型 (Underline) #

  • 0：无下划线
  • 2：单下划线 (xlUnderlineStyleSingle)
  • -4119：双下划线 (xlUnderlineStyleDouble)
