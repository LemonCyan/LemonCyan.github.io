QML之快速入门（二）变换、定位、布局与输入元素 #

在前文中，我们探讨了 QML 的基本语法与属性绑定机制。本文将进一步展开讨论 QML 中的图形变换（几何变化）、四大元素定位器、锚点（anchors）布局以及键盘/文本输入元素与焦点控制域。

一、 简单变换 (Transformations) #

QML 中的视觉项目（Item 的子类）都可以被平移、旋转和缩放。

qml
// ClickableImage.qml - 简单封装的可点击图片组件
import QtQuick 2.0

Image {
    id: root
    signal clicked
    MouseArea {
        anchors.fill: parent
        onClicked: root.clicked()
    }
}

在以下主文件中，三枚火箭在被点击时会执行不同的变换效果：

qml
// transformation.qml
import QtQuick 2.0

Item {
    id: root
    width: bg.width; height: bg.height

    Image {
        id: bg
        source: "assets/background.png"
    }

    MouseArea {
        id: backgroundClicker
        anchors.fill: parent
        onClicked: {
            // 重置场景状态
            rocket1.x = 20
            rocket2.rotation = 0
            rocket3.rotation = 0
            rocket3.scale = 1.0
        }
    }

    // 1. 平移变化：通过修改 x, y 轴坐标实现
    ClickableImage {
        id: rocket1
        x: 20; y: 100
        source: "assets/rocket.png"
        onClicked: x += 5
    }

    // 2. 旋转变化：修改 rotation 属性 (0 到 360)
    ClickableImage {
        id: rocket2
        x: 140; y: 100
        source: "assets/rocket.png"
        smooth: true // 开启平滑抗锯齿，防止边界锯齿化
        onClicked: rotation += 5
    }

    // 3. 缩放与旋转复合变化：修改 scale 属性 (< 1 为缩小，> 1 为放大)
    ClickableImage {
        id: rocket3
        x: 240; y: 100
        source: "assets/rocket.png"
        smooth: true
        onClicked: {
            rotation += 5
            scale -= 0.05
        }
    }
}
ℹ笔记
  • 渲染与几何尺寸：改变 rotation 或 scale 属性只会影响最终画面的渲染外观，并不会真正改变项目的 x、y 以及 width / height 逻辑像素尺寸。
  • 叠加顺序 (Z-Order)：QML 代码中后面声明的元素默认拥有更高的 Z 值，会覆盖在先写的元素之上。可以通过显式设置 z 属性来改变叠加深度。同时，MouseArea 的层级重合会导致顶层 MouseArea 优先吞噬鼠标点击事件。
  • 抗锯齿：在进行旋转或缩放时，建议设置 smooth: true 开启过滤抗锯齿，这能明显消除像素边缘的光栅锯齿，但会略微占用一点渲染性能。

二、 定位元素 (Positioning Elements) #

QtQuick 提供了四种定位器，用于将子元素以特定规则在屏幕中排布：

1. Column (列定位) #

将子项从上到下依次纵向垂直排列，支持通过 spacing 设定行间距：

qml
Column {
    anchors.centerIn: parent
    spacing: 8
    RedSquare {}
    GreenSquare { width: 96 } // 各子项宽度可以不一致
    BlueSquare {}
}

2. Row (行定位) #

将子项从左向右（或取决于 layoutDirection 的右到左）横向水平排布：

qml
Row {
    anchors.centerIn: parent
    spacing: 20
    BlueSquare {}
    GreenSquare {}
    RedSquare {}
}

3. Grid (网格定位) #

将子项排列在二维网格矩阵中。通过设定 rows 和 columns 来控制行列数：

qml
Grid {
    rows: 2; columns: 2
    anchors.centerIn: parent
    spacing: 8
    RedSquare {}
    RedSquare {}
    RedSquare {}
    RedSquare {}
}

4. Flow (流式定位) #

子项会沿水平或垂直方向排列，一旦超出定位器设定的宽高边界，会自动发生折行或折列。

qml
Flow {
    anchors.fill: parent
    anchors.margins: 20
    spacing: 20
    RedSquare {}
    BlueSquare {}
    GreenSquare {}
}

5. 配合 Repeater 重复创建 #

Repeater 相当于 QML 中的循环渲染机制。它可以配合定位器快速克隆模板子元素：

qml
Grid {
    anchors.fill: parent
    spacing: 4
    Repeater {
        model: 16 // 循环生成 16 个格子
        Rectangle {
            width: 56; height: 56
            color: "blue"
            Text {
                anchors.centerIn: parent
                text: "Cell " + index // 隐式导出当前循环的索引号值 index
            }
        }
    }
}

三、 布局项目：锚布局 (Anchors Layout) #

锚点布局是 QML 中最为核心且十分灵活的布局方式。每个元素具有 6 条虚拟的锚线：top、bottom、left、right、horizontalCenter、verticalCenter，对于文本元素还多出一条 baseline（文字底线）。

以下展示六种最常用的锚点约束方式：

graph LR
    A[fill: parent] --> B[全铺占满父窗口，常加 margins 留白]
    C[left: parent.left] --> D[左对齐到父窗口左边缘，可用 leftMargin 微调]
    E[left: sibling.right] --> F[排列在相邻节点的右侧]
    G[horizontalCenter: parent.horizontalCenter] --> H[水平居中对齐]
    I[centerIn: parent] --> J[完全水平和垂直中央对齐]
    K[verticalCenter: parent.verticalCenter] --> L[垂直居中对齐]

锚点对齐实例代码 #

qml
// 1. 铺满父容器并留白 8 像素
anchors.fill: parent
anchors.margins: 8

// 2. 左边缘对齐并偏离 8 像素
anchors.left: parent.left
anchors.leftMargin: 8

// 3. 紧靠在兄弟节点的右边
anchors.left: parent.right

// 4. 以兄弟节点 blue1 为基准垂直排列并水平居中
anchors.top: blue1.bottom
anchors.topMargin: 4
anchors.horizontalCenter: blue1.horizontalCenter

// 5. 绝对居中于父窗体
anchors.centerIn: parent

// 6. 水平居中且左偏 12 像素，同时垂直绝对居中
anchors.horizontalCenter: parent.horizontalCenter
anchors.horizontalCenterOffset: -12
anchors.verticalCenter: parent.verticalCenter

四、 输入元素与焦点控制 #

1. TextInput (单行文本输入) #

允许输入单行文字，提供了 validator (验证器) 和 inputMask (掩码输入) 等属性限制输入格式。

我们可以通过 KeyNavigation 附加属性非常方便地用键盘的 Tab 键切换组件焦点：

qml
TextInput {
    id: input1
    focus: true // 初始获取焦点
    text: "Text Input 1"
    KeyNavigation.tab: input2 // 按 Tab 键跳转到 input2
}
TextInput {
    id: input2
    text: "Text Input 2"
    KeyNavigation.tab: input1 // 按 Tab 键跳回 input1
}

2. 焦点控制的重难点：FocusScope (焦点范围) #

如果我们要将 TextInput 加上背景框，封装成一个独立的、可复用的组件 TLineEdit：

qml
// ❌ 错误示范：TLineEditV1.qml (使用 Rectangle 为根元素)
import QtQuick 2.0
Rectangle {
    width: 96; height: input.height + 8
    color: "lightsteelblue"; border.color: "gray"
    property alias text: input.text
    property alias input: input

    TextInput {
        id: input
        anchors.fill: parent; anchors.margins: 4
        focus: true // 虽然这里设为了 true，但在组件外部实例化时焦点无法传递给内部的 input
    }
}

问题现象：当我们实例化两个 TLineEditV1 组件并用键盘 Tab 键导航切换时，会发现焦点卡住，不会进入内部的 TextInput。因为当外部组件获得焦点时，它被卡在了最顶级的 Rectangle 上，而 Rectangle 无法自动将焦点转发给其内部子元素。

解决办法：使用 FocusScope 作为自定义输入组件的根元素！

qml
//  正确示范：TLineEditV2.qml (使用 FocusScope 作为根元素)
import QtQuick 2.0

FocusScope {
    width: 96; height: input.height + 8
    property alias text: input.text
    property alias input: input

    Rectangle {
        anchors.fill: parent
        color: "lightsteelblue"; border.color: "gray"
    }

    TextInput {
        id: input
        anchors.fill: parent; anchors.margins: 4
        focus: true // 启用 focusScope 后，顶级容器获得焦点会自动下发给 focus 设定为 true 的那个子节点
    }
}

使用 FocusScope 之后，外部通过 Tab 切换焦点或者调用组件的 focus: true 就能顺利传递到文本框内部了。

3. TextEdit (多行文本编辑) #

与 TextInput 类似，支持多行文本。可以通过 paintedWidth 和 paintedHeight 获取在渲染当前长文本时的像素物理尺寸。

我们也应当将其包裹在 FocusScope 内以支持良好的组件复用：

qml
// TTextEdit.qml
import QtQuick 2.0

FocusScope {
    width: 96; height: 96
    Rectangle {
        anchors.fill: parent
        color: "lightsteelblue"; border.color: "gray"
    }
    property alias text: input.text
    TextEdit {
        id: input
        anchors.fill: parent; anchors.margins: 4
        focus: true
    }
}

4. Keys 键盘按键事件绑定 #

通过在获得焦点的元素上添加 Keys.on<KeyName>Pressed 附加属性，可以直接捕获键盘物理按键动作：

qml
DarkSquare {
    width: 400; height: 200
    
    GreenSquare {
        id: square
        x: 8; y: 8
    }

    focus: true // 开启焦点以便接收按键事件
    
    // 监听方向键控制绿色正方形移动
    Keys.onLeftPressed: square.x -= 8
    Keys.onRightPressed: square.x += 8
    Keys.onUpPressed: square.y -= 8
    Keys.onDownPressed: square.y += 8
    
    // 监听加减号进行图形缩放
    Keys.onPressed: {
        switch(event.key) {
            case Qt.Key_Plus:
                square.scale += 0.2
                break;
            case Qt.Key_Minus:
                square.scale -= 0.2
                break;
        }
    }
}
