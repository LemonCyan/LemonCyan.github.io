Qt之qSort常用容器排序算法与结构体多字段排序 #

在 Qt 应用程序开发中，对 QList、QVector 等序列式容器中的数据进行排序是一项极其普遍的需求。Qt 为我们提供了一个非常便捷的模板排序函数 qSort()。

ℹ笔记

关于 C++11 标准与现代 Qt 的兼容性说明： qSort 是基于快速排序算法实现的模板函数。从 Qt 5.0 开始，官方建议在使用 C++11 及以上编译器时，优先使用标准库的 std::sort() 替代 qSort()，因为它们在效率和规范上完全一致。不过，了解 qSort 的用法和编写比较函数（Comparator）的逻辑依然是阅读老项目代码和编写排序逻辑的必备基础。

下面我们将由浅入深，分别讲解如何使用 qSort() 进行 基础整型排序、忽略大小写字符串排序 以及 复杂的自定义结构体多字段关联排序。

一、 基础数据类型升序排序 #

若容器内是 int、double、QString 等内置基础类型，可以直接调用 qSort()，它默认会采用小于号 < 运算符进行升序排列。

cpp
#include <QList>
#include <qalgorithms.h> // qSort 所在头文件

void sortIntegers()
{
    QList<int> list;
    list << 33 << 12 << 68 << 6 << 12;

    // 默认执行升序排序
    qSort(list.begin(), list.end());
    
    // 输出结果: [ 6, 12, 12, 33, 68 ]
}

二、 忽略大小写字符串排序 (自定义 Comparator) #

如果默认的 ASCII 小于号比较不满足要求（例如需要忽略大小写来排列英文字符串），我们可以编写一个自定义的全局比较函数，并将其作为第三个参数传递给 qSort()。

cpp
#include <QStringList>
#include <qalgorithms.h>

// 💡 比较函数规范：返回值为 bool，入参为两个待比较项的常引用
bool caseInsensitiveLessThan(const QString &s1, const QString &s2)
{
    return s1.toLower() < s2.toLower();
}

void sortStrings()
{
    QStringList list;
    list << "AlPha" << "beTA" << "gamma" << "DELTA";

    // 传入自定义的大小写不敏感比较规则
    qSort(list.begin(), list.end(), caseInsensitiveLessThan);
    
    // 输出结果: [ "AlPha", "beTA", "DELTA", "gamma" ]
}

三、 自定义结构体多字段排序 (多级排序优先级) #

在业务报表中，我们往往需要对结构体列表进行复合排序。例如：

  • 结构体代表钢筋属性，包含“钢筋级别（barLevel）”和“钢筋直径（diameter）”。
  • 第一排序键：按“钢筋级别”由小到大（升序）排序。
  • 第二排序键：如果级别相同，则比对“钢筋直径”来进行次级排序。

1. 结构体与比较函数定义 #

cpp
// 钢筋计划量结构体
struct BarAmount
{
    int barLevel;           // 钢筋级别 (如: 1, 2, 3)
    QString diameter;       // 钢筋直径描述 (如: "12-菱", "14")
    double planAmount;      // 计划量
    double purchaseAmount;  // 采购量
    double amount;          // 总量
};

// 预定义一个辅助字符串对比函数
int compareDiameterDescription(const QString &d1, const QString &d2);

// 自定义多级比较逻辑
bool compareBarData(const BarAmount &bar1, const BarAmount &bar2)
{
    // 1. 先比对第一优先级：钢筋级别
    if (bar1.barLevel < bar2.barLevel)
    {
        return true;  // bar1 排在前面
    }
    else if (bar1.barLevel > bar2.barLevel)
    {
        return false; // bar2 排在前面
    }
    else
    {
        // 2. 如果级别完全相同，进入第二优先级：直径对比
        int compareResult = compareDiameterDescription(bar1.diameter, bar2.diameter);
        if (compareResult == -1)
        {
            return true;
        }
        else if (compareResult == 1)
        {
            return false;
        }
        else
        {
            return true; // 属性一致，维持原有相对顺序
        }
    }
}

2. 执行容器排序 #

cpp
// 在控制器类中对数据列表执行多级排定
void OverdraftControl::sortBarData(QList<BarAmount> *barDataList)
{
    if (barDataList == nullptr || barDataList->isEmpty())
        return;

    // 调用 qSort 并绑定结构体专用比较回调
    qSort(barDataList->begin(), barDataList->end(), compareBarData);
}

四、 现代替代方案：std::sort #

如果你的项目采用 C++11 及以上编译器，建议直接使用 <algorithm> 头文件中的 std::sort。它的传参结构和写法与 qSort 完全一致，且消除了旧版 Qt 宏带来的不确定性。

cpp
#include <algorithm> // 引入标准库排序头文件

void modernSortBarData(QList<BarAmount> &barDataList)
{
    // 用 std::sort 代替 qSort
    std::sort(barDataList.begin(), barDataList.end(), compareBarData);
}

通过编写结构体比较器，无论是按多重属性排序还是按升降序排列，都能非常方便且高效地对内存数据完成对齐。
