Qt之获取本地主机网络配置信息（IP、MAC、子网掩码） #

在很多网络应用程序的开发中，我们常常需要收集本地的配置环境。例如获取本机 IP 用于创建 Socket 监听、查询 MAC 地址用于安全授权与物理定位、或者获取本地用户名和主机名进行日志标定。

在 Windows 命令行下，我们可以通过执行 ipconfig /all 打印这些信息。而在 Qt 中，我们则可以直接使用 QtNetwork 模块提供的四大核心类来低成本地实现上述需求：

  • QHostInfo：查询主机名及 DNS 关联解析。
  • QHostAddress：封装并表示 IPv4 和 IPv6 物理地址。
  • QNetworkInterface：提供本机物理/虚拟网卡（网络接口）的列表。
  • QNetworkAddressEntry：封装网卡的 IP 地址、掩码与广播网段三元组。

一、 项目前置配置 #

网络套接字相关的 API 属于 Qt 的 network 子模块。在使用前，需要在项目配置文件中引入该模块：

1. 修改 .pro 文件 #

QT += network

2. 引入头文件 #

cpp
#include <QHostInfo>
#include <QHostAddress>
#include <QNetworkInterface>
#include <QNetworkAddressEntry>

二、 获取本地系统登录用户名 #

可以通过 Qt 提供的高效环境变量抓取宏 qgetenv 轻松获取本机的登录用户名：

cpp
// Windows 平台使用 "USERNAME"，Linux/MacOS 平台通常使用 "USER"
QString userName = qgetenv("USERNAME");
if (userName.isEmpty())
{
    userName = qgetenv("USER");
}
qDebug() << "User Name:" << userName; 
// 输出: User Name: "wangl-d"

三、 获取主机名与 IP 地址列表 (QHostInfo) #

QHostInfo 能够直接捕获本地注册的主机名称，并通过本机 DNS 系统查找绑定的 IP 列表。

cpp
// 1. 获取本地主机名
QString localHostName = QHostInfo::localHostName();
qDebug() << "Local Host Name:" << localHostName;
// 输出: Local Host Name: "wangl-d-pc"

// 2. 根据主机名查询关联 IP 列表
QHostInfo info = QHostInfo::fromName(localHostName);
qDebug() << "All Bind Addresses:" << info.addresses();

// 3. 过滤提取出 IPv4 地址
foreach (QHostAddress address, info.addresses())
{
    if (address.protocol() == QAbstractSocket::IPv4Protocol)
    {
        qDebug() << "IPv4 Address:" << address.toString();
        // 输出: IPv4 Address: "192.168.118.55"
    }
}
✦提示

如果不需要通过主机名进行网络解析，只想直接得到本机网卡上的所有 IP，可以直接使用 QNetworkInterface::allAddresses() 静态接口，它会立即拉取包括回环地址（127.0.0.1、::1）在内的全部网络地址：

cpp
foreach (QHostAddress address, QNetworkInterface::allAddresses())
{
    qDebug() << "Address:" << address.toString();
}

四、 遍历物理网卡获取 MAC、子网掩码与广播地址 (QNetworkInterface) #

由于一台机器上可能装有多个物理网卡（如无线 Wi-Fi、双以太网口），或是运行有虚拟机软件创建的虚拟网卡，我们可以遍历 QNetworkInterface::allInterfaces() 来细化获取每个网卡的详细硬件与网域配制。

cpp
void queryLocalInterfaces()
{
    // 获取所有的网络接口列表
    QList<QNetworkInterface> interfaceList = QNetworkInterface::allInterfaces();
    
    foreach (QNetworkInterface netInterface, interfaceList)
    {
        // 判定网卡是否处于活跃（工作）状态，避开断开连接的网卡
        if (!netInterface.flags().testFlag(QNetworkInterface::IsUp))
            continue;
            
        // 1. 打印设备名与硬件 MAC 地址
        qDebug() << "Device Name:" << netInterface.name();       // 接口标识 uuid 或 eth0
        qDebug() << "Display Name:" << netInterface.humanReadableName(); // 设备友好名称
        qDebug() << "MAC Address:" << netInterface.hardwareAddress();    // 物理 MAC
        
        // 2. 遍历该网卡下绑定的所有 IP 地址三元组 (IP, Netmask, Broadcast)
        QList<QNetworkAddressEntry> entryList = netInterface.addressEntries();
        
        foreach (QNetworkAddressEntry entry, entryList)
        {
            // 过滤 IPv4 网段做详细展示
            if (entry.ip().protocol() == QAbstractSocket::IPv4Protocol)
            {
                qDebug() << "  IP Address:" << entry.ip().toString();
                qDebug() << "  Netmask:   " << entry.netmask().toString();   // 子网掩码
                qDebug() << "  Broadcast: " << entry.broadcast().toString(); // 广播地址
            }
            else if (entry.ip().protocol() == QAbstractSocket::IPv6Protocol)
            {
                qDebug() << "  IPv6 Address:" << entry.ip().toString();
            }
        }
        qDebug() << "-----------------------------------------------";
    }
}
