Qt实现网络播放器 #

在 Qt 应用开发中，网络通信与多媒体播放是两个非常基础且实用的功能。本篇博客将通过调用公开的音乐 API（以百度音乐 API 为例），演示如何使用 Qt 中的 QNetworkAccessManager 发送网络请求、使用 JSON 系列类解析响应数据，以及使用 QMediaPlayer 实现在线音乐试听与歌词下载。

一、 网络播放器实现流程 #

要实现一个支持在线搜索与点播的音乐播放器，一般经历以下四个步骤：

graph TD
    A[用户输入关键字] -->|QNetworkAccessManager GET| B[调用音乐搜索 API]
    B -->|获取 JSON 响应数据| C[解析 JSON 获取歌曲列表及 ID]
    C -->|QNetworkAccessManager GET| D[通过歌曲 ID 请求音频真实下载链接与歌词 URL]
    D -->|QMediaPlayer 加载链接| E[在线播放音频 / 下载 lrc 歌词]

1. 查找歌曲（调用搜索接口） #

  • 接口地址：http://mp3.baidu.com/dev/api/?tn=getinfo&ct=0&ie=utf-8&word=&format=
  • 请求方式：GET
  • 参数说明：
    • word：填写搜索的歌曲名或歌手名。
    • format：返回的数据格式，本例选择 json。

2. 获取歌曲音频链接与歌词 #

  • 接口地址：http://ting.baidu.com/data/music/links?songIds=
  • 参数说明：
    • songIds：传入上一步中解析到的歌曲 ID（song_id）。
  • 返回结果：返回音频文件的播放/下载源链接（songLink）以及歌词文件链接（lrcLink）。

二、 核心代码实现 #

1. 发起网络搜索请求 #

通过 QNetworkAccessManager 向服务器异步提交 GET 请求。

cpp
#include <QNetworkAccessManager>
#include <QNetworkRequest>
#include <QNetworkReply>

#define MP3_URL "http://mp3.baidu.com/dev/api/?"

void HttpManager::searchMusic(const QString &keyword)
{
    // 构造请求参数
    QByteArray queryParams;
    queryParams.append("tn=getinfo");
    queryParams.append("&ct=0");
    queryParams.append("&ie=utf-8");
    queryParams.append("&word=" + keyword); // 输入的歌手或歌名
    queryParams.append("&format=json");

    QString url = QString(MP3_URL) + QString(queryParams);

    QNetworkAccessManager *network_manager = new QNetworkAccessManager(this);
    QNetworkRequest network_request;
    
    // 绑定请求完成的槽函数
    connect(network_manager, &QNetworkAccessManager::finished, 
            this, &HttpManager::replyFinished);
            
    network_request.setUrl(QUrl(url));
    network_manager->get(network_request); // 发送异步 GET 请求
}

2. 接收响应数据并解析 JSON #

当请求完成后，触发槽函数，读取接收到的全部字节并转换为 JSON 对象处理。

cpp
#include <QJsonDocument>
#include <QJsonObject>
#include <QJsonArray>

void HttpManager::replyFinished(QNetworkReply *reply)
{   
    // 检查 HTTP 状态码是否为 200 (正常)
    QVariant statusCode = reply->attribute(QNetworkRequest::HttpStatusCodeAttribute);
    
    if (reply->error() == QNetworkReply::NoError)
    {
        QByteArray bytes = reply->readAll();
        QString result(bytes);
        parseJson(result); // 调用解析函数
    }
    else
    {
        // 处理网络请求错误
    }
    reply->deleteLater();
}

void HttpManager::parseJson(const QString &jsonData)
{
    QByteArray byte_array;
    QJsonParseError json_error;
    
    // 解析 JSON 文本
    QJsonDocument parse_document = QJsonDocument::fromJson(byte_array.append(jsonData), &json_error); 
    
    if (json_error.error == QJsonParseError::NoError) 
    {  
        // 搜索接口返回的是一个数组列表
        if (parse_document.isArray())  
        {  
            QJsonArray array = parse_document.array(); 
            int size = array.size();
            for (int i = 0; i < size; ++i)
            {
                QJsonValue value = array.at(i);
                if (value.isObject())
                {
                    QJsonObject object = value.toObject();
                    QString song_name = "";
                    QString song_id = "";
                    
                    // 获取歌曲名字
                    if (object.contains("song")) {  
                        song_name = object.take("song").toString();
                    }
                    
                    // 获取歌曲唯一的 ID
                    if (object.contains("song_id")) { 
                        song_id = object.take("song_id").toString();
                    }
                    
                    // 将解析到的结果填入界面上的歌曲列表控件 (如 QListWidget)
                    if (!song_name.isEmpty()) {
                        QListWidgetItem *item = new QListWidgetItem(song_name);
                        item->setData(Qt::UserRole, song_id); // 绑定歌曲 ID
                        ui->listWidget->addItem(item);
                    }
                }
            }
        }
    }
}

3. 多媒体在线试听实现 #

当通过步骤二的接口获取到歌曲的 songLink（在线播放链接）后，使用 Qt 多媒体模块中的 QMediaPlayer 即可实现在线流媒体播放。

cpp
#include <QMediaPlayer>

void MusicPlayer::playOnlineStream(const QString &song_link)
{
    QMediaPlayer *player = new QMediaPlayer(this);
    
    // 加载网络音频链接
    player->setMedia(QUrl(song_link)); 
    
    // 设置初始音量为 50%
    player->setVolume(50);
    
    // 开始在线试听播放
    player->play();
}

4. 歌词文件处理 #

从接口获取到的歌词链接（lrcLink）可以拼接为绝对地址，例如：
http://ting.baidu.com/data2/lrc/31626524/31626524.lrc

通过 QNetworkAccessManager 发送 GET 请求下载该文本，下载完成后，通过文件操作按行解析 .lrc 文件中的时间标签（如 [01:23.45] 歌词内容），将其与 QMediaPlayer 运行过程中的 positionChanged(qint64) 信号进行联动，即可完成歌词与音乐的同步滚动显示。
