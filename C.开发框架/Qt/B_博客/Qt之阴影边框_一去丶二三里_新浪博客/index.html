Qt无边框窗口实现阴影边框的两大方案：九宫格贴图与QGraphicsDropShadowEffect #

在开发高颜值的自定义界面时，我们通常会去除操作系统的原生标题栏与边框（设置 Qt::FramelessWindowHint）。然而，光秃秃的无边框窗口在浅色背景下会显得非常突兀，缺乏立体感。

为了给无边框窗口重新穿上立体感的衣服，我们需要为其绘制阴影边框。

本文总结并提供实现阴影边缘的两大黄金方案：九宫格图片拼接法 与 QGraphicsDropShadowEffect 滤镜法。

🔑 前提条件：背景透明性设置 #

无论采用哪种方案，都必须通知操作系统当前窗口支持“半透明背景”，否则窗口边缘的阴影（含有 Alpha 通道）将会被系统渲染为刺眼的黑色大色块。

在自定义窗口的构造函数中添加以下初始化配置：

cpp
// 1. 设置为无边框窗口
setWindowFlags(Qt::FramelessWindowHint | Qt::Dialog);

// 2. 💡 核心：开启背景透明属性
setAttribute(Qt::WA_TranslucentBackground);

方案一：九宫格图片拼图法 (传统高效) #

这是最经典、执行效率极高的方案。其核心原理是：美术提供一张标准的阴影切图，将其裁剪为 8 份：

  • 4 个角（固定大小）：左上、右上、左下、右下。
  • 4 条边（拉伸填充）：上、下、左、右。

然后在 paintEvent 中，根据窗口的实际尺寸动态拼接并绘制这些图片。

C++ 代码实现： #

cpp
#include <QDialog>
#include <QPainter>
#include <QPixmap>
#include <QList>

#define SHADOW_WIDTH 8 // 阴影边框的像素宽度

class ShadowWidget : public QDialog
{
    Q_OBJECT
public:
    explicit ShadowWidget(QWidget *parent = nullptr) : QDialog(parent) {
        setWindowFlags(Qt::FramelessWindowHint | Qt::Dialog);
        setAttribute(Qt::WA_TranslucentBackground);
    }

protected:
    void paintEvent(QPaintEvent *event) override {
        Q_UNUSED(event)
        QPainter painter(this);
        
        // 1. 绘制四周的阴影
        drawShadow(painter);
        
        // 2. 绘制中间的主体白色背景
        // 💡 关键：收缩 SHADOW_WIDTH 的边界，留出空间展示阴影
        painter.setPen(Qt::NoPen);
        painter.setBrush(Qt::white);
        painter.drawRect(QRect(SHADOW_WIDTH, 
                               SHADOW_WIDTH, 
                               this->width() - 2 * SHADOW_WIDTH, 
                               this->height() - 2 * SHADOW_WIDTH));
    }

private:
    void drawShadow(QPainter &painter) {
        QList<QPixmap> pixmaps;
        pixmaps.append(QPixmap(":/shadow/shadow_left.png"));
        pixmaps.append(QPixmap(":/shadow/shadow_right.png"));
        pixmaps.append(QPixmap(":/shadow/shadow_top.png"));
        pixmaps.append(QPixmap(":/shadow/shadow_bottom.png"));
        pixmaps.append(QPixmap(":/shadow/shadow_left_top.png"));
        pixmaps.append(QPixmap(":/shadow/shadow_right_top.png"));
        pixmaps.append(QPixmap(":/shadow/shadow_left_bottom.png"));
        pixmaps.append(QPixmap(":/shadow/shadow_right_bottom.png"));

        int w = this->width();
        int h = this->height();

        // 💡 A. 绘制 4 个固定大小的圆角阴影
        painter.drawPixmap(0, 0, SHADOW_WIDTH, SHADOW_WIDTH, pixmaps[4]); // 左上
        painter.drawPixmap(w - SHADOW_WIDTH, 0, SHADOW_WIDTH, SHADOW_WIDTH, pixmaps[5]); // 右上
        painter.drawPixmap(0, h - SHADOW_WIDTH, SHADOW_WIDTH, SHADOW_WIDTH, pixmaps[6]); // 左下
        painter.drawPixmap(w - SHADOW_WIDTH, h - SHADOW_WIDTH, SHADOW_WIDTH, SHADOW_WIDTH, pixmaps[7]); // 右下

        // 💡 B. 拉伸填充 4 条边缘阴影
        painter.drawPixmap(0, SHADOW_WIDTH, SHADOW_WIDTH, h - 2 * SHADOW_WIDTH, 
                           pixmaps[0].scaled(SHADOW_WIDTH, h - 2 * SHADOW_WIDTH)); // 左
        painter.drawPixmap(w - SHADOW_WIDTH, SHADOW_WIDTH, SHADOW_WIDTH, h - 2 * SHADOW_WIDTH, 
                           pixmaps[1].scaled(SHADOW_WIDTH, h - 2 * SHADOW_WIDTH)); // 右
        painter.drawPixmap(SHADOW_WIDTH, 0, w - 2 * SHADOW_WIDTH, SHADOW_WIDTH, 
                           pixmaps[2].scaled(w - 2 * SHADOW_WIDTH, SHADOW_WIDTH)); // 上
        painter.drawPixmap(SHADOW_WIDTH, h - SHADOW_WIDTH, w - 2 * SHADOW_WIDTH, SHADOW_WIDTH, 
                           pixmaps[3].scaled(w - 2 * SHADOW_WIDTH, SHADOW_WIDTH)); // 下
    }
};

方案二：QGraphicsDropShadowEffect 滤镜法 (现代化快捷) #

Qt 提供了一个内置的阴影图形效果类 QGraphicsDropShadowEffect，可以直接生成顺滑的毛玻璃投影。

⛔危险

❌ 常见新手大坑：
直接在最顶层无边框 QMainWindow 或 QDialog 上调用 setGraphicsEffect(shadow)，会发现阴影根本不显示！
原因：顶层窗口的外围没有多余的像素空间（Padding）来容纳阴影的蔓延。

💡 避坑解决方案：双层窗口嵌套机制 #

我们必须建立一个“保护壳”机制：

  1. 外层窗口 (Container)：仅负责充当容器，设置 WA_TranslucentBackground，并在内部预留一个 Layout 边距（如 10 像素）。
  2. 内层窗口 (Central Widget)：容纳所有真实的控件和白色背景，并将 QGraphicsDropShadowEffect 挂载在内层窗口上。

C++ 代码实现： #

cpp
#include <QDialog>
#include <QVBoxLayout>
#include <QGraphicsDropShadowEffect>

class ShadowEffectDialog : public QDialog
{
    Q_OBJECT
public:
    explicit ShadowEffectDialog(QWidget *parent = nullptr) : QDialog(parent) {
        // 1. 设置外层透明
        setWindowFlags(Qt::FramelessWindowHint | Qt::Dialog);
        setAttribute(Qt::WA_TranslucentBackground);

        // 2. 创建一个垂直布局，留出 10px 边距作为阴影渲染空间
        QVBoxLayout *layout = new QVBoxLayout(this);
        int margin = 10;
        layout->setContentsMargins(margin, margin, margin, margin);

        // 3. 创建真实的内层核心容器 Widget
        QWidget *centralWidget = new QWidget(this);
        centralWidget->setStyleSheet("background-color: white; border-radius: 4px;");
        layout->addWidget(centralWidget);

        // 4. 💡 核心：为内层 Widget 挂载阴影特效，投影就会显示在外层留出的 Margin 中
        QGraphicsDropShadowEffect *shadowEffect = new QGraphicsDropShadowEffect(centralWidget);
        shadowEffect->setBlurRadius(15);                  // 阴影羽化虚化半径
        shadowEffect->setColor(QColor(0, 0, 0, 80));      // 阴影颜色与透明度 (RGBA)
        shadowEffect->setOffset(0, 0);                    // 阴影偏移量 (X, Y)

        centralWidget->setGraphicsEffect(shadowEffect);
    }
};

⚖️ 方案对比与选型指南 #

维度 方案一：九宫格图片拼图 方案二：QGraphicsDropShadowEffect
性能开销 极低（仅执行普通的 drawPixmap 图案平铺）。 较高（涉及运行时的模糊/高斯羽化算法）。
开发便捷度 繁琐，需要美术切出 8 张图或自行裁剪。 极简，仅需数行代码。
动态拉伸 支持，大尺寸拉伸像素不受影响。 较差，大尺寸快速缩放时可能会出现轻微卡顿。
投影调整 困难，调整颜色或羽化必须更换切图。 极易，可实时用 setBlurRadius 调整。
