Qt之等待提示框（QMovie播放gif图片，等待文字变化等） #

在开发 Qt 应用程序界面时，我们经常需要处理网络请求、数据库查询、大文件读写等耗时任务。如果界面在此期间直接冻结卡死，会极大地损害用户体验。虽然 Qt 自带的 QMessageBox 非常实用，但在面对精美的现代化界面开发时显得有些相形见绌。

因此，我们需要自定义一个等待提示框 (Loading Dialog)，在耗时任务进行时以无边框半透明的动画弹窗呈现，给用户提供一个赏心悦目的等待体验。

一、 基本原理与视觉设计 #

自定义等待框的基本实现方案是：

  1. 继承 QDialog 并将其属性设置为无边框（Qt::FramelessWindowHint）且窗口半透明（setWindowOpacity(0.8)）。
  2. 在该窗口上放置一个 QLabel，绑定 QMovie 播放 GIF 加载动图。
  3. 如果需要在动图下方动态显示变化的加载文字（例如 waiting. -> waiting.. -> waiting... 循环），可以利用 QTimer 定时器定时切换文字节点。

二、 等待提示框具体实现代码 #

以下是 LoadingDialog 的 C++ 源码实现：

cpp
#include <QDialog>
#include <QLabel>
#include <QMovie>
#include <QTimer>
#include <QVBoxLayout>

class LoadingDialog : public QDialog
{
    Q_OBJECT
public:
    explicit LoadingDialog(QWidget *parent = nullptr);
    void startLoading();
    void stopLoading();

private slots:
    // 定时刷新底部 waiting 文本
    void changeText();

private:
    QLabel *movie_label;
    QLabel *tip_label;
    QMovie *movie;
    QTimer *timer;
    int index;
    QString base_info;
};

// 构造函数
LoadingDialog::LoadingDialog(QWidget *parent)
    : QDialog(parent), index(0)
{
    // 💡 1. 设定固定尺寸、半透明度与无边框标志
    setFixedSize(120, 120);
    setWindowOpacity(0.85);
    setWindowFlags(Qt::Dialog | Qt::FramelessWindowHint);
    
    // 设置背景色为深淡蓝色 (与 loading 动图匹配)
    setStyleSheet("background-color: rgb(55, 135, 215); border-radius: 5px;");

    // 💡 2. 创建并配置 QMovie 播放动图
    movie_label = new QLabel(this);
    movie_label->setStyleSheet("background-color: transparent;");
    movie_label->setScaledContents(true);
    
    movie = new QMovie(":/icon/loading"); // 对应 res 里的 loading.gif
    movie_label->setMovie(movie);

    // 💡 3. 创建提示文字标签
    tip_label = new QLabel(this);
    tip_label->setStyleSheet("color: white; background-color: transparent;");
    base_info = tr("waiting");
    tip_label->setText(base_info);
    
    // 布局排列
    QVBoxLayout *layout = new QVBoxLayout(this);
    layout->addWidget(movie_label, 0, Qt::AlignCenter);
    layout->addWidget(tip_label, 0, Qt::AlignCenter);
    layout->setContentsMargins(15, 15, 15, 15);
    setLayout(layout);

    // 💡 4. 初始化文本变化定时器
    timer = new QTimer(this);
    connect(timer, &QTimer::timeout, this, &LoadingDialog::changeText);
}

// 启动动画与模态运行
void LoadingDialog::startLoading()
{
    movie->start();
    timer->start(500); // 每 500ms 刷新一次文本
    this->exec();      // 进入模态循环，阻塞调用者
}

// 隐藏与停止
void LoadingDialog::stopLoading()
{
    index = 0;
    timer->stop();
    movie->stop();
    this->accept();
}

// 💡 5. 动态交替增加小数点
void LoadingDialog::changeText()
{
    index++;
    QString dots;
    if (index == 1) {
        dots = ".";
    } else if (index == 2) {
        dots = "..";
    } else {
        dots = "...";
        index = 0;
    }
    tip_label->setText(base_info + dots);
}

三、 💡 核心细节：GIF 锯齿与白边的解决方法 #

在实际测试中，许多人会发现：虽然将 gif 图片的背景在 PS 中导出了透明，但是在半透明淡蓝色背景的 QDialog 上播放时，动图边缘会产生非常严重的白色毛刺锯齿。

为什么会产生白边？ #

  • GIF 的透明通道是 1 位索引透明度，意味着它要么完全透明，要么完全不透明，不支持 Alpha 渐变半透明。
  • 为了让 GIF 图案边缘显得平滑，制作者通常会在图案边缘加入一圈与目标背景融和的过渡颜色像素。如果制作该 GIF 时背景默认是白色，那么边缘就会融合白边。当它被放到非白色的底板（如蓝色）上播放时，这圈白边就会被暴露无遗。

如何解决？ #

  • 最佳方式：在制作或下载 loading GIF 图片时，设置其导出的“混合/哑光 (Matte)”颜色与您 Qt 提示框的背景色完全一致（如本文的淡蓝色 rgb(55,135,215)）。
  • 这样，导出的 GIF 边缘就会与淡蓝色深度融合，当它放到你的淡蓝色 QDialog 上播放时，就不会产生任何肉眼可见的毛刺白边，效果将非常饱满精致。
