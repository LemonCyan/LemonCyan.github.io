QML之鼠标样式控制 #

在桌面端应用程序的交互设计中，鼠标光标（Cursor）样式的动态切换是一个十分细微但对用户体验至关重要的点。比如：悬浮在链接上呈“手型”、编辑文字时呈“I型”、拖拽文件时呈“抓手型”。

在 QML 中，我们无需编写复杂的 C++ 接口，可以直接通过 MouseArea 的 cursorShape 属性在界面中自由控制鼠标样式。

一、 cursorShape 属性概述 #

cursorShape 属性保存当前鼠标悬浮在该 MouseArea 区域内时，指针所表现出的几何样式。它的取值为 Qt::CursorShape 枚举。

ℹ笔记

并非所有的运行平台都支持动态鼠标样式。例如在不支持物理鼠标、没有光标渲染的触控平台（如多数手机、部分嵌入式屏幕）上，设置该属性将没有任何效果。

💡 核心开发技巧：只显示样式而不拦截点击 #

有时，我们只想让鼠标经过某个复杂控件（如特定的背景层、大段文字区）时改变指针样式，但不希望该 MouseArea 拦截并吞噬底层的鼠标点击事件。

这可以通过将受支持的按键清空（acceptedButtons 设为 Qt.NoButton）来实现：

qml
MouseArea {  
    anchors.fill: parent
    cursorShape: Qt.IBeamCursor // 指针在该区域悬停时呈“I型”文本输入状态
    acceptedButtons: Qt.NoButton // 关键：完全不拦截任何鼠标点击动作，事件会穿透给底层控件
}

二、 动态交互式光标切换示例 #

以下代码演示了如何根据鼠标的“移入”、“移出”和“按住鼠标”三个交互状态，使用三元运算符动态变换光标：

qml
import QtQuick 2.0

Rectangle {
    color: "white"
    width: 400; height: 400

    Rectangle {
        id: targetArea
        color: "red"
        anchors.centerIn: parent
        width: 300; height: 300

        MouseArea {
            anchors.fill: parent
            
            // 关键：必须显式开启悬停启用属性，containsMouse 状态才能实时更新
            hoverEnabled: true 

            // 动态判断光标样式：
            // 1. 如果鼠标在区域内 (containsMouse 为真)
            //    - 如果用户按下了鼠标 (pressed 为真)：展示 ClosedHandCursor (闭合抓手，表示拖拽中)
            //    - 如果用户只是悬浮悬停：展示 OpenHandCursor (张开手掌，表示可拖拽)
            // 2. 如果鼠标不在区域内：退回到 ArrowCursor (普通箭头指针)
            cursorShape: (containsMouse
                          ? (pressed ? Qt.ClosedHandCursor : Qt.OpenHandCursor)
                          : Qt.ArrowCursor)
        }
    }
}

三、 Qt 支持的 22 种常用内置光标形状 #

你可以直接在 QML 的 cursorShape 属性中填入以下内置枚举常量：

序号 光标枚举值 鼠标指针形状描述
1 Qt.ArrowCursor 默认的标准箭头光标
2 Qt.UpArrow 指向正上方的向上箭头
3 Qt.CrossCursor 十字线十字光标
4 Qt.WaitCursor 沙漏/等待沙漏光标
5 Qt.IBeamCursor 文本编辑的竖线 I 型光标
6 Qt.SizeVerCursor 双向纵向拉伸箭头（上下伸缩）
7 Qt.SizeHorCursor 双向横向拉伸箭头（左右伸缩）
8 Qt.SizeBDiagCursor 右上到左下的斜向拉伸箭头
9 Qt.SizeFDiagCursor 左上到右下的斜向拉伸箭头
10 Qt.SizeAllCursor 移动物体时的十字四向箭头
11 Qt.BlankCursor 完全空白（隐藏鼠标指针）
12 Qt.SplitVCursor 垂直分割线指示器
13 Qt.SplitHCursor 水平分割线指示器
14 Qt.PointingHandCursor 经典的交互指向手型图标（常用于链接按钮）
15 Qt.ForbiddenCursor 红色禁用/无效操作标识
16 Qt.WhatsThisCursor 问号附加的帮助箭头
17 Qt.BusyCursor 后台繁忙指示光标
18 Qt.OpenHandCursor 悬空等待抓取的开掌手型
19 Qt.ClosedHandCursor 按下抓取后的闭合握拳手型
20 Qt.DragCopyCursor 拖拽复制数据时的附加框指针
21 Qt.DragMoveCursor 拖拽剪切/移动数据时的指针
22 Qt.DragLinkCursor 拖拽建立超链接关系时的指针
