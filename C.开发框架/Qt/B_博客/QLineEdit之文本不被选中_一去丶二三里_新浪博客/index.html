QLineEdit之输入框文本不可选中方法实现 #

在设计密码框等安全系数要求较高的输入框时，我们常常需要像 QQ 密码框一样：无论用户怎么双击、拖拽鼠标或按下全选快捷键，里面的内容都绝对不能被选中（不可出现蓝色高亮选区），同时还要屏蔽复制和右键菜单。

在 Qt 中，文本选中（Text Selection）主要是通过鼠标移动、双击、快捷键（Ctrl+A）以及焦点改变激发的。要完美实现文本不可选中，需要分成两个部分：

  1. 重写 QLineEdit 的内部事件函数（解决鼠标和单体快捷键）。
  2. 在父级窗口实现 eventFilter 过滤（解决多控件 Tab 切换与上下方向键干扰）。

一、 子类化 QLineEdit 屏蔽常规选中行为 #

我们首先创建一个自定义类 PwdLineEdit 继承自 QLineEdit，并在其中重载键盘与鼠标事件：

1. 头文件 (PwdLineEdit.h) #

cpp
#pragma once
#include <QLineEdit>
#include <QKeyEvent>
#include <QMouseEvent>

class PwdLineEdit : public QLineEdit
{
    Q_OBJECT
public:
    explicit PwdLineEdit(QWidget *parent = nullptr) : QLineEdit(parent) {}

protected:
    // 屏蔽全选、复制、粘贴，改写 Home/End 行为
    void keyPressEvent(QKeyEvent *event) override;

    // 屏蔽鼠标拖拽产生选区
    void mouseMoveEvent(QMouseEvent *event) override;

    // 屏蔽双击选中单词
    void mouseDoubleClickEvent(QMouseEvent *event) override;

    // 屏蔽 Shift+点击 等产生选区的鼠标动作
    void mousePressEvent(QMouseEvent *event) override;
};

2. 实现文件 (PwdLineEdit.cpp) #

cpp
#include "PwdLineEdit.h"

void PwdLineEdit::keyPressEvent(QKeyEvent *event)
{
    // 1. 屏蔽系统层面的“全选”快捷键 (如 Ctrl+A)
    if (event->matches(QKeySequence::SelectAll))
    {   
        return;
    }
    // 2. 屏蔽系统层面的“复制”快捷键 (如 Ctrl+C)
    else if (event->matches(QKeySequence::Copy))
    {   
        return;
    }
    // 3. 屏蔽系统层面的“粘贴”快捷键 (如 Ctrl+V)
    else if (event->matches(QKeySequence::Paste))
    {   
        return;
    }
    // 4. 重写 Home/End 键：只移动光标，不触发默认的 Shift+Home 选区高亮
    else if (event->key() == Qt::Key_Home)
    {
        this->setCursorPosition(0);
    }
    else if (event->key() == Qt::Key_End)
    {
        this->setCursorPosition(this->text().length());
    }
    else
    {
        QLineEdit::keyPressEvent(event);
    }
}

void PwdLineEdit::mouseMoveEvent(QMouseEvent *event)
{
    // 屏蔽拖拽：鼠标按下并移动时，QLineEdit 默认会选中文本。这里直接 return 拦截
    return;
}

void PwdLineEdit::mouseDoubleClickEvent(QMouseEvent *event)
{
    // 屏蔽双击：默认双击会选中光标下的单个单词。这里直接拦截
    return;
}

void PwdLineEdit::mousePressEvent(QMouseEvent *event)
{
    // 获取当前鼠标点击处的逻辑字符下标
    int clickPos = cursorPositionAt(event->pos());
    int currentPos = this->cursorPosition();

    // 判定点击位置并手动重设光标，避开默认鼠标按下时激发的复杂 Selection 算法
    if (clickPos < currentPos)
    {
        this->setCursorPosition(currentPos - 1);
    }
    else if (clickPos > currentPos)
    {
        this->setCursorPosition(currentPos + 1);
    }
    else
    {
        this->setCursorPosition(currentPos);
    }
}

二、 在父容器中使用事件过滤器拦截切换动作 #

虽然输入框内部屏蔽了鼠标，但在有多个输入框（如用户名、域名、密码）组成的登录框中，用户通过 Tab 键 或 Up/Down 方向键 切换焦点时，系统默认依然会全选高亮密码框。

我们需要在父窗体（例如 LoginDialog）上安装事件过滤器来解决：

1. 注册事件过滤器 #

cpp
// 在对话框构造函数中，为所有可聚焦控件安装事件过滤器
domain_line_edit->installEventFilter(this);
user_line_edit->installEventFilter(this);
password_line_edit->installEventFilter(this);
login_button->installEventFilter(this);

2. 编写过滤器逻辑 (eventFilter) #

cpp
bool LoginDialog::eventFilter(QObject *obj, QEvent *event)
{
    // 过滤出我们需要管控的输入控件集合
    if (obj == domain_line_edit || obj == user_line_edit || obj == password_line_edit || obj == login_button)
    {
        if (event->type() == QEvent::KeyPress)
        {
            QKeyEvent *keyEvent = static_cast<QKeyEvent*>(event);
            
            // 💡 1. 劫持 Tab 键逻辑，自定义焦点流向，并抹除进入密码框时的选区
            if (keyEvent->key() == Qt::Key_Tab)
            {
                if (domain_line_edit->hasFocus())
                {
                    user_line_edit->setFocus();
                }
                else if (user_line_edit->hasFocus())
                {
                    // 核心：在移入密码框前，用 setSelection 强行限制选中长度为 0
                    int len = password_line_edit->text().length();
                    password_line_edit->setSelection(len, len); // 终点坐标等于起点坐标，相当于不选中
                    password_line_edit->setFocus();
                }
                else if (password_line_edit->hasFocus())
                {
                    login_button->setFocus();
                }
                else
                {
                    focusNextChild();
                }
                return true; // 拦截默认 Tab 聚焦行为
            }
            
            // 💡 2. 禁用上下方向键（防止引起突发的行选择高亮）
            else if (keyEvent->key() == Qt::Key_Up || keyEvent->key() == Qt::Key_Down)
            {
                return true; // 拦截不处理
            }
            
            // 💡 3. 拦截左右方向键，在密码框中只移动光标，不触发选择
            else if (keyEvent->key() == Qt::Key_Left)
            {
                if (password_line_edit->hasFocus())
                {
                    int pos = password_line_edit->cursorPosition();
                    if (pos > 0) {
                        password_line_edit->setCursorPosition(pos - 1);
                    }
                    return true;
                }
            }
            else if (keyEvent->key() == Qt::Key_Right)
            {
                if (password_line_edit->hasFocus())
                {
                    int pos = password_line_edit->cursorPosition();
                    if (pos < password_line_edit->text().length()) {
                        password_line_edit->setCursorPosition(pos + 1);
                    }
                    return true;
                }
            }
        }
    }
    return QDialog::eventFilter(obj, event);
}

三、 总结 #

通过本方法，我们达成了以下安全防护效果：

  • 拖拽失效：用户用鼠标拖动选中文本无效。
  • 双击失效：双击输入框无法选中任何词组。
  • 快捷键封锁：Ctrl+A (全选)、Ctrl+C (复制) 全数失效，且右键菜单不会弹出。
  • 导航无感：Tab 键或鼠标点入聚焦密码框时，光标正常闪烁，但内容不会出现蓝色全选块。
