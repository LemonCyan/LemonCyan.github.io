Qt之创建镜像图像 #

在 Qt 图形渲染中，我们可以对图像（QImage/QPixmap）进行极其丰富的像素级处理，如改变亮度、调节透明度、灰度化、以及缩放大小等。

当我们在开发复杂的用户界面时，经常会遇到某些控件图标或背景需要“水平对称翻转”或“垂直倒影”的场景。对于这种简单的映射处理，我们无需让美工设计多份不同的图片资源，而是可以通过 Qt 的内置函数 QImage::mirrored() 直接在运行时动态生成镜像图，不仅精简了安装包体积，也极大地提升了灵活性。

一、 mirrored() 核心函数 #

QImage 提供了实现镜像效果的便捷方法：

cpp
QImage QImage::mirrored(bool horizontal = false, bool vertical = true) const;

参数解析： #

  • horizontal：是否进行水平镜像（左右对调）。如果设为 true，图像将在水平方向进行翻转。
  • vertical：是否进行垂直镜像（上下对调）。如果设为 true，图像将在垂直方向进行翻转。
ℹ笔记

该函数并不改变原 QImage 像素，而是会返回一份处理好的新 QImage 备份副本。

二、 C++ 具体实现代码 #

以下代码演示了如何载入原图资源，通过镜像接口翻转后，在 UI 界面的 QLabel 上展示出来的步骤：

cpp
#include <QImage>
#include <QPixmap>
#include <QLabel>

// 1. 载入原始图片
QImage original_image(":/Images/logo");

// 💡 2. 根据不同的布尔值组合创建对应的镜像图像
// 例如：进行水平和垂直双重翻转
QImage mirrored_image = original_image.mirrored(true, true);

// 3. 将其转化为 QPixmap 并渲染展示到控件上
icon_label->setPixmap(QPixmap::fromImage(mirrored_image));

三、 参数配置与效果对照表 #

依据传入的 (horizontal, vertical) 两个参数的真假值组合，可以派生出以下四种显示效果：

参数一 (horizontal) 参数二 (vertical) 最终镜像效果说明
false false 保持与原图完全一致，不发生任何翻转。
true false 仅水平镜像。原图发生左右翻转，常用于对称按钮背景或角色面向左/面向右切换。
false true 仅垂直镜像（默认值）。原图发生上下倒影翻转，常用于倒影特效、折射渲染。
true true 双向镜像。图像水平与垂直方向同时翻转，等价于原图围绕中心旋转了 180 度。

利用好 Qt 图像镜像操作，可以用最少的代码、最少的资源包体积，产生最多样化的动态视觉特效。
