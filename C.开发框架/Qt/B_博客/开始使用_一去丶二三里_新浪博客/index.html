Qt5开发入门指南：控制台、QWidget窗口与Qt Quick三种应用模式 #

作为跨平台 C++ 开发的旗舰级工具包，Qt 5 拥有极强的伸缩性：它不仅是一个图形界面库，还提供了健全的底层数据结构、网络及文件 I/O 模块。

在 Qt 5 中，我们可以根据应用场景构建三种完全不同形态的程序：

  1. 控制台应用程序 (Console Application)：无 GUI 界面，常用于服务器守护进程、工具命令行。
  2. 传统窗口应用程序 (QWidget Desktop)：面向经典 PC 平台的重型企业客户端。
  3. Qt Quick 应用程序 (QML 声明式)：面向现代移动触摸屏、流畅动效的新一代界面。

本文将依次介绍这三种模式的开发基础。

一、 快速构建 QML Hello World #

在 Qt Creator 中新建一个 Qt Quick UI 项目，其最基础的核心代码 HelloWorld.qml 如下所示：

qml
import QtQuick 2.0

Rectangle {
    width: 360
    height: 360
    color: "lightgray"

    Text {
        anchors.centerIn: parent
        text: "Hello World"
        font.pointSize: 16
    }

    MouseArea {
        anchors.fill: parent
        onClicked: {
            Qt.quit(); // 点击界面任意地方退出程序
        }
    }
}

QML 是一种类似 JSON 的声明式语言。它描述了一个分层的用户界面：顶层是个 360x360 像素的矩形，中心摆放着文本，并在上方覆盖了一个鼠标交互感应区（MouseArea）。

二、 模式 1：控制台应用程序 (Console) #

控制台应用没有渲染开销，常用于高效处理业务。

1. 字符拼接与输出 #

Qt 提供了功能强大、且完美支持 Unicode 的 QString 类：

cpp
#include <QTextStream>
#include <QString>

int main(int argc, char **argv)
{
    Q_UNUSED(argc)
    Q_UNUSED(argv)

    // 绑定标准输出流，使其具备编码感知能力
    QTextStream cout(stdout, QIODevice::WriteOnly);

    QString s1("Paris");
    QString s2("London");
    
    // 字符串便捷拼接
    QString s = s1 + " " + s2 + "!";
    cout << s << endl;

    return 0;
}

2. 容器与数据流操作 (CSV 文件解析示例) #

下面展示如何用 Qt 的 QFile 与 QTextStream 读取一个 CSV 文件格并解析数据：

cpp
#include <QFile>
#include <QTextStream>
#include <QStringList>
#include <QDebug>

void parseCsvFile()
{
    QList<QStringList> data;
    QFile file("sample.csv");

    if (file.open(QIODevice::ReadOnly | QIODevice::Text))
    {
        QTextStream stream(&file);
        
        // 💡 循环读取流直至末尾 (使用 Qt 提供的便捷关键字 forever)
        forever {
            QString line = stream.readLine();
            
            if (line.isNull()) 
                break; // 文件读取完毕
            if (line.isEmpty()) 
                continue; // 跳过空行

            QStringList row;
            // 遍历逗号分隔的单元格
            foreach (const QString &cell, line.split(",")) {
                row.append(cell.trimmed());
            }
            data.append(row);
        }
        file.close();
    }
}

三、 模式 2：经典 QWidget 窗口应用 #

这是最成熟的 PC 界面编写方式。

1. 继承并绘制自定义控件 (Custom Widget) #

当标准控件无法满足要求时，我们通过继承 QWidget 并重写绘图与鼠标事件来构造自定义控件：

头文件定义 (CustomWidget.h) #

cpp
#pragma once
#include <QWidget>
#include <QPoint>

class CustomWidget : public QWidget
{
    Q_OBJECT
public:
    explicit CustomWidget(QWidget *parent = nullptr);

protected:
    void paintEvent(QPaintEvent *event) override;
    void mousePressEvent(QMouseEvent *event) override;
    void mouseMoveEvent(QMouseEvent *event) override;

private:
    QPoint m_lastPos; // 记录鼠标位置
};

源实现文件 (CustomWidget.cpp) #

cpp
#include "CustomWidget.h"
#include <QPainter>
#include <QMouseEvent>

CustomWidget::CustomWidget(QWidget *parent)
    : QWidget(parent)
{
}

void CustomWidget::paintEvent(QPaintEvent *)
{
    QPainter painter(this);
    QRect r1 = rect().adjusted(10, 10, -10, -10);
    
    // 绘制一个天蓝色边框
    painter.setPen(QColor("#33B5E5"));
    painter.drawRect(r1);

    // 绘制一个跟随鼠标移动的黄色方块
    QRect r2(0, 0, 40, 40);
    if (m_lastPos.isNull()) {
        r2.moveCenter(r1.center());
    } else {
        r2.moveCenter(m_lastPos);
    }
    painter.fillRect(r2, QColor("#FFBB33"));
}

void CustomWidget::mousePressEvent(QMouseEvent *event)
{
    m_lastPos = event->pos();
    update(); // 触发界面重绘
}

void CustomWidget::mouseMoveEvent(QMouseEvent *event)
{
    m_lastPos = event->pos();
    update();
}

2. 标准 UI 控件排版布局与信号槽绑定 #

开发桌面窗体的主要任务，是安排按钮、列表框等子控件，并通过**信号与槽（Signals & Slots）**机制处理交互。

cpp
#include <QVBoxLayout>
#include <QListWidget>
#include <QLineEdit>
#include <QPushButton>

class CityManagerWidget : public QWidget
{
    Q_OBJECT
public:
    CityManagerWidget(QWidget *parent = nullptr) : QWidget(parent) {
        QVBoxLayout *layout = new QVBoxLayout(this);
        
        m_listWidget = new QListWidget(this);
        m_lineEdit = new QLineEdit(this);
        m_quitButton = new QPushButton(tr("Quit"), this);

        layout->addWidget(m_listWidget);
        layout->addWidget(m_lineEdit);
        layout->addWidget(m_quitButton);

        // 💡 信号槽绑定
        connect(m_listWidget, &QListWidget::itemClicked, this, &CityManagerWidget::slotItemClicked);
        connect(m_lineEdit, &QLineEdit::editingFinished, this, &CityManagerWidget::slotUpdateItem);
        connect(m_quitButton, &QPushButton::clicked, qApp, &QApplication::quit);
    }

private slots:
    void slotItemClicked(QListWidgetItem *item) {
        m_lineEdit->setText(item->text());
    }
    
    void slotUpdateItem() {
        QListWidgetItem *item = m_listWidget->currentItem();
        if (item) {
            item->setText(m_lineEdit->text());
        }
    }

private:
    QListWidget *m_listWidget;
    QLineEdit   *m_lineEdit;
    QPushButton *m_quitButton;
};

四、 模式 3：Qt Quick 混编应用 #

现代触摸终端强调高流畅度和淡入淡出动画，使用 C++ 强行绘制动画非常吃力。Qt Quick 引入了 QML 描述界面，并使用 C++ 作为数据源后台。

要在 QML 中显示 C++ 中的数据库模型数据，我们在 C++ 中配置 QSqlTableModel，并将其注册为 QML 上下文属性：

cpp
// 1. 初始化数据库连接并配置模型
QSqlDatabase db = QSqlDatabase::addDatabase("QSQLITE");
db.setDatabaseName("cities.db");
if (!db.open()) {
    qFatal("Unable to open database");
}

QSqlTableModel *cityModel = new QSqlTableModel(this);
cityModel->setTable("city");
cityModel->select();

// 💡 2. 将 C++ 数据模型对象直接暴露给 QML 上下文环境
QQmlApplicationEngine engine;
engine.rootContext()->setContextProperty("cityModel", cityModel);
engine.load(QUrl(QStringLiteral("qrc:///main.qml")));

在前端 QML 文件中，即可像使用原生 QML 对象一样直接读取该 C++ 数据模型：

qml
ListView {
    width: 240
    height: 300
    // 直接绑定 C++ 端注册的上下文对象名称
    model: cityModel
    delegate: Text { 
        text: model.city // 自动匹配 C++ Sql 表的对应列
    }
}
