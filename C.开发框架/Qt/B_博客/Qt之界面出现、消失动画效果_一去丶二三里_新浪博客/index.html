Qt使用QPropertyAnimation实现窗口渐变淡入淡出动画效果 #

在开发专业美观的桌面客户端时，生硬的窗口展示与退出关闭往往显得不够自然。为了提升交互质感，通常会在窗口加载启动时加入**淡入（Fade In）效果，在关闭退出时加入淡出（Fade Out）**效果。

本文将对比演示两种实现方法，并给出基于 Qt 属性动画框架 QPropertyAnimation 且具备内存安全性、防止窗口提前析构的完整方案。

⚠️ 错误做法：CPU 阻塞循环修改透明度 #

有些初学者为了图省事，会在 closeEvent() 中写一个庞大的 for 循环来不断降低透明度：

cpp
// ❌ 错误且极其粗暴的做法（会导致主线程 UI 界面卡死）
void LoginDialog::closeEvent(QCloseEvent *event)
{
    for (int i = 0; i < 100000; i++)
    {
        if (i < 10000)  this->setWindowOpacity(0.9);
        else if (i < 20000) this->setWindowOpacity(0.8);
        // ... 依次类推
        else this->setWindowOpacity(0.0);
    }
    QApplication::quit();
}

为什么该方案极其糟糕？ #

  • 阻塞 GUI 主线程：这个 for 循环完全侵占了主事件循环（Event Loop），导致在此期间界面根本无法进行任何重绘（PaintEvent）刷新，实际上用户看不到渐变，只看到窗口卡死 1 秒后突然消失。
  • 极度消耗 CPU：让 CPU 空转进行无意义的轮询计数，导致单核 CPU 瞬间飙满。

正确做法：使用 QPropertyAnimation 属性动画 #

Qt 提供了底层的动画子系统。我们可以通过动画类 QPropertyAnimation 动态改变窗口的 windowOpacity（窗口透明度）属性。这属于非阻塞式的异步计时绘制，性能优异。

1. 窗口初始化时的“淡入”动画 #

在窗口的构造函数最后一行，配置并开启淡入动画即可：

cpp
MainWidget::MainWidget(QWidget *parent)
    : QWidget(parent)
{
    ui->setupUi(this);

    // 💡 界面初始化：0.0 (完全透明) -> 1.0 (完全显示)
    QPropertyAnimation *fadeInAnim = new QPropertyAnimation(this, "windowOpacity");
    fadeInAnim->setDuration(800);                   // 动画耗时：800 毫秒
    fadeInAnim->setStartValue(0.0);
    fadeInAnim->setEndValue(1.0);
    
    // 设置动画缓动曲线为二次缓入缓出，让渐变更自然
    fadeInAnim->setEasingCurve(QEasingCurve::InOutQuad);
    
    // 💡 播放完后自动销毁动画对象本身，防止内存泄漏
    fadeInAnim->start(QAbstractAnimation::DeleteWhenStopped);
}

2. 窗口关闭时的“淡出”动画 (重写 closeEvent 拦截) #

如果用户直接点击窗口右上角的关闭按钮（或触发自定义的 Close 槽），我们需要拦截这次关闭动作，优先播放淡出动画，待动画彻底播放完毕后再真正销毁窗口。

头文件 (MainWidget.h) 声明： #

cpp
protected:
    void closeEvent(QCloseEvent *event) override;

private:
    bool m_isFadingOut = false; // 标记当前是否处于淡出过渡状态

源文件 (MainWidget.cpp) 实现： #

cpp
void MainWidget::closeEvent(QCloseEvent *event)
{
    // 如果已经处于淡出动画中，允许直接关闭窗口
    if (m_isFadingOut) {
        event->accept();
        return;
    }

    // 💡 1. 拦截关闭事件，防止窗口瞬间消失
    event->ignore();

    m_isFadingOut = true;

    // 💡 2. 启动 1.0 (完全显示) -> 0.0 (完全透明) 的淡出动画
    QPropertyAnimation *fadeOutAnim = new QPropertyAnimation(this, "windowOpacity");
    fadeOutAnim->setDuration(800);
    fadeOutAnim->setStartValue(1.0);
    fadeOutAnim->setEndValue(0.0);
    fadeOutAnim->setEasingCurve(QEasingCurve::InOutQuad);

    // 💡 3. 动画播放完毕后，连接信号触发真正的 close() 行为
    connect(fadeOutAnim, &QPropertyAnimation::finished, this, [this]() {
        this->close(); // 会再次触发 closeEvent()，此时 m_isFadingOut 为 true，窗口正常关闭
    });

    fadeOutAnim->start(QAbstractAnimation::DeleteWhenStopped);
}

三、 💡 高级扩展：为什么自定义属性动画无效？ #

很多开发者在尝试动画自己写的自定义 QWidget 属性（例如自定义的 myAlpha 变量）时，发现画面一动不动。

原因排查与解决： #

QPropertyAnimation 底层依赖于 Qt 的元对象反射系统。如果你想让一个自定义的变量支持动画，必须确保：

  1. 你的类声明中包含了 Q_OBJECT 宏。
  2. 在头文件中使用 Q_PROPERTY 注册该变量，且该变量必须包含对应的 setter 和 getter 函数：
cpp
class CustomWidget : public QWidget
{
    Q_OBJECT
    // 💡 注册属性
    Q_PROPERTY(int myAlpha READ myAlpha WRITE setMyAlpha)
    
public:
    int myAlpha() const { return m_myAlpha; }
    void setMyAlpha(int val) { 
        m_myAlpha = val; 
        update(); // 💡 必须在 setter 中主动调用 update() 触发重绘！
    }

private:
    int m_myAlpha = 255;
};

只要完成了上述注册，便可直接对其进行属性动画控制： new QPropertyAnimation(widget, "myAlpha");
