Qt解析XML文件（QXmlStreamReader） #

在处理 XML 格式数据时，Qt 文档指出：QXmlStreamReader 是一种更快、更方便的基于流式读写的解析器。它是传统的 SAX 解析器（QXmlSimpleReader）的高效替代品，且在应对大型 XML 文件时，由于其采用“随读随走、不全载入内存”的流处理机制，速度和内存占用表现都要优于 DOM 树型解析器（QDomDocument）。

QXmlStreamReader 位于 QtCore 核心模块中，无需在 .pro 中特意引入 QT += xml 模块（若使用 DOM 则依然需要）。

一、 待解析的 XML 文件范例 #

为了让解析演示更具可读性，这里给出一个标准的 person.xml 数据样本：

xml
<?xml version="1.0" encoding="UTF-8"?>
<persons>
    <person id="1">
        <name>一去丶二三里</name>
        <age>25</age>
        <email>liang19890820@163.com</email>
        <website>http://blog.sina.com.cn/liang19890820</website>
    </person>
    <person id="2">
        <name>奋斗的孩子</name>
        <age>26</age>
        <email>fightchild@foxmail.com</email>
        <website>http://blog.sina.com.cn/liang19890820</website>
    </person>
</persons>

二、 C++ 解析逻辑与核心代码实现 #

流式读取的核心思想是：启动一个 while 循环，只要文件未读完且没有错误，就通过 readNext() 移动读取指针，捕获当前的 TokenType（如 StartElement、Characters 等）并读取其标签名称和内容值。

以下为基于 QXmlStreamReader 封装的解析类实现：

cpp
#include <QFile>
#include <QXmlStreamReader>
#include <QList>
#include <QMap>
#include <QMessageBox>
#include <QDebug>

class ParseXML
{
public:
    void parseXML(const QString &file_name);

private:
    QMap<QString, QString> parsePerson(QXmlStreamReader &xml);
    void addElementDataToMap(QXmlStreamReader &xml, QMap<QString, QString> &map) const;
};

// 1. 主流式解析函数
void ParseXML::parseXML(const QString &file_name)
{
    if (file_name.isEmpty())  
        return;  
  
    QFile file(file_name);  
    if (!file.open(QFile::ReadOnly | QFile::Text)) {  
        QMessageBox::information(nullptr, "Error", "Open file error!");
        return;  
    }  
  
    // 💡 QXmlStreamReader 可以操作任何 QIODevice 子类，如 QFile
    QXmlStreamReader xml(&file);
    QList<QMap<QString, QString>> persons;
    
    // 循环遍历整个流，直至结束或捕获错误
    while (!xml.atEnd() && !xml.hasError()) {
        // 读取下一个标签节点并返回其 Token 类型
        QXmlStreamReader::TokenType token = xml.readNext();
        
        // 如果是文档起点，直接跳过进入下一循环
        if (token == QXmlStreamReader::StartDocument) {
            continue;
        }
        
        // 发现元素的起点 (StartElement)
        if (token == QXmlStreamReader::StartElement) {
            // 如果是 persons 根节点，继续向下读
            if (xml.name() == "persons") {
                continue;
            }
            // 💡 如果是 person 节点，开始进行属性与子节点读取
            if (xml.name() == "person") {
                persons.append(this->parsePerson(xml));
            }
        }
    }
  
    // 拦截可能发生的 XML 格式格式解析错误
    if (xml.hasError()) {
        QMessageBox::warning(nullptr, "Parse Error", xml.errorString());
    }
    
    // 🔑 从 reader 中卸载设备，并重置其初始状态，释放系统资源
    xml.clear();
    file.close();

    // 打印测试结果
    qDebug() << "Total parsed persons:" << persons.size();
}

// 2. 子节点 <person> 具体读取解析
QMap<QString, QString> ParseXML::parsePerson(QXmlStreamReader &xml)
{
    QMap<QString, QString> person;
    
    // 安全校验：确认当前是否确实处于 person 开始位置
    if (xml.tokenType() != QXmlStreamReader::StartElement || xml.name() != "person") {
        return person;
    }
    
    // 获取 person 节点的所有属性列表
    QXmlStreamAttributes attributes = xml.attributes();
    if (attributes.hasAttribute("id")) {
        person["id"] = attributes.value("id").toString();
    }
    
    // 指针继续前移
    xml.readNext();
    
    // 💡 只要未读到 person 结束标志 </person>，就循环处理子元素
    while (!(xml.tokenType() == QXmlStreamReader::EndElement && xml.name() == "person")) {
        if (xml.tokenType() == QXmlStreamReader::StartElement) {
            if (xml.name() == "name") {
                this->addElementDataToMap(xml, person);
            } else if (xml.name() == "age") {
                this->addElementDataToMap(xml, person);
            } else if (xml.name() == "email") {
                this->addElementDataToMap(xml, person);
            } else if (xml.name() == "website") {
                this->addElementDataToMap(xml, person);
            }
        }
        xml.readNext();
    }
    
    return person;
}

// 3. 将元素内的具体字符数据 (Characters) 填充至 Map 中
void ParseXML::addElementDataToMap(QXmlStreamReader &xml, QMap<QString, QString> &map) const
{
    if (xml.tokenType() != QXmlStreamReader::StartElement) {
        return;
    }
    
    QString element_name = xml.name().toString(); // 获取当前标签名，如 "name"
    
    xml.readNext(); // 💡 移动到内部，此时 Token 应该为 Characters（即具体文本）
    
    if (xml.tokenType() != QXmlStreamReader::Characters) {
        return;
    }
    
    // 写入对应的键值对映射
    map.insert(element_name, xml.text().toString());
}

三、 总结 #

  • QXmlStreamReader 解析采用的是拉模型 (Pull Model)，即程序自己决定何时移向下一个 Token，这与传统 SAX 的“事件回调推送 (Push Model)”相比，省去了复杂的类状态机维护，更加容易编码和追踪。
  • 必须要严格注意 readNext() 带来的位置移动。在开始元素 <name> 下，执行 readNext() 后的 Token 会变为 Characters（代表文本节点），只有在此 Token 下，调用 xml.text() 才能正确读取到标签中的实际数据。
