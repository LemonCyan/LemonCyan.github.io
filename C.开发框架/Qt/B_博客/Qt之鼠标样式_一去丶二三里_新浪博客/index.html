Qt之鼠标样式（QCursor）配置与自定义光标 #

在 GUI 应用程序的开发中，鼠标光标（Cursor）样式的合理切换能够极大地提升界面的友好度与引导性。例如，当后台正在执行耗时任务时应展现忙碌旋转图标，当鼠标悬浮在超链接上时应呈现指向手型，当需要拉伸窗口尺寸时应显示调整方向的箭头。

Qt 中提供了核心类 QCursor 用于管理光标。我们可以通过调用控件的 setCursor(Qt::CursorShape) 接口直接为其配置系统自带的标准光标，也可以使用自定义图片文件来定义全新的光标图形。

一、 Qt 系统预置的 18 种标准鼠标样式 #

Qt 在命名空间 Qt 中定义了枚举 Qt::CursorShape，包含了常见的 18 种内置光标状态。

编号 属性值常量 说明与常见应用场景
1 Qt::ArrowCursor 默认正常箭头选择
2 Qt::UpArrowCursor 向上箭头（通常用于表格标题段等候选状态）
3 Qt::CrossCursor 精确选择（十字线，多用于画图、测距工具）
4 Qt::WaitCursor 忙碌等待状态（沙漏或转圈）
5 Qt::BusyCursor 后台运行等待状态（箭头旁边带忙碌转圈）
6 Qt::IBeamCursor 文本录入选择（工字形指针）
7 Qt::SizeVerCursor 垂直方向拉伸调整（上下方向箭头）
8 Qt::SizeHorCursor 水平方向拉伸调整（左右方向箭头）
9 Qt::SizeBDiagCursor 沿左下到右上对角线拉伸调整
10 Qt::SizeFDiagCursor 沿左上到右下对角线拉伸调整
11 Qt::SizeAllCursor 全方向移动调整（四向箭头，多用于画布拖动）
12 Qt::SplitVCursor 垂直分割线调节（上下双横线带双箭头）
13 Qt::SplitHCursor 水平分割线调节（左右双竖线带双箭头）
14 Qt::PointingHandCursor 指向手型（多用于点击按钮、超链接）
15 Qt::ForbiddenCursor 禁止不可用状态（红色斜杠圆圈）
16 Qt::OpenHandCursor 打开的抓取手型（准备按住拖拽）
17 Qt::ClosedHandCursor 关闭的抓取手型（正在按住并拖拽）
18 Qt::WhatsThisCursor 帮助疑问选择（问号带箭头）

基本配置示例 #

cpp
// 1. 给当前 Widget 窗口设置光标为手型
this->setCursor(Qt::PointingHandCursor);

// 2. 局部控件（如一个按钮）设置不可用光标
ui->pushButton->setCursor(Qt::ForbiddenCursor);

二、 动态重载全局鼠标光标 #

在很多业务块中（例如网络请求），我们可能需要暂时将整个程序的鼠标锁定为等待状态，完成后再复原。此时可以使用全局静态方法来覆盖与恢复：

cpp
// 1. 强行将整个应用程序的鼠标样式全部覆盖为等待状态
QApplication::setOverrideCursor(Qt::WaitCursor);

// 执行耗时业务逻辑...

// 2. 复原全局鼠标样式（如果覆盖了多次，restore 会逐层回退）
QApplication::restoreOverrideCursor();

三、 使用图片加载自定义光标 (Custom QCursor) #

如果系统预置的光标无法满足你的交互设计（如需要一个自定义的圆圈作为画笔橡皮擦），你可以加载一张外部的 PNG 图片文件构建一个全新的 QCursor。

cpp
void useCustomCursor()
{
    // 1. 加载带透明通道的光标图片
    QPixmap pixmap(":/Images/custom_cursor.png");
    
    // 💡 避坑建议：
    // 根据系统硬件规范（特别是 Windows），自定义光标的像素尺寸通常建议为 32x32。
    // 如果图片尺寸过大（如 128x128 且未缩放），直接设置可能会出现严重的锯齿、残缺或加载失败。
    QSize targetSize(32, 32);
    if (pixmap.size() != targetSize)
    {
        pixmap = pixmap.scaled(targetSize, Qt::KeepAspectRatio, Qt::SmoothTransformation);
    }
    
    // 2. 定义点击的热点坐标 (Hotspot)
    // 默认如果传入 (-1, -1)，热点会被自动定在图片的几何中心。
    // 如果是传统的箭头类型，热点需要精确设置在左上角 (0, 0)；如果是十字线，设为中心 (width/2, height/2)
    int hotX = pixmap.width() / 2;
    int hotY = pixmap.height() / 2;

    // 3. 构建并应用光标
    QCursor customCursor(pixmap, hotX, hotY);
    this->setCursor(customCursor);
}

💡 自定义圆圈（如橡皮擦光标）无法完整画出圆圈的常见原因 #

有些开发者使用 QPainter 动态在内存中绘制一个透明的 QPixmap 圆圈作为光标，但生成的圆圈在边缘常有切边缺失。

  • 原因：绘制圆圈时使用的画笔粗度（Pen Width）也会占用外部像素。例如 painter.drawEllipse(0, 0, 32, 32) 在 Pen 粗为 2 时，实际绘制边界达到了 34，超出了 QPixmap 物理包络边界。
  • 解决：在绘制时主动缩减范围留出画笔边界：painter.drawEllipse(1, 1, 30, 30)。
