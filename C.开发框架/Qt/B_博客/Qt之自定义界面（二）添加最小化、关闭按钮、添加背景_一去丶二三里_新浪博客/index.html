Qt之无边框窗口自定义控制按钮与背景绘制三种实现方案 #

在完成了无边框窗口的鼠标拖拽拖动逻辑之后，接下来必然面临两大核心 UI 重建问题：

  1. 控制按钮重建：需要重新添加最小化、关闭按钮，并将其绑定到窗口行为。
  2. 窗口背景定制：需要为窗口铺设美观的背景图或主题色。

本文针对这两个问题给出具体的实现方案。

一、 重建控制按钮 (最小化、关闭) #

因为去掉了系统默认标题栏，我们需要用 QToolButton 或 QPushButton 在窗口右上角手动绘制控制按键，并关联对应的槽函数：

cpp
// 在窗口的构造函数中初始化控制按键
void MainWidget::initTitleButtons()
{
    int w = this->width(); // 获取当前窗口的宽度

    // 1. 创建控制按钮并以当前窗口为 Parent
    QToolButton *minButton   = new QToolButton(this);
    QToolButton *closeButton = new QToolButton(this);

    // 2. 利用 Qt 自带的系统样式获取标准的“最小化”和“关闭”像素图
    QPixmap minPix   = style()->standardPixmap(QStyle::SP_TitleBarMinButton);
    QPixmap closePix = style()->standardPixmap(QStyle::SP_TitleBarCloseButton);

    minButton->setIcon(minPix);
    closeButton->setIcon(closePix);

    // 3. 相对定位：将按钮固定放置在窗口的右上角区域
    minButton->setGeometry(w - 46, 5, 20, 20);
    closeButton->setGeometry(w - 25, 5, 20, 20);

    // 4. 设置鼠标悬停提示
    minButton->setToolTip(tr("最小化"));
    closeButton->setToolTip(tr("关闭"));

    // 5. 设置扁平化样式（无边框、背景透明）
    minButton->setStyleSheet("QToolButton{ background-color: transparent; border: none; }");
    closeButton->setStyleSheet("QToolButton{ background-color: transparent; border: none; }");

    // 6. 连接核心槽函数
    connect(minButton, &QToolButton::clicked, this, &QWidget::showMinimized);
    connect(closeButton, &QToolButton::clicked, this, &QWidget::close);
}

二、 绘制自定义背景的三种核心方案 #

为窗口定制精美的背景，通常有以下三种方案，开发者可根据性能与动态伸缩要求进行选择：

方案 1：使用 QLabel 贴图法（简单快速） #

这是最容易理解的实现方式。在窗口底层铺设一个拉伸的 QLabel 标签，直接载入图片。

cpp
// 在构造函数最前端创建背景 QLabel
QLabel *background = new QLabel(this);

// 载入图片并铺满整个窗口
background->setPixmap(QPixmap(":/images/login_bg.png"));
background->setGeometry(0, 0, this->width(), this->height());

// 💡 关键：设置图片自动缩放填充 QLabel
background->setScaledContents(true);

// 💡 关键：调用 lower() 将背景层置于最底层，防止遮挡表单输入框等其它子控件
background->lower();

方案 2：使用 QLabel 样式表单色填充法（扁平化主题） #

如果你不需要繁琐的图片，只需要指定窗口为一种纯色主题：

cpp
QLabel *background = new QLabel(this);
background->setGeometry(0, 0, this->width(), this->height());

// 通过 QSS 设置背景色
background->setStyleSheet("background-color: rgb(240, 248, 255);");
background->lower();

方案 3：重写 paintEvent 事件自适应绘制（高级推荐） #

当窗口尺寸可能被用户动态拖拽缩放时，使用 QLabel 可能会出现拉伸像素失真或多重绘制 bug。此时，最专业的方法是继承并重写窗口的绘图事件 paintEvent()，直接在窗口画布上绘制背景：

cpp
// 1. 在头文件中声明：
protected:
    void paintEvent(QPaintEvent *event) override;

// 2. 在源文件中实现：
void MainWidget::paintEvent(QPaintEvent *event)
{
    Q_UNUSED(event);
    
    QPainter painter(this);
    
    // 开启反锯齿，保证圆角和图片渲染平滑
    painter.setRenderHint(QPainter::Antialiasing);

    // 加载资源文件中的背景原图
    QPixmap pixmap(":/images/login_bg.png");

    // 💡 关键：将图片按窗口当前实际 rect 大小进行拉伸绘制，完美自适应缩放
    painter.drawPixmap(this->rect(), pixmap);
}
✦提示

关于 paintEvent 绘制半透明圆角窗口的扩展：
若要实现类似于 QQ 登录框的圆角或半透明玻璃效果，可以在 paintEvent 中使用 QPainterPath 裁剪出圆角矩形，然后使用 painter.drawPath 或带 Alpha 值的画笔填充颜色。
