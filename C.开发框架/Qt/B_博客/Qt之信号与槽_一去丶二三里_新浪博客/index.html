Qt之信号与槽 #

在 Qt 开发中，信号与槽（Signals and Slots）是最核心的基础通信机制。对于许多初学者，当遇到多个信号需要响应时，第一反应往往是为每个信号单独编写一个槽函数。然而，多信号连接多槽会无端增加冗余代码和程序维护开销。将多个信号连接到同一个槽函数，然后在槽中进行来源判定，是更优雅的解决方案。

一、 信号与槽的连接语法演进 #

在 Qt 5 中，信号与槽的语法得到了极大的增强。

Qt 4 及以前的传统语法 #

cpp
connect(sender, SIGNAL(valueChanged(int)), receiver, SLOT(setValue(int)));
  • 机制：SIGNAL() 和 SLOT() 宏利用字符串匹配在运行时建立关联。
  • 缺点：缺少编译期类型检查，如果拼写错误或类型不匹配，只能在运行时才发现报错。

Qt 5 开始推荐的新语法 #

cpp
connect(sender, &Sender::valueChanged, receiver, &Receiver::setValue);
  • 优势：
    1. 编译期检查：编译器会在编译阶段验证信号、槽及 Q_OBJECT 宏是否存在，防止拼写错误。
    2. 支持更广：不仅局限于 SLOT 标记的函数，还可以连接到普通全局函数、静态函数以及 C++11 Lambda 表达式。
    3. 参数自动转换：允许兼容类型的隐式转换，信号和槽的参数个数和类型不需要完全相同（信号的参数个数必须不少于槽的参数个数）。

二、 基础连接模式 #

  1. 一对一：
    cpp
    connect(slider, &QSlider::valueChanged, spin_box, &QSpinBox::setValue);
  2. 一对多（一个信号触发多个动作）：
    cpp
    connect(slider, &QSlider::valueChanged, spin_box, &QSpinBox::setValue);
connect(slider, &QSlider::valueChanged, this, &QWidget::showValue);
  3. 多对一（多个信号连接到同一个槽）：
    cpp
    connect(push_button, &QPushButton::clicked, this, &QWidget::show);
connect(tool_button, &QToolButton::clicked, this, &QWidget::show);
  4. 信号接力（信号连接另一个信号）：
    cpp
    connect(push_button, &QPushButton::clicked, this, &QWidget::buttonClicked);
  5. 断开连接：
    cpp
    disconnect(push_button); // 断开该对象上的所有连接
disconnect(push_button, &QPushButton::clicked, this, &QWidget::show); // 断开特定连接

三、 多信号连接同一槽的区分技巧 #

当多个按钮或组件共用同一个 changeButton 槽时，我们可以在槽函数中识别当前是哪一个控件触发了动作。

方法一：通过 QObject::sender() 配合 qobject_cast #

通过 sender() 获取触发信号的发送端 QObject 指针，然后利用 qobject_cast 进行安全的向下转型：

cpp
// 声明识别枚举
enum BUTTON_ID {
    BUTTON_1,
    BUTTON_2,
    BUTTON_3,
    BUTTON_4
};

// 在初始化中设置 ObjectName 以便区分
push_button_1->setObjectName(QString::number(BUTTON_1, 10));
push_button_2->setObjectName(QString::number(BUTTON_2, 10));
tool_button_1->setObjectName(QString::number(BUTTON_3, 10));
tool_button_2->setObjectName(QString::number(BUTTON_4, 10));

connect(push_button_1, &QPushButton::clicked, this, &MyWidget::changeButton);
connect(push_button_2, &QPushButton::clicked, this, &MyWidget::changeButton);
connect(tool_button_1, &QToolButton::clicked, this, &MyWidget::changeButton);
connect(tool_button_2, &QToolButton::clicked, this, &MyWidget::changeButton);

// 槽函数实现
void MyWidget::changeButton()
{
    QObject *sender_obj = QObject::sender();
    QPushButton *push_btn = qobject_cast<QPushButton *>(sender_obj);
    QToolButton *tool_btn = qobject_cast<QToolButton *>(sender_obj);
    
    int index = -1;
    if (push_btn) {
        index = push_btn->objectName().toInt();
    } else if (tool_btn) {
        index = tool_btn->objectName().toInt();
    }
    
    QString information;
    switch(index) {
        case BUTTON_1: information = "clicked Button 1"; break;
        case BUTTON_2: information = "clicked Button 2"; break;
        case BUTTON_3: information = "clicked ToolButton 3"; break;
        case BUTTON_4: information = "clicked ToolButton 4"; break;
        default: information = "Unknown widget clicked"; break;
    }
    QMessageBox::information(this, "Title", information);
}

方法二：利用 QSignalMapper 翻译与转发信号 #

QSignalMapper 可看作是信号的翻译转发器。它可以把一组无参数的信号（如 clicked()）合并重组，并传递预设的 int、QString 或 QObject* 等参数给槽。

cpp
QSignalMapper *signal_mapper = new QSignalMapper(this);

// 绑定映射关系
connect(push_button_1, &QPushButton::clicked, signal_mapper, QOverload<>::of(&QSignalMapper::map));
connect(push_button_2, &QPushButton::clicked, signal_mapper, QOverload<>::of(&QSignalMapper::map));
connect(tool_button_1, &QToolButton::clicked, signal_mapper, QOverload<>::of(&QSignalMapper::map));
connect(tool_button_2, &QToolButton::clicked, signal_mapper, QOverload<>::of(&QSignalMapper::map));

// 设置映射附加参数（这里使用字符串形式传递 ID）
signal_mapper->setMapping(push_button_1, QString::number(BUTTON_1, 10));
signal_mapper->setMapping(push_button_2, QString::number(BUTTON_2, 10));
signal_mapper->setMapping(tool_button_1, QString::number(BUTTON_3, 10));
signal_mapper->setMapping(tool_button_2, QString::number(BUTTON_4, 10));

// 💡 将翻译后的带参信号 mappedString() 关联到具体槽
connect(signal_mapper, &QSignalMapper::mappedString, this, &MyWidget::changeButton);

四、 💡 核心细节说明 #

1. 同一信号连接多个槽的执行顺序 #

  • 在早期（Qt 4.6 以前）：如果一个信号连接到多个槽，信号发射后槽的调用顺序是不确定的。
  • 自 Qt 5 开始：文档明确指出：槽函数的执行顺序与它们被 connect 连接的先后顺序完全一致。

2. 重载函数连接时的歧义处理 #

对于有多个重载版本的信号，例如 QSpinBox::valueChanged 有 valueChanged(int) 和 valueChanged(QString) 两个重载。在使用新式语法时，如果直接书写：

cpp
connect(spin_box, &QSpinBox::valueChanged, this, &ListView::changeValue);

编译器会报出无从匹配重载函数的错误。为了明确告诉编译器调用哪一个版本，我们需要进行函数指针的显式类型转换：

cpp
// 💡 使用 QOverload 进行强制指定（Qt 5.7+ 推荐）
connect(spin_box, QOverload<int>::of(&QSpinBox::valueChanged), this, &ListView::changeValue);

// 或者使用 static_cast 对成员函数指针进行强制转型（经典做法）
connect(spin_box, static_cast<void (QSpinBox::*)(int)>(&QSpinBox::valueChanged), this, &ListView::changeValue);

熟练掌握信号槽的使用，并能清晰地处理多路复用与重载函数，能极大地精简 Qt 项目的架构设计。
