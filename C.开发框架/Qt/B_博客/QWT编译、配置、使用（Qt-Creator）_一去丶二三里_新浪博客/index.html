QWT编译、配置、使用（Qt Creator） #

之前我们介绍过在 Visual Studio 环境下编译和配置 QWT 的方法。本文将着重介绍在 Qt Creator 开发环境中，如何从源码编译、配置并使用 QWT。

一、QWT 简介 #

QWT，全称是 Qt Widgets for Technical Applications，是一个基于 LGPL 版权协议的开源项目。它为科学和技术背景的应用程序提供了丰富的 2D 绘图 GUI 组件。

核心功能 #

  • 数据展示：支持 Curves（曲线）、Sliders（滑动条）、Dials（表盘）、Compasses（指南针/仪表盘）等 2D 窗体部件。
  • 跨平台：完全基于 Qt 实现，继承了 Qt 的跨平台特性。
  • 官方网址：Qwt SourceForge

二、源码目录结构 #

从官网下载或从版本控制系统（SVN/Git）拉取 QWT 源码后，其主要目录结构如下：

  • src/：存放 QWT 控件库的核心源码。
  • designer/：存放让 Qt Creator 拖拽集成 QWT 控件的设计器插件源码。
  • examples/：官方附带的丰富示例程序和源码。
  • doc/：QWT 的离线 API 帮助文档。
  • textengines/：数学指标语言的文本驱动引擎代码。
  • qwt.pro：Qt 核心项目管理文件。

三、编译步骤 #

  1. 打开项目
    启动 Qt Creator，选择“打开文件或项目”，选择 QWT 根目录下的主工程文件 qwt.pro。

  2. 选择构建套件 (Kit)
    根据需要选择对应的编译器套件（例如 Desktop Qt 5.1.0 MSVC2010 或 MinGW）。

  3. 执行编译

    • 依次执行 qmake -> “构建 (Build)”。
    • 编译完成后，会在 QWT 根目录的 lib/ 文件夹下生成核心库文件：
      • Windows MSVC 产生 qwt.dll / qwtd.dll (动态链接库) 和 qwt.lib / qwtd.lib (静态导入库)。
      • MinGW 产生 qwt.dll / qwtd.dll 和 libqwt.a / libqwtd.a。
    • 同时，在插件目录下会生成设计器插件：qwt_designer_plugin.dll。

四、配置 QWT 环境 #

编译成功后，需要将生成的库文件和头文件分发到 Qt 安装目录中，以便在其他项目中进行常规调用。

ℹ笔记

以下以 Qt 安装路径为 D:\Software\Qt\Qt5.1.0\5.1.0\msvc2010 举例。若使用的是 MinGW 编译器，请将目标路径中 msvc2010 替换为 mingw48_32。

1. 拷贝库文件 #

  • 将编译出的 qwtd.dll 和 qwt.dll 拷贝至 D:\Software\Qt\Qt5.1.0\5.1.0\msvc2010\bin 文件夹下。
  • 将编译出的 qwtd.lib 和 qwt.lib (或 libqwtd.a 和 libqwt.a) 拷贝至 D:\Software\Qt\Qt5.1.0\5.1.0\msvc2010\lib 文件夹下。

2. 拷贝设计器插件 #

  • 将插件 qwt_designer_plugin.dll（如果是 MSVC 还需要加上 .lib 文件）拷贝至 D:\Software\Qt\Qt5.1.0\Tools\QtCreator\bin\plugins\designer 目录下。
  • 效果：完成这一步后，重启 Qt Creator 并打开任意 .ui 界面文件，在左侧的控件工具栏中，就会出现全新的 Qwt Widgets 控件分组。

3. 拷贝头文件 #

  • 在 D:\Software\Qt\Qt5.1.0\5.1.0\msvc2010\include 目录下新建一个名为 QWT 的文件夹。
  • 将 QWT 源码中 src/ 目录下的所有头文件（.h 文件）拷贝至刚刚创建的 QWT 文件夹中。

五、在项目中使用 QWT #

要在新项目中使用 QWT 控件，我们需要在项目的 .pro 配置文件中指定库路径和头文件路径。

配置方式一：通用引入 #

在项目的 .pro 配置文件中加入以下配置代码：

ini
# 定义 QWT 动态链接宏
DEFINES += QWT_DLL

# 指定包含头文件目录
INCLUDEPATH += D:/Software/Qt/Qt5.1.0/5.1.0/msvc2010/include/QWT
DEPENDPATH  += D:/Software/Qt/Qt5.1.0/5.1.0/msvc2010/include/QWT

# 指定链接库
LIBS += -LD:/Software/Qt/Qt5.1.0/5.1.0/msvc2010/lib -lqwt
⚠警告

注意在 Release 模式下链接 -lqwt，在 Debug 模式下根据需要选择链接 -lqwtd（对应带 d 的调试版）。

配置方式二：使用 qwt.prf #

QWT 官方提供了特性配置脚本 qwt.prf。如果已编译配置好，也可以直接通过 include 引入：

ini
CONFIG += qwt
include(D:/Works/Qt/QWT/qwt.prf)

或者引入其内置功能脚本：

ini
include(D:/Works/Qt/QWT/qwtfunctions.pri)

通过上述配置，你的 Qt 项目中就可以无缝调用 QWT 强大的 2D 绘图类（如 QwtPlot, QwtPlotCurve）进行科学数据可视化开发了。
