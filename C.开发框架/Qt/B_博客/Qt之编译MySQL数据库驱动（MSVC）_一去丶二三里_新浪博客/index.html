Qt之编译MySQL数据库驱动（MSVC） #

在 Qt 中进行数据库开发时，默认的开源版本可能并未预装所有的商业数据库驱动（例如 MySQL 驱动 QMYSQL）。

从 Qt 5.2 开始，官方安装包已经默认包含了预编译的 QMYSQL 驱动插件。但在 Qt 5.2 之前的版本中，我们需要根据自己的编译器环境（如 MinGW 或 MSVC）和 MySQL SDK 自行编译出相应的驱动动态链接库。

以下介绍在 Windows 平台下，使用 VS2010 (MSVC 2010) + Qt 5.2 源码 编译 MySQL 驱动的完整步骤。

一、 开发环境与前置准备 #

  • 开发工具：Visual Studio 2010 + Qt 5.2 (MSVC 2010 32-bit/64-bit 离线安装包)
  • Qt Visual Studio Add-in 插件（用于在 VS 中管理 Qt 项目）
  • Qt 源码：安装 Qt 时必须勾选 "Sources" (源码) 组件，我们需要用到其中的数据库驱动插件源码。
  • MySQL 开发包：
    1. 前往 MySQL 官网下载 Windows 版的 MySQL Community Server 压缩包（如 32 位的 mysql-5.6.15-win32）。
    2. 解压后放置在指定目录（例如：D:\mysql-5.6.15-win32），我们需要其 include 头文件与 lib 库文件。

二、 编译配置步骤 #

1. 使用 Qt Command Prompt 生成 Makefile #

  1. 选择：开始菜单 -> 所有程序 -> Qt5.2.0 -> MSVC 2010 -> 打开 Qt 5.2.0 for Desktop (MSVC 2010) 终端。
  2. 切换至 Qt 源码中的 MySQL 驱动源码目录（请根据自己的实际路径进行修改）：
    cmd
    cd D:\Software\Qt\Qt5.2.0\5.2.0\Src\qtbase\src\plugins\sqldrivers\mysql
  3. 执行 qmake 指令，指定 MySQL 头文件和库文件的物理路径：
    cmd
    qmake "INCLUDEPATH+=D:\mysql-5.6.15-win32\include" "LIBS+=D:\mysql-5.6.15-win32\lib\libmysql.lib" mysql.pro
    执行成功后，目录下将自动生成用于编译的 Makefile 文件。

2. 使用 VS 命令提示进行编译 #

  1. 选择：开始菜单 -> 所有程序 -> Microsoft Visual Studio 2010 -> Visual Studio Tools -> 打开 Visual Studio 命令提示 (2010)。
  2. 在该命令行终端中，进入上一步的同一个目录：
    cmd
    D:
cd D:\Software\Qt\Qt5.2.0\5.2.0\Src\qtbase\src\plugins\sqldrivers\mysql
  3. 执行编译命令：
    cmd
    nmake
    编译成功后，将在当前目录中生成对应的 QMYSQL 插件文件：qsqlmysql.dll (Release 版) 和 qsqlmysqld.dll (Debug 版)。

三、 环境部署与运行配置 #

编译出的动态库不能直接被程序自动加载，必须分别拷贝到 Qt 开发环境的指定目录：

1. 部署 SQL 驱动插件 #

将刚刚编译生成的 qsqlmysql.dll 和 qsqlmysqld.dll 两个插件库文件，拷贝到 Qt 编译器套件的插件目录中：
D:\Software\Qt\Qt5.2.0\5.2.0\msvc2010_opengl\plugins\sqldrivers\

2. 部署 MySQL 运行时依赖库 #

Qt 驱动插件底端是基于 MySQL 提供的客户端链接库构建的。你必须将 MySQL 安装目录（D:\mysql-5.6.15-win32\lib）下的 libmysql.dll（如果是 Debug 测试建议同时也带上 libmysqld.dll）拷贝到 Qt 编译器套件的运行二进制 bin 目录中：
D:\Software\Qt\Qt5.2.0\5.2.0\msvc2010_opengl\bin\

❢重要
  • 编译和拷贝文件时，必须严格保证编译器架构的位数一致性。如果你使用的是 32 位的 Qt 编译器，你就必须下载并链接 32 位的 MySQL 动态库；同理，64 位环境必须统一链接 64 位的 MySQL 依赖包，否则在运行时会提示 Driver not loaded 错误。
  • 在部署最终的发布程序包时，也必须将 libmysql.dll 文件放置在与你的 .exe 程序同级的根目录下，以便程序能够正常链接数据库。
