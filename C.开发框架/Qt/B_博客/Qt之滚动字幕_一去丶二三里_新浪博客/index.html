Qt实现滚动字幕（走马灯/跑马灯效果） #

在开发客户端的公告栏、新闻头条栏或者关于我们信息展示时，经常需要实现一个文本水平无限循环滚动的动画效果，这在 Web 前端开发中俗称 走马灯/跑马灯（Marquee）。

在 Qt 中，实现滚动字幕常见有以下两种思路：

  1. 字符位移法：低成本方案，直接用 QTimer 定时截取字符串尾部渲染给普通的 QLabel，呈现字符级的跳动滚动。
  2. 像素平滑法：专业方案，继承 QWidget 并重写其 paintEvent()，在定时器触发下递减 X 轴物理像素偏移，实现无缝平滑的平移滑动。

方案一：基于字符串截取的简易滚动 (字符级) #

1. 实现机制 #

利用 QTimer 每隔固定时间（如 500 毫秒）调用一次槽函数，槽函数内部使用 QString::mid(nPos) 从头向尾部截取字符，并将截取后的字符串设为 QLabel 的文本，从而在视觉上产生文字向左挪动消失的动效。

2. 核心代码 #

cpp
// 1. 初始化字幕文本与定时器
m_scrollCaptionStr = QStringLiteral("欢迎加入我们：Qt分享&&交流 26197884  ");
m_scrollCaptionLabel = new QLabel(this);

m_timer = new QTimer(this);
connect(m_timer, SIGNAL(timeout()), this, SLOT(scrollCaption()));
m_timer->start(500); // 间隔 500 毫秒

// 2. 定时器槽函数实现
void MyWidget::scrollCaption()
{
    static int nPos = 0;
    
    // 如果截取位置超过了文本长度，则重置回起点
    if (nPos > m_scrollCaptionStr.length())
    {
        nPos = 0;
    }
    
    // 从 nPos 开始向后截取剩余的全部文本进行显示
    m_scrollCaptionLabel->setText(m_scrollCaptionStr.mid(nPos));
    
    nPos++;
}

方案二：基于 paintEvent 绘制的平滑滚动 (像素级) #

方案一由于是按整字符跳跃，如果字体比较大，跳动感会非常强烈，略显生硬。为了达到像电影字幕般丝滑的平移效果，我们推荐使用 QPainter 像素级重画 的自定义控件方案。

1. 控件头文件 (MarqueeWidget.h) #

cpp
#pragma once
#include <QWidget>
#include <QTimer>

class MarqueeWidget : public QWidget
{
    Q_OBJECT
public:
    explicit MarqueeWidget(QWidget *parent = nullptr);
    
    // 设置需要滚动的文本
    void setText(const QString &text);
    // 设置滚动速度（毫秒/像素）
    void setSpeed(int ms);

protected:
    void paintEvent(QPaintEvent *event) override;

private slots:
    void updateOffset();

private:
    QString m_text;      // 滚动字幕内容
    int m_offset;        // 水平绘制偏移量 (X坐标)
    int m_textWidth;     // 文本渲染后的物理宽度
    QTimer *m_timer;     // 步进定时器
    int m_speedMs;       // 定时器触发间隔时间
};

2. 控件实现文件 (MarqueeWidget.cpp) #

cpp
#include "MarqueeWidget.h"
#include <QPainter>
#include <QFontMetrics>

MarqueeWidget::MarqueeWidget(QWidget *parent)
    : QWidget(parent)
    , m_offset(0)
    , m_textWidth(0)
    , m_speedMs(30) // 默认 30ms 移动一像素，非常丝滑
{
    m_timer = new QTimer(this);
    connect(m_timer, &QTimer::timeout, this, &MarqueeWidget::updateOffset);
    m_timer->start(m_speedMs);
}

void MarqueeWidget::setText(const QString &text)
{
    m_text = text;
    // 使用当前字体测量文本实际在屏幕上占用的物理像素宽度
    m_textWidth = fontMetrics().width(m_text);
    m_offset = this->width(); // 让文本初始位于控件最右侧外边缘
    update();
}

void MarqueeWidget::setSpeed(int ms)
{
    m_speedMs = ms;
    m_timer->start(m_speedMs);
}

void MarqueeWidget::updateOffset()
{
    m_offset -= 1; // 每次向左步进 1 像素
    
    // 💡 循环临界值判断：
    // 当文本最右端也已经完全移出屏幕左侧边缘时 (offset 负值绝对值大于文本总宽)
    if (m_offset < -m_textWidth)
    {
        m_offset = this->width(); // 重新回到最右端探出头
    }
    
    update(); // 触发重绘 paintEvent
}

void MarqueeWidget::paintEvent(QPaintEvent *event)
{
    Q_UNUSED(event);
    QPainter painter(this);
    
    // 开启文本抗锯齿
    painter.setRenderHint(QPainter::TextAntialiasing);
    
    // 计算 Y 轴居中位置
    int fontHeight = fontMetrics().height();
    int yPos = (this->height() - fontHeight) / 2 + fontMetrics().ascent();
    
    // 渲染文本
    painter.drawText(m_offset, yPos, m_text);
}

四、 总结与选型 #

  • 方案一 (字符截断) 胜在代码极其简单，无需写自定义类。如果字幕字符较短，在非高频刷新的非核心 UI 区域，用来做提示已经足够。
  • 方案二 (像素重画) 胜在视觉极其丝滑且易于扩展。你可以很容易在 paintEvent 里面改变字体颜色、加渐变底色，或者绘制跑马灯小图标，是专业级工程的首选。
