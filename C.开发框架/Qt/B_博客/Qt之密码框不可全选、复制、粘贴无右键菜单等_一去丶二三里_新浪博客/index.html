Qt实现安全密码输入框（禁用全选、复制、粘贴及右键菜单） #

在开发桌面客户端登录界面时，出于安全性防窃取、防脚本录入或者防剪贴板泄漏等需求，密码输入框（Password Edit） 的交互策略通常比普通的文本输入框要严格得多。

一般的高安全输入框要求具备以下特性：

  1. 明文隐藏：显示掩码圆点（如 ●●●●●●）。
  2. 禁用右键菜单：防止通过右键弹出“复制”或“显示密码”选项。
  3. 禁用全选/复制/粘贴快捷键：屏蔽 Ctrl+C、Ctrl+V、Ctrl+A 等操作。
  4. 禁用拖拽选择：屏蔽鼠标按住拖动高亮选中文本。

下面通过派生 QLineEdit 实现一个安全密码输入框 PwdLineEdit。

一、 控件类声明 (PwdLineEdit.h) #

cpp
#pragma once
#include <QLineEdit>
#include <QKeyEvent>
#include <QMouseEvent>

class PwdLineEdit : public QLineEdit
{
    Q_OBJECT
public:
    explicit PwdLineEdit(QWidget *parent = nullptr);
    ~PwdLineEdit();

protected:
    // 💡 键盘事件拦截：屏蔽全选、复制、粘贴快捷键
    void keyPressEvent(QKeyEvent *event) override;

    // 💡 鼠标移动事件拦截：屏蔽拖拽选中文本
    void mouseMoveEvent(QMouseEvent *event) override;
};

二、 控件类实现 (PwdLineEdit.cpp) #

cpp
#include "pwd_line_edit.h"

PwdLineEdit::PwdLineEdit(QWidget *parent)
    : QLineEdit(parent)
{
    // 1. 禁用系统自带的右键上下文菜单
    this->setContextMenuPolicy(Qt::NoContextMenu);

    // 2. 设置密码掩码显示模式（密码字符显示为小圆点）
    this->setEchoMode(QLineEdit::Password);

    // 3. 设置水印提示文本
    this->setPlaceholderText(QStringLiteral("请输入密码"));

    // 4. 限制最大输入长度（如限制为 16 位密码）
    this->setMaxLength(16);

    // 5. 设置输入框样式
    this->setStyleSheet(
        "QLineEdit {"
        "  border: 1px solid gray;"
        "  border-radius: 4px;"
        "  padding: 2px 5px;"
        "  font-size: 12px;"
        "  color: black;"
        "}"
        "QLineEdit:hover {"
        "  border: 1px solid rgb(70, 200, 50);" // 悬浮时变绿
        "}"
    );
}

PwdLineEdit::~PwdLineEdit()
{
}

void PwdLineEdit::keyPressEvent(QKeyEvent *event)
{
    // 判断按下的组合键是否匹配标准的“全选”、“复制”、“粘贴”快捷序列
    if (event->matches(QKeySequence::SelectAll))
    {
        // 拦截，直接忽略返回
        return;
    }
    else if (event->matches(QKeySequence::Copy))
    {
        // 拦截复制
        return;
    }
    else if (event->matches(QKeySequence::Paste))
    {
        // 拦截粘贴
        return;
    }
    else
    {
        // 💡 必须：其它正常按键（如字母、数字、回退键等）转发给基类处理
        QLineEdit::keyPressEvent(event);
    }
}

void PwdLineEdit::mouseMoveEvent(QMouseEvent *event)
{
    Q_UNUSED(event);
    // 💡 拦截鼠标移动：
    // 普通 QLineEdit 在鼠标按住并划过文本时会反显选中蓝底背景，
    // 我们在这里不调用基类事件，直接返回，即可彻底禁用鼠标选中文本的动画与状态。
    return;
}

三、 使用场景集成 #

在登录窗口中，直接将 UI 里的密码框声明为你的 PwdLineEdit 即可：

cpp
// 1. 初始化密码输入框
PwdLineEdit *passwordEdit = new PwdLineEdit(this);

// 2. 获取用户录入的实际密码明文
QString plainPassword = passwordEdit->text(); // 虽然显示为圆点，但 text() 取得的仍是明文内容

通过这套封装，能在不接入额外繁重安全 SDK 的前提下，防止终端物理泄露和绝大多数基础级的键盘复制截取动作。
