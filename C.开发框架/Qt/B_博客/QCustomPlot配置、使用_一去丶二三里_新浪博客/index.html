QCustomPlot配置与初级使用 #

QCustomPlot 是一个基于 Qt 的轻量级开源 2D 图表库。它可用于在 Qt 应用程序中绘制高品质的曲线图、趋势图、极坐标图、柱状图等各类二维数据图表。

不同于庞大复杂的 QWT 库，QCustomPlot 设计得非常轻巧，核心只有两个源文件：qcustomplot.h 与 qcustomplot.cpp。你可以选择直接将这两个文件加入你的项目，也可以预先将其编译为动态链接库（DLL/SO）。

  • 授权协议：GPL
  • 开发语言：C/C++
  • 支持系统：跨平台（Windows, Linux, macOS 等）
  • 官方网址：QCustomPlot 官网

一、配置步骤 #

  1. 下载源码
    前往 QCustomPlot 官网下载页，下载最新的压缩包，解压后可以找到 qcustomplot.h 和 qcustomplot.cpp 两个核心源文件。

  2. 添加文件到工程

    • 将 qcustomplot.h 和 qcustomplot.cpp 拷贝到你的 Qt 工程目录下。
    • 在 Qt Creator 的项目视图中，右键点击工程文件夹，选择“添加现有文件...”，将这两个文件引入项目。

  3. 配置 .pro 文件
    因为 QCustomPlot 的部分功能（如打印成 PDF 或图片等）依赖于 Qt 内部的 printsupport 打印支持模块，所以需要在项目的 .pro 配置文件中添加该模块：

    ini
    QT += printsupport

二、使用示例 #

下面以在主窗口中绘制一条 y=x3 的三次幂函数曲线为例，演示 QCustomPlot 的初级用法。

在 MainWindow 构造函数中编写以下代码：

cpp
#include "qcustomplot.h"
#include <qmath.h>

MainWindow::MainWindow(QWidget *parent) :
    QMainWindow(parent),
    ui(new Ui::MainWindow)
{
    ui->setupUi(this);

    // 实例化 QCustomPlot 绘图区
    QCustomPlot *customPlot = new QCustomPlot(this);
    customPlot->resize(300, 300);

    // 定义存放绘图数据的双精度浮点数数组，101 为采样点长度
    QVector<double> x(101), y(101);

    // 计算 y = x^3 数据点
    // 为了让曲线正负对称，X 轴采样区间设为 [-10, 10]
    for (int i = 0; i < 101; ++i)
    {
        x[i] = i / 5.0 - 10.0;
        y[i] = qPow(x[i], 3); // 计算立方值
    }

    // 1. 向绘图区域添加一条曲线通道 (Graph)
    customPlot->addGraph();

    // 2. 将数据绑定到第一个 Graph 通道上
    customPlot->graph(0)->setData(x, y);

    // 3. 设置水平轴与垂直轴的名称标签
    customPlot->xAxis->setLabel("x");
    customPlot->yAxis->setLabel("y");

    // 4. 设置轴刻度范围，否则可能超出默认视口范围看不到波形
    customPlot->xAxis->setRange(-11, 11);
    customPlot->yAxis->setRange(-1100, 1100);
    
    // 5. 触发重绘渲染
    customPlot->replot();
}

关键函数解析 #

  • addGraph()：为 QCustomPlot 注册一个新的图表曲线，多条曲线可以通过 graph(index) 索引进行管理。
  • setData(x, y)：为曲线加载数据，其参数必须是 QVector<double> 类型的坐标数组。
  • xAxis->setRange() / yAxis->setRange()：设置坐标轴的逻辑视口大小。若要自动适应数据点，也可以使用：
    cpp
    customPlot->graph(0)->rescaleAxes(); // 根据数据自动调整坐标范围
  • replot()：在数据或者样式被更新后，强制绘图区重绘刷新。

三、高级功能前瞻 #

除了简单的静态曲线绘制，QCustomPlot 还支持以下高级特性：

  • 实时数据描绘：配合定时器（QTimer）周期性追加数据点，实现示波器或监控图表的平滑滚动。
  • 图表交互：支持通过鼠标滚轮进行坐标轴缩放，或通过鼠标拖拽进行图表平移（Panning）。
  • 多轴支持：可以在一个绘图区内显示多个独立刻度轴（如左 Y 轴和右 Y 轴）。
  • 多样化渲染：支持渲染柱状图（QCPBars）、统计盒图（QCPStatisticalBox）以及多色热力图（QCPColorMap）。
