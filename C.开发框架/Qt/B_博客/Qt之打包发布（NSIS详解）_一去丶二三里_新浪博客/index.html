Qt之打包发布（NSIS详解） #

在 Windows 平台上开发完 Qt 程序后，需要将程序打包发布给用户。本文将介绍如何查找动态链接库依赖项，并使用 NSIS 工具制作标准的安装包。

一、发布方式对比 #

Qt 程序的发布方式主要有以下两种：

发布方式 原理 优点 缺点
静态编译 将所有关联的库直接编译进 .exe 可执行程序中 发布非常简单，单个文件即可运行 生成的可执行程序体积较大，且可能涉及 LGPL 授权协议合规性 问题
动态编译 可执行程序在运行时动态加载同级或系统目录下的 .dll 库 生成的可执行程序体积小，且能规避商业闭源协议限制 需要手动收集并附带各种 .dll 依赖文件，发布相对繁琐
✦提示

绝大多数商业或开源项目推荐使用 动态编译 发布，既有利于模块升级，又能规避 LGPL 协议的闭源合规风险。

二、查找依赖项 #

在动态发布程序时，必须确保客户端电脑上拥有所有运行所需的动态链接库。

1. 检测依赖库 #

  • 推荐工具：Dependency Walker
  • 检测方法：使用 Dependency Walker 打开编译出的 .exe 文件，工具会自动扫描并列出该程序所依赖的所有底层 .dll 文件。将缺失的库逐步拷贝到程序同级目录下，重新检测，直到没有警告。
  • 命令行替代方案：在 Qt 5 中，官方提供了一个专门的打包工具 windeployqt，可自动复制所有的依赖项：
    bash
    windeployqt MyProject.exe

2. 常见的 Qt 依赖库 #

  1. Qt 核心模块库：
    • Qt5Core.dll
    • Qt5Gui.dll
    • Qt5Widgets.dll
  2. ICU 字符集依赖库（Qt 5 强制依赖）：
    • icudt51.dll
    • icuin51.dll
    • icuuc51.dll
  3. EGL 渲染支持库：
    • libEGL.dll
    • libGLESv2.dll
  4. 平台插件库 (Platforms)：
    • 必须在安装目录下新建 platforms 文件夹，并放入 qwindows.dll 插件。
    • 音视频库需要放入 mediaservice 文件夹；图片支持需要放入 imageformats 文件夹。
    ⚠警告

    插件库必须严格保持原有的目录层次结构。例如：平台插件必须放在 [安装根目录]/platforms/qwindows.dll。 5. MSVC 运行时库：

    • msvcp100.dll
    • msvcr100.dll (根据使用的编译器版本选择，如 VS2010 对应 100 系列，VS2013 对应 120 系列)

    [!IMPORTANT] 注意发布版本（Debug/Release）的区别：

    • Debug 版本 的库文件名后缀带 d（如 Qt5Cored.dll）。
    • Release 版本 的库文件名不带 d（如 Qt5Core.dll）。发布给最终用户的安装包必须使用 Release 版本编译。

三、关于 NSIS 安装包制作 #

NSIS（Nullsoft Scriptable Install System）是一款功能强大的 Windows 安装/卸载制作系统。

1. NSIS 特点 #

  • 免费开源，体积轻量，系统开销小。
  • 支持脚本编写，可定制性极强，几乎可以控制安装、卸载过程中的所有细节。

2. 推荐工具 #

  • NSIS (核心编译器)
  • HM NIS Edit (集成了脚本向导的可视化 IDE)

四、使用 HM NIS Edit 制作安装包 #

通过“脚本向导”+“手动微调”即可快速生成个性化安装脚本。

1. 向导步骤 #

  1. 启动向导：打开 HM NIS Edit，选择“文件” -> “新建脚本向导”。
  2. 填写程序基本信息：包括软件名称、版本号、官方网站、开发作者等。
  3. 设置安装选项：选择安装程序语言为 SimpChinese (简体中文)。
  4. 目录与授权：指定默认安装路径（例如：$PROGRAMFILES\MySoft），并指定授权许可协议文件（.txt 或 .rtf 格式）。
  5. 添加发布文件：
    • 选中可执行程序 .exe。
    • 添加程序依赖的所有 .dll 文件，并导入包含插件（如 platforms/）的文件夹。
    ❢重要

    若要保持子文件夹结构，在添加文件夹时需勾选“包含子目录”并设置正确的输出目标路径。 6. 创建快捷方式：设置在“开始菜单”和“桌面”创建可执行程序的快捷方式，并指定卸载图标。 7. 编译脚本：向导完成后，勾选“保存脚本”并“编译运行”。NSIS 会自动生成一个独立的 setup.exe 安装文件。

2. 生成的 .nsi 脚本片段示例 #

以下是向导自动生成的 pro 风格脚本配置片段：

nsis
; 确保包含多语言支持
!insertmacro MUI_LANGUAGE "SimpChinese"

; 定义安装目录
InstallDir "$PROGRAMFILES\MyQtApp"

; 安装段落
Section "MainSection" SEC01
  SetOutPath "$INSTDIR"
  File "D:\Deploy\MyQtApp.exe"
  File "D:\Deploy\Qt5Core.dll"
  
  ; 保持插件子目录结构
  SetOutPath "$INSTDIR\platforms"
  File "D:\Deploy\platforms\qwindows.dll"
SectionEnd

通过修改 .nsi 脚本，开发者可以轻松实现添加自定义注册表、配置环境变量或执行第三方静默安装等高级需求。
