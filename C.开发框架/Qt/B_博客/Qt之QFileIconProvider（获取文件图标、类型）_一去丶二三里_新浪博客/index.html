Qt之QFileIconProvider（获取文件图标、类型） #

在编写文件浏览器、桌面工具或下载管理软件时，我们往往需要获取系统对各类文件的默认展示图标以及类型文字说明（如“文件夹”、“文本文件”、“PDF 文档”等）。

在 Qt 开发中，有两种主流的方式来实现这一需求：

  1. 方式一：使用 Qt 内置的 QFileIconProvider 接口。
  2. 方式二：在 Windows 平台下，直接调用 Win32 API 接口（SHGetFileInfo）。

方式一：使用 Qt 内置的 QFileIconProvider #

QFileIconProvider 是 Qt 专门提供的用于获取文件与目录系统图标和类型信息的类。使用起来非常简单。

1. 获取通用文件夹/文件类型的图标 #

cpp
#include <QFileIconProvider>
#include <QIcon>

QFileIconProvider icon_provider;

// 获取通用的“文件夹”图标
QIcon folder_icon = icon_provider.icon(QFileIconProvider::Folder);

// 获取通用的“文件”图标
QIcon file_icon = icon_provider.icon(QFileIconProvider::File);

2. 获取具体磁盘文件的图标与类型 #

对于本地实际存在的物理文件，我们可以传入其 QFileInfo 来查询其特有的图标（如 .docx 会显示 Word 蓝色图标）：

cpp
#include <QFileInfo>
#include <QFileIconProvider>
#include <QIcon>

QFileInfo file_info("C:/test_document.docx");
QFileIconProvider icon_provider;

// 获取特定文件的系统图标
QIcon docx_icon = icon_provider.icon(file_info);

// 获取特定文件的系统类型说明名称（如 "Microsoft Word Document"）
QString docx_type = icon_provider.type(file_info);

方式二：利用 Windows API（基于文件扩展名虚拟查询） #

💡 为什么需要 Windows API 的方式？ #

根据 Qt 官方的设计，QFileIconProvider 解析具体文件图标时，必须基于本地实际存在的文件。如果我们只是查询网络传输的数据列表，或者在界面中列举不存在的虚拟文件，使用 QFileIconProvider 将无法正确提取图标。

如果在这种情况下强制在本地生成临时空文件来进行图标提取，当数据量较大时，会引发频繁的物理磁盘 I/O 读写，严重拖慢程序执行效率。

在 Windows 下，我们可以使用底层的 Shell API SHGetFileInfoA。该接口支持传入 SHGFI_USEFILEATTRIBUTES 标志，从而允许我们仅仅传入一个扩展名字符串（如 .txt），即可直接向 Windows 缓存获取系统预设的图标与类型说明，实现非物理虚拟解析。

C++ 具体实现代码： #

cpp
#include <windows.h>
#include <shellapi.h>
#include <string>
#include <QIcon>
#include <QPixmap>

class FileHelper
{
public:
    static QIcon getFileIcon(const QString &file_name);
    static QString getFileType(const QString &file_name);
    static QIcon getFolderIcon();
    static QString getFolderType();
};

// 1. 根据文件名/扩展名获取系统图标
QIcon FileHelper::getFileIcon(const QString &file_name)
{
    QIcon default_file_icon = QIcon(":/icon/file"); // 默认回滚图标
    if (file_name.isEmpty())
        return default_file_icon;

    // 提取后缀名
    std::string str = "file";
    int index = file_name.lastIndexOf(".");
    if (index >= 0) {
        QString suffix = file_name.mid(index); 
        str = suffix.toUtf8().constData(); // 转化为 std::string
    }
    LPCSTR name = str.c_str();
    
    SHFILEINFOA info;
    // 💡 传入 SHGFI_USEFILEATTRIBUTES 以允许对不存在的文件仅进行扩展名匹配
    if (SHGetFileInfoA(name,
                       FILE_ATTRIBUTE_NORMAL,
                       &info,
                       sizeof(info),
                       SHGFI_SYSICONINDEX | SHGFI_ICON | SHGFI_USEFILEATTRIBUTES)) {
        HICON icon = info.hIcon;
        // 转化为 Qt 的 QIcon
        default_file_icon = QIcon(QPixmap::fromWinHICON(icon));
        DestroyIcon(icon); // 🔑 释放系统 HICON 句柄，防范内存泄露
    }
    return default_file_icon;
}

// 2. 根据文件名/扩展名获取文件类型描述
QString FileHelper::getFileType(const QString &file_name)
{
    QString file_type = "file";
    if (file_name.isEmpty())
        return file_type;

    std::string str = "file";
    int index = file_name.lastIndexOf(".");
    if (index >= 0) {
        QString suffix = file_name.mid(index); 
        str = suffix.toUtf8().constData();
    }
    LPCSTR name = str.c_str();
    
    SHFILEINFOA info;
    if (SHGetFileInfoA(name,
                       FILE_ATTRIBUTE_NORMAL,
                       &info,
                       sizeof(info),
                       SHGFI_TYPENAME | SHGFI_USEFILEATTRIBUTES)) {
        std::string type = info.szTypeName;
        file_type = QString::fromLocal8Bit(type.c_str());
    }
    return file_type;
}

// 3. 获取通用的文件夹图标
QIcon FileHelper::getFolderIcon()
{
    QIcon folder_icon = QIcon(":/icon/folder");
    std::string str = "folder";
    LPCSTR name = str.c_str();
    
    SHFILEINFOA info;
    if (SHGetFileInfoA(name,
                       FILE_ATTRIBUTE_DIRECTORY, // 💡 目录属性
                       &info,
                       sizeof(info),
                       SHGFI_SYSICONINDEX | SHGFI_ICON | SHGFI_USEFILEATTRIBUTES)) {
        HICON h_icon = info.hIcon;
        folder_icon = QIcon(QPixmap::fromWinHICON(h_icon)); 
        DestroyIcon(h_icon);
    }
    return folder_icon;
}

// 4. 获取通用的文件夹类型描述
QString FileHelper::getFolderType()
{
    QString folder_type = "folder";
    std::string str = "folder";
    LPCSTR name = str.c_str();
    
    SHFILEINFOA info;
    if (SHGetFileInfoA(name,
                       FILE_ATTRIBUTE_DIRECTORY,
                       &info,
                       sizeof(info),
                       SHGFI_TYPENAME | SHGFI_USEFILEATTRIBUTES)) {
        std::string type = info.szTypeName;
        folder_type = QString::fromLocal8Bit(type.c_str());
    }
    return folder_type;
}

四、 总结与参考 #

  • 跨平台考量：QFileIconProvider 是跨平台的，如果项目需要兼容 Linux/macOS，应在物理文件存在的情况下优先考虑它。
  • 性能优化考量：在 Windows 独占平台上处理海量不存在的文件时，调用 Windows API 并指定 SHGFI_USEFILEATTRIBUTES 能够显著降低物理磁盘开销，是文件管理器类软件的标准设计手段。
  • 更多延伸：更细致的图标与文件管理扩展应用，可阅读博主后续的《Qt之QFileIconProvider续（获取文件图标、类型）》专题博文。
