Qt之开机自启动 #

在 Windows 操作系统中，很多软件（如系统工具、杀毒软件或核心服务）都需要开机自动运行。在发布自己开发的 Qt 应用程序时，我们也常常有“开机自启动”的需求。

在 Windows 下，实现开机自启动最常见也最简单的方式就是修改系统注册表的启动项。

一、代码实现原理 #

Windows 系统存放当前用户开机启动项的注册表路径为：
HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run

在 Qt 中，我们可以使用 QSettings 类非常方便地读写 Windows 注册表。

核心实现代码 #

cpp
#include <QApplication>
#include <QSettings>

#define REG_RUN "HKEY_CURRENT_USER\\Software\\Microsoft\\Windows\\CurrentVersion\\Run"

/**
 * @brief 设置程序是否开机自启动
 * @param is_auto_start true 为开启自启动，false 为取消自启动
 */
void SettingDialog::setAutoStart(bool is_auto_start)
{
    // 获取应用程序名称 (用作注册表中的键名)
    QString application_name = QApplication::applicationName();
    
    // 实例化 QSettings 对象，指定 NativeFormat (在 Windows 下即为读写注册表)
    QSettings *settings = new QSettings(REG_RUN, QSettings::NativeFormat); 
    
    if (is_auto_start)
    {
        // 获取当前可执行程序的绝对路径
        QString application_path = QApplication::applicationFilePath();
        
        // 写入注册表，注意 Windows 路径需要将 "/" 替换为 "\\"
        settings->setValue(application_name, application_path.replace("/", "\\"));
    }
    else
    {
        // 从注册表中移除启动项
        settings->remove(application_name);
    }
    
    // 释放资源
    delete settings;
}

代码解析 #

  • QApplication::applicationName()：获取应用程序名称，作为注册表键值对中的 Key。
  • QApplication::applicationFilePath()：获取当前可执行文件的完整路径，作为 Value 写入注册表。
  • replace("/", "\\")：Windows 注册表路径分隔符为反斜杠 \，而 Qt 路径默认返回正斜杠 /，需要进行替换。

二、注册表路径验证 #

  1. 按下 Win + R 打开运行窗口，输入 regedit 并回车，启动注册表编辑器。
  2. 导航至以下路径：
    HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run
  3. 调用上述自启动配置函数后，你可以在右侧区域看到新添加的以你程序名称为键、以可执行程序路径为值的键值对。

三、权限问题与 UAC 拦截解决办法 #

由于修改注册表涉及系统配置安全，在写入注册表或程序自启动运行时，可能会遭到 Windows 账户控制（UAC）或杀毒软件的拦截，导致自启动失效。

解决此类权限拦截问题主要有以下两种思路：

1. 赋予程序管理员运行权限 #

我们需要让程序在启动时，默认以系统管理员身份运行。

  • 若使用 Visual Studio 编译开发： 在工程上右键 -> 属性 -> 链接器 (Linker) -> 清单文件 (Manifest File) -> 将 UAC 执行级别 (UAC Execution Level) 设置为 requireAdministrator。
  • 生成效果：重新生成程序后，你会发现可执行程序的 .exe 文件图标旁边会多出一个小盾牌标志，表示程序每次启动都会自动申请管理员权限。

2. 手动调整电脑的 UAC 级别 #

若不想修改程序属性，也可以指导用户在控制面板中调低 Windows 的 UAC（用户帐户控制）级别，避免其拦截注册表修改行为。详细配置可以参考相关的 UAC 介绍。
