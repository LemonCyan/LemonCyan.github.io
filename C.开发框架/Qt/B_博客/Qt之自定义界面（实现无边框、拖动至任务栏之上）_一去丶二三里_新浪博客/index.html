Qt之无边框自定义界面实现与鼠标拖动置顶 #

在 Qt 商业产品开发中，系统默认的蓝白风格标题栏与专业的 UI 设计几乎完全格格不入。要打造出像 QQ、网易云音乐等精致的客户端界面，第一步往往就是去掉系统标题栏，自定义整个窗口的外观。

本文从零开始搭建一个无边框窗口，包含拖拽移动和始终悬浮于任务栏以上的完整实现。

一、 去除系统标题栏（FramelessHint） #

在窗口构造函数中，通过 setWindowFlags() 设置两个关键标志位：

cpp
// 窗口初始化时调用（通常在构造函数中）
this->setWindowFlags(Qt::FramelessWindowHint          // ① 去除标题栏与窗口边框
                   | Qt::WindowStaysOnTopHint);        // ② 锁定窗口始终浮于任务栏之上

// 开启鼠标跟踪（必须设置，否则 mouseMoveEvent 在没有按键时不触发）
this->setMouseTracking(true);
❢重要

Qt::WindowStaysOnTopHint 非常关键：若只设置了 FramelessWindowHint 而没有这个标志，用户可以将窗口拖入任务栏区域下方而消失，导致窗口无法通过点击恢复。

二、 声明鼠标拖拽相关变量（.h 文件） #

cpp
class LoginDialog : public QDialog
{
    Q_OBJECT
protected:
    void mousePressEvent(QMouseEvent *event)   override;
    void mouseMoveEvent(QMouseEvent *event)    override;
    void mouseReleaseEvent(QMouseEvent *event) override;

private:
    QPoint m_movePoint;    // 记录鼠标按下时相对于窗口的坐标偏移
    bool   m_mousePressed; // 标记鼠标左键是否处于按住状态
};

三、 实现三个鼠标事件（.cpp 文件） #

cpp
// ① 鼠标按下：记录鼠标相对于窗口的位置偏移
void LoginDialog::mousePressEvent(QMouseEvent *event)
{
    if (event->button() == Qt::LeftButton)
    {
        m_mousePressed = true;
        // event->pos() 返回鼠标相对于窗口客户区的局部坐标
        // 等价于: event->globalPos() - this->pos()
        m_movePoint = event->pos();
    }
}

// ② 鼠标移动：计算新位置并移动窗口
void LoginDialog::mouseMoveEvent(QMouseEvent *event)
{
    if (m_mousePressed)
    {
        // event->globalPos() 返回鼠标在整个屏幕坐标系上的绝对坐标
        QPoint globalPos = event->globalPos();
        
        // 新窗口位置 = 全局鼠标坐标 - 按下时记录的局部偏移
        this->move(globalPos - m_movePoint);
    }
}

// ③ 鼠标释放：结束拖拽
void LoginDialog::mouseReleaseEvent(QMouseEvent *event)
{
    Q_UNUSED(event);
    m_mousePressed = false;
}
✦提示

构造函数中记得初始化 m_mousePressed = false！
如果忘记初始化，m_mousePressed 可能在未按鼠标时随机为 true，导致窗口在鼠标刚移入时就开始乱飞移动。

四、 扩展：最小化、关闭按钮与背景图 #

去掉系统标题栏后，对应的最小化、最大化、关闭按钮也一并消失了，需要手动用 QPushButton 或 QToolButton 重建这些控件，并连接自定义槽：

cpp
// 关闭按钮
m_closeBtn = new QPushButton(this);
m_closeBtn->setIcon(QIcon(":/Icons/close.png"));
m_closeBtn->setStyleSheet("QPushButton{ background: transparent; border: none; }"
                           "QPushButton:hover{ background: rgba(255,0,0,0.7); }");
connect(m_closeBtn, &QPushButton::clicked, this, &QWidget::close);

// 最小化按钮
m_minBtn = new QPushButton(this);
connect(m_minBtn, &QPushButton::clicked, this, &QWidget::showMinimized);

关于背景图和更精细的自定义样式，请参考本系列的续篇：Qt之自定义界面（二）— 添加最小化、关闭按钮、添加背景。
