Qt之生成PDF文件（图片、文本、HTML） #

在 Qt 项目开发中，生成报表或导出文档时，生成本地 PDF 文件 是一项极其常见的功能。Qt 中主要利用 QPrinter（打印机类）来实现 PDF 导出。QPrinter 不仅能通过物理驱动联络打印机打出纸张，还能将渲染引擎重定向输出为 PDF 字节流保存至本地磁盘。

下面详细讲解在 Qt 中将 图片、普通文本 和 HTML 富文本 导出成 PDF 的具体代码实现。

一、 准备工作 #

使用打印和 PDF 导出模块前，需要在工程配置文件中引入 printsupport 模块：

1. 修改 .pro 文件 #

QT += printsupport

2. 引入头文件 #

cpp
#include <QPrinter>
#include <QPainter>
#include <QTextDocument>

二、 图片（控件快照）生成 PDF #

本方案通过将指定的窗口部件（Widget）抓取为 QPixmap 截图，然后利用 QPainter 缩放并绘制到 PDF 虚拟画布中。

cpp
void exportImageToPdf(QWidget *mainWidget, const QString &savePath)
{
    // 1. 初始化高分辨率打印机，配置 A4 纸张，输出格式为 PDF 格式
    QPrinter printer(QPrinter::HighResolution);
    printer.setPageSize(QPrinter::A4);
    printer.setOutputFormat(QPrinter::PdfFormat);
    printer.setOutputFileName(savePath); // 保存路径如 "E:\\test_pixmap.pdf"

    // 2. 抓取当前窗口控件的屏幕快照
    // 注意：Qt 5 中 grabWidget 已被废弃，建议直接使用 widget->grab()
    QPixmap pixmap = mainWidget->grab(mainWidget->rect());

    // 3. 使用 QPainter 将位图重绘到打印设备上
    QPainter painter;
    if (painter.begin(&printer))
    {
        QRect rect = painter.viewport();
        
        // 计算缩放比例，使得抓取的图片自适应铺满 A4 纸张宽度
        int scaleRatio = rect.width() / pixmap.width();
        painter.scale(scaleRatio, scaleRatio);
        
        // 绘制快照图
        painter.drawPixmap(0, 0, pixmap);
        painter.end();
    }
}

三、 纯文本生成 PDF #

适合流式文本或简易报表输出。使用 QPainter::drawText() 在打印机设备上按行计算坐标偏移直接写入。

cpp
void exportTextToPdf(const QString &savePath)
{
    QPrinter printer(QPrinter::HighResolution);
    printer.setOutputFormat(QPrinter::PdfFormat);
    printer.setOutputFileName(savePath); // 如 "E:\\test_text.pdf"

    QPainter painter;
    if (painter.begin(&printer))
    {
        QDateTime currentDateTime = QDateTime::currentDateTime();
        QString dateString = currentDateTime.toString("yyyy-MM-dd hh:mm:ss ddd");
        
        QPoint drawPoint(100, 100); // 初始绘制锚点位置
        
        for (int i = 1; i <= 5; ++i)
        {
            QString message = QString("%1    %2    %3")
                              .arg(QString::number(i))
                              .arg(dateString)
                              .arg(QStringLiteral("北京"));
                              
            // 每次递增 150 像素（由于是 HighResolution，高分辨率下像素间距需拉大）
            drawPoint.setY(drawPoint.y() + 150); 
            painter.drawText(drawPoint, message);
        }
        
        // 💡 提示：如果有多页数据，调用 newPage() 即可起用新的一页继续书写
        // printer.newPage(); 
        
        painter.end();
    }
}

四、 HTML 富文本生成 PDF #

如果我们需要导出包含精美样式表格、粗体字、换行段落的复杂排版，最简单的方法是使用 HTML 代码。通过 QTextDocument 对 HTML 内容进行解析，并直接调用其内置的 print() 函数输出到 PDF。

cpp
void exportHtmlToPdf(const QString &savePath)
{
    // 1. 初始化 PDF 打印设置
    QPrinter printer(QPrinter::ScreenResolution); // 可视分辨率
    printer.setPageSize(QPrinter::A4);
    printer.setOutputFormat(QPrinter::PdfFormat);
    printer.setOutputFileName(savePath); // 如 "E:\\test_html.pdf"

    // 2. 构造 HTML 数据（包含 CSS 表格样式）
    QString html = R"(
        <html>
        <head>
        <style>
            table { width: 100%; border-collapse: collapse; }
            th, td { border: 1px solid gray; padding: 8px; text-align: left; }
            th { background-color: #f2f2f2; }
        </style>
        </head>
        <body>
            <h2>文件属性清单</h2>
            <table>
                <tr>
                    <th>名称</th>
                    <th>修改日期</th>
                    <th>类型</th>
                    <th>大小</th>
                </tr>
                <tr>
                    <td>不同内核编译KO的区别.note</td>
                    <td>2013-12-06</td>
                    <td>Markdown</td>
                    <td>12 KB</td>
                </tr>
                <tr>
                    <td>Qt之开机自启动.cpp</td>
                    <td>2013-12-05</td>
                    <td>C++ Source</td>
                    <td>4 KB</td>
                </tr>
            </table>
        </body>
        </html>
    )";

    // 3. 使用 QTextDocument 解析 HTML 并套入打印机保存
    QTextDocument doc;
    doc.setHtml(html);
    doc.print(&printer); // 自动完成页面分割与渲染输出
}

🛠️ 排版避坑指南 #

  1. 分辨率适配 (HighResolution vs ScreenResolution)：
    • 默认使用 HighResolution（高分辨率）会导致普通的画笔宽度、字体大小在生成的 PDF 中看起来变得极为幼细或难以辨认。这是因为高分辨率打印机下的逻辑像素 DPI 大幅提升。
    • 对普通屏幕截图或纯文字导出，推荐使用屏幕分辨率 QPrinter::ScreenResolution，或者显式使用 painter.scale() 根据物理英寸或纸张视口大小重算比例系数。
  2. 多页排版折页：
    • 在使用 QPainter 手动写字时，应记录好当前的 Y 坐标高度。一旦 Y 坐标超出了纸张的可绘制范围（可通过 printer.pageRect() 换算得出），必须调用 printer.newPage() 重置绘图区域，否则字会重叠或丢失在可见区之外。
