QML文本控件Text属性实战：可运行代码示例与排版效果对照 #

学习了 QML Text 组件的理论属性后，我们通过一系列可直接运行的完整 QML 实例，来直观对比不同排版配置参数下的真实渲染效果。

为了能在本地直接运行，所有范例都包含在 Window 顶级容器中。你可以在 qmlscene 或 Qt Creator 中直接加载运行。

一、 属性实战范例 #

1. 基础字体属性 (字体、字号、下划线、粗体) #

qml
import QtQuick 2.0
import QtQuick.Window 2.1

Window {
    title: "QML Text 基础属性"
    width: 300
    height: 250
    visible: true

    Column {
        anchors.centerIn: parent
        spacing: 8

        Text { text: "普通文本"; color: "blue" }
        Text { text: "指定字体 (Helvetica)"; font.family: "Helvetica" }
        Text { text: "斜体文本"; font.italic: true }
        Text { text: "删除线文本"; font.strikeout: true }
        Text { text: "下划线文本"; font.underline: true }
        Text { text: "加粗文本"; font.bold: true }
        Text { text: "像素大小字号 (16px)"; font.pixelSize: 16 }
        Text { text: "点大小字号 (16pt)"; font.pointSize: 16 }
    }
}

除了简单的 bold: true 外，QML 提供了 5 级更为精细的字重选择：

3. 长文本物理截断 (clip) vs 省略号省略 (elide) #

当文本框的宽度固定为 50px 时，不同截断属性的效果对比：

qml
import QtQuick 2.0
import QtQuick.Window 2.1

Window {
    title: "QML Text 裁剪与省略"
    width: 400
    height: 320
    visible: true

    Column {
        anchors.centerIn: parent
        spacing: 15

        // A. 关闭裁剪：文本会越过 50px 限制溢出显示
        Text {
            text: "abcdefghijklmnopqrstuvwxyz"
            width: 50
            clip: false
            font.pointSize: 16
        }

        // B. 开启裁剪：超出 50px 的字母会被强行隐藏截断
        Text {
            text: "abcdefghijklmnopqrstuvwxyz"
            width: 50
            clip: true
            font.pointSize: 16
        }

        // C. 不省略：默认折叠状态
        Text {
            text: "abcdefghijklmnopqrstuvwxyz"
            width: 50
            font.pointSize: 16
            elide: Text.ElideNone
        }

        // D. 左侧省略：...xyz
        Text {
            text: "abcdefghijklmnopqrstuvwxyz"
            width: 50
            font.pointSize: 16
            elide: Text.ElideLeft
        }

        // E. 中间省略：ab...yz
        Text {
            text: "abcdefghijklmnopqrstuvwxyz"
            width: 50
            font.pointSize: 16
            elide: Text.ElideMiddle
        }

        // F. 右侧省略：abc...
        Text {
            text: "abcdefghijklmnopqrstuvwxyz"
            width: 50
            font.pointSize: 16
            elide: Text.ElideRight
        }
    }
}

4. 字间距 (letterSpacing) 与 词间距 (wordSpacing) #

  • letterSpacing：控制单个字符之间的物理间距。
  • wordSpacing：控制以空格分隔的单词之间的间距。
qml
import QtQuick 2.0
import QtQuick.Window 2.1

Window {
    title: "QML Text 间距实战"
    width: 450
    height: 200
    visible: true

    Column {
        anchors.centerIn: parent
        spacing: 15

        Text { text: "Hello World (默认间距)"; font.pointSize: 16 }
        
        // 字母拉伸 30px
        Text { 
            text: "Hello World"
            font.pointSize: 16
            font.letterSpacing: 30 
        }

        // 单词拉伸 30px
        Text { 
            text: "Hello World"
            font.pointSize: 16
            font.wordSpacing: 30 
        }
    }
}

6. 强制大小写转换 (font.capitalization) #

qml
import QtQuick 2.0
import QtQuick.Window 2.1

Window {
    title: "QML 大小写转换"
    width: 300
    height: 220
    visible: true

    Column {
        anchors.centerIn: parent
        spacing: 10

        // 默认混合输出
        Text { text: "Hello World"; font.pointSize: 16; font.capitalization: Font.MixedCase }
        // 强制全大写
        Text { text: "Hello World"; font.pointSize: 16; font.capitalization: Font.AllUppercase }
        // 强制全小写
        Text { text: "Hello World"; font.pointSize: 16; font.capitalization: Font.AllLowercase }
        // 小型大写字母
        Text { text: "Hello World"; font.pointSize: 16; font.capitalization: Font.SmallCaps }
        // 单词首字母大写
        Text { text: "hello world"; font.pointSize: 16; font.capitalization: Font.Capitalize }
    }
}

7. 四种自动换行模式 (wrapMode) 对比 #

当给文本限制一个固定宽度 width: 100 时，不同的换行配置渲染效果差异极大：

qml
import QtQuick 2.0
import QtQuick.Window 2.1

Window {
    title: "QML 换行模式对比"
    width: 500
    height: 400
    visible: true

    Row {
        anchors.centerIn: parent
        spacing: 20

        // A. 不换行：直接右侧溢出
        Text {
            text: "I am coming, Qt... Just do it."
            width: 100
            font.pointSize: 14
            wrapMode: Text.NoWrap
        }

        // B. 单词边界换行：在逗号/空格处断开，如果单个词（如Justdoit）超长则仍会溢出
        Text {
            text: "I am coming, Qt... Just do it."
            width: 100
            font.pointSize: 14
            wrapMode: Text.WordWrap
        }

        // C. 字符级任意切分：不管是不是单词，到 100px 直接断开换行
        Text {
            text: "I am coming, Qt... Just do it."
            width: 100
            font.pointSize: 14
            wrapMode: Text.WrapAnywhere
        }

        // D. 智能混合换行：能以单词换行优先，超长单词内部强制断开
        Text {
            text: "I am coming, Qt... Just do it."
            width: 100
            font.pointSize: 14
            wrapMode: Text.Wrap
        }
    }
}

二、 交互信号实战 (超链接点击) #

在展示格式化的 HTML 超链接时，我们需要点击链接在系统默认浏览器中打开对应网页：

qml
import QtQuick 2.0
import QtQuick.Window 2.1

Window {
    title: "QML Text 链接激活交互"
    width: 350
    height: 150
    visible: true

    Text {
        anchors.centerIn: parent
        font.pointSize: 16
        textFormat: Text.RichText // 💡 必须设置为富文本格式
        text: "请访问 <a href='http://qt-project.org'>Qt 官方网站</a>。"

        // 💡 捕获超链接激活信号
        onLinkActivated: {
            console.log("检测到链接点击: " + link)
            // 调用操作系统底层打开默认外部浏览器访问网址
            Qt.openUrlExternally(link)
        }
    }
}

通过上述代码，当用户点击“Qt 官方网站”高亮链接时，便会安全调用操作系统默认浏览器访问网页。
