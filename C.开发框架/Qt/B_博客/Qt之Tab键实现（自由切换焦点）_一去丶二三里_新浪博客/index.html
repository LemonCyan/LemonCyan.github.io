Qt之Tab与Shift+Tab键自定义焦点切换机制（EventFilter） #

在桌面客户端中，良好的键盘无障碍交互（Keyboard Navigation）极其重要。用户习惯于使用 Tab 键 向前切换焦点输入框，使用 Shift + Tab 键 向后倒退切换。

在 Qt 框架中，默认的焦点切换路径是由布局（Layout）管理下的控件初始化顺序决定的。为了定制个性化的焦点链，我们主要有两种开发方式：

  1. 静态配置法（简单推荐）：使用 QWidget::setTabOrder()。
  2. 事件过滤拦截法（高级控制）：利用 installEventFilter() 捕捉键盘事件，实现包含特定业务检查（例如输入验证未通过前禁止切换）的焦点跃迁。

方案一：使用系统标准的 setTabOrder（静态配置） #

最便捷、不需要写事件重载的代码级做法是在窗口构造函数中使用静态函数 setTabOrder 将各控件串联：

cpp
// 💡 静态链式调用：w1 -> w2 -> w3 -> w4
QWidget::setTabOrder(ui->realmLineEdit, ui->userLineEdit);
QWidget::setTabOrder(ui->userLineEdit, ui->passwordLineEdit);
QWidget::setTabOrder(ui->passwordLineEdit, ui->checkBox);
QWidget::setTabOrder(ui->checkBox, ui->loginButton);

该方法最符合 Qt 标准规范，且系统会自动处理 Shift+Tab 的逆向回跳。

方案二：基于事件过滤器（Event Filter）的条件型切换 #

如果你面临更复杂的业务需求（例如：必须等帐号 LineEdit 格式输入正确，点击 Tab 键才允许切换至密码框；或者想在切换时播放音效，跳过某些特定只读控件），就需要重写事件过滤器：

1. 安装事件过滤器 #

将需要接管焦点的输入控件安装到当前父窗口：

cpp
void LoginDialog::initTabFilters()
{
    ui->realmLineEdit->installEventFilter(this); 
    ui->userLineEdit->installEventFilter(this); 
    ui->passwordLineEdit->installEventFilter(this); 
    ui->checkBox->installEventFilter(this);
    ui->loginButton->installEventFilter(this);
    ui->closeButton->installEventFilter(this);
}

2. 重写 eventFilter 捕获 Tab 与 Shift+Tab #

在 Qt 内部，Shift+Tab 对应的键盘枚举值为 Qt::Key_Backtab。重写逻辑如下：

cpp
bool LoginDialog::eventFilter(QObject *obj, QEvent *event)
{
    // 判断事件源是否来自我们监控的焦点控件
    if (obj == ui->realmLineEdit || obj == ui->userLineEdit || 
        obj == ui->passwordLineEdit || obj == ui->checkBox ||
        obj == ui->loginButton || obj == ui->closeButton)
    {
        if (event->type() == QEvent::KeyPress)
        {
            QKeyEvent *keyEvent = static_cast<QKeyEvent*>(event);

            // 1. 处理 Tab 键正向切换
            if (keyEvent->key() == Qt::Key_Tab)
            {
                if (ui->realmLineEdit->hasFocus())
                {
                    ui->userLineEdit->setFocus();
                }
                else if (ui->userLineEdit->hasFocus())
                {
                    // 💡 业务限制示例：账号不得为空时才允许 Tab 切换
                    if (ui->userLineEdit->text().isEmpty()) {
                        ui->userLineEdit->setToolTip(QStringLiteral("账号不能为空"));
                        return true; // 返回 true 表示拦截事件，阻止焦点离开
                    }
                    ui->passwordLineEdit->setFocus();
                }
                else if (ui->passwordLineEdit->hasFocus())
                {
                    ui->checkBox->setFocus();
                }
                else if (ui->checkBox->hasFocus())
                {
                    ui->loginButton->setFocus();
                }
                else if (ui->loginButton->hasFocus())
                {
                    ui->closeButton->setFocus();
                }
                else if (ui->closeButton->hasFocus())
                {
                    ui->realmLineEdit->setFocus();
                }
                return true; // 消费此按键事件，防止默认的 Tab 处理打乱我们的逻辑
            }

            // 2. 处理 Shift + Tab (Qt::Key_Backtab) 反向切换
            else if (keyEvent->key() == Qt::Key_Backtab)
            {
                if (ui->closeButton->hasFocus())
                {
                    ui->loginButton->setFocus();
                }
                else if (ui->loginButton->hasFocus())
                {
                    ui->checkBox->setFocus();
                }
                else if (ui->checkBox->hasFocus())
                {
                    ui->passwordLineEdit->setFocus();
                }
                else if (ui->passwordLineEdit->hasFocus())
                {
                    ui->userLineEdit->setFocus();
                }
                else if (ui->userLineEdit->hasFocus())
                {
                    ui->realmLineEdit->setFocus();
                }
                else if (ui->realmLineEdit->hasFocus())
                {
                    ui->closeButton->setFocus();
                }
                return true;
            }
        }
    }
    
    // 非监控事件退还给 QDialog 默认处理
    return QDialog::eventFilter(obj, event);
}

三、 总结建议 #

  • 普通 UI 表单：无脑选用 方案一 (setTabOrder())，开发效率最高，最安全。
  • 带有强校验、强控制或者防破解的受限输入表单（如安全证书登入、锁屏界面）：建议使用 方案二 (Event Filter 捕获 Key_Tab 与 Key_Backtab)。
