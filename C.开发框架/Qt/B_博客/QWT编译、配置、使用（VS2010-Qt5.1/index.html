QWT编译、配置、使用（VS2010 + Qt5.1.0） #

QWT（Qt Widgets for Technical Applications）是一个非常优秀的基于 LGPL 协议的开源 2D 图表控件库。前文我们介绍过在 Qt Creator 环境下的编译配置方式，本文将着重介绍在 VS2010 (Visual Studio 2010) + Qt 5.1.0 环境下如何编译和集成 QWT 控件库。

一、 开发环境与源码结构 #

  • 编译套件：Visual Studio 2010 (MSVC 2010) + Qt 5.1.0
  • QWT 源码目录结构：
    • src/：存放 QWT 库的核心源文件。
    • designer/：存放 Qt Designer 设计器插件的源码。
    • examples/：丰富的图表示例。
    • doc/：官方帮助文档。
    • textengines/：数学公式/MathML 文本渲染引擎代码。

二、 编译步骤 #

1. 启动 Visual Studio 2010 命令提示 #

选择：开始菜单 -> 所有程序 -> Microsoft Visual Studio 2010 -> Visual Studio Tools -> 打开 Visual Studio 命令提示 (2010)。

2. 依次编译核心库、插件与示例 #

在终端中进入你的 QWT 解压源码根目录（例如 E:\QWT），依次执行以下 qmake 和 nmake 指令：

cmd
:: 1. 编译核心 QWT 链接库
cd E:\QWT
qmake qwt.pro  
nmake  

:: 2. 编译 Qt Designer 设计器插件
cd designer  
qmake designer.pro  
nmake  

:: 3. 编译 QWT 官方自带示例
cd ..  
cd examples  
qmake examples.pro  
nmake
✦提示

除了在命令行中编译，你也可以直接使用 VS 2010 导入 qwt.pro，在 VS 集成开发环境中执行生成，其效果是相同的。

三、 Qt 开发套件配置 #

编译完成后，需要将生成的二进制库及头文件分发部署到你的 Qt 安装套件中（以 Qt 默认安装路径 D:\Software\Qt\Qt5.1.0\5.1.0\msvc2010\ 为例）：

  1. 部署动态链接库 (.dll 与 .lib)：

    • 将 E:\QWT\lib\ 目录下的 qwtd.dll 和 qwt.dll 拷贝到 Qt 的运行目录：
      D:\Software\Qt\Qt5.1.0\5.1.0\msvc2010\bin\
    • 将 E:\QWT\lib\ 目录下的 qwtd.lib 和 qwt.lib 拷贝到 Qt 的静态库目录：
      D:\Software\Qt\Qt5.1.0\5.1.0\msvc2010\lib\

  2. 部署设计器插件 (qwt_designer_plugin)：

    • 将 E:\QWT\designer\plugins\designer\ 目录下的 qwt_designer_plugin.dll 和 qwt_designer_plugin.lib 拷贝到 Qt 的设计器插件目录下：
      D:\Software\Qt\Qt5.1.0\5.1.0\msvc2010\plugins\designer\ 配置完成后，当你打开 Qt Designer 设计器时，左侧控件栏中就会自动多出 Qwt 相关的专业图表控件。

  3. 部署 QWT 头文件：

    • 在 Qt 的 include 目录下新建一个名为 QWT 的空文件夹：
      D:\Software\Qt\Qt5.1.0\5.1.0\msvc2010\include\QWT\
    • 将 E:\QWT\src\ 目录下的所有 .h 和 .cpp 源码头文件拷贝到该 QWT 文件夹下。

四、 在 Visual Studio 中使用 QWT #

新建一个 VS Qt 项目后，需要进行以下三项关键配置，项目才可正常引入 QWT 库：

  1. 配置附加包含目录： 打开 VS 项目属性 -> 配置属性 -> C/C++ -> 常规 -> 在 附加包含目录 中添加：
    $(QTDIR)\include\QWT

  2. 配置附加依赖项： 打开 VS 项目属性 -> 配置属性 -> 链接器 -> 输入 -> 在 附加依赖项 中添加（Debug 模式下链接 qwtd.lib，Release 模式下链接 qwt.lib）：
    qwtd.lib

  3. 配置预处理器宏定义： 打开 VS 项目属性 -> 配置属性 -> C/C++ -> 预处理器 -> 在 预处理器定义 中添加：
    QWT_DLL (如果不配置 QWT_DLL 宏定义，在链接时会引发 unresolved external symbol 符号未解析报错。)

配置完成后，可以直接在代码中 #include <qwt_plot.h> 并编译运行了。
