Qt之QTreeView（三）自定义QSS样式 #

在前文中，我们分别介绍了 QTreeView 数据的加载配置以及如何自定义按钮、图标等委托项。本文将通过 QSS（Qt Style Sheets） 技术，提供三种不同风格的树形控件样式设计方案，帮助开发者大幅度改善默认控件的粗糙视觉。

🎨 样式一：扁平淡蓝现代风 #

该风格采用淡灰色轻量级边框，在悬浮时突出浅蓝边线，选中时使用带有渐变的淡蓝背景进行填充，辅以经典的节点开关箭头。

QSS 代码 #

css
QTreeView {
    border: 1px solid lightgray;
}

QTreeView::item {
    height: 40px;
    border-radius: 2px;
    border: 1px solid transparent;
    background: transparent;
    color: black;
}

/* 鼠标悬浮在节点上时 */
QTreeView::item:hover {
    border: 1px solid rgb(185, 215, 250);
}

/* 节点被选中时 */
QTreeView::item:selected {
    border: 1px solid rgb(170, 190, 230);
    background: qlineargradient(x1: 0, y1: 0, x2: 0, y2: 1, 
                                stop: 0   rgb(230, 240, 250), 
                                stop: 0.5 rgb(220, 235, 255), 
                                stop: 1.0 rgb(210, 230, 255));
}

/* 节点展开时的分支指示图标 */
QTreeView::branch:open:has-children {
    image: url(./Resources/Images/branchOpen.png);
}

/* 节点折叠时的分支指示图标 */
QTreeView::branch:closed:has-children {
    image: url(./Resources/Images/branchClose.png);
}

🎨 样式二：分割线流线风 #

该样式去除了子项的四周白框，在父级节点下方加入淡灰色水平分割线，并在悬浮与选中时同步采用带有微弱立体感的渐变蓝色填充，整体感极强。

QSS 代码 #

css
QTreeView {
    border: 1px solid lightgray;
}

QTreeView::item {
    height: 40px;
    border-radius: 2px;
    border: 1px solid transparent;
    background: transparent;
    color: black;
}

/* 拥有子节点的父节点，底部添加下划分割线 */
QTreeView::item:has-children {
    border: none;
    border-bottom: 1px solid lightgray;
}

/* 鼠标悬浮 */
QTreeView::item:hover {
    border: 1px solid rgb(170, 190, 230);
    background: qlineargradient(x1: 0, y1: 0, x2: 0, y2: 1, 
                                stop: 0   rgb(230, 240, 250), 
                                stop: 0.5 rgb(220, 235, 255), 
                                stop: 1.0 rgb(210, 230, 255));
}

/* 节点被选中 */
QTreeView::item:selected {
    border: 1px solid rgb(170, 190, 230);
    background: qlineargradient(x1: 0, y1: 0, x2: 0, y2: 1, 
                                stop: 0   rgb(230, 240, 250), 
                                stop: 0.5 rgb(220, 235, 255), 
                                stop: 1.0 rgb(210, 230, 255));
}

QTreeView::branch:open:has-children {
    image: url(./Resources/Images/branchOpen2.png);
}

QTreeView::branch:closed:has-children {
    image: url(./Resources/Images/branchClose2.png);
}

🎨 样式三：紧凑暖金亮色风 #

适合信息密度较高的紧凑排版（高度减为 25px），使用耀眼而温暖的黄金色（橙黄色）渐变作为悬浮和选中交互，适用于突出关键目录的场景。

QSS 代码 #

css
QTreeView {
    border: 1px solid lightgray;
}

QTreeView::item {
    height: 25px;
    border: none;
    background: transparent;
    color: black;
}

/* 鼠标悬浮 */
QTreeView::item:hover {
    background: qlineargradient(x1: 0, y1: 0, x2: 0, y2: 1, 
                                stop: 0   rgb(255, 220, 130), 
                                stop: 0.5 rgb(255, 220, 130), 
                                stop: 1.0 rgb(255, 230, 150));
}

/* 选中高亮 */
QTreeView::item:selected {
    background: qlineargradient(x1: 0, y1: 0, x2: 0, y2: 1, 
                                stop: 0   rgb(255, 200, 100), 
                                stop: 0.5 rgb(255, 230, 150), 
                                stop: 1.0 rgb(255, 240, 150));
}

QTreeView::branch:open:has-children {
    image: url(./Resources/Images/branchOpen.png);
}

QTreeView::branch:closed:has-children {
    image: url(./Resources/Images/branchClose.png);
}

💡 QSS 定制要点总结 #

通过上述几种样式的组合与改动，核心在于控制好以下属性的组合：

  • ::item：控制基础子项的高度、内边距、前景色与圆角。
  • ::item:hover / ::item:selected：处理状态变化时的边框与渐变底色（推荐使用 qlineargradient 营造层次感）。
  • ::branch:open:has-children / ::branch:closed:has-children：通过设置 image 属性，能够随心所欲定制树状视图折叠/展开时加减号或三角形箭头的贴图效果。
