QML文本元素Text用法详解：格式排版、字体属性、文本换行与特效样式 #

在 QML 界面开发中，Text 是用于在场景中呈现只读格式化文本的最基础元素。它不仅支持普通的纯文本，还支持基本的富文本标记和轮廓、投影等艺术字特效。

✦提示

Text 元素只提供只读文本展示。如果需要用户输入或编辑文本，请查看 TextInput（单行输入）或 TextEdit（多行富文本编辑）。

一、 Text 核心属性速查清单 #

1. 基础布局与颜色 #

  • text : string —— 要显示的文本字符串。
  • color : color —— 文本颜色。支持多种表示方式：
    • 十六进制：color: "#00FF00"
    • SVG 颜色关键字：color: "steelblue" 或 color: "red"
  • clip : bool —— 如果设为 true，当文字超出边界时会被直接裁剪遮罩。

2. 字体相关属性组 (font) #

font 属于复合属性，可通过 font.xxx 进行详细设置：

属性名 类型 说明
font.family string 字体家族名称（不区分大小写，如 "Helvetica" 或 "微软雅黑"）。
font.pointSize real 以**点（Points）**为单位设置字号大小（独立于屏幕设备像素比，推荐）。
font.pixelSize int 以**像素（Pixels）**为单位设置字号大小（会依赖设备硬件）。
font.bold bool 是否加粗。
font.italic bool 是否倾斜。
font.underline bool 是否添加下划线。
font.strikeout bool 是否添加中划线/删除线。
font.weight enumeration 设定粗度级别：Font.Light、Font.Normal、Font.DemiBold、Font.Bold、Font.Black。
font.letterSpacing real 调整单个字母之间的间距。正数拉伸，负数收缩。
font.wordSpacing real 调整单词之间的间距。
font.capitalization enumeration 大小写转换：
• Font.MixedCase：默认不改变
• Font.AllUppercase：强制全部大写
• Font.AllLowercase：强制全部小写
• Font.SmallCaps：小型大写字母
• Font.Capitalize：每个单词首字母大写

3. 文字自适应缩放模式 (fontSizeMode) #

当文本框的宽度或高度固定，而输入字数不确定时，我们可以通过设置 fontSizeMode 限制文字自动缩放，保证文字不会溢出：

  • Text.FixedSize (默认)：字号大小完全由 pointSize 或 pixelSize 决定，超出则直接溢出。
  • Text.HorizontalFit：在宽度不够时，自动缩小字号以完整呈现在单行内。
  • Text.VerticalFit：在高度不够时，自动缩小字号以完整呈现。
  • Text.Fit：长宽不满足时，同时进行水平与垂直缩小。
  • 💡 配合属性：必须配合 minimumPixelSize 或 minimumPointSize 限制缩小的下限，否则文字可能会无限缩小至肉眼不可见。

4. 文本对齐方式 #

  • horizontalAlignment：水平对齐。可选值：Text.AlignLeft（左对齐）、Text.AlignRight（右对齐）、Text.AlignHCenter（居中对齐）、Text.AlignJustify（两端对齐）。
  • verticalAlignment：垂直对齐。可选值：Text.AlignTop（置顶）、Text.AlignBottom（置底）、Text.AlignVCenter（垂直居中）。

5. 省略与截断 (elide) #

当文本超出设定宽度时，可以使用 elide 显示省略号 ...（注意：必须指定了明确的宽度 width 且非富文本时才有效）：

  • Text.ElideNone (默认)
  • Text.ElideLeft：省略号在左侧，如 ...ld!
  • Text.ElideMiddle：省略号在中间，如 He...d!
  • Text.ElideRight：省略号在右侧，如 Hell...

二、 换行模式 (wrapMode) #

若未指定换行模式，所有的文本都会顽固地挤在同一行上，超出宽度也绝不换行。要实现多行自动排版，必须配置 wrapMode：

模式选项 含义与排版效果
Text.NoWrap (默认) 不换行。如果文本带有 \n 则换行，否则一直向右延伸。
Text.WordWrap 单词边界换行。只在英文单词的空格间隙或中文字符之间换行。如果单个单词长度超过宽度，该单词仍会溢出。
Text.WrapAnywhere 无视边界任意换行。只要触及边界就换行，即使会把一个英文单词从中间强行拆散。
Text.Wrap 混合智能换行。优先在单词边界换行，如果单个单词长度直接超过了行宽，则在单词中间强制断开。

三、 文本特效样式 (style) #

QML 支持为文字添加阴影、浮雕及描边效果，极大方便了游戏 UI 或大屏看板的制作：

qml
Row {
    spacing: 15
    
    Text { font.pointSize: 24; text: "普通文字" }
    
    // 💡 凸起浮雕字
    Text { 
        font.pointSize: 24 
        text: "Raised Style"
        style: Text.Raised
        styleColor: "#AAAAAA" // 辅助阴影色
    }
    
    // 💡 描边艺术字
    Text { 
        font.pointSize: 24 
        text: "Outline Style"
        style: Text.Outline
        styleColor: "red"     // 描边边缘色
    }
    
    // 💡 凹陷字
    Text { 
        font.pointSize: 24 
        text: "Sunken Style"
        style: Text.Sunken
        styleColor: "#AAAAAA" 
    }
}

四、 文本格式与性能选型 (textFormat) #

Text 拥有 textFormat 属性，用以控制如何解析字符串中的特殊标记：

  1. Text.AutoText (默认)：引擎使用 Qt::mightBeRichText() 快速检测是否含有类似 HTML 标签的标识符。如果检测成功，自动切换为样式文本。
  2. Text.PlainText：将内容全部视为普通文本渲染，即使包含 <html> 标签也原样打印出来。
  3. Text.StyledText：支持 HTML 3.2 的子集级标记（如 <b>、<i>、<font color="...">、<a href="...">）。要求嵌套关系非常严谨。
  4. Text.RichText：支持更为庞大的 HTML 4 标准。
❢重要

性能建议：
因为 RichText 底层会启动一个完整的富文本解析排版引擎，开销非常大。在列表展示、滚动视图等高频加载场景中，应当优先使用 Text.PlainText 或 Text.StyledText，这会带来成倍的流畅度提升。

五、 高级交互信号 (代码实例) #

1. 利用 onLineLaidOut 动态干预排版 #

该信号在排版引擎计算出每一行的几何位置时触发。我们可以利用它实现奇妙的排版效果（如段落首行缩进或漏斗形排版）：

qml
Text {
    width: 300
    text: "QML is a declarative language used to design user interface-centric applications. This is a paragraph layout demonstration."
    wrapMode: Text.WordWrap

    // 💡 动态将前 3 行文字向右偏移 30 像素
    onLineLaidOut: {
        if (line.number < 3) {
            line.x = line.x + 30
            line.width = line.width - 30
        }
    }
}

2. 利用 onLinkActivated 处理富文本超链接点击 #

当在 QML Text 元素中插入链接标签 <a href="..."> 时，点击它不会自动打开浏览器，我们需要监听点击信号来做出响应：

qml
Text {
    textFormat: Text.RichText
    text: "更多资料请查阅 <a href='http://qt-project.org'>Qt 官方网站</a>。"
    
    // 💡 当用户点击高亮的超链接时触发此信号
    onLinkActivated: {
        console.log("用户点击了链接: " + link)
        // 可以调用系统的外部浏览器打开网址：
        Qt.openUrlExternally(link)
    }
}
