Qt无边框窗口手绘阴影效果与最小化还原黑屏Bug解决方案 #

在上一篇关于窗口阴影的介绍中，我们使用了“九宫格切图拼接”的方案。虽然九宫格贴图效率很高，但它强依赖于外部图片资源。如果需要随时动态调整阴影的宽度、颜色或者窗口圆角，频繁更换图片会非常麻烦。

本文介绍一种纯代码手绘渐变阴影（Procedural Rendering）的轻量级方案，并针对在启用透明窗口背景（WA_TranslucentBackground）时，Windows 平台下极为恶劣的窗口最小化还原后停止重绘（黑屏/白屏/无响应）的系统 Bug，给出彻底解决的修复方案。

一、 纯代码渐变阴影绘制算法 #

本方案的核心思想是：在 paintEvent 中，我们以窗口边缘为起点向内做循环，绘制多层同心矩形路径（QPainterPath）。每向内收缩一像素，就调高一部分画笔的 Alpha（不透明度），利用开方算法（qSqrt）实现类似高斯模糊的平滑软阴影。

C++ 代码实现： #

cpp
#include <QDialog>
#include <QPainter>
#include <QPainterPath>
#include <QtMath> // 引入 qSqrt

#define SHADOW_PADDING 10 // 预留的外部阴影边缘宽度

class DropShadowWidget : public QDialog
{
    Q_OBJECT
public:
    explicit DropShadowWidget(QWidget *parent = nullptr) : QDialog(parent) {
        setWindowFlags(Qt::FramelessWindowHint | Qt::Dialog);
        setAttribute(Qt::WA_TranslucentBackground);
    }

protected:
    void paintEvent(QPaintEvent *event) override {
        Q_UNUSED(event)
        QPainter painter(this);
        
        // 开启反锯齿，保证圆角和边缘过渡柔和
        painter.setRenderHint(QPainter::Antialiasing, true);

        // 1. 绘制阴影边缘 (由外向内渐变)
        QColor shadowColor(0, 0, 0, 50); // 基础半透明黑色
        for (int i = 0; i < SHADOW_PADDING; ++i)
        {
            QPainterPath path;
            // WindingFill 规则保证嵌套路径能正常填充
            path.setFillRule(Qt::WindingFill);
            
            // 💡 矩形随循环向内收缩 1px
            int offset = SHADOW_PADDING - i;
            path.addRect(offset, 
                         offset, 
                         this->width() - offset * 2, 
                         this->height() - offset * 2);
            
            // 💡 核心：透明度以二次方根梯度递增，边缘淡化，中心浓郁
            int alpha = 150 - qSqrt(i) * 50; 
            if (alpha < 0) alpha = 0;
            
            shadowColor.setAlpha(alpha);
            painter.setPen(shadowColor);
            painter.drawPath(path);
        }

        // 2. 绘制窗口内部主体背景 (缩进 SHADOW_PADDING 大小)
        QPainterPath bodyPath;
        bodyPath.setFillRule(Qt::WindingFill);
        
        // 如果需要圆角，可以用 addRoundedRect 代替 addRect
        bodyPath.addRect(SHADOW_PADDING, 
                         SHADOW_PADDING, 
                         this->width() - SHADOW_PADDING * 2, 
                         this->height() - SHADOW_PADDING * 2);
                         
        painter.fillPath(bodyPath, QBrush(Qt::white));
    }
};

二、 💡 避坑 Bug 修复：最小化还原后停止渲染 #

在 Windows 下开发无边框窗口时，几乎所有开发者都遇到过这个经典 Bug：

当设置了 Qt::FramelessWindowHint 和 Qt::WA_TranslucentBackground，点击任务栏或点击控制按钮将窗口最小化，接着再次点击任务栏还原显示时，窗口突然变成白屏、黑屏，或者子控件全部死锁、不再重绘。

这是 Qt 在 Windows 下与 DWM（桌面窗口管理器）进行混合半透明渲染时的图形驱动冲突 Bug。

彻底解决之道：重写 changeEvent 强行重映射与唤醒 #

我们可以在窗口类中重写系统的 changeEvent，检测当窗口从最小化（Minimized）还原到正常无状态（NoState）的一瞬间，利用系统属性或强制发送 Repaint 事件，重映射窗口属性：

cpp
protected:
    void changeEvent(QEvent *event) override {
        // 检测窗口状态改变事件
        if (event->type() == QEvent::WindowStateChange) {
            // 当窗口从最小化状态被还原显示时
            if (windowState() == Qt::WindowNoState) {
                // 💡 核心黑魔法：强制重映射底层窗口实例
                setAttribute(Qt::WA_Mapped);
                // 💡 强行触发完整区域的重新重绘
                this->update();
            }
        }
        
        // 传递给基类继续处理
        QDialog::changeEvent(event);
    }

通过拦截 Qt::WA_Mapped 属性并主动触发 update()，可以完美修复 Windows 平台下还原窗口的白屏 Bug，保证界面重绘畅通无阻。

三、 子控件挂载内置阴影 (QGraphicsDropShadowEffect) #

除了为最顶层窗口手绘阴影外，如果想为界面上的 GroupBox 或 Frame 区域增加卡片投影，使用手画会极其繁琐。此时，可以直接实例化系统的 QGraphicsDropShadowEffect 特效类：

cpp
// 1. 创建阴影效果对象并指定父对象
QGraphicsDropShadowEffect *shadowEffect = new QGraphicsDropShadowEffect(this);

// 2. 配置参数
shadowEffect->setOffset(-3, 3);          // 阴影相对方向偏移量 (X, Y)
shadowEffect->setColor(Qt::gray);        // 投影颜色
shadowEffect->setBlurRadius(8);          // 虚化半径

// 3. 将特效绑定到目标控件上
ui->networkGroupBox->setGraphicsEffect(shadowEffect);

通过灵活结合顶层 paintEvent 手绘阴影与子控件 setGraphicsEffect 特效，即可完美搭建立体富有层次感的客户端交互界面。
