Qt之二维码扫描与常用编码解码库推荐 #

二维码（QR Code, Quick Response Code）使用特定的几何图形按一定规律在平面（二维方向）上分布的黑白相间图形来记录数据符号信息。作为移动互联网时代最常见的信息入口，二维码已广泛应用于产品防伪溯源、名片交流、商品交易和移动支付等各种场景。

一、 二维码与一维码的对比 #

  • 一维码：只能在水平方向上表达信息，信息量小（一般只能容纳几十个字符），通常只能由数字和字母组成，对磨损和褶皱的容错性极低。
  • 二维码：在水平和垂直两个方向都可以存储和传递信息。不仅存储容量大（可达数千字符），而且能存储汉字、数字、二进制流、网址甚至图片信息。二维码拥有出色的纠错机制（L、M、Q、H 四个等级），即便部分区域出现污损或撕裂，依然能够被正常识别解码。

常用二维条码码制包括：QR Code、Data Matrix、MaxiCode、Aztec、PDF417 等。

二、 主流开源二维码编码/解码库 #

在进行 Qt 项目开发时，我们可以引入以下主流的开源二维码编解码库：

1. ZXing (Zebra Crossing) #

  • 特点：由谷歌主导的强大、多格式的 1D/2D 条码图像处理库。使用 Java 实现，但提供了完整的 C++、C#、Python、Android 等各种语言的移植版本。
  • 项目地址：GitHub ZXing

2. Libqrencode (QRencode) #

  • 特点：使用纯 C 语言编写的用于将字符串编码为二维码的程序库。执行速度快，极易嵌入到各种微控制系统或移动应用中。
  • 项目地址：Libqrencode 官网

3. ZBar #

  • 特点：支持扫描摄像头视频流以及静态图片的条码/二维码工具包。支持多平台（Windows、Linux、iOS），并提供了易用的 C/C++ API 接口。
  • 项目地址：ZBar Sourceforge

三、 Qt 专用集成库：QZXing #

QZXing 是对 ZXing（C++ 移植版）进行的 Qt 风格封装库。它将复杂的图像条码解析过程高度抽象，为 Qt/QML 程序开发提供了极其便利的接口支持。

  • 项目地址：QZXing Sourceforge

QZXing 的基本调用示例（C++）： #

cpp
#include <QImage>
#include <QDebug>
#include "QZXing.h" // 引入头文件

void decodeQRCode(const QString &image_path)
{
    QImage image(image_path);
    if (image.isNull()) {
        qDebug() << "Failed to load image";
        return;
    }

    // 💡 声明 QZXing 解码器对象
    QZXing decoder;
    
    // 设置支持的解码格式（仅解码二维码，提升识别速度）
    decoder.setDecoder(QZXing::DecoderFormat_QR_CODE);
    
    // 执行解码
    QString result = decoder.decodeImage(image);
    
    if (result.isEmpty()) {
        qDebug() << "Decode failed: No QR code found.";
    } else {
        qDebug() << "QR Code Decoded Message:" << result;
    }
}

四、 🛠️ 打包发布注意事项 #

在 Windows 平台上使用 Qt 编写并打包发布二维码扫描程序（生成的 .exe）时，经常会遇到在开发机上运行一切正常，但拷贝到其他裸机电脑上时却无法识别和读取 JPG、PNG 等格式图片的问题。

解决方案： #

这是因为 Qt 在加载除基本 BMP 以外的图片格式时，需要依赖其底层的格式插件。

  1. 在您的可执行程序目录（如 release/）下，必须新建一个名为 imageformats 的文件夹。
  2. 从您的 Qt 安装目录下的插件目录中，拷贝对应的插件动态库文件到该文件夹下：
    • 必须包含：qjpeg.dll (JPG格式支持)、qgif.dll (GIF支持)、qico.dll 等。
  3. 保持如下的目录层级部署：
    text
    YourApp/
  |-- YourApp.exe
  |-- Qt5Core.dll
  |-- Qt5Gui.dll
  |-- imageformats/
        |-- qjpeg.dll
        |-- qgif.dll
        |-- qico.dll

这样，您的应用程序在任意电脑上运行时，才能成功加载和解析不同格式的二维码静态图片。
