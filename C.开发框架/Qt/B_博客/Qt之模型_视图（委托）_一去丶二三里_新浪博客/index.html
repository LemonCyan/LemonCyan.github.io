Qt模型视图架构高级开发：QStyledItemDelegate自适应多列编辑器控件实现 #

在 Qt 的 Model/View (模型/视图) 架构中，双击单元格默认弹出的只是一个基础的文本输入框。如果我们需要在表格的不同列提供针对性的录入工具（例如：第一列输入常规字符串，第二列使用微调器选择数字，第三列弹出一个下拉选择框），就需要通过自定义委托编辑器来接管这一交互过程。

控制和定义就地编辑行为的虚函数标准接口，封装在 QStyledItemDelegate 类中。

本文将首先拆解实现自定义编辑器的四个核心虚函数，然后通过一个**多列自适应编辑器（第一列 LineEdit，第二列 SpinBox）**的高级实战代码，演示具体的开发实现。

一、 委托编辑器生命周期四大虚函数 #

自定义交互编辑委托时，必须覆盖实现以下四个关键虚函数：

                    【 委托编辑器的生命周期逻辑 】
双击单元格
   |
   v
[ createEditor ] -------------> 实例化编辑器小部件 (如 QSpinBox)，并返回指针。
   |
   v
[ setEditorData ] ------------> 从 Model 读取原始数据，并载入到编辑器中。
   |
编辑中... (等待用户按 Enter 或点击外部失去焦点)
   |
   v
[ setModelData ] -------------> 将编辑器中的最新值写回 Model，更新底层数据。
   |
   v
[ updateEditorGeometry ] -----> 调整编辑器尺寸，使其精准覆盖当前的单元格边界。

二、 实战：多列自适应编辑器 (C++ 实现) #

下面我们编写一个名为 MultiColumnDelegate 的通用委托类。当用户双击表格时：

  • 双击 Column 0 (第一列)：弹出无边框的 QLineEdit；
  • 双击 Column 1 (第二列)：弹出限制范围在 0~100 的 QSpinBox；
  • 其他列：采用系统默认编辑方式。

1. 头文件声明 (MultiColumnDelegate.h) #

cpp
#pragma once
#include <QStyledItemDelegate>

class MultiColumnDelegate : public QStyledItemDelegate
{
    Q_OBJECT
public:
    explicit MultiColumnDelegate(QObject *parent = nullptr);

    // 💡 1. 负责创建编辑控件
    QWidget *createEditor(QWidget *parent, 
                          const QStyleOptionViewItem &option, 
                          const QModelIndex &index) const override;

    // 💡 2. 负责从 Model 提取数据并显示在控件中
    void setEditorData(QWidget *editor, const QModelIndex &index) const override;

    // 💡 3. 负责将控件中的新数据保存回 Model
    void setModelData(QWidget *editor, 
                      QAbstractItemModel *model, 
                      const QModelIndex &index) const override;

    // 💡 4. 负责控制编辑控件的几何外形 (大小与位置)
    void updateEditorGeometry(QWidget *editor, 
                              const QStyleOptionViewItem &option, 
                              const QModelIndex &index) const override;
};

2. 源文件实现 (MultiColumnDelegate.cpp) #

cpp
#include "MultiColumnDelegate.h"
#include <QLineEdit>
#include <QSpinBox>

MultiColumnDelegate::MultiColumnDelegate(QObject *parent)
    : QStyledItemDelegate(parent)
{
}

QWidget *MultiColumnDelegate::createEditor(QWidget *parent, 
                                           const QStyleOptionViewItem &option, 
                                           const QModelIndex &index) const
{
    // 💡 根据当前点击的列号 (index.column())，动态路由创建不同的编辑器
    if (index.column() == 0)
    {
        // 第一列：返回单行文本编辑器
        QLineEdit *lineEdit = new QLineEdit(parent);
        lineEdit << "border: none; background: #E6F3FF;"; // 可以赋予简单的样式
        return lineEdit;
    }
    else if (index.column() == 1)
    {
        // 第二列：返回数值微调器
        QSpinBox *spinBox = new QSpinBox(parent);
        spinBox->setFrame(false); // 去除微调器默认的外边框
        spinBox->setMinimum(0);
        spinBox->setMaximum(100);
        return spinBox;
    }

    // 其它列交给父类默认处理 (默认返回 QLineEdit)
    return QStyledItemDelegate::createEditor(parent, option, index);
}

void MultiColumnDelegate::setEditorData(QWidget *editor, const QModelIndex &index) const
{
    // 从 Model 的 EditRole 角色中获取底层数据
    QVariant val = index.model()->data(index, Qt::EditRole);

    if (index.column() == 0)
    {
        QLineEdit *lineEdit = qobject_cast<QLineEdit*>(editor);
        if (lineEdit) {
            lineEdit->setText(val.toString());
        }
    }
    else if (index.column() == 1)
    {
        QSpinBox *spinBox = qobject_cast<QSpinBox*>(editor);
        if (spinBox) {
            spinBox->setValue(val.toInt());
        }
    }
    else
    {
        QStyledItemDelegate::setEditorData(editor, index);
    }
}

void MultiColumnDelegate::setModelData(QWidget *editor, 
                                       QAbstractItemModel *model, 
                                       const QModelIndex &index) const
{
    if (index.column() == 0)
    {
        QLineEdit *lineEdit = qobject_cast<QLineEdit*>(editor);
        if (lineEdit) {
            model->setData(index, lineEdit->text(), Qt::EditRole);
        }
    }
    else if (index.column() == 1)
    {
        QSpinBox *spinBox = qobject_cast<QSpinBox*>(editor);
        if (spinBox) {
            spinBox->interpretText(); // 💡 技巧：强制让 QSpinBox 立即校验文本，确保最终输入的字数生效
            model->setData(index, spinBox->value(), Qt::EditRole);
        }
    }
    else
    {
        QStyledItemDelegate::setModelData(editor, model, index);
    }
}

void MultiColumnDelegate::updateEditorGeometry(QWidget *editor, 
                                               const QStyleOptionViewItem &option, 
                                               const QModelIndex &index) const
{
    Q_UNUSED(index)
    // 💡 保证编辑器大小和单元格完全一致
    editor->setGeometry(option.rect);
}

三、 在 QTableView 中绑定自定义委托 #

我们可以在 main 方法中构造一个简单的模型并绑定我们的多列委托：

cpp
#include <QApplication>
#include <QStandardItemModel>
#include <QTableView>
#include "MultiColumnDelegate.h"

int main(int argc, char *argv[])
{
    QApplication app(argc, argv);

    // 创建一个 4 行 2 列的模型
    QStandardItemModel model(4, 2);
    model.setHeaderData(0, Qt::Horizontal, "Name (LineEdit)");
    model.setHeaderData(1, Qt::Horizontal, "Score (SpinBox)");

    // 初始化一些测试数据
    for (int row = 0; row < 4; ++row) {
        model.setData(model.index(row, 0), QString("Student %1").arg(row + 1));
        model.setData(model.index(row, 1), 60 + row * 10);
    }

    // 初始化表格视图
    QTableView tableView;
    tableView.setModel(&model);

    // 💡 实例化我们的多列自适应编辑器委托并绑定
    MultiColumnDelegate delegate;
    tableView.setItemDelegate(&delegate);

    tableView.horizontalHeader()->setStretchLastSection(true);
    tableView.setWindowTitle("QTableView Multi-Editor Delegate");
    tableView.resize(360, 200);
    tableView.show();

    return app.exec();
}

资源销毁说明：
在自定义委托内部，通过 new 创建的编辑器部件（如 QLineEdit / QSpinBox），其父对象指定为了视图传递进来的 parent 变量。当用户按下回车或点击空白处退出编辑状态时，QTableView 会自动回收并销毁这些动态编辑器指针，开发者无需编写任何手动 delete 逻辑，从而避免了内存泄露。
