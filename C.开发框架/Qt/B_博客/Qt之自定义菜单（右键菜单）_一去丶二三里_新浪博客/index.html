Qt之自定义菜单（右键菜单） #

在开发基于 Qt 的桌面应用程序时，我们经常需要为各类展示列表、树形目录（如 QTreeWidget、QTableWidget）或主视窗区域添加右键弹出菜单。

在 Qt 中，QMenu 主要用于菜单栏、上下文右键菜单以及弹出式菜单。配合 QAction 行为项，我们能极其高效、直观地实现右键菜单的功能。

一、 右键菜单的核心实现机制 #

要实现右键菜单，通常有以下几种方式，其中最经典、最推荐的方法是：重写控件的 contextMenuEvent(QContextMenuEvent *event) 事件函数。

我们以自定义的 ImageTree（继承自 QTreeWidget）为例，主要包含以下三个步骤：

  1. 创建 Action 动作 (createActions)：在构造阶段实例化各菜单行为，并配置信号槽。
  2. 多语化绑定 (translateLanguage)：为各项 QAction 赋具体的展示文本。
  3. 拦截右键事件 (contextMenuEvent)：当检测到右键动作时，清除原有项，加载所需菜单并弹窗显示。

二、 核心代码实现 #

以下为自定义 ImageTree 控件的具体 C++ 逻辑排布：

cpp
#include <QTreeWidget>
#include <QMenu>
#include <QAction>
#include <QContextMenuEvent>
#include <QCursor>

class ImageTree : public QTreeWidget
{
    Q_OBJECT
public:
    explicit ImageTree(QWidget *parent = nullptr);

protected:
    // 🔑 1. 重写上下文菜单事件
    void contextMenuEvent(QContextMenuEvent *event) override;

private:
    void createActions();
    void translateLanguage();

private slots:
    void selectImages();
    void selectFolder();
    void removeSelectedImages();
    void removeAllImages();

private:
    QMenu *pop_menu;
    QAction *add_images_action;
    QAction *add_folder_action;
    QAction *remove_selected_action;
    QAction *remove_all_action;
};

// 构造函数
ImageTree::ImageTree(QWidget *parent)
    : QTreeWidget(parent)
{
    createActions();
    translateLanguage();
}

// 🔑 2. 初始化创建菜单项，并连接信号与槽
void ImageTree::createActions()
{
    pop_menu = new QMenu(this);

    add_images_action = new QAction(this);
    add_folder_action = new QAction(this);
    remove_selected_action = new QAction(this);
    remove_all_action = new QAction(this);

    // 关联槽函数
    connect(add_images_action, &QAction::triggered, this, &ImageTree::selectImages);
    connect(add_folder_action, &QAction::triggered, this, &ImageTree::selectFolder);
    connect(remove_selected_action, &QAction::triggered, this, &ImageTree::removeSelectedImages);
    connect(remove_all_action, &QAction::triggered, this, &ImageTree::removeAllImages);
}

// 💡 3. 设置多语化语言环境（亦可在 createActions 中合并定义）
void ImageTree::translateLanguage()
{
    add_images_action->setText(tr("添加图片"));
    add_folder_action->setText(tr("添加文件夹"));
    remove_selected_action->setText(tr("删除所选图片"));
    remove_all_action->setText(tr("删除所有图片"));
}

// 🔑 4. 重写右键拦截展示逻辑
void ImageTree::contextMenuEvent(QContextMenuEvent *event)
{
    // 清除可能残留的历史菜单项，防范多重叠加渲染
    pop_menu->clear();

    // 顺序添加菜单项
    pop_menu->addAction(add_images_action);
    pop_menu->addAction(add_folder_action);
    pop_menu->addSeparator(); // 增加分割线
    pop_menu->addAction(remove_selected_action);
    pop_menu->addAction(remove_all_action);

    // 💡 菜单弹出的位置必须转换为当前鼠标在屏幕上的全局物理坐标 (QCursor::pos())
    pop_menu->exec(QCursor::pos());
    
    // 标记当前事件已被处理，阻止其继续传递
    event->accept();
}

三、 高级扩展：二级菜单 #

如果菜单项非常多（如需要包含子分类），我们可以很容易地通过 QMenu::addMenu() 挂载二级甚至多级菜单项：

cpp
QMenu *submenu = new QMenu(tr("添加效果"), pop_menu);
QAction *action_text_watermark = new QAction(tr("添加文本水印"), this);
QAction *action_image_watermark = new QAction(tr("添加图片水印"), this);

submenu->addAction(action_text_watermark);
submenu->addAction(action_image_watermark);

// 💡 将子菜单直接挂载到主右键菜单上
pop_menu->addMenu(submenu);

四、 常见问题解答与调试 #

  1. 为什么标题栏右键时也会弹出该菜单？如何屏蔽？
    • 原因：如果您的右键监听直接写在包含主标题栏在内的 Parent 窗体，或者 event->pos() 范围涵盖了表头，就会引发穿透。
    • 解决：在 contextMenuEvent 的开头，增加局部坐标的位置校验。例如，如果是在 QTreeWidget 内，判断当前的 event->pos() 是否在 Header 的矩形区域内（header()->rect().contains(pos)），若包含则直接 return 忽略，不运行 pop_menu->exec()。
  2. 多级目录树下，右键获取选中的项为什么滞后了？
    • 原因：默认情况下，鼠标右键点击 QTreeWidget 时，并不会自动让该项获取焦点。
    • 解决：在展示右键菜单前，通过 itemAt(event->pos()) 手动获取当前的项，并执行 setCurrentItem(item) 锁定焦点，确保执行槽函数时获取的数据完全一致。
