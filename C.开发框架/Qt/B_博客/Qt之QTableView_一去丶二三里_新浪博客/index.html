Qt之QTableView #

在 Qt 开发中，当数据集规模较小（例如数百项）时，我们通常选择使用自带内置模型的便利窗口部件，如 QTableWidget、QListWidget 和 QTreeWidget。但面对大规模或复杂的业务数据源时，采用标准的 “模型/视图” (Model/View) 架构就显得更加灵活、高效。

视图部件（如 QTableView）并不存储数据，它们必须提供一个对应的 Model（如 QStandardItemModel 或自定义的 QAbstractTableModel）来提供数据源。本节不对 Model/View 机制做基础阐述，而是针对 QTableView 的三种深入、高级用法展开探讨：

  1. 悬浮状态栏提示 (QToolTip) 的实现
  2. 整行选中色及隐藏聚焦虚线
  3. 鼠标滑过时整行高亮变色效果

一、 实现单元格悬浮提示 (QToolTip) #

当表格中的文本较长、列宽显示不全时，可以通过实现 ToolTip 悬浮提示框显示完整信息。

  1. 开启鼠标追踪：默认情况下，只有鼠标按下时视图才会产生移动事件，因此需要开启鼠标移动监测。
    cpp
    table_view->setMouseTracking(true);
  2. 实现槽函数 showToolTip：
    cpp
    void TableView::showToolTip(const QModelIndex &index)
{
    if (!index.isValid())
        return;
        
    int row = index.row();
    // 假设 list_file 存储了各行的文件路径
    QString file_name = list_file.at(row); 
    if (file_name.isEmpty())
        return;
        
    // 💡 在鼠标当前物理光标位置浮现文本提示
    QToolTip::showText(QCursor::pos(), file_name);  
}
  3. 关联信号与槽：将视图的 entered()（鼠标滑过某项）信号连接到我们编写的槽中。
    cpp
    connect(table_view, &QTableView::entered, this, &TableView::showToolTip);

二、 整行选中、隐藏虚线及选中色配置 #

  1. 设置整行选中属性：
    cpp
    table_view->setSelectionBehavior(QAbstractItemView::SelectRows);
  2. 重写委托类以隐藏虚线：Qt 默认在选中项周围绘制虚线聚焦框，可以通过继承 QStyledItemDelegate 重写 paint 函数，过滤掉焦点状态 State_HasFocus。
    cpp
    void StyledDelegate::paint(QPainter *painter, const QStyleOptionViewItem &option, const QModelIndex &index) const   
{   
    QStyleOptionViewItem view_option(option);   
    // 💡 过滤移除焦点虚线属性
    if (view_option.state & QStyle::State_HasFocus) {   
        view_option.state = view_option.state ^ QStyle::State_HasFocus;   
    }
    QStyledItemDelegate::paint(painter, view_option, index);
}
  3. 将该委托应用至视图：
    cpp
    table_view->setItemDelegate(styled_delegate);
  4. 通过 QSS 配置整行选中颜色：
    css
    QTableView {
    border: none;
    background: white;
}
QTableView::item:selected {
    color: white;
    background: rgb(34, 175, 75); /* 选中行变绿 */     
}

三、 鼠标滑过整行高亮变色 #

如果只通过 QSS 配置 QTableView::item:hover，当鼠标滑过时，仅会高亮当前的单一单元格，这与我们设置的“整行选中”显得有些格格不入。要实现鼠标滑过时整行同步高亮，最优雅的实现是结合自定义 View 与自定义 Model 联动刷新：

1. 自定义 View 中捕获鼠标移动与移出 #

cpp
void TableView::mouseMoveEvent(QMouseEvent *event)
{
    // 获取当前鼠标指针所在的行索引并执行重绘更新
    int row = indexAt(event->pos()).row();
    updateRow(row);
    QTableView::mouseMoveEvent(event);
}

void TableView::leaveEvent(QEvent *event)
{
    // 移出表格时清除高亮状态
    table_model->setHoverRow(-1);
    int column_count = model()->columnCount();
    for (int i = column_count - 1; i >= 0; i--) {
        update(model()->index(current_row, i));
    }
    current_row = -1;
    QTableView::leaveEvent(event);
}

void TableView::updateRow(int row)
{
    if (row == current_row)
        return;
        
    // 传递最新的 hover 行索引给 Model 
    table_model->setHoverRow(row);
    int column_count = model()->columnCount();
    for (int i = column_count - 1; i >= 0; i--) {
        // 重绘旧高亮行与新高亮行的全部单元格
        update(model()->index(current_row, i));
        update(model()->index(row, i));
    }
    
    // 可以同时触发自定义的悬浮提示显示
    table_model->showToolTip(row);
    current_row = row;
}

2. 自定义 Model 中按行号变色 #

在自定义 Model 的 data 接口中，拦截 BackgroundColorRole：

cpp
void TableModel::setHoverRow(int hover_row)
{
    this->hover_row = hover_row;
}

QVariant TableModel::data(const QModelIndex &index, int role) const
{
    if (!index.isValid())
        return QVariant();
        
    int row = index.row();
    if (row < 0 || row >= list_file.size())
        return QVariant();
        
    switch (role) {
        case Qt::BackgroundColorRole: {
            // 💡 若当前项属于鼠标所悬停的行，返回高亮淡蓝色背景
            if (row == hover_row) {
                return QColor(180, 200, 220);
            }
            break;
        }
        case Qt::DecorationRole: // 渲染图标...
            break;
        case Qt::DisplayRole:    // 渲染文本...
            break;
        case Qt::TextAlignmentRole: // 文本对齐...
            break;
        default:
            return QVariant();
    }
    return QVariant();
}

如此一来，无论鼠标移动到哪一行，该行所有的单元格都会得到局部重绘刷新，达到了完美的整行悬浮高亮变色体验。
