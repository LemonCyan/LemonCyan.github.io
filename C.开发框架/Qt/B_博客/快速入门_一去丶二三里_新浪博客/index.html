QML之快速入门（一）语法与基本元素 #

QML（Qt Meta-Object Language）是一种声明性的用户界面标记语言。它将用户界面分解为树状层次的轻量级元素，并支持结合 JavaScript 代码来充实控件行为和交互逻辑。QML 从底层就被设计用于构建现代、流畅的动态用户界面，而非传统的文本文档。

4.1 QML 语法 #

QML 的层级结构非常直观：子元素会隐式继承父坐标系，子元素的 x 和 y 坐标总是相对于其父组件计算的。

简单 QML 示例 #

qml
// rectangle.qml
import QtQuick 2.0

// 根元素为 Rectangle
Rectangle {
    id: root
    width: 120; height: 240
    color: "#D8D8D8"

    // 子元素 1 (Image)
    Image {
        id: rocket
        x: (parent.width - width) / 2; y: 40 // 居中定位
        source: 'assets/rocket.png'
    }

    // 子元素 2 (Text)
    Text {
        y: rocket.y + rocket.height + 20
        width: root.width
        horizontalAlignment: Text.AlignHCenter
        text: 'Rocket'
    }
}

语法要点 #

  • import 语句：用于引入指定版本的模块。构建基础界面时，通常需要首先导入 QtQuick 2.0。
  • 单行与多行注释：与 C++ / JS 相同，支持单行 // 和多行 /* ... */ 注释。
  • 根节点唯一性：每个 .qml 文件必须有且仅有一个根元素。
  • 属性声明：使用 name: value 形式来定义或覆盖属性。
  • 元素命名：通过唯一的 id 来标识元素。最好将最外层的根元素统一命名为 id: root，这有助于避免子元素在层级嵌套中引用混乱。

4.2 属性特性详解 #

QML 元素的属性不仅是简单的键值对，它还支持以下高级特性：

1. 属性绑定 (Property Binding) #

属性可以依赖于另一个或多个属性。当被依赖的属性发生改变时，绑定的属性会自动重新计算并更新：

qml
height: 2 * width // 只要宽度 width 变化，高度 height 会自动同步更新为宽度的 2 倍

2. 自定义属性 #

使用 property 修饰符声明自定义属性：

qml
property int times: 24 // 声明一个整型自定义属性，初始值为 24

3. 属性别名 (Property Alias) #

使用 alias 关键字将内部嵌套元素的属性或对象引用导出给外部：

qml
property alias anotherTimes: thisLabel.times // 将 label 内部的 times 导出为别名 anotherTimes
ℹ笔记

别名功能在组件开发中极其常用，因为外部只能访问组件根节点暴露的属性，内部子节点的属性必须通过 alias 映射出去才能被外部调用。

4. 分组属性 #

当多个属性属于同一大类时，可以使用点号或大括号块形式进行组织：

qml
font.family: "Ubuntu"
font.pixelSize: 24
// 也可以写成：
font { family: "Ubuntu"; pixelSize: 24 }

5. 附加属性 (Attached Properties) #

某些全局相关的属性是由特定的元系统提供的，可以通过 Type.property 引用：

qml
KeyNavigation.tab: otherLabel // 处理 Tab 键导航焦点切换

6. 属性变更信号处理器 #

当属性值变化时，会自动发射名为 on<Property>Changed 的信号：

qml
onHeightChanged: console.log('height changed to:', height)

4.3 JavaScript 脚本交互 #

QML 与 JavaScript 的关系非常密切，你可以通过编写 JS 函数或直接在事件处理器中编写多行 JS 脚本来充实程序逻辑。

qml
Text {
    id: label
    x: 24; y: 24
    property int spacePresses: 0
    text: "Space pressed: " + spacePresses + " times"

    focus: true

    // 键盘空格键按下事件
    Keys.onSpacePressed: {
        increment() // 调用内部 JavaScript 方法
    }

    // 键盘 Esc 键按下事件
    Keys.onEscapePressed: {
        label.text = '' // 破坏性赋值，直接清除原属性绑定关系
    }

    // JavaScript 函数定义
    function increment() {
        spacePresses = spacePresses + 1
    }
}
⚠警告

关于绑定（:）与赋值（=）的区别：

  • 属性绑定（:） 是一种强约束关系，在其生命周期内始终为真。
  • JS 赋值（=） 是一次性的操作。如果为被绑定的属性直接执行了 = 赋值操作（例如按下 Esc 时直接执行了 label.text = ''），原有的数据绑定关系（text: "Space pressed: " + ...）就会被永久破坏和销毁，后续 spacePresses 再变化，文本也不会自动更新了。

4.4 五大基本视觉元素 #

所有视觉元素都继承自 Item 类。

1. Item 元素 #

最基础的视觉元素。它自身没有任何绘制输出（即完全透明），但定义了所有视觉元素共有的几何、层级、按键以及状态等属性。在 UI 结构中，Item 常作为类似 HTML 中 div 的容器角色来使用。

2. Rectangle 元素 #

扩展自 Item，增加了颜色填充、边框以及圆角等视觉支持：

qml
Rectangle {
    width: 200; height: 100
    color: "lightsteelblue"
    border.color: "slategrey"
    border.width: 2
    radius: 8 // 圆角半径
}

同时也支持渐变色填充：

qml
gradient: Gradient {
    GradientStop { position: 0.0; color: "lightsteelblue" }
    GradientStop { position: 1.0; color: "slategrey" }
}

3. Text 元素 #

用于显示只读文本：

qml
Text {
    text: "The quick brown fox"
    color: "#303030"
    font.pixelSize: 28
    elide: Text.ElideMiddle // 文本过长时从中间截断显示 '...'
    wrapMode: Text.WordWrap // 显式设定宽度后允许换行
}

4. Image 元素 #

用于载入并渲染图片（如 PNG、JPG、GIF、BMP 等）：

qml
Image {
    source: "assets/rocket.png" // 支持本地路径（./images/）或网络 URL
    fillMode: Image.PreserveAspectCrop // 保持比例裁剪
    clip: true // 开启裁剪，防止图片溢出边界
}

5. MouseArea 元素 #

非视觉的交互区域，负责捕获特定矩形范围内的鼠标事件：

qml
Rectangle {
    id: button
    width: 100; height: 50
    color: "blue"

    MouseArea {
        anchors.fill: parent
        onClicked: {
            console.log("Button clicked!")
        }
    }
}

4.5 自定义组件 (QML Components) #

QML 支持高度可重用性。通常，我们将一整套元素组织在以大写字母开头的独立 .qml 文件中，即可直接将其定义为一个新组件。

例如，创建一个名为 Button.qml 的文件：

qml
// Button.qml
import QtQuick 2.0

Rectangle {
    id: root
    
    // 1. 导出 API 属性
    property alias text: label.text
    
    // 2. 导出点击信号
    signal clicked
    
    width: 116; height: 26
    color: "lightsteelblue"
    border.color: "slategrey"

    Text {
        id: label
        anchors.centerIn: parent
        text: "Start"
    }

    MouseArea {
        anchors.fill: parent
        onClicked: {
            root.clicked() // 发射根级信号
        }
    }
}

在其他 QML 文件中，就可以直接把该组件作为新元素进行调用：

qml
import QtQuick 2.0

Item {
    // 实例化自定义的 Button
    Button {
        id: startButton
        x: 10; y: 10
        text: "Click Me"
        onClicked: {
            statusText.text = "Button clicked!"
        }
    }

    Text {
        id: statusText
        x: 10; y: 50
        text: "waiting..."
    }
}
