Qt之多语化与动态语言切换方案 #

一个好的桌面端商业软件不仅需要支持本地语言，还应该具备在运行时随意切换多国语言的能力。如果每次切换语言都要求用户重启软件，那么它的用户体验就不够好。

要想在 Qt 应用程序中实现“不重启软件，动态热切换语言”，以及在“首次启动时加载上一次用户保存的选择”，我们需要遵循特定的项目结构规范。

一、 动态切换语言的核心原理 #

要想让界面文本在不重启软件时刷新，需要实现以下三点：

  1. 统一使用 tr() 包装可见文本：所有供用户阅读的静态与动态字符串，全部采用 tr("key") 来包裹。
  2. 提取重译函数 translateLanguage()：不要把 tr() 直接写在构造函数中进行一次性赋值。必须把所有需要翻译的 UI 设置（如 setText、setWindowTitle）写在一个独立的通用成员函数（通常命名为 translateLanguage()）中。
  3. 监听并通知刷新：当语言切换事件触发，在加载了新的 .qm 翻译文件后，依次调用所有活动窗口与对话框的 translateLanguage() 方法重新给控件设值。

二、 核心代码实现 #

下面通过一个主界面（MainWidget）与设置对话框（SettingDialog）的联动来演示如何实现动态切换。

1. 语言枚举与辅助工具定义 #

cpp
enum LANGUAGE
{
    UI_ZH = 0, // 中文
    UI_EN = 1  // 英文
};

2. 主窗体实现 (main_widget.cpp) #

cpp
#include "main_widget.h"
#include <QHBoxLayout>
#include <QVBoxLayout>
#include <QTranslator>

MainWidget::MainWidget(QWidget *parent)
    : QWidget(parent)
{
    this->setMinimumSize(400, 300);

    welcome_label = new QLabel();
    setting_button = new QPushButton();
    ok_button = new QPushButton();
    cancel_button = new QPushButton();
    setting_dialog = new SettingDialog(this);

    QHBoxLayout *button_layout = new QHBoxLayout();
    button_layout->addStretch();
    button_layout->addWidget(setting_button);
    button_layout->addWidget(ok_button);
    button_layout->addWidget(cancel_button);
    button_layout->setSpacing(10);

    QVBoxLayout *main_layout = new QVBoxLayout();
    main_layout->addWidget(welcome_label, 0, Qt::AlignCenter);
    main_layout->addLayout(button_layout);
    main_layout->setContentsMargins(10, 10, 10, 10);
    this->setLayout(main_layout);

    // 💡 关键点 1：初始化时必须先调用一次重译函数来设初值
    this->translateLanguage();

    connect(setting_button, &QPushButton::clicked, this, &MainWidget::showSetting);
    // 监听设置框切换语言的信号
    connect(setting_dialog, &SettingDialog::switchLanguage, this, &MainWidget::onSwitchLanguage);
}

// 💡 关键点 2：将所有 tr() 语句集中在这里
void MainWidget::translateLanguage()
{
    this->setWindowTitle(tr("main widget"));
    welcome_label->setText(tr("welcome to Qt"));
    setting_button->setText(tr("setting"));
    ok_button->setText(tr("ok"));
    cancel_button->setText(tr("cancel"));
}

// 💡 关键点 3：加载翻译文件并分发重译事件
void MainWidget::onSwitchLanguage(int index)
{
    LANGUAGE language = static_cast<LANGUAGE>(index);
    QString language_qm;

    switch(language)
    {
    case UI_ZH:
        language_qm = QString(":/qm/main_widget_zh");
        break;
    case UI_EN:
        language_qm = QString(":/qm/main_widget_en");
        break;
    default:
        language_qm = QString(":/qm/main_widget_zh");
    }

    if(m_currentLanguage != language)
    {
        m_currentLanguage = language;

        // 加载新语言包
        m_translator->load(language_qm);

        // 重新翻译主界面与子对话框
        this->translateLanguage();
        setting_dialog->translateLanguage();

        // 将用户的选择保存到配置文件（如 user.ini），以便下次启动读取
        Util::writeInit("./user.ini", "language", QString::number(language));
    }
}

void MainWidget::showSetting()
{
    setting_dialog->loadConfig();
    setting_dialog->exec();
}

3. 设置对话框实现 (setting_dialog.cpp) #

cpp
#include "setting_dialog.h"

SettingDialog::SettingDialog(QWidget *parent)
    : QDialog(parent)
{
    this->setMinimumSize(300, 200);
    this->setWindowFlags(windowFlags() & ~Qt::WindowContextHelpButtonHint);

    language_label = new QLabel();
    language_combo_box = new QComboBox();
    info_label = new QLabel();

    language_combo_box->addItem("Chinese (中文)", UI_ZH);
    language_combo_box->addItem("English (英文)", UI_EN);

    QHBoxLayout *lang_layout = new QHBoxLayout();
    lang_layout->addStretch();
    lang_layout->addWidget(language_label);
    lang_layout->addWidget(language_combo_box);
    lang_layout->addStretch();

    QVBoxLayout *main_layout = new QVBoxLayout();
    main_layout->addWidget(info_label, 0, Qt::AlignCenter);
    main_layout->addLayout(lang_layout);
    this->setLayout(main_layout);

    // 初始化重译
    this->translateLanguage();

    connect(language_combo_box, SIGNAL(currentIndexChanged(int)), this, SIGNAL(switchLanguage(int)));
}

void SettingDialog::translateLanguage()
{
    this->setWindowTitle(tr("setting dialog"));
    info_label->setText(tr("no brothers no programming"));
    language_label->setText(tr("language"));
    language_combo_box->setItemText(UI_ZH, tr("chinese"));
    language_combo_box->setItemText(UI_EN, tr("english"));
}

4. 程序入口配置与持久化加载 (main.cpp) #

cpp
#include "main_widget.h"
#include <QApplication>
#include <QTranslator>
#include "util.h"

int main(int argc, char *argv[])
{
    QApplication app(argc, argv);

    // 读取最后一次保留的语言设置
    QString language_value;
    QString language_suffix = "zh";
    LANGUAGE language = UI_ZH;
    
    if(Util::readInit("./user.ini", "language", language_value))
    {
        language = static_cast<LANGUAGE>(language_value.toInt());
        if(language == UI_EN) {
            language_suffix = "en";
        }
    }

    // 安装翻译器
    QTranslator translator;  
    translator.load(QString(":/qm/main_widget_") + language_suffix);  
    app.installTranslator(&translator); 

    MainWidget main_widget;
    main_widget.setTranslator(&translator);
    main_widget.setLanguage(language);
    main_widget.show();
    
    return app.exec();
}

三、 Qt 国际化发布三步法 #

完成了 tr() 编码和界面结构调整后，需要依次通过以下 Qt 内置工具链完成国际化落地：

graph LR
    A[C++/QML Source] -->|1. lupdate| B[.ts XML 翻译源]
    B -->|2. Qt Linguist| C[人工翻译并翻译确认]
    C -->|3. lrelease| D[.qm 紧凑二进制文件]
  1. lupdate 工具提取： 在 Qt Creator 中选中菜单的 Update Translations (lupdate)。它会扫描源文件中的所有 tr() 语句，并生成或更新 XML 格式的 .ts 翻译源文件。
  2. Qt Linguist（语言专家）翻译： 使用官方独立的 Linguist GUI 应用程序打开 .ts 文件。翻译人员在其中录入对应的英文、日文等，并点击“确认/完成”勾选。
  3. lrelease 二进制编译： 在 Linguist 中选择 Release 或在 Creator 中点击 Release Translations (lrelease)。它会将可读的 XML 文件编译打包为高效率、体积小的机器理解的 .qm 二进制文件。

💡 多语化规范避坑指南 #

⚠警告

切记：不要在 tr() 中直接使用非 ASCII 字符（例如硬编码中文）。

错误范例：tr("欢迎使用本软件")
这样在无翻译文件或编码格式异常时极易出现乱码。

正确规范：在代码中编写英文作为 key，例如 tr("welcome to app")，然后再用 ts/qm 翻译文件映射出中文。如果需要直接硬编码非翻译文本，请使用 QStringLiteral("中文常量") 替代普通双引号。

使用资源系统（.qrc）嵌入 QM #

建议将生成的 .qm 文件添加进项目资源文件 .qrc（前缀路径通常设为 :/qm/）。

  • 优势 1：大幅减少独立分发的文件数量，便于绿色打包。
  • 优势 2：避免由于用户意外误删 .qm 翻译文件而导致翻译失效。
