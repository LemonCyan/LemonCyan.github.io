Qt之QComboBox自定义下拉项委托（实现账号删除） #

在类似 QQ 等多账号登录界面中，我们经常能看到账号输入框是一个下拉列表（QComboBox）。展开下拉列表后，每一行除了展示账号名称，右侧还会附带一个小叉（Delete）图标。鼠标滑过时小叉高亮，点击则会触发删除并把该条账号从历史列表中移除。

在 Qt 中，要为下拉控件定制这种高级交互外观，最优雅的做法是使用 模型/视图委托 —— 继承 QStyledItemDelegate 并重写其绘制与事件过滤器。

一、 自定义委托类设计 (ItemDelegate) #

我们需要捕获鼠标在下拉项内部的点击与移动，因此需要重写 paint 进行渲染，并重写 editorEvent 进行交互响应。

1. 头文件 (ItemDelegate.h) #

cpp
#pragma once
#include <QStyledItemDelegate>
#include <QModelIndex>

class ItemDelegate : public QStyledItemDelegate
{
    Q_OBJECT
public:
    explicit ItemDelegate(QObject *parent = nullptr);
    ~ItemDelegate() {}

    // 重写绘制函数，用于添加删除小图标
    void paint(QPainter *painter, 
               const QStyleOptionViewItem &option, 
               const QModelIndex &index) const override;

    // 重写事件过滤，响应鼠标悬停与点击
    bool editorEvent(QEvent *event, 
                     QAbstractItemModel *model, 
                     const QStyleOptionViewItem &option, 
                     const QModelIndex &index) override;

signals:
    void deleteItem(const QModelIndex &index); // 发送删除项信号
};

2. 源文件 (ItemDelegate.cpp) #

cpp
#include "ItemDelegate.h"
#include <QPainter>
#include <QMouseEvent>
#include <QApplication>
#include <QToolTip>

ItemDelegate::ItemDelegate(QObject *parent)
    : QStyledItemDelegate(parent)
{
}

// 1. 在每个下拉选项的右侧绘制删除图标
void ItemDelegate::paint(QPainter *painter, 
                         const QStyleOptionViewItem &option, 
                         const QModelIndex &index) const
{
    QStyleOptionViewItem viewOption(option);
    
    // 💡 优化体验：去除 item 被选中时默认的虚线焦点边框
    if (viewOption.state & QStyle::State_HasFocus)
    {
        viewOption.state = viewOption.state ^ QStyle::State_HasFocus;
    }

    // 先调用默认实现绘制背景色和左侧的文字内容
    QStyledItemDelegate::paint(painter, viewOption, index);

    // 计算右侧删除按钮的位置 (A4 A5 等位置对齐)
    int iconSize = 9;
    int verticalOffset = (viewOption.rect.height() - iconSize) / 2;
    
    // 规定按钮矩形：放置在距离右侧边缘 30 像素的位置
    QRect deleteRect(viewOption.rect.left() + viewOption.rect.width() - 30, 
                     viewOption.rect.top() + verticalOffset, 
                     iconSize, iconSize);

    // 绘制删除图标（例如从资源文件中加载 delete.png）
    QPixmap pixmap(":/Images/delete.png");
    painter->drawPixmap(deleteRect, pixmap);
}

// 2. 处理鼠标移动和按下事件
bool ItemDelegate::editorEvent(QEvent *event, 
                               QAbstractItemModel *model, 
                               const QStyleOptionViewItem &option, 
                               const QModelIndex &index)
{
    // 计算与 paint() 中完全相同的按钮区域
    int iconSize = 9;
    int verticalOffset = (option.rect.height() - iconSize) / 2;
    QRect deleteRect(option.rect.left() + option.rect.width() - 30, 
                     option.rect.top() + verticalOffset, 
                     iconSize, iconSize);

    QMouseEvent *mouseEvent = static_cast<QMouseEvent*>(event);
    
    // 鼠标在删除按钮范围内
    if (deleteRect.contains(mouseEvent->pos()))
    {
        if (event->type() == QEvent::MouseButtonPress)
        {
            // 触发按下时，发射删除信号
            emit deleteItem(index);
        }
        else if (event->type() == QEvent::MouseMove)
        {
            // 鼠标悬停在按钮上时，临时改变光标为“手型”，并弹出气泡提示
            QApplication::setOverrideCursor(Qt::PointingHandCursor);
            QToolTip::showText(mouseEvent->globalPos(), QStringLiteral("删除账号信息"));
        }
    }
    else
    {
        // 鼠标移出按钮区，复原为常规光标，并隐去提示
        QApplication::restoreOverrideCursor();
    }

    return QStyledItemDelegate::editorEvent(event, model, option, index);
}

二、 绑定委托与删除槽函数 #

在我们的主窗口（如 Widget）中，将该委托绑定给 QComboBox 的视图，并建立信号槽连接。

cpp
// 在主窗口初始化时绑定委托
ItemDelegate *pDelegate = new ItemDelegate(this);

// 关键：将委托设置给 QComboBox 的下拉视图 View 
ui->comboBox->setItemDelegate(pDelegate);

// 绑定删除项槽函数
connect(pDelegate, SIGNAL(deleteItem(QModelIndex)), 
        this, SLOT(onDeleteAccount(QModelIndex)));

账号删除槽函数实现 #

cpp
#include <QMessageBox>

void Widget::onDeleteAccount(const QModelIndex &index)
{
    // 弹出确认对话框防止用户误触
    QMessageBox::StandardButton btn = QMessageBox::question(
        this, 
        QStringLiteral("提示"), 
        QStringLiteral("确认要删除所选的账号记录吗？"), 
        QMessageBox::Yes | QMessageBox::No, 
        QMessageBox::No
    );

    if (btn == QMessageBox::Yes)
    {
        // 从 QComboBox 数据模型中移除对应的行
        ui->comboBox->removeItem(index.row());
    }
}

三、 技术原理剖析 #

  • setItemDelegate 的作用机制：QComboBox 内部由两个主要部分组成：一是用于常态显示的 QLineEdit；二是用于下拉展开的 QAbstractItemView。使用 setItemDelegate 实际上是改变了下拉视图里的单元格项委托。
  • editorEvent 拦截交互：一般的 paint 只负责单纯的静态绘制。要想让下拉列表的特定区域具备响应鼠标点击（而不触发整行选中）的交互能力，就必须依赖重写 editorEvent 进行坐标域包含判定（deleteRect.contains(pos)）。
