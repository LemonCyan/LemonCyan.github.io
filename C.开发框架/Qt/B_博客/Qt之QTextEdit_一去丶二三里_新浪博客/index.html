Qt之QTextEdit富文本样式配置、图片插入与内容检索高亮 #

在 Qt 桌面开发中，QTextEdit 是处理富文本（Rich Text）和长篇排版文档的核心控件。相比只能录入单行无样式明文的 QLineEdit，QTextEdit 支持复杂的 HTML 标记、字形修饰、段落对齐、甚至内联图片的混排渲染。

从 Qt4 升级到 Qt5，QTextEdit 的 API 进行了一些精简和微调（例如旧有的 alignLeft() 统一被 setAlignment(Qt::Alignment) 代替，setFontFamily 等槽函数的参数更契合现代 C++ 类型）。本文将总结该控件的高频使用场景及相关 C++ 实现代码。

一、 基础字符样式与段落格式设置 #

QTextEdit 提供了一系列便捷的直调接口，用于更改当前选中文本或新录入文本的样式属性。

序号 属性接口 取值与作用说明
1 setFontWeight(int weight) 设置字体的粗细程度，取值源于 QFont::Weight（如 QFont::Bold）
2 setFontItalic(bool b) 设置是否应用斜体字（true 为倾斜，false 为常规）
3 setFontUnderline(bool b) 设置是否带有下划线（true 为添加，false 为消除）
4 setFontFamily(const QString &family) 设置字体家族名称（如 "Microsoft YaHei"、"Courier New"）
5 setFontPointSize(qreal s) 设置字体的字号尺寸（支持浮点型点数）
6 setTextColor(const QColor &c) 设置前景色（字体颜色）
7 setTextBackgroundColor(const QColor &c) 设置选区文字的底色（文本背景颜色）
8 setAlignment(Qt::Alignment a) 设置文本水平对齐（Qt::AlignLeft、Qt::AlignRight、Qt::AlignCenter、Qt::AlignJustify）

二、 往 QTextEdit 中插入图片 (Inline Image) #

我们不能直接将外部图片拖入或追加进 QTextEdit 的缓存，而必须借助 QTextCursor（文本光标） 和 QTextDocument（文档模型） 资源管理器来完成图片资源的绑定与排版。

cpp
void Widget::insertImageToEdit()
{
    // 1. 加载图片文件
    QImage image(":/Images/logo.png");
    if (image.isNull())
        return;

    // 2. 根据视口大小等比例缩放图片尺寸，避免图片太大撑破布局
    int viewportWidth = ui->textEdit->viewport()->width();
    int viewportHeight = ui->textEdit->viewport()->height();
    if (image.width() > viewportWidth || image.height() > viewportHeight)
    {
        image = image.scaled(150, 150, Qt::KeepAspectRatio, Qt::SmoothTransformation);
    }

    // 3. 获取光标和文档模型
    QTextCursor cursor = ui->textEdit->textCursor();
    QTextDocument *document = ui->textEdit->document();
    
    // 💡 避坑建议：
    // 图片在文档内部必须作为缓存资源注册。我们分配一个虚拟的 URL 路径给该图片
    QUrl imageUrl("myresource://logo_thumbnail.png");
    document->addResource(QTextDocument::ImageResource, imageUrl, QVariant(image));

    // 4. 通过 QTextCursor 插入图文格式
    QTextImageFormat imageFormat;
    imageFormat.setName(imageUrl.toString()); // 指向注册的资源名称
    cursor.insertImage(imageFormat);
}

三、 文档全文检索匹配并批量高亮 #

在制作日志编辑器或文本查找替换时，我们需要遍历文档的所有匹配段并应用特定的颜色标记：

cpp
void Widget::searchAndHighlight(const QString &searchText)
{
    if (searchText.trimmed().isEmpty())
        return;

    QTextDocument *document = ui->textEdit->document();
    QTextCursor cursor(document);
    bool found = false;

    // 开启批处理事务块，可以显著提高大型文档的处理速度，并优化撤销（Undo）栈
    cursor.beginEditBlock();

    // 创建要覆盖渲染的高亮字符格式（此处配置为红色粗体）
    QTextCharFormat highlightFormat;
    highlightFormat.setForeground(Qt::red);
    highlightFormat.setFontWeight(QFont::Bold);

    // 循环检索
    QTextCursor searchCursor(document);
    while (!searchCursor.isNull() && !searchCursor.atEnd())
    {
        // 查找指定关键字。FindWholeWords 代表整词匹配，也可以按需去掉
        searchCursor = document->find(searchText, searchCursor, QTextDocument::FindWholeWords);
        
        if (!searchCursor.isNull())
        {
            found = true;
            // 将选中的文字块合并（覆盖）我们定义的高亮格式
            searchCursor.mergeCharFormat(highlightFormat);
        }
    }

    cursor.endEditBlock();

    if (!found)
    {
        QMessageBox::information(this, tr("查找提示"), tr("未在文档中检索到对应的关键字。"));
    }
}

四、 高频痛点：如何设置行间距 (Line Spacing) #

很多开发者抱怨调用 setFont() 并没有提供设置行间距（段落高度）的接口。在 Qt 中，调整行间距需要深入到 QTextBlockFormat（段落块格式） 层进行合并设定：

cpp
void Widget::setTextLineHeight(int percentage)
{
    // 获取当前的光标位置
    QTextCursor cursor = ui->textEdit->textCursor();
    
    // 1. 新建段落块格式
    QTextBlockFormat blockFormat;
    
    // 💡 设置行高类型为比例模式（例如百分之 150 代表 1.5 倍行距）
    blockFormat.setLineHeight(percentage, QTextBlockFormat::ProportionalHeight);
    
    // 2. 选择整篇文档（如果希望全局修改）
    cursor.select(QTextCursor::Document);
    
    // 3. 将新格式合并应用回文本域
    cursor.mergeBlockFormat(blockFormat);
}

通过以上 API 封装，能够极大地提升 QTextEdit 的交互质感，使其在实际工程开发中具备优秀的富文本排版能力。
