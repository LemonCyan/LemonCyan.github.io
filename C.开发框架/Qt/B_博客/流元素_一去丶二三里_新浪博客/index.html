QML之流元素（一）动画详解 #

在现代流畅的用户界面（Fluid UI）设计中，动画是至关重要的基石。QML 通过直观的语法，允许开发者利用状态（States）和过渡转换（Transitions）来操纵元素的属性值，从而建立出极其顺畅、生动的视觉效果。

5.1 QML 动画基础 #

动画的核心原理是值插值（Value Interpolation）。动画会定义一条变化曲线，将某个属性值在指定的时间内平滑地从起始值过渡到目标值。

Qt Quick 中的所有动画都由同一个全局计时器控制，这样不仅能保证不同动画之间的精确同步，也大幅提高了渲染性能。

ℹ笔记

动画的本质是控制属性的改变。QML 中的元素拥有丰富的属性，几乎所有的属性都可以应用动画。但请克制，过度且冗余的动画容易干扰用户视线。

简单动画示例 #

以下代码展示了当火箭加载时，让其在 X 轴上平移的同时做无限旋转：

qml
// animation.qml
import QtQuick 2.0

Image {
    source: "assets/background.png"

    Image {
        x: 40; y: 80
        source: "assets/rocket.png"

        // X 轴平移动画
        NumberAnimation on x {
            to: 240
            duration: 4000
            loops: Animation.Infinite
        }

        // 旋转动画
        RotationAnimation on rotation {
            to: 360
            duration: 4000
            loops: Animation.Infinite
        }
    }
}

5.2 核心动画元素 #

根据不同的属性类型和应用场景，Qt Quick 提供了多类动画元素：

1. 基础动画元素 #

  • PropertyAnimation（属性动画）：通过改变属性值来播放的通用基础动画。
  • NumberAnimation（数字动画）：专用于数值变化。
  • ColorAnimation（颜色动画）：专门处理颜色渐变。
  • RotationAnimation（旋转动画）：专门处理角度旋转。

2. 特殊及高级动画元素 #

  • PauseAnimation（暂停动画）：在动画序列中提供一段时间的延迟。
  • SequentialAnimation（顺序动画）：让子动画按照顺序依次播放。
  • ParallelAnimation（并行动画）：让子动画同时播放。
  • SmoothedAnimation（平滑动画）：使属性值的跟踪过程更加平滑。
  • SpringAnimation（弹簧动画）：提供类似弹簧往复震荡的过渡效果。
  • PathAnimation（路径动画）：让元素沿着指定的几何路径运动。

3. 动画辅助动作 #

  • PropertyAction（属性动作）：在动画播放的特定节点上瞬间改变属性值（不产生渐变）。
  • ScriptAction（脚本动作）：在动画播放的特定节点执行一段 JavaScript 脚本。

5.3 应用动画的三种方式 #

在 QML 中，动画可以通过以下三种常用方式触发应用：

方式一：属性关联动画 (Animation on property) #

直接在属性声明内部应用动画。如上文示例：

qml
NumberAnimation on y {
    to: 40
    duration: 4000
}

特点：元素一加载就会自动运行该动画。

方式二：行为动画 (Behavior on property) #

为特定属性指定默认的行为。当该属性的值被其他脚本或事件修改时，自动通过动画形式过渡：

qml
Behavior on y {
    NumberAnimation { duration: 4000 }
}
// 后续只要修改 y 的值，都会在 4 秒内平滑过渡
onClicked: y = 40

特点：能自动响应所有导致属性改变的事件。

方式三：独立动画 (Standalone Animation) #

将动画定义为独立的 QML 节点，并通过调用显式接口或属性绑定来触发运行：

qml
NumberAnimation {
    id: anim
    target: rocket
    properties: "y"
    from: 200
    to: 40
    duration: 4000
}
// 点击时显式启动
onClicked: anim.start()

特点：最灵活，提供了 start(), stop(), resume(), restart() 等完整控制接口。

5.4 缓冲曲线 (Easing Curves) #

插值算法决定了动画在进行过程中的速度变化。如果不设置，动画默认使用 Easing.Linear（线性插值），即匀速运动。

精心挑选的缓冲类型可以模拟现实物理规律，使界面显得更加自然。例如，翻书滑出效果可以使用慢出快进。

常用缓冲曲线类型 #

QML 提供了数十种预设的缓冲曲线：

  • Linear（匀速线性）
  • InQuad / OutQuad / InOutQuad（二次曲线缓冲）
  • InCubic（三次曲线加速）
  • InElastic（弹性橡皮筋效果）
  • InBack（回弹起跑效果）
  • OutBounce（物理碰撞反弹效果）

缓冲曲线应用示例 #

qml
NumberAnimation {
    id: anim
    target: square
    from: 40
    to: 500
    properties: "x"
    duration: 2000
    easing.type: Easing.OutBounce // 落地后产生乒乓球碰撞般的反弹效果
}

5.5 动画分组与嵌套实战：扔足球 #

在现实场景中，对象的运动往往由多个维度复合而成。我们可以使用 ParallelAnimation 和 SequentialAnimation 的嵌套组合来描述复杂的物体运动。

下面以扔足球的抛物线运动为例：

  1. 水平方向（X 轴）：匀速从左向右平移（线性）。
  2. 垂直方向（Y 轴）：先向上抛起（减速），再向下坠落（加速并发生反弹）。
  3. 自身旋转（Rotation）：在行进过程中不断旋转。

运动曲线分配 #

  • Y 轴上升阶段：使用 Easing.OutCirc 模拟重力减速。
  • Y 轴下落阶段：使用 Easing.OutBounce 模拟落地反弹。
  • X 轴平移与旋转：均使用线性运动。

完整 QML 代码实现 #

qml
import QtQuick 2.0

Item {
    id: root
    width: 480
    height: 300
    property int duration: 3000

    // 背景 - 天空
    Rectangle {
        id: sky
        width: parent.width
        height: 200
        gradient: Gradient {
            GradientStop { position: 0.0; color: "#0080FF" }
            GradientStop { position: 1.0; color: "#66CCFF" }
        }
    }

    // 背景 - 草地
    Rectangle {
        id: ground
        anchors.top: sky.bottom
        anchors.bottom: parent.bottom
        width: parent.width
        gradient: Gradient {
            GradientStop { position: 0.0; color: "#00FF00" }
            GradientStop { position: 1.0; color: "#00803F" }
        }
    }

    // 足球对象
    Image {
        id: ball
        x: 20; y: 240
        source: "assets/soccer_ball.png"

        MouseArea {
            anchors.fill: parent
            onClicked: {
                // 复位并重启运行
                ball.x = 20; ball.y = 240; ball.rotation = 0;
                anim.restart()
            }
        }
    }

    // 抛物线组合动画
    ParallelAnimation {
        id: anim
        
        // 1. 垂直方向（Y轴）：先升后降
        SequentialAnimation {
            // 上抛阶段 (占 40% 时间)
            NumberAnimation {
                target: ball
                properties: "y"
                to: 20
                duration: root.duration * 0.4
                easing.type: Easing.OutCirc
            }
            // 下落及碰撞阶段 (占 60% 时间)
            NumberAnimation {
                target: ball
                properties: "y"
                to: 240
                duration: root.duration * 0.6
                easing.type: Easing.OutBounce
            }
        }

        // 2. 水平方向（X轴）：匀速右移
        NumberAnimation {
            target: ball
            properties: "x"
            to: 400
            duration: root.duration
        }

        // 3. 自转方向：旋转两圈
        RotationAnimation {
            target: ball
            properties: "rotation"
            to: 720
            duration: root.duration * 1.1
        }
    }
}
