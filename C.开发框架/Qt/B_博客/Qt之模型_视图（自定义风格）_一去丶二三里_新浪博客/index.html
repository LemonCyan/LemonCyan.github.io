Qt模型视图架构进阶：自定义单元格绘制委托与QSS进度条美化 #

在基于 QTableView / QTreeView 的界面开发中，默认的单元格绘制只能以单行文本显示。当我们需要在单个单元格中展示更加复杂的复合版面（例如：同时显示文件名、当前下载速度、以及在底部绘制一个细长进度条）时，就必须通过**自定义委托（QStyledItemDelegate）**进行全手绘。

本文将演示如何实现一个高级任务进度卡片委托类 DetailProgressBar，消除多余的焦点框线，并揭秘如何成功将 QSS 样式表应用到委托所绘制的组件上。

一、 自定义单元格委托绘制实现 #

我们创建一个名为 DetailProgressBar 的类，继承自 QStyledItemDelegate，并重写 paint 函数。

C++ 代码实现： #

cpp
#include <QStyledItemDelegate>
#include <QPainter>
#include <QApplication>
#include <QProgressBar>
#include <QStyleOptionProgressBar>

class DetailProgressBar : public QStyledItemDelegate
{
    Q_OBJECT
public:
    explicit DetailProgressBar(QObject *parent = nullptr) : QStyledItemDelegate(parent) {}

    // 💡 核心绘制入口
    void paint(QPainter *painter, 
               const QStyleOptionViewItem &option, 
               const QModelIndex &index) const override
    {
        // 1. 拷贝原始样式选项
        QStyleOptionViewItem viewOption(option);
        
        // 💡 技巧：通过位异或运算，强行清除 Focus 状态，消除单元格被选中时刺眼的虚线框
        if (viewOption.state & QStyle::State_HasFocus) {
            viewOption.state = viewOption.state ^ QStyle::State_HasFocus;
        }

        // 调用默认父类进行行背景和基本高亮绘制
        QStyledItemDelegate::paint(painter, viewOption, index);

        // 2. 针对特定列 (Column == 1) 绘制自定义卡片排版
        if (index.column() == 1) 
        {
            const QAbstractItemModel *itemModel = index.model();
            int currentRow = index.row();

            // 💡 核心跨列读取：从当前行的其它辅助列读取具体属性数据
            QString filename = itemModel->data(itemModel->index(currentRow, 2), Qt::DisplayRole).toString();
            qint64 size = itemModel->data(itemModel->index(currentRow, 3), Qt::DisplayRole).toLongLong();
            qint64 totalSize = itemModel->data(itemModel->index(currentRow, 4), Qt::DisplayRole).toLongLong();
            double speed = itemModel->data(itemModel->index(currentRow, 5), Qt::DisplayRole).toDouble();
            
            // 计算下载进度百分比
            if (totalSize <= 0) totalSize = 1;
            int progress = static_cast<int>((size * 100.0) / totalSize);
            if (progress > 100) progress = 100;

            // 格式化速度字符串（假定 Util::getSpeed 格式化字节为 KB/s 或 MB/s）
            QString speedText = QString("%1/s").arg(speed); // 此处可做格式化

            // 3. 手工绘制文字信息
            // 绘制左上角文件名
            painter->drawText(QRect(option.rect.x() + 5, option.rect.y() + 4, option.rect.width() - 80, 16),
                              filename);
            
            // 绘制右上角速度
            painter->drawText(QRect(option.rect.right() - 75, option.rect.y() + 4, 70, 16),
                              Qt::AlignRight | Qt::AlignVCenter, 
                              speedText);

            // 4. 💡 动态拼装进度条控制项参数
            QStyleOptionProgressBar progressBarOption;
            progressBarOption.minimum = 0;
            progressBarOption.maximum = 100;
            progressBarOption.progress = progress;
            progressBarOption.textAlignment = Qt::AlignCenter;
            progressBarOption.textVisible = false; // 卡片里不显示进度百分比文字
            
            // 计算进度条的精确几何坐标 (贴紧单元格底部，高度为 6px)
            int pbHeight = 6;
            int pbMarginY = 4;
            progressBarOption.rect = QRect(option.rect.x() + 5, 
                                           option.rect.y() + option.rect.height() - pbHeight - pbMarginY,  
                                           option.rect.width() - 10, 
                                           pbHeight);

            // 5. 实例化一个局部的 QProgressBar 临时组件作为绘图渲染载体
            QProgressBar tempProgressBar;
            
            // 💡 重点：把自定义的 QSS 样式表赋给临时的进度条，QStyle 会在绘制时读取此样式
            tempProgressBar.setStyleSheet(
                "QProgressBar {"
                "    border: none;"
                "    background: rgb(210, 225, 240);"
                "    border-radius: 3px;"
                "}"
                "QProgressBar::chunk {"
                "    background: rgb(60, 140, 220);"
                "    border-radius: 3px;"
                "}"
            );

            // 6. 调用全局皮肤引擎进行渲染
            QApplication::style()->drawControl(QStyle::CE_ProgressBar, 
                                               &progressBarOption, 
                                               painter, 
                                               &tempProgressBar);
        }
    }
};

二、 💡 核心问题解答：委托中绘制的组件如何响应 QSS？ #

许多开发者尝试在全局样式表（例如在 main.cpp 中执行 qApp->setStyleSheet(...)）中写入 QProgressBar { ... }，却发现 QTableView 委托中用 drawControl 绘制出来的进度条仍然是操作系统灰蒙蒙的默认外观，样式表完全没有生效。

为什么会失效？ #

Qt 的 QSS 解析引擎在进行渲染时，其寻址是基于 Widget 实例对象树的。在委托的 paint 内部，如果不传入具体的 Widget 对象，系统就会使用最底层的原始风格进行默认绘制，从而无视任何样式表。

解决方案： #

  1. 方案一 (临时赋予)：如上文代码所示，在 paint() 函数里声明一个局部临时组件 QProgressBar tempProgressBar;，并在绘制前调用 tempProgressBar.setStyleSheet(...) 赋予局部样式，接着将其指针作为第四个参数传入 drawControl(...)。
  2. 方案二 (父级委托关联)：如果你希望使用全局的样式表，那么在委托进行 drawControl 调用时，必须将视图控件的指针（如 option.widget）传入：
    cpp
    // 传入 option.widget 指针，使得全局样式可以向下遗传给当前的绘制过程
QApplication::style()->drawControl(QStyle::CE_ProgressBar, 
                                   &progressBarOption, 
                                   painter, 
                                   option.widget);
    只要 QTableView 或其祖先设置了对应的 QSS，通过遗传关系，绘制出来的进度条也会呈现出 QSS 所设定的华丽质感。
