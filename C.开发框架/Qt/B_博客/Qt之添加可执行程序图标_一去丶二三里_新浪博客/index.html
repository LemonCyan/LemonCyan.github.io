Qt之添加可执行程序图标 #

为应用程序配置一个精致的图标不仅能提升美观度，更能让用户直观地识别程序。在 Qt Assistant（帮助文档）中搜索 "Setting the Application Icon"，官方给出了详细的平台相关指导。

本文将直接总结在 Windows 操作系统下，为编译生成的 .exe 可执行程序添加应用程序图标的极简步骤。

一、配置步骤 #

1. 准备图标文件 #

准备好你的图标文件（格式必须是 .ico，例如：player.ico），并将其存放在项目的资源目录中（例如项目根目录下的 images 文件夹中）。

2. 创建或编辑 .rc 资源文件 #

在你的 Qt 项目根目录下新建或编辑一个文本文件，并将其命名为 logo.rc（文件名可以随意定义，后缀必须是 .rc）。

在文件中添加如下的一行代码：

IDI_ICON1               ICON                    "images\\player.ico"
❢重要

这里的路径是相对于 .rc 文件所在目录的相对路径，注意在 Windows 资源文件语法中使用双反斜杠 \\ 作为路径分隔符。

3. 配置项目的 .pro 文件 #

打开你的 Qt 项目 .pro 配置文件，在文件末尾添加以下一行代码，将刚刚创建的 .rc 文件注册进 Qt 的构建系统：

ini
RC_FILE = logo.rc

如果你使用的是 Visual Studio 开发环境，也可以直接在项目属性中的资源编译器选项中关联此 .rc 文件，或者将该 .rc 文件作为现有文件直接拖入 VS 的解决方案管理器中。

4. 重新构建生成 #

保存以上所有更改，执行 qmake，然后选择“重新构建 (Rebuild)”。编译完成后，前往生成目录查看编译出的 .exe 程序，此时它的外观就已经成功替换为你指定的 .ico 图标了！
