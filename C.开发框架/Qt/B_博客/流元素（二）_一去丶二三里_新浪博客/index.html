QML之流元素（二）状态与过渡（States & Transitions） #

在现代 UI 开发中，界面往往被描述为一系列离散的**“状态（States）”。每个状态下，界面部件的属性（如位置、颜色、大小、可见性等）都不尽相同。为了让状态切换显得自然流畅，我们通常会在状态之间加入“过渡（Transitions）”**动画。

QML 提供了非常优雅的状态机与动画过滤机制。下面我们以一个经典的“交通红绿灯”切换效果为例进行讲解。

一、 状态 (States) #

在 QML 中，使用 State 元素来定义不同的界面配置，并通过主项目的 states 列表属性进行管理。

  • 每个状态用唯一的字符串 name 标识。
  • 默认初始化状态的名称为 ""（空字符串），代表项目最开始加载时的默认属性。
  • 状态内部使用 PropertyChanges 元素来描述在该状态下，目标对象的哪些属性应该发生改变。

1. 状态定义基本结构 #

qml
Item {
    id: root
    
    // 管理各种可用状态
    states: [
        State {
            name: "go"
            PropertyChanges { target: light1; color: "black" }
            PropertyChanges { target: light2; color: "green" }
        },
        State {
            name: "stop"
            PropertyChanges { target: light1; color: "red" }
            PropertyChanges { target: light2; color: "black" }
        }
    ]
}

2. 状态切换触发方式 #

触发状态切换非常直接，可以直接为项目的 state 属性赋予新的状态名称：

qml
MouseArea {
    anchors.fill: parent
    // 点击时在 stop 与 go 之间往复切换
    onClicked: parent.state = (parent.state == "stop" ? "go" : "stop")
}
✦提示

除了手动赋值切换，也可以使用 State 元素的 when 属性。将其绑定到一个布尔表达式，当表达式计算为 true 时，系统会自动切入该状态。

二、 红绿灯状态机实例 #

下面我们通过代码实现双灯红绿灯。两个灯为黑色底框，在 "stop" 状态下上灯亮红，在 "go" 状态下下灯亮绿。

qml
import QtQuick 2.0

Rectangle {
    id: trafficLightBox
    width: 150; height: 270
    color: "darkgray"
    radius: 10

    // 默认初始状态设为 "stop"
    state: "stop"

    // 1. 定义红灯（上灯）
    Rectangle {
        id: light1
        x: 25; y: 15
        width: 100; height: 100
        radius: width / 2
        color: "black" // 默认黑色（熄灭）
    }

    // 2. 定义绿灯（下灯）
    Rectangle {
        id: light2
        x: 25; y: 135
        width: 100; height: 100
        radius: width / 2
        color: "black"
    }

    // 3. 配置状态变更属性
    states: [
        State {
            name: "stop"
            PropertyChanges { target: light1; color: "red" }
            PropertyChanges { target: light2; color: "black" }
        },
        State {
            name: "go"
            PropertyChanges { target: light1; color: "black" }
            PropertyChanges { target: light2; color: "green" }
        }
    ]

    // 4. 点击整个区域切换状态
    MouseArea {
        anchors.fill: parent
        onClicked: {
            parent.state = (parent.state == "stop" ? "go" : "stop")
        }
    }
}
❢重要

关于增量修改的原则：在 PropertyChanges 中，我们只需要声明该状态下相对于**默认初始状态（即 ""）**发生改变的属性，而不是相对于“前一个状态”。例如，若 light2 的初始颜色就是 black，在 "stop" 状态里并不需要显式写 PropertyChanges { target: light2; color: "black" }。

三、 过渡动画 (Transitions) #

直接切换状态会让颜色瞬间变色，显得极其生硬。通过在 transitions 列表中添加 Transition 元素，可以平滑地展示变色过程。

  • Transition 可以设置 from 和 to 属性，就像一个过滤器。
  • 只有当状态从 from 指定的值变化到 to 指定的值时，该过渡动画才会播放。
  • from 或 to 可以设为通配符 *，代表匹配任意状态转换。

为红绿灯切换添加淡入淡出过渡 #

qml
    // 将 transitions 属性附加至红绿灯 Box 内部
    transitions: [
        // 仅在从 "stop" 切换到 "go" 时执行平滑过渡
        Transition {
            from: "stop"; to: "go"
            
            // 设定针对两盏灯颜色属性的渐变动画，持续时间为 2 秒 (2000 毫秒)
            ColorAnimation { 
                target: light1
                properties: "color"
                duration: 2000 
            }
            ColorAnimation { 
                target: light2
                properties: "color"
                duration: 2000 
            }
        }
    ]

现在点击界面，当从红灯（stop）切换为绿灯（go）时，你会看到红灯渐渐熄灭，绿灯缓缓亮起，过渡动画效果非常丝滑。而由于我们没有定义从 go 回到 stop 的特定 Transition，逆向切换时仍会顺发秒切。

四、 进阶创意与拓展 #

通过状态与过渡，你可以很容易丰富出更多生动的动效：

  1. 缩放结合：在 "go" 状态中，除了让绿灯亮起，还可以将绿灯的 scale 设为 1.1，红灯设为 0.9，并在过渡中加上 NumberAnimation { properties: "scale"; duration: 300 }，使亮灯具有“弹出放大”的立体视觉。
  2. 警示黄灯闪烁 (attention 状态)：添加一个 "attention" 状态，并配合 SequentialAnimation（串行动画）或 PropertyAnimation 的 loops 循环循环闪烁黄色。
  3. 缓冲曲线 (Easing Curves)：通过配置 ColorAnimation 或 NumberAnimation 的 easing.type 属性（如 Easing.InOutQuad、Easing.OutBounce），能实现回弹或渐入渐出等极其自然丰富的动画节奏。
