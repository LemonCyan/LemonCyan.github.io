Qt之获取系统硬件与内存配置信息（CPU、物理内存、虚拟内存） #

在开发跨平台的客户端（特别是包含诊断面板、性能监视器或状态条）时，经常需要拉取本机的硬件指标，例如：

  1. CPU 核心信息：计算核心数、架构类别、级别型号等。
  2. 物理内存利用率：物理内存总容量、当前可用余量、使用占比等。
  3. 虚拟内存与分页文件：页面缓存文件大小、虚拟内存限额与剩余量等。

Qt 作为一个跨平台的 UI 框架，出于简洁性与高度抽象考虑，并未直接内置与底层硬件或 OS 强耦合的监视接口。要想获取这些底层状态，我们必须根据编译目标平台，使用不同的底层 API：

  • Windows：调用原生 Win32 SDK 系统服务接口（GetSystemInfo、GlobalMemoryStatusEx）。
  • Linux：直接利用文本读写（QFile）读取并解析系统伪文件系统（/proc/ 目录）。

一、 Windows 平台下的硬件与内存获取 (Win32 API) #

在 Windows 操作系统上，我们需要引入系统头文件 <windows.h>，并通过系统结构体完成查询。

cpp
#ifdef Q_OS_WIN
#include <windows.h>
#endif
#include <QDebug>

// 定义换算常数：把字节（Bytes）转成兆字节（MB）
#define MB (1024 * 1024)

void getWindowsSystemInfo()
{
#ifdef Q_OS_WIN
    // 1. 获取 CPU 处理器及分页规格
    SYSTEM_INFO systemInfo;
    GetSystemInfo(&systemInfo);

    qDebug() << QStringLiteral("处理器核心个数: ") << systemInfo.dwNumberOfProcessors;
    qDebug() << QStringLiteral("处理器掩码: ")     << systemInfo.dwActiveProcessorMask;
    qDebug() << QStringLiteral("处理器分页大小: ") << systemInfo.dwPageSize;
    qDebug() << QStringLiteral("处理器类型: ")     << systemInfo.dwProcessorType;
    qDebug() << QStringLiteral("处理器架构级别: ") << systemInfo.wProcessorLevel;
    qDebug() << QStringLiteral("处理器修正版本: ") << systemInfo.wProcessorRevision;
    qDebug() << QStringLiteral("最大寻址内存单元: ") << systemInfo.lpMaximumApplicationAddress;
    qDebug() << QStringLiteral("最小寻址内存单元: ") << systemInfo.lpMinimumApplicationAddress;

    qDebug() << "--------------------------------------------------";

    // 2. 获取物理内存与虚拟内存指标
    MEMORYSTATUSEX statex;
    statex.dwLength = sizeof(statex); // 必须在调用前赋值结构体长度
    
    if (GlobalMemoryStatusEx(&statex))
    {
        qDebug() << QStringLiteral("物理内存使用率 (%): ") << statex.dwMemoryLoad;
        qDebug() << QStringLiteral("物理内存总量 (MB): ")    << statex.ullTotalPhys / MB;
        qDebug() << QStringLiteral("可用物理内存 (MB): ")    << statex.ullAvailPhys / MB;
        qDebug() << QStringLiteral("系统页面文件总大小 (MB): ") << statex.ullTotalPageFile / MB;
        qDebug() << QStringLiteral("系统可用页面文件大小 (MB): ") << statex.ullAvailPageFile / MB;
        qDebug() << QStringLiteral("虚拟内存总大小 (MB): ")    << statex.ullTotalVirtual / MB;
        qDebug() << QStringLiteral("可用虚拟内存大小 (MB): ")    << statex.ullAvailVirtual / MB;
    }
#endif
}

二、 Linux 平台下的硬件与内存获取 (/proc 文件系统) #

在 Linux 系统中，操作系统会将内核动态数据结构和硬件环境映射为虚拟文件。我们只需要通过 QFile 读取以下几个文本文件并使用 QTextStream 解析关键字即可：

  • CPU 规格：/proc/cpuinfo
  • 物理内存指标：/proc/meminfo
  • 虚拟内存指标：/proc/vmstat

Linux 读取实现代码： #

cpp
#include <QFile>
#include <QTextStream>
#include <QDebug>

void getLinuxSystemInfo()
{
    // 1. 获取 CPU 核心数
    QFile cpuFile("/proc/cpuinfo");
    if (cpuFile.open(QIODevice::ReadOnly | QIODevice::Text))
    {
        QTextStream in(&cpuFile);
        int cpuCoresCount = 0;
        while (!in.atEnd())
        {
            QString line = in.readLine();
            // 在 cpuinfo 中，每多一个核心就会出现一行以 processor 开头的段落
            if (line.startsWith("processor"))
            {
                cpuCoresCount++;
            }
        }
        qDebug() << "Linux CPU Cores:" << cpuCoresCount;
        cpuFile.close();
    }

    // 2. 获取物理内存数据
    QFile memFile("/proc/meminfo");
    if (memFile.open(QIODevice::ReadOnly | QIODevice::Text))
    {
        QTextStream in(&memFile);
        qint64 totalMemKb = 0;
        qint64 availMemKb = 0;
        
        while (!in.atEnd())
        {
            QString line = in.readLine();
            if (line.startsWith("MemTotal:"))
            {
                // 解析形如: "MemTotal:        8165432 kB"
                QStringList parts = line.split(" ", QString::SkipEmptyParts);
                if (parts.size() >= 2) {
                    totalMemKb = parts.at(1).toLongLong();
                }
            }
            else if (line.startsWith("MemAvailable:"))
            {
                QStringList parts = line.split(" ", QString::SkipEmptyParts);
                if (parts.size() >= 2) {
                    availMemKb = parts.at(1).toLongLong();
                }
            }
        }
        
        qDebug() << "Total Physical Memory:" << totalMemKb / 1024 << "MB";
        qDebug() << "Available Memory:" << availMemKb / 1024 << "MB";
        if (totalMemKb > 0)
        {
            double usage = (double)(totalMemKb - availMemKb) / totalMemKb * 100.0;
            qDebug() << "Memory Usage:" << usage << "%";
        }
        memFile.close();
    }
}

三、 跨平台封装建议 #

为了让项目调用端感觉不到平台差异，可以在基础类中进行编译预处理宏分割封装：

cpp
class SystemMonitor
{
public:
    static int getCpuCores()
    {
#if defined(Q_OS_WIN)
        SYSTEM_INFO sysInfo;
        GetSystemInfo(&sysInfo);
        return sysInfo.dwNumberOfProcessors;
#elif defined(Q_OS_LINUX)
        // 执行 Linux 下读取 /proc/cpuinfo 并返回核心数的逻辑
        // ...
#else
        return 1; // 默认回退保底
#endif
    }
};

通过上述方式，在不增加额外庞大硬件检测库的前提下，能够极小成本地抓取 Windows/Linux 两大核心桌面系统的运行性能指标。
