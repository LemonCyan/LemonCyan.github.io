Qt之窗体透明 #

在进行 GUI 界面美化时，窗体特效（例如透明度、毛玻璃、圆角边缘等）是经常需要处理的内容。在 Qt 中实现窗体透明主要分为以下几种效果：整体全透明、仅主窗口背景透明（子窗体不透明）以及特定子窗体透明。

下面针对这些效果的实现方式进行详细阐述。

一、 全透明 (Window Opacity) #

这种效果下，主窗口以及窗口中的所有子部件（如按钮、文本框等）都会同时变透明。

实现代码 #

cpp
// 在窗口的构造函数或初始化函数中调用
setWindowOpacity(0.5);

参数说明 #

  • setWindowOpacity(qreal level)：接受一个 qreal 双精度浮点值，取值范围为 0.0 到 1.0。
    • 1.0：默认值，表示完全不透明。
    • 0.0：表示完全透明（隐藏）。
    • 0.5：表示 50% 的半透明效果。

二、 主窗体透明，子窗体不透明 #

这种效果下，仅主窗口的背景部分呈现出半透明或全透明，而窗口内部的各种按钮、文字、控件等子部件依然保持原有的不透明状态。这是现代扁平化与磨砂玻璃风格界面设计中最常用的特效。

实现该效果必须开启 Qt 窗口的无底色透明属性：

cpp
setAttribute(Qt::WA_TranslucentBackground, true);

在此基础上，我们可以通过纯色填充或渐变图片填充两种方式在 paintEvent 中重绘背景。

1. 采用半透明背景色填充 #

如果只需要窗口背景是某一种半透明颜色，在重绘事件中绘制包含 Alpha 通道的颜色即可：

cpp
// 构造函数中设置
setAttribute(Qt::WA_TranslucentBackground, true);

// 在窗口的 paintEvent 中重写
void MyWidget::paintEvent(QPaintEvent *event)
{
    QPainter painter(this);
    // QColor 的第四个参数表示透明度 (Alpha)，范围为 0 - 255
    // 这里的 80 表示背景的半透明等级
    painter.fillRect(this->rect(), QColor(0, 0, 255, 80)); 
}

2. 采用半透明渐变背景图片填充 #

如果你希望主窗口底图呈现带透明渐变的复杂纹理，需要通过设置 CompositionMode_SourceIn 模式将渐变笔刷与图片进行混合渲染：

cpp
// 构造函数中设置
setAttribute(Qt::WA_TranslucentBackground, true);

// 在窗口的 paintEvent 中重写
void QZXingWidget::paintEvent(QPaintEvent *event)
{
    // 载入待混色的原始大图
    QPixmap covert_pixmap(":/Images/background");
    
    // 建立一个大小一致、支持透明的缓冲图层
    QPixmap pixmap(covert_pixmap.width(), covert_pixmap.height());
    pixmap.fill(Qt::transparent); 
    
    QPainter painter(&pixmap);
    QPoint start_point(0, 0);
    QPoint end_point(0, pixmap.height());
    
    // 设置线性渐变，并配置透明通道的阶梯变化
    QLinearGradient linear_gradient(start_point, end_point);
    linear_gradient.setColorAt(0, QColor(255, 255, 255, 100));  // 顶端：透明度 100
    linear_gradient.setColorAt(0.5, QColor(255, 255, 255, 150)); // 中部：透明度 150
    linear_gradient.setColorAt(1, QColor(255, 255, 255, 255));   // 底部：完全不透明

    // 在缓冲图层绘制渐变画刷
    painter.fillRect(this->rect(), QBrush(linear_gradient));
    
    // 关键步骤：使用 SourceIn 混合模式使渐变与原图重叠合并
    painter.setCompositionMode(QPainter::CompositionMode_SourceIn); 
    painter.drawPixmap(0, 0, covert_pixmap);
    painter.end();
    
    // 在主屏幕上输出混合后的半透明像素底图
    QPainter painter2(this);
    painter2.drawPixmap(0, 0, pixmap);
}

三、 子窗体透明，主窗体不透明 #

通常用于悬浮提示框、消息气泡或独立浮层。这种情况下主窗口不透明，仅弹出的子窗口呈透明状态。
