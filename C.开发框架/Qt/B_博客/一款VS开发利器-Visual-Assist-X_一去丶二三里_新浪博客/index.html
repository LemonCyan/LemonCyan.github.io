一款VS开发利器 - Visual Assist X #

对于在 Windows 下使用 Microsoft Visual Studio 进行 C++ 与 Qt 开发的程序员，Visual Assist X（俗称“西红柿插件”）绝对是一款不可多得的辅助神器。它能完全集成到 VS 环境中，在不改变原有开发习惯的同时，极大地缩短编码耗时。

一、 关于 Visual Assist X #

Visual Assist X 具有强大的编辑和智能导航特性。

  • 语言支持广：支持 Microsoft Visual Studio 2003 至更高版本的各个开发版本，对 C/C++、C#、ASP、Visual Basic、Java 和 HTML 等语言均有良好支持。
  • 效率提升明显：自动识别各种关键字、系统函数与成员变量；提供智能的输入联想补全；自动纠正大小写输入错误；高亮标示代码中的语法隐患。

核心特性优势： #

  1. 更快的代码编写：提供精准的上下文关联补全，减少敲击键盘次数和潜在拼写错误。
  2. 快速阅读和理解代码：代码结构高亮更丰富，提供鼠标悬浮定义详情。
  3. 高效重构：支持快捷重命名类、函数、变量，自动提取方法或修改函数签名，且不易出错。
  4. 闪电般的代码导航：支持利用快捷键立即跳转到项目中的任意文件（Shift + Alt + O）或任意符号（Shift + Alt + S）。

详细资料及官方版本可参考 Whole Tomato 官网：http://www.wholetomato.com

二、 在 Visual Assist X 中配置 Qt 开发环境 #

当我们通过 Visual Studio 导入 Qt 管理的项目（配合 Qt VS Tools 插件）进行开发时，可能会发现西红柿插件无法自动联想 Qt 框架特有的类名和函数（如 QString、QWidget 等），造成代码提示失效。

为了恢复完美的智能代码提示，我们需要手动在插件中配置 Qt 的头文件目录：

  1. 打开 Visual Studio，在顶部菜单栏依次选择：“VAssistX” -> “Visual Assist X Options...”（选项菜单）。
  2. 在弹出的选项对话框中，在左侧选择 “Projects” -> “C/C++ Directories”。
  3. 在右侧 “Platform” 下拉框中，选择 “Custom”（自定义平台）。
  4. 在下方的 “Show Directories for” 下拉列表中选择 “Stable include files”（静态包含文件）。
  5. 点击新建路径图标，将您当前所使用的 Qt 版本的常用模块头文件包含目录添加进来。以典型的桌面开发为例，需要添加以下三个头文件目录：
    • QtCore 的 include 目录（例如 C:\Qt\Qt5.1.1\5.1.1\msvc2012\include\QtCore）
    • QtGui 的 include 目录（例如 C:\Qt\Qt5.1.1\5.1.1\msvc2012\include\QtGui）
    • QtWidgets 的 include 目录（例如 C:\Qt\Qt5.1.1\5.1.1\msvc2012\include\QtWidgets）
  6. 点击 OK 确认并关闭选项卡。

配置完成后，Visual Assist X 会重新扫描这些目录并建立后台符号表索引。稍等几秒钟，在编辑器中键入 Qt 相关类时，即可享受飞一般的代码提示与补全体验。
