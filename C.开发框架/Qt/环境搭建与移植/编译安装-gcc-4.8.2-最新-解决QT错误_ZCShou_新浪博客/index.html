欢迎转载，请注明出处： CentOS6.5内置的GCC版本为4.4，而Qt5.2.1则需要4.8.2的支持（支持C++11特性），因此， 必须先升级GCC。（对于CentOS7，默认的gcc版本就是4.8.2。） 从GNU官网下载源码

第一步：下载完成后，解压（以gcc-4.8.2.tar.bz2为例）： tar -jxvf gcc-4.8.2.tar.bz2 cd gcc-4.8.2

第二步：进入gcc-4.8.2目录中，设置编译依赖关系 ./contrib/download_prerequisites(联网情况下)

注意： (1)编译GCC4.8需要三个依赖包： MPFR=mpfr-2.4.2 GMP=gmp-4.3.2 MPC=mpc-0.8.1 联网情况下，输入命令：./contrib/download_prerequisites，脚本会自动wget到这几个依赖 包并编译。 断网情况下 断网环境下，请严格按照版本号下载并按顺序编译这三个依赖包，否则可能会导致GCCmake失 败。 从 下载GMP安装包 gmp-5.1.3 .tar.bz2 从http://ftp.gnu.org/gnu/mpfr/下载MPFR安装包 mpfr-3.1.2.tar.gz 从http://www.cise.ufl.edu/mirrors/GNU/pub/gnu/mpc下载MPC安装包 mpc-1.0.1.tar.gz 把GMP，MPFR 和 MPC 三个包分别解压到单独的文件中。 安装gmp cd gmp-5.1.3 ./configure make make check //这一步是必要的,用来查看有没有文件不匹配或缺失,在最后提示,到时注意看有没有error之 类的提示,如果没有说明安装正常了。 make install 有必要说明程序的头文件(.h)和库文件(lib*)的位置,本次安装会安装在 /usr/local/include 和 /usr/local/lib ,这个对后面安装mpfr很有作用. 安装mpfr cd mpfr-3.1.2 ./configure --with-gmp-include=/usr/local/include –with-gmp-lib=/usr/local/lib make make check //在每步操作中一定要看看有没有错误。 make install 安装MPC cd mpc-1.0.1 ./configure ftp://ftp.gnu.org/gnu/gmp/

make make check make install 上边安装成功后，还要配置lib目录，因为gcc编译时需要 exportLD_LIBRARY_PATH=$LD_LIBRARY_PATH:/usr/local/lib 这次就可以安装gcc了 第三步：配置gcc编译选项 cd .. mkdir gcc-build-4.8.2 cd gcc-build-4.8.2 ../gcc-4.8.2/configure --enable-checking=release--enable-languages=c,c++ -- disable-multilib

配置完成后，将生成Makefile文件。（注意：路径问题../gcc-4.8.2/） 注意：编译源码时，最好新建目录，防止编译后的文件和源文件干扰 注意： configure有几个编译参数需要理解一下： --prefix//默认gcc的安装目录，CentOS-6.5下面最好安装到/usr下，不然可能会有问题，采用 默认即可。 --enable-languages//指定gcc能编译哪些语言的文件，每种语言用逗号分隔,例如c,c++,java --disable-multilib //默认gcc能在32位系统上将代码编译成64位程序，或者在64位系统上编译 成32位程序，如果加上这个编译选项则表示关闭这个gcc的交叉编译功能。 第四步：编译 make -j4//这个过程需要30-120分钟的时间，依据电脑配置而定。j4,是四个作业一块运行，从 而提升编译效率。

注意：目录是在我们建立的gcc-build-4.8.2中，这样编译后的文件就在本目录了，防止与源码混 淆 编译安装 gcc 4.8.2 --最新--解决QT错误 编译安装 gcc 4.8.2 --最新--解决QT错误
