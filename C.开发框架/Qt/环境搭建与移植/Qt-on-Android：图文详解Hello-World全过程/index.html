Qt on Android：图文详解Hello World全过程 #

本文将从实践出发，演示如何在 Windows 环境下使用 Qt Creator 3.0 创建、管理、编译、签名并部署你的第一个 Qt on Android 应用程序（在屏幕上显示 "Hello Qt on Android!"）。

ℹ笔记

本文前置环境要求与《Windows下Qt 5.2 for Android开发入门》保持一致。请确保 Android NDK、SDK 以及 Ant 构建环境已在 Qt Creator 中配置妥当。

一、 创建工程 #

  1. 打开 Qt Creator，依次选择：文件(F) -> 新建文件或项目(N)。
  2. 在新建工程模板界面中，选择 应用程序 分类下的 Qt Widgets Application。在右侧支持的平台列表中，应该能看到 Android 选项已呈可用状态。
  3. 点击“选择(C)...”，在项目介绍页面中：
    • 名称：填写 HelloQtAndroid
    • 创建路径：选择你的工作空间目录（例如 D:\projects\blogs\qt）
  4. 在 Kit Selection (构建套件选择) 阶段：
    • 勾选 Android for armeabi (GCC 4.7, Qt 5.2.0) 套件（用于交叉编译成 Android 的 .so 和打包 APK）。
    • 也可以同时勾选 Desktop Qt 5.2.0 MinGW 32bit（用于在 PC 本地开发和快捷调试）。
  5. 在 类信息 阶段：
    • 基类 选择 QWidget。
    • 取消勾选 Generate form（不使用 .ui 界面文件，全部在 cpp 中用代码手动构建界面）。
  6. 项目管理阶段保持默认，点击“完成”创建工程。

二、 Qt Creator 开发界面介绍 #

创建完成后，我们进入 Qt Creator 的核心开发界面。主要区域及快捷按钮功能如下：

  • 左侧栏“编辑”标签：代码编辑模式。
  • 左侧栏“项目”标签：打开构建和运行相关的环境配置（稍后我们需要在此配置 Android 的打包属性）。
  • 左侧“构建版本”按钮（电脑或机器人图标）：快速切换 Debug/Release 编译版本或切换编译器套件。
  • “运行”按钮（绿色三角形）：启动编译、链接、打包、并拉起设备上的应用。
  • 底端“问题/编译输出/应用程序输出”窗口：展示 GCC 编译警告、链接错误以及 APK 执行时的 Android Logcat 输出。

三、 配置 Android 运行与打包选项 #

点击左侧栏的 项目 标签，切换到 Android for armeabi 套件，并将构建版本切换为 Release。此时左下角的运行按钮图标会变为小安卓机器人加上 “Release” 字样。

接着，点击“构建”旁边的 运行 标签进行详细配置。

1. 部署配置 (Deployment Settings) #

点击部署配置下的“详情”按钮，展开以下关键配置：

  • 对包签名 (Sign package)： 发布 Android 程序必须对其进行数字签名。勾选此项后，需要指定一个签名密钥文件（.keystore）。

    • 创建证书：如果没有密钥，点击 Create 按钮，填写密钥位置、别名、密码及证书组织信息进行新建。
    ❢重要

    请妥善保管生成的密钥文件及其密码。在后续升级已发布到应用商店的 APK 时，必须使用与之前版本完全相同的证书签名，否则设备会拒绝覆盖安装。

  • Qt 库部署策略 (Qt Library Deployment)： Qt 程序运行依赖大量的 Qt 基础 .so 动态库。Qt on Android 提供了以下几种部署方式：

    1. 使用 Ministro 服务 (Use Ministro service to install Qt)：
      • 原理：应用本身不打包 Qt 库，启动时通过呼起设备上的 Ministro 服务，Ministro 会自动联网下载或重用已安装的 Qt 依赖库。
      • 优缺点：APK 安装包体积非常小（仅几兆），但国内由于网络环境限制常常无法正常安装 Ministro 服务，容易导致程序首次启动黑屏。
    2. 在 APK 中捆绑 Qt 库 (Bundle Qt libraries in APK)：
      • 原理：直接将程序所依赖的所有 Qt .so 动态库一并打包压缩进你的单个 .apk 包中。
      • 优缺点：安装后直接可用，完全不受网络和 Ministro 服务的制约。缺点是 APK 安装包体积会大幅上升（通常 15MB 起步）。
    ✦提示

    在国内开发和测试环境下，强烈推荐使用“在 APK 中捆绑 Qt 库”策略，可以避免绝大多数黑屏和无法运行的问题。

  • 构建完成后打开包路径： 勾选 Open package location after build，编译生成 APK 后，系统会自动弹出资源管理器窗口显示打包好的 APK 文件夹。

2. 创建 AndroidManifest.xml #

AndroidManifest 是 Android APK 的全局配置文件。点击运行配置里的 Create AndroidManifest.xml 按钮。

在 Qt 提供的图形化编辑界面中（或点击 XML Source 手动修改 xml）：

  • Package name：修改包名（例如将默认的 org.qtproject.example 改为 com.foruok.helloqt）。
  • Version code：配置版本号。
  • API Level：设置最低支持的 Android SDK API 等级（Minimum API）与目标等级（Target API）。
  • Application Icon：指定高、中、低三种分辨率的图标。
  • Permissions：在下拉列表中添加你所需要的 Android 权限（如网络访问、读取SD卡等）。

四、 编写代码与编译运行 #

  1. 切换回代码编辑界面，双击打开 widget.cpp 文件。
  2. 引入 QLabel 头文件：
    cpp
    #include <QLabel>
  3. 在 Widget 构造函数中添加显示文本的代码：
    cpp
    Widget::Widget(QWidget *parent)
    : QWidget(parent)
{
    // 创建一个标签显示文本并以当前 Widget 为父窗口
    new QLabel("Hello Qt on Android !", this);
}
  4. 将 Android 手机开启 USB 调试模式 并通过数据线连接电脑。
  5. 点击左侧的绿色“运行”按钮。在弹出的目标设备选择框中，选中你的真机设备（例如 Motorola XT882，Android 2.3.6），点击“确定”。
  6. 稍等片刻，Qt Creator 编译打包完成后，真机上就会顺利启动程序并显示出 "Hello Qt on Android!"！
