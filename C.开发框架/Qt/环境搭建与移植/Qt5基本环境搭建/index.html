点击下一步； 此界面可以忽略不填，直接点击Skip； 继续点击下一步； 此处可以更改QT安装路径（建议使用默认路径），选择好之后点击下一步；

此处为选择安装组件，图示为安装QT部分组件，如若想要安装全部将其选择打钩即可。选择完毕点击 下一步； 此处同意接受协议，选择完毕后点击下一步； 此处为确认安装，点击安装按钮进行QT安装。 QT正在安装界面。

安装完成，点击下一步； 此时QT安装完成，点击完成退出。 3、此时QT的环境安装成功，但还不能编译运行程序。此时需要下载安装一个安装包即可； 下载安装命令：sudo apt-get install libgl1-mesa-dev，即 至此，QT的环境安装完毕。 二、Modbus环境的配置安装 1、将安装包文件libmodbus-3.0.6.tar.gz（见附件Modbus安装包）拷贝至Ubuntu用户目录下 2、将该安装包解压，解压命令为：tar xvf libmodbus-3.0.6.tar.gz，即

3、进入解压目录，命令为：cd libmodbus-3.0.6/，即 4、生成Makefile文件，命令：./configure，即 看到生成Makefile文件， 5、编译，命令为：make，即 6、安装，命令为：sudo make install，即 7、安装完成后在/usr/local/include/modbus目录下有4个modbus相关头文件，即 在/usr/local/lib目录下有生成的4个modbus相关库文件，即 将上图中libmodbus.so.5、libmodbus.so、libmodbus.so.5.0.5三个库文件拷贝到/lib目录下，命令 为：sudo cp libmodbus.so* /lib，即 8、此时，在Linux环境下Modbus配置完成，但是若要在QT中使用Modbus通信，则需要在QT工程文 件中添加以下代码：

INCLUDEPATH += /usr/local/include/modbus/ LIBS += -L/usr/local/lib -lmodbus

即 至此，Modbus通信的配置安装使用完成。 三、QtXlsx环境的配置安装 1、将安装包文件QtXlsxWriter-master（见附件QTxlsx源码文件）拷贝至Ubuntu用户目录下

6、接下来就可以使用Qt进行excel的操作了，只是需要注意， 使用的时候需要包含头文件 在你的 qmake .pro 需要添加: 添加完毕后重新构建qmake，否则会提示连接不到库。 至此Qt Xlsx安装配置完成。 四、Qwt环境的配置安装 1 、首先下载Qwt的安装包，命令： svn checkout svn://svn.code.sf.net/p/qwt/code/branches/qwt-6.1（注：没装svn的先下载安装svn，命 令为：sudo apt install subversion），即 2、cd进入到qwt-6.1目录进行Makefile的生成，命令为：/opt/Qt5.6.1/5.6/gcc_64/bin/qmake，即 3、生成Makefile后进行编译，命令为：make，即 注：若此步骤编译出错，例 project ERROR :Unknown module(s) in QT: svg 执行此命令：sudo apt-get install libqt5svg5* 即可！ 如果出现这样的错误：Project ERROR: Unknown module(s) in QT: designer 安装qttools5-dev：sudo apt-get install qttools5-dev*

4、安装，命令为：sudo make install，即 5、配置环境 首先，将~qwt-6.1/designer/plugins/designer/下的libwt_designer_plugin.so拷贝 到/opt/Qt5.6.1/Tools/QtCreator/lib/Qt/plugins/designer，命令为： sudo cp libqwt_designer_plugin.so /opt/Qt5.6.1/Tools/QtCreator/lib/Qt/plugins/designer/， 即 其次将qwt-6.1.4-svn/lib下的4个文件分别拷贝到/opt/Qt5.6.1/Tools/QtCreator/lib/qtcreator/ 和/opt/Qt5.6.1/5.6/gcc_64/lib下，命令为： sudo cp * /opt/Qt5.6.1/Tools/QtCreator/lib/qtcreator/ sudo cp * /opt/Qt5.6.1/5.6/gcc_64/lib，即 6、工程用到qwt，那么要在你的工程文件即.pro文件添加如下代码： INCLUDEPATH += /usr/local/qwt-6.1/include LIBS += -L"/usr/local/qwt-6.1/lib/" -lqwt 添加头文件和库的路径，即

五、MySQL数据库环境的配置安装 1、将安装包文件qtbase-opensource-src-5.6.0-rc.tar.gz和 mysql-server_5.7.14-1ubuntu16.04_amd64.deb-bundle.tar（见附件MySQL数据库安装包）拷贝 至Ubuntu用户目录下 2、将数据库安装包解压，命令为： tar xvf mysql-server_5.7.14-1ubuntu16.04_amd64.deb-bundle.tar 即

3、安装配置MySQL数据库，将解压后的11个deb包用sudo dpkg -i [包名]命令逐个安装，因为包中 存在依赖关系，按先后顺序安装，即 1)sudo dpkg -i mysql-common_5.7.14-1ubuntu16.04_amd64.deb 2)sudo dpkg -i libmysqlclient20_5.7.14-1ubuntu16.04_amd64.deb 3)sudo dpkg -i libmysqlclient-dev_5.7.14-1ubuntu16.04_amd64.deb 4)sudo dpkg -i libmysqld-dev_5.7.14-1ubuntu16.04_amd64.deb 5)此时需要安装一个依赖包，命令为：sudo apt-get install libaio1 6)sudo dpkg -i mysql-community-client_5.7.14-1ubuntu16.04_amd64.deb 7)sudo dpkg -i mysql-client_5.7.14-1ubuntu16.04_amd64.deb 8)sudo dpkg -i mysql-community-source_5.7.14-1ubuntu16.04_amd64.deb 9)安装第二个依赖包，命令为：sudo apt-get install libmecab2 10)sudo dpkg -i mysql-community-server_5.7.14-1ubuntu16.04_amd64.deb 此步骤执行后设置密码,在终端下就可以用mysql -uroot -p1来登录数据库（注：这个1是设置的登录 密码） 11)sudo dpkg -i mysql-server_5.7.14-1ubuntu16.04_amd64.deb 12)sudo dpkg -i mysql-community-test_5.7.14-1ubuntu16.04_amd64.deb 13)sudo dpkg -i mysql-testsuite_5.7.14-1ubuntu16.04_amd64.deb

6、检查qmake版本，命令为：qmake -v 7、执行qmake前需要安装3个依赖包，命令为： sudo apt-get install libssl-dev sudo apt-get install libcrypto++-dev sudo apt-get install libmysqlclient-dev 8、执行qmake生成Makefile，命令为：/opt/Qt5.6.1/5.6/gcc_64/bin/qmake "INCLUDEPATH+=/usr/include/mysql" "LIBS+=-L/usr/lib/mysql -lmysqlclient_r" mysql.pro 9、编译，命令为：sudo make，即 可能报错： 解决办法：首先去/usr/lib/x86_64-linux-gnu目录下查找库函数，ls -l libmysql*
