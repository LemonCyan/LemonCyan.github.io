Ubuntu 19.10 嵌入式 Qt 开发环境的搭建 (适用于 Tiny6410) #

前言 #

这篇文章主要是基于 Ubuntu 19.10 版本编写的。写此文的初衷是为了记录自己的实践过程（使用 Tiny6410 开发板进行实训）。本文将介绍如何从零搭建一个完整的嵌入式 Qt 开发环境，并对过程中遇到的问题给出对应的解决方案。

ℹ笔记

本教程在虚拟机环境下演示。虽然使用的是 Ubuntu 19.10，但在低版本（如 Ubuntu 16.04、18.04）上同样可以成功搭建。

1. 安装前的准备工作 #

开发环境要求 #

  • 宿主机系统：Ubuntu 19.10 (或 Ubuntu 16.04 / 18.04)
  • gcc/g++ 版本：4.8.5 (或更低版本)
  • 交叉编译器：arm-linux-gcc-4.5.1
  • 基础依赖包：tslib-1.4, qt-everywhere-opensource-src-4.8.5

降级 gcc/g++ #

在较高版本的 Ubuntu（如 19.10）中，默认的 gcc 版本过高可能导致编译老版本 Qt 库失败，建议降级到 4.8：

bash
sudo apt-get install gcc-4.8 g++-4.8
sudo update-alternatives --install /usr/bin/gcc gcc /usr/bin/gcc-4.8 100
sudo update-alternatives --install /usr/bin/g++ g++ /usr/bin/g++-4.8 100

2. 安装交叉编译器 #

⚠警告

全程推荐使用 sudo 权限执行具体命令，但不要直接切换到 root 账户环境（如 sudo su），以免由于用户权限混乱导致环境变量失效。

安装步骤 #

  1. 获取安装包
    将交叉编译器压缩包 arm-linux-gcc-4.5.1-v6-vfp-20101103.tgz 复制到 Ubuntu 系统中（例如：/home/[用户名]/Share）。

  2. 解压安装包
    进入压缩包所在文件夹，将其拷贝到 /tmp 目录并解压到根目录 /：

    bash
    sudo cp arm-linux-gcc-4.5.1-v6-vfp-20101103.tgz /tmp
cd /tmp
sudo tar xvzf arm-linux-gcc-4.5.1-v6-vfp-20101103.tgz -C /
    ❢重要

    注意 tar 命令中的 -C /，表示解压到根目录。最后的 / 以及 -C 前后的空格不能遗漏。

  3. 配置环境变量
    打开当前用户的 .bashrc 配置文件：

    bash
    cd ~
gedit .bashrc # 也可以使用 vim

    在文件末尾添加以下路径：

    bash
    export PATH=/opt/FriendlyARM/toolschain/4.5.1/bin:$PATH

    保存并退出，在终端中使配置立即生效（无需 sudo）：

    bash
    source .bashrc

  4. 验证安装
    输入以下命令检查编译器版本：

    bash
    arm-linux-gcc -v

    若成功安装，终端将输出编译器的版本信息。

常见错误：提示 arm-linux-gcc: 找不到该文件 #

这通常是因为 64 位系统缺少 32 位运行库支持。可以尝试通过以下几种方法解决：

  • 方案一：安装 32 位标准库支持
    bash
    sudo apt-get install g++-multilib
  • 方案二：安装 lsb-core 运行库
    bash
    sudo apt-get install lsb-core
  • 方案三：针对较老版本 Ubuntu，尝试安装 ia32-libs
    bash
    sudo apt-get install ia32-libs

3. 安装 tslib (触摸屏库) #

tslib 是嵌入式 Linux 中常用的触摸屏校准和数据滤波库。

编译步骤 #

  1. 解压源码

    bash
    tar xzf tslib-1.4.tar.gz
cd tslib/

  2. 生成配置文件

    bash
    sudo ./autogen.sh
    ⚠警告

    如果提示 autoreconf: not found 错误，请先执行安装工具集：

    bash
    sudo apt-get install autoconf automake libtool

  3. 配置编译参数 (Configure) 创建临时安装目录并设置参数：

    bash
    mkdir tmp
echo "ac_cv_func_malloc_0_nonnull=yes" > arm-linux.cache
sudo ./configure --host=arm-linux --cache-file=arm-linux.cache --prefix=$(pwd)/tmp

  4. 编译并安装

    bash
    sudo make
sudo make install

常见编译错误 #

错误现象：

text
In function ‘open’, inlined from ‘main’ at ts_calibrate.c:229:11:
/usr/include/bits/fcntl2.h:51:24: error: call to ‘__open_missing_mode’ declared with attribute error: open with O_CREAT in second argument needs 3 arguments

原因分析：这是由于较新版本的 gcc 对 open 函数的安全检查更严格，要求在使用 O_CREAT 时必须指定第三个权限参数。
解决方法：修改 tests/ts_calibrate.c 文件中的相关代码，补充权限参数 0777：

c
// 修改前
cal_fd = open(calfile, O_CREAT | O_RDWR);
// 修改后
cal_fd = open(calfile, O_CREAT | O_RDWR, 0777);
  1. 拷贝库文件到系统目录
    bash
    sudo mkdir /usr/local/tslib
cd tmp
sudo cp -rfd * /usr/local/tslib/
    ℹ笔记

    -d 参数用于保持符号链接。

4. 安装 Qt Creator #

  1. 给官方安装包赋予可执行权限：
    bash
    sudo chmod 777 qt-creator-linux-x86_64-opensource-2.5.2.bin
  2. 启动图形化安装向导：
    bash
    sudo ./qt-creator-linux-x86_64-opensource-2.5.2.bin
    按照提示完成安装。

5. 编译 Qt 库源码 #

我们需要分别编译两个版本的 Qt 库：PC 版（用于在电脑上通过 Qt Creator 模拟运行和设计界面）和 ARM 版（用于将程序交叉编译后移植到 Tiny6410 开发板上运行）。

5.1 准备工作 #

在 /usr/local/ 目录下创建编译文件夹：

bash
sudo mkdir /usr/local/qt-pc /usr/local/qt-arm

解压 qt-everywhere-opensource-src-4.8.5.tar.gz 源码包，并将解压后的内容分别拷贝至上述两个文件夹中。

5.2 编译 PC 版 #

  1. 进入 /usr/local/qt-pc 目录：
    bash
    cd /usr/local/qt-pc
sudo ./configure
  2. 配置成功后，开始编译并安装。建议使用多核加速：
    bash
    sudo make -j4
sudo make install -j4
    默认会被安装到 /usr/local/Trolltech/Qt-4.8.5/ 下。
⚠警告

如果在配置阶段出现 Basic XLib functionality test failed!，是由于宿主机缺少 X11 开发库。可执行以下命令安装：

bash
sudo apt-get install libx11-dev libxext-dev libxtst-dev

5.3 编译 ARM 版 #

  1. 进入 /usr/local/qt-arm/ 目录：

    bash
    cd /usr/local/qt-arm/

  2. 配置交叉编译规格文件 qmake.conf
    修改 /usr/local/qt-arm/mkspecs/qws/linux-arm-g++/qmake.conf，将默认的编译器路径替换为对应的 arm-linux-gcc 绝对路径，并加入 -lts 支持：

    ini
    # modifications to g++.conf
QMAKE_CC         = /opt/FriendlyARM/toolschain/4.5.1/bin/arm-linux-gcc -lts
QMAKE_CXX        = /opt/FriendlyARM/toolschain/4.5.1/bin/arm-linux-g++ -lts
QMAKE_LINK       = /opt/FriendlyARM/toolschain/4.5.1/bin/arm-linux-g++ -lts
QMAKE_LINK_SHLIB = /opt/FriendlyARM/toolschain/4.5.1/bin/arm-linux-g++ -lts

# modifications to linux.conf
QMAKE_AR         = /opt/FriendlyARM/toolschain/4.5.1/bin/arm-linux-ar cqs
QMAKE_OBJCOPY    = /opt/FriendlyARM/toolschain/4.5.1/bin/arm-linux-objcopy
QMAKE_STRIP      = /opt/FriendlyARM/toolschain/4.5.1/bin/arm-linux-strip

  3. 配置编译参数 在 /usr/local/qt-arm/ 目录下执行：

    bash
    sudo ./configure -prefix /usr/local/Trolltech/QtEmbedded-4.8.5-arm -opensource -confirm-license -release -shared -embedded arm -xplatform qws/linux-arm-g++ -depths 16,18,24 -fast -optimized-qmake -pch -qt-sql-sqlite -qt-libjpeg -qt-zlib -qt-libpng -qt-freetype -little-endian -host-little-endian -no-qt3support -no-libtiff -no-libmng -no-opengl -no-mmx -no-sse -no-sse2 -no-3dnow -no-openssl -no-webkit -no-qvfb -no-phonon -no-nis -no-cups -no-glib -no-xcursor -no-xfixes -no-xrandr -no-xrender -no-separate-debug-info -nomake examples -nomake tools -nomake docs -qt-mouse-tslib -I/usr/local/tslib/include -L/usr/local/tslib/lib

  4. 编译并安装

    bash
    sudo make -j4
sudo make install -j4

常见配置错误：The tslib functionality test failed! #

这通常是因为配置程序找不到编译好的 tslib 头文件或库文件，或者交叉编译器不匹配。

  • 排查路径 1：确认环境变量中的 arm-linux-gcc 是否正常，可在终端输入该命令按两次 Tab 键测试。
  • 排查路径 2：确保编译 tslib 和 编译 QtE 使用的交叉编译器是同一个版本，切忌中途更换。
  • 排查路径 3：验证 tslib 编译出的库格式是否正确。进入 /usr/local/tslib/bin，使用 file 命令查看程序格式：
    bash
    file ts_test
    如果输出显示是 ARM 架构即可。如果错误地显示为 X86 架构，说明 tslib 并没有被正确地交叉编译，需要彻底删除 tslib 源码目录，重新解压后严格按照第 3 节中参数重新配置并编译。

6. 配置 Qt Creator #

打开安装好的 Qt Creator，进行交叉编译套件的配置：

  1. 设置 Qt Versions

    • 进入 Tools -> Options -> Build & Run -> Qt Versions 菜单。
    • 点击 Add，分别添加 PC 版 and ARM 版的 qmake 路径：
      • PC 版：/usr/local/Trolltech/Qt-4.8.5/bin/qmake
      • ARM 版：/usr/local/Trolltech/QtEmbedded-4.8.5-arm/bin/qmake

  2. 添加 GCC 编译器

    • 在 Compilers 标签页，点击 Add -> GCC。
    • 配置对应的交叉编译器路径：/opt/FriendlyARM/toolschain/4.5.1/bin/arm-linux-g++。

  3. 配置 Kits（构建套件）

    • 分别创建 PC 和 Tiny6410-ARM 两个套件。
    • 在 Tiny6410-ARM 套件中，将 Compiler 选择为刚才添加的 arm-linux-g++ 交叉编译器，Debugger、Qt version 选择为对应的 ARM 版，即可完成套件绑定。

至此，适用于 Tiny6410 的 Ubuntu 嵌入式 Qt 开发环境已全部搭建完毕！
