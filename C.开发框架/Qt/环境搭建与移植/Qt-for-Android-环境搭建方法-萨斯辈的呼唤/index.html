Qt for Android 环境搭建与配置教程 #

在进行移动设备跨平台开发时，将 Qt 项目编译成 Android 应用（.apk 文件）是极其常见的业务需求。本文详细讲解在 Windows 下搭建 Qt 5.1.1 for Android 编译与调试环境的详细步骤，涵盖必需安装包的准备、系统环境变量的设定、以及 Android 虚拟设备（AVD）配置的全流程。

第一步：下载与准备安装包 #

开始前，请根据您电脑的操作系统位数（32位 / 64位）下载对应的程序安装包，并解压到一个不包含中文与空格的纯英文路径中。

  1. Qt 离线安装包（包含 Android 构建套件）：
    • 示例：qt-windows-opensource-5.1.1-android-x86-win32-offline.exe
    • 下载通道：Qt Downloads
  2. Android ADT Bundle（包含 Eclipse、Android SDK Manager、ADT）：
    • 64位包名：adt-bundle-windows-x86_64-20131030.zip
    • 32位包名：adt-bundle-windows-x86-20131030.zip
  3. Android NDK：
    • android-ndk-r9b-windows-x86_64.zip
    • android-ndk-r9b-windows-x86_64-legacy-toolchains.zip
    • 下载地址：Android NDK Tools
  4. Apache Ant 构建工具（用于生成 APK）：
    • apache-ant-1.9.2-bin.zip
    • 下载地址：Ant Downloads
  5. Java SDK (JDK)：
    • jdk-7-windows-i586.exe (或更高版本，推荐 1.7)

第二步：安装环境 #

  1. 安装 JDK：按照引导默认安装即可。
  2. 解压 SDK & NDK：
    • 🔑 关键要点：必须将两个 NDK 压缩文件（android-ndk-r9b 以及对应的 legacy-toolchains）解压合并到同一个文件夹中。
    • 所有解压的工具链（ADT、NDK、Ant）均应放置在相同的物理大目录下，例如 D:\qtforandroid\。

第三步：配置系统环境变量 #

右键“计算机” -> “属性” -> “高级系统设置” -> “环境变量”，在“系统变量”中双击找到 Path 变量，在末尾添加各编译组件对应的 bin 路径。

以下为示例路径配置（实际使用时需按各自具体安装位置修正）：

text
C:\Program Files (x86)\Java\jdk1.7.0\bin;
C:\Qt\Qt5.1.1\5.1.1\android_armv7\bin;
C:\Qt\Qt5.1.1\5.1.1\android_x86\bin;
C:\Qt\Qt5.1.1\5.1.1\mingw48_32\bin;
C:\Qt\Qt5.1.1\Tools\mingw48_32\bin;
C:\Qt\Qt5.1.1\Tools\QtCreator\bin;
D:\qtforandroid\adt-bundle-windows-x86_64-20131030\sdk\tools
❢重要

每一个变量路径路径之间必须用分号（;）分隔。配置完毕后点击保存生效。

第四步：Qt Creator 设置与安卓虚拟机（AVD）创建 #

  1. 打开 Qt Creator，在上方菜单栏选择 “工具” -> “选项”。
  2. 在左侧面板选择 “Android”，依次配置各工具链的位置：
    • JDK 路径：指向您的 Java JDK bin 上层目录。
    • Android SDK 路径：指向解压的 adt-bundle 内部的 sdk 目录。
    • Android NDK 路径：指向解压合并后的 NDK 根目录。
    • Ant 路径：指向 apache-ant-1.9.2 的根文件夹。
  3. 点击选项中的 “启动 Android AVD 管理器”，在弹出的窗口中点击 “New” 新建一台虚拟机：
    • AVD Name：输入 android
    • Device：选择标准分辨率的模拟器。
    • Target：对应您需要的 Android API 版本。
    • 设置好后点击 OK，回到列表点击 “Start” -> “Launch”，启动并耐心等待 Android 虚拟设备完全开启。

第五步：新建项目并测试编译 #

  1. 重启 Qt Creator，新建工程，选择 “Qt GUI 应用”。
  2. 🔑 关键步骤：在构建套件 (Kits) 选择页面，务必勾选 Android for arm (GCC 4.8, Qt 5.1.1)，切勿误选 x86 版本。
  3. 在 MainWindow 界面中，双击打开 mainwindow.ui，放置一个 PushButton。考虑到手机纵向分辨率，建议在属性栏中将 Geometry 设为 480 x 800。
  4. 点击 Qt Creator 左侧边栏的 “项目”，切至 Android 构件状态。如果左下角运行图标变为绿色机器人，则说明配置全部成功。

第六步：运行与生成 APK #

  1. 在电脑的运行中输入 cmd 打开命令行提示符。
  2. 输入启动虚拟机的指令：
    bash
    emulator -avd android
    （其中 android 为第 4 步创建模拟器时赋予的名称）
  3. 待虚拟机加载至桌面状态后，返回 Qt Creator，点击左下角的绿色三角形启动编译与部署。
  4. 编译过程会花费几分钟，稍后即可在安卓模拟器中看到您编写的 Qt 按钮程序。
  5. APK 生成路径： 项目最终打包生成的 .apk 安装包文件，默认存放在项目工程目录的 <ProjectName>/android/bin/ 目录下。
  6. 关闭虚拟机：在命令行窗口直接输入 Ctrl + C 即可关断模拟器。
