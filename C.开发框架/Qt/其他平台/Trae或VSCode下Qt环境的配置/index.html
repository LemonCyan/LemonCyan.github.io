Trae或VSCode下Qt环境的配置

在 AI 辅助编程十分火热的今天，如何利用 AI 去辅助我们完成 Qt 程序的编写与设计，市面上的 AI 编程类型 IDE 层出不穷，选择哪种类型的 IDE 对于辅助我们实现敏捷开发有重要意义

目前使用到的几款 IDE 来说，VSCode 可定制化程度最高，但配置较为复杂，AI 的权限没有那么高，Trae 使用最为方便，AI 权限高，使用时环境都可以让 AI 来配置，Cursor/Antigravity 等软件更加集中在 AI 对话而非代码本身，于我的使用习惯不符

如果你不想进行复杂配置，直接用 trae 命令行我使用 opencode

安装必要工具 #

在开始配置之前，请确保安装了以下工具：

  1. Qt：Qt 是构建 GUI 应用的核心框架。下载并安装最新版本的 Qt，具体下载地址可参考 Qt 官方网站。
  2. CMake：从 Qt 6 开始，CMake 成为默认的构建工具。下载 CMake 的具体版本，可访问 CMake 官方网站。

完成安装后，确保这些工具已正确添加到系统环境变量中，以便在后续步骤中正确识别。

配置 Trae 开发环境 #

配置系统环境变量 #

我们需要把 Qt 库路径、MinGW 编译器路径、CMake 路径 添加到系统环境变量中。

① 先找到你需要的路径 #

打开文件资源管理器，进入 C:\Qt 目录，找到以下 3 个路径：

cpp
路径1（MinGW编译器）: C:\Qt\Tools\mingw1310_64\bin
路径2（CMake工具）: C:\Qt\Tools\CMake_64\bin
路径3（Qt库）: C:\Qt\6.8.0\mingw_64\bin

⚠️ 注意：你的版本号可能不同！

  • mingw1310_64 可能是 mingw1120_64 等
  • 6.8.0 可能是 6.5.0、6.7.0 等
  • 请按你实际看到的文件夹名称为准

② 打开环境变量设置 #

cpp
1. 按 Win 键，搜索「环境变量」
2. 点击「编辑系统环境变量」
3. 点击右下角「环境变量(N)...」按钮
4. 在下方「系统变量」区域，找到 Path，双击它

③ 添加三条路径 #

在弹出的编辑窗口中：

cpp
1. 点击「新建」
2. 粘贴第一条路径：C:\Qt\Tools\mingw1310_64\bin
3. 再点「新建」
4. 粘贴第二条路径：C:\Qt\Tools\CMake_64\bin
5. 再点「新建」
6. 粘贴第三条路径：C:\Qt\6.8.0\mingw_64\bin
7. 点击「确定」→「确定」→「确定」（三次确定全部关闭）

④ 验证是否配置成功 #

关闭所有已打开的终端和 VSCode，然后：

cpp
1. 按 Win+R，输入 cmd，回车
2. 依次输入以下命令：

bash
gcc --version

应该看到类似输出：

cpp
gcc (x86_64-posix-seh-rev1, Built by MinGW-Builds) 13.1.0

bash
cmake --version

应该看到类似输出：

cpp
cmake version 3.27.7

bash
qmake --version

应该看到类似输出：

cpp
QMake version 3.1
Using Qt version 6.8.0 in C:/Qt/6.8.0/mingw_64/lib

步骤 1：安装扩展插件 #

  1. 打开 Cursor 或 VS Code。
  2. 进入插件市场，安装以下必要插件：
    • C/C++ 插件：为 C/C++ 开发提供语法支持和代码补全功能。
    • Qt Configure：用于配置 Qt 开发环境。
    • Qt Tools：提供 Qt 相关工具的支持。
    • CMake：用于 CMake 构建系统的支持。
    • CMake Tools：辅助 CMake 的构建过程。

步骤 2：设置 Qt 安装路径 #

  1. 打开命令面板（快捷键 Ctrl + Shift + P）。
  2. 输入 >Set Qt Dir，然后选择 Qt 安装的主目录，例如 D:\Qt\5.14.2。

步骤 3：创建新 Qt 项目 #

  1. 再次打开命令面板，输入 >New Qt Project。
  2. 根据提示输入项目名称，选择适用的项目套件。
  3. 选择使用 CMake 或 qmake 作为构建工具，并根据项目需求选择是否包含 UI 组件。

配置 CMake #

在使用 CMake 工具时，可能会遇到编译信息缺失的问题。按照以下步骤进行配置：

  1. 打开命令面板，输入 >Select CMake Kit，选择合适的 CMake 套件。
  2. 在设置中找到 CMake 路径，填写 CMake 的安装路径，例如 D:\Qt\cmake-3.31.6\bin\cmake.exe。
  3. 应用配置后，重新构建项目以确保配置生效。

下载 CMake 的具体版本可参考 CMake 官方下载页面。

配置 Qt Configure #

进入 Qt configure 插件的设置界面，分别输入 MingwPath 为 D:\Qt\Qt5.14.2\Tools\mingw730_64，QtDir 为 d:\Qt\Qt5.14.2，Qt Kit Dir 为 D:\Qt\Qt5.14.2\Tools\mingw730_64，并将设置应用到所有

第四步：创建第一个 Qt 项目 #

① 创建项目文件夹 #

cpp
1. 在你喜欢的位置新建一个文件夹，比如：D:\QtProjects\HelloQt
2. 打开 VSCode
3. 点击菜单：文件 → 打开文件夹 → 选择刚才创建的 HelloQt 文件夹

② 创建 CMakeLists.txt 文件 #

在 VSCode 左侧文件资源管理器中，点击 新建文件 图标，创建文件： 文件名：CMakeLists.txt 粘贴以下内容：

cmake
# 指定 cmake 最低版本
cmake_minimum_required(VERSION 3.1.0)

# 设置项目名称
set(PROJECT_NAME test)
project(${PROJECT_NAME})

# 开启自动处理 ui 文件
set(CMAKE_AUTOUIC ON)
set(CMAKE_AUTOMOC ON)
set(CMAKE_AUTORCC ON)

# 设置自动包含当前路径
set(CMAKE_INCLUDE_CURRENT_DIR ON)

# 设置 c++ 标准
set(CMAKE_CXX_STANDARD 11)
set(CMAKE_CXX_STANDARD_REQUIRED ON)

# 设置 qt 编译器路径，这里需要根据自己的路径修改
set(QT_PATH "D:/Qt/6.10.1/mingw_64")
# 假设你的版本是 6.10.1，如果不是请修改
set(CMAKE_PREFIX_PATH "D:/Qt/6.10.1/mingw_64")

# 设置输出路径
set(CMAKE_RUNTIME_OUTPUT_DIRECTORY ${CMAKE_SOURCE_DIR}/bin)

# 包查找
find_package(Qt6 REQUIRED COMPONENTS Widgets)

# 添加源文件
file(GLOB SOURCE_FILE ${PROJECT_SOURCE_DIR}/src/*.cpp)
file(GLOB HEADER_FILE ${PROJECT_SOURCE_DIR}/src/*.h)
file(GLOB UI_FILE ${PROJECT_SOURCE_DIR}/src/*.ui)
file(GLOB RESOURCE_FILE ${PROJECT_SOURCE_DIR}/src/*.qrc)

# 链接可执行文件
find_package(Qt5 COMPONENTS Widgets REQUIRED)
# 添加可执行文件
add_executable(HelloQt
    main.cpp
)
add_executable(
    ${PROJECT_NAME}
    ${SOURCE_FILE}
    ${HEADER_FILE}
    ${RESOURCE_FILE}
    ${UI_FILE}
)
target_link_libraries(${PROJECT_NAME} Qt6::Widgets)

📌 5 个文件都创建好了吗？确认后我们进入第五步：配置 CMake 并编译运行项目。

配置调试环境 #

为了确保项目的调试功能正常工作，需要在 .vscode/launch.json 文件中添加以下配置：

json
{
    "version": "0.2.0",
	    "configurations": [
        {
            "name": "QtBuild",
            "type": "cppdbg",
            "request": "launch",
            "program": "${command:cmake.launchTargetPath}",
            "args": [],
            "stopAtEntry": false,
            "cwd": "${workspaceRoot}",
            "environment": [
                {
                    "name": "PATH",
                    "value": "d:/Qt/Qt5.14.2/5.14.2/mingw73_64/bin"
                }
            ],
            "externalConsole": false,
            "miDebuggerPath": "D:/Qt/Qt5.14.2/Tools/mingw730_64/bin/gdb.exe"
        }
    ]
}

这个配置':

  • 指定了调试程序的路径。
  • 设置了环境变量 PATH，确保调试器能够找到必要的工具。
  • 指定了 GDB 调试器的路径。

第五步：配置 CMake 并编译运行项目 #

① 配置 CMake Kit（选择编译器） #

cpp
1. 按 Ctrl+Shift+P 打开命令面板
2. 输入：CMake: Select a Kit
3. 回车

你会看到一个列表，选择带有 MinGW 字样的那一项，类似：

cpp
┌──────────────────────────────────────────┐
│ GCC 13.1.0 x86_64-w64-mingw32            │ ← 选这个
│ Visual Studio Community 2022...          │
│ [Scan for kits]                          │
└──────────────────────────────────────────┘

⚠️ 如果列表里没有 MinGW 选项：

  1. 按 Ctrl+Shift+P
  2. 输入：CMake: Scan for Kits
  3. 回车，等待扫描完成
  4. 再重新执行 CMake: Select a Kit

② 配置 CMake（Configure） #

cpp
1. 按 Ctrl+Shift+P 打开命令面板
2. 输入：CMake: Configure
3. 回车

观察 VSCode 底部的 输出面板，应该看到类似：

cpp
[cmake] -- The CXX compiler identification is GNU 13.1.0
[cmake] -- Found Qt6: C:/Qt/6.8.0/mingw_64/lib/cmake/Qt6
[cmake] -- Configuring done
[cmake] -- Generating done
[cmake] -- Build files have been written to: D:/QtProjects/HelloQt/build

⚠️ 如果报错找不到 Qt6：

需要手动告诉 CMake 去哪里找 Qt。在 VSCode 中：

  1. 按 Ctrl+Shift+P
  2. 输入：settings json
  3. 选择「首选项：打开工作区设置(JSON)」

粘贴以下内容（注意修改为你的实际路径）：

json
{
  "cmake.configureArgs": [
    "-DCMAKE_PREFIX_PATH=C:/Qt/6.8.0/mingw_64"
  ]
}

保存后，再重新执行 CMake: Configure

③ 编译项目（Build） #

cpp
1. 按 Ctrl+Shift+P 打开命令面板
2. 输入：CMake: Build
3. 回车

或者直接按快捷键：F7 底部输出面板应该显示：

cpp
[build] [5/5] Linking CXX executable HelloQt.exe
[build] Build finished with exit code 0

看到 exit code 0 就表示编译成功！

④ 运行项目 #

cpp
1. 按 Ctrl+Shift+P 打开命令面板
2. 输入：CMake: Run Without Debugging
3. 回车

或者看 VSCode 底部状态栏，点击 ▶ 按钮：

cpp
┌─────────────────────────────────────────────────────┐
│ ⚙Build  │ ▶ HelloQt │ 🔧Debug  │ GCC 13.1.0        │
│          │   ↑点这里  │          │                   │
└─────────────────────────────────────────────────────┘

⑤ 调试项目（额外说明） #

如果你想 打断点调试：

cpp
1. 在代码行号左侧点击，出现红色圆点（断点）
2. 按 Ctrl+Shift+P
3. 输入：CMake: Debug
4. 回车

程序会在断点处暂停，你可以查看变量值、单步执行等。

七、编译 #

点击终端 -> 新建终端。

先进入到 build 目录，然后输入 CMake 编译命令：

bash
# 进入 build
cd build

# 执行 cmake
cmake ..

# 编译
cmake --build .

# 运行
../bin/test.exe

其他 #

  1. 无法找到编译信息：请确保 CMake 路径配置正确，并且项目已经成功生成。
  2. launch.json 配置错误：检查 program 和 miDebuggerPath 是否正确指向 Qt 安装目录下的相应文件。
