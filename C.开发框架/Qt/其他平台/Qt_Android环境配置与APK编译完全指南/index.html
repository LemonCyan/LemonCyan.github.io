Qt_Android环境配置与APK编译完全指南

环境要求 #

Qt 6 Android 开发需要以下组件，版本之间存在严格依赖：

组件 Qt 6.5+ 版本要求 说明
JDK 17+ 推荐 Adoptium 或 OpenJDK 发行版，64 位
Android SDK API 28-36 需包含 Platform Tools 和 Build Tools
Android NDK 匹配 Qt 版本的 NDK Qt 6.10 使用 NDK r27c (27.2.12479018)
Gradle 8.x Qt 6.10 集成 Gradle 8.14.3 + AGP 8.10.1
❢重要

NDK 版本必须与 Qt 官方构建时使用的版本匹配，否则会出现符号链接错误。错误的 NDK 版本是最常见的编译失败原因之一。

第一部分：开发环境搭建 #

1.1 安装 JDK #

Qt 6.x 要求 JDK 17 或更高版本。推荐从以下来源获取：

  • Adoptium（推荐）
  • OpenJDK
  • Oracle JDK

Windows 安装验证：

powershell
# 检查 Java 版本
java -version

# 设置 JAVA_HOME 环境变量
$env:JAVA_HOME = "C:\Program Files\Eclipse Adoptium\jdk-17.0.x"

Linux 安装：

bash
# Ubuntu/Debian
sudo apt install openjdk-17-jdk

# 验证安装
java -version

# 设置 JAVA_HOME
export JAVA_HOME=/usr/lib/jvm/java-17-openjdk-amd64

1.2 安装 Android SDK 和 NDK #

有两种安装方式：通过 Qt Creator 自动安装（推荐）或手动安装。

方式一：Qt Creator 自动配置（推荐） #

  1. 打开 Qt Creator → Edit → Preferences → Devices → Android
  2. 点击 Set Up SDK 按钮
  3. Qt Creator 将自动下载并配置：
    • Android Command-line SDK Tools
    • Platform Tools
    • Build Tools
    • 匹配当前 Qt 版本的 NDK

方式二：手动安装 #

下载地址：

  • SDK Tools: https://developer.android.com/studio#command-line-tools-only
  • NDK: https://developer.android.com/ndk/downloads

Linux 自动化安装脚本：

bash
#!/bin/bash

# 配置变量 - 根据 Qt 版本调整
ndkVersion="r27c"
sdkBuildToolsVersion="34.0.0"
sdkApiLevel="android-34"
repository="https://dl.google.com/android/repository"

# 下载 SDK Command-line Tools
wget -q $repository/commandlinetools-linux-11076708_latest.zip
unzip -qq commandlinetools-linux-11076708_latest.zip -d android-sdk
mkdir -p android-sdk/cmdline-tools/latest
mv android-sdk/cmdline-tools/* android-sdk/cmdline-tools/latest/ 2>/dev/null || true

# 下载 NDK
wget -q $repository/android-ndk-$ndkVersion-linux.zip
unzip -qq android-ndk-$ndkVersion-linux.zip

# 设置环境变量
export ANDROID_SDK_ROOT=$(pwd)/android-sdk
export ANDROID_NDK_ROOT=$(pwd)/android-ndk-$ndkVersion
export PATH=$PATH:$ANDROID_SDK_ROOT/cmdline-tools/latest/bin

# 接受许可证
yes | sdkmanager --licenses

# 安装必要组件
sdkmanager "platforms;$sdkApiLevel" \
           "platform-tools" \
           "build-tools;$sdkBuildToolsVersion"

echo "SDK 安装完成"
echo "ANDROID_SDK_ROOT=$ANDROID_SDK_ROOT"
echo "ANDROID_NDK_ROOT=$ANDROID_NDK_ROOT"

Windows PowerShell 安装脚本：

powershell
$ndkVersion = "r27c"
$sdkBuildToolsVersion = "34.0.0"
$sdkApiLevel = "android-34"
$repository = "https://dl.google.com/android/repository"

# 下载 SDK Tools
Invoke-WebRequest "$repository/commandlinetools-win-11076708_latest.zip" -OutFile "sdk-tools.zip"
Expand-Archive -Path "sdk-tools.zip" -DestinationPath "android-sdk" -Force

# 下载 NDK
Invoke-WebRequest "$repository/android-ndk-$ndkVersion-windows.zip" -OutFile "ndk.zip"
Expand-Archive -Path "ndk.zip" -DestinationPath "." -Force

# 设置环境变量
$env:ANDROID_SDK_ROOT = "$PWD\android-sdk"
$env:ANDROID_NDK_ROOT = "$PWD\android-ndk-$ndkVersion"

# 安装 SDK 组件
& "$env:ANDROID_SDK_ROOT\cmdline-tools\bin\sdkmanager.bat" --sdk_root="$env:ANDROID_SDK_ROOT" `
    "platforms;$sdkApiLevel" "platform-tools" "build-tools;$sdkBuildToolsVersion"

1.3 配置 Qt Creator #

完成 SDK/NDK 安装后，在 Qt Creator 中配置路径：

  1. Tools → Options → Devices → Android

  2. 设置以下路径：

    • JDK 位置：C:\Program Files\Eclipse Adoptium\jdk-17.0.x 或 /usr/lib/jvm/java-17-openjdk-amd64
    • Android SDK 位置：SDK 安装目录
    • Android NDK 位置：NDK 版本目录（需指向具体版本，如 ndk/27.2.12479018）

  3. Tools → Options → Kits

    • 添加或选择 Android Qt 版本
    • 配置对应的 Kit，选择正确的编译器和 Qt 版本

第二部分：APK 编译流程 #

2.1 编译架构 #

Qt Android 应用的编译流程涉及多个工具协作：

flowchart LR
    A[CMake/qmake] --> B[编译 C++/QML]
    B --> C[生成 .so 共享库]
    C --> D[androiddeployqt]
    D --> E[Gradle 构建]
    E --> F[APK/AAB]

核心工具职责：

工具 作用
CMake/qmake 构建系统，编译 C++ 代码为共享库
androiddeployqt 收集 Qt 依赖、生成 Android 项目结构
Gradle 打包资源、签名、生成最终 APK/AAB

2.2 CMake 项目配置（Qt 6 推荐） #

Qt 6 推荐使用 CMake 作为构建系统。基础 CMakeLists.txt 配置：

cmake
cmake_minimum_required(VERSION 3.16)
project(MyApp VERSION 1.0 LANGUAGES CXX)

find_package(Qt6 REQUIRED COMPONENTS Core Gui Quick)

qt_standard_project_setup()

qt_add_executable(MyApp
    main.cpp
)

target_link_libraries(MyApp PRIVATE
    Qt6::Core
    Qt6::Gui
    Qt6::Quick
)

# Android 特定配置
if(ANDROID)
    set_target_properties(MyApp PROPERTIES
        QT_ANDROID_PACKAGE_SOURCE_DIR "${CMAKE_CURRENT_SOURCE_DIR}/android"
    )
endif()

install(TARGETS MyApp
    BUNDLE DESTINATION .
    LIBRARY DESTINATION ${CMAKE_INSTALL_LIBDIR}
)

2.3 qmake 项目配置 #

对于 Qt 5 项目或仍使用 qmake 的场景：

QT += quick core gui

CONFIG += c++17

SOURCES += main.cpp

# Android 资源目录
android {
    ANDROID_PACKAGE_SOURCE_DIR = $$PWD/android

    # 额外库（如果需要）
    ANDROID_EXTRA_LIBS += \
        $$PWD/libs/$$ANDROID_TARGET_ARCH/libcustom.so
}

2.4 命令行编译 #

使用 CMake 编译 APK：

bash
# 配置项目（以 arm64-v8a 架构为例）
cmake -S . -B build-android \
    -DCMAKE_TOOLCHAIN_FILE=$ANDROID_NDK_ROOT/build/cmake/android.toolchain.cmake \
    -DCMAKE_PREFIX_PATH=$QT_ANDROID_PATH \
    -DANDROID_ABI=arm64-v8a \
    -DANDROID_PLATFORM=android-28 \
    -DCMAKE_BUILD_TYPE=Release

# 构建
cmake --build build-android

# 生成 APK
cmake --build build-android --target apk

手动调用 androiddeployqt：

bash
androiddeployqt \
    --input build-android/android-MyApp-deployment-settings.json \
    --output build-android/android-build \
    --android-platform android-34 \
    --gradle

2.5 多架构编译 #

Qt 6 CMake 支持一次构建多个 ABI：

bash
cmake -S . -B build-android \
    -DQT_ANDROID_BUILD_ALL_ABIS=ON \
    -DCMAKE_PREFIX_PATH=$QT_ANDROID_PATH

支持的架构：

  • arm64-v8a（64 位 ARM，现代设备）
  • armeabi-v7a（32 位 ARM）
  • x86_64（64 位 x86，模拟器）
  • x86（32 位 x86，旧模拟器）

第三部分：OpenSSL 集成 #

由于法律限制，Qt 安装包不包含 OpenSSL 库。网络功能（HTTPS、SSL 套接字）需要手动集成。

3.1 使用预编译库（推荐） #

KDAB 维护了 android_openssl 项目，提供预编译的 OpenSSL 库。

CMake 集成：

cmake
include(FetchContent)

FetchContent_Declare(
    android_openssl
    GIT_REPOSITORY https://github.com/KDAB/android_openssl.git
    GIT_TAG master
)
FetchContent_MakeAvailable(android_openssl)

# 链接到目标
if(ANDROID)
    add_android_openssl_libraries(MyApp)
endif()

qmake 集成：

android {
    include(/path/to/android_openssl/openssl.pri)
}

3.2 Qt Creator 配置 #

  1. Tools → Options → Devices → Android
  2. 在 OpenSSL 设置中指定 android_openssl 目录
  3. 项目设置 → Build Android APK → 勾选 Include prebuilt OpenSSL libraries

3.3 验证 SSL 支持 #

cpp
#include <QSslSocket>
#include <QDebug>

void checkSsl() {
    qDebug() << "SSL 支持:" << QSslSocket::supportsSsl();
    qDebug() << "SSL 库版本:" << QSslSocket::sslLibraryBuildVersionString();
}

第四部分：APK 签名与发布 #

4.1 创建签名密钥库 #

bash
keytool -genkey -v \
    -keystore my-release-key.jks \
    -keyalg RSA \
    -keysize 2048 \
    -validity 10000 \
    -alias my-key-alias

4.2 Qt Creator 签名配置 #

  1. Projects → Build Settings → Build Android APK
  2. 选择密钥库文件和别名
  3. 输入密钥库密码

4.3 命令行签名 #

bash
# 生成未签名的 APK
androiddeployqt --output build-android/android-build --gradle

# 签名 APK
jarsigner -verbose -sigalg SHA256withRSA -digestalg SHA-256 \
    -keystore my-release-key.jks \
    build-android/android-build/build/outputs/apk/release/android-build-release-unsigned.apk \
    my-key-alias

# 优化 APK
zipalign -v 4 \
    android-build-release-unsigned.apk \
    MyApp-release.apk

4.4 生成 AAB（Google Play 发布） #

Qt 6.3+ 支持直接生成 Android App Bundle：

bash
androiddeployqt \
    --input android-MyApp-deployment-settings.json \
    --output android-build \
    --android-platform android-34 \
    --gradle \
    --aab

第五部分：常见问题排查 #

5.1 ABI 检测失败 #

错误： Failed to detect the ABIs used by the Qt version

原因： Qt Android 组件未正确安装

解决：

  1. 运行 Qt Maintenance Tool → Add or Remove Components
  2. 确保选中 Qt for Android 相关组件
  3. 重启 Qt Creator

5.2 NDK 目录结构错误 #

错误： NDK directory structure isn't correct

原因： NDK 路径指向了 ndk 根目录而非版本目录

解决： 将路径从 /path/to/ndk 改为 /path/to/ndk/27.2.12479018（具体版本号）

5.3 Gradle 构建失败 #

错误： Execution failed for task ':processDebugResources'

解决：

  1. 检查 android-build/build.gradle 中的 AGP 版本
  2. 确保 Gradle 版本与 AGP 兼容
  3. 清理构建目录后重试：
bash
rm -rf android-build
cmake --build . --target apk

5.4 Windows 路径过长 #

错误： FileNotFoundException 或构建失败

原因： Windows 默认路径限制 260 字符

解决：

  • 将项目移动到较短的路径（如 C:\Dev\MyApp）
  • 或启用 Windows 长路径支持

5.5 版本不匹配 #

问题表现 可能原因 解决方法
链接错误 NDK 版本不匹配 使用 Qt 对应的 NDK 版本
Gradle 错误 AGP 版本过低 更新 build.gradle
编译失败 JDK 版本不正确 Qt 6.x 需要 JDK 17+

第六部分：应用图标与名称定制 #

6.1 准备 AndroidManifest.xml #

首次编译项目后，在 build-xxx/android-build 目录中会生成 AndroidManifest.xml 模板。将此文件复制到项目源码目录：

your-project/
├── android/
│   ├── AndroidManifest.xml
│   └── res/
│       ├── drawable-ldpi/icon.png   (36x36)
│       ├── drawable-mdpi/icon.png   (48x48)
│       ├── drawable-hdpi/icon.png   (72x72)
│       ├── drawable-xhdpi/icon.png  (96x96)
│       └── drawable-xxhdpi/icon.png (144x144)
└── CMakeLists.txt

6.2 配置项目指向自定义资源 #

CMake 项目：

cmake
if(ANDROID)
    set_target_properties(MyApp PROPERTIES
        QT_ANDROID_PACKAGE_SOURCE_DIR "${CMAKE_CURRENT_SOURCE_DIR}/android"
    )
endif()

qmake 项目：

android {
    ANDROID_PACKAGE_SOURCE_DIR = $$PWD/android
}

6.3 通过 Qt Creator 设置图标 #

  1. 在 Qt Creator 中双击 AndroidManifest.xml 打开清单编辑器
  2. 在 Application icon 区域为各 DPI 等级选择图标文件：
DPI 等级 推荐尺寸 适用设备
ldpi 36×36 低分辨率旧设备
mdpi 48×48 中等分辨率
hdpi 72×72 高分辨率
xhdpi 96×96 超高分辨率
xxhdpi 144×144 现代高端设备

6.4 修改应用名称 #

在 AndroidManifest.xml 中修改以下字段：

xml
<application android:label="你的应用名称">
    <activity android:label="你的应用名称"
              ...>
    </activity>
</application>

或在 Qt Creator 清单编辑器中直接编辑 Application name 和 Activity name 字段。
