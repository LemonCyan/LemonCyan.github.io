关于 QT 的系统总结（非常全面，非常好） #

这是一篇非常全面的 Qt 知识点总结，涵盖了 Qt 的编译环境、项目原理、布局管理、核心控件、QSS、内存管理、信号槽、多线程以及动态链接库的调用等多个方面。

一、编译环境与开发流程 #

开发 Qt 应用程序主要有两种集成开发环境（IDE）：

  1. VS + Qt 插件：VS 调试功能强大，适合习惯微软生态的开发者。但对信号槽的自动生成支持不够友好，需要手动编写，且较容易遇到中文编码问题。
  2. Qt Creator（官方推荐）：跨平台的集成开发环境，内置 Qt Designer 界面设计器，能非常方便地拖拽设计 UI 界面。最重要的是，它无缝集成了详尽的官方帮助文档（在 Qt Creator 中按 F1 即可快速查阅）。

二、QT 项目的构成及原理 #

以最常用的“Qt Widgets Application”项目为例，一个标准的 Qt 项目包含以下 4 个核心文件：

  • main.cpp：主入口文件，在 main 函数中实例化主窗体类并调用 show() 显示界面。
  • mainwindow.ui：XML 格式的 UI 界面文件，用 Qt Designer 打开进行可视化拖拽设计。
  • mainwindow.h & mainwindow.cpp：后台逻辑的头文件与源文件。

UI 初始化原理 #

在后台代码中，我们不能像其他一些框架一样直接通过 this->controlName 访问界面控件，而是通过 ui 指针（即 ui->controlName）进行操作。

MainWindow 类中包含一个指向 Ui::MainWindow 的私有指针成员 ui：

cpp
// mainwindow.h 声明
namespace Ui {
class MainWindow;
}

class MainWindow : public QMainWindow {
    Q_OBJECT
public:
    explicit MainWindow(QWidget *parent = 0);
    ~MainWindow();
private:
    Ui::MainWindow *ui;
};

当构建项目时，Qt 的元对象编译器（uic）会将 .ui 文件编译生成一个 ui_mainwindow.h 头文件，在这个文件里定义了命名空间 Ui 下的 MainWindow 类，其中包含了初始化控件的 setupUi(QWidget *parent) 方法。构造函数一进来就会调用 ui->setupUi(this) 完成界面控件的创建与绑定。

三、QT 中的布局 #

Qt 提供了四种基础布局管理器：

  • Vertical Layout（垂直布局）：子控件从上到下排列。
  • Horizontal Layout（水平布局）：子控件从左到右排列。
  • Grid Layout（网格/表格布局）：行列定位排版。
  • Form Layout（表单布局）：左侧标签、右侧输入框的表单样式。
✦提示

绝大多数复杂的界面都可以通过 水平布局 和 垂直布局 的相互嵌套，再配合弹簧占位控件（HorizontalSpacer 和 VerticalSpacer）实现。

布局的两种使用方式 #

  1. 拖放布局控件：直接将 Layout 控件拖入界面，再把普通子控件拖入其中。这种方式下，Qt Creator 实际上会自动生成一个 QWidget 作为该布局的容器父节点。
  2. 容器指定布局：直接选中某个容器控件（如 QFrame 或顶级窗口 MainWindow），在空白处右键选择“布局”，将其设为某种布局模式。此时，容器中的所有直接子控件都会被该布局自动约束。

四、QT 中的通用控件 #

最常用的控件包括 QPushButton（按钮）、QLineEdit（文本单行输入框）、QRadioButton（单选框）、QCheckBox（复选框）、QFrame（容器控件）、QProgressBar（进度条）等。这些控件的用法直观简单，通常查阅官方文档即可掌握。

五、QVariant 类型 #

在 Qt 中，QVariant 扮演着“万能数据包裹类”的角色，几乎所有通用控件的数据绑定接口都依赖于它。它可以包裹常见的 QString, int, double 等类型，也可以包裹复杂的 Qt 自定义类（如 QPoint, QRect 等）。

包裹自定义结构体/类 #

若要将自定义的实体类放入 QVariant 中，需要按照如下步骤进行：

  1. 声明元类型：在类定义下方使用 Q_DECLARE_METATYPE 宏。
    cpp
    struct MyClass {
    int id;
    QString name;
};
Q_DECLARE_METATYPE(MyClass)
  2. 设置与获取：
    cpp
    // 包裹数据
MyClass myclass;
QVariant var = QVariant::fromValue(myclass);

// 取出数据
myclass = var.value<MyClass>();

六、QComboBox 控件 (下拉列表框) #

在实际开发中，下拉框每一项除了显示给用户看的文本外，还需要绑定隐藏的数据标识（如 ID 或数据库实体对象）。

  • 添加项目并绑定隐藏数据：
    cpp
    QComboBox *comboBox = new QComboBox();
comboBox->addItem("选项A", QVariant(1001)); // 绑定文本与对应的隐藏数据 (ID: 1001)
  • 获取当前选中的隐藏数据：
    cpp
    QVariant var = comboBox->currentData();
int id = var.toInt();

七、QTableWidget 控件 (数据表格) #

QTableWidget 用于以网格形式展示和管理结构化数据。

常用属性配置 #

  • focusPolicy：设置为 NoFocus 可以隐藏点击单元格时出现的虚线虚框。
  • editTriggers：设置为 QAbstractItemView::NoEditTriggers 可以使单元格变为只读，禁止用户双击编辑。
  • selectionBehavior：设置为 QAbstractItemView::SelectRows 实现按整行选中。
  • selectionMode：设置为 QAbstractItemView::ExtendedSelection 支持多选。

常用代码片段 #

  1. 在单元格中插入子控件：
    cpp
    QComboBox *comBox = new QComboBox();
comBox->addItem("F");
comBox->addItem("M");
ui->tableWidget->setCellWidget(row, col, comBox); // 注意使用 setCellWidget 而不是 setItem
  2. 启用单元格复选框：
    cpp
    QTableWidgetItem *item = new QTableWidgetItem();
item->setCheckState(Qt::Unchecked); // 设置勾选状态后，item 自动呈现为 CheckBox 样式
ui->tableWidget->setItem(row, col, item);
  3. 读写单元格的自定义数据：
    cpp
    // 设置数据
QTableWidgetItem *item = new QTableWidgetItem("文本");
item->setData(Qt::UserRole, QVariant::fromValue(myClassInstance));
ui->tableWidget->setItem(row, col, item);

// 获取数据
QTableWidgetItem *item = ui->tableWidget->item(row, col);
MyClass model = item->data(Qt::UserRole).value<MyClass>();
  4. 定位点击坐标对应的单元格：
    cpp
    QModelIndex index = ui->tableWidget->indexAt(QPoint(x, y));
int row = index.row();
int col = index.column();

自定义表头复选框 (QHeaderView 重绘) #

默认的 QHeaderView 无法直接插入复选框，必须通过重绘来实现。

cpp
// 自定义表头 myqheaderview.h
class MyQHeaderView : public QHeaderView {
    Q_OBJECT
public:
    explicit MyQHeaderView(Qt::Orientation orientation, QWidget *parent = 0);
    void setChecked(bool checked);
signals:
    void headCheckBoxToggled(bool checked);
protected:
    void paintSection(QPainter *painter, const QRect &rect, int logicalIndex) const;
    void mousePressEvent(QMouseEvent *event);
private:
    QRect checkBoxRect(const QRect &sourceRect) const;
    bool m_isOn;
};

八、QTabWidget 控件 (选项卡) #

选项卡控件提供多页切换能力。

  • 切换当前页：ui->tabWidget->setCurrentIndex(index);
  • 移除选项卡：ui->tabWidget->removeTab(index);

九、QWebView 控件 (嵌入网页) #

QWebView（基于 WebKit 模块）用于加载 HTML 并进行交互。

ℹ笔记

在 Qt 5 中，原 WebKit 模块已逐渐被新一代的 QWebEngineView (基于 Chromium 内核) 替代，但交互思路大致相同。

1. 加载页面 #

cpp
ui->webView->load(QUrl("http://www.baidu.com"));
// 如果是本地网页，必须添加 file:/// 协议头
ui->webView->load(QUrl("file:///C:/test.html"));

2. Qt 掉 JS 函数 #

在 loadFinished 信号对应的槽中（确保网页已渲染完毕），执行脚本：

cpp
QString js = "alert('Hello JS!')";
ui->webView->page()->mainFrame()->evaluateJavaScript(js);

3. JS 调用 Qt 函数 (Qt WebKit Bridge) #

要在 JavaScript 中直接调用 C++ 提供的对象，必须满足以下条件：

  1. 被暴露的 C++ 类必须继承自 QObject，并在类头部声明 Q_OBJECT。
  2. 暴露的方法必须被声明为 public slots（公有槽函数）或加上 Q_INVOKABLE 宏修饰。

将 C++ 对象注册给网页： 在 javaScriptWindowObjectCleared 信号触发时注入对象：

cpp
// 绑定信号
connect(ui->webView->page()->mainFrame(), &QWebFrame::javaScriptWindowObjectCleared,
        this, &MainWindow::populateJavaScriptWindowObject);

// 槽函数实现
void MainWindow::populateJavaScriptWindowObject() {
    // 将 this (MainWindow) 注册为 JS 中的全局对象 "QtObj"
    ui->webView->page()->mainFrame()->addToJavaScriptWindowObject("QtObj", this);
}

JS 侧调用代码：

javascript
QtObj.TestQt(); // 调用 C++ 中的 Q_INVOKABLE 或 slot 方法

十、使用 QSS (Qt 样式表) #

QSS 继承了 CSS 的主要语法，专为 Qt 界面美化而设计。

选择器类型 #

  • 类型选择器：QPushButton { ... } 作用于 QPushButton 及其子类。
  • 类选择器：.QPushButton { ... } 作用于 QPushButton，但不包括其派生子类。
  • ID 选择器：#okButton { ... } 作用于 objectName 为 okButton 的控件。
  • 属性选择器：QPushButton[flat="false"] { ... } 作用于满足特定属性值的控件。
  • 后代与直接子选择器：QDialog QPushButton { ... } 和 QDialog > QPushButton { ... }。

全局加载 QSS #

推荐把 QSS 样式保存到 .qss 文件中，并通过 Qt 资源系统（.qrc）统一载入：

cpp
QFile file(":/qss/main.qss");
file.open(QFile::ReadOnly);
QTextStream stream(&file);
QString stylesheet = stream.readAll();
this->setStyleSheet(stylesheet); // 作用于当前窗体及其子控件
file.close();

十一、编码问题与乱码解决 #

如果在 C++ 源文件中直接书写中文字符串，经常会遭遇编译期报错 error C2001: 常量中有换行符 或运行期显示乱码。

终极解决办法 #

  1. 在含有中文字符的源文件开头，添加编译器指令：
    cpp
    #pragma execution_character_set("utf-8")
  2. 使用外部文本编辑器（如 UltraEdit 或 VS Code）将该源文件的物理编码保存为 UTF-8 with BOM 格式。
  3. 重新在 Qt Creator 中打开、编译即可解决。

十二、QT 的内存管理 (半自动垃圾回收) #

在 Qt 中，绝大多数 new 出来的 UI 对象都不需要手动调用 delete 释放，因为它们有父子对象链（Object Tree）管理机制。

  • 核心逻辑：所有继承自 QObject 的类，如果在实例化时通过构造函数指定了父对象（parent），那么当父对象被 delete 释放时，其下挂载的所有子对象都会被自动 delete 释放。
  • 安全销毁：不推荐直接 delete 一个处于事件循环中的 QObject 对象。如果要立刻销毁，应当使用 obj->deleteLater()，它会在当前事件循环结束后安全地回收内存。

十三、信号与槽机制 (Signal & Slot) #

信号槽是 Qt 的核心通讯特征，负责对象间的解耦通信。

槽函数绑定方式 #

  1. 自动关联：在 Qt Designer 中右键控件选择“转到槽...”，选择对应信号后，Qt Creator 会自动生成如下规则的函数声明与定义：
    cpp
    void on_buttonName_clicked();
    Qt 内部会通过 metaObject 解析该函数命名并自动完成绑定。
  2. 手动连接 (推荐)：使用 QObject::connect() 接口，在代码中进行精准绑定：
    cpp
    connect(ui->btnTest, &QPushButton::clicked, this, &MainWindow::onBtnTestClicked);

核心机制与moc #

信号槽的自动化处理离不开 Qt 的元对象编译器（moc, Meta-Object Compiler）。在项目构建时，moc 会扫描含有 Q_OBJECT 宏的类，并生成相应的 moc_*.cpp 代码文件。里面通过 qt_meta_data_ 数组存储信号槽对应的元数据信息，并在 qt_static_metacall 函数中通过 switch-case 转发回调。

十四、QT 中的线程 (QThread) #

在工作线程中执行计算任务，可以通过继承 QThread 重新实现 run 函数：

cpp
class MyThread : public QThread {
    Q_OBJECT
protected:
    void run() override {
        // 线程执行的逻辑任务
    }
};

启动线程调用 thread->start()，它会在新线程中调起 run 方法。

❢重要

切记：工作线程中绝对不能直接操作主 UI 线程中的界面控件！必须通过发射自定义信号的方式，将数据传递给主线程的槽函数，由主线程接收后安全地更新界面。

十五、在 QT 中使用第三方 DLL #

可以通过 Qt Creator 提供的“添加库”向导非常方便地导入外部库。完成向导后，.pro 文件中会自动追加包含路径和库路径代码：

ini
win32: LIBS += -L$$PWD/E:/trans/ -lTransAPI
INCLUDEPATH += $$PWD/E:/trans/include
DEPENDPATH += $$PWD/E:/trans/include

十六、为控件添加右键菜单 #

为任意 QWidget 控件添加右键菜单主要有两种方式：

方式 1：设置 customContextMenuRequested 信号 #

  1. 设置控件的右键政策属性：
    cpp
    ui->btnTest->setContextMenuPolicy(Qt::CustomContextMenu);
  2. 绑定自定义右键信号：
    cpp
    connect(ui->btnTest, &QWidget::customContextMenuRequested, this, &MainWindow::showBtnMenu);
  3. 在槽函数中构造菜单：
    cpp
    void MainWindow::showBtnMenu(const QPoint &pos) {
    QMenu *cmenu = new QMenu(ui->btnTest);
    QAction *action1 = cmenu->addAction("菜单项 1");
    connect(action1, &QAction::triggered, this, &MainWindow::onMenuClick);
    cmenu->exec(QCursor::pos()); // 弹出显示右键菜单
}

方式 2：重写 contextMenuEvent #

重写子类中的 void contextMenuEvent(QContextMenuEvent *event) 事件，并在内部执行菜单弹出。
