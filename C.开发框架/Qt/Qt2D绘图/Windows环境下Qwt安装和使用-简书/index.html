Windows环境下Qwt安装和使用 - 简书

Windows环境下Qwt安装和使用教程 #

Qwt (Qt Widgets for Technical Applications) 是一个基于 Qt 编写的开源 2D 绘图与控制组件库。它包含大量的图表显示控件（如曲线图、柱状图、刻度盘、仪表等），是进行测控、仪器仪表与数据可视化开发的首选插件。

本文以常见的 Win7 32位、Qt 5.5、MinGW 4.9.2、Qt Creator 3.4.2 环境为例，详细介绍如何编译、配置及引用 Qwt 库。

一、 环境准备 #

  1. 安装带有 MinGW 的 Qt：
    • 必须确保使用的是集成了 MinGW 的离线安装包（例如 qt-opensource-windows-x86-mingw492-5.5.0.exe）。安装时勾选 MinGW 组件。
    • 将 MinGW 的 bin 目录（例如 D:\Qt\5.5\mingw492_32\bin）配置到系统的系统变量 Path 中。
  2. 下载 Qwt 资源：
    • 打开 Qwt Sourceforge，下载以下三个关键文件（以 Qwt 6.1.2 为例）：
      • qwt-6.1.2.zip （源码）
      • qwt-6.1.2.pdf （用户手册）
      • qwt-6.1.2.qch （Qt Creator 帮助文档）

二、 安装 Qwt 帮助文档 #

为了在 Qt Creator 中随时按下 F1 查阅 Qwt 类的定义：

  1. 将下载的 qwt-6.1.2.qch 文件拷贝至 Qt 安装目录的帮助文档下，如 D:\Qt\5.5\Docs\Qt-5.5\。
  2. 打开 Qt Creator，在菜单栏选择 “工具” -> “选项”。
  3. 选择 “帮助” -> “文档” 子选项卡，点击右侧的 “添加...” 按钮。
  4. 选中 qwt-6.1.2.qch 并应用。之后即可在 Qt 帮助文档列表中查阅 Qwt 控件的完整 API。

三、 编译与安装 Qwt #

解压 qwt-6.1.2.zip 源码压缩包至您的本地非中文路径（例如 D:\qwt-6.1.2\）。我们提供以下两种编译方案：

方案一：使用命令行编译 (推荐，最直接) #

  1. 点击 Windows “开始” 菜单 -> “所有程序”，找到 Qt 5.5 对应的终端命令行快捷入口：Qt 5.5 for Desktop (MinGW 4.9.2 32 bit) 并打开。
  2. 在弹出的命令行中，通过 cd 进入解压后的 Qwt 源码目录：
    bash
    cd D:\qwt-6.1.2
  3. 依次执行以下编译三部曲：
    bash
    qmake qwt.pro
mingw32-make
mingw32-make install
    ℹ笔记

    执行 mingw32-make 时会进行大批量的 C++ 编译，耗时通常需要 5 ~ 15 分钟，请耐心等待。 4. 编译完成：执行 mingw32-make install 之后，Qwt 会被自动安装部署至 C:\Qwt-6.1.2 目录下。

方案二：使用 Qt Creator 集成开发环境编译 #

  1. 用 Qt Creator 直接打开 Qwt 目录下的项目管理文件 qwt.pro。
  2. 在左侧树状栏中，双击打开子项目配置文件 qwtbuild.pri。
  3. 🔑 关键步骤：定位到第 30 行左右，在其前方加上 # 注释掉：
    ini
    # CONFIG           += debug_and_release
    （注释它的目的是防止由于 MinGW 平台下混合编译产生报错）。
  4. 在 Qt Creator 中，选择 Release 或 Debug 构建工程，点击绿色的三角形运行构建。
  5. 构建生成的各种静态库和动态链接库文件将输出到工程外部的构建文件夹中（例如 D:\build-qwt-Desktop_Qt_5_5_0_MinGW_32bit-Debug\）。

四、 核心工作：拷贝与集成 Qwt 文件 #

编译完成后，我们必须将 Qwt 的输出库部署到 Qt Creator 的相应系统库中，以便编译器和 Qt 界面设计器能够识别它们。

以方案一生成的 C:\Qwt-6.1.2\ 为参考：

  1. 拷贝库文件：
    • 将 C:\Qwt-6.1.2\lib\ 下的静态库 libqwt.a 与 libqwtd.a 复制到您的 Qt 编译套件库目录下，如 D:\Qt\5.5\mingw492_32\lib\。
  2. 拷贝动态链接库 (DLL)：
    • 将 C:\Qwt-6.1.2\lib\ 下的动态库 qwt.dll 与 qwtd.dll 复制到您的 Qt 运行 bin 目录下，如 D:\Qt\5.5\mingw492_32\bin\。
  3. 拷贝设计师插件：
    • 将 C:\Qwt-6.1.2\plugins\designer\ 下的 qwt_designer_plugin.dll 复制到您的 Qt 套件设计师目录，如 D:\Qt\5.5\mingw492_32\plugins\designer\。
  4. 拷贝头文件：
    • 在您的 Qt 套件包含目录下新建名为 Qwt 的目录（如 D:\Qt\5.5\mingw492_32\include\Qwt）。
    • 将 C:\Qwt-6.1.2\include\ 下的所有头文件（.h）全部复制到新建的 Qwt 目录下。

五、 测试与使用 #

我们可以在 Qt Creator 中新建一个基本的 Qt GUI 工程来测试集成效果。

1. 修改 .pro 工程配置文件 #

在项目的 .pro 文件末尾，加入 Qwt 静态链接和头文件指向路径：

ini
# 💡 定义动态与静态链接规则，并引入头文件目录
DEFINES += QT_DLL QWT_DLL

LIBS += -L"D:/Qt/5.5/mingw492_32/lib" -lqwtd
LIBS += -L"D:/Qt/5.5/mingw492_32/lib" -lqwt

INCLUDEPATH += D:/Qt/5.5/mingw492_32/include/Qwt

2. 在 Qt Designer 中拖拽控件 #

  1. 右键项目中的 mainwindow.ui，选择 “用...打开” -> “Qt Designer”。
    ❢重要

    如果您直接使用 Qt Creator 内部集成的“设计”窗口，可能会发现控件箱中没有 Qwt 插件。这是因为官方发行的 Windows Qt Creator 是用 MSVC 编译器编译的，无法识别通过 MinGW 编译生成的 qwt_designer_plugin.dll 插件。因此，我们必须独立启动标准的 Qt Designer 程序来编辑 UI。 2. 打开 Qt Designer 后，在左侧的 Widget Box 底端，可以看到新增的 Qwt Widgets 控件列表。 3. 拖拽一个 QwtPlot 控件放置在界面中央，保存并关闭。 4. 返回 Qt Creator 运行该项目，即可成功看到渲染生成的二维坐标网格画布！
