永久组合

永久投资组合跟全天候相比哪个更好？或者说这两种多资产投资策略适合哪种投资者？各有什么优劣势？在国内资本市场是否有更好的组合方式？今天，我们就来聊聊这个话题。

1、两个组合的结构对比 #

首先，我们看看两种组合的设计理念和投资组合结构有什么不同

a、永久组合： #

诞生于1987年，由"自由主义投资哲学家"Harry Browne提出，核心逻辑非常简单：不同资产应对不同经济环境，被称为"最无聊的投资策略"。

结构非常简单：25% 股票，25% 长期国债，25% 黄金，25% 现金。

无论经济环境如何变化，总有资产在上涨：

通过四种资产均衡配置，理论上可以在任何宏观环境下保持稳定。之所以被称为：Permanent Portfolio（永久组合），意思是：一旦配置好，几乎可以永久持有。

优点： 极度简单，只有4类资产，再平衡规则简单易执行;对通胀有天然保护;任何人都能复制。

缺点： 持有25%现金拖累收益,牛市期间明显跑输,黄金长期无现金流。

永久组合业绩回测：过去30年年化收益7.21%

b、全天候组合： #

由桥水基金创始人Ray Dalio在1996年推出，理论基础是风险平价，他认为传统配置之所以波动大，是因为各资产对风险的贡献不均衡，通过大幅增加债券比例来对冲股票的波动，同时引入商品和黄金来防范通胀。这里就不详细展开讲了，有兴趣的读者可以去看之前写的那篇文章。

优点： 收益风险比（夏普比率）极高。用较低的风险换取了接近股票市场的长期回报。

缺点： 对利率环境较为敏感，55%债券在过去40年有效，是因为全球利率长期下降，如果未来进入长期通胀时代，债券表现可能弱。普通投资者难完全复制平价策略，只能简单模拟。再平衡规则复杂，普通人很难有效执行

3、普通投资者应该怎么选？ #

我在这里给一个简单的选择标准：

**适合永久组合的人：**不想研究宏观，不想频繁调仓，追求低波动，投资经验不多。那么永久组合更适合你。它的核心优势是：简单，可长期执行。

**适合全天候组合的人：**对资产配置理解较深，可以做全球资产配置，能定期再平衡，能接受债券比例较高，那么全天候组合可能更优。

在各大第三方平台上也有很多基于永久组合投资策略的投顾，但个人觉得完全没必要花这个投顾费，自己去做个业绩回测，DIY组合成本会更低，业绩也不会有太大差异，大家可以自己动手做做数据回测，也欢迎在留言区分享

4、我的个人建议 #

如果你觉得永久组合太“笨”，全天候组合又太“难”，我建议采用一个更具普适性的折中版本，作为你资产配置的起点：

40% 股票 + 40% 债券（短债+长债）+ 10% 黄金 + 10% 商品

这个组合本质上就是：永久组合 + 全天候组合的折中版本。

增加了股票比例，降低了债券比例，减少了不生息的黄金资产，去掉了现金（用短债替代），且通过国内的ETF工具就能轻松实现，我组合清单如下：

股票类(40%)：沪深300，中证500，标普500，纳斯达克100；

短期债券(20%)：1-3年期国债；

长期债券(20%)：7-10年期国债；

黄金(10%)：黄金；

大宗商品(10%)：大宗商品

根据上述策略进行的数据回测分析，2018年至今总收益率112.38%，年化收益10.51%，最大回撤12.31%，年化波动率7.74%。

（对比我之前自建的全天候组合业绩表现回测：2018年至今总收益96.66%，年化收益率9.41%，最大回撤8.89%，年化波动率5.91%。）

5、写在最后 #

资产配置领域最有影响力的两句话来自这两位大师：

Harry Browne：不要预测未来，要为所有未来做好准备。

Ray Dalio：不要押注单一环境，要构建能适应所有环境的组合。

他们的方法不同，但目标一样：让投资组合穿越周期。

而真正决定投资结果的，从来不是组合本身。

而是：你能不能坚持它。
