傅立叶分析：从周期现象到频域 #

任何有规律重复的东西，都能拆成一堆正弦波的叠加。傅立叶分析干的事，就是把「它长什么样」翻译成「它由哪些频率组成」。

本文由三份来源合并重排：一份讲直觉的随笔（周期现象 → 矢量分解 → 函数分解 → 时域到频域）、一份讲公式的课堂笔记（正交分解 → 级数 → 变换 → 性质 → Hilbert 变换）、一份讲图像应用的短篇（二维 DFT）。合并时删掉了重复的铺垫与个人感慨，补正了原文在网页抓取时丢失的公式。

零、全景：先看这张表 #

信号类型 连续/离散 周期? 工具 频谱形态
连续 + 周期 连续 周期 傅立叶级数 离散谱线，间隔 Ω0​=2π/T0​
连续 + 非周期 连续 非周期 傅立叶变换 连续频谱，密度函数 X(Ω)
离散 + 周期 离散 周期 DFS / DFT 周期离散谱

一句话记住主线：周期 → 级数（离散谱）；非周期 → 变换（连续谱）。二者不是两种理论，而是同一个式子在 T→∞ 时的两个端点。

阅读时可以走三条线：

  • 想搞懂为什么要这么分解 → 第一、二节
  • 想搞懂公式怎么来、怎么算 → 第三、四、五节
  • 只想知道工程上怎么用（滤波、信号完整性、图像） → 第六、八节

一、周期现象：为什么值得造一个「频域」 #

工作和生活里到处都是周期现象：旁边调 audio driver 的工程师放的 1 kHz 正弦、公园游船推开的波纹、示波器上的晶振方波。

周期现象分两种：

  • 时间上的周期：1 kHz 的音频，一秒重复一千次。
  • 空间上的周期：水面的波纹、布料的纹理，本质是一个 pattern 在不断重复。

人对时间的流逝、空间的变化都有直觉（眼睛、耳朵、触觉就是身体自带的 sensor），所以周期现象对我们像呼吸一样自然。但还有另一个观察世界的侧面：频域（frequency domain）。

描述时间上的周期现象用频率（frequency）——一秒重复的次数。描述空间上的周期现象用空间频率（spatial frequency）——单位长度里重复几次，单位可以是 cycle/mm，也可以直接是「每像素几个周期」。图像处理里的“高频”说的就是这个。

换个侧面看世界，是本文全部内容的动机。

二、分解：从矢量到函数 #

进入傅立叶级数之前，先接受两个词：

  1. 分析（analysis）：把一个复杂信号（函数）拆成更简单的成分，比如一堆 sin、cos。
  2. 合成（synthesis）：用这些简单成分重新拼回复杂信号。

后面不再区分「函数」和「信号」这两个词。

1、矢量的分解 #

一个二维矢量可以沿 x、y 轴投影，拆成 Ax​ 和 Ay​。沿别的方向拆也完全可以——只要选一组「坐标轴」，任何矢量都能拆成几个分量之和。

推广到三维就是 x、y、z 三轴，再推广到 $n$ 维：概念一样，只是没有直观图形，得靠想象。

关键不是“能不能拆”，而是“选哪组轴”。通常选两两垂直的轴，因为这样各分量互不干扰、求系数最省事。这个要求，就是后面「正交」的来源。

2、函数的分解 #

取一个周期为 1 的信号：f(t+1)=f(t)。它的基频是 1，于是拿来做「坐标轴」的自然是 sin(2πt)、cos(2πt)。

先看叠出来的东西：

sin(2πt)+sin(4πt)+sin(6πt)+⋯

sin(4πt) 的频率是 2，但它同样满足「每隔 1 秒波形重复一次」（实际上每 0.5 秒就重复一次）。把频率为 1、2、3……的函数加在一起，得到的结果仍然是周期为 1 的函数——因为每个加数都有“每隔 1 秒重复”这个性质，加起来当然也保留。

上式的毛病是太特殊（t=0 时全为 0）。如果允许调整每个谐波的幅度和相位，就能拼出各种形状的周期为 1 的函数。

于是自然会问一个反过来的问题：

任意一个周期为 1 的函数，是否都能分解成频率 1、2、3……这些成分的线性组合？

如果成立，那任意周期函数都能拆成一堆 sin 之和。这和矢量分解没有本质区别：各个频率的 sin 函数就是 n 维空间里的 n 根坐标轴，函数在某根轴上的“投影长度”就是该次谐波的幅度。

3、点积、正交、标准正交基 #

先复习点积（dot product）：A=(a1​,a2​)、B=(b1​,b2​)，则 A⋅B=a1​b1​+a2​b2​。

把点积搬到函数上。若 $f$、$g$ 都是 $[0,1]$ 上的平方可积函数，定义：

⟨f,g⟩=∫01​f(t)g(t)​dt

被积函数是 $f$ 乘以 $g$ 的共轭。出现共轭是因为后面要用复指数 ej2πkt，函数可能是复值的；如果都是实函数，共轭就等于没有。

两个矢量的点积为 0 就是正交（orthogonal）——二维三维里就是垂直。函数也一样：⟨f,g⟩=0 就说函数 $f$ 与 $g$ 正交。

再看坐标系：$(1,0)$ 和 $(0,1)$ 是两个最基础的向量，即标准正交基（standard orthogonal basis）。任意向量都能写成它们的线性组合；反过来，它们的线性组合能充满整个二维空间。

函数空间能不能也找一组两两正交的函数，其线性组合充满整个函数空间？能，而且不止一组。傅立叶级数只是碰巧选了 sin/cos 或复指数作为那组标准正交基而已——换成别的一组正交函数（比如 Walsh 函数、Legendre 多项式），就是别的级数展开。

矢量的长度来自 A⋅A，函数同理。记 ∥f∥ 为函数的模：

⟨f,f⟩=∥f∥2

4、一个题外话：分解也是一种工程方法 #

这套「把复杂对象拆成互不干扰的分量，逐个处理」的思路，和软件设计是同一件事：复杂需求拆成模块，复杂 issue 拆成可复现的最小步骤。区别只在于矢量和函数有严格的正交性保证，而模块之间的“正交”得靠人来守。

三、正交分解的一般框架 #

把第二节的直觉写成通用公式。

正交：若两个信号 x1​(t)、x2​(t) 在区间 (t1​,t2​) 上满足

∫t1​t2​​x1​(t)x2∗​(t)dt=0

则称二者在该区间上正交，x2∗​ 表示共轭。

正交信号集：集合 {x1​(t),…,xn​(t)} 中任意两个都满足

∫t1​t2​​xi​(t)xj∗​(t)dt={0,Ki​,​i=ji=j​

完备正交信号集：在这个集合之外，找不到任何一个信号能与集合内所有信号都正交。完备集通常包含无穷多个元素（n→∞）。

有了完备正交信号集，区间上任意信号 $x(t)$ 都能展开：

x(t)=C1​x1​(t)+C2​x2​(t)+⋯+Cn​xn​(t)=i=1∑n​Ci​xi​(t)

系数由均方误差最小求出：

Ci​=∫t1​t2​​xi2​(t)dt∫t1​t2​​x(t)xi​(t)dt​

这一步是整个傅立叶分析的“发动机”：求系数 = 做内积 = 投影。后面所有系数公式（ak​、bk​、Xk​、$F(u,v)$）都是这一个式子的不同外衣。

四、连续周期信号：傅立叶级数 #

1、三角形式 #

三角函数集

{1, cos(Ω0​t), cos(2Ω0​t), …, sin(Ω0​t), sin(2Ω0​t), …}

在区间 (t0​,t0​+T0​] 上构成完备正交信号集，其中 Ω0​=2π/T0​ 是基频角频率。

于是区间上任意信号可展开为：

x(t)=2a0​​+k=1∑∞​[ak​cos(kΩ0​t)+bk​sin(kΩ0​t)],t∈(t0​,t0​+T0​]

因为集合里每个函数都以 T0​ 为周期，把 $x(t)$ 以 T0​ 周期延拓成 x^(t) 后，等式在整个实轴上成立：

x^(t)=2a0​​+k=1∑∞​[ak​cos(kΩ0​t)+bk​sin(kΩ0​t)],t∈(−∞,∞)

系数（把 x^ 投影到各根轴上）：

ak​=T0​2​∫t0​t0​+T0​​x^(t)cos(kΩ0​t)dt,k=0,1,2,…
bk​=T0​2​∫t0​t0​+T0​​x^(t)sin(kΩ0​t)dt,k=1,2,…
a0​=T0​2​∫t0​t0​+T0​​x^(t)dt

奇偶性可以直接砍掉一半计算：

  • x^(t) 是实偶函数 → x^cos 偶、x^sin 奇 → bk​=0，只有余弦项。
  • x^(t) 是实奇函数 → x^cos 奇、x^sin 偶 → ak​=0，只有正弦项。

2、幅相形式 #

把同频的 sin 与 cos 合成一项：

x^(t)=2A0​​+k=1∑∞​Ak​cos(kΩ0​t+φk​)
Ak​=ak2​+bk2​​,φk​=−arctanak​bk​​
ak​=Ak​cosφk​,bk​=−Ak​sinφk​

Ak​ 是 $k$ 次谐波振幅，φk​ 是相位，kΩ0​ 是 $k$ 次谐波角频率。工程上更爱用这个形式：幅度谱 + 相位谱，正是示波器和频谱仪读出来的两个东西。

3、狄利赫利条件：什么时候能展开 #

不是所有周期信号都能展开成傅立叶级数，需要满足：

  1. 一个周期内绝对可积：∫t0​t0​+T0​​∣x^(t)∣dt<∞
  2. 一个周期内不连续点数目有限
  3. 一个周期内极大值、极小值点数目有限

实践中的工程信号几乎都满足。真正麻烦的是条件 2 背后的东西——不连续点会让级数在跳变处「永远差一点」，见第七节的吉布斯现象。

4、指数形式 #

利用欧拉公式

ejθ=cosθ+jsinθ

把三角形式改写：

x^(t)=2A0​​+k=1∑∞​2Ak​​[ej(kΩ0​t+φk​)+e−j(kΩ0​t+φk​)]

把第二项的求和下标从 k=1…∞ 换成 k=−∞⋯−1，再利用 ak​ 关于 $k$ 为偶、bk​ 关于 $k$ 为奇导出的 A−k​=Ak​、φ−k​=−φk​，合并后得到：

x^(t)=k=−∞∑∞​Xk​ejkΩ0​t
Xk​=21​Ak​ejφk​=21​(ak​−jbk​)=T0​1​∫t0​t0​+T0​​x^(t)e−jkΩ0​tdt,k=0,±1,±2,…

Xk​ 就是傅立叶系数（复系数），它同时携带振幅和相位信息。

5、负频率是怎么回事 #

指数形式里 $k$ 从 −∞ 取到 +∞，冒出了「负频率」。这不是物理上真有个反向转的波，而是数学记账：一个实余弦波 cos(Ω0​t) 在复指数基下必须拆成 ejΩ0​t 和 e−jΩ0​t 两个共轭分量才能凑出实数值。

所以对实信号恒有 X−k​=Xk∗​（共轭对称），负频率那一半的信息是冗余的。理解这一点，后面看 DFT 的对称性、看 Hilbert 变换的“单边谱”就不会卡住。

6、三种形式对照 #

形式 表达式 系数 用在哪

幅相 2A0​​+∑Ak​cos(kΩ0​t+φk​) Ak​,φk​ 频谱仪读数、工程直观

五、从级数到变换：非周期信号 #

1、让周期趋于无穷 #

非周期信号可以看成周期 T→∞ 的周期信号。此时：

  • 谱线间隔 Ω0​=2π/T→0，离散谱线挤成连续谱；
  • 每条谱线的幅值也趋于无穷小。

幅值趋于 0 就没法用了，但这些无穷小量之间保持固定比例，于是改看单位频带内的频谱值——频谱密度函数。令

X(Ω)=T→∞lim​Xk​T=T→∞lim​∫−T/2T/2​x(t)e−jkΩ0​tdt

取极限后 kΩ0​→Ω，得到傅立叶变换：

X(Ω)=∫−∞∞​x(t)e−jΩtdt

由级数展开式取极限，求和变积分，得到傅立叶反变换：

x(t)=2π1​∫−∞∞​X(Ω)ejΩtdΩ

两式构成一对变换对。X(Ω) 一般是复函数：

X(Ω)=∣X(Ω)∣e−jφ(Ω)

∣X(Ω)∣ 是幅值频谱（各频率分量的相对幅值），φ(Ω) 是相位频谱。

记法提醒：2π1​ 放正变换还是反变换，不同教材不一样；用角频率 Ω 时放反变换，用普通频率 $f$（Ω=2πf）时两边的 2π 会抵消。查表时先确认约定。

2、存在条件 #

傅立叶变换存在的充分条件是绝对可积：

∫−∞∞​∣x(t)∣dt<∞

这是个充分不必要条件。符号函数、阶跃、直流、冲激都不满足，但工程上照样用——引入广义函数（冲激函数 δ）后，它们的变换都有确定意义。

3、典型信号速查 #

单边指数：x(t)=e−αtε(t)，α>0

X(Ω)=∫0∞​e−αte−jΩtdt=α+jΩ1​

矩形脉冲：x(t)=E[ε(t+τ/2)−ε(t−τ/2)]

X(Ω)=∫−τ/2τ/2​Ee−jΩtdt=Ω2E​sin2Ωτ​=EτSa(2Ωτ​)
Sa(x)=xsinx​

这一条是信号完整性的起点：脉冲越窄（τ 越小），频谱越宽。

符号函数：x(t)=sgn(t) 不满足绝对可积，借助奇双边指数信号取极限：

x1​(t)={−eαt,e−αt,​t<0t>0​,sgn(t)=α→0lim​x1​(t)

冲激的频谱是常数——各频率份量均匀，这就是“理想瞬时冲击包含所有频率”的数学说法。

直流：由 δ(Ω) 的反变换反推

F−1[δ(Ω)]=2π1​∫−∞∞​δ(Ω)ejΩtdΩ=2π1​

从而

F[2π1​]=δ(Ω),F[1]=2πδ(Ω)

七、收敛性：为什么方波永远差一点 #

有了系数公式，能不能用有限项拼出原信号？

  • 连续函数的和是连续函数。周期 1、占空比 50% 的开关信号有跳变，不可能用有限个 sin/cos 表示出来。
  • 可微函数的和可微。锯齿波虽然连续，但一阶不可微，同样不行。

结论：只有足够平滑（任意阶可微）的函数才能用有限项精确表示。其余信号必须上无穷级数：

f(t)=k=−∞∑∞​Ck​ej2πkt

只要 $f(t)$ 在一个周期内是有限能量信号，上式就成立——但等号是均方意义下的相等（能量意义收敛），不是逐点相等。逐点相等与否属于收敛性理论，交给数学家。

工程上的实际后果是吉布斯现象（Gibbs phenomenon）：用有限项逼近有跳变的信号时，在跳变点附近会出现约 9% 的过冲，增加项数只会让过冲变窄、不会消失。

这正好解释了一个硬件现象：理想方波在频域上无限宽；把它限制到有限带宽后，时域上就必然出现上升沿、振铃和过冲。不是信号“变坏了”，是带宽砍掉的部分必须还回来。

八、二维：图像的傅立叶变换 #

图像是二维信号，对它做二维离散傅立叶变换（2D DFT）。对 M×N 的图像 $f(x,y)$：

F(u,v)=MN1​x=0∑M−1​y=0∑N−1​f(x,y)e−j2π(Mux​+Nvy​)
f(x,y)=u=0∑M−1​v=0∑N−1​F(u,v)ej2π(Mux​+Nvy​)

归一化系数 MN1​ 有的放在正变换、有的放在反变换、有的两边各放 MN​1​，只是约定不同，不影响结论。

怎么读这张频谱图：

  • $F(u,v)$ 与 $f(x,y)$ 不是一一对应的局部关系。$F(u,v)$ 是整幅图像所有像素与基函数 e−j2π(ux/M+vy/N) 乘积之和，每个频点都用了全部像素。
  • $F(0,0)$ 是所有像素之和（直流分量）。按上面的归一化，F(0,0)=MN1​∑f=fˉ​，即平均亮度。
  • 低频（$u,v$ 靠近 0）对应图像的整体轮廓、大块明暗；高频对应边缘、细节、噪声。
  • 显示频谱时习惯先做 $fftshift$ 把低频挪到中心，再取 log(1+∣F∣) —— 否则动态范围太大，屏幕上只看得见一个亮点。

两种最基本的频域滤波：

操作 频域做法 时域效果
低通（模糊/去噪） 保留中心低频，衰减外围 边缘变软，噪声变小
高通（锐化/边缘提取） 保留外围，衰减中心 只剩轮廓，平坦区变黑

因为时域卷积等于频域相乘（第六节），在频域做乘法，等价于在时域做卷积——这就是所有频域滤波器的合法性来源，也是 FFT 能把 O(N2) 的卷积降到 O(NlogN) 的原因。

九、Hilbert 变换与解析信号 #

1、定义 #

实信号 $x(t)$ 的希尔伯特变换：

x^(t)=x(t)∗πt1​

由第六节那条变换对，它在频域是一个「相位移相器」：

πt1​ ⟷ −jsgn(Ω)

作用效果：正频率分量移相 −90∘，负频率分量移相 +90∘。所以余弦的 Hilbert 变换是正弦。

变换两次：

πt1​∗πt1​ ⟷ (−jsgn(Ω))(−jsgn(Ω))=−1

即两次 Hilbert 变换得到原信号的相反数——这也说明 Hilbert 反变换就是再变一次取负。于是正弦的 Hilbert 变换是负的余弦。

2、解析信号 #

z(t)=x(t)+jx^(t)

频域上：

Z(Ω)=X(Ω)+jX(Ω)sgn(Ω)={2X(Ω),0,​Ω>0Ω<0​

这一步把双边谱变成了单边谱：负频率被抹掉，正频率幅度加倍。对实信号，这样既不丢信息，又只保留一半数据。

3、Hilbert 解调 #

设窄带信号

x(t)=α(t)cos[2πfs​t+φ(t)]

其中 fs​ 是载波频率，α(t) 是包络（也是窄带信号），φ(t) 是相位调制信号。把包络展开：

α(t)=1+m=1∑M​Xm​cos(2πfm​t+γm​)

对 $x(t)$ 做 Hilbert 变换求解析信号 $z(t)$，得

z(t)=ej[2πfs​t+φ(t)][1+m=1∑M​Xm​cos(2πfm​t+γm​)]

记 $A(t)=1+\sum X_m\cos(2\pi f_m t+\gamma_m)$、Φ(t)=2πfs​t+φ(t)，则

z(t)=A(t)ejΦ(t)

解析信号的实部是原信号、虚部是它的 Hilbert 变换。于是：

α(t)=A(t)=x2(t)+x^2(t)​
φ(t)=Φ(t)−2πfs​t=arctanx(t)x^(t)​−2πfs​t

瞬时频率由相位求导得到：

f(t)=2π1​dtdφ(t)​=2π1​dtdΦ(t)​−fs​

一句话总结：窄带信号经过 Hilbert，可以同时解出包络 α(t)、相位 φ(t)、频率 $f(t)$——SSVEP、QRS 波检测、振动分析里的“包络谱”都是这套。工程上对应 scipy.signal.hilbert。
