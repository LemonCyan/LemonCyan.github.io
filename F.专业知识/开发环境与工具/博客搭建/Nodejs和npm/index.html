Nodejs和npm

更新 nodejs 到最新版本 #

卸载自带的 nodejs

cpp
sudo apt autoremove nodejs

cpp
sudo apt purge nodejs

安装 20 版本的 nodejs

cpp
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash - && sudo apt-get install -y nodejs

查看版本是否更新，否则关闭命令行重新打开

nodejs -v

安装 nodejs 安装工具到全局

sudo npm install n -g

安装稳定版本 nodejs

sudo n stable

安装 npm （20 版本） #

注意： 目前 Node.js 的最新 LTS（长期支持）版本是 v20（代号 Iron），它自带的 npm 版本通常是 v10 左右。

以下是安装 Node.js v20（包含对应 npm）的两种最佳方法：

方法一：使用 NodeSource 安装（推荐，最简单） #

这是最直接的方法，适合将其作为系统级软件安装。

  1. 准备环境

确保你的系统已经安装了 curl：

Bash

cpp
sudo apt-get update
sudo apt-get install -y ca-certificates curl gnupg
  1. 添加 Node.js v20 的源

运行以下命令，从 NodeSource 获取 v20 的安装脚本：

Bash

cpp
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -

3. 安装 Node.js (会自动包含 npm)

Bash

cpp
sudo apt-get install -y nodejs
  1. 验证安装

安装完成后，检查版本是否正确：

Bash

cpp
node -v
# 输出应类似: v20.x.x

npm -v
# 输出应类似: 10.x.x

方法二：使用 NVM 安装（适合开发者） #

如果你将来需要在不同版本的 Node.js 之间切换（例如同时开发旧项目和新项目），推荐使用 NVM (Node Version Manager)。

  1. 安装 NVM

运行安装脚本：

Bash

cpp
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash
  1. 激活 NVM

安装后，你需要关闭并重新打开终端，或者运行以下命令让环境变量立即生效：

Bash

cpp
export NVM_DIR="$HOME/.nvm"
[ -s "$NVM_DIR/nvm.sh" ] && \. "$NVM_DIR/nvm.sh"

3. 安装 Node.js v20

Bash

cpp
nvm install 20

4. 设置为默认版本

Bash

cpp
nvm use 20
nvm alias default 20

💡 额外提示：配置国内镜像源 (加速下载) #

如果你在中国大陆，安装完 npm 后，下载包的速度可能会很慢。建议将 npm 源切换到国内镜像（淘宝/阿里云镜像）：

方式 1：直接切换源

Bash

cpp
npm config set registry https://registry.npmmirror.com

方式 2：验证源是否切换成功

Bash

cpp
npm config get registry
# 输出应该是: https://registry.npmmirror.com/
