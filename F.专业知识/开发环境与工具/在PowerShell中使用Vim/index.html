在 PowerShell 中使用 Vim #

闲来无事，买了一个 Win8 系统的小平板，带键盘，准备打造成专门用来写博客的工具（本文就是用它写的第一篇）。捣鼓一圈之后，首先要解决的是用什么看代码。在 PC 时代，习惯了 Linux 命令行的方式，一般都是 Windows 系统 + VMWare 虚拟机 + Linux 系统 + Vim + SecureCRT，但是这个庞大配置，显然不适合小平板。于是我就打起 PowerShell 的主意了。

我想要的无非就是一个命令行的环境，加上 Vim 工具。而微软在 WIN7、WIN8 时，就在系统中集成了一个 Shell 工具——PowerShell。这个工具虽然没有 Linux 系统的 Shell 强大，但相比 Windows 的 Command Line，还是强大不少。那是否可以利用它呢？答案是肯定的。

第一步：安装 Vim #

首先，需要去 Vim 官网下载并安装一个可运行于 Win8 系统的执行文件。

第二步：使能脚本执行 #

然后，设置 PowerShell 环境，使能 "allow scripts to run" 选项，步骤如下：

  1. 以管理员的身份运行 PowerShell；
  2. 执行 Set-ExecutionPolicy RemoteSigned 命令，在对话框中选择 Y。
text
PS C:\Windows\system32> Set-ExecutionPolicy RemoteSigned

执行策略更改
执行策略可帮助你防止执行不信任的脚本。更改执行策略可能会产生安全风险，如
http://go.microsoft.com/fwlink/?LinkID=135170 中的 about_Execution_Policies 帮助主题所述。
是否要更改执行策略?
[Y] 是(Y)  [N] 否(N)  [S] 挂起(S)  [?] 帮助 (默认值为"Y"): Y

PS C:\Windows\system32>

第三步：创建 Profile 配置文件 #

接下来，使用 new-item 命令，创建一个 PowerShell 的配置文件 Profile。

powershell
new-item -path $profile -itemtype file -force

第四步：添加 vim 别名 #

最后，编辑配置文件（notepad $profile），添加 vim 相关的 alias。

powershell
set-alias vim "C:/Program Files/Vim/Vim74/./vim.exe"

# To edit the Powershell Profile
# (Not that I'll remember this)
Function Edit-Profile
{
    vim $profile
}

# To edit Vim settings
Function Edit-Vimrc
{
    vim $HOME\_vimrc
}

重启 PowerShell 后，就可以正常使用了（后续可以按照正常的方式配置 VIM，这里就不多说了）。
