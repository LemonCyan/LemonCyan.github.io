  • 使用项目设置覆盖全局设置

    在项目顶层文件夹下创建.vscode文件夹，并创建settings.json

    json
    "cmake.configureSettings": {
    "CMAKE_PREFIX_PATH": "C:/qt-sdk/build/qt_sdk_msvc_release_static",
    "MY_OPTION_1": true,
    "MY_OPTION_2": "123"
},
"cmake.configureArgs": [
    "-DTESTaaa=ON",
    "-Dbabababa=123",
    "-GNinja"
],
"cmake.debugConfig": {
    "environment": [
        {
            "name": "PATH",
            "value": "${env:PATH};C:/aaa/bin"
        },
        {
            "name": "my_env_var",
            "value": "aaa"
        }
    ]
}

    其中cmake.configureSettings和cmake.configureArgs作用是一样的，只是写法不同，可以只留着一个。
