MinGW 下安装 man 工具包 #

在软件开发方面，我算是一个坚定的 Linux 追随者：vim、make、gcc、man、shell 等等，每一个工具都充满了艺术的气息。因而工作时，电脑都会运行两个操作系统：Windows 是主系统，主要用于日常的邮件收发、文档编写等工作；Linux 运行在虚拟机上，主要负责软件开发。

后来发现 MinGW 这个工具后，可以在 Windows 系统下完成大部分的 Linux 操作，并可以编译生成在 Windows 下执行的二进制文件。因而就渐渐地把开发工作转移至 MinGW，这样就不用再开一个虚拟机了。

可是刚使用 MinGW 时，有一个很不舒服的地方：无法使用 man 命令。要知道，该命令在 Linux 下可是神通广大，上知各种 shell 命令的使用方法，下知各种库函数的参数定义和调用示例（个人感觉，比 Windows 下的 MSDN 好用多了）。所以，我用了一个笨到极致的方法：开着虚拟机，就是为了使用 Linux 系统里面的 man 命令！

突然有一天，我想，难道在 MinGW 下真的不能使用 man 吗？毫无疑问，是可以的。下面我就简单说明一下怎么在 MinGW 下使用 man 命令。

1. 使用 mingw-get 安装 msys-man package #

bash
[xxx@xxx ~]# mingw-get install msys-man

安装成功后，使用 man man 命令，测试是否安装成功。

2. 下载最新版本的 man 手册 #

下载链接如下：https://www.kernel.org/pub/linux/docs/man-pages/

写这篇文章时，版本为 3.56：man-pages-3.56.tar.gz。

3. 在 MinGW shell 中，解压 man 手册，并编译安装 #

bash
tar zxvf man-pages-3.56.tar.gz
cd man-pages-3.56
make
make install

4. 安装成功后，测试 #

bash
man vfork

Yeah，成功了。
