16通道 EEG

在脑机接口（BCI）与生物电信号处理领域，外行往往关注后端的模式识别算法与深度学习解码，而真正决定系统可用性上限的，是模拟前端那几微伏到几十微伏的微弱生理电信号。

16 通道是一个经过工程实践检验的平衡点：它既能完整覆盖国际 10-20 系统的核心脑区（全面兼顾运动想象的感觉运动区 C3​/C4​/Cz​ 以及 SSVEP 的枕叶区 O1​/Oz​/O2​），又没有将模拟前端的布线密度、通道间串扰与电源共模抑制比（CMRR）推向失控的边缘。

两类的核心电极（国际 10-20 系统命名）如下：

**运动想象 / 感觉运动区（μ 节律 8–12 Hz、β 节律）**
- 核心三导：**C3、Cz、C4**
  - C3：右手（左脑对侧）ERD 最显著
  - C4：左手（右脑对侧）ERD 最显著
  - Cz：双脚/舌等中线部位想象时的关键点
- 常用扩展：FC3/FC4、FCz、CP3/CP4、CPz、C1/C2（提高空间分辨率与 CSP 滤波效果）

**SSVEP（枕叶视觉区）**
- 核心三导：**O1、Oz、O2**
- 常用扩展：**POz**（信噪比往往最高）、PO3/PO4、Pz、PO5/PO6、Oz 邻近的 O1/O2 交织位

**要点对比**
- 运动想象：信号源在中央沟两侧，电极必须贴近 C 系列（C3/Cz/C4 为最小集），扩展朝向 FC/CP 环。
- SSVEP：信号源在枕叶视觉皮层，电极必须覆盖 O 系列，且 POz/POz 附近的枕顶区常比纯 Oz 更强。

本文从芯片选型权衡、两片 ADS1299 硬件级联拓扑、输入抗混叠与电容微音效应抑制、低噪声模拟电源树设计，讲到 MCU 固件时序调度与上位机数据校验，完整呈现一套低成本、高精度的 16 通道 EEG 采集系统设计。

1. 系统整体架构与选型权衡 #

1.1 硬件全链路拓扑设计 #

1.2 为什么选择 ADS1299 而非分立方案 #

头皮脑电信号的主频集中在 $0.5 \sim 100\text{ Hz}$，幅值通常仅有 $10 \sim 100\ \mu V$。在未经屏蔽的普通室内环境下，电网辐射引入的 50 Hz 工频干扰电压可高达数伏，比脑电信号大上万倍。

若采用传统分立方案（低噪声仪表放大器 INA + 多阶有源带通滤波器 + 多通道逐次逼近型 SAR ADC）：

  1. 增益与相位失配严重：分立电阻电容的容差（即使用 0.1% 精度电阻）会导致 16 个通道间的共模抑制比崩塌，通道间相位差随频率漂移，严重损害空间滤波（如 CSP 与多导联 CCA）的性能。
  2. 板级面积与功耗受限：16 通道意味着需要 16 组独立仪放与滤波网络，PCB 走线极其复杂，极易引入寄生耦合。

TI 推出的 ADS1299 是专为脑电测量设计的 24 位高分辨率 ΔΣ 模数转换芯片：

  • 单片集成 8 通道低噪声可编程增益放大器（PGA）与 24 位 ADC。
  • 在最高增益（Gain=24）、250 SPS 采样率下，输入参考噪声低至 1.0 μVpp​（0.14 μVrms​）。
  • 内部集成偏置驱动放大器（用于右腿驱动 RLD），可动态提取各通道共模电位并反相注入人体，将整机工频共模抑制比提升 20 dB 以上。

1.3 主控选型：ATmega328P 的可行性边界与 STM32 演进 #

许多开发者直觉上认为 ATmega328P（16MHz 主频、2KB SRAM）性能孱弱，难以承担 16 通道高精度采集。但从数据通量与通信开销的实际计算来看，它完全能够胜任基础推流任务：

  • 采样通量计算： 在 250 SPS 采样率下，16 个通道均采用 24 位（3 字节）量化： $$\text{净数据率} = 16 \times 3 \times 250 = 12,000\text{ 字节/秒}$$ 加上 4 字节协议开销（帧头、帧计数、校验和），整机每秒传输： $$(16 \times 3 + 4) \times 250 = 13,000\text{ 字节/秒} = 130\text{ kbps} \text{（含 UART 起止位）}$$
  • ATmega328P 的硬件 SPI 运行在 4 MHz 时钟下，读取单片 24 字节数据耗时约 48 μs；两片读取总耗时不足 100 μs，仅占 250 SPS 采样周期（4000 μs）的 2.5%。

选型决策界限：

  • 选用 ATmega328P：适用于快速搭型、低功耗电池便携系统、纯透传流式采集系统，开发与固件烧录门槛低。
  • 必须升级至 STM32F103/STM32G4：若系统需要在板卡端执行实时电极接触阻抗测量、板上 50Hz 数字陷波、或采样率需提升至 $1\text{ kSPS} \sim 4\text{ kSPS}$，必须切换到支持双 SPI + DMA 硬件搬运的高性能 MCU。

2. 核心硬件电路设计与关键参数计算 #

2.1 两片 ADS1299 级联的具体拓扑 #

要实现 16 通道采集，必须使用两颗 ADS1299。级联方案有两种拓扑：菊花链模式（Daisy-Chain）与独立片选并行模式（Parallel SPI）。

工程实战中强烈推荐独立片选并行模式。菊花链模式下只要一颗芯片时序错位，整个 64 字节串行链全部损坏且极难排查；并行模式下每片数据独立，容错率高。

具体引脚级联连接细则：

  1. 时钟同步（核心）：主芯片的 CLKSEL 引脚接高电平使能内部振荡器，软件配置寄存器使能时钟输出，从主芯片的 CLK 引脚输出 2.048 MHz 方波；从芯片的 CLKSEL 引脚接地（选择外部时钟），其 CLK 引脚直接连接主芯片的 CLK 引脚。两片芯片共用物理时钟源，彻底杜绝不同晶振微小频差引起的采样相位漂移。
  2. 转换启动同步：两片芯片的 START 硬件引脚必须并联连接至 MCU 的同一个 GPIO 引脚。通过单一硬件跳变沿同时触发两颗芯片内部转换计数器。
  3. 数据就绪同步：在共享时钟与同时启动前提下，两颗芯片的数据转换时刻完全一致（相差 $< 1$ 个时钟周期）。只需将主芯片的 DRDY 引脚连接至 MCU 的外部中断引脚（INT0），从芯片的 DRDY 悬空即可。
  4. 右腿偏置（BIAS）处理：仅启用主芯片内部的 BIAS 放大器并引出至反馈网络，从芯片的 BIASOUT 引脚悬空。从芯片中各通道的共模采样电位通过外部总线汇入主芯片的 BIASINV 端。

2.2 模拟前端差模与共模滤波网络参数计算 #

每个电极输入端必须配置 RC 抗混叠与静电防护网络：

参数设计依据与计算推导：

  • 串联限流电阻 $R$：取 $R_1 = R_2 = 10\text{ k}\Omega$。ADS1299 在增益为 24 时直流输入阻抗约为 1000 MΩ，交流输入阻抗约为 100 MΩ。10 kΩ 电阻引入的信号衰减仅为 0.01%，完全可以忽略；同时配合芯片内部保护二极管，能够吸收人体静电放电（ESD）的大部分冲击能量。
  • 共模电容 Ccm​ 与差模电容 Cdiff​：取 $C_{\text{cm}} = 100\text{ nF}$，$C_{\text{diff}} = 47\text{ nF}$。
    • 共模低通截止频率： $$f_{c,\text{cm}} = \frac{1}{2\pi R C_{\text{cm}}} = \frac{1}{2\pi \times 10^4 \times 100 \times 10^{-9}} \approx 159.1\text{ Hz}$$
    • 差模低通截止频率： $$f_{c,\text{diff}} = \frac{1}{2\pi R (2C_{\text{diff}} + C_{\text{cm}})} = \frac{1}{2\pi \times 10^4 \times (2 \times 47 + 100) \times 10^{-9}} \approx 82.0\text{ Hz}$$
  • 电容介质选型硬性要求： 所有模拟前端滤波电容必须选用 C0G (NP0) 材质。严禁在微伏级信号链路上采用常见的 X7R 或 Y5V 材质贴片电容！X7R 陶瓷介质具有显著的压电效应（Piezoelectric Effect），外界轻微的机械振动、轻敲桌面甚至电缆摇晃，都会使电容产生微伏级的压电电荷，在脑电图谱上表现为剧烈的低频运动伪迹。

2.3 双极性超低噪声电源树与接地分割 #

ADS1299 的内部 ADC 性能对模拟电源纹波极其敏感。推荐采用 ±2.5 V 双极性模拟供电（$\text{AVDD} = +2.5\text{ V}$，$\text{AVSS} = -2.5\text{ V}$），数字部分采用 +3.3 V 供电（$\text{DVDD} = +3.3\text{ V}$）。

双极性供电的巨大工程优势在于：输入电极能够以系统模拟地（AGND）为参考点上下对称摆动，无需在输入端加入复杂的共模抬升分压偏置电路。

电源方案设计与接地要点：

  1. LDO 选型：模拟正负轨选用超低噪声低压差线性稳压器（如 TI LP2985-2.5 或 TPS72301 / TPS73201），基准噪声控制在 10 μVrms​ 级别。
  2. 避免开关电源直供：严禁直接使用 DCDC 开关电源或无滤波的电荷泵芯片驱动 AVDD/AVSS。若使用电荷泵生成负压，必须在后级插入 π 型 LC 滤波网络（10 μH 屏蔽电感 $+ 22\ \mu F$ 钽电容）后再输入 LDO。
  3. 单点接地（Star Grounding）：PCB 布局严禁将模拟地（AGND）与数字地（DGND）大面积混合大铜皮直铺。应在物理布局上将板卡清晰划分为模拟区与数字区，SPI 走线严禁跨越模拟敏感走线，AGND 与 DGND 仅在两颗 ADS1299 下方的模拟接地中心通过一颗 0 Ω 贴片电阻（或磁珠）实施单点汇流。

2.4 数据手册中未明说的配置盲区 #

  1. 内部 4.5V 参考电压的纹波陷阱： 数据手册标注支持内部 4.5 V 独立参考源。但内部参考发生器的共模抑制性能较差，若 AVDD−AVSS 轨上存在微小纹波，该纹波会直接调制到参考基准上，导致 ADC 全量程增益随电源噪声抖动。在追求极致低噪声时，应在 VREFP 与 VREFN 引脚之间并联一颗 10 μF 钽电容与一颗 100 nF 优质高频陶瓷电容。
  2. 输入偏置电流温漂与电极极化： 电极长时间浸泡在导电膏中会产生微弱的直流极化电压（数十毫伏）。若没有直流泄放通路，极化电荷会逐渐在输入电容上累积直至运放输入轨饱和。在每个输入端对模拟地（AGND）并联一颗 $1\text{ M}\Omega \sim 10\text{ M}\Omega$ 的高阻抗弱泄放电阻，能够显著抑制基线长周期慢漂。

3. 固件架构与实时数据流传输 #

3.1 SPI 模式 1 时序配置与片选隔离 #

ADS1299 的 SPI 物理层工作在 Mode 1（$\text{CPOL} = 0, \text{CPHA} = 1$），即空闲时 SCLK 为低电平，数据在 SCLK 下降沿采样、上升沿移位更新。

ATmega328P 寄存器初始化及分时片选读取逻辑：

c
#include <avr/io.h>
#include <avr/interrupt.h>
#include <util/delay.h>

#define CS1_PIN   PORTB2  // 主芯片片选 (Pin 10)
#define CS2_PIN   PORTB1  // 从芯片片选 (Pin 9)
#define START_PIN PORTD4  // 并联启动引脚 (Pin 4)

void SPI_Master_Init(void) {
    // 设置 MOSI, SCK, SS 为输出引脚
    DDRB |= (1 << DDB3) | (1 << DDB5) | (1 << DDB2) | (1 << DDB1);
    DDRD |= (1 << DDD4); // START 引脚设为输出

    // 默认片选拉高无效
    PORTB |= (1 << CS1_PIN) | (1 << CS2_PIN);

    // 使能 SPI, 设置为主机模式, 模式1 (CPOL=0, CPHA=1), 时钟分频 = 4 (4MHz)
    SPCR = (1 << SPE) | (1 << MSTR) | (1 << CPHA) | (0 << SPR1) | (0 << SPR0);
    SPSR = (0 << SPI2X); // 正常时钟速度
}

uint8_t SPI_Transfer(uint8_t data) {
    SPDR = data;
    while (!(SPSR & (1 << SPIF))); // 等待硬件传输完毕
    return SPDR;
}

3.2 24 位补码向 32 位有符号整数的高效转换 #

ADS1299 输出的数据为 24 位二进制补码（Big-Endian，MSB 在前）。在 8 位 AVR 单片机上执行位拼接时，若直接使用普通移位运算会导致高位符号丢失。必须对最高有效位（Bit 23）进行符号位扩展（Sign Extension）：

c
int32_t Parse_24Bit_Signed(uint8_t b_msb, uint8_t b_mid, uint8_t b_lsb) {
    // // ← 关键处理: 拼装成32位并强制符号扩展，避免负电压出现截断错误
    int32_t val = ((int32_t)b_msb << 16) | ((int32_t)b_mid << 8) | ((int32_t)b_lsb);
    if (val & 0x800000) {
        val |= 0xFF000000; // 负数补齐前导 1
    }
    return val;
}

在增益 Gain=24、$V_{\text{REF}} = 4.5\text{ V}$ 配置下，最低有效位（LSB）对应的物理电压标量常数为：

Scale=Gain×(223−1)VREF​​=24×8,388,6074.5​≈22.3517 nV/LSB

3.3 环形缓冲队列与波特率精细化核算 #

很多系统在提升至 16 通道后出现数据丢帧，其核心原因往往不是 SPI 读取过慢，而是串口发送带宽与缓冲区设计失误。

数据帧设计与波特率校验：

  • 数据帧格式： [0xAA 0x55] (帧头, 2B) + [帧序号] (1B) + [16通道数据 × 3B] (48B) + [校验和 XOR] (1B) = 52 字节/帧
  • 采样率 250 SPS 下的通量计算： $$52\text{ 字节/帧} \times 250\text{ 帧/秒} = 13,000\text{ 字节/秒}$$ UART 通信包含 1 个起始位、8 个数据位、1 个停止位（每字节开销 10 位）。 $$\text{最小物理波特率需求} = 13,000 \times 10 = 130,000\text{ bps}$$

标准波特率 115200 bps 的理论上限仅能承载 $11,520\text{ 字节/秒}$，直连运行必然发生缓冲区溢出丢帧！ 因此硬件串口波特率必须配置为 230400 bps（有效吞吐量可达 $23,040\text{ 字节/秒}$），留有充裕的带宽余量。

单片机完整中断采集与转发架构代码：

c
#define FRAME_HEADER_1 0xAA
#define FRAME_HEADER_2 0x55

volatile uint8_t sample_pending = 0;
uint8_t frame_seq = 0;
uint8_t tx_packet[52];

// INT0 外部中断：主 ADS1299 的 DRDY 引脚下降沿触发
ISR(INT0_vect) {
    sample_pending = 1;
}

void Read_16Ch_Data(void) {
    uint8_t ch_buf[48];
    uint8_t checksum = 0;

    // 1. 读取主芯片 8 个通道 (CH 1-8)
    PORTB &= ~(1 << CS1_PIN); // CS1 拉低
    _delay_us(2);
    // 跳过 24 位芯片状态字 (Status Word)
    SPI_Transfer(0x00); SPI_Transfer(0x00); SPI_Transfer(0x00);
    for (uint8_t i = 0; i < 24; i++) {
        ch_buf[i] = SPI_Transfer(0x00);
    }
    PORTB |= (1 << CS1_PIN);  // CS1 拉高

    _delay_us(2);

    // 2. 读取从芯片 8 个通道 (CH 9-16)
    PORTB &= ~(1 << CS2_PIN); // CS2 拉低
    _delay_us(2);
    // 跳过从芯片状态字
    SPI_Transfer(0x00); SPI_Transfer(0x00); SPI_Transfer(0x00);
    for (uint8_t i = 24; i < 48; i++) {
        ch_buf[i] = SPI_Transfer(0x00);
    }
    PORTB |= (1 << CS2_PIN);  // CS2 拉高

    // 3. 打包数据帧
    tx_packet[0] = FRAME_HEADER_1;
    tx_packet[1] = FRAME_HEADER_2;
    tx_packet[2] = frame_seq++;
    checksum = tx_packet[2];

    for (uint8_t i = 0; i < 48; i++) {
        tx_packet[3 + i] = ch_buf[i];
        checksum ^= ch_buf[i];
    }
    tx_packet[51] = checksum;

    // 4. 发送至串口发送缓冲区
    for (uint8_t i = 0; i < 52; i++) {
        while (!(UCSR0A & (1 << UDRE0))); // 等待串口缓冲区就绪
        UDR0 = tx_packet[i];
    }
}

int main(void) {
    SPI_Master_Init();
    // 初始化串口波特率 230400 bps (16MHz 晶振, U2X0=1 时 UBRR0=8)
    UCSR0A |= (1 << U2X0);
    UBRR0 = 8;
    UCSR0B = (1 << TXEN0);

    // 配置 INT0 下降沿触发中断
    EICRA |= (1 << ISC01) | (0 << ISC00);
    EIMSK |= (1 << INT0);

    // 启动芯片转换
    PORTD |= (1 << START_PIN);
    sei();

    while (1) {
        if (sample_pending) {
            sample_pending = 0;
            Read_16Ch_Data();
        }
    }
}

4. 上位机 Python 解析与实时滤波验证 #

上位机负责监听串口、执行校验和解析，将原始数据恢复为以微伏（μV）为单位的浮点数组，并施加 50Hz 陷波器与带通滤波器。

python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
16 通道 ADS1299 上位机实时数据流解析模块
包含二进制反序列化、异或校验和验证、微伏转换与带通滤波管道
"""

import serial
import struct
import numpy as np
from scipy.signal import iirnotch, butter, lfilter


class ADS1299StreamParser:
    FRAME_HEADER = b"\xAA\x55"
    FRAME_SIZE = 52
    SCALE_UV = (4.5 / (24 * (2**23 - 1))) * 1e6  # 转换系数，转换为微伏 (uV)

    def __init__(self, port="COM4", baudrate=230400):
        self.ser = serial.Serial(port, baudrate, timeout=1.0)
        self.buffer = bytearray()
        
        # 预设 250Hz 下的 50Hz 陷波滤波器系数
        self.b_notch, self.a_notch = iirnotch(50.0, 30.0, 250.0)

    def read_samples(self, target_samples=250):
        """同步读取指定样本数量的 16 通道微伏矩阵"""
        samples_collected = []

        while len(samples_collected) < target_samples:
            raw_data = self.ser.read(self.ser.in_waiting or 1024)
            if not raw_data:
                continue
            self.buffer.extend(raw_data)

            # 遍历缓冲区寻找合法帧
            while len(self.buffer) >= self.FRAME_SIZE:
                # 寻找帧头 0xAA 0x55
                idx = self.buffer.find(self.FRAME_HEADER)
                if idx == -1:
                    self.buffer.clear()
                    break
                if idx > 0:
                    del self.buffer[:idx]  # 丢弃帧头前的残留碎片

                if len(self.buffer) < self.FRAME_SIZE:
                    break  # 剩余字节不够一整帧，等待下一次接收

                packet = self.buffer[:self.FRAME_SIZE]
                seq = packet[2]
                payload = packet[3:51]
                expected_cksum = packet[51]

                # 校验和判定 (XOR)
                cksum = seq
                for b in payload:
                    cksum ^= b

                if cksum == expected_cksum:
                    # 解析 16 通道 24 位有符号整型
                    channels_uv = []
                    for ch in range(16):
                        b0, b1, b2 = payload[ch * 3 : ch * 3 + 3]
                        raw_int = (b0 << 16) | (b1 << 8) | b2
                        if raw_int & 0x800000:
                            raw_int -= 0x1000000  # 符号位扩展
                        channels_uv.append(raw_int * self.SCALE_UV)

                    samples_collected.append(channels_uv)
                    del self.buffer[:self.FRAME_SIZE]
                else:
                    # 校验失败，滑动 1 字节重新定位帧头
                    del self.buffer[:1]

        data_array = np.array(samples_collected).T  # 转换为 (16, target_samples) 形状
        # 执行 50Hz 工频陷波
        filtered_data = lfilter(self.b_notch, self.a_notch, data_array, axis=1)
        return filtered_data

    def close(self):
        if self.ser.is_open:
            self.ser.close()

5. 调试避坑指南与典型失效模式 #

在调试微伏级采集板卡时，很多工程现象极其反直觉。以下归纳一线实操中最容易遭遇的五个典型陷阱：

5.1 排查法则：电源、地平面、电极、时序的四步隔离 #

遇到波形满偏、噪声淹没有效波形时，严格按照以下优先级定位：

  1. 测供电轨纯净度：用示波器交流耦合档测量 AVDD 与 AVSS 引脚，纹波峰峰值应 <1 mV。若看到开关电源的尖峰脉冲，必须先解决前级电源滤波。
  2. 测地平面电位差：用示波器测量模拟地（AGND）与数字地（DGND）引脚之间的交直流压差，该压差应 $< 100\ \mu V$。若压差过大，说明单点接地走线过长或接地回路被大电流分割。
  3. 测电极接触阻抗：电极脱落或导电膏干涸会导致等效接触阻抗升高至数十千欧以上，外界工频辐射在电极阻抗上的分压会直接打满前置放大器。
  4. 查 SPI 逻辑分析仪波形：排查 SCLK 与 CS 的建立时间。ADS1299 要求 CS 拉低后必须至少经过 6 个时钟周期方可发送第一个 SPI 字节。
