数据库mysql转为postgresql变动

数据库 mysql 转为 postgresql 变动 #

因为工作需要，项目以前使用的 mysql 数据，现在需要更改为 postgresql。

一、MYSQL 转 PG #

利用 navicat：工具->数据传输直接将 mysql 库->postgresql 库，变动：

  • navicat 转换后的 sql，会丢失默认值

官网找到一个工具 Mysql 转 PostgreSQL，这个工具官方是付费的，貌似是专门做异构数据库转换的。限制是单表只能转 50 条数据，表无限制。

使用 navicat:工具->数据传输直接将数据从 mysql 同步到 pg 即可。

二、DDL 变动 #

MYSQL:

sql
ALTER TABLE table_name MODIFY COLUMN column_name datatype

pg：

sql
ALTER TABLE table_name ALTER COLUMN  column_name TYPE datatype

mysql->pg：

tinyint->int

datetime->timestamp

三、DML 变动 #

postgresql string 的列不能用 integer 的值查，mysql 可以自动转；

数据表中字段如果有大写的话，pg 查询语句是需要加双引号的，因此创建数据表的时候字段最好采用下划线的方式：

sql
select id,"loginName" from user;

参考;PostgreSQL 与 MySQL 的日期类型 DATE/date 的格式区别

更多 sql 实现和标准 sql 区别可以查看 https://www.runoob.com/sql/sql-tutorial.html。

四、如何将 mysql 列名从驼峰修改为下划线 #

由于历史原因，在创建数据表的时候，表字段采用了驼峰命名，如何将命名规则转为带有下划线的呢？

我们可以通过如下命令查询一个数据库下有哪些字段：

sql
select * from information_schema.columns where table_schema='blog'

结果如下：

我们可以编写 python 脚本，根据表名、旧的字段名，属性信息，以及新的列名，然后生成批量修改列名的脚本。每一条修改语句类似：

sql
ALTER TABLE `table_name` CHANGE `$old_column_name` `new_column_name` VARCHAR(40) null default "xxx" comment "comment"

需要注意的是：

该条语句不会更改原有的索引。

python 脚本如下：

python
import pymysql


class MySqlTransform(object):
    """
    将mysql数据库auth库中的所有表中驼峰格式的字段转为下划线命名
    """
    def __init__(self, host, port, user, password,database):
        # 数据库配置
        self.__conn = None
        self.__MYSQL_CONFIG = {
            'user': user,
            'port': port,
            'host': host,
            'password': password,
            'database': database
        }

        self.__cur = self.__get_connect()

    def __get_connect(self):
        # 建立连接
        self.__conn = pymysql.connect(**self.__MYSQL_CONFIG)
        # 使用cursor()方法获取操作游标
        cur = self.__conn.cursor()
        if not cur:
            raise (NameError, "连接数据库失败")
        else:
            return cur

    def __del__(self):
        """
        析构
        """
        if self.__conn:
            self.__conn.close()

    def exec_query(self, sql):
        """
        执行查询语句
        """
        self.__cur.execute(sql)
        return self.__cur


# 驼峰转下划线 ID=>id  loginName => login_name
def camel_to_underline(text):
    lst = []
    last_supper_index = None
    for index, char in enumerate(text):
        if char.isupper():
            if index != 0 and (last_supper_index == None or last_supper_index + 1 != index):
                lst.append("_")
            last_supper_index = index
        lst.append(char)

    return "".join(lst).lower()


def transform_sql_column(item=None):
    database = "blog"
    sql = "select * from information_schema.columns where table_schema='{}';".format(database)

    mysql = MySqlTransform("127.0.0.1", 3306, "root", "123456",database)
    cur = mysql.exec_query(sql)
    res = cur.fetchall()
    for index, item in enumerate(res):
        table_name = item[2]
        old_column_name = item[3]
        new_column_name = camel_to_underline(old_column_name)
        column_type = item[15]
        column_null = 'null' if item[6] == 'YES' else 'not null'
        column_defult = '' if item[5] is None else 'default {}'.format(item[5])
        column_comment = item[19]
        if old_column_name == new_column_name:
            continue
        # 分割
        sql = 'alter table {} change column {} {} {} {} {} comment "{}";'.format(table_name,old_column_name,new_column_name, column_type, column_null, column_defult, column_comment)
        print(sql)


if __name__ == '__main__':
    transform_sql_column()
