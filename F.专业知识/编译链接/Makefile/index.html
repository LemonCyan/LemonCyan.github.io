2.多个文件生成单个模块 #

3.多个文件生成多个模块 #

二、Makefile的三次执行 #

1.在当前目录敲下make，执行makefile，判断KERNELRELEASE是否被定义，未被定义则进入else语句（为KDIR（内核源码树）和 #

PWD（当前文件夹）赋值），同时执行target all的指令， make -C 进入内核源码树目录，同时依据内核源码顶层目录下的Makefile来定义KERNELRELEASE

2.之后会回到PWD（当前目录），将hello.c变异生成hello.o文件，之后跳转到内核源码树，搜集所需要的目标文件。 #

3.最后回到PWD（当前目录），将hello.o生成hello.ko文件 #
