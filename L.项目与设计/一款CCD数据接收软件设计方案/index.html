一款CCD数据接收软件设计方案

TCD1304

竞品

jingpin

高灵敏线阵图像传感器模组

  1. 串口/USB 口通訊
  2. 支持外部触发输入输出
  3. 支持 TTL，UART，RS485，支持外部触发，可调模拟电压输出，Trigger 输出，光源控制；
  4. 支持 Windows、Linux
  5. 用途光谱分析、紫外光谱、近红外光谱、图像识别、遥感检测、工业测量

  • UART RX 串口数据接口端口（3.3V）

  • UART TX 串口数据収送端口（3.3V）

  • Trigger In1 单次外部触収输入（3.3V）

  • Trigger In2 连续外部触収输入（3.3V）

  • Sync 同步信号输出，5V 电平

  • Trigger 可编程输出，5V 电平

  • Analog Out 0-5V，可编程电压输出

  • Trigger In1：在脉冲上升沿时刻开始采集当前图像，采集完成则自动输出图像，曝光时间 MCU 控制,默认高电平，下降沿触发。

  • Trigger In2：外触发引脚，3.3V 电平，最大 5V，PWM 脉冲输入模式，高电平持续时间为 CCD 的积分时间，低电平时间是采集和传输时间，低电平时间最小需持续 4ms，高电平最小需持续 10us。

  • Sync：输出传感器的同步触发信号，正脉冲输出，上升沿图像传感器电子快门打开，传感器开始积分，高电平持续时间为曝光时间，可直接接氙灯的 trig 引脚。

  • Trigger Out2：可编程输出，提供了控制接口，用户可通过软件控制该端口的输出状态。

  • Analog Out：可编程模拟电压输出接口，0-5V 的电压范围，分辨率 1.2mV。

软件功能：

  • 连续/单次/暂停获取图像。

  • 设置曝光时间。

  • 设置平均次数，采集多幅图像平均后输出一幅，有利于提高稳定性、信噪比。

  • 设置平滑度。

  • 设置采样间隔，0-65535ms，间隔时间越长，帧率越慢。

  • 获取背景光谱，减去背景光谱。

  • 图像自动缩放。

  • 存储当前光谱数据。

  • 硬件信息，依次为硬件版本号，传感器型号，固件版本号，序列号。

  • 当前的传输帧率和显示帧率。

  • 硬触发模式

  • Single trigger ：单次触収，输入单个脉冲

  • Continuous trigger：连续触収，输入连续触収脉冲，可控制曝光时间。

  • 模拟端口电压输出值，分辨率 0.1V。

  • Trigger2 引脚输出电平控制，0V，和 5V。

  • 读叏和设置 TTL 端口的串口波特率，自动保存到 flash，上电后自动加载设定值。

  • 设置图像增益和基线偏移量，Offset 值-254 到+254，真值图像基线上移，反之下移。

  • 获叏和保存以上参数。

  • 每个像素对应的坐标值，每个值占 16bit

  • 获叏，和写入 X 坐标数据，等待写入后，重新上电，重新打开软件，清除文本框中内容，Get 数据，如果和写入数据丌一致，点击 Erase 按键，擦除 flash 后重复以上操作。注意要先写坐标数据，然后保存配置参数。

  • Sync 引脚控制，选中后输出同步脉冲，反之关闭同步脉冲输出功能

  • 切换 X 坐标单位 Wavelenght，Ramanshift，Wavenumber，波长，拉曼位移，波数，分别对应矫正数据 1,2,3,本 demo 用的还是 3 次拟合的方法，如波长转换算法： for(int i=0;i<2048;i++){double wavelength = f0*i^3+f1*i^2+f2*i+f3;}

  • 连续采集模式

  • 单次采集模式

  • 暂停采集

  • 积分时间(TIME)设置 Byte 2：积分时间的高 8 位 Byte 3：积分时间的低 8 位

  • 积分时间(UNIT)单位设置 Byte 2：积分时间单位 0x00:ms ，0x01：us

  • 触发模式(HARD TRIGGER)设置 Byte 2： 0：软触发 1：外部连续脉冲触发，Trigger In2 引脚 2：外部单脉冲触发 ，对应 Trigger In1 引脚

  • 模拟电压输出(ANALOG)设置 Byte 2： 电压值 0-5000mV 的高 8 位 Byte 3： 电压值 0-5000mV 的低 8 位

  • TRIGGER OUT 输出设置 Byte 2： 1：Trigger Out 引脚输出高电平，5V 0：Trigger Out 引脚输出高电平，0V

  • 同步信号输出（OUTPUT SYNC SIGNAL）设置 Byte 2： 1：使能输出同步信号 0：禁止输出同步信号

  • 获取积分时间(TIME) Byte 2：积分时间的高 8 位 Byte 3：积分时间的低 8 位

  • 获取积分时间单位(UNIT) Byte 2：积分时间单位 0x00:ms ，0x01：us

  • 获取版本信息(HDINFO.)

  • 触发间隔（INTERVAL）设置 DATA1： 间隔时间高 8 位 DATA2：间隔时间低 8 位

  • 获取触发间隔（INTERVAL） DATA1： 间隔时间高 8 位 DATA2：间隔时间低 8 位

  • 平滑（SMOOTH）等级设置 Byte 2： 有效值 1-10

  • 获取平滑（SMOOTH）等级 Byte 2：平滑等级

  • 平均次数(AVG)设置 Byte 2： 有效值 1-255

  • 获取平均次数(AVG) Byte 2：平均次数，范围 1-255

  • TTL 串口波特率（TTL SERIAL/RS485 BAUD RATE）设置 Byte 2： 有效值 1-5 1：波特率 115200，2：波特率 384000，3：波特率 921600 5: 波特率 3686400

  • 获取 TTL 串口波特率（TTL SERIAL/RS485 BAUD RATE）

  • 增益（GAIN）设置 Byte 2： 0-255

  • 获取增益（GAIN） Byte 2： 增益值

  • 偏移（OFFSET）设置 Byte 2： 数据位 0-255 Byte 3： 符号位，0：负值，1：正值

  • 获取偏移（OFFSET） Byte 2： 数据位 0-255 Byte 3： 符号位，0：负值，1：正值

  • 水平镜像（MIRROR）设置 Byte 2： 0x00： 正常输出 ; 0x01 : 水平镜像输出

  • 水平镜像状态读取（MIRROR） Byte 2： 0x00： 正常输出 ; 0x01 : 水平镜像输出

  • RS485 ID（RS485）设置 Byte 2： 0-255 RS485 ID

  • RS485 ID（RS485）读取 Byte 2： 0-255 RS485 ID

  • 保存参数

  • WRITE：写入 X 坐标值 DATA：2048 个像素坐标值对应的无符号整型 16 进制数，每个数 2 个 byte，高位在前，数据长度 4096bytes。

  • READ：读取 X 坐标值 DATA：2048 个像素坐标值对应的无符号整型 16 进制数，每个数 2 个 byte，高位在前，数据长度 4096bytes。

  • 写入矫正系数 DATA1：矫正系数编号，可以写入 3 组，分别取值 0x01, 0x02, 0x03。 DATA2: 矫正系数数据，64 bytes。

  • 获取矫正系数 DATA1：矫正系数编号，值 0x01, 0x02, 0x03，分别读取对应数据。 DATA2: 矫正系数数据，64 bytes。
