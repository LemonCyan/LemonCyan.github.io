# Anti-patterns

## AP1 – Monolithic Prompt

Never place all logic into a single system prompt.

## AP2 – Magic Fix

Do not rely on "the AI will probably fix it next time".

## AP3 – Silent Overwrite

Never overwrite user code without diff or backup.

## AP4 – Spec Drift

Specs must not be silently ignored to make generation easier.

# 反模式

## AP1 — 单一提示巨构  
切勿将全部逻辑堆砌于单一系统提示中。

## AP2 — 神奇修复幻想  
切勿寄望“AI 下次大概会自行修正”。

## AP3 — 静默覆盖  
切勿在无差异比对或备份的前提下，擅自覆盖用户代码。

## AP4 — 规范偏移  
绝不可为简化生成过程而悄然忽视规格要求。

# 二、assemble.py —— Prompt 组合器

> 目标：把各个 `modules/*.md` 拼接成 `system.current`，保证：
> - 顺序可控
> - 可添加 hash / 版本  
> - 可在 CI/CD 自动生成  
> - 支持 unit test



## 1️⃣ 工程级 assemble.py 示例

```python
import os
import hashlib

MODULE_DIR = "prompt/modules"
SYSTEM_DIR = "prompt/system"
MODULE_ORDER = [
    "role.md",
    "constraints.md",
    "output_format.md",
    "diff_rules.md",
    "safety.md"
]

def load_module(module_name):
    path = os.path.join(MODULE_DIR, module_name)
    with open(path, "r", encoding="utf-8") as f:
        return f.read().strip()

def compute_hash(text):
    """计算内容哈希，用于版本管理或回归测试"""
    return hashlib.sha256(text.encode("utf-8")).hexdigest()

def assemble_system():
    """组合所有模块生成 system.current"""
    content = "\n\n".join(load_module(m) for m in MODULE_ORDER)
    # 写入 system.current
    os.makedirs(SYSTEM_DIR, exist_ok=True)
    current_path = os.path.join(SYSTEM_DIR, "system.current")
    with open(current_path, "w", encoding="utf-8") as f:
        f.write(content)
    # 返回内容和 hash
    return content, compute_hash(content)

if __name__ == "__main__":
    content, h = assemble_system()
    print(f"System prompt assembled, SHA256: {h}")

2️⃣ 工程级补充说明 #

  1. 模块顺序可控
    • role.md 必须最前，constraints.md 紧随其后
    • output_format.md 在 parser 之前
  2. 生成的 system.current 是单一入口
    • Engine / AI client 只读取 system.current
  3. hash 校验

  4. 可扩展

  5. 可测试

    • 可以写 snapshot 测试，确保系统行为可追踪

四、engine.py —— 执行引擎入口（核心） #

🎯 职责 #

  • 启动一次任务流
  • 串联 scheduler / executor / validation
  • 决定 继续 / 重试 / 中断

engine.py（完整示例） #

python
# engine/engine.py

from engine.scheduler import Scheduler
from engine.executor import Executor
from engine.state_manager import StateManager

class ExecutionEngine:
    def __init__(self):
        self.state = StateManager()
        self.scheduler = Scheduler(self.state)
        self.executor = Executor(self.state)

    def run(self):
        while True:
            task = self.scheduler.next_task()
            if task is None:
                print("✅ All tasks completed")
                break

            result = self.executor.execute(task)

            if not result["success"]:
                self.state.mark_failed(task["id"], result["error"])
                break

输入 #

  • context/task_state.json
  • 当前 project 状态

输出 #

  • 执行结果
  • 更新后的 state

# engine/scheduler.py

class Scheduler:
    def __init__(self, state):
        self.state = state

    def next_task(self):
        for task in self.state.tasks():
            if task["status"] == "pending":
                return task
        return None

class Executor:
    def __init__(self, state):
        self.state = state

    def execute(self, task):
        print(f"▶ Executing task {task['id']}")

        # 1. 调用 AI（此处 mock）
        ai_output = {
            "type": "plan",
            "steps": [{"id": "s2-1", "description": "do something"}]

        return {"success": True}

# engine/state_manager.py

import json

STATE_FILE = "context/task_state.json"

class StateManager:
    def __init__(self):
        with open(STATE_FILE) as f:
            self.state = json.load(f)

    def tasks(self):
        return self.state["tasks"]

    def mark_done(self, task_id):
        for t in self.state["tasks"]:
            if t["id"] == task_id:
                t["status"] = "done"
        self._save()

    def mark_failed(self, task_id, error):
        for t in self.state["tasks"]:
            if t["id"] == task_id:
                t["status"] = "failed"
                t["error"] = error
        self._save()

    def _save(self):
        with open(STATE_FILE, "w") as f:
            json.dump(self.state, f, indent=2)

# evolution/evaluation.py

def should_evolve(memory):
    total_tasks = memory.get("total_tasks", 0)
    failures = len(memory.get("errors", []))

    if total_tasks < 10:
        return False

    failure_rate = failures / total_tasks
    return failure_rate > 0.2
