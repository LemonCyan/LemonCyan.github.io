NOFX配置

本文记录了在 Debian 12 (Bookworm) 系统上部署 NOFX 自动化交易系统的完整流程。如果你是第一次接触，建议按顺序一步步来，不要跳过任何步骤。

环境要求 #

在开始之前，确认你有：

  • 一台 Debian 12 系统的服务器（VPS 或本地虚拟机都行）
  • root 权限或 sudo 权限
  • 稳定的网络连接

💡 下面所有命令默认在 root 用户下执行。如果你用的是普通用户，记得在命令前加 sudo。

第一步：安装 Docker #

Docker 是容器化工具，虽然我们这次主要用源码编译的方式部署，但装上 Docker 方便以后做其他事情。

bash
curl -fsSL https://get.docker.com -o get-docker.sh && sh get-docker.sh

安装完成后，运行 docker --version 确认一下是否成功。

第二步：安装 TA-Lib #

TA-Lib 是一个技术分析库，NOFX 的策略计算依赖它。这一步需要从源码编译安装。

2.1 安装编译所需的工具 #

bash
sudo apt install -y build-essential automake wget

2.2 下载并编译 TA-Lib #

bash
# 下载源码包
wget http://prdownloads.sourceforge.net/ta-lib/ta-lib-0.4.0-src.tar.gz

# 解压
tar -xzf ta-lib-0.4.0-src.tar.gz

# 进入目录
cd ta-lib

# 配置（安装到 /usr 目录下）
./configure --prefix=/usr

# 编译（-j 参数会利用多核加速）
sudo make -j$(nproc)

# 安装
sudo make install

2.3 验证安装 #

安装完成后，检查这两个路径是否存在：

  • 头文件目录：/usr/include/ta-lib/
  • 库文件：/usr/lib/libta_lib.so

如果都在，说明 TA-Lib 装好了。

装完记得回到上一级目录：cd ..

第三步：安装 Go 语言环境 #

NOFX 后端用 Go 写的，所以需要先装 Go 编译器。Debian 12 默认源里的 Go 版本可能偏旧，我们用 backports 源安装较新版本。

3.1 添加 Backports 源 #

bash
echo "deb http://deb.debian.org/debian bookworm-backports main" | tee /etc/apt/sources.list.d/backports.list

3.2 更新软件包列表 #

bash
sudo apt update

3.3 安装 Go #

bash
sudo apt -t bookworm-backports install -y golang

安装后用 go version 确认版本，建议 1.21 以上。

第四步：安装 Node.js 和 npm #

NOFX 前端用的是 Node.js，我们安装官方 LTS 版本。

4.1 添加 NodeSource 源 #

bash
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo bash -

4.2 安装 Node.js #

bash
sudo apt install -y nodejs

4.3 验证安装 #

bash
node -v
npm -v

分别应该能看到 v20.x.x 和 10.x.x 这样的版本号。

第五步：拉取并编译 NOFX #

环境准备好了，现在开始部署 NOFX 本体。

5.1 克隆项目 #

bash
git clone https://github.com/NoFxAiOS/nofx.git
cd nofx

5.2 配置 RSA 密钥 #

NOFX 启动时需要 RSA 密钥来加密敏感数据。你需要生成一对密钥并配置到 .env 文件中。

生成密钥的方法：

项目自带了 start.sh 脚本，可以看看里面怎么生成的，或者手动执行：

bash
# 生成私钥
openssl genrsa -out private.pem 2048

# 生成公钥
openssl rsa -in private.pem -pubout -out public.pem

然后把私钥内容（注意是文件内容，不是文件路径）配置到 .env 文件的 RSA_PRIVATE_KEY 变量中。

⚠️ 如果跳过这一步直接启动，会报错：

cpp
Failed to initialize encryption service: failed to load RSA private key: environment variable RSA_PRIVATE_KEY not set

5.3 安装后端依赖 #

bash
go mod download

5.4 安装前端依赖 #

bash
cd web
npm install
cd ..

5.5 编译后端 #

bash
go build -o nofx

编译成功后，当前目录会出现一个名为 nofx 的可执行文件。

第六步：启动服务 #

启动需要开两个终端窗口（或者用 tmux/screen）。

终端 1：启动后端 #

bash
./nofx

终端 2：启动前端开发服务器 #

bash
cd web
npm run dev

访问 Web 界面 #

启动成功后，打开浏览器访问：

http://127.0.0.1:3000

如果是在远程服务器上部署，把 127.0.0.1 换成服务器的公网 IP。

快捷方式 #

如果不想手动一步步来，项目提供了 start.sh 脚本：

bash
./start.sh start --build

这个命令会自动完成编译和启动。

常见问题 #

Q: 启动时报 RSA 密钥相关错误怎么办？ #

按照上面 5.2 节的说明生成密钥并配置 .env 文件。

Q: 前端页面打不开？ #

  1. 检查前端服务是否正常运行
  2. 确认防火墙是否放行了 3000 端口
  3. 如果用的是云服务器，检查安全组规则

Q: 编译 TA-Lib 失败？ #

确保已经安装了 build-essential 和 automake，这两个包提供了必要的编译工具。

后续配置 #

部署完成后，你可能还需要：

  • 配置反向代理（Nginx/Caddy）绑定域名
  • 申请 SSL 证书开启 HTTPS
  • 配置交易所 API 密钥

这些内容后续再单独写。
