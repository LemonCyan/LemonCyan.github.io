TELEGRAM_NOTIFICATIONS

Telegram 交易通知配置指南 #

概述 #

NOFX 支持通过 Telegram Bot 发送交易通知。当系统执行交易操作（开仓、平仓）时，会自动发送消息到您指定的 Telegram 聊天。

功能特点 #

  • ✅ 异步发送 - 不影响交易执行速度
  • ✅ 可选功能 - 未配置时自动禁用
  • ✅ 详细信息 - 包含交易对、数量、价格、杠杆等
  • ✅ 中英双语 - 消息同时显示中英文操作名称

配置步骤 #

1. 创建 Telegram Bot #

  1. 在 Telegram 中搜索 @BotFather
  2. 发送 /newbot 命令
  3. 按提示设置 Bot 名称和用户名
  4. 保存返回的 Bot Token（格式如：123456789:ABCdefGHIjklMNOpqrsTUVwxyz）

2. 获取 Chat ID #

方法一：私聊 Bot

  1. 向你的 Bot 发送任意消息
  2. 访问：https://api.telegram.org/bot<YOUR_TOKEN>/getUpdates
  3. 从返回的 JSON 中找到 chat.id

方法二：群组通知

  1. 将 Bot 添加到群组
  2. 在群组中 @Bot 发送任意消息
  3. 访问上述 URL 获取群组 chat_id（负数）

3. 配置环境变量 #

在 .env 文件中添加：

bash
# Telegram 通知配置
TELEGRAM_BOT_TOKEN=your_bot_token_here
TELEGRAM_CHAT_ID=your_chat_id_here

4. 重启应用 #

bash
# Docker 方式
docker-compose restart

# 直接运行方式
# 停止当前运行的程序，重新启动
./nofx

通知消息示例 #

cpp
📈 做多开仓 / Open Long

🤖 策略: `MyTrader`
📊 交易对: `BTC-USDT-SWAP`
📦 数量: `0.100000`
💰 价格: `$97500.00`
⚡ 杠杆: `10x`
🛡️ 止损: `$95000.00`
🎯 止盈: `$100000.00`

⏰ 时间: `2024-12-29 05:00:00 UTC`

日志查看 #

启动时会显示通知服务状态：

cpp
📱 Telegram notifications enabled

如果未配置：

cpp
📱 Telegram notifications disabled (TELEGRAM_BOT_TOKEN or TELEGRAM_CHAT_ID not set)

故障排除 #

收不到通知 #

  1. 检查 .env 中的 Token 和 Chat ID 是否正确
  2. 确保 Bot 未被封禁
  3. 查看应用日志中是否有 ⚠️ Failed to send Telegram notification 错误

Bot Token 无效 #

  • 确保 Token 格式正确（包含冒号）
  • 检查是否有多余空格
  • 可通过 https://api.telegram.org/bot<TOKEN>/getMe 验证

Chat ID 错误 #

  • 群组 Chat ID 是负数（如 -1001234567890）
  • 私聊 Chat ID 是正数
  • 确保 Bot 有权限在该聊天中发送消息

技术说明 #

  • 通知发送在独立 goroutine 中执行，不会阻塞交易流程
  • 默认超时时间 10 秒
  • 支持 Markdown 格式
  • 仅在交易成功执行后发送通知

相关代码 #

  • Telegram 客户端: notify/telegram.go
