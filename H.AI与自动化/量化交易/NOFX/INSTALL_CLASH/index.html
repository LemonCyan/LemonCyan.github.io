INSTALL_CLASH

arm64 架构的 Linux 系统（比如 Raspberry Pi 4/5、某些 ARM 服务器、Jetson、某些云服务器等）安装和配置 Clash（或 Clash Meta / Mihomo）的步骤如下。

目前原版 Clash 项目已删除，推荐使用 Clash Meta（也叫 Mihomo）内核，它兼容性更好、支持更多协议（Hysteria2、TUIC 等），社区活跃。

推荐两种方式（选一种即可） #

方式 1：纯命令行（Clash Meta 内核） - 最轻量，适合服务器/无桌面环境 #

  1. 确认系统架构（确保是 arm64 / aarch64）

    bash
    uname -m
# 应该输出 aarch64

  2. 下载最新 Clash Meta（Mihomo） arm64 版本

    去 GitHub Release 页面：https://github.com/MetaCubeX/mihomo/releases

    找最新版（比如 v1.18.x 或 alpha 版），下载文件名类似：

    • mihomo-linux-arm64-v1.18.x.gz 或 clash.meta-linux-arm64-alpha-xxxx.gz

    命令下载（替换成最新版本链接）：

    bash
    cd ~
mkdir clash && cd clash
wget https://github.com/MetaCubeX/mihomo/releases/download/v1.18.8/mihomo-linux-arm64-v1.18.8.gz
# 或 alpha 版（更新更快，支持更多功能）：
# wget https://github.com/MetaCubeX/mihomo/releases/download/Alpha/mihomo-linux-arm64-alpha-xxxx.gz

  3. 解压 & 赋予执行权限 & 重命名

    bash
    gzip -d mihomo-linux-arm64-*.gz
chmod +x mihomo-linux-arm64-*
mv mihomo-linux-arm64-* clash   # 改名为 clash 方便记忆

  4. 创建配置目录并放入 config.yaml

    bash
    mkdir -p ~/.config/clash
# 把你的订阅链接保存为 config.yaml（或 config.yml）
# 方法一：手动下载订阅
wget -O ~/.config/clash/config.yaml "你的订阅链接"

# 方法二：用 clash 第一次运行自动生成模板（推荐先跑一次）
./clash  # 运行一次，它会生成默认 config.yaml 和 Country.mmdb
# 然后按 Ctrl+C 停止，编辑 ~/.config/clash/config.yaml 替换成你的订阅内容

  5. 运行测试

    bash
    ./clash -d ~/.config/clash
# 或后台运行：
nohup ./clash -d ~/.config/clash > clash.log 2>&1 &

    看到类似输出就成功：

    cpp
    INFO[0000] RESTful API listening at: 127.0.0.1:9090
INFO[0000] HTTP proxy listening at: 127.0.0.1:7890
INFO[0000] SOCKS proxy listening at: 127.0.0.1:7891

  6. 设置系统代理（临时测试）

    bash
    export http_proxy=http://127.0.0.1:7890
export https_proxy=http://127.0.0.1:7890
export all_proxy=socks5://127.0.0.1:7891

# 测试
curl -I https://www.google.com

  7. 做成 systemd 服务（开机自启） - 强烈推荐

    bash
    sudo nano /etc/systemd/system/clash.service

    粘贴以下内容（根据你的路径调整）：

    ini
    [Unit]
Description=Clash daemon, A rule-based proxy in Go.
After=network-online.target

[Service]
Type=simple
Restart=always
ExecStart=/home/你的用户名/clash/clash -d /home/你的用户名/.config/clash
# 如果想用 root 运行可以改成 /root/clash/clash ...
AmbientCapabilities=CAP_NET_ADMIN CAP_NET_BIND_SERVICE

[Install]
WantedBy=multi-user.target

    然后：

    bash
    sudo systemctl daemon-reload
sudo systemctl enable --now clash
sudo systemctl status clash

方式 2：带图形界面（推荐桌面环境，如 Ubuntu Desktop ARM、Raspberry Pi OS） #

用 Clash Verge Rev（支持 arm64 Linux，最现代的 GUI 客户端，内置 Clash Meta 内核）：

  1. 去官网或 GitHub 下载 arm64 版本：

    • https://github.com/clash-verge-rev/clash-verge-rev/releases
    • 下载 Clash.Verge_x.x.x_arm64.AppImage 或 .deb 包

  2. 安装：

    • AppImage：直接 chmod +x Clash.Verge*.AppImage 然后双击运行
    • deb 包：sudo apt install ./Clash.Verge_*.deb

  3. 启动后导入订阅链接 → 选择节点 → 开启系统代理 / TUN 模式即可。

    Clash Verge Rev 界面友好，支持自动更新内核、规则集等。

常见问题快速解决 #

  • 端口被占：改 config.yaml 里的 port: 7890、socks-port: 7891、mixed-port: 7890 等
  • Country.mmdb 缺失：第一次运行 clash 会自动下载；或手动下载放 config 目录：https://github.com/MetaCubeX/meta-rules-dat/releases
  • TUN 模式需要权限：服务文件加 AmbientCapabilities=CAP_NET_ADMIN CAP_NET_BIND_SERVICE，或用 root 运行
  • 更新内核：直接替换 clash 文件为新版，systemd 会自动重启
