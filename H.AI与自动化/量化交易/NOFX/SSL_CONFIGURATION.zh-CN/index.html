🔒 NOFX SSL 配置指南 #

本指南将指导您如何为 NOFX 前端启用 HTTPS/SSL 支持。

前置条件 #

  1. SSL 证书文件：
    • server.crt (公钥/证书链)
    • server.key (私钥)
  2. 确保您拥有服务器的 root 权限或 sudo 权限。

步骤 1: 准备证书文件 #

在项目根目录下创建一个 certs 目录，并将您的证书文件放入其中。

您提到的文件对应关系如下：

  • domain.cert.pem -> server.crt
  • private.key.pem -> server.key

(注：public.key.pem 通常不需要在 Nginx 中单独配置，因为它已包含在证书中)

bash
mkdir -p certs
# 假设您的文件在当前目录
cp domain.cert.pem certs/server.crt
cp private.key.pem certs/server.key

如果您想使用 自签名证书 进行测试 (仅用于开发)，可以使用以下命令生成：

bash
openssl req -x509 -nodes -days 365 -newkey rsa:2048 \
  -keyout certs/server.key \
  -out certs/server.crt \
  -subj "/C=CN/ST=State/L=City/O=NOFX/OU=Dev/CN=localhost"

步骤 2: 修改 Nginx 配置 #

编辑 nginx/nginx.conf 文件，添加 SSL 监听配置。

nginx
server {
    listen 80;
    server_name localhost;
    # 强制重定向 HTTP 到 HTTPS (可选)
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl;
    server_name localhost;

    # SSL 证书配置
    ssl_certificate /root/nofx/certs/domain.cert.pem;
    ssl_certificate_key /root/nofx/certs/private.key.pem;

    # SSL 优化配置 (推荐)
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers HIGH:!aNULL:!MD5;
    ssl_prefer_server_ciphers on;

    # Frontend root
    root /usr/share/nginx/html;
    index index.html;

    # Gzip compression
    gzip on;
    gzip_vary on;
    gzip_min_length 1024;
    gzip_types text/plain text/css text/xml text/javascript application/x-javascript application/xml+rss application/javascript application/json;

    # Frontend routes
    location / {
        try_files $uri $uri/ /index.html;
        location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2|ttf|eot)$ {
            expires 1y;
            add_header Cache-Control "public, immutable";
        }
    }

    # Proxy API requests
    location /api/ {
        proxy_pass http://nofx:8080/api/;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        
        proxy_connect_timeout 300s;
        proxy_send_timeout 300s;
        proxy_read_timeout 300s;
    }

    # Health check
    location /health {
        return 200 "OK\n";
        add_header Content-Type text/plain;
        access_log off;
    }
}

步骤 3: 修改 Docker Compose 配置 #

编辑 docker-compose.yml 文件，将证书挂载到容器中，并开放 443 端口。

找到 nofx-frontend 服务部分，进行如下修改：

yaml
  nofx-frontend:
    # ... 其他配置保持不变 ...
    ports:
      - "${NOFX_FRONTEND_PORT:-80}:80"   # HTTP 端口
      - "${NOFX_SSL_PORT:-443}:443"      # HTTPS 端口 (新增)
    volumes:
      - ./certs:/etc/nginx/certs:ro      # 挂载证书目录 (新增)
    # ... 其他配置保持不变 ...

步骤 4: 重启服务 #

完成上述更改后，需要重建并重启容器以应用配置。

bash
# 停止旧容器
docker compose down

# 启动新服务
docker compose up -d
