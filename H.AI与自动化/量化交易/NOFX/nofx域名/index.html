nofx域名

NOFX 这个项目（https://github.com/NoFxAiOS/nofx）本身的后端服务默认监听 3000 端口，前端通常也是通过这个端口访问（或配合 vite/next 等框架）。

项目原生并没有内置 https 支持和证书管理功能，所以想要使用 自定义端口 + HTTPS 证书，目前社区最常见且推荐的做法是：

使用 Nginx（或 Caddy）做反向代理 + 自动申请/管理 SSL 证书

推荐方案对比 #

方式 自定义端口难度 证书管理难度 推荐指数 适用场景
Nginx + certbot ★★☆☆☆ ★★☆☆☆ ★★★★★ 最稳定、最常见、国内服务器友好
Caddy ★☆☆☆☆ ★☆☆☆☆ ★★★★☆ 最简单自动，适合新手
Cloudflare Tunnel ★★☆☆☆ ★☆☆☆☆ ★★★★☆ 零公网 IP、快速上线
直接改代码端口 ★★★★☆ ★★★★★ ★☆☆☆☆ 不推荐（维护麻烦）

最常用做法：Nginx + certbot（强烈推荐） #

  1. 先把 nofx 正常跑起来

    bash
    # 假设你已经 docker-compose up -d 或者 npm run dev 启动了
# 确认 http://你的服务器IP:3000 可以访问到 nofx 界面

  2. 安装 nginx

    bash
    # Ubuntu/Debian
sudo apt update
sudo apt install -y nginx

# CentOS/Rocky
sudo dnf install nginx

  3. 启动 nginx（先只用 80 端口）

    bash
    sudo systemctl enable --now nginx

  4. 申请 Let's Encrypt 证书（最简单方式）

    bash
    sudo apt install -y certbot python3-certbot-nginx   # Ubuntu

# 或者 snap 方式（推荐，证书更新更稳定）
sudo snap install --classic certbot
sudo ln -s /snap/bin/certbot /usr/bin/certbot

    然后执行（把 your-domain.com 换成你自己的域名）：

    bash
    sudo certbot --nginx -d your-domain.com -d www.your-domain.com

    certbot 会：

    • 自动帮你申请证书
    • 自动修改 nginx 配置加上 https
    • 自动配置 80 → 443 重定向

  5. 手动创建/修改 Nginx 配置文件（如果 certbot 没自动生成好）

    创建文件：/etc/nginx/sites-available/nofx

    nginx
    server {
    listen 80;
    server_name your-domain.com www.your-domain.com;

    # 自动跳转到 https（certbot 通常会自动加）
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl http2;
    server_name your-domain.com www.your-domain.com;

    # 证书路径（certbot 自动生成，通常是下面这样）
    ssl_certificate /etc/letsencrypt/live/your-domain.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/your-domain.com/privkey.pem;

    # 推荐的安全配置（可选但建议加）
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers HIGH:!aNULL:!MD5;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
    }
}

    启用配置：

    bash
    sudo ln -s /etc/nginx/sites-available/nofx /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx

  6. 想要改端口？（比如改成 8443）

    把 listen 443 ssl http2; 改成你想要的端口，例如：

    nginx
    listen 8443 ssl http2;

    然后防火墙放行：

    bash
    sudo ufw allow 8443
# 或
sudo firewall-cmd --add-port=8443/tcp --permanent
sudo firewall-cmd --reload

快速总结（最简流程） #

  1. 域名解析到服务器
  2. 跑通 nofx（3000 端口）
  3. 装 nginx + certbot
  4. sudo certbot --nginx -d 你的域名
  5. 访问 https://你的域名 即可（自动跳转）

如果你的服务器在国内，或者 Cloudflare 已经接管了域名，也可以直接用 Cloudflare 的免费 SSL + 反向代理（甚至可以隐藏 3000 端口）。

有遇到具体报错或你现在用的部署方式（docker？直接 npm？云服务器？），可以贴出来，我再给你更精准的步骤。
