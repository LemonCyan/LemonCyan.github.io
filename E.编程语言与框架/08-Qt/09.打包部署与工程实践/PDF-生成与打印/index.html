本篇在 08-Qt / 09.打包部署与工程实践 里排第六。讲的是同一件事：程序把内容变成纸，或者变成 PDF 文件。

讲什么：QPdfWriter 和 QPrinter 两条出口、QPainter 怎么往上画、控件快照导出、纯文本与 HTML 富文本生成 PDF、多页手动翻页、打印预览与打印对话框、文件保存与打开、中文字体嵌入。

不讲什么：不写报表引擎（Qt 自己也没有）、不讲 PDF 解析和阅读器开发（Qt 不提供，得靠第三方）、不讲打印机驱动与系统打印队列排错。

跨篇指路：安装包与依赖库看《打包与分发》；发布后变慢、内存上涨看《发布后的性能问题》；日志落盘与开机自启动看《日志与开机自启》。

一、Qt 的输出能力全景 #

Qt 把「往哪儿画」抽象成一个基类：QPaintDevice。QPainter 只认这个基类，不认具体设备。同一段绘制代码，换一个设备对象，产物就从像素变成纸，再变成 PDF。

这个观念立住，后面每一节都是它的推论。

设备类 产物 典型用途
QWidget 窗口里的像素 控件自绘、paintEvent
QImage / QPixmap 内存位图 截图、缩略图、离屏合成
QPrinter 纸张，或磁盘上的 PDF 打印、导出 PDF
QPdfWriter 只有磁盘上的 PDF 后台生成、无打印机的机器
QSvgGenerator SVG 矢量文件 图形交付、可再编辑

QPaintDevice 给绘制代码暴露的接口不多，每一个都要看懂：

cpp
int    width()  const;        // 设备宽度，单位是「设备像素」
int    height() const;
int    widthMM()  const;      // 物理宽度，毫米
int    heightMM() const;
int    logicalDpiX() const;   // 逻辑 DPI，横向
int    logicalDpiY() const;
qreal  devicePixelRatio() const;

四个数决定坐标怎么换算：width() / height() 是像素，widthMM() / heightMM() 是毫米，logicalDpi() 是两者的比例尺。A4 纸 210×297 毫米，96 DPI 下算出来 794×1123 像素，1200 DPI 下算出来 9921×14031 像素。同一张纸，像素数差十几倍。

这就是 QPrinter::HighResolution 会把字变细的根源：字号按「点」给，点换算成像素要乘 DPI，DPI 一高，字占的像素多了，而你手写的坐标还是固定像素值，比例就歪了。

把内容送上纸或 PDF，Qt 里一共三条路：

路线 做法 分页 适用
直接绘制 QPainter 加自己算坐标 全手动 纯文本、绘图、自定义版式
控件快照 控件抓成 QPixmap 再画上去 一页一张图 把现成界面原样存下来
文档流 QTextDocument::print() 自动 HTML 富文本、长文本、表格

三条路都落在 QPaintDevice 上，终点可以互换。下面按这个顺序走。

二、QPdfWriter 与 QPrinter #

两个类名字像亲戚，分工很干净：QPdfWriter 只会写 PDF 文件，QPrinter 既写 PDF 文件也驱动真实打印机。

先看工程配置。两者都在 Qt Print Support 模块里，.pro 不加模块会在链接阶段报错：

text
QT += printsupport

CMake 工程链接 Qt5::PrintSupport，头文件按需引：

cpp
#include <QPdfWriter>            // 纯 PDF 出口
#include <QPrinter>              // 打印或 PDF
#include <QPainter>              // 绘制
#include <QTextDocument>         // 富文本
#include <QPageLayout>           // 纸张版面
#include <QPrintDialog>          // 打印对话框
#include <QPrintPreviewDialog>   // 预览窗口

1. QPdfWriter #

构造参数就是一个文件路径，分辨率默认 1200 DPI：

cpp
QPdfWriter writer(QStringLiteral("D:/report.pdf"));

writer.setPageSize(QPageSize(QPageSize::A4));
writer.setPageMargins(QMarginsF(15, 15, 15, 15), QPageLayout::Millimeter);
writer.setResolution(300);        // 默认 1200，按需下调
writer.setTitle(QStringLiteral("月度报表"));
writer.setCreator(QStringLiteral("ReportTool 1.0"));

QPainter painter;
if (!painter.begin(&writer)) {
    return;                       // 路径不可写，或文件被别的程序占用
}
// ... 在这里画 ...
painter.end();

setResolution() 是 QPdfWriter 自己的方法，不是 QPaintDevice 的，它是这条路上唯一能调 DPI 的入口。

2. QPrinter #

QPrinter 多一步：先告诉它往哪儿输出。

cpp
QPrinter printer(QPrinter::HighResolution);
printer.setOutputFormat(QPrinter::PdfFormat);        // 出 PDF
printer.setOutputFileName(QStringLiteral("D:/report.pdf"));
printer.setPageSize(QPrinter::A4);
printer.setOrientation(QPrinter::Portrait);

不调 setOutputFormat(QPrinter::PdfFormat)，它就去调系统打印机打纸。调了，setOutputFileName() 才有意义。

3. 两个类的对照 #

维度 QPdfWriter QPrinter
输出目标 只能是 PDF 文件 PDF 文件，或物理打印机
构造参数 文件路径 打印模式枚举
分辨率 setResolution(int) 构造时给 HighResolution / ScreenResolution
纸张 setPageSize(QPageSize) setPageSize(QPrinter::A4) 或 setPaperSize(QSizeF, Unit)
页边距 setPageMargins(QMarginsF, Unit) setPageMargins(QMarginsF, Unit)
元数据 setTitle / setCreator 不支持
预览 不支持 QPrintPreviewDialog 直接吃
打印对话框 不支持 QPrintDialog 直接吃
需要打印机驱动 不需要 需要（PDF 输出模式下也不需要）
无界面程序可用 可以 可以，但不能弹对话框
典型场景 后台任务、批量导出 交互打印、带预览的导出

选法很直白：要弹预览、要弹打印对话框、要真打纸，用 QPrinter；只闷头生成一个 PDF 文件，用 QPdfWriter。

4. PDF 和打印是同一套 API #

因为两个类都继承 QPaintDevice。QPainter::begin() 收的是 QPaintDevice*，传 QPdfWriter* 和传 QPrinter* 对它毫无区别。

下面这段，device 换一个，行为就从「存成 PDF」变成「打出来」：

cpp
void drawReport(QPaintDevice *device)
{
    QPainter painter;
    if (!painter.begin(device)) {
        return;
    }

    QRect page = painter.viewport();      // 可绘制区域，已扣掉页边距
    int   dpi  = device->logicalDpiY();

    QFont font = painter.font();
    font.setPixelSize(dpi * 12 / 72);     // 12 点，按 DPI 换算成像素
    painter.setFont(font);

    painter.drawText(page, Qt::AlignLeft | Qt::AlignTop,
                     QStringLiteral("设备运行日报"));

    painter.end();
}

调用处只差一行：

cpp
QPdfWriter writer(QStringLiteral("D:/report.pdf"));
writer.setPageSize(QPageSize(QPageSize::A4));
drawReport(&writer);          // 出 PDF

QPrinter printer(QPrinter::HighResolution);
drawReport(&printer);         // 进打印队列

想通这一层，「生成 PDF」和「打印」就不再是两件事，只是一件事的两个出口。往后凡是讲绘制，对两者同时成立。

三、用 QPainter 画 PDF #

QPainter 的生命周期只有两条规则：begin() 成功才能画，end() 必须调。

1. 两种写法 #

栈对象直接构造，析构时自动结束：

cpp
QPainter painter(&writer);
if (!painter.isActive()) {
    return;
}
painter.drawText(100, 100, QStringLiteral("hello"));
// 离开作用域自动 end()

手动 begin() / end()，适合中途要判断或提前返回的场景。第二种写法里任何提前 return 之前都得补 end()，漏了会留下半截文件。只有需要「失败了别动文件」时才用它。

2. 坐标原点与 viewport #

原点在纸张左上角，X 向右，Y 向下。painter.viewport() 返回当前可绘制矩形，页边距已经扣掉，直接拿它排版最省事：

cpp
QRect vp = painter.viewport();
painter.drawRect(vp.adjusted(0, 0, -1, -1));   // 画出边界确认版面

viewport() 会随 scale() / translate() 变化，所以在改变换之前先取。

3. 缩放比例必须用浮点 #

最常见的需求是把一张固定尺寸的图铺满整页，量出两个宽度除一下：

cpp
QRect vp = painter.viewport();
qreal k  = qMin(qreal(vp.width())  / pixmap.width(),
                qreal(vp.height()) / pixmap.height());
painter.scale(k, k);
painter.drawPixmap(0, 0, pixmap);

这里必须用 qreal 做除法。老代码里常见这种写法：int x = rect.width() / pixmap.width();，两个整数相除，结果直接截断。截图 1000 像素宽、页面 794 像素宽，算出来是 0，scale(0, 0) 把图缩成一点，PDF 打开一片空白。

整数除法是这块最高频的 bug，看到 int = 宽 / 宽 就该警觉。

4. HighResolution 的坑 #

QPrinter(QPrinter::HighResolution) 把逻辑 DPI 拉到 1200 上下。同一段代码，屏幕上画 12 像素的字，在纸上只有 1/100 英寸，小到看不清。

方式 代码 适用
换低分辨率 QPrinter printer(QPrinter::ScreenResolution); 纯文本、截图导出
按 DPI 换算字号 font.setPixelSize(dpi * pt / 72); 需要精确控制字号
整体缩放 painter.scale(dpi / 96.0, dpi / 96.0); 已有按屏幕坐标写好的绘制代码

第三种最省改动，先把坐标系压回「按屏幕像素思考」的比例，原来的代码一行不动：

cpp
qreal k = device->logicalDpiY() / 96.0;
painter.scale(k, k);
painter.drawText(20, 40, QStringLiteral("按屏幕坐标写的旧代码"));

四、控件快照转 PDF #

最快的出图办法是把界面上排好的控件抓成位图，整张贴上去。用户看到什么样，PDF 里就是什么样，不用重新排版。

1. 三个入口 #

Qt 给控件上提供三种「输出到绘制设备」的能力，适用范围不同：

方法 所有者 输出 适用控件
print(QPagedPaintDevice*) QTextEdit、QTextDocument、QPlainTextEdit 文字，可分页 文本类控件
render(QPaintDevice*) QWidget 控件自身渲染，含子控件 所有控件
grab() QWidget 返回 QPixmap 所有控件

render() 直接把控件画到目标设备；grab() 先离屏渲染成位图，再由你决定画到哪儿。要缩放、要拼接、要先做图像处理，选 grab()；只是原样贴上去，render() 更直接。

QWidget::print() 只有文本类控件有实际实现，其他控件调它等于一次普通渲染，别指望它替你分页。

2. 单个控件直接输出 #

cpp
void MainWindow::on_btnSave_clicked()
{
    QString fileName = QFileDialog::getSaveFileName(
        this, tr("导出PDF文件"), QString(), QStringLiteral("*.pdf"));

    if (fileName.isEmpty()) {
        return;
    }

    // 用户没写后缀，补一个
    if (QFileInfo(fileName).suffix().isEmpty()) {
        fileName.append(".pdf");
    }

    QPdfWriter writer(fileName);
    writer.setPageSize(QPageSize(QPageSize::A4));

    ui->tableWidget->render(&writer);      // 表格控件整体渲染成一页
}

QTableWidget、QTreeWidget、QTextEdit 这类控件用 render() 最省事。它按控件本身的尺寸画，被滚动条藏起来的部分一样会画出来，不会截断。

3. 多控件合成一张 #

内容分散在几个控件里时，先把它们塞进同一个容器（一个 QWidget 或 QStackedWidget），再对容器整体抓图。所有要打印的内容都放在 stackedWidget 上，只抓它一个就够：

cpp
void MainWindow::saveStackedWidgetToPdf()
{
    QString fileName = QFileDialog::getSaveFileName(
        this, tr("保存PDF文件"), QString(), QStringLiteral("*.pdf"));

    if (fileName.isEmpty()) {
        return;
    }

    if (QFileInfo(fileName).suffix().isEmpty()) {
        fileName.append(".pdf");
    }

    QPixmap pixmap = ui->stackedWidget->grab(ui->stackedWidget->rect());

    // 纸张尺寸跟内容一样大，避免大片留白
    QPdfWriter writer(fileName);
    writer.setPageSize(QPageSize(QSizeF(pixmap.width(), pixmap.height()),
                                 QPageSize::Point,
                                 QStringLiteral("Custom")));
    writer.setResolution(300);

    QPainter painter;
    if (!painter.begin(&writer)) {
        return;
    }

    QRect vp = painter.viewport();
    const qreal k = qMin(qreal(vp.width())  / pixmap.width(),
                         qreal(vp.height()) / pixmap.height());
    painter.scale(k, k);
    painter.drawPixmap(0, 0, pixmap);
    painter.end();

    QMessageBox::information(this, tr("生成PDF"), tr("保存PDF文件成功"));
}

4. 自定义纸张的两个坑 #

早期写法用 QPrinter，两个坑都踩在上面：

cpp
printerPixmap.setPageSize(QPrinter::Custom);
printerPixmap.setPaperSize(QSizeF(ui->stackedWidget->height(),
                                  ui->stackedWidget->width()),
                           QPrinter::Point);
printerPixmap.setOrientation(QPrinter::Landscape);

第一个坑：宽高写反。setPaperSize() 第一个参数是宽，第二个是高，老代码把 height() 传给了宽，靠 setOrientation(Landscape) 把纸转横来对冲。两个错误互相抵消，凑合能出图，改成竖向打印立刻错版。按控件真实宽高给 QSizeF(w, h)，别靠横竖翻转来救。

第二个坑：拿控件像素数当点值。QSizeF(width, height) 单位标了 QPageSize::Point，传进去的却是像素数。控件 800×600 像素，纸就是 800×600 点，约 282×212 毫米，比 A4 还宽一圈。要么统一用 QPageSize::Pixel 配 setResolution()，要么把像素换算成毫米：

cpp
// 按 DPI 折成毫米，物理尺寸才对得上
const QSizeF sizeMM(pixmap.width()  * 25.4 / 96.0,
                    pixmap.height() * 25.4 / 96.0);
writer.setPageSize(QPageSize(sizeMM, QPageSize::Millimeter));

5. 长内容切片分页 #

控件高度超过一页时，单页纸这条路就断了：要么纸拉到离谱，要么内容被裁。做法是把整张截图切成若干段，每段用源矩形裁一块贴上去：

cpp
const int pageH = writer.height();     // 一页能放多少像素
int  top = 0;
bool firstPage = true;

QPainter painter;
if (!painter.begin(&writer)) {
    return;
}

while (top < pixmap.height()) {
    if (!firstPage) {
        writer.newPage();              // 翻页
    }
    firstPage = false;

    const int sliceH = qMin(pageH, pixmap.height() - top);
    painter.drawPixmap(QRect(0, 0, pixmap.width(), sliceH),
                       pixmap,
                       QRect(0, top, pixmap.width(), sliceH));
    top += sliceH;
}

painter.end();

切片高度不能大于 writer.height()，超出的部分被静默裁掉；后面的内容接着画在下一次切片上，看起来就是「少了一截」。

五、纯文本生成 PDF #

不依赖任何控件，直接往 PDF 上按行写字。适合导出日志、清单、简单报表。思路极简：定一个起点坐标，每写一行把 Y 往下挪。

cpp
void exportTextToPdf(const QString &savePath)
{
    QPdfWriter writer(savePath);
    writer.setPageSize(QPageSize(QPageSize::A4));
    writer.setResolution(300);

    QPainter painter;
    if (!painter.begin(&writer)) {
        return;
    }

    const QString dateString =
        QDateTime::currentDateTime().toString(QStringLiteral("yyyy-MM-dd hh:mm:ss ddd"));

    QFont font = painter.font();
    font.setPixelSize(48);              // 300 DPI 下约等于 11.5 点
    painter.setFont(font);

    QPoint drawPoint(300, 300);         // 起始锚点，高分辨率坐标系

    for (int i = 1; i <= 5; ++i) {
        const QString message = QStringLiteral("%1    %2    %3")
                                    .arg(i)
                                    .arg(dateString)
                                    .arg(QStringLiteral("北京"));

        drawPoint.setY(drawPoint.y() + 150);    // 每行下移 150 像素
        painter.drawText(drawPoint, message);
    }

    painter.end();
}

两点要留意：drawText(QPoint, QString) 的锚点是基线左端，不是顶边；Y 增量写死 150 只在这个字号、这个 DPI 下好看，字号一改就挤或者散。

1. 行距交给字体度量 #

cpp
const QFontMetrics fm(painter.font());
const int lineH = fm.lineSpacing();       // 单行总高，含行间距
int y = fm.ascent() + 300;                // 第一行基线

for (int i = 1; i <= 5; ++i) {
    painter.drawText(300, y, QStringLiteral("第 %1 行").arg(i));
    y += lineH;
}

lineSpacing() 随字号自适应，改字号不用重算数值。

2. 列对齐不要靠空格 #

纯文本拼空格对齐，字体一不等宽就歪。改用矩形加对齐标志，列宽由你定：

cpp
struct Row { int idx; QString date; QString city; QString value; };

const QVector<Row> rows = {
    {1, QStringLiteral("2026-11-17 08:12:33"), QStringLiteral("北京"), QStringLiteral("1284")},
    {2, QStringLiteral("2026-11-17 09:40:02"), QStringLiteral("上海"), QStringLiteral("0975")},
};

const int colX[] = {300, 500, 1800, 2400};    // 300 DPI 下的列起点

for (const Row &r : rows) {
    painter.drawText(QRect(colX[0], y, 200, lineH),
                     Qt::AlignLeft | Qt::AlignVCenter, QString::number(r.idx));
    painter.drawText(QRect(colX[1], y, 1300, lineH),
                     Qt::AlignLeft | Qt::AlignVCenter, r.date);
    painter.drawText(QRect(colX[2], y, 600, lineH),
                     Qt::AlignLeft | Qt::AlignVCenter, r.city);
    painter.drawText(QRect(colX[3], y, 600, lineH),
                     Qt::AlignRight | Qt::AlignVCenter, r.value);
    y += lineH;
}

数字列给 Qt::AlignRight，位数不同的行右边缘才对齐，看着像一张表。

六、HTML 富文本转 PDF #

需要表格、粗体、段落缩进、行内样式时，手写坐标会累死。QTextDocument 直接解析 HTML 子集，自带分页。

cpp
void exportHtmlToPdf(const QString &savePath)
{
    QPrinter printer(QPrinter::ScreenResolution);
    printer.setPageSize(QPrinter::A4);
    printer.setOutputFormat(QPrinter::PdfFormat);
    printer.setOutputFileName(savePath);

    QString html = QStringLiteral(R"(
        <html><head><style>
            table { width: 100%; border-collapse: collapse; }
            th, td { border: 1px solid gray; padding: 8px; text-align: left; }
            th { background-color: #f2f2f2; }
        </style></head><body>
            <h2>文件属性清单</h2>
            <table>
                <tr><th>名称</th><th>修改日期</th><th>类型</th><th>大小</th></tr>
                <tr>
                    <td>不同内核编译KO的区别.note</td>
                    <td>2013-12-06</td><td>Markdown</td><td>12 KB</td>
                </tr>
                <tr>
                    <td>Qt之开机自启动.cpp</td>
                    <td>2013-12-05</td><td>C++ Source</td><td>4 KB</td>
                </tr>
            </table>
        </body></html>
    )");

    QTextDocument doc;
    doc.setDefaultFont(QFont(QStringLiteral("Microsoft YaHei"), 10));
    doc.setHtml(html);
    doc.print(&printer);       // 自动完成分页与渲染
}

关键点是最后一行。doc.print() 收 QPagedPaintDevice*，QPrinter 满足，用 QPrinter 加 PdfFormat 是最稳的写法。

1. 分辨率要跟设备对上 #

HTML 这条路用 QPrinter::ScreenResolution，不然后果是字小到看不见。QTextDocument 的排版单位跟着设备 DPI 走，HighResolution 下它按 1200 DPI 换算毫米，1 像素被当成 1/1200 英寸。

要高 DPI 又要字号正常，换组合：QPdfWriter 设 300 DPI，文档尺寸手动指定成设备像素。

cpp
QPdfWriter writer(savePath);
writer.setPageSize(QPageSize(QPageSize::A4));
writer.setResolution(300);

QTextDocument doc;
doc.setHtml(html);

const QRectF paintRect = writer.pageLayout().paintRectPixels(writer.resolution());
doc.setPageSize(paintRect.size());
doc.drawContents(&writer, paintRect);

2. 编码：中文乱码的第一条路 #

setHtml() 的参数是 QString。HTML 来自文件或网络时，必须按 UTF-8 解码，别让 QString 从字节数组隐式构造：

cpp
// 错：Qt5 里这条走 Latin-1，中文全变问号
doc.setHtml(QByteArray("<p>中文</p>"));

// 对：显式声明编码
QFile f(QStringLiteral(":/template.html"));
if (f.open(QIODevice::ReadOnly)) {
    doc.setHtml(QString::fromUtf8(f.readAll()));
}

HTML 头部写 <meta charset="utf-8"> 只对人有用，QTextDocument 不看这个标签，它只认你传进来的 QString 已经是对的字符。

3. 默认字体与边距 #

cpp
QFont base(QStringLiteral("Microsoft YaHei"));
base.setPointSize(10);
doc.setDefaultFont(base);      // 必须在 setHtml 之前
doc.setDocumentMargin(36);     // 文档四周留白，单位像素

顺序反了，HTML 里没写 font-family 的段落会沿用文档原来的默认字体。

4. 带图片的 HTML #

<img src="..."> 用相对路径时，得告诉文档去哪儿找资源：

cpp
doc.setBaseUrl(QUrl::fromLocalFile(QStringLiteral("D:/report/assets/")));
doc.setHtml(html);      // html 里写 <img src="logo.png">

路径带中文或空格时用 QUrl::fromLocalFile()，别手动拼 file:///，否则取不到图，出来是个空白框。

七、排版与分页 #

QPainter 不会自动换页。画到纸外的东西不是流到下一页，是直接消失。分页必须自己算、自己翻。

这跟 HTML 那条路正好相反：QTextDocument::print() 内部按 QTextFrame 自动翻页，你什么都不用管；QPainter 这条路，每一页的版面都得重新起算。

1. 可用高度怎么拿 #

方法 含义 单位
printer.paperRect() 整张纸，含不可打印区 设备像素
printer.pageRect() 可打印区 设备像素
writer.pageLayout().paintRectPixels(dpi) 可打印区 设备像素
writer.pageLayout().margins() 页边距 QMarginsF
painter.viewport() 当前变换后的可绘制矩形 逻辑坐标

QPrinter 上 paperRect() 与 pageRect() 的差就是物理不可打印边距。QPdfWriter 没这个概念，它的页边距完全由 setPageMargins() 决定：

cpp
const QRect usable =
    writer.pageLayout().paintRectPixels(writer.resolution());
const int bottom = usable.bottom();     // 超过这个 Y 就该翻页

2. 手动翻页的骨架 #

cpp
int y = usable.top() + margin;

QPainter painter;
if (!painter.begin(&writer)) {
    return;
}

for (const Row &r : rows) {
    const int rowH = lineH + 8;

    if (y + rowH > usable.bottom()) {     // 放不下，先翻页
        writer.newPage();
        y = usable.top() + margin;
        drawTableHeader(painter, usable, y);   // 每页重画表头
        y += headerH;
    }

    drawOneRow(painter, r, y);
    y += rowH;
}

painter.end();

三件事：翻页前判断、翻页后重置 y、翻页后补表头。少了第三条，第二页起就没有列名，读者不知道哪列是什么。

3. newPage() 会重置变换 #

newPage() 之后，painter 的变换矩阵、视图窗口、视图原点全部回到默认，前面 scale() 过的比例不留。

cpp
writer.newPage();
painter.resetTransform();             // 显式复位更保险
preparePageLayout(painter, writer);   // 重设字体、重算边距

前面那段「一张图铺满一页」的代码能跑，是因为它只画一页。要画多页，scale() 必须放进每页的循环里。

4. 页脚与页码 #

页码要知道总页数，总页数得画完才知道。两种处理：先排一遍算总页数再排第二遍真正画（耗时翻倍，页码准），或者只写当前页号。只写当前页时：

cpp
void drawFooter(QPainter &p, const QRect &usable, int pageNo)
{
    p.drawText(QRect(usable.left(), usable.bottom() - 40,
                     usable.width(), 40),
               Qt::AlignRight | Qt::AlignVCenter,
               QStringLiteral("第 %1 页").arg(pageNo));
}

画表格分隔线同理，drawLine() 的 Y 必须小于 usable.bottom()，超出去那条线不会报错、也不会跑到下一页，它就没了。

5. 三种分页方案对照 #

方案 谁负责翻页 难度 适合
QPainter + 手动 newPage() 自己 中 自定义版式、一页一张图
QTextDocument::print() 框架 低 HTML 报表、长文本
控件快照切片 自己 低 界面原样导出

三条路的分页代价其实一样：都要求你清楚「一页能放多少」。区别只是前两条和第三条要写代码，中间那条不用。

八、打印预览 QPrintPreviewDialog #

QPrintPreviewDialog 是一个现成的预览窗口：左边是纸的缩略图，工具栏里有缩放、上下页，还有打印。它不负责画任何东西，只负责显示和翻页。画什么由你决定，靠信号来回。

环节 谁做 说明
建 QPrinter 你 纸张、方向、分辨率
建 QPrintPreviewDialog 你 构造参数就是这个 QPrinter
paintRequested(QPrinter*) 对话框发出 每页每次重绘都会发
往里画 你的槽函数 收到就画，画完返回
exec() 你 阻塞到用户关窗

1. 接法 #

cpp
void MainWindow::on_btnPreview_clicked()
{
    QPrinter printer(QPrinter::HighResolution);
    printer.setPageSize(QPrinter::A4);
    printer.setOrientation(QPrinter::Portrait);

    QPrintPreviewDialog preview(&printer, this);
    preview.setMinimumSize(1000, 600);      // 太小缩略图看不清

    connect(&preview, &QPrintPreviewDialog::paintRequested,
            this, &MainWindow::onPreviewPaintRequested);

    preview.exec();                         // 关窗后返回
}

槽函数签名固定是 void (QPrinter*)，别把参数写成裸 QPrinter 值。

2. 槽里画什么 #

cpp
void MainWindow::onPreviewPaintRequested(QPrinter *printer)
{
    QPainter painter;
    if (!painter.begin(printer)) {
        return;
    }

    QRect page = painter.viewport();

    QFont font = painter.font();
    font.setPixelSize(printer->logicalDpiY() * 14 / 72);
    painter.setFont(font);

    painter.drawText(page.adjusted(80, 80, -80, -80),
                     Qt::AlignHCenter | Qt::AlignTop,
                     tr("设备运行日报"));

    painter.end();
}

printer->logicalDpiY() 在预览里的值和真打印时一致，所以预览看到的字，打出来一样大。这是预览能当所见即所得用的前提。

3. 三条硬规则 #

槽会被反复调用。 用户缩放、翻页、切单双页，对话框都重新发 paintRequested。槽里必须是纯绘制：不改业务数据、不递增页码计数、不往容器里塞元素。写一次变一次状态，翻两页页码就乱跳。

每次进来都从头画。 别想「接着上一页画」，每次都是新的 QPainter，begin() 之后就当空白纸。

预览只吃 QPrinter。 构造参数类型是 QPrinter*，QPdfWriter 用不了。要预览 PDF 输出，就把 QPrinter 设成 PdfFormat，预览里看到的和存下来的 PDF 是同一套渲染。

4. 预览里的打印按钮 #

工具栏上的打印按钮走它自己内部的 QPrintDialog，不用你写代码。用户点完就进系统打印队列，你的槽被调一次，内容就出去了。想改默认行为，在 exec() 之前把 QPrinter 配好：

cpp
printer.setCopyCount(1);
printer.setDuplex(QPrinter::DuplexLongSide);

5. 预览一张截图 #

界面原样预览，逻辑跟导出 PDF 一样，只是设备换成预览给的 QPrinter：

cpp
void MainWindow::onPreviewSnapshot(QPrinter *printer)
{
    QPixmap pixmap = ui->stackedWidget->grab(ui->stackedWidget->rect());

    QPainter painter;
    if (!painter.begin(printer)) {
        return;
    }

    QRect vp = painter.viewport();
    const qreal k = qMin(qreal(vp.width())  / pixmap.width(),
                         qreal(vp.height()) / pixmap.height());
    painter.scale(k, k);
    painter.drawPixmap(0, 0, pixmap);
    painter.end();
}

qMin 取两个比例里小的那个，图完整进纸、不裁边、不变形。只取宽度比例，长条形控件会上下切掉。

九、打印对话框与打印流程 #

QPrintDialog 是系统打印设置窗口的 Qt 封装：选打印机、页码范围、份数、方向。它不改渲染逻辑，只改 QPrinter 上的配置。

1. 文本控件直接打印 #

cpp
void MainWindow::on_btnPrint_clicked()
{
    QPrinter printer;
    if (printer.printerName().isEmpty()) {
        QMessageBox::warning(this, tr("打印"), tr("没有可用的打印机"));
        return;                          // 一台都没装，别弹空对话框
    }

    QPrintDialog dlg(&printer, this);

    if (ui->textEdit->textCursor().hasSelection()) {
        dlg.addEnabledOption(QAbstractPrintDialog::PrintSelection);
    }

    if (dlg.exec() == QDialog::Accepted) {
        ui->textEdit->print(&printer);    // 文本控件自带分页
    }
}

printerName() 为空说明系统里没装任何打印机，此时 QPrintDialog 弹出来一片空白，用户只能点取消。提前拦掉。addEnabledOption() 必须在 exec() 之前调，之后加不生效。

2. 控件快照打印 #

cpp
void MainWindow::on_btnPrintSnapshot_clicked()
{
    QPixmap pixmap = ui->stackedWidget->grab(ui->stackedWidget->rect());

    QPrinter printer(QPrinter::HighResolution);
    printer.setPageSize(QPrinter::A4);
    printer.setOrientation(QPrinter::Landscape);

    QPrintDialog dlg(&printer, this);
    if (dlg.exec() != QDialog::Accepted) {
        return;
    }

    QPainter painter;
    if (!painter.begin(&printer)) {
        return;
    }

    QRect vp = painter.viewport();
    const qreal k = qMin(qreal(vp.width())  / pixmap.width(),
                         qreal(vp.height()) / pixmap.height());
    painter.scale(k, k);
    painter.drawPixmap(0, 0, pixmap);
    painter.end();
}

QPrinter 要先配好纸张再交给对话框。对话框里用户会覆盖方向、纸张，你在 exec() 之后设的会被忽略，之前设的才是默认值。

3. 完整打印流程 #

阶段 代码 用户能改的
准备 QPrinter printer(QPrinter::HighResolution); —
默认值 setPageSize / setOrientation / setCopyCount 对话框里全部可改
校验 printer.printerName().isEmpty() —
交互 QPrintDialog dlg(&printer, this); 打印机、范围、份数、方向
确认 dlg.exec() == QDialog::Accepted —
输出 print() 或 QPainter —

用 print() 的控件自动遵守页码范围；自己用 QPainter 画的，得从 printer.pageRange().fromPage() 起算，QPrinter 不会替你跳过前面的页，newPage() 调几次仍由你定。

没进队列时 printer.printerState() 返回 QPrinter::Error，常见原因是打印机离线、纸盒空、驱动装错。别在界面线程里死等，更别用 QThread::sleep() 轮询。

十、保存与浏览 #

导出 PDF 的前半段是「存到哪儿」，用 QFileDialog；后半段是「怎么打开看」，Qt 自己不做，得借外力。

1. 保存对话框与后缀补全 #

cpp
QString fileName = QFileDialog::getSaveFileName(
    this,
    tr("导出PDF文件"),
    QStandardPaths::writableLocation(QStandardPaths::DocumentsLocation),
    tr("PDF 文档 (*.pdf)"));

if (fileName.isEmpty()) {
    return;                              // 用户取消
}

if (QFileInfo(fileName).suffix().isEmpty()) {
    fileName.append(".pdf");
}

三点：第三个参数给默认目录（文档目录、上次导出目录），比空串好用；getSaveFileName() 不会自动补后缀，得自己补，否则存出来没扩展名，双击打不开；用户选了已存在的文件，对话框默认会问是否覆盖，这个确认不用自己写。记住上次路径用 QSettings 存一个 key，存成功后回写 QFileInfo(fileName).absolutePath()，下次当默认目录传进去。

2. 用系统程序打开 #

Qt 没有内置 PDF 渲染能力，也没有「打开 PDF 的控件」。最快的办法交给系统上已装的阅读器，开一个进程：

cpp
void MainWindow::on_btnBrowse_clicked()
{
    const QString fileName = QFileDialog::getOpenFileName(
        this, tr("选择文件"), QString(),
        tr("PDF 文档 (*.pdf);;所有文件 (*.*)"));

    if (fileName.isEmpty()) {
        return;
    }

    QProcess *p = new QProcess(this);        // 挂父对象，自动回收
    p->startDetached(QStringLiteral("C:\\Program Files (x86)\\Foxit Software\\"
                                    "Foxit Reader Plus\\FoxitReaderPlus.exe"),
                     QStringList() << fileName);
}

好处就一条：两个函数调完能看。代价得说清：

项目 进程方案 第三方库方案
代码量 两行 编译库、写渲染、写翻页
依赖 用户机器得装了阅读器 库随程序发布
可控性 无，窗口是别人的 完全可控
体积 零 库几十 MB
适合 只求打开看一眼 做真正的阅读器

它的问题很直白：路径写死，换台机器立刻失效；用户没装这个阅读器就开不起来。换成系统默认关联程序就稳了：

cpp
QDesktopServices::openUrl(QUrl::fromLocalFile(fileName));

它按文件关联找程序，Windows 上走 ShellExecute，Linux 上走 xdg-open，Mac 上走 open。返回 bool，失败提示「系统没有关联 PDF 阅读器」即可。

3. 自己做阅读器要走 Poppler #

Qt 官方不带 PDF 解析，Poppler 加 poppler-qt5 能做。流程是 Poppler::Document::load() 打开，page(i)->renderToImage(150, 150) 出一张 QImage，贴到 QScrollArea 里的 QLabel 上，翻页就是换 i。代价在编译：Windows 上要处理 freetype、fontconfig、libjpeg、zlib 一堆依赖，版本一错就卡住。只做「导出个 PDF 给人看」，这条路不值得走。

4. 存完校验一下 #

QFileInfo(fileName).size() 是 0，说明文件建出来了但内容没写进去——QPainter::begin() 失败就是这个现象。查目标目录是否可写、文件是否被别的程序占用。

十一、中文与字体嵌入 #

PDF 里的中文出问题，原因只有两个，分开查很快：

  1. 字体没嵌进 PDF —— 你的机器正常，换台机器全是方块
  2. 编码不对 —— 你自己的机器上就已经是乱码

判据很干脆：自己机器上对、只有别人打开不对，是字体问题；自己机器上就不对，是编码问题。

症状 原因 往哪儿查
本机正常，别人打开是方块 字体没嵌入 PDF 属性里的字体列表
本机就是问号或方块 编码错 QString::fromUtf8() 漏了
个别汉字显示成方框 字体缺这个字形 换字体族
表格里中文挤在一起 字体不匹配列宽 换字体或调列宽

1. 字体必须嵌入 #

PDF 里存的不是「字」，是「字形编号 + 字体引用」。字体没嵌入，阅读器只能拿本机字体去猜，猜不到就画方块。字体必须嵌进 PDF，这不是优化项，是能不能打开的问题。

QPrinter 上默认开着，setFontEmbeddingEnabled(true)，不用手写。QPdfWriter 没这个开关，它一定把用到的字体以子集方式写进文件。

验证嵌入情况，装 poppler-utils，一行命令看完：

text
$ pdffonts report.pdf
name                        type       emb sub uni object ID
ABCDEF+MicrosoftYaHei-Bold  TrueType   yes yes yes     12  0
GHIJKL+SimSun               TrueType   yes yes yes     15  0

emb 列是 yes 就嵌进去了。全是 no，或者字体名变成 Helvetica、Times-Roman，说明绘制时没指定中文字体，Qt 走了默认西文字体。

2. 字体族得自己指定 #

cpp
QFont f;
f.setFamily(QStringLiteral("Microsoft YaHei"));
f.setPointSize(10);
painter.setFont(f);

不指定字体族，QPainter 用 QApplication 默认字体，落到 PDF 里映射成 Arial 或 Times New Roman，中文靠系统临时 fallback 补，补出来的字体信息不进 PDF。HTML 那条路设在文档上，且必须在 setHtml() 之前。

跨平台发布时字体名不一样，跑一遍 QFontDatabase 挑一个存在的，给逻辑名挂替身：QFont::insertSubstitution("MyCJK", family)，代码里统一写 MyCJK，换平台只改一处。

3. 编码：乱码的第二条路 #

drawText() 和 setHtml() 收的都是 QString，内部 UTF-16，跟源文件编码无关。出事的地方在 QByteArray 转 QString 这一步。

场景 容易写错 正确写法
读 UTF-8 文件 QString(bytes) QString::fromUtf8(bytes)
读 Windows 本地编码 QString(bytes) QString::fromLocal8Bit(bytes)
解析 JSON 或网络响应 QString(bytes) QString::fromUtf8(bytes)
写文件 text.toLocal8Bit() text.toUtf8()

QString(const char*) 在 Qt5 里走 Latin-1 转换，中文一进就坏。看到 QByteArray 变 QString，先找 fromUtf8。

MSVC 下还有一层：源文件本身。源文件存成 UTF-8 无 BOM，MSVC 按本地代码页（GBK）解析里面的中文字面量，编译进去就已经是错的。修法是加 QMAKE_CXXFLAGS += /utf-8（CMake 用 add_compile_options(/utf-8)），或者把源文件存成 UTF-8 带 BOM。

4. 嵌入会让文件变大 #

字体子集嵌入会给文件加几百 KB 到几 MB，一次导出几十个 PDF 要注意磁盘占用。反过来为省体积关掉嵌入，等于让文件在别人机器上打不开，不划算。

十二、易错点速查 #

前面各节踩过的坑收成一张表，出问题先在这里对一遍。

# 症状 原因 处理
1 PDF 是空白页 int x = 宽 / 宽; 整数除法得 0 用 qreal 做除法
2 只输出了第一页 忘了 newPage() 每页画完调一次
3 内容少了一截 画超出页高，被静默裁剪 翻页前判断 y + 高 > usable.bottom()
4 第二页没有表头 翻页后没重画 newPage() 后调 drawTableHeader()
5 第二页坐标全乱 newPage() 重置了变换矩阵 每页重新 scale() 和算边距
6 字小到看不清 HighResolution 下沿用屏幕坐标 换 ScreenResolution 或按 DPI 换算
7 字巨大、挤出纸外 ScreenResolution 下用了高分辨率坐标 同上，两个方向都要对
8 大片留白 纸用 A4，内容只有一小块 自定义纸张尺寸贴合内容
9 宽高颠倒 setPaperSize() 宽高写反，靠横竖翻转凑 按真实宽高给 QSizeF
10 预览翻页页码乱跳 槽函数里改了业务状态 槽里只画，不改数据
11 预览是空白 paintRequested 没连 检查 connect 和槽签名
12 QPdfWriter 预览不了 预览只吃 QPrinter 用 QPrinter 开 PdfFormat
13 打印对话框一片空白 系统没装打印机 printerName().isEmpty() 提前拦
14 导出文件是 0 字节 QPainter::begin() 失败 查目录权限、文件占用
15 文件双击打不开 没补 .pdf 后缀 补全后缀再输出
16 中文全是方块 字体没嵌入 指定中文字体族，pdffonts 验 emb
17 中文全是问号 QString(bytes) 走了 Latin-1 改 QString::fromUtf8()
18 换台机器中文没了 字体未嵌入或用了非嵌入字体 保持 setFontEmbeddingEnabled(true)
19 链接报 undefined symbol .pro 没加模块 QT += printsupport
20 外链阅读器打不开 硬编码了别人机器的路径 改 QDesktopServices::openUrl()
21 打印范围被忽略 自己 QPainter 画时没读 pageRange() 从 fromPage() 起算
22 表格数字不齐 列宽固定但字宽不定 数字列 Qt::AlignRight

三条主线记住就够了。

一是 PDF 和打印是同一套 API。QPdfWriter 和 QPrinter 都是 QPaintDevice，绘制代码写一份，换设备两边跑，差别只在纸张设置和能不能弹对话框。

二是分页必须自己算。QPainter 不会自动翻页，newPage() 之后所有版面重新起算，超出去的内容直接消失，不会流到下一页。

三是中文要管两头。字体得嵌进 PDF，字符串得按正确编码进 QString。断一个就是乱码，症状还分得清：本机对、别处错是字体，本机就错是编码。
