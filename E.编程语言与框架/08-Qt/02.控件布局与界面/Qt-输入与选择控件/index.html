本篇讲 Qt 的输入类控件：QComboBox 下拉框、QLineEdit 行编辑、QTextEdit 富文本、自定义搜索框、QCompleter 自动补全，以及怎么把 QToolTip 用在取词上。

讲什么：这些控件的常用 API；QComboBox 背后的 model/view 结构；QLineEdit 的三种输入约束手段；密码框的事件级封锁；复选下拉框的完整封装。

不讲什么：布局管理器和 QSS 的整体写法，属于同目录的布局与样式篇；模型视图框架的通用理论，属于 03.模型视图与表格；QML 侧的输入控件，属于 07.QML与Quick。

跨篇指路：QComboBox 的委托绘制有更细的展开，在模型视图篇的委托部分；QTableView 的复选框和自定义绘制也在那边。

一、输入控件的共同点 #

输入控件放在一起看能省掉不少重复记忆。形状差别很大，骨架是同一套。 它们都直接或间接继承 QWidget，QSS 改外观、setEnabled、setFocusPolicy、setToolTip 对每个控件都成立。焦点策略这条在登录框这种多输入框场景里会用到，要 Tab 进得去，控件得有 Qt::StrongFocus。状态变化都靠信号往外抛，区别只在粒度：QLineEdit 抛 textChanged，QComboBox 抛 currentIndexChanged 和 currentTextChanged，QTextEdit 抛 textChanged 和 cursorPositionChanged。注意 QComboBox 的 currentIndexChanged 在代码里调 setCurrentIndex 也会触发，activated 才只在用户操作时触发，这个差别是后面一堆 bug 的源头。

控件 定位 数据载体 高频信号
QLineEdit 单行纯文本 QString textChanged、textEdited、editingFinished、returnPressed
QTextEdit 多行富文本 QTextDocument textChanged、cursorPositionChanged、selectionChanged
QComboBox 选项选择 QAbstractItemModel currentIndexChanged、currentTextChanged、activated
QCompleter 补全助手，不是控件 QAbstractItemModel activated

QCompleter 那行容易看错：它继承 QObject，不是 QWidget，自己不带界面。候选弹窗由内部实现，你只负责给模型、挂到输入框上。 组合关系记三条：QComboBox 开了 setEditable(true) 后内部新建一个 QLineEdit 当编辑区，combo->lineEdit() 拿到的就是它；QLineEdit 挂上 QCompleter，setCompleter() 一行就开补全；QTextEdit 内部是一个 QTextDocument，格式操作最后都落到文档加光标上。 合起来看，本篇九个素材排在一条线上：单行文本 → 加约束 → 加补全 → 变成选项 → 变成富文本。

二、QComboBox 的基本用法 #

1. 插入与读取 #

addItem 有两个版本，只给文本，或者文本加附带数据：

cpp
QComboBox *proxy_combo = new QComboBox(this);
proxy_combo->addItem("no proxy");        // 只给文本
proxy_combo->addItem("http", 2);         // 文本 + 附带数据（写进 Qt::UserRole）

批量插用 addItems(QStringList)，中间插用 insertItem(index, text, data)，改文本用 setItemText(index, text)，删一项用 removeItem(index)，清空用 clear()。读当前项三个入口：

cpp
int idx       = proxy_combo->currentIndex();   // 空的时候是 -1
QString text  = proxy_combo->currentText();
QVariant data = proxy_combo->currentData();    // 默认读 Qt::UserRole
QVariant next = proxy_combo->currentData(Qt::UserRole + 1);

currentData 默认读 Qt::UserRole，塞在别的 role 就得显式传，这点官方文档写得很轻。

2. 把枚举值当附带数据 #

业务里常见的是下拉框显示文本、背后存枚举，addItem 第二参直接给枚举：

cpp
typedef enum {
    PROXY_NONE,      // 没有代理
    PROXY_BROWSER,   // 浏览器代理
    PROXY_HTTP,      // HTTP 代理
    PROXY_SOCKS4,    // SOCKS4 代理
    PROXY_SOCKS5,    // SOCKS5 代理
} Proxy_Types;
proxy_combo->addItem("no proxy",    PROXY_NONE);
proxy_combo->addItem("use browser", PROXY_BROWSER);
proxy_combo->addItem("http",        PROXY_HTTP);
proxy_combo->addItem("socks4",      PROXY_SOCKS4);
proxy_combo->addItem("socks5",      PROXY_SOCKS5);
// 取值时转回去
Proxy_Types type = static_cast<Proxy_Types>(proxy_combo->currentData().toInt());

这样界面文本改了不影响逻辑，枚举值改了也不影响显示，两边解耦。

3. 信号怎么选 #

信号 触发时机 用在哪
currentIndexChanged(int) 当前项变了，代码 setCurrentIndex 也触发 跟着索引走的联动
currentTextChanged(QString) 当前文本变了 文本驱动的过滤
activated(int) 用户主动选中了一项 只认用户操作的业务
highlighted(int) 鼠标在下拉项上划过 预览、状态栏提示
editTextChanged(QString) 可编辑状态下编辑区文本变了 输入中过滤候选

Qt5 里 currentIndexChanged 有两个重载，连信号必须带 QOverload 指明：

cpp
connect(proxy_combo, QOverload<int>::of(&QComboBox::currentIndexChanged),
        this, &MyWidget::proxyChange);

Qt6 去掉了 QString 重载，只剩 int 版，新版本可以直接写 &QComboBox::currentIndexChanged。老代码里保留 QOverload 不会错。

4. 常用设置项 #

接口 作用 备注
setEditable(bool) 编辑区可输入 内部会新建 QLineEdit
setInsertPolicy(policy) 新输入的文本插到哪个位置 配合 editable 用
setMaxCount(int) 列表最多保留多少项 0 表示不限
setMaxVisibleItems(int) 下拉弹出最多显示几行 超出出滚动条
setDuplicatesEnabled(bool) 允许重复项 默认不允许
setSizeAdjustPolicy(policy) 宽度怎么跟着内容变 AdjustToContents 常用
setMinimumContentsLength(int) 按字符数算最小宽度 配合上一项
setPlaceholderText(QString) 空值时的水印 只在 editable 下显示
setIconSize(QSize) 项图标的尺寸 图标不缩放时最明显
setFrame(bool) 是否画边框 想全靠 QSS 画时关掉
setModel(QAbstractItemModel *) 换数据源 见第三章
setView(QAbstractItemView *) 换下拉视图 QSS 项样式不生效时必做
setItemDelegate(QAbstractItemDelegate *) 换绘制方式 自定义显示的主入口
setLineEdit(QLineEdit *) 换内部编辑框 可塞只读框当展示条

5. 用 QSS 调下拉列表 #

默认下拉列表行高很局促，QSS 能改行高、边框、下拉箭头：

cpp
QComboBox *network_type = new QComboBox(this);
// 必须先换掉默认视图，否则 QComboBox QAbstractItemView::item 的样式不生效
network_type->setView(new QListView());
network_type->setStyleSheet(
    "QComboBox { border: 1px solid gray; }"
    "QComboBox QAbstractItemView::item { height: 20px; }"
    "QComboBox::down-arrow { image: url(:/icon/arrowdown); }"
    "QComboBox::drop-down { border: 0px; }"
);

setView(new QListView()) 是常被漏掉的一行。默认视图是内部私有类，选择器匹配不上，换成标准 QListView 之后 item 级别的样式才生效。

6. 可编辑模式下的样式失真 #

打开 setEditable(true) 之后，QSS 美工会露出一处毛病。先看样式：

css
QComboBox { border-radius: 2px; border: 1px solid gray; }
QComboBox:hover { border-radius: 3px; border-width: 2px; border-color: rgb(50, 180, 250); }
QComboBox::down-arrow { image: url(:/login/arrow_down); }
QComboBox::drop-down { width: 20px; border-left: 1px solid gray; background: transparent; }
QComboBox::drop-down:hover { border-left: 1px solid lightgray; background: rgb(220, 240, 250); }

不开可编辑时，悬停四周边框整体加粗成 2px 浅蓝；开了可编辑，悬停时只有右侧下拉箭头附近的边框加粗，左半边编辑区还停在 1px 灰色。 原因是内部动态创建了一个 QLineEdit 当编辑区，左半边显示的其实是它的边框和背景。父级的 border-width 只影响外缘，内部这个保持 1px 默认样式，把变粗的蓝边盖住了。验证一行：

cpp
combo_box->lineEdit()->setStyleSheet("border: 1px solid red;");

跑起来能看到可编辑区内部多出一个红框，位置正好是那块 1px 灰边的范围。 改法一，消掉内部编辑框的边框和外边距，把父级边框露出来：

cpp
combo_box->lineEdit()->setStyleSheet("margin: 1px; border: 0px;");

改法二更干净，父级留 padding，让子控件被向内挤压：

css
QComboBox { border-radius: 2px; border: 1px solid gray; padding: 2px; }

留出 2px 内边距后，内部渲染框自动往里收，四周边框都归 QComboBox 自己画，开不开可编辑、悬停变不变粗都对称。工程里优先用改法二，不用碰内部控件。

三、QComboBox 的模型与代理 #

这一章是本篇的骨架。QComboBox 看着就是「一个文本框加一个箭头」，内部其实是 QListView 加 QAbstractItemModel 的封装，addItem 只是往默认模型追加一行的便利写法。 记住这条分界线：只要显示方式超出「一行纯文本加可选图标」，就得往下走一层，用 setItemDelegate 换绘制，或者用 setModel 换数据源。

1. 三个可换的部件 #

cpp
QAbstractItemModel *m = proxy_combo->model();   // 数据
QAbstractItemView  *v = proxy_combo->view();    // 下拉弹出时用的视图
proxy_combo->setModel(other_model);             // 换数据
proxy_combo->setView(new QListView());          // 换视图（QSS 项样式也靠它）
proxy_combo->setItemDelegate(new MyDelegate()); // 换绘制

model 出数据、view 出区域、delegate 出像素。QComboBox 自己负责折叠状态那一行，把模型里当前索引那格的数据取出来，画到编辑区或者按钮上。按需求挑路径：

需求 该用哪个接口 代价
只加文本和附带数据 addItem / insertItem 最省事
换画法，多颜色、多列、加图标 setItemDelegate 中等，写 paint 和 sizeHint
数据来自别处或结构复杂 setModel 加自定义模型 高，但最灵活
一行里要塞真控件（按钮、复选框） setView 加 setItemWidget 中等，要处理事件穿透

2. 便利写法对应的模型操作 #

addItem("http", 2) 展开就是往默认模型追加一行：

cpp
// addItem("http", 2) 的等价写法
QStandardItemModel *model = qobject_cast<QStandardItemModel *>(proxy_combo->model());
if (model) {
    QStandardItem *item = new QStandardItem("http");
    item->setData(2, Qt::UserRole);
    model->appendRow(item);
}

qobject_cast 这里要判空，QComboBox 的默认模型类型没有写进公开接口。要长期用模型接口，就自己 setModel 一个 QStandardItemModel，别依赖默认那个。

3. 用 setItemDelegate 换绘制 #

需求是每行左边主文本、右边灰色副文本，比如 socks5 加端口号：

cpp
class TwoColumnDelegate : public QStyledItemDelegate
{
public:
    explicit TwoColumnDelegate(QObject *parent = nullptr)
        : QStyledItemDelegate(parent) {}
    void paint(QPainter *painter, const QStyleOptionViewItem &option,
               const QModelIndex &index) const override
    {
        QStyleOptionViewItem opt = option;
        initStyleOption(&opt, index);
        // 先让样式把底画完（选中态、悬停态靠它），清掉 opt.text 避免重画文本
        opt.text.clear();
        QStyle *style = opt.widget ? opt.widget->style() : QApplication::style();
        style->drawControl(QStyle::CE_ItemViewItem, &opt, painter, opt.widget);
        const QRect r = opt.rect.adjusted(4, 0, -4, 0);
        painter->save();
        painter->setPen(index.data(Qt::ForegroundRole).value<QColor>());
        painter->drawText(r, Qt::AlignLeft | Qt::AlignVCenter,
                          index.data(Qt::DisplayRole).toString());
        painter->setPen(QColor(150, 150, 150));      // 右侧副文本走 UserRole + 1
        painter->drawText(r, Qt::AlignRight | Qt::AlignVCenter,
                          index.data(Qt::UserRole + 1).toString());
        painter->restore();
    }
    QSize sizeHint(const QStyleOptionViewItem &option,
                   const QModelIndex &index) const override
    {
        QSize s = QStyledItemDelegate::sizeHint(option, index);
        s.setHeight(qMax(s.height(), 24));
        return s;
    }
};

挂上去，副文本塞进模型：

cpp
proxy_combo->setView(new QListView());      // 不换视图，委托的 sizeHint 未必生效
proxy_combo->setItemDelegate(new TwoColumnDelegate(proxy_combo));
QStandardItemModel *model = new QStandardItemModel(proxy_combo);
QStandardItem *item = new QStandardItem("socks5");
item->setData("1080", Qt::UserRole + 1);
model->appendRow(item);
proxy_combo->setModel(model);

两个细节：initStyleOption 之后不清 opt.text，样式会把文本按默认方式再画一次，得到两层重叠的字；setView 不换成标准 QListView，委托的尺寸计算在部分样式下会被忽略。

4. 一行里塞真控件 #

真实场景是 QQ 登录界面的账号历史列表，每行一个账号、行尾一个删除按钮：

text
+------------------------------+
| safe_0@sina.com          [x] |   <- 点 [x] 抛 removeAccount
+------------------------------+

这不是 delegate 的活儿，delegate 只负责画，接不到按钮点击。做法是拿 QListWidget 当模型和视图，每行用 setItemWidget 挂一个真的 QWidget。先写行控件的声明：

cpp
// AccountItem.h
#pragma once
#include <QWidget>
#include <QLabel>
#include <QPushButton>
#include <QMouseEvent>
class AccountItem : public QWidget
{
    Q_OBJECT
public:
    explicit AccountItem(QWidget *parent = nullptr);
    void setAccountNumber(const QString &account_text);
    QString getAccountNumber() const;
signals:
    void showAccount(const QString &account);
    void removeAccount(const QString &account);
protected:
    // 自定义点击，避免按删除按钮时顺带触发整行选中
    void mousePressEvent(QMouseEvent *event) override;
    void mouseReleaseEvent(QMouseEvent *event) override;
private:
    QLabel      *account_number_label;
    QPushButton *delete_button;
    bool         is_mouse_press;
};

实现，布局是 QLabel 加弹簧加 QPushButton：

cpp
AccountItem::AccountItem(QWidget *parent)
    : QWidget(parent), is_mouse_press(false)
{
    account_number_label = new QLabel(this);
    delete_button = new QPushButton(this);
    QPixmap delete_pixmap(":/loginDialog/delete");
    delete_button->setIcon(delete_pixmap);
    delete_button->setIconSize(delete_pixmap.size());
    delete_button->setStyleSheet("background: transparent; border: 0px;");
    connect(delete_button, &QPushButton::clicked, this, [this]() {
        emit removeAccount(account_number_label->text());
    });
    QHBoxLayout *layout = new QHBoxLayout(this);
    layout->addWidget(account_number_label);
    layout->addStretch();
    layout->addWidget(delete_button);
    layout->setContentsMargins(5, 5, 5, 5);
    layout->setSpacing(5);
    setLayout(layout);
}
void AccountItem::setAccountNumber(const QString &account_text)
{ account_number_label->setText(account_text); }
QString AccountItem::getAccountNumber() const
{ return account_number_label->text(); }
void AccountItem::mousePressEvent(QMouseEvent *event)
{
    if (event->button() == Qt::LeftButton)
        is_mouse_press = true;
}
void AccountItem::mouseReleaseEvent(QMouseEvent *event)
{
    Q_UNUSED(event);
    if (is_mouse_press) {
        emit showAccount(account_number_label->text());
        is_mouse_press = false;
    }
}

再挂进 QComboBox：

cpp
QComboBox   *account_combo = new QComboBox(this);
QListWidget *list_widget   = new QListWidget(this);
// 1. 用 QListWidget 的模型和视图替换 QComboBox 默认的那套
account_combo->setModel(list_widget->model());
account_combo->setView(list_widget);
account_combo->setEditable(true);
// 2. 逐行建项并嵌入自定义控件
for (int i = 0; i < 3; ++i)
{
    AccountItem *account_item = new AccountItem(list_widget);
    account_item->setAccountNumber(QString("safe_%1@sina.com").arg(i));
    connect(account_item, &AccountItem::showAccount, this, &LoginDialog::onShowAccount);
    connect(account_item, &AccountItem::removeAccount, this, &LoginDialog::onRemoveAccount);
    QListWidgetItem *list_item = new QListWidgetItem(list_widget);
    list_widget->setItemWidget(list_item, account_item);
}

两个槽，一个填空一个删项：

cpp
void LoginDialog::onShowAccount(const QString &account)
{
    account_combo->setEditText(account);
    account_combo->hidePopup();
}
void LoginDialog::onRemoveAccount(const QString &account)
{
    account_combo->hidePopup();
    if (QMessageBox::question(this, "Remove Account",
                              "Are you sure to remove account?") != QMessageBox::Yes)
        return;
    for (int i = 0; i < list_widget->count(); ++i)
    {
        QListWidgetItem *item = list_widget->item(i);
        AccountItem *account_item =
            qobject_cast<AccountItem *>(list_widget->itemWidget(item));
        if (account_item && account_item->getAccountNumber() == account) {
            list_widget->takeItem(i);       // 先摘掉，顺序不能反
            delete item;
            break;
        }
    }
}

takeItem 会把项从列表摘出并交出所有权，之后必须自己 delete，否则一直在漏。顺序反了，先 delete 再 takeItem，列表里留一个野指针。

5. 别用 itemClicked 填空 #

用 QListWidget 自带的 itemClicked 或 itemPressed 做行选中，回调里调 setEditText 会触动 QComboBox 的刷新流程，结果是下拉框一闪而过、关不掉、或者点了没反应。解决办法是把交互放进行控件自己的 mouseReleaseEvent，让它往外抛信号，QComboBox 完全不知情。上面 AccountItem 重写鼠标事件就是为这个。

四、QComboBox 实现复选 #

原生 QComboBox 只能单选。业务里要勾多个导出字段、多个过滤标签，就得自己封一个。两条路子：

方案 做法 适用
模型/视图委托法 自定义 QStandardItemModel，用 QItemDelegate 画 checkbox 选项多、要求性能，控制逻辑偏复杂
列表视图嵌入法 QListWidget 里挂 QCheckBox，用 setView 和 setModel 塞进下拉框 选项几十条以内，好改好调

下面按第二种走，封一个 MultiComboBox。

1. 结构设计 #

继承 QComboBox，内部做三件事：建一个 QListWidget 当下拉视图，每个 item 用 setItemWidget 挂一个 QCheckBox；把 QComboBox 的 model 和 view 都换成这个 QListWidget 的；绑一个只读 QLineEdit 当展示条，任何复选框状态变化时遍历收集文本，用分号拼接写回去。

2. 头文件 #

cpp
#pragma once
#include <QComboBox>
#include <QListWidget>
#include <QLineEdit>
#include <QCheckBox>
#include <QStringList>
class MultiComboBox : public QComboBox
{
    Q_OBJECT
public:
    explicit MultiComboBox(QWidget *parent = nullptr);
    void addCheckItem(const QString &text, const QVariant &userData = QVariant());
    QStringList     getSelectedTexts() const;
    QList<QVariant> getSelectedData() const;
    void clearAll();
signals:
    void selectionChanged();
private slots:
    void onStateChanged(int state);
    void onTextChanged(const QString &text);
private:
    QListWidget *m_listWidget;
    QLineEdit   *m_lineEdit;
    QString      m_selectedText;   // 当前拼接好的选中明文
    bool         m_isUpdating;     // 状态更新防护锁
};

3. 实现文件 #

cpp
#include "MultiComboBox.h"
MultiComboBox::MultiComboBox(QWidget *parent)
    : QComboBox(parent), m_isUpdating(false)
{
    m_listWidget = new QListWidget(this);
    m_lineEdit   = new QLineEdit(this);
    m_lineEdit->setReadOnly(true);
    // 替换模型、视图、编辑区
    this->setModel(m_listWidget->model());
    this->setView(m_listWidget);
    this->setLineEdit(m_lineEdit);
    // 兜住 QComboBox 的文本回写，否则拼好的内容会被清空
    connect(m_lineEdit, &QLineEdit::textChanged, this, &MultiComboBox::onTextChanged);
}
void MultiComboBox::addCheckItem(const QString &text, const QVariant &userData)
{
    QListWidgetItem *pItem = new QListWidgetItem(m_listWidget);
    m_listWidget->addItem(pItem);
    pItem->setData(Qt::UserRole, userData);
    QCheckBox *pCheckBox = new QCheckBox(this);
    pCheckBox->setText(text);
    m_listWidget->setItemWidget(pItem, pCheckBox);
    connect(pCheckBox, &QCheckBox::stateChanged, this, &MultiComboBox::onStateChanged);
}
void MultiComboBox::onStateChanged(int state)
{
    Q_UNUSED(state);
    if (m_isUpdating)
        return;
    m_isUpdating = true;
    QStringList selectedList;
    for (int i = 0; i < m_listWidget->count(); ++i)
    {
        QCheckBox *pCheckBox = qobject_cast<QCheckBox *>(
            m_listWidget->itemWidget(m_listWidget->item(i)));
        if (pCheckBox && pCheckBox->isChecked())
            selectedList.append(pCheckBox->text());
    }
    m_selectedText = selectedList.join("; ");
    m_lineEdit->setText(m_selectedText);
    m_lineEdit->setToolTip(m_selectedText);   // 宽度不够时悬停看全部
    m_isUpdating = false;
    emit selectionChanged();
}
void MultiComboBox::onTextChanged(const QString &text)
{
    // 底层视图想清空编辑区时，强行复原
    if (!m_isUpdating && text != m_selectedText)
        m_lineEdit->setText(m_selectedText);
}
QStringList MultiComboBox::getSelectedTexts() const
{
    QStringList list;
    for (int i = 0; i < m_listWidget->count(); ++i)
    {
        QCheckBox *pCheckBox = qobject_cast<QCheckBox *>(
            m_listWidget->itemWidget(m_listWidget->item(i)));
        if (pCheckBox && pCheckBox->isChecked())
            list.append(pCheckBox->text());
    }
    return list;
}
QList<QVariant> MultiComboBox::getSelectedData() const
{
    QList<QVariant> dataList;
    for (int i = 0; i < m_listWidget->count(); ++i)
    {
        QListWidgetItem *pItem = m_listWidget->item(i);
        QCheckBox *pCheckBox = qobject_cast<QCheckBox *>(m_listWidget->itemWidget(pItem));
        if (pCheckBox && pCheckBox->isChecked())
            dataList.append(pItem->data(Qt::UserRole));
    }
    return dataList;
}
void MultiComboBox::clearAll()
{
    m_isUpdating = true;
    m_listWidget->clear();
    m_selectedText.clear();
    m_lineEdit->clear();
    m_isUpdating = false;
}

和普通 QComboBox 一样初始化，只是插项换成 addCheckItem：

5. 那个回写缺陷 #

代码里有两处不显眼但必须有：m_isUpdating 这把锁，和 onTextChanged 的复原逻辑。 原因在 QComboBox 自己的行为。下拉列表展开后，用户点空白处折叠、切走焦点、或者选中某项，QComboBox 都会试图把当前索引那格的数据回写进编辑区。我们用的是只读 QLineEdit 加外部拼接的文本，这一回写就把辛苦拼好的「运维工程师; 测试团队」冲掉，编辑区变空。 onTextChanged 就是在回写发生的瞬间把 m_selectedText 塞回去，m_isUpdating 用来区分这次文本变化是自己写的还是外面冲进来的，避免自己写自己的死循环。

六、QLineEdit 的输入限制与校验 #

三种手段，管的事完全不同，混用会互相打架。

手段 接口 控制什么 介入时机 典型场景
长度 setMaxLength(int) 最多几个字符 超出直接截断 密码 16 位、手机号 11 位
掩码 setInputMask(QString) 每一位的格式和占位符 逐位限制，占位符常驻 日期、电话、IP、序列号
校验器 setValidator(QValidator *) 整体内容是否合法 输入过程判定，非法时提交不出去 数值范围、小数位数、正则

一句话分开：maxLength 砍长度，inputMask 钉格式，validator 判合法性。三者不互相替代。

1. setValidator #

cpp
// 整数范围
QLineEdit *age_edit = new QLineEdit(this);
age_edit->setValidator(new QIntValidator(1, 150, age_edit));
// 浮点，两位小数，禁掉科学计数法
QLineEdit *price_edit = new QLineEdit(this);
QDoubleValidator *dv = new QDoubleValidator(0.0, 99999.99, 2, price_edit);
dv->setNotation(QDoubleValidator::StandardNotation);
price_edit->setValidator(dv);
// 正则：IPv4
QLineEdit *ip_edit = new QLineEdit(this);
QRegularExpression re("^((25[0-5]|2[0-4]\\d|1?\\d?\\d)\\.){3}"
                      "(25[0-5]|2[0-4]\\d|1?\\d?\\d)$");
ip_edit->setValidator(new QRegularExpressionValidator(re, ip_edit));

QDoubleValidator 默认允许 1e5 这种写法，StandardNotation 才能把用户锁在小数格式里。QRegExpValidator 在 Qt5 里还能用，Qt6 已经删了，新代码直接写 QRegularExpressionValidator。 validator 的返回值有三档：Acceptable、Intermediate、Invalid。Intermediate 表示「现在还不合法，但继续输下去会合法」，输入框允许这种状态存在，比如输 - 号、输 0. 的时候。整段都不合法了，输入框会拒绝键盘输入，回车也不发 returnPressed，这就是 validator 顺手把提交也拦了的原因。

2. setInputMask #

字符 含义 字符 含义
9 数字，必填 0 数字，可留空
A 字母，必填 a 字母，可留空
N 字母或数字，必填 n 字母或数字，可留空
X 任意字符，必填 x 任意字符，可留空
> / < 后面字母转大写 / 转小写 ! 关掉大小写转换
\ 转义，把上述字符当普通分隔符 H / B 十六进制 / 二进制字符集 
cpp
QLineEdit *date_edit = new QLineEdit(this);
date_edit->setInputMask("0000-00-00");     // 日期，分隔符是普通字符
QLineEdit *phone_edit = new QLineEdit(this);
phone_edit->setInputMask("9999-9999;_");   // 分号后是空位占位符

写法是 掩码字符串;空位字符，分号后面那个字符决定没输入的位显示什么，常用下划线。掩码里的 -、(、) 这类不在字符表里的符号会被当成固定分隔符，用户删不掉。副作用是控件里一直有占位符，text() 返回的字符串也带着它们，取值前先清干净，或者按掩码位置按位取。

3. setMaxLength #

cpp
QLineEdit *password_edit = new QLineEdit(this);
password_edit->setMaxLength(16);

超出的输入直接被丢掉，连信号都不发。它算的是字符数不是字节数，密码里放中文时按字符算。

4. 三者同时用会怎样 #

  • maxLength 加 validator：先截长度再判合法性。写了 0 到 999 的 QIntValidator，maxLength 又设成 2，用户输 123 会被截成 12，validator 帮不上忙。
  • inputMask 加 validator：冲突。掩码负责格式，validator 拿到的是带占位符的文本，正则几乎全部拒绝。这两个只能选一个。
  • inputMask 加 maxLength：以掩码为准，长度由掩码字符串决定，再设 maxLength 不起作用。
  • 任何组合都要在 editingFinished 里再校验一遍。validator 拦的是键盘输入，粘贴进来的内容、程序 setText 的内容都绕得过去。

七、密码框的特殊处理 #

登录窗口的密码框要求严一档：明文隐藏显示圆点、禁用右键菜单、禁用全选复制粘贴快捷键、禁用鼠标拖拽和双击选中。前两条一行一条，后两条得重写事件。分两步走：控件内部管鼠标和快捷键，父窗口管焦点切换。

1. 子类声明 #

2. 构造与事件实现 #

cpp
PwdLineEdit::PwdLineEdit(QWidget *parent)
    : QLineEdit(parent)
{
    this->setContextMenuPolicy(Qt::NoContextMenu);    // 关掉右键菜单
    this->setEchoMode(QLineEdit::Password);           // 圆点显示
    this->setPlaceholderText(QStringLiteral("请输入密码"));
    this->setMaxLength(16);
    this->setStyleSheet(
        "QLineEdit { border: 1px solid gray; border-radius: 4px;"
        "  padding: 2px 5px; font-size: 12px; color: black; }"
        "QLineEdit:hover { border: 1px solid rgb(70, 200, 50); }"
    );
}
void PwdLineEdit::keyPressEvent(QKeyEvent *event)
{
    // matches() 按当前平台解析标准快捷键，比硬编 Ctrl+A 稳
    if (event->matches(QKeySequence::SelectAll))
        return;
    else if (event->matches(QKeySequence::Copy))
        return;
    else if (event->matches(QKeySequence::Paste))
        return;
    else if (event->key() == Qt::Key_Home)
        this->setCursorPosition(0);
    else if (event->key() == Qt::Key_End)
        this->setCursorPosition(this->text().length());
    else
        QLineEdit::keyPressEvent(event);              // 其余键交给基类
}
void PwdLineEdit::mouseMoveEvent(QMouseEvent *event)
{
    Q_UNUSED(event);
    return;   // 不调基类，拖拽选中彻底失效
}
void PwdLineEdit::mouseDoubleClickEvent(QMouseEvent *event)
{
    Q_UNUSED(event);
    return;   // 双击选词失效
}
void PwdLineEdit::mousePressEvent(QMouseEvent *event)
{
    // 点击位置换成字符下标，按方向挪一格，避开默认的选区算法
    const int clickPos   = cursorPositionAt(event->pos());
    const int currentPos = this->cursorPosition();
    if (clickPos < currentPos)
        this->setCursorPosition(currentPos - 1);
    else if (clickPos > currentPos)
        this->setCursorPosition(currentPos + 1);
    else
        this->setCursorPosition(currentPos);
}

Home、End 这两条得单独写。QLineEdit 默认对 Home 是「移到行首」，但之前按过 Shift 就变成选中整段，这里统一改成只挪光标。mousePressEvent 里为什么要算一格偏移：直接 return 不调基类，光标永远不动，点哪儿都没反应；调用基类又会跑一遍内部选区计算，按住 Shift 点一下就出蓝底。折中办法是自己算下标，手动 setCursorPosition。

3. 父窗口拦截焦点切换 #

控件内部只管键盘和鼠标落在它身上的时候。登录框里还有用户名和域名两个输入框，用户按 Tab 从上一个跳进密码框，Qt 默认会把密码框内容全选高亮。在父窗口装事件过滤器：

cpp
// 构造函数里，给要管控的控件都装上
domain_line_edit->installEventFilter(this);
user_line_edit->installEventFilter(this);
password_line_edit->installEventFilter(this);
login_button->installEventFilter(this);

过滤器里做三件事：接管 Tab 走向、吃掉上下方向键、左右方向键只挪光标：

cpp
bool LoginDialog::eventFilter(QObject *obj, QEvent *event)
{
    if (obj == domain_line_edit || obj == user_line_edit ||
        obj == password_line_edit || obj == login_button)
    {
        if (event->type() == QEvent::KeyPress)
        {
            QKeyEvent *keyEvent = static_cast<QKeyEvent *>(event);
            // 1. Tab：自定义焦点流向，进密码框前先把选区长度清零
            if (keyEvent->key() == Qt::Key_Tab)
            {
                if (domain_line_edit->hasFocus()) {
                    user_line_edit->setFocus();
                } else if (user_line_edit->hasFocus()) {
                    const int len = password_line_edit->text().length();
                    password_line_edit->setSelection(len, len);   // 起终点重合即不选
                    password_line_edit->setFocus();
                } else if (password_line_edit->hasFocus()) {
                    login_button->setFocus();
                } else {
                    focusNextChild();
                }
                return true;          // 拦掉默认的 Tab 处理
            }
            // 2. 上下方向键：直接吃掉，防止触发整行高亮
            if (keyEvent->key() == Qt::Key_Up || keyEvent->key() == Qt::Key_Down)
                return true;
            // 3. 左右方向键：密码框内只挪光标
            if (keyEvent->key() == Qt::Key_Left && password_line_edit->hasFocus())
            {
                const int pos = password_line_edit->cursorPosition();
                if (pos > 0)
                    password_line_edit->setCursorPosition(pos - 1);
                return true;
            }
            if (keyEvent->key() == Qt::Key_Right && password_line_edit->hasFocus())
            {
                const int pos = password_line_edit->cursorPosition();
                if (pos < password_line_edit->text().length())
                    password_line_edit->setCursorPosition(pos + 1);
                return true;
            }
        }
    }
    return QDialog::eventFilter(obj, event);
}

setSelection(len, len) 这招值得记：起点和终点都设成文本长度，选区长度为 0，看上去就是没选中。它必须在 setFocus() 之前调，焦点进去之后再调用，QLineEdit 已经把默认的全选做完了。取明文还是 text()，显示是圆点，取出来是明文：

cpp
PwdLineEdit *passwordEdit = new PwdLineEdit(this);
QString plainPassword = passwordEdit->text();

这套办法挡住的是屏幕肩窥、鼠标复制、脚本模拟 Ctrl+C 这类入门手段。要防内存抓取和键盘记录，得在传输和内存层另想办法，控件层做不到。

八、QCompleter 自动补全 #

QCompleter 不是控件，是个 QObject 助手。给它一个模型，挂到输入框上，用户敲第一个字符它就开始按列表提示。

cpp
QStringList word_list;
word_list << "Java" << "C++" << "C#" << "PHP"
          << "Perl" << "Python" << "Delphi" << "Ruby";
QLineEdit *search_line_edit = new QLineEdit(this);
QCompleter *completer = new QCompleter(word_list, this);
completer->setCaseSensitivity(Qt::CaseInsensitive);
search_line_edit->setCompleter(completer);

候选是静态列表时，把 QStringList 交给构造函数就完事，它内部替你套一个 QStringListModel。要补全文件路径就换成 QFileSystemModel：

cpp
QCompleter *dir_completer = new QCompleter(this);
QFileSystemModel *fs_model = new QFileSystemModel(dir_completer);
fs_model->setRootPath(QDir::rootPath());
dir_completer->setModel(fs_model);
search_line_edit->setCompleter(dir_completer);

老代码这里写的是 QDirModel，那是 Qt4 的类，Qt5 已标废弃，Qt6 直接删掉，迁移时按上面换成 QFileSystemModel。

接口 作用
setMaxVisibleItems(int) 候选弹窗最多显示几条
setCaseSensitivity(Qt::CaseSensitivity) 比对是否区分大小写，默认 CaseSensitive
setModelSorting(ModelSorting) 告知模型是否已排序，决定能不能二分查找
setCompletionMode(Mode) PopupCompletion、InlineCompletion、UnfilteredPopupCompletion
setFilterMode(Qt::MatchFlags) 前缀匹配还是任意位置匹配
setCompletionRole(int) 拿模型哪个 role 去比对
setWrapAround(bool) 翻到底回到开头

两个枚举的取值：Qt::CaseInsensitive 为 0、Qt::CaseSensitive 为 1；QCompleter::UnsortedModel 为 0、CaseSensitivelySortedModel 为 1、CaseInsensitivelySortedModel 为 2。 setModelSorting 别随手填。声明成已排序而模型其实没排，补全内部会走二分查找，结果是「明明列表里有这个词，就是补不出来」，而且不报错，只能靠盯代码查。拿不准就留在 UnsortedModel。 要让用户输过的词进候选池，接 editingFinished 往模型里塞：

cpp
QStringListModel *string_list_model = new QStringListModel(this);
completer->setModel(string_list_model);
connect(search_line_edit, &QLineEdit::editingFinished,
        this, &MainWidget::onEditFinished);
void MainWidget::onEditFinished()
{
    const QString text = search_line_edit->text();
    if (text.isEmpty())
        return;                     // 先挡空串，否则每次失焦都塞一条
    if (!word_list.contains(text, Qt::CaseInsensitive))
    {
        word_list << text;
        string_list_model->setStringList(word_list);
    }
}

重复判断带上 Qt::CaseInsensitive，否则 Python 和 python 会变成两条。还有一个高频需求：比对用英文、候选栏显示中文。setCompletionRole 就是为它准备的，模型里 CompletionRole 那列放英文或拼音，DisplayRole 放中文，补全按前者匹配，弹窗按后者显示。

九、QTextEdit 富文本编辑 #

QTextEdit 能吃 HTML、能排版、能插内联图片。它比 QLineEdit 多出来的那一层就是 QTextDocument，格式操作最后都落到文档加光标上。

接口 作用
setFontWeight(int) 字重，取 QFont::Weight，如 QFont::Bold
setFontItalic(bool) 斜体
setFontUnderline(bool) 下划线
setFontFamily(const QString &) 字体家族，如 Microsoft YaHei
setFontPointSize(qreal) 字号，支持小数
setTextColor(const QColor &) 前景色
setTextBackgroundColor(const QColor &) 文本底色
setAlignment(Qt::Alignment) AlignLeft、AlignRight、AlignCenter、AlignJustify

这些接口作用在当前选区或光标处的插入格式上，没选区就影响接下来输入的字。Qt4 的 alignLeft()、alignCenter() 在 Qt5 里统一收敛成 setAlignment，setFontFamily 的参数也换成 const QString &，迁移时这两处必改。

1. 插入内联图片 #

图片不能直接 append 进去，得先注册成文档资源，再用 QTextCursor 插入：

cpp
QImage image(":/Images/logo.png");
if (image.isNull())
    return;
// 按视口缩放，防止大图撑破布局
if (image.width() > ui->textEdit->viewport()->width() ||
    image.height() > ui->textEdit->viewport()->height())
    image = image.scaled(150, 150, Qt::KeepAspectRatio, Qt::SmoothTransformation);
// 分一个虚拟 URL，把像素注册进文档资源表
QUrl imageUrl("myresource://logo_thumbnail.png");
ui->textEdit->document()->addResource(QTextDocument::ImageResource,
                                      imageUrl, QVariant(image));
QTextImageFormat imageFormat;
imageFormat.setName(imageUrl.toString());       // 指向注册用的名字
ui->textEdit->textCursor().insertImage(imageFormat);

addResource 这步省不得。QTextImageFormat 里存的是资源名，渲染时文档按名字去资源表取像素，塞文件路径在部分平台取不到。

2. 全文检索并批量高亮 #

cpp
QTextDocument *document = ui->textEdit->document();
QTextCursor cursor(document);
cursor.beginEditBlock();              // 合并成一步撤销
QTextCharFormat highlightFormat;
highlightFormat.setForeground(Qt::red);
highlightFormat.setFontWeight(QFont::Bold);
QTextCursor searchCursor =
    document->find(searchText, 0, QTextDocument::FindWholeWords);
while (!searchCursor.isNull())
{
    searchCursor.mergeCharFormat(highlightFormat);
    searchCursor = document->find(searchText, searchCursor,
                                  QTextDocument::FindWholeWords);
}
cursor.endEditBlock();

beginEditBlock 和 endEditBlock 必须成对，中间所有修改合成一个撤销单元，大文档上还能快出一个量级。FindWholeWords 是整词匹配，要按子串找就去掉这个 flag。

3. 行间距 #

setFont 只管字形，行距在 QTextBlockFormat 上：

cpp
QTextCursor cursor = ui->textEdit->textCursor();
QTextBlockFormat blockFormat;
blockFormat.setLineHeight(150, QTextBlockFormat::ProportionalHeight);   // 1.5 倍
cursor.select(QTextCursor::Document);     // 整篇应用；只改当前段就别 select
cursor.mergeBlockFormat(blockFormat);

ProportionalHeight 的数值是百分比，150 就是 1.5 倍。想要固定像素行高，换成 QTextBlockFormat::FixedHeight，数值单位变成像素。

十、自定义搜索框 #

目标是一条栏：左边路径框带返回按钮，右边搜索框带放大镜，中间可以拖。做法是把按钮塞进 QLineEdit 自己的布局里，让它们浮在输入框上层。

cpp
QLabel      *forward_path      = new QLabel();
QLineEdit   *forward_line_edit = new QLineEdit();
QLineEdit   *search_line_edit  = new QLineEdit();
QToolButton *forward_button    = new QToolButton(this);
QToolButton *search_button     = new QToolButton(this);
forward_path->setPixmap(QPixmap(":/icon/path"));
forward_path->setAlignment(Qt::AlignRight | Qt::AlignVCenter);
forward_path->setFixedSize(20, 24);
forward_line_edit->setPlaceholderText("computer");
forward_line_edit->setMinimumSize(100, 25);
search_line_edit->setPlaceholderText("search");
search_line_edit->setMinimumSize(50, 25);
// 两个按钮的公共属性一遍配完，剩下只换图标和提示
for (QToolButton *btn : {forward_button, search_button}) {
    btn->setFixedSize(25, 24);
    btn->setIconSize(QSize(16, 16));
    btn->setAutoRaise(true);
    btn->setCursor(Qt::ArrowCursor);
    btn->setStyleSheet("background:transparent;");
}
forward_button->setToolTip("forward");
forward_button->setIcon(QIcon(":/icon/gobtn"));
search_button->setToolTip("search");
search_button->setIcon(QIcon(":/icon/search"));

接着把按钮摆进输入框，并且给文字留出位置：

cpp
QHBoxLayout *forward_layout = new QHBoxLayout();
forward_layout->addWidget(forward_path);
forward_layout->addStretch();
forward_layout->addWidget(forward_button);
forward_layout->setSpacing(0);
forward_layout->setContentsMargins(0, 0, 0, 0);
forward_line_edit->setLayout(forward_layout);
// 不设边距，输入的字符会钻到图标底下
forward_line_edit->setTextMargins(forward_path->width(), 0,
                                  forward_button->width(), 0);
QHBoxLayout *search_layout = new QHBoxLayout();
search_layout->addStretch();
search_layout->addWidget(search_button);
search_layout->setSpacing(0);
search_layout->setContentsMargins(0, 0, 0, 0);
search_line_edit->setLayout(search_layout);
search_line_edit->setTextMargins(0, 0, search_button->width(), 0);

setTextMargins 是这套写法的命门。按钮浮在输入框上，不预留两侧边距，光标和文字就压到图标下面。最后用 QSplitter 拼成一条，边框只画外侧半边：

cpp
QSplitter *search_splitter = new QSplitter(this);
search_splitter->setFrameShape(QFrame::NoFrame);
search_splitter->setHandleWidth(1);
search_splitter->addWidget(forward_line_edit);
search_splitter->addWidget(search_line_edit);
search_splitter->setStretchFactor(0, 8);     // 路径栏占 8 份
search_splitter->setStretchFactor(1, 2);     // 搜索框占 2 份
search_splitter->setChildrenCollapsible(false);
forward_line_edit->setStyleSheet(
    "QLineEdit{border-style:outset; border-top-width:1px; border-left-width:1px;"
    "border-bottom-width:1px; border-top-color:gray; border-left-color:gray;"
    "border-bottom-color:gray; background:white;}");
search_line_edit->setStyleSheet(
    "QLineEdit{border-style:outset; border-top-width:1px; border-right-width:1px;"
    "border-bottom-width:1px; border-top-color:gray; border-right-color:gray;"
    "border-bottom-color:gray; background:white;}");
search_splitter->setStyleSheet("QSplitter::handle{background:lightgray;}");

两个框各自只画三边，中间那条 1 像素的 handle 当分隔线，合起来看是一个整体控件。事件接两个信号就够：

cpp
connect(search_line_edit, &QLineEdit::returnPressed, this, [=]() {
    doSearch(search_line_edit->text());
});
connect(search_button, &QToolButton::clicked, this, [=]() {
    doSearch(search_line_edit->text());
});

Qt5.2 之后有更省事的写法，用 addAction：

cpp
search_line_edit->addAction(QIcon(":/icon/search"), QLineEdit::TrailingPosition);

addAction 自己处理边距和点击区域，不用手算 setTextMargins，也不用管按钮尺寸。新项目直接用它，上面那套留着维护老代码。

十一、QToolTip 的用法 #

控件级提示一行就完，setToolTip("...") 之后归框架管。要做出「鼠标停在哪个单词上就显示哪个单词」的效果，得自己接 ToolTip 事件：捕获 QEvent::ToolTip，把鼠标下的单词取出来，交给 QToolTip::showText 显示。

cpp
class TextEdit : public QTextEdit
{
    Q_OBJECT
public:
    TextEdit(QWidget *parent = nullptr) : QTextEdit(parent)
    {
        setFrameStyle(QFrame::NoFrame);
        setVerticalScrollBarPolicy(Qt::ScrollBarAlwaysOff);
        setHorizontalScrollBarPolicy(Qt::ScrollBarAlwaysOff);
        setText("hello Qt!");
    }
    bool event(QEvent *event) override
    {
        if (event->type() == QEvent::ToolTip)
        {
            QHelpEvent *helpEvent = static_cast<QHelpEvent *>(event);
            // 控件坐标转文档光标，取出光标下的整词
            QTextCursor cursor = cursorForPosition(helpEvent->pos());
            cursor.select(QTextCursor::WordUnderCursor);
            QToolTip::showText(helpEvent->globalPos(), cursor.selectedText());
            return true;      // 已处理，别再走默认提示
        }
        return QTextEdit::event(event);
    }
};

四个要点：ToolTip 事件的实际类型是 QHelpEvent，不是 QEvent，必须转换之后才能取 pos()；pos() 是控件坐标，给 cursorForPosition 用，globalPos() 是屏幕坐标，给 showText 用，两个弄反提示框会飘到屏幕角落；返回 true 表示已经处理完，返回 false 会落到基类，弹出来的就是 setToolTip 设的那个整控件提示；WordUnderCursor 按文本边界规则切词，英文取词正好，中文会按字切，要做中文分词得自己上词典。 取到的词拿去查词典、查翻译，再拼成 showText 的文本，就是划词翻译的完整链路。词典查询是同步的，词库大时要加缓存，别在 ToolTip 事件里做磁盘随机读。
