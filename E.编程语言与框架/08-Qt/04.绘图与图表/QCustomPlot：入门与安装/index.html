这篇只讲 QCustomPlot 的入门与安装：它是什么、为什么只有一个文件、怎么塞进工程、几个核心类怎么搭起来、一张最小图怎么跑通、图怎么导出。

不讲的部分：曲线样式的细化用法、坐标轴刻度细节、大数据量降采样与性能调优，这些在同目录的曲线绘制、坐标轴与性能两篇里。Qwt、QChart、QPainter 手绘、图形视图框架各有专篇，选型对比也单独成篇。本篇只负责把你从「没听过」带到「能画出一张静态图，能存成 PNG」。

一、QCustomPlot 是什么 #

QCustomPlot 是面向 Qt C++ 的 2D 绘图库，服务于 QtWidgets 体系下的实时数据可视化。它画的是曲线图、散点图、柱状图、K 线图、热力图、统计盒图这类二维图表。

它的身份信息很干净：

属性 值
当前版本 2.1.1（2022-11-06）
Qt 依赖 Qt 5.0+，2.1.1 起兼容 Qt 6.4
C++ 标准 C++11
支持系统 Windows / Linux / macOS
授权 GPLv3，闭源商用需购买商业授权
官网 https://www.qcustomplot.com

它继承 QWidget，所以它就是一个控件。你能往界面上放 QLabel 的地方，就能放它。这一点决定了它跟 Qt Charts 的分野：QCustomPlot 不依赖 Graphics View 那一套场景/视图，自己用 QPainter 直接往窗口上画。

跟另外两个常见选择摆一起看 #

维度 QCustomPlot Qwt Qt Charts
交付形态 2 个源文件 需自行编译成库、配环境 Qt 官方附加模块
集成成本 拷文件 + 一行 .pro 编译库 + 链接 + 环境变量 装模块 + 一行 .pro
外部依赖 只要 printsupport 自身库与版本配套 QtCharts 模块
渲染方式 QPainter 软件渲染，可开 OpenGL QPainter Graphics View
实时性能 高，可开 OpenGL 与队列重绘 中上 中等
3D 无 无 无（3D 在 QtDataVisualization）
许可证 GPLv3 / 商业 LGPL 系 LGPLv3 / 商业
适配场景 中小项目、实时曲线、要改源码 老项目、科研出图 与 Qt 官方模块保持一致、快速出图

三家的取舍在选型那篇展开。这里只记一句话：想要零依赖、能改源码、单文件交付，选 QCustomPlot。

二、为什么它只有一个文件 #

这是 QCustomPlot 最核心的设计事实，也是它相对于 Qwt 的主要优势：

QCustomPlot 全部实现就在 qcustomplot.h 和 qcustomplot.cpp 两个文件里。

不需要编译成共享库，不需要装任何第三方依赖，不需要设环境变量，不需要 install 到系统路径。你把这两个文件拷进工程目录，加进项目，就能 #include "qcustomplot.h" 开始画图。

对照一下 Qwt 的流程：下载源码包、用 qmake 编译出 qwt.dll / libqwt.so、把头文件路径和库路径写进 .pro、把 dll 拷到可执行文件旁边或写进 PATH、Qt 版本换了还得重编。QCustomPlot 把这一整串砍成了「拷贝」两个字。

一个文件换来的代价 #

单文件也意味着全量编译。qcustomplot.cpp 解开约 2.8MB，编译单元极大。

第一个代价是编译慢。第一次全量构建要等一会儿，之后增量编译不受影响，因为你不会天天改它。

第二个代价是 MinGW 会撞上对象文件段数上限，报 too many sections 或 File too big：

# MinGW 下编译 qcustomplot.cpp 报 too many sections 时加这行
QMAKE_CXXFLAGS += -Wa,-mbig-obj

第三个代价是它的内部实现在你的工程里是可见可改的。这是好事：需要绕过 setData() 的深拷贝、直接写内部缓冲区时，改 qcustomplot.h 加一个访问器就行，不用等上游发版。代价是升级时要把你的改动重新贴一遍。

有人会问能不能把它预编译成 DLL 减小编译时间。可以，做法跟普通 Qt 库没区别：单独建一个库工程，TEMPLATE = lib，导出符号，然后主工程链接它。但对多数项目来说，为了省一次编译时间去维护一个自建库工程，不划算。默认就用两个文件。

三、安装与集成进工程 #

第 1 步：下载源码 #

去官网下载页取最新压缩包，解压后拿到 qcustomplot.h 与 qcustomplot.cpp。压缩包里还有 examples 和 documentation，examples 值得留着，官方示例覆盖了大量 API 用法。

第 2 步：把文件放进工程 #

把两个文件拷到你的 Qt 工程目录下（跟 .pro 同级，或建个 3rdparty/ 子目录放进里面）。

然后在 Qt Creator 的项目视图里右键工程 →「添加现有文件...」→ 选中这两个文件。或者直接手写进 .pro：

SOURCES += qcustomplot.cpp
HEADERS += qcustomplot.h

第 3 步：.pro 里加 printsupport（最容易漏的一步） #

要用 QCustomPlot，必须在 .pro 里加 QT += printsupport。

原因很直接：从 Qt5 起，QPrinter、QPdfWriter、QPrintDialog 这些打印相关类被拆进了独立的 QtPrintSupport 模块，主 QtGui 里不再有它们。QCustomPlot 的 savePdf()、savePng() 内部要用到这些类型，源码里 #include <QPrinter>，你的 .pro 不声明模块，链接器就找不到实现。

漏了会是什么样：编译能过，链接阶段一次性炸出一大串错误，全是 undefined reference to 'QPrinter::...'、undefined reference to 'QPdfWriter::...' 这类。看着吓人，其实就一条配置的事。

# Qt5 及以上：widgets 与 printsupport 都要
QT += widgets printsupport

# 可选：OpenGL 加速
DEFINES += QCUSTOMPLOT_USE_OPENGL
QT += opengl

# 可选：MinGW 大对象支持
QMAKE_CXXFLAGS += -Wa,-mbig-obj

SOURCES += qcustomplot.cpp
HEADERS += qcustomplot.h

老写法里有个 greaterThan(QT_MAJOR_VERSION, 4): QT += widgets printsupport，意思一样，只是兼容 Qt4 时代 widgets 还没独立出来的情形。项目只跑 Qt5/Qt6 的话，直接写 QT += widgets printsupport 更清楚。

第 4 步：CMake 工程怎么接 #

不用 qmake 的话，模块名换成 PrintSupport，两个源文件直接列进可执行目标：

cmake
cmake_minimum_required(VERSION 3.16)
project(MyPlotApp LANGUAGES CXX)

set(CMAKE_CXX_STANDARD 11)
set(CMAKE_CXX_STANDARD_REQUIRED ON)
set(CMAKE_AUTOMOC ON)

find_package(Qt6 REQUIRED COMPONENTS Widgets PrintSupport)

add_executable(${PROJECT_NAME}
    main.cpp
    qcustomplot.cpp
    qcustomplot.h
)

target_link_libraries(${PROJECT_NAME} PRIVATE
    Qt6::Widgets
    Qt6::PrintSupport
)

# 可选：OpenGL 加速
# find_package(Qt6 REQUIRED COMPONENTS OpenGL OpenGLWidgets)
# target_link_libraries(${PROJECT_NAME} PRIVATE Qt6::OpenGL Qt6::OpenGLWidgets)
# target_compile_definitions(${PROJECT_NAME} PRIVATE QCUSTOMPLOT_USE_OPENGL)

这里 CMAKE_AUTOMOC ON 是必须的，因为 qcustomplot.h 里有带 Q_OBJECT 的类，moc 要处理它。qmake 默认会扫 HEADERS 里的文件做 moc，CMake 靠 AUTOMOC 补上这一步。

第 5 步：在 Qt Designer 里用 #

想在 .ui 里直接摆一个图表控件，用「提升」：

  1. 往窗体上拖一个普通 QWidget，给它起个名字，比如 customPlotWidget。
  2. 右键这个 Widget →「提升为...」（Promote to...）。
  3. 提升的类名填 QCustomPlot，头文件填 qcustomplot.h。
  4. 点「添加」→「提升」。

完事。这个 Widget 现在就是 QCustomPlot 类型，代码里用 ui->customPlotWidget->addGraph() 直接访问，不用自己 new。

提升只改 .ui 里的类名映射，二进制层面它还是 QWidget 的壳子，所以布局、尺寸策略、父对象归属全都照旧。这也是为什么不推荐把 QCustomPlot 注册成 Designer 插件：提升一步就到，插件反而要跟着 Qt 版本重编。

四种安装方式对照 #

方式 做法 适合 注意
qmake 直接加源文件 .pro 写 SOURCES / HEADERS 绝大多数 qmake 工程 必须加 QT += printsupport
CMake 加源文件 add_executable 列两个文件，链 Qt6::PrintSupport CMake 工程 必须开 AUTOMOC
Designer 提升 拖 QWidget 后提升为 QCustomPlot 界面用 .ui 描述 头文件名要写准
预编译成 DLL/SO 单独库工程 + 导出符号 多工程共用一份 升级要跟 Qt 版本重编

四、核心类：QCustomPlot、QCPGraph、QCPAxis #

先把对象树看清楚，后面所有代码都是在树上找节点。

text
QCustomPlot                     控件本身，也是画布
 └─ plotLayout (QCPLayoutGrid)  顶层网格布局
     └─ QCPAxisRect              坐标轴矩形，一块独立的绘图区
         ├─ xAxis   (QCPAxis)    底部轴
         ├─ yAxis   (QCPAxis)    左侧轴
         ├─ xAxis2  (QCPAxis)    顶部轴，默认隐藏
         ├─ yAxis2  (QCPAxis)    右侧轴，默认隐藏
         ├─ legend  (QCPLegend)  图例
         └─ QCPAbstractPlottable 图形项：QCPGraph / QCPBars / QCPCurve ...

关键关系一句话说清：

QCustomPlot 是控件，它内部有 QCPAxisRect；每个 rect 有 4 根 QCPAxis（上、下、左、右）；图形项（QCPGraph 等）挂在 rect 上，用自己的 x/y 轴去取数据坐标。

所以「多坐标系」在 QCustomPlot 里不是加控件，是加 rect。「双 Y 轴」不用加 rect，把 yAxis2 显示出来就行。

各类职责 #

类 职责
QCustomPlot 主控件，管理图层、坐标轴矩形、图形项、交互与重绘
QCPAxisRect 坐标轴矩形，容纳一组 QCPAxis 与挂在它上面的图形项
QCPAxis 单根坐标轴，管刻度、标签、范围、缩放类型
QCPAbstractPlottable 所有图形项的基类，提供 setData / rescaleAxes / 选中态
QCPGraph 折线图与散点图，最常用的图形项
QCPBars 柱状图
QCPCurve 参数曲线，允许 x 不单调
QCPColorMap 热力图
QCPFinancial K 线图 / OHLC 图
QCPLayoutGrid 网格布局，排列多个 QCPAxisRect
QCPLayoutInset 内嵌布局，把元素浮在 rect 上（标题、水印）
QCPLayer 图层，控制绘制顺序与缓冲策略
QCPAbstractItem 图形元素基类，QCPItemText / QCPItemLine 等
QCPLegend 图例，本质是 QCPLayoutInset 的子类

渲染怎么走 #

默认走 QPainter 软件渲染，流程三步：

  1. 按 z-order 依次遍历 QCPLayer。
  2. 每个图层调用其下 QCPLayerable 的绘制方法。
  3. lmBuffered 缓冲图层只在内容变化时重画，静态元素靠这个省开销。

要开 OpenGL 加速得两步都做：编译期定义 QCUSTOMPLOT_USE_OPENGL，运行期调 setOpenGl(true)。只做一步是无效的——宏没定义时 setOpenGl 这个函数根本不存在，编译直接报错找不到成员。

cpp
// 编译期：.pro 里 DEFINES += QCUSTOMPLOT_USE_OPENGL
// 运行期：
customPlot->setOpenGl(true);

三个类的常用接口 #

QCPAxis 管坐标轴：

cpp
QCPAxis *xAxis = customPlot->xAxis;   // 底部 X 轴
QCPAxis *yAxis = customPlot->yAxis;   // 左侧 Y 轴

// 范围
xAxis->setRange(0, 100);
yAxis->setRangeReversed(true);        // 反转，2.1.1 起支持

// 刻度
xAxis->ticker()->setTickCount(10);
xAxis->setTickLabelFont(QFont("Arial", 9));
xAxis->setTickLabelRotation(45);

// 对数坐标
yAxis->setScaleType(QCPAxis::stLogarithmic);
yAxis->setTicker(QSharedPointer<QCPAxisTickerLog>(new QCPAxisTickerLog));

// 时间轴
QSharedPointer<QCPAxisTickerDateTime> dateTicker(new QCPAxisTickerDateTime);
dateTicker->setDateTimeFormat("yyyy-MM-dd\nhh:mm:ss");
xAxis->setTicker(dateTicker);

xAxis->setLabel("Time (s)");

注意 setScaleType(stLogarithmic) 之后必须同时换成 QCPAxisTickerLog，两步缺一不可：刻度算法和坐标映射是分开的，只改一个会画出刻度均匀分布的对数轴，看着像对数轴，其实是错的。

QCPGraph 管曲线：

cpp
QCPGraph *graph = customPlot->addGraph();

QVector<double> x(100), y(100);
for (int i = 0; i < 100; ++i) {
    x[i] = i;
    y[i] = qSin(i / 10.0);
}
graph->setData(x, y);

graph->setName("Sine Wave");
graph->setPen(QPen(Qt::blue, 2));
graph->setLineStyle(QCPGraph::lsLine);
graph->setScatterStyle(QCPScatterStyle(QCPScatterStyle::ssCircle, 5));

graph->setBrush(QBrush(QColor(0, 0, 255, 50)));
graph->setAntialiased(true);

addGraph() 有重载，可以指定挂在哪个 rect 的哪两根轴上：addGraph(customPlot->xAxis, customPlot->yAxis2)。不传参数就是默认 rect 的 xAxis + yAxis。

QCustomPlot 自己的交互开关：

cpp
customPlot->setInteractions(QCP::iRangeDrag | QCP::iRangeZoom | QCP::iSelectPlottables);

customPlot->axisRect()->setRangeDrag(Qt::Horizontal);   // 只允许水平拖
customPlot->axisRect()->setRangeZoom(Qt::Vertical);     // 只允许垂直缩放
customPlot->axisRect()->setRangeZoomFactor(0.9, 0.9);

setInteractions 是位掩码，漏掉哪个标志就少哪个能力。iRangeDrag 和 iRangeZoom 是最常开的两项，iSelectPlottables 让曲线可点选（点击后能拿到 selectedPlottables()）。

五、最小可运行例子 #

目标：画一条 y=x3，负半轴对称，自己 new 控件，不依赖 .ui。

先看 .pro，就这几行：

QT += core gui widgets printsupport

TARGET = plotdemo
TEMPLATE = app

SOURCES += main.cpp \
           mainwindow.cpp \
           qcustomplot.cpp

HEADERS += mainwindow.h \
           qcustomplot.h

再看窗口构造函数，一个文件写完：

cpp
#include "mainwindow.h"
#include "ui_mainwindow.h"
#include "qcustomplot.h"
#include <qmath.h>

MainWindow::MainWindow(QWidget *parent) :
    QMainWindow(parent),
    ui(new Ui::MainWindow)
{
    ui->setupUi(this);

    // 实例化绘图区，挂到当前窗口
    QCustomPlot *customPlot = new QCustomPlot(this);
    customPlot->resize(300, 300);

    // 101 个采样点
    QVector<double> x(101), y(101);

    // x 取 [-10, 10]，步长 0.2
    for (int i = 0; i < 101; ++i)
    {
        x[i] = i / 5.0 - 10.0;
        y[i] = qPow(x[i], 3);
    }

    // 1. 添加一条曲线通道
    customPlot->addGraph();

    // 2. 把数据绑到第 0 号通道
    customPlot->graph(0)->setData(x, y);

    // 3. 设置轴标签
    customPlot->xAxis->setLabel("x");
    customPlot->yAxis->setLabel("y");

    // 4. 设置轴范围，否则默认视口看不到这条曲线
    customPlot->xAxis->setRange(-11, 11);
    customPlot->yAxis->setRange(-1100, 1100);

    // 5. 触发重绘
    customPlot->replot();
}

把 .pro 编一遍，跑起来就是一条三次曲线。

每一步在干什么 #

调用 作用 坑
addGraph() 注册一条新曲线，返回 QCPGraph*，索引从 0 递增 返回值不用也行，靠 graph(i) 取
graph(0)->setData(x, y) 绑定数据，参数必须是 QVector<double>，两个长度相等 长度不等会画出错位折线
xAxis->setRange() 定逻辑视口 不设就看默认 0~5，曲线跑出画面
xAxis->setLabel() 轴标题 中文字体要单独设，见易错点
replot() 强制重画 不调就一片空白

想省掉手算范围 #

不手动 setRange 也行，交给数据自己定：

cpp
customPlot->graph(0)->rescaleAxes();  // 按这条曲线的数据自动定范围
customPlot->replot();

或者整张图一起收：

cpp
customPlot->rescaleAxes();  // 所有 plottable 都参与

区别是 graph(0)->rescaleAxes() 只算那一条，customPlot->rescaleAxes() 算全部。图里有两条量纲差很远的曲线时，用前者分别定会比较舒服。

上例是 new 出来的，窗口缩放时它不会跟着变。按第三章第 5 步提升过控件的话，ui->customPlot 就是同一个对象，把 customPlot-> 换成 ui->customPlot-> 即可，且尺寸交给布局管，不用 resize(300, 300) 硬定。

六、图表的组成部分 #

一张 QCustomPlot 里能数出六样东西。

组成 对象 说明
坐标轴矩形 axisRect() 一块绘图区，含 4 根轴
坐标轴 xAxis / yAxis / xAxis2 / yAxis2 下、左、上、右
图形项 graph(0)、plottable(i) 曲线、柱、K 线等
图例 legend 显示各曲线名字
标题 QCPTextElement 放在顶层布局第 0 行
图层 layer("main") 等 控制绘制顺序

四根轴都在，两根默认藏起来 #

xAxis2、yAxis2 一直存在，只是默认不可见。想用右轴，两步：

cpp
customPlot->yAxis2->setVisible(true);
customPlot->yAxis2->setTickLabels(true);

setVisible(true) 只让轴线出现，刻度文字要另开 setTickLabels(true)。漏了第二步会看到一根没有数字的轴。

上轴同理：xAxis2->setVisible(true) + setTickLabels(true)。

双 Y 轴怎么挂曲线 #

cpp
customPlot->yAxis2->setVisible(true);
customPlot->yAxis2->setTickLabels(true);

// 温度挂左轴
QCPGraph *graph1 = customPlot->addGraph(customPlot->xAxis, customPlot->yAxis);
graph1->setName("Temperature (°C)");
graph1->setPen(QPen(Qt::red, 2));

// 湿度挂右轴
QCPGraph *graph2 = customPlot->addGraph(customPlot->xAxis, customPlot->yAxis2);
graph2->setName("Humidity (%)");
graph2->setPen(QPen(Qt::blue, 2));

customPlot->yAxis->setLabelColor(Qt::red);
customPlot->yAxis2->setLabelColor(Qt::blue);
customPlot->legend->setVisible(true);

addGraph(xAxis, yAxis) 两个参数决定这条曲线的数据按哪两根轴换算像素。数据挂错轴，曲线会跑到画面外或者被压成一条线，这是双轴图最常见的错。

图例 #

默认是存在的，只是不显示。打开并摆位置：

cpp
customPlot->legend->setVisible(true);
customPlot->legend->setBrush(QColor(255, 255, 255, 200));  // 半透明白底
customPlot->axisRect()->insetLayout()->setInsetAlignment(
    0, Qt::AlignTop | Qt::AlignRight);

曲线名来自 graph->setName()，不设名字图例里就是空的。

标题 #

标题不是控件的属性，是顶层布局里的一行元素：

cpp
customPlot->plotLayout()->insertRow(0);
customPlot->plotLayout()->addElement(0, 0,
    new QCPTextElement(customPlot, "温度采集", QFont("sans", 12, QFont::Bold)));

insertRow(0) 在原有 axisRect 上方挤出一行，addElement(0, 0, ...) 把文字元素放进去。不 insertRow 直接 addElement 会覆盖掉 axisRect，图就没了。

七、图层与布局 #

两块内容分开看：布局管「元件摆在哪」，图层管「谁先画」。

布局：三层结构 #

顶层是 plotLayout()，一个 QCPLayoutGrid。默认只有一格，那一格里放着一个 QCPAxisRect。

cpp
QCPLayoutGrid *layout = customPlot->plotLayout();
qDebug() << layout->rowCount() << layout->columnCount();  // 1 1

要摆成 2×2 四张图，两种做法。

做法一，复用默认 rect，再插新的：

cpp
// 扩成 2 行 2 列
customPlot->plotLayout()->insertRow(1);
customPlot->plotLayout()->insertColumn(1);

// (0,0) 已经是默认的 axisRect，把它移到左上就位
customPlot->plotLayout()->addElement(1, 0, new QCPAxisRect(customPlot));
customPlot->plotLayout()->addElement(0, 1, new QCPAxisRect(customPlot));
customPlot->plotLayout()->addElement(1, 1, new QCPAxisRect(customPlot));

做法二，清空重来，全部新建：

cpp
customPlot->plotLayout()->clear();           // 卸掉默认 rect

for (int row = 0; row < 2; ++row) {
    for (int col = 0; col < 2; ++col) {
        QCPAxisRect *rect = new QCPAxisRect(customPlot);
        customPlot->plotLayout()->addElement(row, col, rect);
        // 每个 rect 有自己的四根轴
        rect->axis(QCPAxis::atBottom)->setLabel("t");
        rect->axis(QCPAxis::atLeft)->setLabel("v");
    }
}

clear() 会连同默认 axisRect 一起删掉，之后 customPlot->xAxis 就指向一个已被销毁的对象。所以清空之后一律用 rect->axis(QCPAxis::atBottom) 这条路取轴，别再碰 customPlot->xAxis。这是多图布局里第一个要记住的事。

QCPAxisRect::axis() 的参数是枚举：atBottom、atTop、atLeft、atRight，分别对应 0、1、2、3 号轴。

内嵌布局：把东西浮在图上 #

axisRect()->insetLayout() 是 QCPLayoutInset，元素按绝对对齐方式浮在 rect 上，不参与网格。图例就住在里面：

cpp
// 图例默认位置就是 insetLayout 的第 0 个
customPlot->axisRect()->insetLayout()->setInsetAlignment(
    0, Qt::AlignTop | Qt::AlignRight);

// 加一个右上角的水印
QCPItemText *watermark = new QCPItemText(customPlot);
watermark->position->setType(QCPItemPosition::ptAxisRectRatio);
watermark->position->setCoords(0.97, 0.03);
watermark->setText("DRAFT");
watermark->setPen(QPen(Qt::gray));

图层：管绘制顺序 #

QCustomPlot 默认有六个图层，按从下到上的顺序：

图层名 装什么
background 背景
grid 网格线
main 曲线、图形项
axes 坐标轴、刻度
legend 图例
overlay 覆盖层，鼠标指针之类

顺序即 z-order。把曲线挪到网格下面，就被网格压住了。

自己开一层：

cpp
customPlot->addLayer("annotation");                  // 插在最上面
customPlot->addLayer("underlay", customPlot->layer("grid"), QCustomPlot::limBelow);

customPlot->graph(0)->setLayer("main");
customPlot->legend->setLayer("legend");

addLayer(name, sibling, mode) 的 mode 有两个：limAbove 插在 sibling 上面，limBelow 插在下面。不传 sibling 就追加到最顶。

已经存在的图层可以用 moveLayer() 重排：

cpp
customPlot->moveLayer(customPlot->layer("annotation"), customPlot->layer("overlay"),
                      QCustomPlot::limAbove);

缓冲图层 #

图层有个 mode 属性，两个值：

  • lmLogical：每次 replot() 都重画。默认值。
  • lmBuffered：内容没变就复用上次的绘制结果。

静态元素多、只动一条曲线的场景，把网格和坐标轴层设成 lmBuffered 能省一截开销：

cpp
customPlot->layer("grid")->setMode(QCPLayer::lmBuffered);
customPlot->layer("axes")->setMode(QCPLayer::lmBuffered);

设了缓冲之后，改完坐标轴（比如 setRange）要记得 replot()；缓存图层的失效靠它自己的脏标记，某些属性变更不走标记，保险做法是改完主动刷一次。

八、添加图形元素 #

曲线以外的装饰件叫 item，基类 QCPAbstractItem，都挂在 QCustomPlot 上，然后指定挂到哪个 rect。

类 画什么
QCPItemText 文字标注
QCPItemLine 带箭头的线段
QCPItemStraightLine 无限延伸的直线，做参考线
QCPItemRect 矩形
QCPItemEllipse 椭圆
QCPItemCurve 贝塞尔曲线
QCPItemTracer 追踪点，跟着曲线走
QCPItemBracket 括号，标注区间
QCPItemPixmap 图片

定位方式 #

每个 item 的 position 有个 setType()，三种坐标系：

类型 坐标含义 用途
ptPlotCoords 数据坐标 标在某个数据点上
ptAxisRectRatio rect 内比例，0~1 固定贴在图表某角
ptAbsolute 像素 精确像素定位，跟着窗口缩放会跑偏

另外还有相对定位：setParentAnchor() 让一个位置点跟着另一个 item 的位置走。

一个完整的例子：点击显示坐标 #

需求是点一下图，弹出一个文本标签指出该点的 x、y，再用一根箭头从标签指到点击处。

cpp
// 头文件里声明
QCPItemText *m_textLabel;
QCPItemLine *m_arrow;

// 初始化，放在构造函数里
m_textLabel = new QCPItemText(m_plot);
m_textLabel->setPositionAlignment(Qt::AlignTop | Qt::AlignHCenter);
m_textLabel->position->setType(QCPItemPosition::ptAxisRectRatio);
m_textLabel->position->setCoords(0.5, 0);
m_textLabel->setVisible(false);

m_arrow = new QCPItemLine(m_plot);
m_arrow->start->setParentAnchor(m_textLabel->bottom);
m_arrow->setHead(QCPLineEnding::esSpikeArrow);
m_arrow->setVisible(false);

cpp
// 重写 mousePressEvent
void MyPlot::mousePressEvent(QMouseEvent *event)
{
    double x = m_plot->xAxis->pixelToCoord(event->pos().x());
    double y = m_plot->yAxis->pixelToCoord(event->pos().y());

    m_arrow->end->setCoords(x, y);
    m_textLabel->setText(QString("x=%1\ny=%2").arg(x).arg(y));

    m_textLabel->setVisible(true);
    m_arrow->setVisible(true);
    m_plot->replot();

    QCustomPlot::mousePressEvent(event);   // 别忘了透传
}

关键在 pixelToCoord()：它把像素坐标换算成数据坐标，正变换是 coordToPixel()。所有「鼠标位置 → 数据值」的交互都靠这一对函数。

start->setParentAnchor(m_textLabel->bottom) 让箭头起点始终黏在标签下边框，标签动了箭头自己跟着动，不用手动算。setHead(esSpikeArrow) 是给终点加箭头，esNone 表示不加。

别让 item 画到轴外面 #

默认 item 可以画到 rect 之外，压在刻度文字上。想裁掉：

cpp
m_textLabel->setClipToAxisRect(true);

常用 item 的配套设置 #

cpp
// 追踪点：贴在曲线第 50 个数据点上
QCPItemTracer *tracer = new QCPItemTracer(customPlot);
tracer->setGraph(customPlot->graph(0));
tracer->setGraphKey(50);
tracer->setInterpolating(true);          // 允许在两点之间插值
tracer->setStyle(QCPItemTracer::tsCircle);
tracer->setPen(QPen(Qt::red));
tracer->setBrush(Qt::red);

// 水平参考线
QCPItemStraightLine *refLine = new QCPItemStraightLine(customPlot);
refLine->point1->setCoords(0, 3.3);
refLine->point2->setCoords(1, 3.3);
refLine->setPen(QPen(Qt::DashLine));

QCPItemTracer 的 setGraphKey() 用的是曲线的 key（横坐标），不是索引。用索引要写 setGraphKey(customPlot->graph(0)->data()->at(50)->key)。

九、导出图片 #

QCustomPlot 提供一组 save*() 接口，一口气把当前画面存成各种格式。它们全部依赖 QtPrintSupport——这就是第三章那个 QT += printsupport 的由来。PDF 输出走 QPdfWriter，PNG/JPG/BMP 走 QImage，两者都在这个模块里。

cpp
// 位图：宽 800，高 600，缩放 1.0
customPlot->savePng("plot.png", 800, 600, 1.0, -1);
customPlot->saveJpg("plot.jpg", 800, 600, 1.0, -1);
customPlot->saveBmp("plot.bmp", 800, 600, 1.0);

// 矢量：PDF
customPlot->savePdf("plot.pdf", 800, 600);

签名里的 -1 表示用默认质量/DPI。不传宽高就按控件当前尺寸出图。

参数含义 #

参数 作用
width / height 输出像素尺寸，不传则取控件尺寸
scale 缩放系数，2.0 等于二倍图
quality 只有 JPG 用得上，-1 走默认

导出图跟自己看到的不一样，八成是尺寸参数没给：控件在屏幕上只有 300×300 时，不传宽高就只能存出 300×300。

要更高清的图 #

高分屏下把 scale 提到 2，或者直接按倍数放大宽高：

cpp
customPlot->savePng("plot@2x.png", 1600, 1200, 2.0);

scale 会把字号、线宽按比例一起放大，不是简单地在像素层面插值。所以放大后的图刻度文字依然清晰，这是它跟「截屏放大」的区别。

存到 QPixmap 再自己处理 #

不想落盘，想自己贴到界面上或塞进剪贴板：

cpp
QPixmap pixmap = customPlot->toPixmap(800, 600, 1.0);
QLabel *preview = new QLabel;
preview->setPixmap(pixmap);

toPixmap() 内部会临时改一次渲染尺寸，画完再恢复，屏幕上的控件不受影响。要在别处画，用 toPainter(QCPPainter *painter, int width, int height)，把 QPainter 交进去。

打印 #

接打印机也是同一条路：

cpp
QPrinter printer(QPrinter::HighResolution);
printer.setPageSize(QPageSize(QPageSize::A4));
customPlot->print(&printer);

print() 会把整张图按页面比例重排，适合报表输出。用 QPrintPreviewDialog 包一层就能先预览。

导出时的两个注意点 #

导出前先 replot()。save*() 系列是从内部绘制流程里截出来的，数据改了没重绘，存出来还是旧图。

导出 PDF 时中文字体变成方框，原因是 QPdfWriter 走的是字体嵌入路径，控件上的字体名在 PDF 侧找不到对应字体。解决办法是显式给控件设一个系统里存在的字体族，别依赖默认。

十、版本与兼容性 #

项目 1.x 2.x（当前 2.1.1）
数据容器 QCPDataMap（QMap<double, QCPData>） QCPGraphDataContainer（内含 QVector<QCPGraphData>）
数据点类型 QCPData QCPGraphData
遍历方式 QMap 迭代器 data()->constBegin() / at(i)
共享数据 setData(QCPDataMap*) setData(QSharedPointer<QCPGraphDataContainer>)
内存布局 树，节点分散 连续数组，缓存友好
兼容 Qt Qt4 起 Qt5.0+，2.1.1 兼容 Qt6.4

1.x 到 2.x 的数据容器重写是最大的断代点。从 1.x 迁过来，凡是直接碰过 QCPDataMap 的代码都要改：graph->data()->insert(...) 这类写法在 2.x 里不再存在，要换成 graph->data()->add(QCPGraphData(key, value))。

具体到 Qt 版本 #

Qt5 全系可用，QT += widgets printsupport 两个模块都要。Qt6 从 2.0 起就支持，2.1.1 起官方标了 Qt 6.4 兼容。

C++11 是最低要求，QSharedPointer、nullptr、constexpr 在源码里到处用，标准压到 C++98 编不过。

许可证 #

GPLv3。动态链接闭源程序也算衍生作品，商用闭源必须买商业授权。个人项目、内部工具、开源项目用 GPLv3 没问题。

已知局限 #

  1. 没有 QML 原生支持，嵌入 QML 要用 QQuickPaintedItem 包一层，自己处理 paint()。
  2. 只有 2D。三维曲面、体渲染这类需求要换工具或叠 OpenGL。
  3. 单文件 2.8MB，首次全量编译慢，MinGW 下要开 -Wa,-mbig-obj。
  4. 数据量上到百万点级别要靠降采样，库本身不替你做。见坐标轴与性能那篇。

背景色那段代码 #

QBrush 默认是 NoBrush，只 setColor() 不设样式，画出来就是透明的：

cpp
QBrush backRole;
backRole.setColor(QColor("skyblue"));
backRole.setStyle(Qt::SolidPattern);   // 少了这行背景不会变色
myPlot->setBackground(backRole);

子线程更新 #

不能在工作线程里直接调 graph->addData()。QCustomPlot 的所有绘制对象都绑在主线程，跨线程访问会崩。

cpp
// 错：工作线程直接操作
workerThread->graph()->addData(x, y);   // 崩

// 对：发信号，主线程收
emit dataReady(x, y);                   // 连接用 Qt::QueuedConnection

采集线程只管攒数据，主线程的槽函数里一次性搬进曲线。这样线程安全，也让重绘次数可控。

实时场景的四个动作 #

场景 做法
采集与渲染互相阻塞 拆到两个线程，中间用信号槽或加锁缓冲
频繁重绘 攒一批 setData，再统一 replot
重绘过于密集 用 replot(QCustomPlot::rpQueuedReplot) 合并请求
内存只涨不降 removeBefore() 清掉窗口外的旧点 
cpp
void RealtimePlotWidget::updatePlot()
{
    QVector<double> timestamps, values;
    {
        QMutexLocker locker(&m_dataMutex);
        if (m_pendingTimestamps.isEmpty()) return;
        timestamps = std::move(m_pendingTimestamps);
        values = std::move(m_pendingValues);
    }

    auto *graph = m_plot->graph(0);
    for (int i = 0; i < timestamps.size(); ++i)
        graph->addData(timestamps[i], values[i]);

    double currentTime = timestamps.last();
    graph->data()->removeBefore(currentTime - WINDOW_SIZE);  // 清旧点
    m_plot->xAxis->setRange(currentTime - WINDOW_SIZE, currentTime);
    m_plot->yAxis->rescale(true);
    m_plot->replot(QCustomPlot::rpQueuedReplot);
}

rpQueuedReplot 把重绘请求排进事件循环，同一轮里多次调用只真正画一次。QCustomPlot::rpImmediateRefresh 是立刻同步重画，两者别混用。

直接写内部缓冲区 #

setData() 每次都会重新分配并整份拷贝。数据量大、刷新快时，绕过去直接写 QVector 快得多：

cpp
// 2.x：改 qcustomplot.h，给 QCPGraphDataContainer 加一个访问器
QVector<QCPGraphData>* coreData() { return &mData; }

cpp
// 用它
QVector<QCPGraphData> *mData = customPlot->graph(0)->data()->coreData();
mData->clear();

QCPGraphData newPoint;
for (int i = 0; i < 10000; ++i) {
    double x = i / 50.0;
    newPoint.key = x;
    newPoint.value = qSin(x);
    mData->append(newPoint);   // 尾部追加，连续内存写入
}

customPlot->replot();

前提是 key 必须已经升序。直接 append 一个乱序序列，渲染时折线会来回交叉，画面是错的。1.x 那边对应的是拿到 QCPDataMap* 直接 insert，2.x 里这条路已经不存在。

改源码的代价是升级要重新贴。把改动记在项目的升级清单里，别等换版本时踩。

曲线以外的 plottable #

QCPBars、QCPStatisticalBox 这些不走 graph()，走通用的 plottable() 索引：

cpp
// 取最后添加的那个，转成柱状图
QCPBars *theBar = qobject_cast<QCPBars*>(myPlot->plottable());
if (theBar) {
    QVector<double> xData, yData;
    // ... 填数据
    theBar->setData(xData, yData);
}

qobject_cast 失败返回 nullptr，一定要判空。用 dynamic_cast 也行，qobject_cast 在 Qt 环境里更快。
