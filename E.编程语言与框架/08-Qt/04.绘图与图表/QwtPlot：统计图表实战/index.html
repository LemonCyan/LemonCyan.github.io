本篇只讲一件事：用 QwtPlot 画统计图表。范围包括柱状图 QwtPlotBarChart、直方图 QwtPlotHistogram、分组与堆叠 QwtPlotMultiBarChart，以及围绕它们的自定义轴刻度、逐柱配色、横竖切换、图例标注和导出。

不讲 Qwt 的编译安装，不讲 QwtPlotCurve 的曲线插值与坐标轴缩放细节，也不讲 QCustomPlot 与 QChart 的同类写法。这些在 04.绘图与图表 目录的其他篇目里分开写：曲线与坐标轴看《Qwt 曲线与坐标轴》，库的类层次看《Qwt 库结构》，选哪个库看《绘图库选型》，纯手工绘制看《QPainter》两篇。

代码基于 Qt 5 加 Qwt 6.1，C++ 写。示例数据是一张人物战斗力排行榜和一张盈亏表，换成自己的业务数据就能跑。

一、统计图表与曲线图的差别 #

QwtPlot 只是一个画布容器。它管四条轴、一层网格、一块 Canvas、一个图例。真正画东西的是挂在它上面的 QwtPlotItem 子类。换图表类型，就是把 A 项 detach，把 B 项 attach。

text
QwtPlot（Canvas + 四条轴 + 图例）
├── QwtPlotGrid           网格
├── QwtPlotCurve          曲线：一串连续 (x, y) 采样点
├── QwtPlotBarChart       柱状图：一组柱子 = 一个 item
├── QwtPlotMultiBarChart  分组柱 / 堆叠柱：每组多根
├── QwtPlotHistogram      直方图：区间 + 频次
└── QwtPlotMarker         标线：零位线、阈值线、注释

曲线和统计图在 Qwt 里差得很远，不是换个类名的事：

维度 QwtPlotCurve QwtPlotBarChart
数据语义 连续函数采样，x 有物理量纲 离散类别计数，下标就是类别序号
X 轴含义 时间、长度、温度这类连续量 第 0 根、第 1 根柱子，本身无意义
刻度定制 自动等分就够用，最多调一下 setAxisScale 必须换成类别文本，等分刻度直接废掉
图形项粒度 一个 item 一条线 一个 item 一组柱子
逐点配色 setPen 换整条线；逐点要拆多条曲线 重写 specialSymbol，不拆 item
图例 一条线一个图例项 一组柱子一个图例项，或者逐柱一项
空值处理 断开或跳过采样点 缺一根柱子就占一个空位，X 轴不能塌

最后一行容易踩。曲线的 X 轴是连续的，中间少一个采样点，线还能连上。柱状图的 X 轴是 0 到 n-1 的整数序列，你少塞一个值，后面的柱子全部左移一位，标签和柱子就错位了。所以柱状图的样本数组必须和类别数组严格等长。

本篇所有示例都围绕一条主线：一个 QwtPlotBarChart 对象管一整组柱子，柱子的身份靠下标认，不靠对象。这一条决定了后面所有的定制手法。

二、QwtPlotBarChart：柱状图 #

最小可跑的柱状图就这么几行：

cpp
#include <qwt_plot.h>
#include <qwt_plot_barchart.h>

QwtPlot *plot = new QwtPlot(parent);
plot->setTitle(QStringLiteral("月度访问量"));

QwtPlotBarChart *bars = new QwtPlotBarChart(QStringLiteral("访问量"));
bars->setSamples(QVector<double>() << 120.0 << 340.0 << 260.0 << 410.0);
bars->setBaseline(0.0);
bars->attach(plot);

plot->replot();

这段代码画出来能看，但 X 轴是 0、0.5、1、1.5 这样的默认等分刻度，柱子之间也没有间隔。要把它变成能看的报表，得碰下面这些接口：

接口 作用
setSamples(const QVector<double>&) 塞入一组数值，下标就是类别序号
setOrientation(Qt::Orientation) 柱子生长方向，纵向或横向
setBaseline(double) 柱子起算值，0 是常规起点，盈亏图要留负值空间
setSpacing(int) 相邻柱子之间的像素间隔
setMargin(int) 柱子与画布边缘的像素间隔
setSymbol(QwtColumnSymbol *) 统一替换所有柱子的绘制符号
setLegendMode(LegendMode) 图例策略，整组一项还是逐柱一项
setLegendIconSize(const QSize&) 图例图标尺寸
specialSymbol(int, const QPointF&) 虚函数，逐柱生成绘制符号
barTitle(int) 虚函数，逐柱生成图例标题
dataSize() 当前样本数量

QwtPlotBarChart 的构造参数是一个标题，它会出现在图例里。注意这个标题是整组的标题，不是单根柱子的。想让每根柱子各有一个图例条目，就得改 setLegendMode，再接 barTitle。

把默认值调成报表样子的写法：

cpp
QwtPlotBarChart *bars = new QwtPlotBarChart();
bars->setSamples(samples);
bars->setBaseline(0.0);
bars->setSpacing(6);
bars->setMargin(4);
bars->setOrientation(Qt::Vertical);
bars->attach(plot);

// X 轴退化成类别轴：0 到 n-1，步长 1
plot->setAxisScale(QwtPlot::xBottom, 0, bars->dataSize() - 1, 1.0);
plot->setAxisMaxMinor(QwtPlot::xBottom, 0);
plot->setAxisScaleDraw(QwtPlot::xBottom, new QwtScaleDraw());

三个细节值得盯一下。

柱宽不是设的，是算的。 柱子宽度由画布宽度、样本数、spacing、margin 一起决定。样本从 5 根变 50 根，柱宽自动缩。想让柱子永远 30 像素宽，只能在 QwtColumnSymbol::draw 里自己截宽，后面「逐柱设置颜色」一章的代码就是这么干的。

setAxisScale 的上界必须是 dataSize() - 1。 写 dataSize() 会多留半根柱子的空档，第一根柱子还会被挤偏半格。

attach 之后才有 dataSize()。 顺序反了拿到 0，轴范围变成 0 到 -1，画出来一片空白。

QwtPlotBarChart 内部维护的是 QVector<double>。样本按顺序排，第 i 个值的柱子中心落在 X 轴坐标 i 上。它不知道第 i 个柱子叫什么名字，那是轴刻度的事。这是 Qwt 把「数据」和「标签」拆开的直接后果，也是后面必须自己做 QwtScaleDiv 的根本原因。

三、柱子的数据组织 #

samples 里只有数值。类别名、颜色、附加说明都得另存。业务代码里最省事的做法是用一个 struct 数组当唯一数据源：

cpp
struct BarItem
{
    QString name;
    double  value;
    QColor  color;
};

QVector<BarItem> buildData()
{
    QVector<BarItem> rows;
    rows << BarItem{QStringLiteral("扫地神僧"), 10000, QColor(0, 160, 230)}
         << BarItem{QStringLiteral("无崖子"),   9500, QColor(115, 185, 35)}
         << BarItem{QStringLiteral("萧远山"),   8888, QColor(235, 30, 35)}
         << BarItem{QStringLiteral("虚竹"),     8000, QColor(255, 130, 0)}
         << BarItem{QStringLiteral("鸠摩智"),   4500, QColor(255, 175, 200)};  // 中略五条
    return rows;
}

然后用一趟循环拆出三份平行数据：

cpp
QVector<double>  samples;
QStringList      names;
QList<QColor>    colors;
for (const BarItem &item : buildData()) {
    samples += item.value;
    names   += item.name;
    colors  += item.color;
}

bars->setSamples(samples);

三份数组的下标必须一一对应。这是柱状图里最容易出事的地方：你在某处 names.removeAt(2)，忘了同步 samples，后面全错位。

数据组织方式有三种，按场景挑：

方式 写法 适用场景 代价
平行数组 QVector<double> + QStringList + QList<QColor> 一次性静态数据 三份数组同步靠人肉，改数据要改三处
struct 数组 QVector<BarItem>，用时拆成平行数组 排行榜、单组柱状图 拆分那一步不能忘
二维样本 QVector<QVector<double>>，交给 QwtPlotMultiBarChart 分组柱、堆叠柱 每组数量必须一致，长度不齐会补齐成 0

排行榜场景还有一个隐含前提：排序要在 setSamples 之前完成。Qwt 不排序，你给什么顺序就画什么顺序，X 轴下标跟着数据走。想在界面上加个「按名称排序」按钮，就得重新算 samples 与 names 再 setSamples 一次，然后重绘。

数值范围也别忘。排行榜的数值从 4500 到 10000，轴范围写死 0..10000 就行；换成动态数据，setAxisScale 的上界要取 std::max_element 的结果再乘 1.1，否则最高的那根柱子顶到画布边缘，看着像被切掉。

cpp
double vmax = *std::max_element(samples.constBegin(), samples.constEnd());
plot->setAxisScale(QwtPlot::yLeft, 0.0, vmax * 1.1);

负值数据的处理放到「横向与纵向切换」一章，那时候要一起算轴范围和零位线。

四、自定义轴刻度标签 #

柱状图最难受的一步来了。QwtPlotBarChart 把类别信息全扔了，X 轴上只剩 0 到 9。默认刻度会给你 0、1、2、3……9，看着像数组下标，不像排行榜。

先看默认等分刻度为什么救不回来。setAxisScale(xBottom, 0, 9, 1.0) 写完，Qwt 的内部逻辑会把区间 0 到 9 做等分，主刻度数量受画布像素数限制。窗口窄一点，主刻度只剩 0、2、4、6、8 五个，你的「慕容博」就消失了。窗口拉宽又变成十个。刻度的疏密跟着像素走，跟你的类别数量没关系，这就是等分刻度在类别轴上失效的原因。

真正的做法是自己造一份 QwtScaleDiv，把刻度位置一个个列出来：

cpp
#include <qwt_scale_div.h>

// 一个类别一根主刻度，位置就是整数下标
QwtScaleDiv div(0.0, names.size() - 1.0);

QList<double> majors;
for (int i = 0; i < names.size(); ++i)
    majors << static_cast<double>(i);

div.setTicks(QwtScaleDiv::MajorTick, majors);
div.setTicks(QwtScaleDiv::MediumTick, QList<double>());
div.setTicks(QwtScaleDiv::MinorTick,  QList<double>());

plot->setAxisScaleDiv(QwtPlot::xBottom, div);

QwtScaleDiv 三个要素：上下界、三档刻度列表（主、中、次）、每档的刻度位置。手动填完之后塞给 setAxisScaleDiv，Qwt 就不再自己算刻度了，你给几根就是几根。

几个顺序上的坑：

  • setAxisScaleDiv 之后不能再调 setAxisScale。后者会重新生成一个 QwtScaleDiv 顶掉你手工造的那份。
  • 刻度列表里的数值必须落在上下界之间，越界的会被丢掉，不报错。
  • 想让柱子和画布边缘留点空隙，两端各放宽 0.5：QwtScaleDiv(-0.5, names.size() - 0.5)。这样首尾两根柱子不会贴边。

刻度位置有了，标签还是「0」「1」「2」。换文字靠 QwtScaleDraw 的子类，重写 label(double)：

cpp
#include <qwt_scale_draw.h>
#include <QStringList>

class NameScaleDraw : public QwtScaleDraw
{
public:
    explicit NameScaleDraw(const QStringList &labels)
        : d_labels(labels)
    {
    }

    QwtText label(double value) const override
    {
        const int index = static_cast<int>(value);
        if (index >= 0 && index < d_labels.size())
            return QwtText(d_labels.at(index));
        return QwtText();
    }

private:
    QStringList d_labels;
};

plot->setAxisScaleDraw(QwtPlot::xBottom, new NameScaleDraw(names));

setAxisScaleDraw 会接管这个对象的生命周期，别自己 delete。每根轴要一个独立实例，同一份 QwtScaleDraw 指针塞给两根轴，析构时双重释放。

排行榜的类别名短，到这一步就够了。真实项目里名称长得多，「扫地神僧」换成「Φ12 HRB400 螺纹钢」试试，横向摆必然糊成一团。三种处理方式：

做法 接口 能做到 做不到
换文字 重写 QwtScaleDraw::label 下标转中文、加单位后缀 标签位置和间距完全不变，长标签照样撞
手工刻度 QwtScaleDiv + setAxisScaleDiv 任意刻度位置，可以故意跳过某几根 标签仍是纯文本，挤还是挤
倾斜对齐 setLabelRotation + setLabelAlignment 长标签错开，成本极低 图标、换行、双行排版做不来
重写绘制 重写 QwtScaleDraw::drawLabel 图标加文本、双行、任意对齐 坐标得自己算，算错就是一坨

先上倾斜，最省事：

cpp
class TiltNameScaleDraw : public QwtScaleDraw
{
public:
    TiltNameScaleDraw(Qt::Orientation orientation, const QStringList &labels)
        : d_labels(labels)
    {
        Q_UNUSED(orientation)

        // 砍掉次要刻度与中等刻度，主刻度保留 5 像素
        setTickLength(QwtScaleDiv::MinorTick,  0);
        setTickLength(QwtScaleDiv::MediumTick, 0);
        setTickLength(QwtScaleDiv::MajorTick,  5);

        // 隐藏轴底线，图表看起来干净
        enableComponent(QwtScaleDraw::Backbone, false);

        // 倾斜 -10 度，垂直居中
        setLabelRotation(-10.0);
        setLabelAlignment(Qt::AlignVCenter);
    }

    QwtText label(double value) const override
    {
        const int index = static_cast<int>(value);
        if (index >= 0 && index < d_labels.size())
            return QwtText(d_labels.at(index));
        return QwtText();
    }

private:
    QStringList d_labels;
};

enableComponent(QwtScaleDraw::Backbone, false) 会把 X 轴那条横线去掉。排行榜图表里这条线意义不大，留白更舒服。刻度长度全设 0 的话，连小短线也一起没了，只剩文字。

再往上走就是「图标 + 文本」的混排标签。做法是先用占位串把宽度占住，再在 drawLabel 里自己画：

cpp
#include <QPainter>
#include <QFontMetrics>

class IconTextScaleDraw : public QwtScaleDraw
{
public:
    explicit IconTextScaleDraw(const QStringList &labels)
        : d_labels(labels)
    {
        setTickLength(QwtScaleDiv::MinorTick,  0);
        setTickLength(QwtScaleDiv::MediumTick, 0);
        setTickLength(QwtScaleDiv::MajorTick,  0);
        enableComponent(QwtScaleDraw::Backbone, false);
    }

    // 返回一串空格，靠它把刻度间距撑开
    QwtText label(double) const override
    {
        return QwtText(QStringLiteral("                   "));
    }

    void drawLabel(QPainter *painter, double value) const override
    {
        const QFont     font = this->label(value).font();
        const QRectF    rect = this->labelRect(font, value);
        const QPointF   pos  = this->labelPosition(value);
        QString level, text;
        const int index = static_cast<int>(value);
        if (index >= 0 && index < d_labels.size()) {
            // 标签格式 "LEVEL_A;Φ12"
            const QStringList parts = d_labels.at(index).split(QLatin1Char(';'));
            if (parts.count() > 1) {
                level = parts.at(0);
                text  = parts.at(1);
            }
        }

        const QFontMetrics fm(font);
        const int textWidth = fm.horizontalAdvance(text);
        const int offsetX   = (rect.width() - textWidth - 13) / 2;
        const int left      = static_cast<int>(pos.x() - rect.width() / 2 + offsetX);
        // 左边画图标
        painter->drawPixmap(QPointF(left, pos.y()),
                            QPixmap(QStringLiteral(":/Bar/barLevel%1").arg(level)));
        // 右边画文字，留 13 像素给图标
        painter->drawText(QRect(left + 13, static_cast<int>(pos.y()),
                                static_cast<int>(rect.width() - offsetX - 13),
                                static_cast<int>(rect.height()) + 5),
                          Qt::AlignLeft | Qt::AlignVCenter, text);
    }

private:
    QStringList d_labels;
};

这段代码的关键不在画图，在 label() 返回的那 19 个空格。labelRect() 的宽度是按 label() 的文本算出来的，你返回空串，rect 宽度接近 0，图标和文字全挤在一个点上。占位串的长度直接决定刻度之间的空隙，名称越长，空格要越多。

QFontMetrics::horizontalAdvance 是 Qt 5.11 之后的接口。老版本用 fm.width(text)，两者在等宽字体下结果一致。

五、逐柱设置颜色 #

QwtPlotBarChart 没有 setBarColor(int index, QColor color) 这种接口，也没有 bars[3]->setBrush() 的写法。原因在第二章说过：一整组柱子只是画布上的一个图形项。Qwt 内部拿 QVector<double> 逐根算矩形，然后统一交给一个 QwtColumnSymbol 去画。你手里没有「第 3 根柱子」这个对象。

所以逐柱配色的正确姿势是接管「生成符号」这一步。QwtPlotBarChart 留了一个虚函数：

cpp
virtual QwtColumnSymbol *specialSymbol(int sampleIndex, const QPointF &position) const;

每个样本要绘制前，Qwt 调一次这个函数，把下标和柱子的位置坐标递给你，你返回一个 QwtColumnSymbol，它拿去画。返回 nullptr 表示这一根用默认符号。

于是配色变成下标查表：

cpp
#include <qwt_plot_barchart.h>
#include <qwt_column_symbol.h>
#include <QColor>

class DistroChartItem : public QwtPlotBarChart
{
public:
    DistroChartItem()
    {
        // 图例按柱标题逐条显示
        setLegendMode(QwtPlotBarChart::LegendBarTitles);
        setLegendIconSize(QSize(15, 15));
    }

    void addDistro(const QString &distro, const QColor &color)
    {
        d_distros += distro;
        d_colors  += color;
        itemChanged();          // 通知 item 数据变了
    }

    QwtColumnSymbol *specialSymbol(int index, const QPointF &) const override
    {
        // Box 是方柱，Raised 是浮雕描边
        QwtColumnSymbol *symbol = new QwtColumnSymbol(QwtColumnSymbol::Box);
        symbol->setLineWidth(5);
        symbol->setFrameStyle(QwtColumnSymbol::Raised);

        QColor color(Qt::white);
        if (index >= 0 && index < d_colors.size())
            color = d_colors.at(index);
        symbol->setPalette(color);
        return symbol;
    }

    QwtText barTitle(int sampleIndex) const override
    {
        if (sampleIndex >= 0 && sampleIndex < d_distros.size())
            return QwtText(d_distros.at(sampleIndex));
        return QwtText();
    }

private:
    QList<QColor>  d_colors;
    QStringList    d_distros;
};

四点必须记牢：

返回的对象所有权交出去了。 你在 specialSymbol 里 new 出来的符号由 QwtPlotBarChart 负责 delete，自己别再碰，更不能把成员变量的指针返回去——同一个指针被 delete 两次就崩了。

每次重绘都会调。 replot() 一次，10 根柱子就调 10 次 specialSymbol，1000 根就 1000 次。函数体里只做查表和 new，别读文件、别查数据库、别 qDebug() 刷屏。

颜色表的下标必须和样本对得上。 d_colors 少一位，后面所有柱子的颜色整体错位一根，而且不报错，只是颜色看着不对。

setPalette 只是填充色，描边另算。 要改边框颜色用 setLinePen，要改线宽用 setLineWidth。QwtColumnSymbol::Box 配 QwtColumnSymbol::Raised 出立体描边，配 NoFrame 出纯色块。

如果所有柱子一个色，别写 specialSymbol，直接 setSymbol：

cpp
QwtColumnSymbol *symbol = new QwtColumnSymbol(QwtColumnSymbol::Box);
symbol->setPalette(QColor(0, 160, 230));
symbol->setLineWidth(1);
symbol->setFrameStyle(QwtColumnSymbol::NoFrame);
bars->setSymbol(symbol);        // 所有柱子共用，item 接管所有权

三种配色粒度的取舍：

粒度 手段 代码量 适用
整组一色 setSymbol 3 行 单一指标，靠图例区分系列
逐柱一色 重写 specialSymbol 20 行 排行榜、分类对比
逐柱按规则变色 specialSymbol 里算颜色 40 行起 阈值告警、盈亏损益

第三档才是报表里真正要用的。颜色不由数据源给，而是按数值当场算：超过计划量 5% 标红，低于 5% 标绿，正负 5% 以内标黄。这段逻辑放在 specialSymbol 里，或者更彻底一点，塞进自定义的 QwtColumnSymbol 构造函数——具体写法在「堆叠与分组」一章展开。

六、横向与纵向切换 #

QwtPlotBarChart 有一个 orientation 属性，两行代码就能把柱子从竖的变成横的：

cpp
bars->setOrientation(Qt::Vertical);     // 竖向柱，默认值
bars->setOrientation(Qt::Horizontal);   // 横向柱

只改这一句，图会歪掉。因为轴的含义也跟着换了：

text
纵向 Qt::Vertical              横向 Qt::Horizontal
xBottom = 0..n-1 类别下标      yLeft   = 0..n-1 类别下标
yLeft   = 数值                 xBottom = 数值
零位线 y = 0，HLine            零位线 x = 0，VLine

竖着排的时候，X 轴是「人物」、Y 轴是「战斗力」。横过来之后，柱子从 Y 轴往右长，Y 轴变成「人物」、X 轴变成「战斗力」。你要是只调 setOrientation 不动轴，结果就是「人物」两个字还挂在左边，刻度却是 0 到 10000 的数字，类别名跑到底下去了。

源码里的处理办法很直接：拿两个局部变量记住「类别轴」和「数值轴」，横向时对调两个轴的 ID，再按角色配置。

cpp
void BarChart::setOrientation(int value)
{
    const Qt::Orientation orientation =
        (value == 0) ? Qt::Vertical : Qt::Horizontal;
    int categoryAxis = QwtPlot::xBottom;   // 纵向：类别在 X
    int valueAxis    = QwtPlot::yLeft;     // 纵向：数值在 Y

    if (orientation == Qt::Horizontal)
        qSwap(categoryAxis, valueAxis);    // 横向：两个角色互换
    d_barItem->setOrientation(orientation);

    // ---- 类别轴 ----
    setAxisTitle(categoryAxis, QStringLiteral("人物"));
    setAxisMaxMinor(categoryAxis, 0);
    setAxisScaleDiv(categoryAxis, makeCategoryDiv(d_distros.size()));
    setAxisScaleDraw(categoryAxis, new NameScaleDraw(d_distros));
    // ---- 数值轴 ----
    setAxisTitle(valueAxis, QStringLiteral("战斗力"));
    setAxisMaxMinor(valueAxis, 5);
    setAxisScale(valueAxis, 0, 10000);
    setAxisScaleDraw(valueAxis, new QwtScaleDraw());

    plotLayout()->setCanvasMargin(5);
    replot();
}

makeCategoryDiv 就是第四章那段构造代码抽成的辅助函数，入参是类别数量，返回两端各留 0.5 空档的 QwtScaleDiv。横竖切换时它跟着类别轴走。

这套写法的四条纪律：

类别轴用 setAxisScaleDiv，数值轴用 setAxisScale，两者别串。 同一条轴上先 setAxisScaleDiv 再 setAxisScale，手工刻度被覆盖。反过来先 setAxisScale 再 setAxisScaleDiv 也白搭，后者才生效——但代码读起来就别扭了。

轴标题必须跟着换。 这是切换后最容易漏的一步，漏了就是「人物」标在数值轴上。

setAxisMaxMinor 也要跟着换。 类别轴的次要刻度要设 0，否则柱子之间会冒出半格刻度。数值轴保留 5 个次要刻度看得更清楚。

每次切换都会 new 一个 QwtScaleDraw。 setAxisScaleDraw 会 delete 上一个实例，不会泄漏，但频繁切换时对象反复创建销毁。要省这点开销，就在构造函数里建好实例并缓存成员指针，切换时传回去。

负值场景还要加一条零位线。这条线的方向同样随 orientation 翻转：纵向图里它是水平线（y = 0），横向图里是垂直线（x = 0）。

cpp
#include <qwt_plot_marker.h>

// 成员：QwtPlotMarker *m_zeroLine = nullptr;

if (m_zeroLine == nullptr) {
    m_zeroLine = new QwtPlotMarker();
    m_zeroLine->setLinePen(QPen(Qt::red, 1, Qt::DashLine));
    m_zeroLine->setLabelAlignment(Qt::AlignRight | Qt::AlignTop);
    m_zeroLine->attach(this);
}

if (orientation == Qt::Horizontal) {
    m_zeroLine->setLabel(QwtText(QStringLiteral("x = 0")));
    m_zeroLine->setLineStyle(QwtPlotMarker::VLine);
    m_zeroLine->setXValue(0.0);
} else {
    m_zeroLine->setLabel(QwtText(QStringLiteral("y = 0")));
    m_zeroLine->setLineStyle(QwtPlotMarker::HLine);
    m_zeroLine->setYValue(0.0);
}

标线只创建一次，切换时改 setLineStyle 和对应的坐标值。QwtPlotMarker 用 HLine 就只看 Y 值，用 VLine 就只看 X 值，两个值都设也不冲突。

盈亏图的数值轴范围要跨零：setAxisScale(valueAxis, -100, 100)。柱子从 0 往上或往下长，零位虚线正好落在中间。范围不对称的时候要自己算上下界：

cpp
const auto mm = std::minmax_element(samples.constBegin(), samples.constEnd());
const double lo = qMin(0.0, *mm.first);
const double hi = qMax(0.0, *mm.second);
plot->setAxisScale(valueAxis, lo * 1.1, hi * 1.1);

写 * 1.1 是为了给柱头的数值文字留位置。不留的话最上面那根柱子的数字会被画布边缘切掉一半。

七、QwtPlotHistogram：直方图 #

柱状图和直方图在中文里常被混着叫，在 Qwt 里是两个类，数据模型完全不同。

QwtPlotBarChart 收的是 QVector<double>，一个值一根柱，横轴是类别。QwtPlotHistogram 收的是 QVector<QwtIntervalSample>，一个样本带一个区间和一个值，横轴是连续的数值轴：

cpp
#include <qwt_plot_histogram.h>
#include <qwt_samples.h>
#include <QPen>
#include <QBrush>

QwtPlotHistogram *hist = new QwtPlotHistogram(QStringLiteral("请求耗时分布"));
hist->setStyle(QwtPlotHistogram::Columns);
hist->setBaseline(0.0);
hist->setPen(QPen(QColor(0, 120, 180), 1));
hist->setBrush(QColor(0, 160, 230, 180));

QVector<QwtIntervalSample> bins;
const double binWidth = 10.0;
for (int i = 0; i < counts.size(); ++i) {
    const double lo = i * binWidth;
    const double hi = lo + binWidth;
    bins << QwtIntervalSample(counts.at(i), lo, hi);
}
hist->setSamples(bins);
hist->attach(plot);
plot->setAxisTitle(QwtPlot::xBottom, QStringLiteral("耗时 (ms)"));
plot->setAxisTitle(QwtPlot::yLeft,   QStringLiteral("请求数"));
plot->setAxisScale(QwtPlot::xBottom, 0.0, counts.size() * binWidth);
hist->setOrientation(Qt::Vertical);

QwtIntervalSample 的构造顺序是 (value, lowerBound, upperBound)，第一个参数是高度，别按「左闭右开区间」的直觉把数值排在最后。顺序写反了不会报错，画出来一片空白，因为高度变成了区间边界那么大的数。

三种绘制样式：

样式 效果 用途
Columns 实心柱加边框 常规直方图，最常用
Outline 只有边框，内部透明 两套分布叠在一起对比
Lines 只画区间边界的竖线 区间很密、柱宽只有两三像素时

QwtPlotBarChart 与 QwtPlotHistogram 的差别：

维度 QwtPlotBarChart QwtPlotHistogram
样本类型 QVector<double> QVector<QwtIntervalSample>
横轴语义 类别下标，无物理量纲 连续数值区间
柱宽来源 布局自动计算 由 interval 宽度决定
相邻柱 有间隔，setSpacing 控制 紧挨，表达连续分布
逐柱配色 specialSymbol(int, const QPointF&) specialSymbol(const QwtIntervalSample&, const QPointF&)
轴刻度 必须自定义成类别文本 数值轴，等分刻度够用
典型场景 排行榜、分类对比、盈亏表 耗时分布、误差分布、频次统计

选哪个看横轴。横轴是「谁」，用 QwtPlotBarChart；横轴是「多少到多少」，用 QwtPlotHistogram。排行榜的横轴是人物名称，属于前者；接口耗时分布的横轴是毫秒区间，属于后者。

QwtPlotHistogram 也有 specialSymbol，签名和柱状图不同，第一个参数是完整样本而不是下标。要按高度分段着色（比如 P99 之后标红），就从 sample.value 判断，超阈值给红色配方，否则给蓝色，其余写法和柱状图一样。

八、堆叠与分组 #

一根柱子装不下两个指标的时候，用 QwtPlotMultiBarChart。它是 QwtPlotBarChart 的多系列版本：外层是类别，内层是系列。

cpp
#include <qwt_plot_multi_barchart.h>

QwtPlotMultiBarChart *bars = new QwtPlotMultiBarChart(QStringLiteral("采购对比"));
bars->setLayoutPolicy(QwtPlotMultiBarChart::AutoAdjustSamples);
bars->setSpacing(10);
bars->setMargin(0);
bars->setStyle(QwtPlotMultiBarChart::Grouped);     // 分组
// bars->setStyle(QwtPlotMultiBarChart::Stacked); // 堆叠

QList<QwtText> titles;
titles << QwtText(QStringLiteral("计划量"))
       << QwtText(QStringLiteral("实际采购"));
bars->setBarTitles(titles);

// 外层下标 = 类别，内层下标 = 系列
QVector<QVector<double>> samples;
for (const BarAmount &row : d_rows)
    samples << (QVector<double>() << row.planAmount << row.purchaseAmount);

bars->setSamples(samples);
bars->attach(plot);

samples 的形状最容易搞反。samples[0] 是第 0 个类别的所有系列值，samples[0][1] 是第 0 个类别的第 1 个系列。写成「按系列分组」的样子（外层系列、内层类别），画出来的柱子会横着错位，而且很难一眼看出来。

两种排布：

模式 枚举值 柱子关系 适合
分组 Grouped 同一类别内并排，多根挨着站 计划与实际对比、同比环比
堆叠 Stacked 同一类别内向上累加 构成占比、总量拆分

分组模式看的是「两根柱子谁高」，堆叠模式看的是「总量的构成」。同一个数据集，想问「实际采购有没有超计划」用分组，想问「总成本里材料占多少」用堆叠。

布局策略也影响观感：

策略 含义
AutoAdjustSamples 按画布宽度自动缩放柱宽，报表里最稳
SampleSize 用样本里的固定宽度
ScaleSamplesToAxes 按轴范围缩放，柱宽跟着轴走
ScaleSampleToCanvas 按画布比例缩放
FixedSampleSize 固定像素宽度，窗口拉大柱子不跟着变粗

逐柱、逐系列的着色走另一个虚函数，比单系列版本多一个参数：

cpp
virtual QwtColumnSymbol *specialSymbol(int sampleIndex, int valueIndex) const;

sampleIndex 是类别下标，valueIndex 是系列下标。两个下标都在手，就能实现「实际采购量按阈值变色、计划量保持空心底框」这种效果：

cpp
class GJHPlotMultiBarChart : public QwtPlotMultiBarChart
{
public:
    void setRows(const QList<BarAmount> &rows) { m_rows = rows; }

protected:
    QwtColumnSymbol *specialSymbol(int sampleIndex, int valueIndex) const override
    {
        const BarAmount row = m_rows.at(sampleIndex);
        const EnAmount kind = (valueIndex == 1) ? PurchaseAmount : PlanAmount;
        return new GJHOverdraftColumnSymbol(row.amount,
                                            row.planAmount,
                                            row.purchaseAmount,
                                            kind);
    }

private:
    QList<BarAmount> m_rows;
};

阈值判定逻辑写在符号的构造函数里：

cpp
GJHOverdraftColumnSymbol(double amount, double planAmount,
                         double purchaseAmount, EnAmount kind)
    : QwtColumnSymbol()
    , m_amount(qRound(amount))
    , m_planAmount(qRound(planAmount))
    , m_purchaseAmount(qRound(purchaseAmount))
    , m_kind(kind)
    , m_textHeight(18)
    , m_textSpacing(10)
    , m_width(30)
{
    m_color = QColor(0, 160, 230);              // 默认蓝

    if (m_kind == PurchaseAmount) {
        if (m_planAmount == 0) {
            // 计划为 0，任何采购都是超采
            m_color = (m_purchaseAmount > 0) ? Qt::red : Qt::yellow;
        } else {
            const double ratio = qAbs(m_planAmount - m_purchaseAmount) / m_planAmount;
            if (ratio <= 0.05)
                m_color = Qt::yellow;           // 正负 5% 以内
            else
                m_color = (m_planAmount > m_purchaseAmount) ? Qt::green : Qt::red;
        }
    }
    m_color.setAlpha(180);                      // 半透明，压住网格线
}

三步判定：计划量为 0 单算、偏差 5% 以内算正常、其余按方向分绿红。qRound 先取整是为了消掉浮点误差——9999.9999 和 10000 落在 5% 边界上，会得到两种颜色。

绘制时两种角色分开处理。采购量画实心柱，计划量画空心底框再叠一段填充：

cpp
void draw(QPainter *painter, const QwtColumnRect &rect) const override
{
    QRectF r = rect.toRect();
    if (!r.isValid())
        return;

    // 柱宽固定 30 像素，居中裁切
    if (r.width() != m_width) {
        const int left = static_cast<int>((r.width() - m_width) / 2);
        r = QRectF(r.left() + left, r.top(), m_width, r.height());
    }
    const int h = static_cast<int>(r.height());

    if (m_kind == PurchaseAmount) {
        // 采购量：按上限比例换算高度，从底部往上画实心柱
        int ph = 0;
        if (m_purchaseAmount != 0 && m_amount != 0)
            ph = static_cast<int>(m_purchaseAmount / (m_amount * 1.2 / h));

        const QRectF bar(r.left(), r.bottom() - ph, r.width(), ph);
        const QRectF textRect(r.left() - m_textSpacing, bar.top() - m_textHeight,
                              r.width() + 2 * m_textSpacing, ph + m_textHeight);
        painter->setPen(Qt::NoPen);
        painter->setBrush(m_color);
        painter->drawRect(bar);
        painter->setPen(Qt::black);
        painter->drawText(textRect, Qt::AlignTop | Qt::AlignHCenter,
                          QString::number(m_purchaseAmount));
    } else {
        // 计划量：先描一个空心底框当总量，再按阶段比例填充
        painter->setBrush(Qt::NoBrush);
        painter->setPen(m_color);
        painter->drawRect(r);

        int plh = 0;
        if (m_amount != 0)
            plh = static_cast<int>(m_planAmount / (m_amount / h));

        const QRectF bar(r.left(), r.bottom() - plh, r.width(), plh);
        painter->setBrush(m_color);
        painter->drawRect(bar);
        // 智能避让：阶段量超过半高就写进柱内，否则甩到柱头外
        QRectF textRect(r.left() - m_textSpacing, bar.top() - m_textHeight,
                        r.width() + 2 * m_textSpacing, plh + m_textHeight);
        if (m_planAmount > m_amount / 2)
            textRect = bar;

        painter->setPen(m_planAmount > m_amount / 2 ? Qt::white : Qt::black);
        painter->drawText(textRect, Qt::AlignTop | Qt::AlignHCenter,
                          QString::number(m_planAmount));
    }
}

m_planAmount > m_amount / 2 这句是防重叠的核心。柱子高的时候文字塞在柱子里面，矮的时候甩到柱头上方，两行文字不会撞在一起。数值文字用白色压在深色柱子内，用黑色飘在浅色画布外，两种背景都能看清。

高度换算按「纵轴上限取最大值 1.2 倍」来算：柱高 = 值 / (上限 / 柱区高度)，源码里的写法是 值 / (上限 * 1.2 / 柱高)。这套比例算下来，柱子顶端永远落在画布上方留白处，不会顶到边。

分组模式和堆叠模式共用同一套 specialSymbol，但堆叠时后一根柱子的底边接着前一根的顶边，数值文字的位置要跟着改。堆叠 + 内嵌文字是组合起来最费劲的一种，写之前先把「文字贴着谁」想清楚。

九、图例与标注 #

图例在 QwtPlotBarChart 上有两种模式，选错就是「十条一模一样的色块」：

模式 图例内容 前提
LegendIcon 整组一个图标，配 item 标题 什么都不用做，默认
LegendBarTitles 每根柱子一条，各配标题 必须重写 barTitle(int)

LegendBarTitles 会逐根调 barTitle(sampleIndex) 要标题，你返回空 QwtText 就是一排空图例。条目多了会挤，用 QwtLegend::setMaxColumns 控制列数。

insertLegend 的位置参数决定图例贴哪边：LeftLegend、RightLegend、TopLegend、BottomLegend 四个值，ExternalLegend 表示不画在画布上，得自己接管 QwtLegend 部件布局。

柱头数值标注靠重写 QwtColumnSymbol::draw。这是全篇唯一直接操作 QPainter 的地方：

cpp
#include <qwt_column_symbol.h>
#include <QPainter>

class ValueColumnSymbol : public QwtColumnSymbol
{
public:
    ValueColumnSymbol(double value, const QColor &color)
        : QwtColumnSymbol(), d_value(value), d_color(color) {}

    void draw(QPainter *painter, const QwtColumnRect &rect) const override
    {
        const QRectF r = rect.toRect();
        painter->setBrush(d_color);
        painter->setPen(Qt::NoPen);
        painter->drawRect(r);
        painter->setPen(Qt::black);
        int top    = static_cast<int>(r.top());
        int height = static_cast<int>(r.height());
        Qt::Alignment align;
        if (d_value >= 0) {
            // 正值：文字在柱头上方，往上借 15 像素
            top    -= 15;
            height += 15;
            align   = Qt::AlignTop | Qt::AlignHCenter;
        } else {
            // 负值：文字在柱尾下方，往下借 15 像素
            height += 15;
            align   = Qt::AlignBottom | Qt::AlignHCenter;
        }
        painter->drawText(QRect(static_cast<int>(r.left()), top,
                                static_cast<int>(r.width()), height),
                          align, QString::number(d_value));
    }

private:
    double d_value;
    QColor d_color;
};

正负分支的差别只在 top 要不要往前挪。正值柱从基线往上长，文字得放在柱顶之上；负值柱往下长，柱子的 top() 就是基线，文字要贴着柱子底部。height 两边都加 15，是为了给文字腾出一行的高度。

除了柱头文字，标注还有标线这一类。QwtPlotMarker 能画三种线：

类型 含义 用在哪
QwtPlotMarker::HLine 水平线，只认 Y 值 零位线、目标线
QwtPlotMarker::VLine 垂直线，只认 X 值 横向图的零位线、分界点
QwtPlotMarker::Cross 十字，X 与 Y 都认 峰谷定位

画一条「计划量」阈值线，配上文字说明：

cpp
QwtPlotMarker *target = new QwtPlotMarker();
target->setLineStyle(QwtPlotMarker::HLine);
target->setYValue(8000.0);
target->setLinePen(QPen(QColor(200, 60, 60), 1, Qt::DashDotLine));

QwtText label(QStringLiteral("计划量 8000"));
label.setColor(QColor(200, 60, 60));
target->setLabel(label);
target->setLabelAlignment(Qt::AlignLeft | Qt::AlignBottom);
target->attach(plot);

标线的文字位置跟着线走，AlignLeft | AlignBottom 表示贴在线段的左端下方。想放在右端就改 AlignRight。标线文字和柱头文字撞在一起时，把标注的 m_textSpacing 调大，或者索性把标线画在柱子后面——attach 的先后顺序决定绘制层级，先 attach 的在下层。

十、导出与打印 #

导出用 QwtPlotRenderer，两个接口：

cpp
QwtPlotRenderer renderer;

// 按文件扩展名判断格式，尺寸随当前窗口
renderer.exportTo(plot, QStringLiteral("/tmp/chart.pdf"));

// 指定物理尺寸，单位是毫米
renderer.renderTo(plot, QStringLiteral("/tmp/chart.png"), QSizeF(180, 120));

QSizeF 的单位是毫米，不是像素。写 QSizeF(600, 500) 出来会是一张 600 毫米宽的巨图，A4 纸塞不下。想按 A4 横排导出，用 QSizeF(297, 210)。

导出时字体按磅值、柱宽按比例重算，所以图上元素的位置和屏幕预览不会完全一致。柱宽是算出来的（第二章说过），尺寸一变柱宽跟着变，specialSymbol 里写死的 30 像素柱宽在导出时会显得偏细——想两处一致，就得让柱宽随 rect.width() 走，别写死。

给用户选格式的完整写法：

cpp
void GJHOverdraftControlChart::exportChart(int width, int height)
{
    QString dir = getRecentDir();
    if (!dir.endsWith(QLatin1Char('\\')) && !dir.endsWith(QLatin1Char('/'))) {
        dir.append(QLatin1Char('\\'));
        dir = QDir::toNativeSeparators(dir);
    }
    const QString filePath = dir + QStringLiteral("超采控制表");
    // 矢量格式写死，位图格式按 Qt 当前支持的来
    QStringList filters;
    filters << QStringLiteral("PDF文档 (*.pdf)")
            << QStringLiteral("SVG文档 (*.svg)")
            << QStringLiteral("Postscript文档 (*.ps)");
    const QList<QByteArray> formats = QImageWriter::supportedImageFormats();
    if (!formats.isEmpty()) {
        QStringList patterns;
        for (const QByteArray &fmt : formats)
            patterns << QStringLiteral("*.%1").arg(QString::fromLatin1(fmt));
        filters << QStringLiteral("Images图片 (%1)").arg(patterns.join(QLatin1Char(' ')));
    }

    QString selectedFilter;
    const QString fileName = QFileDialog::getSaveFileName(
        this, QStringLiteral("导出图表为"), filePath,
        filters.join(QStringLiteral(";;")), &selectedFilter);
    if (fileName.isEmpty())
        return;

    QwtPlotRenderer renderer;
    renderer.renderTo(this, fileName, QSizeF(width, height));
}

三个细节：

扩展名决定格式。 用户选了「PDF文档」但文件名写成 chart.png，出来的是 PNG。renderTo 看的是文件名的后缀，不看 selectedFilter。要做严格校验，就在返回后检查后缀，不匹配自动补上。

路径分隔符必须转本地格式。 Windows 上拼出来的正斜杠路径，某些版本的 QFileDialog 和 QImageWriter 都认，但混着用容易出意外。QDir::toNativeSeparators 一行解决。

打印走同一条路。 QwtPlotRenderer::renderTo 收 QPaintDevice * 重载，构造一个 QPrinter printer(QPrinter::HighResolution)，printer.setPageOrientation(QPageLayout::Landscape) 转横排，再 renderer.renderTo(plot, &printer) 就完事。

导出失败时先看文件名。路径里有中文、有空格、目录不存在，三种情况 renderTo 都只是静默返回，不抛异常也不返回错误码。

构造函数负责数据、画布皮肤、图例：

cpp
#include "barchart.h"
#include <qwt_plot_canvas.h>
#include <qwt_plot_layout.h>
#include <qwt_plot_renderer.h>
#include <qwt_legend.h>

BarChart::BarChart(QWidget *parent)
    : QwtPlot(parent)
{
    const struct {
        QString name;
        double  hits;
        QColor  color;
    } rows[] = {
        {QStringLiteral("扫地神僧"), 10000, QColor(0, 160, 230)},
        {QStringLiteral("无崖子"),    9500, QColor(115, 185, 35)},
        {QStringLiteral("萧远山"),    8888, QColor(235, 30, 35)},
        {QStringLiteral("慕容博"),    8500, QColor(160, 70, 164)},
        {QStringLiteral("虚竹"),      8000, QColor(255, 130, 0)},
        {QStringLiteral("萧峰"),      7888, QColor(125, 125, 125)},
        {QStringLiteral("段誉"),      7000, QColor(125, 125, 255)},
        {QStringLiteral("天山童姥"),  6500, QColor(180, 255, 180)},
        {QStringLiteral("李秋水"),    5000, QColor(135, 205, 250)},
        {QStringLiteral("鸠摩智"),    4500, QColor(255, 175, 200)}
    };

    // 整体背景与标题
    setAutoFillBackground(true);
    setPalette(QColor(QStringLiteral("Linen")));
    setTitle(QStringLiteral("天龙八部十大高手排行榜"));

    // 画布：立体圆角凹陷
    QwtPlotCanvas *canvas = new QwtPlotCanvas();
    canvas->setLineWidth(2);
    canvas->setFrameStyle(QFrame::Box | QFrame::Sunken);
    canvas->setBorderRadius(10);
    QPalette canvasPalette(QColor(QStringLiteral("Plum")));
    canvasPalette.setColor(QPalette::Foreground, QColor(QStringLiteral("Indigo")));
    canvas->setPalette(canvasPalette);
    setCanvas(canvas);

    // 数据装配
    d_barChartItem = new DistroChartItem();
    QVector<double> samples;
    for (const auto &row : rows) {
        d_distros += row.name;
        samples   += row.hits;
        d_barChartItem->addDistro(row.name, row.color);
    }
    d_barChartItem->setSamples(samples);
    d_barChartItem->attach(this);

    insertLegend(new QwtLegend());
    setOrientation(0);
    setAutoReplot(false);      // 批量改动后手动 replot
}

setAutoReplot(false) 是性能开关。它关掉之后，所有 setAxis*、attach、setSamples 都不会自动触发重绘，只有你显式 replot() 才刷一次。构造过程里改十几项属性，开着自动重绘就是刷十几次。

setOrientation 的实现见第六章，原样搬过来。主窗口加一条工具栏，下拉框换方向、按钮导 PDF：

cpp
#include <QApplication>
#include <QMainWindow>
#include <QToolBar>
#include <QComboBox>
#include <QToolButton>
#include "barchart.h"

class MainWindow : public QMainWindow
{
public:
    explicit MainWindow(QWidget *parent = nullptr)
        : QMainWindow(parent)
    {
        BarChart *chart = new BarChart(this);
        setCentralWidget(chart);

        QToolBar *toolBar = new QToolBar(this);
        QComboBox *orientationBox = new QComboBox(toolBar);
        orientationBox->addItem(QStringLiteral("Vertical (纵向)"));
        orientationBox->addItem(QStringLiteral("Horizontal (横向)"));
        orientationBox->setSizePolicy(QSizePolicy::Fixed, QSizePolicy::Fixed);

        QToolButton *btnExport = new QToolButton(toolBar);
        btnExport->setText(QStringLiteral("Export PDF"));
        connect(btnExport, SIGNAL(clicked()), chart, SLOT(exportChart()));
        connect(orientationBox, SIGNAL(currentIndexChanged(int)),
                chart, SLOT(setOrientation(int)));

        toolBar->addWidget(orientationBox);
        toolBar->addWidget(btnExport);
        addToolBar(toolBar);
        chart->setOrientation(orientationBox->currentIndex());
    }
};

int main(int argc, char *argv[])
{
    QApplication a(argc, argv);
    MainWindow w;
    w.resize(600, 500);
    w.show();
    return a.exec();
}

整体的数据流：

text
rows[]（名称 + 数值 + 颜色）
   ├── d_distros  ──→ NameScaleDraw 的 label()  ──→ X 轴类别文字
   ├── samples    ──→ setSamples()               ──→ 柱子高度
   └── colors     ──→ specialSymbol() 查表        ──→ 逐柱颜色
                          └── barTitle() 查表     ──→ 图例条目

跑起来调整窗口大小，柱子宽度会跟着变，类别标签始终对齐。这就是把数据、刻度、绘制三层分开之后的效果：改数据不动刻度和颜色，换刻度不动数据。

十二、易错点速查 #

现象 根因 处理
柱子全挤在左边半屏 setAxisScale 上界写成 dataSize() 改成 dataSize() - 1
只有部分类别有刻度 用了 setAxisScale 的等分刻度 手工造 QwtScaleDiv 走 setAxisScaleDiv
手工刻度不生效 之后又调了 setAxisScale 两者只能留一个，顺序无关
标签还是数字不是名称 忘了 setAxisScaleDraw 挂上重写 label() 的 QwtScaleDraw 子类
长标签糊成一团 没倾斜、没占位 setLabelRotation(-10)，或重写 drawLabel 预留宽度
图标标签变成一个小点 label() 返回空串，labelRect 宽度为 0 返回一串空格把宽度占住
逐柱颜色不生效 只调了 setSymbol 重写 specialSymbol，别用 setSymbol
颜色整体错位一根 d_colors 与 samples 长度不一致 加断言 Q_ASSERT(d_colors.size() == samples.size())
切换方向后标题错位 只调了 setOrientation，轴没跟着换 用 qSwap 交换类别轴与数值轴的 ID
零位线方向不对 标线类型没随方向改 横向用 VLine，纵向用 HLine
柱头数字被切掉 数值轴没留余量 上界乘 1.1，或改 plotLayout()->setCanvasMargin
数值文字互相重叠 文字固定写在柱外 超过半高就写进柱内，见第八章
图例一排空方块 开了 LegendBarTitles 没重写 barTitle 补上 barTitle 返回类别名
导出图比例变形 QSizeF 当成像素填了 单位是毫米，A4 横排用 QSizeF(297, 210)
导出静默失败 目录不存在、路径含非法字符 检查目录，QDir::toNativeSeparators 转码
每改一个属性闪一次 自动重绘开着 setAutoReplot(false)，批量改完手动 replot()
程序退出时崩溃 手工 delete 了 QwtScaleDraw 或 QwtColumnSymbol 交给 Qwt 管，别碰所有权

三条最快的排查路径：

柱子位置不对，先打印 dataSize() 和轴范围，九成是范围算错。标签内容不对，先确认 setAxisScaleDraw 挂上去的是新实例，不是把指针塞错轴。颜色不对，先在 specialSymbol 里 qDebug() << index，看回调的下标是不是你以为的那个。

统计图表的难点从来不在画柱子，在于 Qwt 把「数据」「刻度」「绘制」拆成三层，每层都要你亲手接上。记住那句主线——一个 item 管一组柱子，柱子的身份是下标——剩下的接口都能自己推出来。
