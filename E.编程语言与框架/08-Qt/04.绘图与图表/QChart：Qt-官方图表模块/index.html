本篇只讲一件事：Qt 官方 QtCharts 模块怎么用。

  • 讲什么：模块定位与许可、QChart / QChartView / Series 三者的分工、折线/曲线/柱状/堆叠/饼图/散点/面积七类图的画法、坐标轴 QAbstractAxis、图例与标题、动画与主题、数据动态更新、工程里怎么启用、跟第三方库怎么取舍。
  • 不讲什么：QPainter 底层绘制、QGraphicsView 图形视图框架本身、QCustomPlot 与 Qwt 的内部机制。这三块各自成篇，本篇只在选型对比时点到。
  • 跨篇指路：要像素级手绘看同目录的 QPainter 两篇；要 Qt 之外的成熟绘图库看 QCustomPlot 三篇与 Qwt 四篇；纠结用哪个先翻选型篇。

一、QtCharts 模块是什么 #

QtCharts 是 Qt 官方提供的 2D 图表模块。它把折线、曲线、柱状、堆叠、饼图、散点、面积这一整套图做进了 Qt 里，坐标轴、图例、标题、动画、主题都是模块自带的能力，不用自己算布局。

关键点在这里：它是官方模块，但默认不装。

装 Qt 的时候，Qt Charts 在安装器里是一个独立可选组件，默认的 Desktop 套件里不含它。装完 Qt 打开 Qt Maintenance Tool，选 Add or remove components，在对应 Qt 版本节点下面勾上 Qt Charts。不勾，后面 .pro 里写 QT += charts 会直接报错：

text
Unknown module(s) in QT: charts

看到这行报错，九成不是代码问题，是组件没装。

工程里启用，qmake 一行：

QT += charts

CMake 也简单：

cmake
find_package(Qt6 COMPONENTS Charts REQUIRED)
target_link_libraries(myapp PRIVATE Qt6::Charts)

许可这块单独说，因为它卡住过不少项目。QtCharts 走的是 GPLv3 / 商业双授权，不是 LGPL。Qt5 时代如此，Qt6 之后依然如此，LGPLv3 的选项不包含 Qt Charts。含义很直接：项目如果按 LGPL 动态链接 Qt 发布闭源软件，再挂上 QtCharts 就不合规。三条路——按 GPL 开源、买商业授权、换库（QCustomPlot 或 Qwt）。选型细节看同目录的选型篇。

Qt5 与 Qt6 的模块形态有变化。Qt5 里 Qt Charts 是附加模块，头文件带模块前缀：

cpp
#include <QtCharts/QChartView>
#include <QtCharts/QLineSeries>
#include <QtCharts/QChart>

并且要在文件里写一句 QT_CHARTS_USE_NAMESPACE 把类名拉进全局作用域。Qt6 里 Qt Charts 随主仓库发布，头文件去掉前缀，QT_CHARTS_USE_NAMESPACE 不再需要。具体的命名空间展开方式以所用版本的头文件为准，版本之间的小改动别硬背。

二、三个核心类：QChart、QChartView、Series #

QtCharts 的类很多，骨架只有三个。

类 角色 关键接口
QChart 图表本体。管 Series、坐标轴、图例、标题、动画、主题 addSeries() / createDefaultAxes() / addAxis() / setTitle() / legend() / setTheme()
QChartView 显示控件，继承自 QGraphicsView，本身是个 QWidget 构造函数传 chart / setChart() / setRenderHint() / setRubberBand() / setDragMode()
Series 数据序列。QLineSeries、QBarSeries、QPieSeries 等都是它的子类 append() / replace() / setPen() / attachAxis()

关系是一条直线：

text
Series  --addSeries()-->  QChart  --setChart()-->  QChartView  --addWidget()-->  布局 / 窗口

QChart 是图表本体，负责容纳和管理一个或多个数据系列，处理整体绘制逻辑。QChartView 负责把 QChart 显示出来。Series 负责存数据。先造 Series 存数据，再交给 QChart 组织，最后塞进 QChartView 呈现。

这里有第一道坎，也是最常见的「图不出来」原因：

Series 必须 addSeries() 之后再 createDefaultAxes() 或手动挂轴，否则不显示。

只 addSeries() 不建轴，Series 确实在 chart 里，但绘图区一片空白——没有任何轴给数据定标，引擎不知道 x 从哪到哪、y 从哪到哪。顺序也不能反：createDefaultAxes() 是按「当前已在 chart 里的 Series」来生成轴的，你先调它再 addSeries()，等于白调。

createDefaultAxes() 还有个副作用要知道。它会把 chart 上已有的坐标轴删掉重造，所以用了手动挂轴的项目就别再混着调它。

最小可跑的一段：

cpp
QLineSeries *series = new QLineSeries();
series->append(0, 6);   // 在 (0, 6) 添加点
series->append(1, 3);   // 在 (1, 3) 添加点
series->append(2, 5);   // 在 (2, 5) 添加点

QChart *chart = new QChart();
chart->addSeries(series);        // 数据系列加入图表
chart->setTitle("示例线形图");     // 图表标题
chart->createDefaultAxes();      // 生成默认坐标轴

QChartView *chartView = new QChartView(chart);
chartView->setRenderHint(QPainter::Antialiasing);   // 抗锯齿

QVBoxLayout *layout = new QVBoxLayout(ui->chart_widget);
layout->addWidget(chartView);    // 放进已有 QWidget

QChartView 自己没什么神秘的。每个 QChartView 绑定一个 QChart，构造时传指针，或者事后 setChart() 换掉：

cpp
QChartView *chartView = new QChartView(chart);
QMainWindow window;
window.setCentralWidget(chartView);
window.show();

构造函数签名：

cpp
QChartView::QChartView(QChart *chart, QWidget *parent = nullptr);

chart 是要显示的图表，parent 是父窗口部件，默认为空；给了非空的父对象，它就跟着父组件一起被管理和布局。

常用接口分四类。

设置与获取图表对象：

cpp
QChartView *chartView = new QChartView();
QChart *chart = new QChart();
chartView->setChart(chart);      // 动态设置图表

QChart* chart() const 反向取回当前图表，后续所有对图的操作都从它出发。

渲染设置用 setRenderHint(QPainter::RenderHint hint, bool on = true)，最常开的是抗锯齿：

cpp
chartView->setRenderHint(QPainter::Antialiasing);

动画挂在 chart 上，不在 view 上：

cpp
chartView->chart()->setAnimationOptions(QChart::AllAnimations);

用户交互两个开关。框选缩放：

cpp
chartView->setRubberBand(QChartView::RectangleRubberBand);

拖动平移：

cpp
chartView->setDragMode(QGraphicsView::ScrollHandDrag);

缩放复位走 chart：

cpp
chartView->chart()->zoomReset();

橡皮筋（RubberBand）类型有四种，含义如下：

枚举 效果
QChartView::NoRubberBand 无橡皮圈。绘图区拖不出选框，也就无法缩放
QChartView::RectangleRubberBand 矩形橡皮圈。松手后选中区域在 XY 双向放大，填满绘图区
QChartView::HorizontalRubberBand 水平橡皮圈。松手后只把所选范围在水平方向放大
QChartView::VerticalRubberBand 竖直橡皮圈。松手后只把所选范围在竖直方向放大

默认是无橡皮圈，想要框选缩放得自己开。

QChartView 继承自 QGraphicsView，鼠标和键盘事件都能重载，交互行为可以完全定制。

鼠标事件：

cpp
void MyChartView::mousePressEvent(QMouseEvent *event) {
    QPoint point = event->pos();        // 鼠标点击位置
    // 自定义鼠标点击操作
    QChartView::mousePressEvent(event); // 保持默认行为
}

键盘事件，比如按 R 复位缩放：

cpp
void MyChartView::keyPressEvent(QKeyEvent *event) {
    if (event->key() == Qt::Key_R) {
        chart()->zoomReset();
    } else {
        QChartView::keyPressEvent(event);
    }
}

重载完记得把事件还给基类，不然框选和拖动会一起失效。

不想用内置橡皮筋、要自己接一套框选（比如右键菜单 + 框选放大一起做），就用三个鼠标事件加一个 QRubberBand：

cpp
/// 鼠标右键菜单 + 左键框选
void WidgetPloter::mousePressEvent(QMouseEvent *event)
{
    if (event->button() == Qt::RightButton) {
        m_menu->exec(event->globalPos());     // 点击位置弹右键菜单
    }

    if (event->button() == Qt::LeftButton) {
        origin = event->pos();                // 记录框选起点

        if (!rubberBand) {
            rubberBand = new QRubberBand(QRubberBand::Line, this);
        }

        rubberBand->setGeometry(QRect(origin, QSize()));   // 初始大小为 0
        rubberBand->show();
    }
    // 想省事就直接开内置的矩形橡皮圈：
    // this->setRubberBand(QChartView::RectangleRubberBand);
}

void WidgetPloter::mouseMoveEvent(QMouseEvent *event)
{
    if (rubberBand) {
        // 起点到当前鼠标位置，normalized() 保证左上角为正
        rubberBand->set(QRect(origin, event->pos()).normalized());
    }
}

void WidgetPloter::mouseReleaseEvent(QMouseEvent *event)
{
    if (rubberBand) {
        rubberBand->hide();                   // 松手先隐藏选框
        m_plot->zoomIn(QRect(origin, event->pos()).normalized());   // 按选区缩放
    }
}

三个事件分工明确：按下记起点并显示框，移动实时改框大小，松手隐藏框并按选区缩放。QRubberBand 只是那块可视化的选框，本身不碰数据。

这段代码的 m_plot->zoomIn() 是 QCustomPlot 那一套命名，m_plot->scroll(10, 5)（整体平移）、m_plot->zoom(0.9)（按系数缩放）、m_plot->zoomReset()（撤销缩放）也是。原样搬到 QChartView 上编译不过，得换成 QChart 的接口：

cpp
void MyChartView::mouseReleaseEvent(QMouseEvent *event)
{
    if (rubberBand) {
        rubberBand->hide();
        QRect band = QRect(origin, event->pos()).normalized();
        chart()->zoomIn(mapToScene(band).boundingRect());   // 换成场景坐标
    }
    QChartView::mouseReleaseEvent(event);
}

zoomIn 收的是图表坐标系的矩形，直接把 view 的 event->pos() 坐标丢进去会缩放到错的位置，mapToScene() 这步不能省。另一条路是框完直接改轴范围：axisX->setRange(...) 加 axisY->setRange(...)，效果一样，可控性更强，但要自己处理边界和反向拖拽。

想边写边看框的位置，qDebug() 打一行就够了：

cpp
qDebug() << rect().x() << rect().y() << rect().width() << rect().height()
         << origin.x() << origin.y();

一段能直接编译运行的完整程序：

cpp
#include <QtCharts/QChartView>
#include <QtCharts/QLineSeries>
#include <QtCharts/QChart>
#include <QtWidgets/QApplication>
#include <QtWidgets/QMainWindow>

QT_CHARTS_USE_NAMESPACE

int main(int argc, char *argv[]) {
    QApplication a(argc, argv);

    QLineSeries *series = new QLineSeries();   // 创建折线系列
    series->append(0, 6);                      // 添加数据点
    series->append(2, 4);
    series->append(3, 8);
    series->append(7, 4);
    series->append(10, 5);

    QChart *chart = new QChart();              // 创建图表
    chart->addSeries(series);                  // 系列加入图表
    chart->setTitle("Simple Line Chart Example");
    chart->createDefaultAxes();                // 默认坐标轴

    QChartView *chartView = new QChartView(chart);
    chartView->setRenderHint(QPainter::Antialiasing);

    QMainWindow window;
    window.setCentralWidget(chartView);
    window.resize(800, 600);
    window.show();

    return a.exec();
}

这段是 Qt5 写法。搬到 Qt6，删掉 QT_CHARTS_USE_NAMESPACE，头文件换成 <QChartView>、<QLineSeries>、<QChart> 即可。

三、折线图与曲线图 #

QLineSeries 是最基础的一种 Series。它存一堆点，点之间用直线段连起来，形成连续折线。

画直线用它：

cpp
QLineSeries m_series;          // QLineSeries 对象
QPen green(Qt::red);           // 红色画笔
green.setWidth(2);             // 线宽 2 像素
m_series.setPen(green);        // 画笔应用到系列
m_series.append(m_x, m_y);     // 追加数据点 (m_x, m_y)

点靠 append 一个个加，颜色粗细靠 QPen 定。数据的类型是 QPointF，append(x, y) 是它的便捷重载。

想要平滑曲线换 QSplineSeries。它对离散点做三次样条插值，输出的线在点与点之间是弧，拐折消失。适合趋势展示，不适合强调「数据只在采样点上有值」的场景——插值出来的中间值不是真实测量值，报表里容易被人误读成实测。原始波形、脉冲、阶跃这种，老老实实用 QLineSeries。

append 之外还有几个批量接口好用：

cpp
series->append(QPointF(1.0, 2.0));            // 单点
series->append(QList<QPointF>{ /* ... */ });  // 一批点
series->replace(QList<QPointF>{ /* ... */ }); // 整体替换
series->remove(0);                            // 删掉第 0 个点
series->clear();                              // 全清

replace() 是刷新整屏数据的正确姿势，比 clear() 再逐个 append() 少一轮重绘。

数据量大以后折线会卡。QChart 这边有个缓解手段：

cpp
series->setUseOpenGL(true);

它是把系列渲染转到 OpenGL。代价明确——开启后 X 轴只能使用原生的数值轴 QValueAxis，无法使用时间轴 QDateTimeAxis；采用时间轴的点，在开启 OpenGL 之后曲线直接不显示。时间序列数据要做高性能，得把时间戳换算成毫秒数走 QValueAxis，自己格式化标签。

折线图的标准搭建流程，还是那五步：造 Series、灌点、addSeries、createDefaultAxes、塞进 QChartView。多曲线就在同一个 chart 上 addSeries 多次，每条 Series 各设各的 QPen，createDefaultAxes() 会按所有系列的范围算出一套公用轴。要让每条曲线独立配色，就在 addSeries 之后逐条 setPen，别指望默认颜色撞得好看。

曲线的线型、端点样式全部走 QPen：

cpp
QPen pen(QColor(0, 120, 215));
pen.setWidthF(2.0);
pen.setStyle(Qt::SolidLine);
pen.setCapStyle(Qt::RoundCap);
pen.setJoinStyle(Qt::RoundJoin);
series->setPen(pen);

setWidthF() 收浮点，setWidth() 收整数。高 DPI 屏上想画细线用前者。

点标记本身默认不画。要显示点，QtCharts 的风格是换 QScatterSeries 叠加，或者用 QLineSeries::setPointsVisible(true) 把点显出来，两者能共存于同一 chart。

四、柱状图与堆叠 #

柱状图这套类先认全。下面这张表是模块里 Series 的全景，画哪种图查哪一行：

Series 类 用途 配套坐标轴
QLineSeries 折线 QValueAxis / QDateTimeAxis
QSplineSeries 平滑曲线 QValueAxis / QDateTimeAxis
QScatterSeries 散点 QValueAxis / QDateTimeAxis
QAreaSeries 面积（带填充） QValueAxis / QDateTimeAxis
QBarSeries 垂直柱状 QBarCategoryAxis + QValueAxis
QStackedBarSeries 垂直堆叠柱 QBarCategoryAxis + QValueAxis
QPercentBarSeries 百分比堆叠柱 QBarCategoryAxis + QValueAxis
QHorizontalBarSeries 水平柱状 QBarCategoryAxis + QValueAxis
QHorizontalStackedBarSeries 水平堆叠柱 同上
QHorizontalPercentBarSeries 水平百分比堆叠 同上
QPieSeries 饼图 / 环形图 无轴
QBoxPlotSeries 箱线图 QBarCategoryAxis + QValueAxis
QCandlestickSeries K 线图 QBarCategoryAxis + QValueAxis

柱状图的数据单元不是点，是 QBarSet。一个 QBarSet 代表图例里的一项，里面按分类顺序存一组值。

cpp
QBarSet *set0 = new QBarSet("Jane");
QBarSet *set1 = new QBarSet("John");
*set0 << 1 << 2 << 3 << 4 << 5;   // 五个分类的取值
*set1 << 5 << 0 << 0 << 4 << 0;

QBarSeries *series = new QBarSeries();
series->append(set0);
series->append(set1);

QChart *chart = new QChart();
chart->addSeries(series);
chart->setTitle("季度销量");

QBarSet 重载了 operator<<，连着写就行。取值的个数就是分类数，几个 QBarSet 就往同一根柱子位置并排放几根。

轴要手动挂，两个：

cpp
QStringList categories;
categories << "一月" << "二月" << "三月" << "四月" << "五月";

QBarCategoryAxis *axisX = new QBarCategoryAxis();
axisX->append(categories);
chart->addAxis(axisX, Qt::AlignBottom);
series->attachAxis(axisX);

QValueAxis *axisY = new QValueAxis();
axisY->setRange(0, 6);
chart->addAxis(axisY, Qt::AlignLeft);
series->attachAxis(axisY);

顺序是固定的：chart->addAxis(轴, 停靠边) 把轴加到图表上，series->attachAxis(轴) 把轴绑到系列上。两步少一步，轴或者柱子就有一方不出现。

柱状图想要中文分类名，手动建 QBarCategoryAxis 最稳，别指望默认轴给你套上分类标签。

堆叠就是把 QBarSeries 换成它的兄弟类，其它代码不动：

cpp
QStackedBarSeries *series = new QStackedBarSeries();

三类柱状的区别：

类 堆叠方式 Y 轴量纲
QBarSeries 不堆叠，同类并排 原始值
QStackedBarSeries 堆叠累加 总量
QPercentBarSeries 堆叠并归一化到 100% 百分比

QPercentBarSeries 会自动把每根柱按比例压到 0~100，Y 轴你设成 0~100 就行。用它的时候别把 QValueAxis 范围写成原始数据范围，柱会冲出绘图区。

水平方向对应三个类：QHorizontalBarSeries、QHorizontalStackedBarSeries、QHorizontalPercentBarSeries。此时分类轴停靠左边 Qt::AlignLeft，数值轴停靠底部 Qt::AlignBottom，跟垂直版正好对调。

数值标签打开：

cpp
series->setLabelsVisible(true);        // 显示柱顶数值
series->setLabelsPosition(QAbstractBarSeries::LabelsOutsideEnd);
set0->setColor(QColor(0, 160, 230));   // 单组配色

QAbstractBarSeries::LabelsPosition 还有 LabelsCenter、LabelsInsideEnd、LabelsInsideBase，柱太矮时用外置，柱子高用内置不占地方。

五、饼图 #

饼图的数据单元是 QPieSlice，一瓣一个切片。QPieSeries::append(标签, 数值) 是最快的写法：

cpp
QPieSeries *series = new QPieSeries();
series->append("苹果", 40);
series->append("香蕉", 30);
series->append("橙子", 20);
series->append("其他", 10);

QChart *chart = new QChart();
chart->addSeries(series);
chart->setTitle("水果占比");

饼图不用坐标轴，也别去调 createDefaultAxes()——它没有轴可建。加上 QChartView 就能显示。

单个切片要精修，从 slices() 里取：

cpp
QPieSlice *slice = series->slices().at(0);
slice->setExploded(true);          // 抽出来
slice->setLabelVisible(true);      // 显示标签
slice->setLabel("苹果 40%");        // 自定义标签文字
slice->setPen(QPen(Qt::darkGreen, 2));
slice->setBrush(Qt::green);

setExploded(true) 把那瓣从圆心弹出去，饼图做重点强调时常用，但一次只弹一瓣，弹多了像打翻的披萨。

环形图只改一个数：

cpp
series->setHoleSize(0.4);   // 中间挖空，0~1，占半径比例
series->setPieSize(0.7);    // 饼半径占绘图区短边的比例

setHoleSize(0) 是实心饼，0.4 是个好看的环。setPieSize 控制整体缩放，饼图默认会撑得比较满，留点边距。

标签位置：

cpp
slice->setLabelPosition(QPieSlice::LabelOutside);   // 引线拉出去

四档：LabelOutside、LabelInsideHorizontal、LabelInsideNormal、LabelInsideRotated。分类多、名字长用外置；名字短、瓣够大用内置。

切片可以接信号做交互：

cpp
connect(slice, &QPieSlice::clicked, this, [slice]() {
    slice->setExploded(!slice->isExploded());
});
connect(slice, &QPieSlice::hovered, this, [slice](bool state) {
    slice->setExploded(state);
});

hovered(bool) 传的是悬停状态，悬停即弹、移开即收，比点击更顺手。

六、散点图与面积图 #

散点图用 QScatterSeries，一个点一个标记，点之间不连线。它跟 QLineSeries 同为 QXYSeries 的子类，append(x, y) 那套接口一致。

cpp
QScatterSeries *series = new QScatterSeries();
series->setName("采样点");
series->setMarkerSize(12.0);                        // 标记大小
series->setMarkerShape(QScatterSeries::MarkerShapeCircle);
series->setColor(QColor(0, 120, 215));              // 填充色
series->setBorderColor(QColor(0, 60, 120));         // 边框色

series->append(1.0, 2.0);
series->append(2.5, 3.1);
series->append(4.0, 1.7);
series->append(5.5, 4.2);

标记形状两档：MarkerShapeCircle 圆、MarkerShapeRectangle 方。散点密集时改小 markerSize，不然糊成一片。点数上万就上 setUseOpenGL(true)，同样有 X 轴只能挂 QValueAxis 的限制。

选中态和悬停态可以单独配色：

cpp
series->setSelectedColor(Qt::red);

再配合 series->selectPoint(3) 或 setSelectedPoints() 做程序化高亮。

面积图用 QAreaSeries，它自己不存数据，靠两条折线当上下边界：

cpp
QLineSeries *upper = new QLineSeries();
*upper << QPointF(1, 5) << QPointF(2, 6) << QPointF(3, 7) << QPointF(4, 6.5);

QLineSeries *lower = new QLineSeries();
*lower << QPointF(1, 2) << QPointF(2, 3) << QPointF(3, 3.5) << QPointF(4, 2.5);

QAreaSeries *area = new QAreaSeries(upper, lower);
area->setName("波动区间");

QPen pen(Qt::darkCyan);
pen.setWidth(2);
area->setPen(pen);
area->setBrush(QBrush(QColor(0, 180, 180, 90)));   // 半透明填充

QChart *chart = new QChart();
chart->addSeries(area);
chart->createDefaultAxes();

只给一条边界时，面积从 0 基线填起：

cpp
QAreaSeries *area = new QAreaSeries(upper);   // 下边界默认 y = 0

两个坑。第一，上下边界的 X 序列最好对齐，点数对不上时填充形状会歪。第二，QAreaSeries 只把边界线交给绘图引擎，attachAxis() 时要挂在 area 上，别挂在 upper 上——挂错了轴范围只覆盖一条线，另一条会被裁掉。

QAreaSeries 的填充走 setBrush，边线走 setPen，两个都要设，只设 brush 会留一圈默认黑边。

面积图叠折线做「区间 + 均值」很常见：一条 QAreaSeries 画带，一条 QLineSeries 画中位数，共用同一套轴。这种组合里，两条系列都要 addSeries，轴用 createDefaultAxes() 一次生成更省事。

七、坐标轴 QAbstractAxis #

所有坐标轴都继承自 QAbstractAxis。模块里就五种，按数据类型挑：

轴类 数据类型 典型用途
QValueAxis 连续数值 折线、散点、面积的常规 X/Y 轴
QDateTimeAxis 日期时间（毫秒时间戳） 时间序列
QLogValueAxis 对数刻度 跨数量级的数据
QBarCategoryAxis 字符串分类 柱状图、箱线图、K 线
QCategoryAxis 自定义分段标签 数值轴上的业务区间标注

通用接口不多，记住这几个够用：

接口 作用
setRange(min, max) 轴范围
setTitleText() 轴标题
setLabelFormat() 标签格式串
setTickCount() 刻度个数（含首尾）
setLabelsVisible() 标签显隐
setGridLineVisible() 网格线显隐
setLineVisible() 轴线本身显隐
setLabelsAngle() 标签旋转角度，防止长标签重叠
setReverse() 反向，Y 轴做大时用得到

数值轴：

cpp
QValueAxis *axisX = new QValueAxis;   // 新建 QValueAxis
axisX->setRange(0, 2000);             // 坐标范围
axisX->setLabelFormat("%g");          // 标签格式
axisX->setTitleText("Samples");       // 轴标题
axisX->setTickCount(5);               // 刻度数量

setRange 定义显示范围，setTickCount 定刻度数量，两个配合才能让图看着清爽。刻度给太多标签会挤成一排糊字，一般 5 到 10 个。

setLabelFormat 的格式串走 printf 那一套："%g" 通用、"%d" 整数、"%.2f" 两位小数、"%.1f ms" 带单位后缀。

时间日期轴：

cpp
QDateTimeAxis *axisX = new QDateTimeAxis;   // 新建 QDateTimeAxis
axisX->setTickCount(10);
axisX->setFormat("yyyy-MM-dd");             // 标签格式：年-月-日
axisX->setTitleText("Date");

// 设置起止时间
QDateTime startTime = QDateTime::fromString(minValue, "yyyy-MM-dd");
QDateTime endTime   = QDateTime::fromString(maxValue, "yyyy-MM-dd");
axisXDate->setRange(startTime, endTime);

// 轴绑到图表
chart->addAxis(axisXDate, Qt::AlignBottom);
// 轴绑到曲线
series->attachAxis(axisXDate);
// 追加点位，X 必须是毫秒时间戳
series->append(QPointF(QDateTime::fromString(curValueX, "yyyy-MM-dd").toMSecsSinceEpoch(), curValueY));

时间轴三个硬规定，踩过就记住了。

一，X 值必须是 toMSecsSinceEpoch() 出来的 qreal 毫秒数，不能塞字符串，也不能塞 QDateTime。塞错类型曲线直接不出现，编译还不报错。

二，setFormat 用的是 Qt 的日期格式符，MM 是月、mm 是分、yyyy 是四位年。写成 "yyyy-mm-dd" 出来的标签里是分钟数，看着像日期但不是。

三，setTickCount 给太密，时间标签互相压字。跨度大就减少刻度，或者配合 setLabelsAngle(-45) 斜排。

分类轴和自定义轴：

cpp
QCategoryAxis *axisY = new QCategoryAxis();
axisY->append("低", 33);
axisY->append("中", 66);
axisY->append("高", 100);
axisY->setRange(0, 100);

QCategoryAxis::append(标签, 该段上限) 是按数值区间贴业务标签，跟 QBarCategoryAxis 的纯字符串分类不是一回事。

Qt5 有个老接口写法，素材里也能见到：

cpp
chart->addSeries(series);
chart->setTitle("Sunspots count (by Space Weather Prediction Center)");
chart->setAxisX(axisX, series);   // Qt5 早期写法

setAxisX() / setAxisY() 在 Qt5 后期已废弃，Qt6 里直接移除。新代码统一写：

cpp
chart->addAxis(axisX, Qt::AlignBottom);
series->attachAxis(axisX);
chart->addAxis(axisY, Qt::AlignLeft);
series->attachAxis(axisY);

addAxis 的第二个参数是停靠边，可选 Qt::AlignBottom、Qt::AlignTop、Qt::AlignLeft、Qt::AlignRight。同一侧挂两条轴时 Qt 不会帮你错位排布，两条会画在同一位置，多 Y 轴场景得自己权衡范围与视觉。

轴和系列是独立的两个对象，绑上才生效。反过来，一条系列可以同时挂 X、Y 两条轴，也可以被多套轴共享——多轴曲线的做法就是不同系列挂不同 Y 轴。

八、图例与标题 #

标题最简单：

cpp
chart->setTitle("温湿度监控");
chart->setTitleFont(QFont("Microsoft YaHei", 12, QFont::Bold));
chart->setTitleBrush(QBrush(Qt::darkSlateGray));

标题为空字符串时不占位，绘图区自动上移，不用手动调边距。

图例从 chart->legend() 拿，默认已经挂在 chart 上并且可见：

cpp
QLegend *legend = chart->legend();
legend->setVisible(true);
legend->setAlignment(Qt::AlignBottom);            // 位置：上/下/左/右
legend->setMarkerShape(QLegend::MarkerShapeRectangle);
legend->setLabelColor(Qt::darkGray);
legend->setFont(QFont("Microsoft YaHei", 9));
legend->setBackgroundVisible(false);              // 去掉图例底框

图例条目从哪来？QXYSeries 从 setName() 来，QBarSet 从构造参数来，QPieSeries 从 append(标签, 值) 来。名字是空串，图例里就没有这一项。

setAlignment 四档：Qt::AlignTop、Qt::AlignBottom、Qt::AlignLeft、Qt::AlignRight。饼图的图例放右侧比放底部更省地方。

逐条改标记样式：

cpp
const auto markers = legend->markers();
for (QLegendMarker *marker : markers) {
    marker->setLabel("");
}

markers() 返回的是 QLegendMarker 列表，可以逐条改 setBrush、setPen、setLabel。想做「点击图例切换系列显隐」，也是在这个列表上接 clicked 信号，然后 series->setVisible(!series->isVisible())。

标题和图例都属于「布局元素」，QChart 会自动让绘图区避开它们。手写 plotArea() 坐标做叠加绘制时，记得它们占的空间会变。

九、动画与主题 #

动画三行开完：

cpp
chart->setAnimationOptions(QChart::AllAnimations);
chart->setAnimationDuration(600);                       // 毫秒
chart->setAnimationEasingCurve(QEasingCurve::OutQuart); // 缓动曲线

AnimationOption 是标志位组合：

枚举 效果
QChart::NoAnimation 关闭全部动画
QChart::GridAxisAnimations 坐标轴与网格线动画
QChart::SeriesAnimations 系列数据变化动画
QChart::AllAnimations 以上都开

动画只在数据变化时触发，静态图表开着它没开销。实时刷新的场景要留意：SeriesAnimations 配高频 replace()，每帧都在补间，看起来是抖的，这时关掉动画反而清楚。

主题一行：

cpp
chart->setTheme(QChart::ChartThemeDark);
枚举 观感
QChart::ChartThemeLight 浅色，默认
QChart::ChartThemeBlueCerulean 蓝调深色
QChart::ChartThemeDark 深色
QChart::ChartThemeBrownSand 沙棕
QChart::ChartThemeBlueNcs 工业蓝
QChart::ChartThemeHighContrast 高对比，适合投影演示
QChart::ChartThemeBlueIcy 冰蓝
QChart::ChartThemeQt Qt 品牌绿灰

主题有个必须知道的副作用：它会重刷整套配色，把你之前设的 setPen / setBrush 全盖掉。所以顺序是先 setTheme()，再逐条配 setPen。反过来的写法在改主题后颜色会莫名其妙变回去。

主题还会改图表背景和绘图区底色，但 QChartView 这个 view 自身的底色是另一层，要一起刷：

cpp
chartView->setBackgroundBrush(QBrush(QColor(30, 30, 30)));

老版本用的是 setBackgroundBrush() 在 QGraphicsView 上的同名接口，行为一致。

十、数据动态更新 #

更新只有两种姿势：

cpp
m_series.append(m_x, m_y);      // 追加：在现有数据尾巴上加一个点
m_series->replace(m_buffer);    // 整体刷新：用新数据集替掉旧的

追加适合流式数据，来一个点画一个点。replace() 适合定时全量刷新，一次换掉整批点，比 clear() 再逐个 append() 少一轮重绘。

满屏之后要滚动的写法：

cpp
qreal dwidth = chart->plotArea().width() / (m_axis.tickCount() * 2);  // 每次滚动的像素宽度
qreal dx = 10 / (m_axis.tickCount() * 2);                            // 横坐标偏移量
m_x += dx;                       // 更新 x
m_y = sin(m_x);                  // 算新的 y
m_series.append(m_x, m_y);       // 追加数据点

// 满屏之后滚动窗口
if (m_x > 10) {
    chart->scroll(dwidth, 0);
}

三个细节值得盯住。

plotArea().width() 在首次布局完成前返回 0。在构造函数里算 dwidth，结果恒为 0，图看着就是不动。要么放到 show() 之后，要么在 resizeEvent 里重算。

tickCount 同时进了像素和坐标两个换算，改刻度个数会连带改滚动速度，两个系数得一起调。

滚动和轴范围是两回事。chart->scroll() 平移视图，axisX->setRange(min, max) 改数据窗口。用滚动就别再手动改范围，两个一起用会互相抢。

驱动用定时器：

cpp
QTimer *timer = new QTimer(this);
connect(timer, &QTimer::timeout, this, &Widget::updateChart);
timer->start(33);      // 约 30 fps

高频刷新要关动画，setAnimationOptions(QChart::NoAnimation)。开着 SeriesAnimations 每帧都在补间，画面是抖的。点数上万再加 setUseOpenGL(true)，代价在第三章说过——X 轴只能用 QValueAxis。

十一、在工程里启用 QtCharts #

四步，少一步就跑不起来。

第一步，安装器勾 Qt Charts。Unknown module(s) in QT: charts 这行报错基本都出在这里。

第二步，工程文件加模块：

QT += core gui widgets charts
TARGET = chartdemo
TEMPLATE = app
SOURCES += main.cpp

QT 这行必须是 +=。写成 = 会把默认模块全顶掉，编到一半满屏未定义符号。

第三步，头文件与命名空间。这一步 Qt5 和 Qt6 分道扬镳：

项目 Qt5 Qt6
模块形态 独立附加模块 随主仓库发布的组件
qmake QT += charts QT += charts
CMake find_package(Qt5 COMPONENTS Charts REQUIRED) + Qt5::Charts find_package(Qt6 COMPONENTS Charts REQUIRED) + Qt6::Charts
头文件 #include <QtCharts/QChart> #include <QChart>
命名空间 需要 QT_CHARTS_USE_NAMESPACE 不再需要
加轴方式 setAxisX() 已废弃，用 addAxis + attachAxis 只有 addAxis + attachAxis
许可 GPLv3 / 商业 GPLv3 / 商业，无 LGPL 选项

Qt6 里命名空间的处理方式以所用版本的头文件为准，QT_CHARTS_USE_NAMESPACE 这个宏在 Qt6 中不再需要，写了会报未定义。

第四步，部署。windeployqt 会自动带上 Qt5Charts.dll 或 Qt6Charts.dll，漏了这个 dll，程序在开发机上跑得好好的，拷到别人机器上启动就崩。

十二、与第三方库的取舍 #

同目录另外十一篇讲的就是这些选项。一表看完：

方案 许可 数据量级 上手成本 定制自由度
QtCharts GPLv3 / 商业 万点级 低，接口统一 中，受模块封装限制
QCustomPlot GPL / 商业 十万点级 低，两个文件拖进工程 高
Qwt LGPL 系 十万点级 中，API 偏老派 中高
QPainter 手绘 随 Qt 看你写多好 高 完全自由

三条判断线，按顺序问自己。

许可先过。项目是闭源商业软件、又只能用 LGPL 动态链接，QtCharts 直接出局，转 Qwt 或买商业授权。

再看数据量。曲线点数稳定在几万以上、刷新率要求高，QCustomPlot 比 QtCharts 省心，QtCharts 的性能上限就在那里。

最后看外观需求。要工业仪表盘那套指针、表盘、老式刻度，Qwt 现成；要完全自定义的图形，QPainter 是唯一选择，代价是所有布局、缩放、坐标换算都得自己写。

QtCharts 的强项是「Qt 项目里最省事的一套」：系列类型齐、轴和图例自动布局、主题动画自带、跟 Qt Widgets 和 Qt Quick 都合得来。代价是许可限制和性能上限。

十三、易错点速查 #

现象 原因 处理
Unknown module(s) in QT: charts 组件没装 安装器勾 Qt Charts，或 .pro 里 QT += charts
QChart 未定义 头文件或命名空间 Qt5 加 QT_CHARTS_USE_NAMESPACE，Qt6 换 <QChart>
窗口出来一片空白 addSeries 后没建轴 createDefaultAxes() 或手动 addAxis + attachAxis
手配的轴消失 createDefaultAxes() 会删轴重建 用自定义轴的项目别调它
时间轴曲线不显示 X 值不是毫秒时间戳 QDateTime::toMSecsSinceEpoch()
开 OpenGL 后时间轴失效 模块限制 换 QValueAxis，标签自己格式化
柱状图标签变成数字 没挂分类轴 手动建 QBarCategoryAxis 并 attachAxis
换主题后颜色全变 setTheme() 覆盖 pen/brush 先 setTheme() 再逐条配色
图例某条目空白 系列没设名字 setName()，QBarSet 用构造参数
框选缩放没反应 默认 NoRubberBand setRubberBand(QChartView::RectangleRubberBand)
重载后又不能拖动了 没调基类实现 事件末尾调 QChartView::xxxEvent(event)
plotArea().width() 为 0 布局还没完成 放到 show() 之后或 resizeEvent 里算
饼图调 createDefaultAxes() 崩溃 饼图没有轴 饼图不建轴
闭源 + LGPL 项目用了 QtCharts 许可是 GPL / 商业 换 Qwt、QCustomPlot 或买授权

排查顺序就一条：先确认模块装没装、.pro 加没加，再确认轴建没建，最后才怀疑数据和样式。前两个占九成。

QtCharts 这套东西的骨架很薄：QChart 收 Series 和轴，QChartView 负责显示，Series 存数据。把「先 addSeries 再建轴」这条顺序刻进肌肉记忆，剩下全是查表配参数的事。
