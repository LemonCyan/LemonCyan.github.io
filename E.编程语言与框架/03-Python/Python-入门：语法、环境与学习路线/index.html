一、Python 是什么：解释型语言的运行方式 #

Python 是解释型语言。这句话不是标签，它直接决定三件事：代码怎么被执行、为什么比 C 慢、部署时目标机上必须有什么。编译型语言的流程是「源码 → 编译器 → 机器码」，产物脱离编译器独立运行；Python 没有这一步独立的构建，python hello.py 一条命令把分析和执行连着做完。

对比项 编译型（C / Go / Rust） 解释型（Python）
构建产物 目标平台的机器码 源码文件本身
执行者 CPU 直接取指执行 解释器逐条执行
跨平台方式 每个平台各编译一次 一份源码，各平台装解释器
启动开销 极低 解释器初始化 + 编译字节码
运行速度 快 慢一到两个数量级
交付依赖 系统动态库 目标机的 Python 版本与第三方包

一条 python hello.py 内部有四步，只有最后一步在真的干活：

text
hello.py → 词法/语法分析 → 语法树 AST → 编译成字节码 → PVM 逐条执行

分析和编译在每次启动、每次 import 时都发生一次。为省掉重复编译，CPython 把导入过的模块字节码缓存到 __pycache__，文件名带版本号（如 util.cpython-312.pyc）。.pyc 只省下「源码编译成字节码」这一段，逻辑还是逐条解释，别指望它提速。

想看解释器眼里的代码用 dis 反汇编：LOAD_FAST 把局部变量压进求值栈，BINARY_OP 弹两个做加法，RETURN_VALUE 返回。每条指令都要回到虚拟机派发循环判一次类型，这就是 Python 慢的根源——同样的加法，C 编译出来是一条机器指令，Python 要走三条字节码加若干次类型检查。所以纯 Python 循环里每条字节码都要分派，能换成内置函数、推导式、生成器就别手写循环；数值计算整块交给 NumPy，让 C 层去算；启动时间受 import 数量影响，冷启动敏感的场景要控制依赖。

解释型语言靠虚拟机执行，虚拟机里有一条全局锁，即 GIL，它保证同一时刻只有一个线程执行字节码。线程要跑先抢锁，跑满指定字节码条数、或主动进入 sleep / 等 I/O 时放锁，别的线程才有机会。I/O 密集型任务在等待时主动放锁，多线程确实省时间；计算密集型任务里的线程一直攥着锁，多开线程只是多了上下文切换开销，跑得比单线程还慢，那种情况得用 multiprocessing。

部署时，解释执行把「运行环境」变成交付物的一部分：

交付方式 目标机需要 适用场景
源码 Python + 手动装依赖 脚本、内部工具
源码 + requirements.txt Python + pip install -r 常规服务部署
容器镜像 Docker 线上服务
PyInstaller 单文件 无 发给不懂 Python 的同事

PyInstaller 是把解释器和字节码一起塞进包里，体积几十兆起步、冷启动还慢。

笔记开头列了一长串能力：系统运维、图形处理、数学处理、文本处理、数据库编程、网络编程、Web 编程、多媒体应用、黑客编程、爬虫、机器学习、人工智能。落到可操作的方向就这几块：脚本与运维用 os、pathlib、subprocess、shutil，本篇第十五章讲；文本处理用 str、re、csv、json，本篇第八、十五、十七章讲；数据与科学计算用 NumPy、SciPy、Pandas、Matplotlib，Web 后端用 Flask、Django、Tornado，爬虫用 requests、BeautifulSoup、Selenium，桌面 GUI 用 PyQt5、Tkinter，这些各有专篇；机器学习从 scikit-learn、PyTorch 起步，见第十七章。

现在还看到 print 'hello' 的代码，那是 Python 2 的写法，它 2020 年 1 月 1 日已停止维护。

项目 Python 2 Python 3
输出 print 'hi'（语句） print('hi')（函数）
字符串 str 是字节串，另有 unicode str 是 Unicode 文本，bytes 独立
除法 3 / 2 得 1 3 / 2 得 1.5，3 // 2 得 1
整数 int 与 long 两种 只有 int，任意精度
异常 except E, e: except E as e:
区间 / 输入 xrange、raw_input range 惰性、input 返回字符串
源码编码 默认 ASCII，要写 coding 声明 默认 UTF-8

看到 print x、except E, e、xrange、urllib2 这类写法，先改成 3 的对应形式再跑。

二、环境与版本管理 #

装 Python 只有一条原则：装官方发行版，把解释器路径放进 PATH，认准你要用的那一个。Windows 去 python.org 下 3.12 或 3.13 的安装包，第一屏勾上 Add python.exe to PATH；漏勾了不用重装，重跑安装包选 Modify 补上。走 Microsoft Store 的那版别用，解释器塞在 WindowsApps 目录下，权限和路径都别扭。

bash
python --version
python -c "import sys; print(sys.executable)"
where python

sys.executable 是唯一可信的答案，它告诉你敲 python 到底启动了哪个文件。多版本共存时用启动器 py -0p 列出所有版本（带星号的是默认），再用 py -3.11 -m pip install requests 指定版本执行。

macOS 自带 /usr/bin/python3 是系统工具链的一部分，别往上装包、别升级它，用 brew install python@3.12 另装一份。Linux 发行版仓库里的 python3 偏旧，要新的就上 pyenv，别替换系统自带的那个，包管理器自己依赖它。

动作 Windows macOS / Linux
看版本 python --version python3 --version
走模块方式装包 python -m pip install x python3 -m pip install x
建虚拟环境 python -m venv .venv python3 -m venv .venv
激活 .venv\Scripts\Activate.ps1 source .venv/bin/activate
版本 维护截止 建议
3.10 2026-10 match 语句从这版开始有
3.11 2027-10 稳，第三方轮子齐
3.12 2028-10 新项目首选
3.13 2029-10 可用，自由线程是实验特性
3.14 2030-10 追新特性可以上

选版本的现实依据是轮子覆盖率。某个库只发了 3.12 的二进制包，你装 3.13 就得现场编译，还要装 C 编译器。刚发布的版本等半年再上，能少踩安装坑。笔记里「包管理及其版本管理工具」这块容易混，工具各管一件事：

工具 管什么 什么时候用
pip 往当前解释器里装包 基础工具，一直都在用
venv 给项目隔离一套 site-packages 每个项目一个，标配
conda 解释器版本 + 二进制包 + 环境 科学计算、装不上编译依赖
pyenv 装多个解释器版本并切换 同时维护 3.10 和 3.13
poetry / uv 依赖解析 + 锁文件 + 打包 要可复现构建

模块是 .py 文件，包是带 __init__.py 的目录。四种导入方式，from module import * 别用，它让名字从哪来变得不可追：

python
import sys, os                    # 整个模块，逗号连写
from pathlib import Path          # 只导入一个名字
import numpy as np                # 起别名
from collections import OrderedDict, defaultdict

模块要么在脚本同目录，要么在某条搜索路径上，路径按 sys.path 的顺序查：第一条是脚本所在目录，后面是标准库、site-packages、PYTHONPATH。这个顺序带来一个坑：你在项目里建个 random.py、json.py 或 queue.py，它会盖掉标准库同名模块，import random 拿到的是你的文件，标准库那套功能全没了。建文件名前先想想有没有撞上标准库。

一个既能当脚本跑又能被导入的文件，结构固定：

python
# calc.py
def add(a, b):
    return a + b


def main():
    print(add(1, 2))


if __name__ == '__main__':
    main()

__name__ 是解释器自动塞进模块的变量：直接 python calc.py 跑时它是 '__main__'，被 import calc 时它是 'calc'。那行 if 的意思是「只有直接运行时才往下走」。

三、pip 与包管理 #

pip 随解释器一起装，机器上有几个 Python 就有几个 pip，各管各的 site-packages，所以装包统一走模块方式 python -m pip install requests，把 pip 绑到确定的解释器上。裸敲 pip 时落到哪个版本取决于 PATH 里谁在前面，「A 环境装了包、B 环境找不到」这类问题排查起来很浪费时间。

目的 命令
装包 / 指定版本 python -m pip install requests / "requests==2.31.0"
升级 / 卸载 python -m pip install -U requests / uninstall requests
看清单 / 看详情 python -m pip list / show requests
导出依赖 / 按清单装 pip freeze > requirements.txt / pip install -r requirements.txt
查依赖冲突 python -m pip check 
text
requests                # 任意版本
requests==2.31.0        # 精确锁定
requests>=2.28,<3.0     # 区间
requests~=2.31.0        # 兼容版本，等价于 >=2.31.0,<2.32.0
pywin32==306; sys_platform == "win32"    # 分号后是环境标记，不满足就跳过

线上服务锁精确版本，本地小工具可以放宽。pip 的解析器不是万能的：A 要 urllib3<2、B 要 urllib3>=2，它会先装一个再被另一个覆盖，跑起来报 ImportError。pip check 能查出一部分，根治办法是每个项目一套虚拟环境。新项目改用 pyproject.toml 声明依赖，poetry、uv、pdm 都吃这份文件，还能生成锁文件固定整棵依赖树，核心就两行：requires-python = ">=3.10" 加 dependencies = ["requests>=2.28", "flask>=3.0"]。

三条纪律：不要 sudo pip install，它会往系统目录写文件；不要在系统解释器里装业务包，升级发行版时全丢；不要把 pip install 的结果当成可复现构建，freeze 出来的清单才是。

四、pip 换源：解决下载慢 #

pip 默认从 https://pypi.org/simple 拉包，服务器在境外，国内直连经常卡在几十 KB/s，装一个带编译依赖的包能耗掉半小时。换源就是让 pip 去国内镜像取包，镜像站定期同步 PyPI 全量索引和文件，装的还是同一个包、同一个版本，只是下载链路短了。临时换源加 -i，跑完就完，不改变全局设置，写法是 pip install markdown -i https://pypi.tuna.tsinghua.edu.cn/simple；一次装多个包时 -i 只写一遍，分包放在同一行里。

镜像 索引地址
清华 https://pypi.tuna.tsinghua.edu.cn/simple
阿里云 https://mirrors.aliyun.com/pypi/simple/
腾讯云 https://mirrors.cloud.tencent.com/pypi/simple
豆瓣 https://pypi.douban.com/simple/
中科大 https://mirrors.ustc.edu.cn/pypi/simple
华为云 https://repo.huaweicloud.com/repository/pypi/simple

走 HTTP 的镜像、或证书链不被信任时，报 The repository located at ... is not a trusted or secure host，加 --trusted-host mirrors.aliyun.com 放行，只对本次命令生效；镜像支持 HTTPS 时优先用 https://，少一个豁免少一个隐患。每次都写 -i 太啰嗦，写进 pip 配置文件：

bash
# 清华
pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
# 阿里云
pip config set global.index-url https://mirrors.aliyun.com/pypi/simple/
# 腾讯云
pip config set global.index-url http://mirrors.cloud.tencent.com/pypi/simple
# 豆瓣
pip config set global.index-url http://pypi.douban.com/simple/
# 换回官方源
pip config unset global.index-url

pip config set 会自动写进对应平台的用户级配置文件。写了却不生效，用 pip config debug 看它依次读了哪些文件、哪个存在。手写文件的位置在 %APPDATA%\pip\pip.ini（Windows）或 ~/.config/pip/pip.conf（macOS / Linux）；%APPDATA% 一般展开成 C:\Users\你的用户名\AppData\Roaming，目录默认隐藏，地址栏直接粘路径进去：

text
[global]
index-url = https://pypi.tuna.tsinghua.edu.cn/simple

[install]
trusted-host = pypi.tuna.tsinghua.edu.cn

trusted-host 可以写多个，用空格或换行分隔。验证换源是否生效，装的时候加 -v，输出里出现 Looking in indexes: https://pypi.tuna.tsinghua.edu.cn/simple 才算配置起效，例如 pip install requests -v。

镜像只改下载地址，不改包的内容和版本，锁版本时该写的 == 一个都不能少。要同时装私有仓库的包，别把 index-url 换掉，用 --extra-index-url 追加。镜像站偶尔滞后几小时到一天，刚发布的版本在上面找不到（No matching distribution found），临时换回官方源装一次就行。

五、虚拟环境 #

全局装包的问题是版本冲突。项目 A 要 requests==2.25.0，项目 B 要 2.31.0，全局 site-packages 里只放得下一个 requests/ 目录，装了新的就盖掉旧的。虚拟环境给每个项目一套独立的 site-packages，互相看不见，venv 是标准库自带的，python -m venv .venv 一条命令建出来。

Windows 激活用 .venv\Scripts\Activate.ps1，macOS / Linux 用 source .venv/bin/activate。PowerShell 第一次跑脚本报「禁止运行脚本」，先执行 Set-ExecutionPolicy -Scope CurrentUser RemoteSigned 改策略。激活后提示符前面多一个 (.venv)，python、pip 都指向环境里的副本，确认进对了看 python -c "import sys; print(sys.prefix)" 打印的路径。退出用 deactivate，删环境直接删目录。不激活也能用环境里的解释器，写全路径就行，脚本、任务计划、CI 里都这么写：.venv\Scripts\python.exe main.py。项目根的 .gitignore 加 .venv/ 和 __pycache__/ 两行。

工具 建什么 什么时候用
venv 隔离包目录，共用同一个解释器 日常首选
conda 隔离整个解释器 + 二进制包 科学计算，装不上编译依赖时
pipx 给命令行工具单独建环境 装 black、poetry 这类全局工具

conda 连解释器版本一起锁（conda create -n py311 python=3.11），NumPy、SciPy 这类带 C/Fortran 扩展的包用它装能跳过编译。pipx 处理另一类需求：black、poetry 是命令行工具，装进项目环境切环境就用不了，装全局又怕冲突，pipx 给每个工具单开环境再把可执行文件链到 PATH。

六、语法格式与编码规范 #

Python 用缩进表达代码块，不用花括号。缩进是语法的一部分，不是排版习惯。

python
if 1 < 2:
    print('true')
    print('还在 if 里')
print('出来了')

三条硬规矩：冒号结尾的行下面必须缩进；同一代码块缩进量必须一致；缩进量随意，整个文件统一用 4 个空格。混用空格和 Tab 会报 TabError: inconsistent use of tabs and spaces in indentation，这类错误在编辑器里看不出来，因为 Tab 被渲染成 4 个空格宽，肉眼看齐了、字节不同。把编辑器设成「Tab 键插入空格」，一次解决。一行太长要断，优先用括号：圆括号、方括号、花括号没闭合时语句不算结束，随便断，写法如 total = (1 + 2 + 3 + 4 + 5) 拆成两行；别用反斜杠续行，那是最后手段，后面多一个空格就报语法错。

Python 3 的源码默认 UTF-8，不用写 # -*- coding: utf-8 -*-。那行声明是 Python 2 的遗产，只在文件确实不是 UTF-8 时才必须写。文件存成 GBK 又没声明，解释器按 UTF-8 读，遇到中文直接 SyntaxError: Non-UTF-8 code starting with ...。

注释用 #，从符号到行尾。三引号包起来的第一个语句是文档字符串，存放在 __doc__ 里，help(fn) 能打出来，写「干什么」，不写「怎么干」。命名风格照这张表来：

对象 风格 例子
模块、包 全小写加下划线 data_utils.py
类 大驼峰 HttpClient
函数、变量 小写加下划线 parse_url
常量 全大写加下划线 MAX_RETRY
内部使用 / 特殊方法 单下划线前缀 / 双下划线包裹 _cache / __init__

文档字符串长这样：def area(r): """返回半径为 r 的圆面积。""" return 3.14159 * r * r，三引号写在函数体第一行。

Python 大小写敏感，Name 和 name 是两个东西。中文标识符合法，姓名 = '张三' 能跑，但工具链和队友都会难受。PEP 8 里最该记住的几条：二元运算符两侧各一个空格，但函数默认参数和关键字参数的等号不带空格（def f(a, b=1)）；顶层函数和类之间空两行；import 分三组（标准库、第三方、本地），组内按字母序；别用 l、O、I 当变量名。行宽老标准是 79，现在普遍按 88 或 100。规范靠工具执行，python -m pip install ruff black 之后跑 ruff check . 和 black .，检查与格式化一次到位。

35 个关键字不能用作变量名，True、False、None 同样保留：

类别 关键字
条件循环 if elif else for while break continue pass
定义 def class lambda return yield global nonlocal
异常 try except finally raise assert with
导入 / 逻辑 / 其他 import from as / and or not in is / del async await

pass 是空语句占位用。assert 是调试期校验，python -O 跑时会全部失效，别拿它做业务校验。

七、变量、类型与运算 #

变量不是装数据的盒子，是贴在对象上的名字。a = 1 的意思是「把名字 a 绑到整数对象 1 上」，再执行 a = 2，a 改绑到另一个对象，原来的 1 没人引用就被回收：

python
a = 1
print(id(a))
a = 2
print(id(a))           # 变了，说明是另一个对象
b = a
print(id(a) == id(b))  # True，两个名字指向同一个对象

由此引出一条铁律：给不可变对象「改值」其实是新建对象，给可变对象改内容才是原地改。变量本身没有类型，对象才有，x = 42 之后 x = 'hello' 完全合法。这带来灵活性，也带来一类运行时错误：参数传错类型，只有真跑到那一行才炸。解法是类型标注加 mypy，标注像 def add(a: int, b: int) -> int: 这样写，给人和工具看，运行时不做检查，add('a', 'b') 照样返回 'ab'。Python 是动态类型，同时也是强类型：'1' + 1 直接抛 TypeError，不会偷偷把字符串转成数字。

类型 字面量 可变 可哈希 典型用途
int 42、0xff、1_000 不可变 可 计数、下标
float / bool 3.14、1e-3 / True 不可变 可 测量值 / 判断结果
str / bytes 'abc' / b'abc' 不可变 可 文本 / 二进制
list [1, 2] 可变 不可 有序集合，频繁增删
tuple (1, 2) 不可变 可 定长记录
dict / set {'a': 1} / {1, 2} 可变 不可 键值映射 / 去重
NoneType None 不可变 可 表示「没有值」

int 没有位数上限，2 ** 1000 能算出来，大数运算不溢出。

运算符 含义 例子 结果
+ / * 加、拼接 / 重复 1 + 2、'ab' * 2 3、'abab'
/ 真除法，结果总是 float 7 / 2 3.5
// 向下取整除法 -7 // 2 -4
% 取余 -7 % 2 1

divmod 商和余一起拿 divmod(7, 2) (3, 1)

输入处理与错误检查 #

想判断输入的出生年份在 2000 年之前：

python
birth = input('birth: ')
if birth < 2000:
    print('00前')
else:
    print('00后')

输入 1982，直接报错 TypeError: '<' not supported between instances of 'str' and 'int'：birth 是字符串 '1982'，字符串和整数不能比大小。转成整数再比就对了，但输入 abc 会报 ValueError: invalid literal for int() with base 10: 'abc'。校验得自己加：

python
while True:
    s = input('birth: ')
    if not s.isdigit():
        print('请输入数字')
        continue
    birth = int(s)
    break

print('00前' if birth < 2000 else '00后')

负数、空格、全角数字这几种输入，isdigit() 各有取舍。要求严就用 try 包住转换，见第十六章。

八、字符串与常用方法 #

字符串是不可变序列，'abc'[0] = 'x' 直接报 TypeError，所有「修改」都返回新字符串。四种写法：'single'、"double"、三引号多行、原始字符串 r'C:\Users\liuluhua\Desktop'。单双引号等价，内容里有 ' 就用双引号省掉转义；r 前缀让反斜杠不再是转义符。

方法 作用 例子
len(s) 长度 len('中文') → 2
s.find(x) / s.index(x) 找子串 找不到时 find 返 -1，index 抛异常
s.count(x) / s.replace(a, b) 计数 / 替换，可限次数 'aaa'.replace('a','b',2) → 'bba'
s.split(sep) 切成列表 'a,b'.split(',') → ['a','b']
s.strip() 去两端空白 ' x '.strip() → 'x'
s.startswith(x) / s.endswith(x) 前后缀判断 'a.py'.endswith('.py')
s.join(it) 用 s 连接 '-'.join(['a','b']) → 'a-b'
s.upper() / s.lower() 大小写转换 'Ab'.lower() → 'ab'
s.zfill(n) / s.rjust(n) 补零 / 右对齐 '7'.zfill(3) → '007'
s.isdigit() / s.isalpha() 全数字 / 全字母 输入校验
s.encode() / b.decode() 文本与字节互转 读写文件、发请求

split() 不带参数时按任意空白切，并丢掉连续空白产生的空串：'a b\tc'.split() 得 ['a', 'b', 'c']。join 是它的逆操作，拼接大量字符串用它，比 + 快也省内存。

三种格式化并存，新代码统一用 f-string：

python
name, score = 'Bob', 92.456

print('%s 得分 %.1f' % (name, score))        # % 风格，老代码常见
print('{} 得分 {:.1f}'.format(name, score))  # str.format，适合延迟求值
print(f'{name} 得分 {score:.1f}')            # f-string，3.6 起有

print(f'{score:.2f}')      # 92.46
print(f'{score:>10.2f}')   # 右对齐，总宽 10
print(f'{0.1234:.1%}')     # 12.3%
print(f'{1234567:,}')      # 1,234,567

str 存文本（Unicode 码点），bytes 存字节，靠 encode / decode 转换：

python

print(b, len(b), len(s))    # b'\xe4\xb8\xad\xe6\x96\x87' 6 2
print(b.decode('utf-8'))    # 中文

编码不一致就报 UnicodeDecodeError。碰到不知道编码的文件，用 chardet 探测再解码：

python

raw = open('data.txt', 'rb').read()
text = raw.decode(chardet.detect(raw)['encoding'])

Windows 上还有个坑：open() 不写 encoding 时用系统区域默认编码，中文 Windows 上是 GBK，Linux 上是 UTF-8，同一份代码读同一个文件结果不同。养成显式写 encoding='utf-8' 的习惯。

九、列表、元组、字典与集合 #

容器 语法 有序 可变 元素可重复 查找
list [1, 2] 是 是 是 O(n)
tuple (1, 2) 是 否 是 O(n)
dict {'a': 1} 是（3.7 起保持插入序） 是 键唯一 O(1)
set {1, 2} 否 是 否 O(1)

列表尾部追加是 O(1)，头部插入是 O(n)，append、insert、extend 分别对应加一个、指定位置加、合并另一个可迭代对象：

操作 写法 说明
删除指定值 lst.remove(x) 值不存在抛 ValueError
删指定位置 lst.pop(i) / del lst[i] pop 返回被删的值，默认删最后一个
查找 / 计数 lst.index(x) / lst.count(x)
排序 / 反转 lst.sort(key=..., reverse=True) 原地改，返回 None
浅拷贝 lst.copy() / lst[:] 只复制顶层

排序的 key 收一个函数，按返回值比：

python
words = ['apple', 'Bob', 'cherry']
print(sorted(words))                    # 大写字母排前面
print(sorted(words, key=str.lower))     # 忽略大小写

sort() 原地改、返回 None，sorted() 返回新列表。写成 lst = lst.sort() 会得到 None，这是高频错误。= 只是给同一个列表多起一个名字，b = a; b.append(4) 之后 a 也变了。要独立副本用 a.copy() 或 a[:]，这是浅拷贝，只复制最外层：

python
import copy

a = [[1, 2], [3, 4]]
b = a.copy()
b[0].append(99)
print(a)              # [[1, 2, 99], [3, 4]]，内层被改了

c = copy.deepcopy(a)
c[0].append(100)
print(a)              # 不受影响

元组不可变，适合定长记录和当字典键。x, y = (3, 4) 是解包，(1) 是加括号的整数，单元素元组必须写 (1,)。函数返回多个值用的就是元组：return min(nums), max(nums)，调用方 low, high = min_max(...) 解包。

字典存键值映射，d.get('k', 默认) 键不存在也不抛异常，d['k'] 会抛 KeyError：

操作 写法 说明
删除 d.pop('k', 默认) / d.popitem() popitem 删最后插入的那对
批量更新 d.update(other) 覆盖同名键
遍历 d.items() / d.keys() / d.values() 视图，可迭代
判键存在 'k' in d O(1)，别用 in d.keys()
设默认值 d.setdefault('k', 默认) 键不存在则写入并返回默认值 
python
from collections import Counter

groups = {}
for word in ['apple', 'avocado', 'banana']:
    groups.setdefault(word[0], []).append(word)
print(groups)                                   # {'a': ['apple', 'avocado'], 'b': ['banana']}
print(Counter('abracadabra').most_common(2))    # [('a', 5), ('b', 2)]

字典的键必须可哈希，str、数字、tuple 可以，list、dict、set 不行，用列表当键报 TypeError: unhashable type: 'list'。

集合无序、元素唯一，专治去重和成员判断，remove 不存在抛 KeyError，discard 不报错：

python
print({'python', 'web', 'python'})          # {'python', 'web'}，自动去重
print(list(dict.fromkeys([1, 2, 2, 3])))    # [1, 2, 3]，去重同时保住顺序
print({1, 2} & {2, 3}, {1, 2} - {2, 3})     # {2} {1}，交集与差集

集合的价值在复杂度：判断一个值在不在 10 万个元素里，list 逐个比是 O(n)，set 算一次哈希是 O(1)。爬虫去重、黑白名单匹配这类高频判断，把容器换成 set，耗时能掉几个数量级。set 本身不可哈希，要拿集合当键用 frozenset。同时遍历多个容器用 zip：

python
for i, (n, a) in enumerate(zip(['a', 'b', 'c'], [1, 2, 3]), start=1):
    print(i, n, a)

zip 按最短的那个截断，长度不齐时静默丢数据。要求长度对齐就用 zip(..., strict=True)（3.10 起），不齐抛 ValueError。

十、切片与推导式 #

切片写法 seq[start:stop:step]，三个位置都能省，含头不含尾：

python
s = 'abcdefgh'

print(s[2:5])      # cde
print(s[:3])       # abc
print(s[-3:])      # fgh，负数从尾部数
print(s[::2])      # aceg，步长 2
print(s[::-1])     # hgfedcba，步长 -1 就是反转
print(s[0:100])    # abcdefgh，越界不报错
print(s[100])      # IndexError，取单个元素才报

含头不含尾好处很实在：s[:i] 加 s[i:] 拼起来正好等于 s，不用减一。切片还能赋值和删除，这是列表专有的：

python
nums = [0, 1, 2, 3, 4, 5]
nums[1:3] = ['a', 'b', 'c']    # 替换，长度可以不等
print(nums)                     # [0, 'a', 'b', 'c', 3, 4, 5]

del nums[::2]                   # 按步长删除
print(nums)                     # ['a', 'c', 4]

推导式把「建空容器 + 循环 + append」三步压成一行。最常用的是列表推导，方括号开头；集合推导、字典推导只是换了外层的括号：

python
squares = [x * x for x in range(10)]
print(squares)     # [0, 1, 4, 9, 16, 25, 36, 49, 64, 81]

evens = [x for x in range(20) if x % 2 == 0]              # 加过滤
labels = ['偶' if x % 2 == 0 else '奇' for x in range(5)]   # 加条件表达式

嵌套循环顺序和手写 for 一致；四种推导式只差外面的括号：

python
pairs = [(x, y) for x in range(2) for y in range(2)]
flat = [n for row in [[1, 2], [3, 4]] for n in row]   # [1, 2, 3, 4]

lst = [x * 2 for x in range(3)]          # 列表，立即求值
st = {x % 3 for x in range(6)}           # 集合，自动去重
d = {x: x * 2 for x in range(3)}         # 字典，冒号前是键

字典推导也常用来过滤，键冲突时后者覆盖前者：

python
scores = {'a': 91, 'b': 58, 'c': 77}
print({k: v for k, v in scores.items() if v >= 60})   # {'a': 91, 'c': 77}
print({x % 2: x for x in range(5)})                   # {0: 4, 1: 3}

读起来超过一行就该换回普通循环。推导式里塞三层 for 加两个 if，压行不是目的。

十一、流程控制：条件与循环 #

条件判断靠缩进划分代码块，条件后面必须带冒号。从上往下判断，命中一个为真的分支就执行对应代码块，后面的全部跳过，所以范围窄的条件放前面：

python
if condition1:
    action1
elif condition2:
    action2
else:
    action3

3.10 起了 match 语句，按模式匹配，比一长串 elif 清楚：

python
def handle(cmd):
    match cmd.split():
        case ['go', direction]:
            return f'往 {direction}'
        case ['quit']:
            return '退出'
        case _:
            return '未知'

for...in 遍历可迭代对象，比 C 的计数循环好写：

python
for name in ['Michael', 'Bob', 'Tracy']:
    print(name)

total = 0
for x in range(1, 101):
    total += x
print(total)              # 5050
print(sum(range(101)))    # 5050，内置函数一行搞定

range(start, stop, step) 左闭右开，range(5) 是 0..4，range(1, 10, 2) 是 1,3,5,7,9。它返回惰性序列，list(range(5)) 才转成列表。while 在条件为真时反复执行：

python
total = 0
n = 99
while n > 0:
    total += n
    n -= 2
print(total)      # 2500，99 以内奇数之和

遍历时改列表会出问题，删元素、加元素都会让迭代器错位。正确做法是遍历副本，或者重建列表：

python
nums = [1, 2, 3, 4, 5]
for n in nums[:]:          # 遍历切片副本
    if n % 2 == 0:
        nums.remove(n)
print(nums)                # [1, 3, 5]

nums = [n for n in [1, 2, 3, 4, 5] if n % 2 == 1]    # 或者干脆重建

break 立即结束整个循环，continue 跳过本轮剩下的语句进入下一轮，else 挂在循环上表示「循环正常跑完没被 break」：

python
for n in range(2, 10):
    if n % 7 == 0:
        print(f'{n} 能被 7 整除')
        break
else:
    print('没找到')

pass 是空语句，写个还没实现的函数体、if 里暂时什么都不做，都得放它，否则缩进块为空报 IndentationError。

十二、函数：定义、参数与作用域 #

def 定义函数，return 返回值，没写 return 的函数返回 None。函数是一等对象：能赋给变量、能当参数传、能当返回值、能放进容器。

python
def add(a, b):
    """返回两数之和。"""
    return a + b


print(add(1, 2))      # 3
参数形式 写法 说明
位置参数 def f(a, b) 按顺序传
关键字参数 f(a=1, b=2) 按名字传，顺序随意
默认参数 def f(a, b=10) 默认值必须在非默认值后面
可变位置参数 def f(*args) 收成元组
可变关键字参数 def f(**kwargs) 收成字典

星号在定义时是「收集」，在调用时是「拆开」，同一个符号两种用法：

python
def show(a, b=2, *args, **kwargs):
    print(a, b, args, kwargs)


show(1)                          # 1 2 () {}
show(1, 3, 5, 7, x=9)            # 1 3 (5, 7) {'x': 9}
show(*[1, 3], **{'x': 9})        # 列表和字典也能拆开传

默认参数只在定义时求值一次，这是最阴的一个坑。默认值在 def 执行时算好并绑在函数对象上，每次调用用的都是同一个列表，拿 None 当哨兵才安全：

python
def bad(item, box=[]):        # 错：默认列表被所有调用共享
    box.append(item)
    return box


print(bad(1), bad(2))         # [1, 2] [1, 2]，第二次把第一次的结果带上了


def good(item, box=None):
    if box is None:
        box = []
    box.append(item)
    return box

返回多个值就返回元组，调用方解包：q, r = divmod(7, 2) 得 3 1。

作用域按 LEGB 顺序找名字：Local（函数内）→ Enclosing（外层函数）→ Global（模块级）→ Builtin（内置）。内层函数读外层变量，拿到的是外层那个；在函数内给名字赋值，这个名字在整个函数内就算局部变量，哪怕赋值语句在后面：

python
x = 'global'


def outer():
    x = 'enclosing'

    def inner():
        print(x)      # enclosing，外层函数优先于全局

    inner()


outer()

要改全局变量得 global 声明，改外层函数变量用 nonlocal；能不用就不用，到处改外部状态，函数就不再可预测：

python
counter = 0


def inc():
    global counter
    counter += 1


def make_counter():
    n = 0

    def step():
        nonlocal n
        n += 1
        return n

    return step

递归必须有两样东西：终止条件、规模缩小。Python 没有尾调用优化，默认递归上限 1000 层（sys.getrecursionlimit()），超了报 RecursionError；层数深的逻辑改写成循环加显式栈，别去调 setrecursionlimit，那会真的把 C 栈撑爆。

python
def fact(n):
    if n <= 1:            # 终止条件
        return 1
    return n * fact(n - 1)


print(fact(5))    # 120

十三、lambda 与函数式工具 #

lambda 定义一个没有名字的单表达式函数，函数体只能是一个表达式，不能有语句、不能写 return：

python
square = lambda x: x * x
print(square(5))                     # 25
print((lambda a, b: a + b)(1, 2))    # 3

它的价值不在「短」，在于「就地传一个用完就丢的函数」，最典型是排序的 key：

python
rows = [('b', 2), ('a', 3), ('c', 1)]
print(sorted(rows, key=lambda r: r[1]))           # 按第二列
print(sorted(rows, key=lambda r: (-r[1], r[0])))  # 多级排序

多级排序那条用元组当 key：先按第二列降序，相同再按第一列升序。给 lambda 起名字是反模式，square = lambda x: x * x 不如 def square(x): return x * x，后者在报错信息和 help() 里都有名字。

map(f, iterable) 把 f 应用到每个元素，返回迭代器：

python
def f(x):
    return x * x


r = map(f, [1, 2, 3, 4, 5, 6])
print(r)              # <map object at 0x...>，打印出来是个对象
print(list(r))        # [1, 4, 9, 16, 25, 36]
print(list(r))        # []，迭代器已经被耗尽

返回的是迭代器不是列表，这是新手第一困惑点：print(r) 看到的是一串地址，得用 list()、for 或 next() 取，手动取到尾部靠 StopIteration 收尾。迭代器只能走一遍，走完就空了，要重复用就存成列表。

filter(f, iterable) 按 f 的返回值筛，也返回迭代器；f 传 None 时按元素真值筛，顺手能去掉空值：

python
print(list(filter(lambda n: n % 2 == 1, range(10))))         # [1, 3, 5, 7, 9]
print(list(filter(None, [0, 1, '', 'a', None, [], [1]])))    # [1, 'a', [1]]

reduce(f, iterable, init) 用一个二元函数把序列折成一个值，在 functools 里：

python
from functools import reduce

print(reduce(lambda x, y: x * y, [1, 2, 3, 4]))         # 24
print(reduce(lambda x, y: x + y, [1, 2, 3, 4, 5]))      # 15

计算过程是滚雪球，reduce(f, [x1, x2, x3, x4]) 等于 f(f(f(x1, x2), x3), x4)：以 [1, 2, 3, 4] 乘为例，f(1,2)=2，f(2,3)=6，f(6,4)=24。传了 init 就从 init 和第一个元素开始算，空序列没 init 会抛 TypeError。同一个活，推导式和 sum 更直接：

python
print([x * x for x in range(1, 7)])       # 比 list(map(f, ...)) 清楚
print(sum(x * x for x in range(1, 7)))    # 比 reduce 清楚

真要写函数式风格，先看有没有现成的聚合函数：sum、min、max、any、all、sorted，它们都在 C 层实现，比 map + reduce 快。

十四、生成器与迭代器 #

可迭代对象是能 for 的东西，迭代器是真正在走的那个把手。实现了 __iter__ 就是可迭代的，同时实现 __next__ 才是迭代器。for 的底层动作是拿 iter() 换出迭代器，反复 next()，靠 StopIteration 知道该停了。生成器函数用 yield 而不是 return，调用时不执行函数体，只返回一个生成器对象：

python
def countdown(n):
    while n > 0:
        yield n
        n -= 1


print(countdown(3))            # <generator object countdown at 0x...>
for i in countdown(3):
    print(i)                   # 3 2 1

执行到 yield 就暂停，把值交出去，下次 next 从暂停的地方接着走，局部变量全保留。这就是「懒」的来源：不取就不算。生成器表达式是把推导式的方括号换成圆括号，在函数调用里当唯一参数时还能省掉那层括号：

python
g = (x * x for x in range(5))
print(next(g))      # 0
print(list(g))      # [1, 4, 9, 16]，第一个已经被取走了

print(sum(x * x for x in range(1000000)))    # 一行算完，内存几乎不涨
方式 内存 首次出结果 能重复遍历
列表 [x for x in ...] 全部元素 等全部算完 能
生成器 (x for x in ...) 一次一个 立刻 不能

读 10GB 的日志文件，readlines() 一次把文件塞进内存，四五个 G 的机器直接被打死；逐行迭代就是流式的，内存只占一行。这就是生成器的全部价值：把「先造完再用」改成「边造边用」。

两个陷阱。生成器只能走一遍，第二遍拿到空列表；生成器里 return 的值只能从异常对象里取：

python
g = (x for x in range(3))
print(list(g), list(g))    # [0, 1, 2] []


def gen():
    yield 1
    return 'done'


g = gen()
print(next(g))     # 1
try:
    next(g)
except StopIteration as e:
    print(e.value)  # done

要多次遍历，就存成列表，或者把生成器做成函数，每次调用重新生成。send() 可以往生成器里送值，throw() 往里抛异常，close() 让它提前结束，这套机制是协程的原型，async / await 就是从它长出来的。判断一个对象能不能 for，用 collections.abc 的类型：

python
from collections.abc import Iterable, Iterator

print(isinstance([1, 2], Iterable))            # True
print(isinstance([1, 2], Iterator))            # False，列表不是迭代器
print(isinstance(iter([1, 2]), Iterator))      # True

十五、文件操作 #

读文本文件用 with，代码块结束时自动关闭，不用记得写 close()。encoding='utf-8' 别省，它决定跨平台行为：

python
with open('data.txt', 'r', encoding='utf-8') as f:
    for line in f:               # 逐行迭代，大文件用这个
        print(line.rstrip())

with open('data.txt', 'r', encoding='utf-8') as f:
    text = f.read()              # 一次读完，只适合小文件
模式 含义 文件不存在时 有内容时
'r' 只读 抛 FileNotFoundError 从头发
'w' 只写 新建 清空
'a' 追加 新建 从尾写
'x' 独占新建 新建 抛 FileExistsError
'b' 二进制，与其他组合 按上面 按上面

二进制用 'rb' / 'wb'，读出来是 bytes，不经过编码转换，图片、压缩包、序列化数据都走这条：

python
with open('out.txt', 'w', encoding='utf-8') as f:
    f.write('第一行\n')
    f.writelines(['第二行\n', '第三行\n'])

with open('logo.png', 'rb') as f:
    print(f.read(8))       # b'\x89PNG\r\n\x1a\n'

pathlib 与目录操作 #

路径拼接别用字符串 +，Windows 上是 \、Linux 上是 /，拼错了在另一台机器上就找不到文件。pathlib 统一处理，它还自带常用操作：

python
from pathlib import Path

p = Path('C:/Users/liuluhua/Desktop') / 'data' / 'a.txt'
print(p.exists(), p.suffix, p.stem, p.name, p.parent)

Path('d').mkdir(parents=True, exist_ok=True)      # 建目录
Path('a.txt').read_text(encoding='utf-8')         # 直接读文本
Path('a.txt').unlink()                            # 删文件
list(Path('.').glob('*.py'))                      # 列目录 / 匹配

要递归删非空目录用 shutil.rmtree，这条命令不可撤销，路径先 resolve() 打出来确认一遍。

序列化 #

把对象存成文件再读回来，最通用的是 JSON，只支持基本类型（dict、list、str、数字、bool、None）：

python
import json

data = {'name': '张三', 'age': 30, 'tags': ['a', 'b']}

with open('cfg.json', 'w', encoding='utf-8') as f:
    json.dump(data, f, ensure_ascii=False, indent=2)

with open('cfg.json', 'r', encoding='utf-8') as f:
    print(json.load(f) == data)     # True

ensure_ascii=False 让中文原样写出，不转成 \u5f20 这种形式；不写文件的版本是 json.dumps() / json.loads()。处理日期、集合、自定义类会报 TypeError: Object of type datetime is not JSON serializable，写一个 default 函数转换：

python
import datetime
import json


def encode(o):
    if isinstance(o, (datetime.datetime, datetime.date)):
        return o.isoformat()
    if isinstance(o, set):
        return sorted(o)
    raise TypeError(f'不支持的类型: {type(o)}')


print(json.dumps({'t': datetime.date(2026, 11, 17)}, default=encode))

需要保真还原任意 Python 对象时用 pickle，但它不安全：反序列化会执行任意代码，只能读自己生成的文件。CSV 用标准库 csv，别自己 split(',')，引号、逗号、换行都会让手写解析出错：

python
import csv

with open('rows.csv', 'w', newline='', encoding='utf-8-sig') as f:
    w = csv.writer(f)
    w.writerow(['姓名', '分数'])
    w.writerow(['张三', 92])

newline='' 必须加，否则 Windows 上会多出空行；编码用 utf-8-sig 带 BOM，Excel 直接打开不乱码。读用 csv.DictReader，行变成字典。

十六、异常处理 #

程序出错时抛异常，不处理就一路向上冒，最后打印 traceback 并退出。try / except 接住它，让程序继续走：

python
try:
    birth = int(input('birth: '))
except ValueError:
    print('输入的不是数字')
else:
    print('00前' if birth < 2000 else '00后')
finally:
    print('无论成败都执行')

四个块的职责：try 里放会出错的语句；except 按异常类型接，一次接多种写元组 (ValueError, TypeError)；else 在没出错时执行；finally 一定执行，用来放清理动作。

except Exception 能接住几乎所有运行时错误，但别一上来就这么写。它把「文件不存在」和「算错了」混成一类，出了问题连排错方向都没有。先接具体类型，兜底留到最后一行。raise 主动抛出，raise ... from e 保留原始异常链：

python
def parse_port(s):
    try:
        port = int(s)
    except ValueError as e:
        raise ValueError(f'端口必须是整数：{s}') from e
    if not 0 < port < 65536:
        raise ValueError(f'端口超出范围：{port}')
    return port

自定义异常继承 Exception 就够，业务异常单独建类，调用方才能精确捕获。finally 和 with 的分工：with 是自动清理的标准写法，finally 留给 with 管不了的东西。只处理你预期的错误，其他让它冒出来，吞掉异常是排错的最大障碍：

python
try:
    do_something()
except Exception:
    pass      # 错：出什么事都不知道，线上只能靠猜

traceback 要打就看完整的，traceback.format_exc() 拿到字符串，适合写日志；except ... as e 里的 e 直接用 print 只给一行，信息量不够。

方向三：数据库 #

后端绕不开三种库，选型先看数据形状：关系型的 SQLite、MySQL 适合结构固定要事务的场景，文档型的 MongoDB 适合字段不固定、嵌套结构，内存型的 Redis 适合缓存、计数器、队列。SQLite 是标准库自带的，零配置，学习和原型首选：

python
import sqlite3

conn = sqlite3.connect('demo.db')
cur = conn.cursor()
cur.execute('CREATE TABLE IF NOT EXISTS t (id INTEGER PRIMARY KEY, name TEXT)')
cur.execute('INSERT INTO t (name) VALUES (?)', ('张三',))    # 参数化，别拼字符串
conn.commit()
print(cur.execute('SELECT * FROM t').fetchall())
conn.close()

SQL 里拼字符串会打开注入的口子，永远用 ? 占位符传参。MySQL 用 PyMySQL 或 mysqlclient，MongoDB 用 PyMongo（接近 shell 的原始接口）或 MongoEngine（对象映射），Redis 用 redis-py。

十八、易错点速查 #

现象 原因 改法
TypeError: can only concatenate str 把 input() 的结果当数字用 先 int() / float() 转换
SyntaxError: Non-UTF-8 code 文件不是 UTF-8 又没声明编码 统一存 UTF-8
TabError: inconsistent use of tabs 空格与 Tab 混用 编辑器设成 Tab 插入空格
UnboundLocalError 函数内赋值让名字变成本地变量 用 global / nonlocal，或改名
默认参数里的列表被复用 默认值只在定义时求值一次 默认写 None，函数内再建
lst = lst.sort() 得到 None sort 原地改并返回 None 用 sorted() 或分两行写
改了副本却改到了原列表 = 是引用，浅拷贝也只复制顶层 用 copy.deepcopy()
(1) 不是元组 单元素元组要带逗号 写 (1,)
KeyError 直接下标取了一个不存在的键 用 d.get(k, 默认)
TypeError: unhashable type: 'list' 拿可变对象当字典键或集合元素 转成 tuple
循环里 remove 漏删元素 边遍历边改容器，迭代器错位 遍历副本或重建列表
map 打印出来是地址 返回的是迭代器不是列表 list(...) 包一层
第二次遍历生成器为空 迭代器只能走一遍 存成列表或重新生成
FileNotFoundError 相对路径按当前工作目录解析 用 Path(__file__).parent 定位
读文件中文乱码 open() 没写 encoding 显式写 encoding='utf-8'
CSV 乱码或多空行 编码与换行参数没设对 utf-8-sig + newline=''
装包成功但 import 失败 装进了另一个解释器 python -m pip install
自己的 random.py 盖掉标准库 脚本目录在 sys.path 第一位 改名，别撞标准库
pip 下载卡住 走的是境外官方源 换国内镜像，见第四章
pip 报 not a trusted host 镜像走 HTTP 或证书不被信任 加 --trusted-host
ModuleNotFoundError 换机器就出现 依赖没写进清单 pip freeze > requirements.txt
