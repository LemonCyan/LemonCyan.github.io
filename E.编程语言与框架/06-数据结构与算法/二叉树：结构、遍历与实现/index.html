一、树的基本术语 #

树是 n（n≥0）个结点的有限集，n=0 叫空树。非空树满足两条：有且仅有一个特定的结点叫根（root）；n>1 时，其余结点分成 m（m>0）个互不相交的有限集 T1、T2……Tm，每个集合本身又是一棵树，叫根的子树（subtree）。

两条都是硬条件。根只能有一个；子树之间不能相交，一个结点不会同时挂在两个父结点下面。

树是非线性结构：结点可以有零个或多个直接后继（子结点），至多一个直接前驱（父结点）。根没有前驱，叶结点没有后继。线性表一前一后，树一父多子。

术语 定义 判据
结点的度 该结点拥有的子树个数 数孩子，不是数全部后代
叶结点 度为 0 的结点 左右指针都为空
内部结点 度不为 0、且不是根的结点 有孩子，头上还有人
树的度 所有结点的度的最大值 扫一遍取最大
孩子 / 双亲 子树的根是孩子，本结点是双亲 一条边两端的两个称呼
兄弟 同一个双亲的孩子 共用一个父结点
层次 根为第 1 层，往下逐层加一 边数 + 1
深度 / 高度 结点层次的最大值 从根到最远叶子的边数 + 1
路径长度 从根到某结点经过的边数 层数 - 1
有序树 子树从左到右有次序、不能互换 交换子树算另一棵树
森林 m（m≥0）棵互不相交的树的集合 砍掉根剩下的部分

拿一棵具体的树把词数一遍：

text
            A
          / | \
         B  C  D
        / \    |
       E   F   G

A 的度 3，B 的度 2，C 的度 0，D 的度 1，E、F、G 的度 0。树的度是 3。叶结点 C、E、F、G 共 4 个，内部结点 A、B、D 共 3 个。深度 3。从根到 G 的路径长度 2。这棵是有序树，把 B 和 C 换个位置就是另一棵树。

维度 线性表 树
结构 一对一 一对多
首元素 有后继，无前驱 根结点无前驱
末元素 有前驱，无后继 叶结点无后继
中间元素 一前一后 一个父结点，多个孩子
遍历 一条路走到底 先序 / 中序 / 后序 / 层序

二、树的表示方法 #

一个结点有几个孩子事先不知道，struct 里写不出不定长成员。三条路，各砍一刀。

双亲表示法 #

c
#define MAX_TREE_SIZE 100
typedef struct {
    char data;
    int  parent;          /* 双亲下标，根记 -1 */
} PTNode;
typedef struct {
    PTNode nodes[MAX_TREE_SIZE];
    int    n;
} PTree;

查双亲 O(1)，查孩子 O(n)。往上找用得多的场景选它，并查集就是这条路。

孩子表示法 #

c
typedef struct CNode {
    int child;                /* 孩子在数组中的下标 */
    struct CNode *next;
} CNode;
typedef struct {
    char   data;
    CNode *firstchild;        /* 孩子链表头 */
} CTBox;

查孩子 O(度)，查双亲还得扫全表。两个表示法拼一起就是双亲孩子表示法，两个方向都能查，代价是存储翻倍。

孩子兄弟表示法 #

c
typedef struct CSNode {
    char data;
    struct CSNode *firstchild;    /* 第一个孩子 */
    struct CSNode *nextsibling;   /* 右边的下一个兄弟 */
} CSNode, *CSTree;

firstchild 改名 lchild，nextsibling 改名 rchild，就是二叉链表。所以有一条定理：任意一棵树都可以完全等价地转成一棵二叉树。

转换三步：兄弟之间加线；每个结点只保留与第一个孩子的连线，其余父子线抹掉；以根为轴顺时针转 45 度。转完原树的第一个孩子成了左孩子，下一个兄弟成了右孩子。根没有兄弟，所以转换后的二叉树根一定没有右子树。

表示法 每个结点存什么 查孩子 查双亲 典型用途
双亲 数据 + 双亲下标 O(n) O(1) 并查集、往上找
孩子 数据 + 孩子链表头 O(度) O(n) 往下找孩子
孩子兄弟 数据 + 第一个孩子 + 下一个兄弟 O(度) O(n) 树转二叉树

三、二叉树：每个结点最多两个分支 #

二叉树是 n（n≥0）个结点的有限集合，或为空集（空二叉树），或由一个根结点和两棵互不相交的、分别叫根结点左子树和右子树的二叉树组成。

三条特点：

  1. 每个结点最多两棵子树，不存在度大于 2 的结点。是「最多有」不是「只有」，可以 0 棵、可以 1 棵。
  2. 左子树和右子树有序，不能颠倒。
  3. 只有一个子树时，也要说清是左还是右。

第 3 条是二叉树和「度最大为 2 的有序树」的分界线，后者允许单个孩子不分左右。

高频判断题：「二叉树是度为 2 的有序树」——错。二叉树可以是空集，度可以小于 2；「度为 2」要求每个结点恰好两个孩子。

二叉树的价值在递归定义：左右子树都是二叉树。这句话直接决定代码形状——处理一棵树，等于处理根，再处理左右子树。三种遍历、建树、求深度全是这个套路。

四、二叉树的五种形态 #

text
  (1) 空        (2) 单根        (3) 只有左      (4) 只有右      (5) 左右都有
    ∅             A               A               A               A
                                   /                 \             / \
                                  B                   B           B   C
  1. 空二叉树。
  2. 只有一个根结点。
  3. 根只有左子树。
  4. 根只有右子树。
  5. 根左右子树都有。

第 3 和第 4 是两棵不同的二叉树，结点数一样、结构像镜像，但在二叉树里不能互相顶替，因为左右有序。

形态 3 和 4 往下延伸就是单支树：每个结点最多一个孩子，整棵树退化成一条链。n 个结点深度 n，查找插入全部退化到链表水平。这是二叉树最差的样子，也是平衡树要解决的——把深度压回 O(log n)。

形态 5 往下铺，第 i 层最多 2^(i-1) 个结点。这条上限下一章算。

五、满二叉树与完全二叉树 #

满二叉树 #

所有分支结点都有左、右子树，所有叶子都在同一层。

text
            1
          /   \
         2     3
        / \   / \
       4   5 6   7
  1. 叶子只能在最下面一层。
  2. 非叶子结点的度一定是 2。
  3. 同样深度下结点最多、叶子最多：2^k - 1 个结点，叶子 2^(k-1) 个。

完全二叉树 #

对 n 个结点按层序编号：根是 1，从左到右逐层往下。若编号 i（1≤i≤n）的结点与同深度满二叉树中编号 i 的结点位置完全相同，它就是完全二叉树。

大白话：从上到下、从左到右一层层铺，中间不许断，只允许最后缺几个。

text
        1               1
      /   \           /   \
     2     3         2     3
    / \   / \       / \     \
   4   5 6   7     4   5     6
  /
 8
   完全，不是满        非完全：6 号空着，7 号却有结点

特点：

  1. 叶子只出现在最下两层。
  2. 最下层叶子集中在左部连续位置。
  3. 倒数第二层若有叶子，集中在右部连续位置。
  4. 度为 1 的结点只有左孩子，不存在只有右孩子的情况。
  5. 同样结点数下深度最小。

第 4 条最容易漏。完全二叉树里度为 1 的结点最多一个：编号 i 有右孩子就必有左孩子，真出现只有一个孩子的结点，它只能是本层最后一个带孩子的，后面不会再来第二个。

判定走层序，见过第一个空孩子之后不许再出现孩子。代码用到第七章的 bitree_t 和 MAXN，先看逻辑：

c
int IsComplete(bitree_t *r)
{
    bitree_t *q[MAXN];
    int front = 0, rear = 0, flag = 0;

    if (r == NULL)
        return 1;
    q[rear++] = r;

    while (front < rear) {
        bitree_t *p = q[front++];

        if (p->lchild) {
            if (flag) return 0;
            q[rear++] = p->lchild;
        } else flag = 1;

        if (p->rchild) {
            if (flag) return 0;
            q[rear++] = p->rchild;
        } else flag = 1;
    }

    return 1;
}

flag 一置位，后面再挂孩子立刻判死。

维度 满二叉树 完全二叉树
定义 每层铺满，叶子全在最下层 与同深度满二叉树前 n 个编号位置对应
叶子位置 只能在最下层 只能在最下两层
非叶结点 度一定是 2 度可为 1，最多 1 个，且只有左孩子
深度 k 的结点数 恰好 2^k - 1 2^(k-1) ≤ n ≤ 2^k - 1
包含关系 一定是完全二叉树 不一定是满的
顺序存储 不浪费 不浪费

一句话：满二叉树一定是完全二叉树，完全二叉树不一定是满的。

六、二叉树的性质 #

性质 1 #

第 i 层至多有 2^(i-1) 个结点（i≥1）。第 1 层是根，2^0 = 1，每个结点最多两个孩子，往下翻倍。

性质 2 #

深度为 k 的二叉树至多有 2^k - 1 个结点（k≥1）。逐层上限相加：2^0 + 2^1 + …… + 2^(k-1) = 2^k - 1。

是 2^k - 1，不是 2^(k-1)。深度 3 最多 7 个，不是 4 个。下界补一句：深度 k 至少 k 个结点，就是那条单支链。

性质 3 #

叶子结点数 n0、度为 2 的结点数 n2，满足：

text
n0 = n2 + 1

推导只用一次数边。设度为 0、1、2 的结点数为 n0、n1、n2：

text
结点总数        n = n0 + n1 + n2
边的总数        E = n - 1          （除根外每个结点对应一条入边）
换个方向数边    E = n1 + 2 * n2    （度为 1 伸 1 条，度为 2 伸 2 条）
联立            n0 + n1 + n2 - 1 = n1 + 2 * n2
                n0 = n2 + 1

用法：知道叶子数能算度为 2 的结点数，反过来也行；配上结点总数能把 n1 也逼出来。

性质 4 #

n 个结点的完全二叉树深度 k = ⌊log2 n⌋ + 1。

完全二叉树前 k-1 层是满的，共 2^(k-1) - 1 个，第 k 层至少还有 1 个：

text
2^(k-1) - 1 < n ≤ 2^k - 1
2^(k-1) ≤ n < 2^k

取以 2 为底的对数，k-1 ≤ log2 n < k，得 k = ⌊log2 n⌋ + 1。

性质 5 #

n 个结点的完全二叉树按层序从 1 编号，编号 i 的结点：

  1. i > 1 时双亲是 ⌊i/2⌋；i = 1 是根，没有双亲。
  2. 2i ≤ n 时左孩子是 2i，否则没有左孩子。
  3. 2i + 1 ≤ n 时右孩子是 2i + 1，否则没有右孩子。
  4. i 所在层次是 ⌊log2 i⌋ + 1。

这四条把结构关系翻译成下标运算，是顺序存储的全部依据。

一条顺手的推论 #

n 个结点的二叉链表，空指针域有 n + 1 个。n 个结点共 2n 个指针域，其中 n - 1 个指向孩子，2n - (n - 1) = n + 1 个空着。线索二叉树就是拿这些空域存前驱后继。

编号 内容 常见变形
性质 1 第 i 层至多 2^(i-1) 个 第 i 层至少 1 个
性质 2 深度 k 至多 2^k - 1 个 至少 k 个；满树恰好 2^k - 1
性质 3 n0 = n2 + 1 配 n0 + n1 + n2 = n 求全部
性质 4 k = ⌊log2 n⌋ + 1 由 n 反推深度，或由深度定 n 的范围
性质 5 双亲 ⌊i/2⌋，左 2i，右 2i+1 顺序存储的全部下标运算
推论 空指针域 n + 1 个 线索二叉树

两道题算一遍 #

题一：10 个度为 2 的结点、5 个度为 1 的结点。n0 = 10 + 1 = 11，总数 n = 11 + 5 + 10 = 26。

题二：完全二叉树 1000 个结点求叶子数。n1 只能是 0 或 1，n = 1000 是偶数说明 n1 = 1。n0 + n2 = 999，又 n0 = n2 + 1，两式相加 2 * n2 + 1 = 999，n2 = 499，n0 = 500。深度是 ⌊log2 1000⌋ + 1 = 10。

七、顺序存储与链式存储 #

二叉树在内存里没有形状，只能靠结构模拟双亲与孩子的关系。三种存法：顺序存储、二叉链表、三叉链表。

顺序存储 #

完全二叉树按层序编号，编号与下标一一对应，逻辑关系全靠下标算，不用指针。n 个结点开 n + 1 的数组，下标 0 空置。性质 5 那三条直接当函数用：

c
#define MAXN 100
typedef char data_t;

data_t SqTree[MAXN];    /* SqTree[1] 是根，SqTree[0] 空置 */
int    SqN;             /* 结点个数 */

int Parent(int i) { return i / 2; }
int LChild(int i) { return 2 * i <= SqN ? 2 * i : 0; }
int RChild(int i) { return 2 * i + 1 <= SqN ? 2 * i + 1 : 0; }

非完全二叉树补虚结点，硬凑成完全二叉树，补出来的位置数据留空。实例，4 个结点：

text
        A
       / \
      B   C
           \
            D

层序编号：A 是 1，B 是 2，C 是 3，B 没孩子所以 4、5 空着，D 是 C 的右孩子落在 7 号，6 号空着。数组长这样：

c
data_t a[] = {0, 'A', 'B', 'C', 0, 0, 0, 'D'};   /* 下标 0~7，n = 7 */

7 个格子装 4 个结点，浪费 3 个。极端情况是右斜树：深度 k、k 个结点，按编号要占到 2^k - 1 号位，数组得开 2^k - 1 格。k = 10 时，10 个结点占 1023 格。

所以顺序存储只用于完全二叉树，或者本身接近完全的树，别拿它存稀疏的树。

二叉链表 #

c
/* data_t 在上一段已经 typedef 过，这里只给结点结构 */
typedef struct node_t {
    data_t data;
    struct node_t *lchild;
    struct node_t *rchild;
} bitree_t;

n 个结点用 n 个存储单元，2n 个指针域里 n - 1 个有用、n + 1 个空。空间随结点数线性增长，不受形状影响。后面所有代码都用这套结构。

三叉链表 #

c
typedef struct tnode_t {
    data_t data;
    struct tnode_t *lchild;
    struct tnode_t *rchild;
    struct tnode_t *parent;    /* 指向双亲，根为 NULL */
} tbitree_t;

找双亲从 O(n) 变 O(1)，代价是每个结点多一个指针，建树、插入、删除都要顺手维护 parent，漏一次就是脏指针。

维度 顺序存储 二叉链表 三叉链表
存储单元 数组，下标 1 起 数据 + 2 指针 数据 + 3 指针
找左孩子 O(1)，2i O(1) O(1)
找双亲 O(1)，⌊i/2⌋ O(n) O(1)
空间 完全树无浪费，稀疏树浪费大 恰好 n 个结点 多 n 个指针
插入删除 整体挪动 改指针 改指针并修 parent
适用 完全二叉树、堆 通用 频繁往上找

八、二叉树的创建 #

建树三条路：从顺序数组搬、从遍历序列读、手工拼。三条路最后都做同一件事：给 data 赋值，给 lchild、rchild 赋指针或 NULL。

从顺序数组建 #

思路来自性质 5：编号 i 的结点，左孩子在 2i，右孩子在 2i+1。

c
/* a[0] 空置，a[1..n] 按层序编号；0 表示虚结点 */
bitree_t *CreateByArray(int i, const data_t a[], int n)
{
    bitree_t *root;

    if (i > n || a[i] == 0)
        return NULL;

    root = (bitree_t *)malloc(sizeof(bitree_t));
    if (root == NULL)
        return NULL;

    root->data   = a[i];
    root->lchild = CreateByArray(2 * i, a, n);
    root->rchild = CreateByArray(2 * i + 1, a, n);

    return root;
}

把第七章那棵 4 结点的树喂进去：

c
data_t a[] = {0, 'A', 'B', 'C', 0, 0, 0, 'D'};
int n = sizeof(a) / sizeof(a[0]) - 1;      /* n = 7 */
bitree_t *t = CreateByArray(1, a, n);

展开看一轮：i=1 建 A，去左 i=2 建 B；B 的左 i=4 是 0，返回 NULL；B 的右 i=5 是 0，返回 NULL；回到 A 去右 i=3 建 C；C 的左 i=6 是 0；C 的右 i=7 建 D；D 的左右 i=14、i=15 都超过 n。虚结点的判断全压在函数开头那句 if (i > n || a[i] == 0) 里。

从扩展前序序列建 #

给每个空指针位置补一个虚结点，记 #，得到扩展二叉树，走一遍就得到扩展序列。

树乙原样与补完的样子：

text
        A                 A
       / \               /   \
      B   C             B     C
       \               / \   / \
        D             #   D #   #
                         / \
                        #   #

前序走一遍，空的地方输出 #，得到 AB#D##C##，9 个字符对应 4 个结点加 5 个空指针。同一棵树，中序扩展序列是 #B#D#A#C#，后序扩展序列是 ###DB##CA。三个序列都能手算，用来验算自己写没写对。

建树只用前序这一版：

c
/* 按扩展前序序列建树，'#' 表示空，pp 指向当前读到的位置 */
bitree_t *CreateByExt(const char **pp)
{
    char c = **pp;
    bitree_t *root;

    if (c == '\0')
        return NULL;

    (*pp)++;                    /* 吃掉一个字符 */

    if (c == '#')
        return NULL;

    root = (bitree_t *)malloc(sizeof(bitree_t));
    if (root == NULL)
        return NULL;

    root->data   = c;
    root->lchild = CreateByExt(pp);
    root->rchild = CreateByExt(pp);

    return root;
}

c
const char *s = "AB#D##C##";
bitree_t *t = CreateByExt(&s);

跑一遍，九步：

步 读到 动作 回填
1 A 建 A，递归左 —
2 B 建 B，递归左 —
3 # 返回 NULL B 的左孩子空
4 D 建 D，递归左 —
5 # 返回 NULL D 的左孩子空
6 # 返回 NULL D 的右孩子空，D 返回
7 C 建 C，递归左 B 返回，A 的左孩子 = B
8 # 返回 NULL C 的左孩子空
9 # 返回 NULL C 的右孩子空，C 返回，A 的右孩子 = C

为什么只用前序？根在序列最前面，读到第一个字符就知道根是谁，剩下两段分给左右子树。换中序扩展序列 #B#D#A#C#，第一个字符是 #，你分不清这是「整棵树为空」还是「根的左孩子为空」，解析立刻卡死。后序更不用说，根压在最后。这条是高频错误，第十六章还会点名。

手工搭 #

结点少、结构固定，直接造结点再挂上去。

c
/* 造一个结点 */
bitree_t *MakeNode(data_t item, bitree_t *lchild, bitree_t *rchild)
{
    bitree_t *p = (bitree_t *)malloc(sizeof(bitree_t));

    if (p == NULL)
        return NULL;

    p->data   = item;
    p->lchild = lchild;
    p->rchild = rchild;

    return p;
}

树甲那棵 7 结点的满二叉树自底向上拼，父结点要用到已经存在的孩子：

c
/* 手工搭出树甲，顺序不能反 */
bitree_t *BuildByHand(void)
{
    bitree_t *d = MakeNode('d', NULL, NULL);
    bitree_t *e = MakeNode('e', NULL, NULL);
    bitree_t *f = MakeNode('f', NULL, NULL);
    bitree_t *g = MakeNode('g', NULL, NULL);
    bitree_t *b = MakeNode('b', d, e);
    bitree_t *c = MakeNode('c', f, g);

    return MakeNode('a', b, c);
}

先造 A 再造 B，B 的地址就没地方放。

改树：插入与删除 #

c
/* 在 parent 的第 lr 个位置插入子树，lr=0 左，lr=1 右；原位有孩子就插不进去 */
int InsertChild(bitree_t *parent, int lr, bitree_t *child)
{
    if (parent == NULL)
        return 0;

    if (lr == 0 && parent->lchild == NULL) {
        parent->lchild = child;
        return 1;
    }

    if (lr == 1 && parent->rchild == NULL) {
        parent->rchild = child;
        return 1;
    }

    return 0;
}

/* 后序释放整棵树 */
void DestroyTree(bitree_t *r)
{
    if (r == NULL)
        return;
    DestroyTree(r->lchild);
    DestroyTree(r->rchild);
    free(r);
}

/* 删掉 parent 的第 lr 棵子树，lr=0 左，lr=1 右 */
void DeleteChild(bitree_t *parent, int lr)
{
    bitree_t *p;

    if (parent == NULL)
        return;

    if (lr == 0) {
        p = parent->lchild;
        parent->lchild = NULL;
    } else {
        p = parent->rchild;
        parent->rchild = NULL;
    }

    DestroyTree(p);
}

删除必须先把指针摘下来，再释放。反过来做，DestroyTree 读的就是已经还给系统的内存，成了悬空指针；只 free 一个结点不往下递归，整棵子树就漏了。

三条路怎么选：完全二叉树和堆用顺序数组，题目给遍历序列就用扩展前序，结点少就手工搭。

九、先序遍历 #

规则四步：空则返回；访问根；先序左子树；先序右子树。一句话：根左右。

c
void PreOrder(bitree_t *r)
{
    if (r == NULL)
        return;

    printf("%c ", r->data);      /* 访问根 */
    PreOrder(r->lchild);         /* 先序左 */
    PreOrder(r->rchild);         /* 先序右 */
}

树甲：

text
            a
          /   \
         b     c
        / \   / \
       d   e f   g

输出 a b d e c f g。手算过程摊开：

步 当前结点 动作 已输出
1 a 访问 a，进左 a
2 b 访问 b，进左 a b
3 d 访问 d，左右都空，返回 a b d
4 e 访问 e，左右都空，返回 a b d e
5 c 访问 c，进左 a b d e c
6 f 访问 f，左右都空，返回 a b d e c f
7 g 访问 g，返回 a b d e c f g

每个结点访问一次，时间 O(n)。递归深度等于树高，空间 O(h)，树甲是 3，单支树是 n。

先序的用处是复制一棵树：先造根，再递归造左右子树，顺序正好对上。

c
bitree_t *CopyTree(bitree_t *r)
{
    bitree_t *p;

    if (r == NULL)
        return NULL;

    p = MakeNode(r->data, NULL, NULL);
    p->lchild = CopyTree(r->lchild);
    p->rchild = CopyTree(r->rchild);

    return p;
}

十、中序遍历 #

规则：空则返回；中序左子树；访问根；中序右子树。一句话：左根右。

c
void InOrder(bitree_t *r)
{
    if (r == NULL)
        return;

    InOrder(r->lchild);          /* 中序左 */
    printf("%c ", r->data);      /* 访问根 */
    InOrder(r->rchild);          /* 中序右 */
}

输出 d b e a f c g。看结果就能读出结构：a 被夹在左子树那一串 d b e 和右子树那一串 f c g 中间；左子树里 b 又被夹在 d 和 e 中间。中序的每个结点都出现在它左子树全部结点之后、右子树全部结点之前。

步 当前结点 动作 已输出
1 d 一路向左到底，左空，访问 d d
2 b 左收完，访问 b，进右 d b
3 e 左空，访问 e，返回 d b e
4 a 左收完，访问 a，进右 d b e a
5 f 一路向左到 f，访问 d b e a f
6 c 左收完，访问 c，进右 d b e a f c
7 g 访问 g，返回 d b e a f c g

中序有一个别人没有的性质：对二叉搜索树做中序遍历，得到的一定是递增序列。搜索树规定左子树全小于根、右子树全大于根，中序「左根右」正好把这个大小关系排成一条线。查找、插入、删除全靠它，详见同目录的查找算法篇。

中序还能判对称、判搜索树是否合法：走一遍看序列递不递增。

十一、后序遍历 #

规则：空则返回；后序左子树；后序右子树；访问根。一句话：左右根。

c
void PostOrder(bitree_t *r)
{
    if (r == NULL)
        return;

    PostOrder(r->lchild);        /* 后序左 */
    PostOrder(r->rchild);        /* 后序右 */
    printf("%c ", r->data);      /* 访问根 */
}

输出 d e b f g c a。根 a 落在最后，一个字符不差。

步 当前结点 动作 已输出
1 d 走到最左的叶子，访问 d d
2 e b 的右孩子，访问 e d e
3 b 左右都收完，访问 b d e b
4 f 转到右子树，最左的叶子，访问 f d e b f
5 g c 的右孩子，访问 g d e b f g
6 c 左右都收完，访问 c d e b f g c
7 a 右子树收完，访问 a d e b f g c a

后序的用处都是「先处理孩子、再处理自己」的场景：

  • 释放整棵树。第八章的 DestroyTree 就是后序，孩子没放完不能放父结点，否则拿不到孩子的地址。
  • 求深度、结点数、叶子数。孩子的结果出来才能算父亲。
  • 表达式树求值。叶子是操作数，内部结点是运算符，后序正好是逆波兰式的求值顺序。

后序是三种遍历里唯一没法用「一路向左压栈」直接写的，非递归要多绕一圈，第十四章处理。

十二、三种遍历的对比与还原 #

差别只有一行 #

先序、中序、后序的区别只有一件事：访问根结点这一步放在哪。

text
先序  PreOrder  :  访问根   左子树   右子树
中序  InOrder   :  左子树   访问根   右子树
后序  PostOrder :  左子树   右子树   访问根

递归代码只差 printf 那一行的位置，另外两行一模一样：

遍历 第一行 第二行 第三行
先序 访问根 递归左 递归右
中序 递归左 访问根 递归右
后序 递归左 递归右 访问根

三个序列长度一样、元素集合一样，只是排列不同。树甲 7 个结点，三个序列都是 7 个字符。

三张表对齐看 #

遍历 顺序 助记 树甲输出 根在哪 首元素 尾元素
先序 根左右 先到先得 a b d e c f g 最前 根 最右下的叶
中序 左根右 夹在中间 d b e a f c g 中间 最左的结点 最右的结点
后序 左右根 最后收尾 d e b f g c a 最后 最左下的叶 根

规律：先序第一个字符一定是根，后序最后一个字符一定是根，中序的根在中间某处。

轮廓法手算 #

沿树的外侧逆时针走一圈，每个结点会被经过三次：进入它的左子树前、从左子树回来、从右子树回来。第一次经过输出得先序，第二次得中序，第三次得后序。

树甲走一遍：先序 a b d e c f g，中序 d b e a f c g，后序 d e b f g c a，与代码跑的一致。手上没编译器时，这个办法比脑内跟栈快十倍。

为什么非要三种 #

树是图形结构，人一眼能看懂，计算机只处理线性序列，遍历就是把树摊平成一条线。

  • 先序：先拿根，适合复制、序列化、目录先父后子。
  • 中序：天生有序，适合二叉搜索树、判合法性。
  • 后序：先拿孩子的结果，适合释放、求值、统计。

还原：哪些组合够用 #

已知序列 能否唯一确定 原因
先序 + 中序 能 先序首字符定根，中序把根的左右切开
中序 + 后序 能 后序末字符定根，中序把根的左右切开
先序 + 后序 不能 两个都只给出根和结点集合，给不出左右分界

第三种不能，理由是硬伤：先序告诉你根是谁、剩下哪些结点归这棵子树；后序也告诉你根是谁、剩下哪些结点归这棵子树。两个都缺同一个信息——这些结点挂在左边还是右边。中序恰好提供它：根在中间，左边全是左子树的结点，右边全是右子树的结点。

结论：两个序列里必须有一个是中序，才能唯一还原。

先序 + 中序的还原算法 #

c
/* pre[l1..r1] 是先序，in[l2..r2] 是中序 */
bitree_t *Rebuild(const char *pre, const char *in,
                  int l1, int r1, int l2, int r2)
{
    bitree_t *root;
    int k, leftlen;

    if (l1 > r1)
        return NULL;

    root = MakeNode(pre[l1], NULL, NULL);     /* 先序首字符是根 */

    for (k = l2; k <= r2; k++)                /* 在中序里找根 */
        if (in[k] == pre[l1])
            break;

    leftlen = k - l2;                         /* 左子树结点个数 */

    root->lchild = Rebuild(pre, in, l1 + 1, l1 + leftlen, l2, k - 1);
    root->rchild = Rebuild(pre, in, l1 + leftlen + 1, r1, k + 1, r2);

    return root;
}

调用 Rebuild("ABDC", "BDAC", 0, 3, 0, 3)。

练习一：先序 ABDC，中序 BDAC #

  1. 先序首字符 A，根是 A。
  2. 中序 BDAC 里找 A，左边 BD、右边 C。左子树结点集合 {B, D}，右子树 {C}。
  3. 先序去掉 A 剩 BDC，按左 2 右 1 切成 BD 和 C。
  4. 左子树：先序 BD、中序 BD。首字符 B 是根；中序里 B 在最左，左边没东西，所以 B 没有左子树；右边是 D，D 是 B 的右孩子。
  5. 右子树只有 C，挂到 A 右边。
text
        A
       / \
      B   C
       \
        D

回代：前序 A B D C，中序 B D A C，后序 D B C A，与题给的对上。

同一棵树，先序扩展序列 AB#D##C##、中序扩展序列 #B#D#A#C#、后序扩展序列 ###DB##CA，三组一一对应，这也是验算的最快办法。

练习二：中序 ABCDEFG，后序 BDCAFGE，求先序 #

  1. 后序末字符 E，根是 E。
  2. 中序里 E 在中间，左边 ABCD、右边 FG。
  3. 后序去掉末位 E 剩 BDCAFG，按左 4 右 2 切成 BDCA 和 FG。
  4. 左子树：后序 BDCA 末位 A 是根。中序 ABCD 里 A 在最左，A 没有左子树，右边是 BCD；后序剩 BDC，末位 C 是根，中序 BCD 里 C 居中，左 B 右 D。
  5. 右子树：后序 FG 末位 G 是根，中序 FG 里 G 在最右，G 没有右子树，左边是 F。
text
        E
       / \
      A   G
       \  /
       C F
      / \
     B   D

前序 E A C B D G F。回代后序得 B D C A F G E，与题目给的 BDCAFGE 一致。

练习三：先序 ABC，后序 CBA #

这组给不出唯一答案。根是 A，剩下 B、C 都在 A 的左子树里，两种摆法：

text
   形态一              形态二
     A                  A
    /                  /
   B                  B
  /                    \
 C                      C

两个都满足先序 ABC、后序 CBA，却是两棵不同的树，中序一个是 CBA、一个是 BCA。所以先序 + 后序定不了唯一的树。

这个三结点反例背下来。被问「先序和后序能不能还原」，答不能，再甩反例，比背结论强。

十三、层序遍历 #

不按递归走，按高度走：从根开始，一层一层往下，同一层从左到右。

队列是唯一合适的工具。出队一个结点，把它按先左后右推进队尾，队里永远是「上一层剩下的」加「下一层已经发现的」。

c
void LevelOrder(bitree_t *r)
{
    bitree_t *q[MAXN];
    int front = 0, rear = 0;

    if (r == NULL)
        return;

    q[rear++] = r;                      /* 根入队 */

    while (front < rear) {
        bitree_t *p = q[front++];       /* 队头出队 */

        printf("%c ", p->data);

        if (p->lchild)
            q[rear++] = p->lchild;
        if (p->rchild)
            q[rear++] = p->rchild;
    }
}

树甲跑一遍：

步 出队 输出 新入队 队列内容
1 a a b, c b c
2 b b d, e c d e
3 c c f, g d e f g
4 d d — e f g
5 e e — f g
6 f f — g
7 g g — 空

输出 a b c d e f g，正好是层序编号的顺序。

按层换行 #

想知道「这一层还剩几个」，就在内层循环开始前把当前队列长度记下来：

c
void LevelPrint(bitree_t *r)
{
    bitree_t *q[MAXN];
    int front = 0, rear = 0;

    if (r == NULL)
        return;
    q[rear++] = r;

    while (front < rear) {
        int cnt = rear - front;         /* 这一层的结点数，必须先存下来 */
        int i;

        for (i = 0; i < cnt; i++) {
            bitree_t *p = q[front++];
            printf("%c ", p->data);

            if (p->lchild)
                q[rear++] = p->lchild;
            if (p->rchild)
                q[rear++] = p->rchild;
        }

        printf("\n");
    }
}

树甲输出：

text
a
b c
d e f g

cnt 那一行是关键。写成 for (i = 0; i < rear - front; i++) 就废了：循环里 rear 一直在涨，条件永远成立，整棵树打在一行。

层序还能求树宽（结点最多的那层的结点数），判完全二叉树（第五章的 IsComplete 就是层序变体），以及不用递归求深度（第十五章给代码）。

数组队列容量是 MAXN，层序的空间开销等于树的最大宽度。开小了会写穿数组，练习树开 100 够用，上生产要按实际规模算，或者换循环队列。

十四、递归与非递归实现 #

递归为什么能跑：每调一次 PreOrder，系统就往栈上压一层，存返回地址和局部变量 r；遇到 NULL 那一层立刻返回，栈开始回弹。树甲 7 个结点，栈最深 3 层，正好是树高。所以递归的空间开销是 O(h)。

单支树上 h = n，递归会压 n 层栈，n 上万就得改成非递归——把这套系统栈换成自己的数组。

前序非递归 #

一路向左，沿途访问并入栈；走到空就出栈，转向右孩子。

c
void PreOrderIter(bitree_t *r)
{
    bitree_t *st[MAXN];
    int top = -1;
    bitree_t *p = r;

    while (p != NULL || top >= 0) {
        while (p != NULL) {
            printf("%c ", p->data);     /* 入栈前访问 */
            st[++top] = p;
            p = p->lchild;
        }
        p = st[top--];
        p = p->rchild;
    }
}

中序非递归 #

跟前序只差一个位置：printf 从入栈前挪到出栈后。

c
void InOrderIter(bitree_t *r)
{
    bitree_t *st[MAXN];
    int top = -1;
    bitree_t *p = r;

    while (p != NULL || top >= 0) {
        while (p != NULL) {
            st[++top] = p;              /* 只压栈，不访问 */
            p = p->lchild;
        }
        p = st[top--];
        printf("%c ", p->data);         /* 出栈时访问 */
        p = p->rchild;
    }
}

后序非递归 #

后序卡在一个地方：出栈时不知道右子树处理完没有。跳过去就漏，直接访问就早。两种解法。

第一种，双栈。按「根、右、左」压进第二个栈，最后倒着输出：

c
void PostOrderIter(bitree_t *r)
{
    bitree_t *s1[MAXN], *s2[MAXN];
    int t1 = -1, t2 = -1;
    bitree_t *p;

    if (r == NULL)
        return;

    s1[++t1] = r;

    while (t1 >= 0) {
        p = s1[t1--];
        s2[++t2] = p;                   /* 根先进 s2，再进右、再进左 */
        if (p->lchild)
            s1[++t1] = p->lchild;
        if (p->rchild)
            s1[++t1] = p->rchild;
    }

    while (t2 >= 0)                     /* 倒序弹出就是 左、右、根 */
        printf("%c ", s2[t2--]->data);
}

第二种，单栈加 last 标记。last 记住上一个访问完的结点，用它判断右子树走没走：

c
void PostOrderOneStack(bitree_t *r)
{
    bitree_t *st[MAXN];
    bitree_t *last = NULL;
    bitree_t *p = r;
    int top = -1;

    while (p != NULL || top >= 0) {
        while (p != NULL) {
            st[++top] = p;
            p = p->lchild;
        }

        p = st[top];                    /* 先看栈顶，不急着弹 */

        if (p->rchild != NULL && p->rchild != last) {
            p = p->rchild;              /* 右边还没走，先去右边 */
        } else {
            printf("%c ", p->data);     /* 右边走过了，可以访问自己 */
            last = p;
            top--;                      /* 这时候才真出栈 */
            p = NULL;                   /* 置空，回到出栈分支 */
        }
    }
}

p = NULL 那句是灵魂。不置空，内层 while 会把 p->lchild 再压一遍，死循环。两种写法结果一样，双栈好懂，单栈省空间，树甲都是 d e b f g c a。

回调式遍历 #

把「访问」抽成函数指针，遍历逻辑和业务逻辑分开：

c
typedef void (*visit_fn)(data_t);

void PreOrderTraverse(bitree_t *r, visit_fn visit)
{
    if (r == NULL)
        return;

    visit(r->data);
    PreOrderTraverse(r->lchild, visit);
    PreOrderTraverse(r->rchild, visit);
}

配套的访问函数 void PrintItem(data_t item) 里写 printf("%c ", item);，调用 PreOrderTraverse(t, PrintItem);。想改成求和、写文件、存数组，只换 visit 那一个函数。

实现 辅助结构 时间 空间 代码量 什么时候用
递归 系统栈 O(n) O(h) 最短 默认选它
前序迭代 数组栈 O(n) O(h) 中 深度大、怕爆系统栈
中序迭代 数组栈 O(n) O(h) 中 同上
后序双栈 两个数组栈 O(n) O(h) 长 图好懂，不想维护 last
后序单栈 一个数组栈 O(n) O(h) 长 空间紧
层序 队列 O(n) O(宽度) 短 按层处理、求宽度

十五、遍历的应用：求深度、结点数、叶子数 #

这三个函数同一个骨架：先拿孩子的结果，再算自己，也就是后序。

求深度 #

c
int GetDepth(bitree_t *r)
{
    int ld, rd;

    if (r == NULL)
        return 0;

    ld = GetDepth(r->lchild);
    rd = GetDepth(r->rchild);

    return (ld > rd ? ld : rd) + 1;
}

空树深度 0，只有一个根深度 1。这个边界别搞反，很多题的答案就差这 1。

不想用递归就用层序，一层加一：

c
int GetDepthByLevel(bitree_t *r)
{
    bitree_t *q[MAXN];
    int front = 0, rear = 0, depth = 0;

    if (r == NULL)
        return 0;
    q[rear++] = r;

    while (front < rear) {
        int cnt = rear - front;
        int i;

        depth++;                        /* 每处理完一层，深度加一 */

        for (i = 0; i < cnt; i++) {
            bitree_t *p = q[front++];

            if (p->lchild)
                q[rear++] = p->lchild;
            if (p->rchild)
                q[rear++] = p->rchild;
        }
    }

    return depth;
}

结点数 #

c
int CountNode(bitree_t *r)
{
    if (r == NULL)
        return 0;

    return CountNode(r->lchild) + CountNode(r->rchild) + 1;
}

叶子数 #

c
int CountLeaf(bitree_t *r)
{
    if (r == NULL)
        return 0;

    if (r->lchild == NULL && r->rchild == NULL)
        return 1;                       /* 左右都空才是叶子 */

    return CountLeaf(r->lchild) + CountLeaf(r->rchild);
}

只写 if (r->lchild == NULL) 就错了，那是「没有左孩子」，单支树的结点会被算成叶子。

度为 1 和度为 2 的结点数 #

c
int CountDeg1(bitree_t *r)
{
    if (r == NULL)
        return 0;

    /* 一个空一个不空，就是度为 1 */
    return ((r->lchild == NULL) != (r->rchild == NULL))
           + CountDeg1(r->lchild) + CountDeg1(r->rchild);
}

int CountDeg2(bitree_t *r)
{
    if (r == NULL)
        return 0;

    return (r->lchild != NULL && r->rchild != NULL)
           + CountDeg2(r->lchild) + CountDeg2(r->rchild);
}

树甲代进去：深度 3，结点 7，叶子 4，度为 1 的 0 个，度为 2 的 3 个。验性质 3：n0 = 4，n2 = 3，4 = 3 + 1，对上了。

拼成一个能跑的程序 #

主函数：

c
int main(void)
{
    data_t a[] = {0, 'a', 'b', 'c', 'd', 'e', 'f', 'g'};
    int n = sizeof(a) / sizeof(a[0]) - 1;
    bitree_t *t = CreateByArray(1, a, n);

    printf("深度：%d\n", GetDepth(t));
    printf("结点数：%d\n", CountNode(t));
    printf("叶子数：%d\n", CountLeaf(t));
    printf("度为1：%d\n", CountDeg1(t));
    printf("度为2：%d\n", CountDeg2(t));

    printf("先序：");     PreOrder(t);          printf("\n");
    printf("中序：");     InOrder(t);           printf("\n");
    printf("后序：");     PostOrder(t);         printf("\n");
    printf("先序迭代："); PreOrderIter(t);      printf("\n");
    printf("中序迭代："); InOrderIter(t);       printf("\n");
    printf("后序迭代："); PostOrderIter(t);     printf("\n");
    printf("后序单栈："); PostOrderOneStack(t); printf("\n");
    printf("层序：");     LevelOrder(t);        printf("\n");

    DestroyTree(t);

    return 0;
}

十六、易错点速查 #

现象 原因 后果 正解
三种遍历序列混了 没抓住「访问根在哪」 整道题全错 根左右、左根右、左右根
递归崩在空指针上 忘写 if (r == NULL) return; 段错误 递归函数第一句判空
深度为 k 的结点数算少一半 性质 2 记成 2^(k-1) 差一倍 是 2^k - 1
n0 = n2 + 1 代错 把 n1 一起算进去了 结果偏差 这条只连 n0 和 n2
顺序存储孩子全错位 下标从 0 开始照抄 2i、2i+1 找不到孩子 下标 1 起，0 号空置
遍历踩到野指针 malloc 后没给叶子赋 NULL 随机崩溃 每个新结点显式写 lchild = rchild = NULL
先序 + 后序还原出两种树 组合缺中序 答案不唯一 必须带中序
用中序扩展序列建树卡死 根不在首位，首字符是 # 解析不出结构 建树只用扩展前序序列
释放后还读内存 先序释放，父结点先被 free 拿不到孩子、内存泄漏 后序释放
层序全打在一行 cnt 没提前存，rear 一直在涨 少了换行 先 int cnt = rear - front;
空树深度算成 1 边界没处理 答案差 1 空树深度 0
打印一串乱码 data_t 是 char 却用 %d 数值错乱 格式符跟着 typedef 走
DeleteChild 删不干净 先把指针置 NULL 再 free 漏掉整棵子树 先存指针、摘链、再释放
数组队列写穿 MAXN 没按最大宽度算 覆盖别的变量 按宽度开，或用循环队列

三条自查清单：

  1. 三个递归函数能不能默写出来，printf 各在第几行。答不上来就是没吃透「只差一行」。
  2. 随手画一棵 7 结点的树，手写三个序列，再用轮廓法验一遍。两遍对不上就重画。
  3. 拿到两个序列先问一句：有没有中序。没有就回一句「不唯一」，顺手给出三结点反例。
