一、概述 #

正则表达式是记录文本规则的代码，用于模式匹配与文本搜索。其思路与 Windows 文件查找中的通配符（wildcard）相近：在 *.doc 中，* 被解释为任意字符串，因而可以找出某个目录下的全部 Word 文档。正则表达式在通配符的基础上提供了更完整的规则描述能力，由表达式、量词与断言组成。

本篇按「概念 → 语法元素 → 进阶机制 → 速查表」组织：先说明模式的构成，再依次给出字符、元字符、量词、分支与分组等基本元素，随后讨论贪婪与懒惰、定位与边界、反向引用、注释和运算符优先级，最后给出可直接查阅的字符含义表。

三、模式的构成 #

正则表达式的模式由以下几类成分组合而成：

成分 说明
字面值字符 普通字符按字面意义匹配，例如字母、数字、空格，直接匹配自身。
特殊字符 点号 .、星号 *、加号 +、问号 ? 等，具有特殊含义和功能。
字符类 用方括号 [ ] 包围的字符集合，匹配其中任意一个字符；[^ ] 匹配除括号内字符以外的任意一个字符。
元字符 如 \d、\w、\s，匹配数字、字母、空白字符等特定类型。
量词 如 {n}、{n,}、{n,m}，指定匹配的次数或范围。
边界符号 如 ^、$、\b、\B，匹配字符串的开头、结尾、单词边界与非边界位置。
分组和捕获 ( ) 用于分组并捕获子表达式；(?: ) 用于分组但不捕获。

一个典型的模式解析示例如下，该表达式可匹配 (010)88886666、022-22334455、02912345678 等电话号码格式：

\(?0\d{2}[) -]?\d{8}

其结构依次为：转义后的左括号 \(? 出现 0 次或 1 次；一个字面量 0；两位数字 \d{2}；右括号、连字符或空格三者之一构成的可选字符类 [) -]?；最后 8 位数字 \d{8}。

四、字符与字符类 #

字符匹配直接在方括号中列出，例如 [aeiou] 匹配任何一个英文元音字母，[.?!] 匹配 .、? 或 ! 中的标点符号。也可以指定字符范围：[0-9] 的含义与 \d 完全一致，表示一位数字；[a-z0-9A-Z_] 完全等同于 \w。

普通字符

字符 含义
[ABC] 匹配 [...] 中的所有字符。
[^ABC] 匹配除 [...] 中字符以外的所有字符。
[A-Z] 表示一个区间，匹配所有大写字母；[a-z] 表示所有小写字母。
. 匹配除换行符（\n、\r）之外的任何单个字符，相当于 [^\n\r]。
[\s\S] 匹配所有字符。\s 匹配所有空白符（含换行），\S 匹配非空白符。
\w 匹配字母、数字、下划线，等价于 [A-Za-z0-9_]。

非打印字符

字符 含义
\cx 匹配由 x 指明的控制字符。例如 \cM 匹配一个 Control-M 或回车符；x 的值须为 A–Z 或 a–z 之一，否则将 c 视为原义的 c 字符。
\f 匹配一个换页符，等价于 \x0c 和 \cL。
\n 匹配一个换行符，等价于 \x0a 和 \cJ。
\r 匹配一个回车符，等价于 \x0d 和 \cM。
\s 匹配任何空白字符，包括空格、制表符、换页符等，等价于 [ \f\n\r\t\v]；Unicode 正则表达式会匹配全角空格符。
\S 匹配任何非空白字符，等价于 [^ \f\n\r\t\v]。
\t 匹配一个制表符，等价于 \x09 和 \cI。
\v 匹配一个垂直制表符，等价于 \x0b 和 \cK。

五、元字符与转义 #

元字符是具有特殊意义的字符，用于定义匹配模式或规则。

元字符 含义
. 匹配任意单个字符（换行符除外）。
* 匹配前面的字符零次或多次。
+ 匹配前面的字符一次或多次。
? 匹配前面的字符零次或一次；亦可表示懒惰模式。
^ 匹配字符串的开头。
$ 匹配字符串的结尾。
[] 匹配方括号中的任意一个字符。
() 标记一个子表达式的开始和结束位置。
| 在两个或多个模式之间进行选择。

特殊字符

字符 含义
$ 匹配输入字符串的结尾位置；若设置 RegExp 对象的 Multiline 属性，也匹配 \n 或 \r。匹配本身须写作 \$。
( ) 标记子表达式的开始和结束位置，子表达式可获取供以后使用；匹配圆括号本身须转义。
* 匹配前面的子表达式零次或多次；匹配本身须写作 \*。
+ 匹配前面的子表达式一次或多次；匹配本身须写作 \+。
. 匹配除换行符 \n 之外的任何单字符；匹配本身须写作 \.。
[ 标记中括号表达式的开始；匹配本身须转义。
? 匹配前面的子表达式零次或一次，或指明一个非贪婪限定符；匹配本身须写作 \?。
\ 将下一个字符标记为特殊字符、原义字符、向后引用或八进制转义符。
^ 匹配输入字符串的开始位置；在方括号表达式中表示不接受该字符集合；匹配本身须写作 \^。
{ 标记限定符表达式的开始；匹配本身须转义。
| 指明两项之间的一个选择；匹配本身须转义。

字符转义 若需匹配特殊字符本身，须用反斜杠将其转义成普通字符。例如匹配句号须写作 \.，匹配星号本身须写作 \*。常用的转义字符还有 \d（任意一个数字字符）、\w（任意一个字母、数字或下划线）、\s（任意一个空白字符）、\b（单词边界），可避免手动罗列所有可能的字符。

转义字符

字符 含义
\d 匹配任意一个数字字符。
\w 匹配任意一个字母、数字或下划线字符。
\s 匹配任意一个空白字符（空格、制表符、换行符等）。
\b 匹配单词的边界。

反义字符以反斜杠开头、后跟一个大写字母，表示匹配除该字符类别之外的任意字符。

字符 含义
\D 匹配任意一个非数字字符。
\W 匹配任意一个非字母、数字或下划线字符。
\S 匹配任意一个非空白字符。
\B 匹配不在单词边界上的任意一个字符。

六、量词与重复 #

量词 {n}、{n,}、{n,m} 分别表示重复 n 次、重复 n 次或更多次、重复 n 到 m 次。

字符 含义
* 匹配前面的子表达式零次或多次。zo* 能匹配 z 与 zoo；等价于 {0,}。
+ 匹配前面的子表达式一次或多次。zo+ 能匹配 zo 与 zoo，但不能匹配 z；等价于 {1,}。
? 匹配前面的子表达式零次或一次。do(es)? 可匹配 do、does；等价于 {0,1}。
{n} n 为非负整数，匹配确定的 n 次。o{2} 不能匹配 Bob 中的 o，但能匹配 food 中的两个 o。
{n,} 至少匹配 n 次。o{2,} 不能匹配 Bob 中的 o，但能匹配 foooood 中的所有 o；o{1,} 等价于 o+，o{0,} 等价于 o*。
{n,m} m 与 n 均为非负整数且 n <= m，最少匹配 n 次、最多匹配 m 次。o{1,3} 匹配 fooooood 中的前三个 o；o{0,1} 等价于 o?。逗号与两个数之间不能有空格。

注意 不能将限定符与定位符一起使用。紧靠换行或单词边界的前后不能存在一个以上的位置，因此 ^* 之类的表达式不被允许。

七、分支条件与分组 #

\| 元字符用于在两种或多种模式之间进行选择。匹配分支条件时从左到右测试每个条件，一旦满足某个分支，就不再向右测试其余分支。

( ) 元字符标记一个子表达式的开始和结束位置，同时把匹配结果捕获供后续使用；(?: ) 只分组而不捕获。

IP 地址匹配是分组与分支组合的典型例子：

((2[0-4]\d|25[0-5]|[01]?\d\d?)\.){3}(2[0-4]\d|25[0-5]|[01]?\d\d?)

注意 原素材把该表达式中的分隔符写作 .，并按 {3} 重复；此处按「点号须转义为字面量」的常规写法补回 \.，其余分组与分支结构与原素材一致。

八、贪婪与懒惰 #

当表达式中包含可接受重复的限定符时，默认行为是在使整个表达式能得到匹配的前提下匹配尽可能多的字符。以 a.*b 为例，它匹配最长的以 a 开始、以 b 结束的字符串；作用于 aabab 时会匹配整个 aabab，这称为贪婪匹配。

若需要匹配尽可能少的字符，可在限定符后加一个问号 ? 转为懒惰匹配：.*? 表示在能使整个匹配成功的前提下使用最少的重复。a.*?b 匹配最短的以 a 开始、以 b 结束的字符串；作用于 aabab 时匹配 aab（第一到第三个字符）和 ab（第四到第五个字符）。

九、定位符与边界 #

字符 含义
^ 匹配输入字符串开始的位置；若设置 RegExp 对象的 Multiline 属性，还与 \n 或 \r 之后的位置匹配。
$ 匹配输入字符串结尾的位置；若设置 Multiline 属性，还与 \n 或 \r 之前的位置匹配。
\b 匹配一个单词边界，即字与空格间的位置。
\B 匹配非单词边界。

十、反向引用 #

用小括号指定一个子表达式后，匹配该子表达式的文本（即分组捕获的内容）可在表达式或其它程序中进一步处理。反向引用用于重复搜索前面某个分组匹配的文本，例如 \1 代表分组 1 匹配的文本；分组 0 对应整个正则表达式。

\b(\w+)\b\s+\1\b

该表达式可用来匹配重复的单词，例如 go go 或 kitty kitty。

十一、注释 #

小括号的另一种用途是通过语法 (?#comment) 包含注释。下面在 IP 地址表达式的三个分支后分别附上注释：

2[0-4]\d(?#200-249)|25[0-5](?#250-255)|[01]?\d\d?(?#0-199)

注意 原素材在此处的第二个分支中夹带了一条自建站点的内网链接，按清洗要求已移除，未保留该链接内容。

十二、运算符优先级 #

正则表达式从左到右计算，并遵循与算术表达式类似的优先级顺序：相同优先级从左到右运算，不同优先级先高后低。下表从最高到最低列出各运算符的优先级。

运算符 描述
\ 转义符。
()、(?:)、(?=)、[] 圆括号和方括号。
*、+、?、{n}、{n,}、{n,m} 限定符。
^、$、任何元字符、任何字符 定位点和序列（位置和顺序）。
| 替换，即「或」操作；字符具有高于替换运算符的优先级，使得 m|food 匹配 m 或 food。

注意 原素材该表末行被 \| 截断，仅保留 m 字样；此处按「字符优先级高于替换运算符」的说明补全末行语义，未引入素材之外的运算符。

十三、正则表达式字符含义表 #

下表汇总本篇涉及的字符及其含义，供查阅。

注意 原素材该表为三列结构，多行内容被 \| 拆分到相邻单元格，个别行（如 x\|y、\un）的示例残缺。本篇统一改写成两列，合并被拆散的释义；无法从原素材恢复的示例以 — 标注，不补写素材之外的内容。

字符 含义
\ 将下一个字符标记为特殊字符、原义字符、向后引用或八进制转义符。例如 n 匹配字符 n，\n 匹配换行符，\\ 匹配反斜杠，\( 匹配左括号。
^ 匹配输入字符串的开始位置；若设置 Multiline 属性，也匹配 \n 或 \r 之后的位置。
$ 匹配输入字符串的结束位置；若设置 Multiline 属性，也匹配 \n 或 \r 之前的位置。
* 匹配前面的子表达式零次或多次；等价于 {0,}。
+ 匹配前面的子表达式一次或多次；等价于 {1,}。
? 匹配前面的子表达式零次或一次；等价于 {0,1}。
{n} 匹配确定的 n 次。
{n,} 至少匹配 n 次；o{1,} 等价于 o+，o{0,} 等价于 o*。
{n,m} 最少匹配 n 次且最多匹配 m 次；o{0,1} 等价于 o?，逗号与两个数之间不能有空格。
?（紧跟其它限定符） 转为非贪婪模式，尽可能少地匹配。例如 o+? 对 oooo 只匹配单个 o，而 o+ 匹配全部 o。
. 匹配除换行符之外的任何单个字符；要匹配包括 \n 在内的任何字符，可使用 (.|\n) 之类的模式。
(pattern) 匹配 pattern 并获取该匹配；可从 Matches 集合取得，在 VBScript 中使用 SubMatches 集合，在 JScript 中使用 $0…$9 属性；匹配圆括号本身须转义。
(?:pattern) 匹配 pattern 但不获取匹配结果，即非获取匹配、不存储供以后使用；用 | 组合模式各部分时很有用，例如 industr(?:y|ies)。
(?=pattern) 正向肯定预查，在任何匹配 pattern 的字符串开始处匹配查找字符串，属非获取匹配；例如 Windows(?=95|98)。
(?!pattern) 正向否定预查，在任何不匹配 pattern 的字符串开始处匹配查找字符串，属非获取匹配；例如 Windows(?!95|98)。
(?<=pattern) 反向肯定预查，与正向肯定预查类似但方向相反；例如 (?<=95|98)Windows。
(?<!pattern) 反向否定预查，与正向否定预查类似但方向相反；例如 (?<!95|98)Windows 能匹配 3.1Windows 中的 Windows，但不能匹配 2000Windows 中的 Windows。
x|y 匹配 x 或 y。原素材此处示例残缺（仅保留 z 字样），未补写 —。
[xyz] 字符集合，匹配所包含的任意一个字符；例如 [abc] 匹配 plain 中的 a。
[^xyz] 负值字符集合，匹配未包含的任意字符；例如 [^abc] 匹配 plain 中的 p、l、i、n。
[a-z] 字符范围，匹配指定范围内的任意字符；例如匹配 a 到 z 的任意小写字母。
[^a-z] 负值字符范围，匹配任何不在指定范围内的字符。
\b 匹配一个单词边界；例如 er\b 匹配 never 中的 er，但不匹配 verb 中的 er。
\B 匹配非单词边界；er\B 匹配 verb 中的 er，但不匹配 never 中的 er。
\cx 匹配由 x 指明的控制字符；x 须为 A–Z 或 a–z 之一，否则将 c 视为原义字符。
\d 匹配一个数字字符，等价于 [0-9]。
\D 匹配一个非数字字符，等价于 [^0-9]。
\f 匹配一个换页符，等价于 \x0c 和 \cL。
\n 匹配一个换行符，等价于 \x0a 和 \cJ。
\r 匹配一个回车符，等价于 \x0d 和 \cM。
\s 匹配任何空白字符，等价于 [ \f\n\r\t\v]。
\S 匹配任何非空白字符，等价于 [^ \f\n\r\t\v]。
\t 匹配一个制表符，等价于 \x09 和 \cI。
\v 匹配一个垂直制表符，等价于 \x0b 和 \cK。
\w 匹配字母、数字、下划线，等价于 [A-Za-z0-9_]。
\W 匹配非字母、数字、下划线，等价于 [^A-Za-z0-9_]。
\xn 匹配 n，其中 n 为两位十六进制转义值；例如 \x41 匹配 A，\x041 等价于 \x04 与 1。
\num 匹配 num，num 为正整数，表示对所获取匹配的引用；例如 (.)\1 匹配两个连续的相同字符。
\n 标识八进制转义值或向后引用：若 \n 之前至少有 n 个获取的子表达式，则 n 为向后引用；否则若 n 为八进制数字（0–7），则为八进制转义值。
\nm 标识八进制转义值或向后引用，按之前获取的子表达式个数判定；若 n、m 均为八进制数字，则匹配八进制转义值 nm。
\nml 若 n 为八进制数字（0–3）且 m、l 均为八进制数字（0–7），则匹配八进制转义值 nml。
\un 匹配 n，其中 n 为四个十六进制数字表示的 Unicode 字符；例如 \u00A9 匹配版权符号。原素材此处示例以孤立反引号结尾，已清理。

十四、小结 #

构造一个正则表达式可按以下顺序推进：

  1. 确定需要匹配的基本字符或字符类别、字符集合。
  2. 确定匹配的字符或字符集合的数量。
  3. 处理特殊字符和转义字符。
  4. 处理边界和位置的匹配。
  5. 使用捕获组 () 进行多组匹配。
  6. 使用反向引用。
  7. 使用逻辑操作符进行判定。

十五、常见错误与陷阱 #

  • 默认贪婪：含重复限定符的表达式默认匹配尽可能长的文本，容易越过预期边界；需要最短匹配时应在限定符后加 ?。
  • 限定符与定位符连用：^* 之类表达式不成立，定位点前后不能存在多个位置。
  • 转义丢失：特殊字符本身（.、*、( 等）必须转义，否则被解释为元字符；IP 表达式中的点号应写作 \.。
  • 分支短路：\| 从左到右测试，一旦命中就不再向右测试，分支顺序会影响匹配结果。
  • 逗号后空格：{n,m} 的逗号与两个数之间不能有空格。
  • 优先级误判：字符的优先级高于替换运算符 \|，需要整体选择时须用 () 分组。
  • 表格与外链：原素材的字符含义表存在被 \| 拆断的行与孤立反引号，且注释示例中夹带自建站点链接；本篇已统一表格结构并移除该链接，查阅时须注意残缺行以 — 标注。
