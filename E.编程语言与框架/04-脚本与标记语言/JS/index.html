四、外部的 JavaScript #

HTML 中的 JavaScript 脚本代码必须位于 <script> 与 </script> 标签之间。脚本可放置在 HTML 页面的 <head> 或 <body> 部分；通常的做法是把函数放入 <head> 部分，或放在页面底部，使脚本集中在一处而不干扰页面内容。

通常需要在某个事件发生时执行代码，例如用户点击按钮时；若把 JavaScript 代码放入函数中，即可在事件发生时调用该函数。

脚本也可保存到外部文件中，供多个网页复用。外部 JavaScript 文件的扩展名是 .js；使用外部文件时，在 <script> 标签的 src 属性中指定该 .js 文件。

html
<button type="button" onclick="myFunction()">点击这里</button>
<p><b>注释：</b>myFunction 保存在名为 "myScript.js" 的外部文件中。</p>
<script src="myScript.js"></script>

外部文件 myScript.js 中的函数定义：

javascript
function myFunction()
{
    document.getElementById("demo").innerHTML = "的第一个 JavaScript 函数";
}

注意：外部脚本不能包含 <script> 标签。在标签中填写 onclick 事件调用函数时，不是 onclick=函数名，而是 onclick=函数名+()（参见 第15节）。

本节合并 JavaScript.md 的「示例分析」素材，共三段代码。第一段给出页面重载函数 reloadPageContent 与基于 jQuery 的点击展开／隐藏函数 updateClick；第二段给出通过 XMLHttpRequest 与 fetch 获取文本并写入 mainmenu 容器的 getInnerHTML、showPicture；第三段给出以 XMLHttpRequest 向后端 POST 请求文件内容与文件列表的 openFile、blogList，其中 openFile 借助 marked.parse 把响应文本渲染为 Markdown 样式。三段代码共同构成「重载页面 → 绑定菜单点击 → 拉取并渲染内容」的页面交互流程（异步请求机制参见 第9节）。

注意：原文使用内网地址，此处以占位域名替代。

注意：示例中的 $（jQuery）与 marked 来自外部库，原文未给出引入方式或版本，本篇不补写相关 API。

第一段：页面重载与菜单点击展开／隐藏。

// 在当前页面重新载入页面
function reloadPageContent(reloadPage){
    window.location.replace(reloadPage);

// 按钮点击展开或隐藏
function updateClick(){
    $(document).ready((function() {    // ready 函数来确保文档加载完毕后再执行代码（jQuery 库代码）
        $("a").click((function() {    // 为文档中的所有 <a> 标签绑定点击事件

第二段：获取文本并更新容器内容。

javascript
// 获取并更新 innerHTML 中的内容
function getInnerHTML(filePos){
    var xhr = new XMLHttpRequest();
    xhr.open("GET", filePos, true);
    xhr.onreadystatechange = function() {
        if (xhr.readyState === 4 && xhr.status === 200) {
            var htmlContent = xhr.responseText;
            document.getElementById("mainmenu").innerHTML = htmlContent;
            updateClick();
        }
    };
    xhr.send();
}

function showPicture(){
    fetch('https://example.com/api/get_picture?id=1',
        {method: 'GET', headers: {'Content-Type': 'application/json'},})
        .then(response => response.text())
        .then(data => {document.getElementById("mainmenu").innerHTML = data})
}

第三段：向后端请求文件内容与文件列表。

javascript
function openFile(filePos){
    var xhr = new XMLHttpRequest();
    xhr.open("POST", "https://example.com/api/getFileContent", true);
    xhr.setRequestHeader("Content-Type", "application/json;charset=UTF-8");
    var message = {
        filePos
    };
    var jsonMessage = JSON.stringify(message);
    xhr.onreadystatechange = function () {
        if (xhr.readyState === 4 && xhr.status === 200) {
            var responseContainer = document.getElementById("mainmenu");
            responseContainer.innerHTML =
                '<meta name="viewport" content="width=device-width, initial-scale=1">' +
                '<link rel="stylesheet" href="2.css/github-markdown-css/github-markdown.css">' +
                '<style>.markdown-body {box-sizing: border-box;min-width: 200px;max-width: 980px;margin: 0 auto;padding: 45px;}@media (max-width: 767px) {.markdown-body {padding: 15px;}}</style>' +
                '<article class="markdown-body">' + marked.parse(xhr.responseText) + '</article>';
        }
    };
    xhr.send(jsonMessage);
}

function blogList() {
    // 创建 XMLHttpRequest 对象
    var xhr = new XMLHttpRequest();

    // 配置请求，将消息发送到后端 Python 服务器
    xhr.open("POST", "https://example.com/api/getFileList", true);

    // 设置请求头，告诉服务器发送的是 JSON 数据
    xhr.setRequestHeader("Content-Type", "application/json;charset=UTF-8");

    // 创建要发送的消息对象
    var message = {
        "message": "Hello, backend!"
    };

    // 将消息对象转换为 JSON 格式
    var jsonMessage = JSON.stringify(message);

    // 处理响应
    xhr.onreadystatechange = function () {
        if (xhr.readyState === 4 && xhr.status === 200) {
            // 在页面上显示后端返回的消息
            var responseContainer = document.getElementById("mainmenu");
            responseContainer.innerHTML = "后端返回的消息: " + xhr.responseText;
        }
    };

    // 发送请求
    xhr.send(jsonMessage);
}

规则 说明

json

<input id="demo" type="text">
<script>
    function myFunction()
    {
        var x = document.getElementById("demo").value;
        if(isNaN(x)||x.replace(/(^\s*)|(\s*$)/g,"")==""){
            alert("不是数字");
        }
    }
</script>
<button type="button" onclick="myFunction()">点击这里</button>

十五、常见错误与陷阱 #

陷阱 说明
外部脚本含 <script> 标签 外部脚本不能包含 <script> 标签
onclick 漏写括号 在标签中填写 onclick 事件调用函数时，不是 onclick=函数名，而是 onclick=函数名+()
文档加载后调用 document.write() 只能在 HTML 输出流中使用；文档已加载后使用会覆盖整个文档
混淆 null 与 undefined 二者的值相等，但类型不等
混淆 DOM 查找方法 通过 id 用 getElementById，通过标签名用 getElementsByTagName，通过类名用 getElementsByClassName
容器与标签名查找混用 原文示例中先以 getElementById("main") 取得容器，再以该容器的 getElementsByTagName("p") 取段落

注意：原文「类」「JavaScript Promise」「日期（Date）」「清空 Console 窗口」以及部分仅有名称的关键字等处仅有标题或残句，未提供可用细节；本篇以 > **注意** 标注，不补写素材没有的 API 或标准细节（参见 第3节、第5节、第6节、第9节、第12节）。
