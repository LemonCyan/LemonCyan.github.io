四、订阅源结构 #

RSS 订阅源由频道与条目两类元素构成：频道描述订阅源整体，条目描述其中的单条内容（参见 第5节）。素材以元素清单形式给出字段名、必需性与描述；原文两处围栏误标为 html，内容实为 XML 元素名，本篇按内容改为 xml，并以「订阅源」「条目」统一替换原文混用的 feed、项目等写法。字段名与可选、必需标注均按原文保留，未增删字段。

4.1 频道（Channel） #

xml
<channel>
<category> 可选的。为订阅源定义所属的一个或多个种类。
<cloud> 可选的。注册进程，以获得订阅源更新的立即通知。
<copyright> 可选的。告知版权资料。
<description> 必需的。描述频道。
<docs> 可选的。规定指向当前 RSS 文件所用格式说明的 URL。
<generator> 可选的。规定用于生成订阅源的程序。
<image> 可选的。在聚合器呈现某个订阅源时，显示一个图像。
<language> 可选的。规定编写订阅源所用的语言。
<lastBuildDate> 可选的。定义订阅源内容的最后修改日期。
<link> 必需的。定义指向频道的超链接。
<managingEditor> 可选的。定义订阅源内容编辑的电子邮件地址。
<pubDate> 可选的。为订阅源的内容定义最后发布日期。
<rating> 可选的。订阅源的 PICS 级别。
<skipDays> 可选的。规定忽略订阅源更新的天。
<skipHours> 可选的。规定忽略订阅源更新的小时。
<textInput> 可选的。规定应当与订阅源一同显示的文本输入域。

4.2 条目（Item） #

xml
<item>
<author> 可选的。规定条目作者的电子邮件地址。
<category> 可选的。定义条目所属的一个或多个类别。
<comments> 可选的。允许条目连接到有关此条目的注释（文件）。
<description> 必需的。描述此条目。
<enclosure> 可选的。允许将一个媒体文件导入一个条目中。
<guid> 可选的。为条目定义一个唯一的标识符。
<link> 必需的。定义指向此条目的超链接。
<pubDate> 可选的。定义此条目的最后发布日期。
<source> 可选的。为此条目指定一个第三方来源。

注意 原文两份清单的首行分别为 <channel> 参考手册 元素 描述 与 <item> 参考手册 元素 描述，属于表头而非字段定义，本篇按表头处理；两份清单仅列出上述元素，本篇不补写清单之外的字段。

八、小结 #

  • 部署：RSSHub 以 docker-compose.yml 启动，四步依次为下载配置、检查配置、创建 redis-data 卷、docker-compose up -d；配置文件地址为 https://raw.githubusercontent.com/DIYgod/RSSHub/master/docker-compose.yml （参见 第3节）。
  • 订阅源结构：频道与条目各有独立的元素清单，两者均以 <description>、<link> 为必需字段，其余字段标注为可选（参见 第4节）。
  • 验证：通过 http://www.feedvalidator.org/ 提供的验证器检查订阅源（参见 第5节）。
  • 阅读器：功能项按文字、图片、视频、设置四类归纳（参见 第6节）；实现相关内容在原文中仅为提纲（参见 第7节）。
