一、概述 #

Markdown 是一种轻量级标记语言，使用易读易写的纯文本格式编写文档，文档后缀通常为 .md 或 .markdown。Markdown 文档可以导出为 HTML、Word、图像、PDF、Epub 等多种格式，也可用于撰写电子书（如 Gitbook）。

注意 不同 Markdown 编辑器支持的语法略有差异。本篇所述的 GFM 工作清单、KaTeX 公式、SVG 流程图与 UML 顺序图等属于扩展语法，依赖具体渲染器，使用前须确认目标平台是否支持。

本篇按「基础排版 → 行内元素 → 块级元素 → 表格与脚注 → 扩展语法 → 速查表」组织，并在末尾给出常见错误与陷阱。

三、标题与段落 #

3.1 井号标题 #

使用 1 到 6 个 # 表示一级到六级标题，# 与标题文字之间保留一个空格：

markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题

3.2 底线式标题 #

也可用 = 和 - 分别标记一级和二级标题：

markdown
一级标题
=================
二级标题
-----------------

3.3 段落与换行 #

段落换行有两种写法：在行尾使用两个以上空格后回车，或在段落之后留一个空行。

四、文本样式 #

样式 语法 示例
加粗 前后 ** 或 __ **加粗**
斜体 前后 * 或 _ *斜体*
删除线 前后 ~~ ~~删除线~~
内联代码 前后单个反引号 code
下划线 HTML 标签 与 下划线
高亮 前后 == ==高亮文本==

对应的写法示例：

markdown
*斜体文本*
_斜体文本_
**粗体文本**
__粗体文本__
***粗斜体文本***
___粗斜体文本___
~~这是要删除的文本~~
<u>带下划线文本</u>

注意 下划线采用 HTML 的 标签，高亮采用 ==，二者都不是标准 Markdown 语法，取决于编辑器的扩展支持。

五、分隔线 #

在一行中用三个以上的星号、减号或底线建立分隔线，行内不能有其他内容；星号或减号之间也可插入空格。以下写法均有效：

markdown
***
* * *
*****
- - -
----------

六、列表 #

6.1 无序列表与有序列表 #

无序列表使用星号、加号或减号作为标记，标记后须加一个空格；有序列表使用数字加 .。

markdown
* 第一项
* 第二项
* 第三项
+ 第一项
- 第一项
1. 第一项
2. 第二项
3. 第三项

6.2 嵌套列表 #

子列表选项前添加两个或四个空格即可嵌套，无序与有序可混合：

markdown
1. 第一项：
- 第一项嵌套的第一个元素
- 第一项嵌套的第二个元素
2. 第二项：
- 第二项嵌套的第一个元素
- 第二项嵌套的第二个元素

6.3 任务列表 #

GFM 工作清单用 - [ ] 与 - [X] 表示未完成与已完成项，可逐层嵌套：

markdown
- [X]  A 计划
  - [X]  A1 计划
  - [ ]  A2 计划
- [ ]  B 计划

显示效果：渲染后为带勾选框的任务清单，已勾选与未勾选项目按层级缩进排列（原文此处为外链截图，本篇以文字描述）。

七、区块引用 #

区块引用在段落开头使用 > 后跟一个空格；> 可嵌套，也可在引用中使用列表，或在列表中使用引用（需在 > 前加四个空格缩进）。

markdown
> 区块
>> 区块嵌套
>>> 区块嵌套
> 1. 区块列表1
> 2. 区块列表2
> + 区块列表1
> + 区块列表2
* 列表1
    > 列表区块1
    > 列表区块2
* 列表2

八、代码 #

8.1 内联代码 #

段落中的函数或片段可用单个反引号包起，例如 printf()。

8.2 代码块 #

代码块有三种写法：行首四个空格、制表符缩进，或用三个反引号围栏包裹并指定语言。带语言标注的围栏示例：

javascript
// javascript 冒泡排序
function bubbleSort(array) {
  let swapped = true;
  do {
    swapped = false;
    for (let j = 0; j < array.length; j++) {
      if (array[j] > array[j + 1]) {
        let temp = array[j];
        array[j] = array[j + 1];
        array[j + 1] = temp;
        swapped = true;
      }
    }
  } while (swapped);
  return array;
}

注意 原素材称代码块支持 168 种编程语言；该数字为特定编辑器所声明的支持数量，不同渲染器支持的语言种类并不一致。

九、链接与图片 #

9.1 链接 #

行内链接写作 [链接名称](地址)，自动链接可直接用尖括号包裹地址，例如 <baidu.com>。也可把网址抽成变量放在文末，即参考式链接：

markdown
这个链接用 1 作为网址变量 [Google][1]
然后在文档的结尾为变量赋值（网址）

[1]: http://www.google.com/
[猿料]: https://yuanliao.info

有效外链示例：Blog 网址、Google、猿料。在部分编辑器中，鼠标右击或按住 Ctrl 键点击链接可用系统默认浏览器打开。

9.2 图片 #

图片语法与链接相似，前缀为 !，并可附可选标题：

markdown
![alt 属性文本](图片地址)
![alt 属性文本](图片地址 "可选标题")

图片地址也可按高级链接的方式放在文档结尾；若要修改图片大小，可采用 HTML 的 标签。部分编辑器支持拖放图片文件或粘贴截图，可直接把图片源数据存入笔记，并可将图片作为文件拖动到任意窗口使用。

显示效果：原素材此处为一张外链 LOGO 图片（第三方代码托管图床上的图标文件），本篇以文字描述替代，避免外链失效（原文此处为外链截图，本篇以文字描述）。

十、表格 #

使用 | 分隔单元格，用 - 分隔表头与其余行：

markdown
|  表头   | 表头  |
|  ----  | ----  |
| 单元格  | 单元格 |
| 单元格  | 单元格 |

对齐方式由分隔行中的冒号决定：-: 使内容和标题栏居右，:- 居左，:-: 居中。

十一、脚注 #

脚注是对文本的补充说明，格式为 [^要注明的文本]；具体渲染效果取决于编辑器是否支持脚注扩展。

下表把常用语法压缩为一处，便于快速查阅。

类别 写法 说明
引用 > 加空格 区块引用，可嵌套。
链接 [名称](地址) 行内链接；[名称][变量] 为参考式链接。
图片 ![alt](地址) 可加可选标题。
无序列表 -、*、+ 加空格 子项缩进二或四空格。

13.2 KaTeX 数学公式 #

KaTeX 支持内联公式与公式块，官网为 KaTeX。内联公式用单个 $ 包裹，例如质能方程 $E=mc^2$；公式块用两个 $ 包裹，例如柯西–施瓦茨不等式：

markdown
$$
\displaystyle \left( \sum_{k=1}^n a_k b_k \right)^2 \leq \left( \sum_{k=1}^n a_k^2 \right) \left( \sum_{k=1}^n b_k^2 \right)
$$

十四、小结 #

Markdown 以纯文本描述文档结构：标题与段落构成骨架，文本样式、链接、图片构成行内元素，列表、区块引用、代码、表格与脚注构成块级元素，GFM 工作清单、KaTeX 公式、SVG 与 UML 图表为常见扩展。基础语法在各编辑器间较为一致，扩展语法则须逐一确认渲染器支持情况。原文中的语法示例、样式速查表与代码片段已合并进对应章节，重复出现的「链接」「图片」小节只保留信息更完整的一份。

十五、常见错误与陷阱 #

  • 标题层级混用：一篇文档应只有一个一级标题；作为语法示范的 #、## 行必须放进代码块，否则会被渲染成真实标题、破坏结构。
  • 围栏语言误标：原素材把大量 Markdown 示例标为 cpp，本篇统一改为 markdown；代码块须标注与内容一致的语言，且围栏成对。
  • 外链截图失效：原素材含第三方图床上的 8 张截图与 1 张 LOGO，均为外链托管，存在失效风险，本篇已统一改为文字说明。
  • HTML 标签依赖渲染器： 下划线、 调整图片大小并非标准 Markdown，部分平台会原样输出或过滤。
  • 扩展语法非通用：任务列表、== 高亮、脚注、KaTeX、SVG、UML 都需要对应扩展支持，不能假定所有编辑器均可渲染。
  • 对齐符位置：表格分隔行的 -:、:-、:-: 决定居右、居左、居中，冒号位置写错会导致对齐失效。
  • 链接与图片地址：地址中若含空格或括号须妥善转义；把图片地址放在文末的参考式写法须保证变量定义存在，否则链接无法解析。
